# 微服务示例

可运行的实现及其说明在
**[container-app/microservices](../container-app/microservices/README.md)**。

此目录仅供导航。它不包含 `azure.yaml`、`infra/` 或 `src/`。
不要在这里运行 `azd up`。

从仓库根目录开始：

```bash
cd examples/container-app/microservices
```

然后按照链接的 README 说明，了解先决条件、部署、验证、本地
开发、实用练习、成本和清理方法。

示例包含一个 Node.js API 网关和一个只读 Python 产品服务。
订单、用户、通知、数据库和消息服务是扩展思路，
不是此仓库中包含的实现。
