# মাইক্রোসার্ভিস উদাহরণ

চালানোযোগ্য বাস্তবায়ন এবং এর নির্দেশাবলী রয়েছে
**[container-app/microservices](../container-app/microservices/README.md)** এ।

এই ডিরেক্টরি শুধুমাত্র নেভিগেশন এর জন্য। এতে কোন `azure.yaml`, `infra/`, বা `src/` নেই।
এখানে `azd up` চালাবেন না।

রিপোজিটরি রুট থেকে:

```bash
cd examples/container-app/microservices
```

তারপর পূর্বশর্ত, মোতায়েন, যাচাইকরণ, লোকাল
ডেভেলপমেন্ট, ব্যবহারিক অনুশীলন, খরচ, এবং পরিষ্কার করার জন্য সংযুক্ত README অনুসরণ করুন।

নমুনাটিতে একটি Node.js API গেটওয়ে এবং একটি শুধুমাত্র পড়ার জন্য Python প্রোডাক্ট সার্ভিস রয়েছে।
অর্ডার, ব্যবহারকারী, নোটিফিকেশন, ডেটাবেস, এবং মেসেজিং সার্ভিসগুলি এক্সটেনশন আইডিয়া,
এই রিপোজিটরির অন্তর্ভুক্ত নয় এমন বাস্তবায়ন।
