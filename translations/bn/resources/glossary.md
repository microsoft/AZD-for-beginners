- **📖 বেসিক শিখুন**: [অধ্যায় ১: AZD বেসিক](../docs/chapter-01-foundation/azd-basics.md)
- **🤖 AI পরিভাষা**: [অধ্যায় ২: AI-প্রথম উন্নয়ন](../docs/chapter-02-ai-development/microsoft-foundry-integration.md)

## পরিচিতি

এই ব্যাপক শব্দকোষটি Azure Developer CLI এবং Azure ক্লাউড উন্নয়নে ব্যবহৃত পরিভাষা, ধারণা এবং সংক্ষিপ্ত রূপের সংজ্ঞা প্রদান করে। প্রযুক্তিগত ডকুমেন্টেশন বুঝতে, সমস্যা সমাধান করতে এবং azd প্রকল্প ও Azure পরিষেবা সম্পর্কে কার্যকরভাবে যোগাযোগের জন্য অপরিহার্য রেফারেন্স।

## শেখার লক্ষ্য

এই শব্দকোষ ব্যবহার করে আপনি:
- Azure Developer CLI পরিভাষা এবং ধারণাগুলি বুঝতে পারবেন
- Azure ক্লাউড উন্নয়ন সংক্রান্ত শব্দভান্ডার এবং প্রযুক্তিগত শব্দগুচ্ছ আয়ত্ত করতে পারবেন
- Infrastructure as Code এবং ডিপ্লয়মেন্ট পরিভাষা দক্ষতার সঙ্গে রেফারেন্স করতে পারবেন
- Azure পরিষেবা নাম, সংক্ষিপ্ত রূপ এবং তাদের উদ্দেশ্য বুঝতে পারবেন
- সমস্যা নির্ণয় এবং ডিবাগিং পরিভাষার সংজ্ঞাগুলি এক্সেস করতে পারবেন
- উন্নত Azure আর্কিটেকচার এবং উন্নয়ন ধারণা শিখতে পারবেন

## শেখার ফলাফল

নিয়মিত এই শব্দকোষ রেফারেন্স করলে, আপনি সক্ষম হবেন:
- সঠিক Azure Developer CLI পরিভাষা ব্যবহার করে কার্যকরভাবে যোগাযোগ করতে
- প্রযুক্তিগত ডকুমেন্টেশন এবং ত্রুটি বার্তা পরিষ্কারভাবে বুঝতে
- আত্মবিশ্বাসের সঙ্গে Azure পরিষেবা ও ধারণায় নেভিগেট করতে
- উপযুক্ত প্রযুক্তিগত শব্দভাণ্ডার ব্যবহার করে সমস্যা নির্ণয় করতে
- সঠিক প্রযুক্তিগত ভাষা দিয়ে দলের আলোচনায় অবদান রাখতে
- নিয়মিত আপনার Azure ক্লাউড বিকাশের জ্ঞান সম্প্রসারিত করতে

## A

**ARM টেমপ্লেট**  
Azure Resource Manager টেমপ্লেট। JSON-ভিত্তিক Infrastructure as Code ফর্ম্যাট যা Azure রিসোর্সগুলি ডিক্লেয়ারেটিভভাবে সংজ্ঞায়িত এবং ডিপ্লয় করার জন্য ব্যবহৃত হয়।

**অ্যাপ সার্ভিস**  
Azure-এর প্ল্যাটফর্ম-অ্যাজ-এ-সার্ভিস (PaaS) অফার যা ওয়েব অ্যাপ্লিকেশন, REST API এবং মোবাইল ব্যাকএন্ড হোস্ট করার জন্য ব্যবহৃত হয়, যেখানে অবকাঠামো ব্যবস্থাপনা করতে হয় না।

**অ্যাপ্লিকেশন ইনসাইটস**  
Azure-এর অ্যাপ্লিকেশন পারফরম্যান্স মনিটরিং (APM) সেবা যা অ্যাপ্লিকেশনের কর্মক্ষমতা, উপলব্ধতা এবং ব্যবহার সম্পর্কে গভীর অন্তর্দৃষ্টি প্রদান করে।

**Azure CLI**  
Azure রিসোর্স পরিচালনার জন্য কমান্ড-লাইন ইন্টারফেস। এটি AZD কে সম্পূরক করে কিন্তু আলাদা লগইন রয়েছে; মূল AZD প্রমাণীকরণ `azd auth login` ব্যবহার করে।

**Azure Developer CLI (azd)**  
ডেভেলপার-কেন্দ্রিক কমান্ড-লাইন টুল যা টেমপ্লেট এবং Infrastructure as Code ব্যবহার করে Azure-এ অ্যাপ্লিকেশন তৈরি এবং ডিপ্লয়মেন্ট প্রক্রিয়া দ্রুততর করে।

**azure.yaml**  
azd প্রকল্পের প্রধান কনফিগারেশন ফাইল যা পরিষেবা, অবকাঠামো এবং ডিপ্লয়মেন্ট হুক সংজ্ঞায়িত করে।

**Azure Resource Manager (ARM)**  
Azure এর ডিপ্লয়মেন্ট এবং ব্যবস্থাপনা পরিষেবা যা রিসোর্স তৈরি, আপডেট এবং মোছার জন্য একটি ব্যবস্থাপনা স্তর প্রদান করে।

## B

**Bicep**  
Microsoft দ্বারা তৈরি ডোমেইন-স্পেসিফিক ল্যাংগুয়েজ (DSL) যা Azure রিসোর্স ডিপ্লয়মেন্টের জন্য ব্যবহৃত হয়। ARM টেমপ্লেট থেকে সহজ সিঙ্কট্যাক্স প্রদান করে এবং ARM-এ কম্পাইল হয়।

**বিল্ড**  
সোর্স কোড কম্পাইল, ডিপেন্ডেন্সি ইনস্টল এবং অ্যাপ্লিকেশন ডিপ্লয়মেন্টের জন্য প্রস্তুত করার প্রক্রিয়া।

**ব্লু-গ্রীন ডিপ্লয়মেন্ট**  
ডিপ্লয়মেন্ট স্ট্রাটেজি যা দুইটি অভিন্ন প্রোডাকশন পরিবেশ (নীল ও সবুজ) ব্যবহার করে ডাউনটাইম এবং ঝুঁকি কমায়।

## C

**কন্টেইনার অ্যাপস**  
Azure-এর সার্ভারলেস কন্টেইনার সার্ভিস যা জটিল অবকাঠামো ম্যানেজ না করে কন্টেইনারাইজড অ্যাপ্লিকেশন চালাতে সক্ষম করে।

**CI/CD**  
কন্টিনিউয়াস ইন্টিগ্রেশন/কন্টিনিউয়াস ডিপ্লয়মেন্ট। কোড পরিবর্তন একীকরণ এবং অ্যাপ্লিকেশন ডিপ্লয়মেন্টের স্বয়ংক্রিয় পদ্ধতি।

**Cosmos DB**  
Azure-এর গ্লোবালি বিতরণকৃত, মাল্টি-মডেল ডাটাবেস সার্ভিস যা থ্রুপুট, ল্যাটেন্সি, উপলব্ধতা এবং কনসিস্টেন্সির জন্য ব্যাপক SLA প্রদান করে।

**কনফিগারেশন**  
সেটিংস এবং প্যারামিটার যা অ্যাপ্লিকেশনের আচরণ এবং ডিপ্লয়মেন্ট বিকল্প নিয়ন্ত্রণ করে।

## D

**ডিপ্লয়মেন্ট**  
লক্ষ্য অবকাঠামোতে অ্যাপ্লিকেশন এবং তাদের ডিপেন্ডেন্সি ইনস্টল ও কনফিগার করার প্রক্রিয়া।

**ডকার**  
কন্টেইনার প্রযুক্তি ব্যবহার করে অ্যাপ্লিকেশন উন্নয়ন, শিপিং এবং চালানোর প্ল্যাটফর্ম।

**Dockerfile**  
একটি টেক্সট ফাইল যা ডকার কন্টেইনার ইমেজ বিল্ড করার নির্দেশনা ধারণ করে।

## E

**এনভায়রনমেন্ট**  
একটি ডিপ্লয়মেন্ট লক্ষ্য যা আপনার অ্যাপ্লিকেশনের নির্দিষ্ট একটি ইনস্ট্যান্স প্রতিনিধিত্ব করে (যেমন, ডেভেলপমেন্ট, স্টেজিং, প্রোডাকশন)।

**এনভায়রনমেন্ট ভেরিয়েবলস**  
কনফিগারেশন মান যা কীগুলি ও ভ্যালু জোড়া হিসেবে সংরক্ষণ করা হয় এবং অ্যাপ্লিকেশন রানটাইমে অ্যাক্সেস করতে পারে।

**এন্ডপয়েন্ট**  
URL বা নেটওয়ার্ক ঠিকানা যেখানে একটি অ্যাপ্লিকেশন বা সেবা অ্যাক্সেস করা যায়।

## F

**ফাংশন অ্যাপ**  
Azure-এর সার্ভারলেস কম্পিউট সার্ভিস যা অবকাঠামো পরিচালনা ছাড়াই ইভেন্ট-চালিত কোড চালানোর সুযোগ দেয়।

## G

**GitHub Actions**  
GitHub রিপোজিটরির সাথে সংযুক্ত CI/CD প্ল্যাটফর্ম যা ওয়ার্কফ্লো স্বয়ংক্রিয় করে।

**Git**  
সোর্স কোডের পরিবর্তন ট্র্যাক করার জন্য ব্যবহৃত বিতরণকৃত ভার্সন কন্ট্রোল সিস্টেম।

## H

**হুকস**  
কাস্টম স্ক্রিপ্ট বা কমান্ড যা ডিপ্লয়মেন্ট লাইফসাইকেলের নির্দিষ্ট পয়েন্টে চালানো হয় (প্রিপ্রোভিশন, পোস্টপ্রোভিশন, প্রিডিপ্লয়, পোস্টডিপ্লয়)।

**হোস্ট**  
Azure পরিষেবা ধরণ যেখানে একটি অ্যাপ্লিকেশন ডিপ্লয় করা হবে (যেমন, appservice, containerapp, function)।

## I

**Infrastructure as Code (IaC)**  
অবকাঠামো কোডের মাধ্যমে সংজ্ঞায়িত এবং পরিচালনার প্র্যাকটিস, ম্যানুয়াল পদ্ধতির পরিবর্তে।

**Init**  
একটি নতুন azd প্রকল্প আরম্ভ করার প্রক্রিয়া, সাধারণত একটি টেমপ্লেট থেকে।

## J

**JSON**  
JavaScript Object Notation। সাধারণত কনফিগারেশন ফাইল এবং API রেসপন্সের জন্য ব্যবহৃত ডেটা বিনিময়ের ফর্ম্যাট।

**JWT**  
JSON Web Token। পক্ষগুলোর মধ্যে তথ্য নিরাপদে প্রেরণের জন্য JSON অবজেক্ট ফরম্যাট।

## K

**কি ভল্ট**  
Azure-এর সেবা যা সিক্রেট, কী এবং সার্টিফিকেট নিরাপদে সংরক্ষণ ও পরিচালনা করে।

**Kusto Query Language (KQL)**  
Azure মনিটর, অ্যাপ্লিকেশন ইনসাইটস এবং অন্যান্য Azure পরিষেবায় ডেটা বিশ্লেষণের জন্য ব্যবহৃত প্রশ্ন ভাষা।

## L

**লোড ব্যালেন্সার**  
একটি সেবা যা একাধিক সার্ভার বা ইনস্ট্যান্সের মধ্যে আসা নেটওয়ার্ক ট্র্যাফিক বন্টন করে।

**লগ অ্যানালেটিক্স**  
Azure-এর সেবা যা ক্লাউড এবং অন-প্রিমাইস পরিবেশ থেকে টেলিমেট্রি ডেটা সংগ্রহ, বিশ্লেষণ এবং পরিচালনা করে।

## M

**ম্যানেজড আইডেন্টিটি**  
Azure-এর বৈশিষ্ট্য যা অন্যান্য Azure পরিষেবায় প্রমাণীকরণের জন্য স্বয়ংক্রিয়ভাবে পরিচালিত আইডেন্টিটি প্রদান করে।

**মাইক্রোসার্ভিসেস**  
আর্কিটেকচরিক্যাল পদ্ধতি যেখানে অ্যাপ্লিকেশনগুলো ছোট, স্বতন্ত্র সার্ভিসের সমষ্টি হিসাবে তৈরি হয়।

**মনিটর**  
Azure-এর এককরণের মনিটরিং সমাধান যা অ্যাপ্লিকেশন এবং অবকাঠামোর পূর্ণ-স্ট্যাক পর্যবেক্ষণ সুবিধা প্রদান করে।

## N

**Node.js**  
ক্রোমের V8 JavaScript ইঞ্জিনের ওপর নির্মিত জাভাস্ক্রিপ্ট রানটাইম, যা সার্ভার-সাইড অ্যাপ্লিকেশন তৈরির জন্য ব্যবহৃত হয়।

**npm**  
Node.js-এর প্যাকেজ ম্যানেজার যা ডিপেন্ডেন্সি এবং প্যাকেজ পরিচালনা করে।

## O

**আউটপুট**  
অবকাঠামো ডিপ্লয়মেন্ট থেকে ফেরত আসা মান যা অ্যাপ্লিকেশন বা অন্যান্য রিসোর্সগুলি ব্যবহার করতে পারে।

## P

**প্যাকেজ**  
ডিপ্লয়মেন্টের জন্য অ্যাপ্লিকেশন কোড এবং ডিপেন্ডেন্সি প্রস্তুত করার প্রক্রিয়া।

**প্যারামিটারস**  
অবকাঠামো টেমপ্লেটে ইনপুট মান প্রদান করে ডিপ্লয়মেন্ট কাস্টমাইজ করার জন্য।

**PostgreSQL**  
ওপেন-সোর্স রিলেশনাল ডাটাবেস সিস্টেম যা Azure-তে ম্যানেজড সার্ভিস হিসেবে সমর্থিত।

**প্রোভিশনিং**  
অবকাঠামো টেমপ্লেটে সংজ্ঞায়িত Azure রিসোর্স তৈরি এবং কনফিগার করার প্রক্রিয়া।

## Q

**কোটা**  
Azure সাবস্ক্রিপশন বা অঞ্চলে তৈরি করা যেতে পারে এমন রিসোর্সের পরিমান সীমা।

## R

**রিসোর্স গ্রুপ**  
Azure রিসোর্সের একটি যৌক্তিক পাত্র যা একই জীবনচক্র, অনুমতি এবং নীতিমালা ভাগ করে।

**রিসোর্স টোকেন**  
azd দ্বারা তৈরি অনন্য স্ট্রিং যা ডিপ্লয়মেন্ট জুড়ে রিসোর্স নামের ইউনিকনেস নিশ্চিত করে।

**REST API**  
HTTP পদ্ধতি ব্যবহার করে নেটওয়ার্কযুক্ত অ্যাপ্লিকেশন ডিজাইনের আর্কিটেকচরিক্যাল স্টাইল।

**রোলব্যাক**  
একটি অ্যাপ্লিকেশন বা অবকাঠামো কনফিগারেশনের পূর্ববর্তী সংস্করণে ফিরে যাওয়ার প্রক্রিয়া।

## S

**সার্ভিস**  
আপনার অ্যাপ্লিকেশনের একটি উপাদান যা azure.yaml-এ সংজ্ঞায়িত (যেমন, ওয়েব ফ্রন্টেন্ড, API ব্যাকএন্ড, ডাটাবেস)।

**SKU**  
স্টক কিপিং ইউনিট। Azure রিসোর্সের বিভিন্ন সার্ভিস স্তর বা পারফরম্যান্স স্তর উপস্থাপন করে।

**SQL ডাটাবেস**  
Microsoft SQL Server ভিত্তিক Azure-এর ম্যানেজড রিলেশনাল ডাটাবেস সার্ভিস।

**স্ট্যাটিক ওয়েব অ্যাপস**  
সোর্স কোড রিপোজিটরি থেকে সম্পূর্ণ-স্ট্যাক ওয়েব অ্যাপ্লিকেশন তৈরি এবং ডিপ্লয় করার জন্য Azure সেবা।

**স্টোরেজ অ্যাকাউন্ট**  
Azure সেবা যা ব্লব, ফাইল, কিউ এবং টেবিল সহ ডেটা অবজেক্টের জন্য ক্লাউড স্টোরেজ প্রদান করে।

**সাবস্ক্রিপশন**  
Azure অ্যাকাউন্টের কন্টেইনার যা রিসোর্স গ্রুপ এবং রিসোর্স ধারণ করে, বিলিং এবং অ্যাক্সেস ব্যবস্থাপনার সঙ্গে।

## T

**টেমপ্লেট**  
পূর্বনির্মিত প্রকল্প কাঠামো যা সাধারণ প্রেক্ষাপটে অ্যাপ্লিকেশন কোড, অবকাঠামো সংজ্ঞা এবং কনফিগারেশন অন্তর্ভুক্ত করে।

**Terraform**  
ওপেন-সোর্স Infrastructure as Code টুল যা Azure সহ একাধিক ক্লাউড প্রদানকারী সমর্থন করে।

**ট্রাফিক ম্যানেজার**  
বিশ্বব্যাপী Azure অঞ্চলের মধ্যে ট্রাফিক বিতরণের জন্য Azure-এর DNS-ভিত্তিক ট্রাফিক লোড ব্যালেন্সার।

## U

**URI**  
ইউনিফর্ম রিসোর্স আইডেন্টিফায়ার। একটি স্ট্রিং যা একটি নির্দিষ্ট রিসোর্সকে নির্দেশ করে।

**URL**  
ইউনিফর্ম রিসোর্স লোকেটর। URI-এর এমন একটি ধরন যা একটি রিসোর্স কোথায় অবস্থিত এবং কিভাবে তা পাওয়া যায় তা নির্দিষ্ট করে।

## V

**ভার্চুয়াল নেটওয়ার্ক (VNet)**  
Azure-এর জন্য বেসিক প্রাইভেট নেটওয়ার্ক ব্লক যা বিচ্ছিন্নতা এবং সেগমেন্টেশন প্রদান করে।

**VS কোড**  
Visual Studio Code। একটি জনপ্রিয় কোড সম্পাদক যা Azure এবং azd ইন্টিগ্রেশনের জন্য চমৎকার।

## W

**Webhook**  
HTTP কলব্যাক যা নির্দিষ্ট ইভেন্টের মাধ্যমে ট্রিগার হয়, সাধারণত CI/CD পাইপলাইনে ব্যবহৃত হয়।

**What-if**  
Azure বৈশিষ্ট্য যা ডিপ্লয়মেন্ট সম্পাদন না করে কি পরিবর্তন হবে তা দেখায়।

## Y

**YAML**  
YAML Ain't Markup Language. এমন একটি মানব-পাঠযোগ্য ডেটা সিরিয়ালাইজেশন স্ট্যান্ডার্ড যা azure.yaml-এর মতো কনফিগারেশন ফাইলের জন্য ব্যবহৃত হয়।

## Z

**জোন**  
Azure অঞ্চলের ভৌত পৃথক স্থান যা রিডান্ডেন্সি এবং উচ্চ উপলব্ধতা প্রদান করে।

## Azure সেবা নামের মিল

| সাধারণ নাম | অফিসিয়াল Azure সেবা নাম | azd হোস্ট টাইপ |
|-------------|------------------------------|---------------|
| ওয়েব অ্যাপ | Azure App Service | `appservice` |
| API অ্যাপ | Azure App Service | `appservice` |
| কন্টেইনার অ্যাপ | Azure Container Apps | `containerapp` |
| ফাংশন | Azure Functions | `function` |
| স্ট্যাটিক সাইট | Azure Static Web Apps | `staticwebapp` |
| ডাটাবেস | Azure Database for PostgreSQL | অবকাঠামো রিসোর্স, অ্যাপ্লিকেশন নয় `host` |
| NoSQL ডাটাবেস | Azure Cosmos DB | অবকাঠামো রিসোর্স, অ্যাপ্লিকেশন নয় `host` |
| স্টোরেজ | Azure Storage Account | অবকাঠামো রিসোর্স, বিল্ট-ইন অ্যাপ্লিকেশন নয় `host` |
| ক্যাশ | Azure Managed Redis | অবকাঠামো রিসোর্স, অ্যাপ্লিকেশন নয় `host` |
| সার্চ | Azure AI Search | অবকাঠামো রিসোর্স, অ্যাপ্লিকেশন নয় `host` |
| মেসেজিং | Azure Service Bus | অবকাঠামো রিসোর্স, অ্যাপ্লিকেশন নয় `host` |

`services.<name>.host` একটি অ্যাপ্লিকেশন ডিপ্লয়মেন্ট লক্ষ্য নির্বাচন করে; এটি কোনো Azure রিসোর্স প্রকারের জন্য শর্টহ্যান্ড নয়। ডাটাবেস, ক্যাশ, সার্চ সার্ভিস এবং কিউগুলি সাধারণত অবকাঠামো প্রদানকারীর মাধ্যমে প্রোভিশন করা হয় এবং আউটপুট/কনফিগারেশনের মাধ্যমে অ্যাপ্লিকেশনের সাথে সংযুক্ত থাকে।

## প্রসঙ্গ-নির্দিষ্ট শব্দ

### উন্নয়ন শব্দ
- **হট রিলোড**: উন্নয়নের সময় স্বয়ংক্রিয়ভাবে অ্যাপ্লিকেশন আপডেট করা রিস্টার্ট ছাড়া
- **বিল্ড পাইপলাইন**: কোড বিল্ড এবং টেস্ট করার স্বয়ংক্রিয় প্রক্রিয়া
- **ডিপ্লয়মেন্ট স্লট**: একটি অ্যাপ সার্ভিসের মধ্যে স্টেজিং পরিবেশ
- **এনভায়রনমেন্ট প্যারিটি**: ডেভেলপমেন্ট, স্টেজিং এবং প্রোডাকশন পরিবেশগুলিকে একই রকম রাখা

### নিরাপত্তার শব্দ
- **ম্যানেজড আইডেন্টিটি**: স্বয়ংক্রিয় ক্রেডেনশিয়াল ব্যবস্থাপনা প্রদান করে Azure বৈশিষ্ট্য
- **কি ভল্ট**: সিক্রেট, কী এবং সার্টিফিকেটের জন্য নিরাপদ সংরক্ষণ
- **RBAC**: Azure রিসোর্সের জন্য ভূমিকা-ভিত্তিক অ্যাক্সেস নিয়ন্ত্রণ
- **নেটওয়ার্ক সিকিউরিটি গ্রুপ**: নেটওয়ার্ক ট্র্যাফিক নিয়ন্ত্রণের ভার্চুয়াল ফায়ারওয়াল

### মনিটরিং শব্দ
- **টেলিমেট্রি**: পরিমাপ এবং ডেটার স্বয়ংক্রিয় সংগ্রহ
- **অ্যাপ্লিকেশন পারফরম্যান্স মনিটরিং (APM)**: সফটওয়্যার কর্মক্ষমতা পর্যবেক্ষণ
- **লগ অ্যানালেটিক্স**: লগ ডেটা সংগ্রহ এবং বিশ্লেষণের সেবা
- **অ্যালার্ট রুলস**: মেট্রিক বা শর্তের উপর ভিত্তি করে স্বয়ংক্রিয় নোটিফিকেশন

### ডিপ্লয়মেন্ট শব্দ
- **ব্লু-গ্রীন ডিপ্লয়মেন্ট**: জিরো-ডাউনটাইম ডিপ্লয়মেন্ট স্ট্র্যাটেজি
- **ক্যানারি ডিপ্লয়মেন্ট**: ব্যবহারকারীদের একটি উপসেটের জন্য ধীরে ধীরে রোলআউট
- **রোলিং আপডেট**: ধারাবাহিকভাবে অ্যাপ্লিকেশন ইনস্ট্যান্স প্রতিস্থাপন
- **রোলব্যাক**: পূর্ববর্তী অ্যাপ্লিকেশন সংস্করণে ফিরে যাওয়া
