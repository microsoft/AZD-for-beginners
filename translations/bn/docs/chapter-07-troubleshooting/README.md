## ওভারভিউ

এই অধ্যায়টি আপনাকে Azure Developer CLI ব্যবহার করার সময় সাধারণ সমস্যা নির্ণয় ও সমাধানে সাহায্য করবে। ডিপ্লয়মেন্ট ব্যর্থতা থেকে AI-সংক্রান্ত সমস্যাগুলো পর্যন্ত।

> কমান্ড নির্দেশিকা মুক্তিপ্রাপ্ত `azd 1.37.2` রেফারেন্সের বিরুদ্ধে পর্যালোচিত। ক্লাউড ডিপ্লয়মেন্ট কার্যকর করা হয়নি। কমান্ড ব্যবহারের আগে উদাহরণ রিসোর্স নাম এবং আইডি পরিবর্তন করুন।

## শেখার উদ্দেশ্য

এই অধ্যায় সম্পন্ন করলে আপনি পারবেন:
- সাধারণ AZD ডিপ্লয়মেন্ট ব্যর্থতা নির্ণয় করতে
- প্রমাণীকরণ ও অনুমতি সমস্যা ডিবাগ করতে
- AI সার্ভিস সংযোগ সমস্যা সমাধান করতে
- সমস্যার সমাধানের জন্য Azure Portal এবং CLI ব্যবহার করতে

## 🚨 দ্রুত সমাধান

### প্রমাণীকরণ সমস্যা
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### প্রোভিশনিং ব্যর্থতা
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### রিসোর্স দ্বন্দ্ব
প্রথমে বিদ্যমান রিসোর্স এবং ডিপ্লয়মেন্ট ত্রুটি পরীক্ষা করুন। একটি শেয়ার্ড বা প্রোডাকশন পরিবেশ মুছে নামের দ্বন্দ্ব সমাধান করবেন না। একটি **নতুন ব্যবহারযোগ্য পরিবেশের** জন্য একটি ইউনিক নাম ব্যবহার করুন:

```bash
azd env new different-name
azd up
```

### কোটা ছাড়ানো
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

`AZURE_LOCATION` পরিবর্তন করলে বিদ্যমান রিসোর্স স্থানান্তর হয় না এবং পুনঃডিপ্লয়মেন্টে লোকেশন দ্বন্দ্ব হতে পারে।

## 📋 ত্রুটি কোড রেফারেন্স

| ত্রুটি | কারণ | সমাধান |
|-------|-------|----------|
| `AuthenticationError` | লগ ইন করা হয়নি | `azd auth login` |
| `ResourceNotFound` | রিসোর্স অনুপস্থিত | রিসোর্স নাম পরীক্ষা করুন |
| `QuotaExceeded` | সাবস্ক্রিপশন সীমা | কোটা বৃদ্ধির অনুরোধ করুন |
| `InvalidTemplate` | Bicep সিনট্যাক্স ত্রুটি | `az bicep build` |
| `Conflict` | রিসোর্স বিদ্যমান | নতুন নাম ব্যবহার করুন বা মুছে ফেলুন |
| `Forbidden` | অনুপলব্ধ অনুমতি | RBAC রোল চেক করুন |

## 🔄 রিসেট এবং পুনরুদ্ধার

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

হার্ড রিসেট ডেটা মুছে দেয় এবং এন্ডপয়েন্ট পরিবর্তিত হতে পারে। প্রথমে ব্যাকআপ নিন এবং ইন্টারেক্টিভ ডিলিশন প্রম্পটগুলি পর্যালোচনা করুন। `--force --purge` শুধুমাত্র ব্যবহারযোগ্য পরিবেশের জন্য প্রযোজ্য যেখানে অপরিবর্তনীয় মুছে ফেলা ইচ্ছাকৃত।
