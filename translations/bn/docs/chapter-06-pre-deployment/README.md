**📚 কোর্স**: [শুরুর জন্য AZD](../../README.md) | **⏱️ সময়কাল**: ২-৪ ঘণ্টা পাঠ; পরিবর্তিত ল্যাবের জন্য অতিরিক্ত সময় | **⭐ জটিলতা**: মধ্যম–উন্নত

## পর্যালোচনা

এই অধ্যায়ে আপনার অ্যাপ্লিকেশন মোতায়েনের পূর্বে অপরিহার্য পরিকল্পনা এবং যাচাই ধাপগুলি আলোচনা করা হয়েছে। সঠিক ক্ষমতা পরিকল্পনা, SKU নির্বাচন এবং প্রিফ্লাইট চেকের মাধ্যমে ব্যয়বহুল ভুল এড়ানো শিখুন।

> নির্দেশনা রিলিজকৃত `azd 1.37.2` রেফারেন্সের বিরুদ্ধে পর্যালোচনা করা হয়েছে। ক্লাউড মোতায়েন কার্যকর করা হয়নি। বড় পাঠগুলোতে চিত্রিত অংশ রয়েছে, সম্পূর্ণ স্থানীয় মোতায়েন প্রকল্প নয়।

## শিক্ষার উদ্দেশ্য

এই অধ্যায় সম্পন্ন করে, আপনি:
- মোতায়েনের পূর্বে প্রিফ্লাইট পরীক্ষা চালাবেন
- ক্ষমতা পরিকল্পনা করবেন এবং সম্পদের প্রয়োজনের অনুমান করবেন
- ব্যয় অপ্টিমাইজেশনের জন্য উপযুক্ত SKU নির্বাচন করবেন
- মনিটরিংয়ের জন্য অ্যাপ্লিকেশন ইনসাইটস কনফিগার করবেন
- বহুমুখী এজেন্ট সমন্বয় প্যাটার্ন এবং তাদের মোতায়েন প্রয়োজনীয়তা বুঝবেন

## 🚀 দ্রুত শুরু

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

az bicep build --file infra/main.bicep

azd env get-values
```

## ☑️ পূর্ব-নিয়োগ চেকলিস্ট

### `azd provision` এর পূর্বে

- [ ] অঞ্চলের জন্য কোটা যাচাই করা হয়েছে
- [ ] SKUs যথাযথভাবে নির্বাচিত
- [ ] ব্যয় অনুমান পর্যালোচনা করা হয়েছে
- [ ] নামকরণ পদ্ধতি সামঞ্জস্যপূর্ণ
- [ ] নিরাপত্তা/RBAC কনফিগার করা হয়েছে

### `azd deploy` এর পূর্বে

- [ ] পরিবেশ ভেরিয়েবল সেট করা হয়েছে
- [ ] Key Vault-এ সিক্রেট রাখা হয়েছে
- [ ] সংযোগ স্ট্রিং যাচাই করা হয়েছে
- [ ] স্বাস্থ্য পরীক্ষা কনফিগার করা হয়েছে
