# অধ্যায় ১: ভিত্তি ও দ্রুত শুরু

**📚 কোর্স**: [নতুনদের জন্য AZD](../../README.md) | **⏱️ সময়কাল**: প্রথম ডিপ্লয়মেন্টসহ ৭৫-১২০ মিনিট; অতিরিক্ত অনুশীলনগুলি বেশ সময় লাগে | **⭐ জটিলতা**: শিক্ষানবিশ

---

## ওভারভিউ

এই অধ্যায়ে Azure Developer CLI (azd) এর মূল বিষয়বস্তু পরিচিত করা হবে। আপনি মূল ধারণাগুলি শিখবেন, টুলস ইনস্টল করবেন এবং Azure-এ আপনার প্রথম অ্যাপ্লিকেশন ডিপ্লয় করবেন।

> কমান্ড এবং কনফিগারেশন পর্যালোচনা লক্ষ্যমাত্রা: `azd 1.37.2` (নভেম্বর ২০২৬)। পর্যালোচনার সময় লাইভ Azure provisioning চালানো হয়নি।

## শেখার উদ্দেশ্য

এই অধ্যায় সম্পন্ন করার মাধ্যমে আপনি:
- Azure Developer CLI কী এবং এটি Azure CLI থেকে কীভাবে পৃথক তা বুঝতে পারবেন
- আপনার প্ল্যাটফর্মে AZD ইনস্টল ও কনফিগার করতে পারবেন
- `azd up` ব্যবহার করে Azure-এ আপনার প্রথম অ্যাপ্লিকেশন ডিপ্লয় করতে পারবেন
- `azd down` ব্যবহার করে রিসোর্সগুলি পরিষ্কার করতে পারবেন

## ✅ এখানে শুরু করুন: আপনার সেটআপ যাচাই করুন

শুরু করার আগে, নিশ্চিত করুন আপনার স্থানীয় মেশিন ১ম অধ্যায়ের টেমপ্লেটের জন্য প্রস্তুত:

**উইন্ডোজ:**
```powershell
.\validate-setup.ps1
```

**ম্যাকওএস / লিনাক্স:**
```bash
bash ./validate-setup.sh
```

যদি স্ক্রিপ্ট কোন অভাবিত টুলস রিপোর্ট করে, সেগুলি প্রথমে ঠিক করুন এবং তারপর অধ্যায়টি চালিয়ে যান।

## 🚀 দ্রুত শুরু

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ সফলতার মানদণ্ড

এই অধ্যায় শেষ করার পর, আপনি সক্ষম হবেন:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
