# AI ডেভেলপারদের জন্য AZD কর্মশালা

> উৎস নির্দেশিকা AZD 1.37.2 অনুযায়ী ৪ নভেম্বর, ২০২৬ এ পর্যালোচনা করা হয়েছে। স্ক্রিনশটগুলি উদাহরণস্বরূপ; সেবার প্রাপ্যতা, পোর্টাল লেবেল এবং টেমপ্লেট ডিফল্ট পরিবর্তিত হতে পারে।

> [!IMPORTANT]  
> **এই কর্মশালাটি একটি কর্মশালা গাইড দিয়ে সজ্জিত যা আপনি আপনার স্থানীয় ব্রাউজারে প্রিভিউ করতে পারেন। শুরু করতে, GitHub Codespaces, একটি ডেভ কন্টেইনার, অথবা MkDocs ইন্সটল করা স্থানীয় ক্লোনে রিপো খুলুন—তারপর সক্রিয় VS Code টার্মিনাল দেখা পর্যন্ত অপেক্ষা করুন এবং টাইপ করুন:**  
> কোর্স রিপোজিটরি রুট থেকে `requirements-dev.txt` ইন্সটল করুন, তারপর সামনে চালু রাখার জন্য `python -m mkdocs serve --config-file workshop/mkdocs.yml` চালান।
> **আপনাকে একটি পপ-আপ ডায়ালগ দেখতে হবে যে ব্রাউজারে প্রিভিউ পৃষ্ঠা খোলা যাবে।**

AI অ্যাপ্লিকেশন ডিপ্লয়মেন্টের উপর মনোযোগ দিয়ে Azure Developer CLI (AZD) শেখার জন্য হাতে কলমে কর্মশালায় আপনাকে স্বাগতম। এই কর্মশালাটি ৩ ধাপে AZD টেমপ্লেটের ব্যবহারিক ধারণা অর্জনে সহায়তা করে:

1. **আবিষ্কার** - আপনার উপযোগী টেমপ্লেটটি খুঁজে বের করা।
1. **ডিপ্লয়মেন্ট** - ডিপ্লয় করুন এবং এটি কাজ করে কিনা যাচাই করুন
1. **ব্যক্তিগতকরণ** - পরিবর্তন করুন এবং পুনরাবৃত্তি করুন যতক্ষণ না এটি আপনার হয়ে ওঠে!

এই কর্মশালার মাধ্যমে, আপনাকে কোর ডেভেলপার টুল ও ওয়ার্কফ্লো ও পরিচয় করিয়ে দেওয়া হবে, যা আপনার সমগ্র-শেষ উন্নয়ন যাত্রা সহজতর করবে।

## আপনি কি শিখবেন

AZD টেমপ্লেটকে একটি শেখার স্যান্ডবক্স হিসাবে বিবেচনা করুন যা Microsoft Foundry তে শেষ থেকে শেষ পর্যন্ত উন্নয়নের বিভিন্ন ক্ষমতা ও সরঞ্জাম অন্বেষণ করতে দেয়। এই কর্মশালার শেষে, এই প্রসঙ্গে বিভিন্ন টুল ও ধারণার বিষয়ে আপনার একটি অন্তর্দৃষ্টিমূলক ধারণা থাকা উচিত।

| ধারণা  | উদ্দেশ্য |
|:---|:---|
| **Azure Developer CLI** | টুল কমান্ড ও ওয়ার্কফ্লো বুঝুন|
| **AZD টেমপ্লেটস**| প্রকল্পের গঠন ও কনফিগারেশন বুঝুন|
| **Azure AI Agent**| Microsoft Foundry প্রকল্প প্রদান ও ডিপ্লয়মেন্ট  |
| **Azure AI Search**| এজেন্ট সহ প্রসঙ্গ প্রকৌশল সক্ষম করুন |
| **পর্যবেক্ষণযোগ্যতা**| ট্রেসিং, মনিটরিং ও মূল্যায়ন অন্বেষণ |
| **রেড টিমিং**| প্রতিদ্বন্দ্বিতামূলক পরীক্ষণ ও শমনের কৌশল অন্বেষণ |
| | |
