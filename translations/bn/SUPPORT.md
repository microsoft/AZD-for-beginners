# সমর্থন

## কোর্স সংক্রান্ত সমস্যা ও প্রশ্ন

সমস্যা রিপোর্ট করার আগে [course issues](https://github.com/microsoft/AZD-for-beginners/issues) অনুসন্ধান করুন। প্রভাবিত ইংরেজি পাঠ, আপনি যে কমান্ড চালিয়েছেন, আপনার AZD/এক্সটেনশনের সংস্করণ এবং ত্রুটির বার্তাটি অন্তর্ভুক্ত করুন। লগ এবং স্ক্রিনশট থেকে শংসাপত্র, টোকেন, সাবস্ক্রিপশন তথ্য এবং ব্যক্তিগত ডেটা সরিয়ে দিন।

সাধারণ শিখন প্রশ্নের জন্য, [Azure developer community](https://discord.gg/microsoft-azure) ব্যবহার করুন। কমিউনিটির প্রতিক্রিয়া একটি নিশ্চিতে সমর্থন সেবা নয়।

## টুল এবং সার্ভিস সংক্রান্ত সমস্যা

পুনরুত্পাদনযোগ্য AZD CLI বাগ [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) রিপোর্ট করুন। Azure সার্ভিস ঘটনা বা সাবস্ক্রিপশন-নির্দিষ্ট সাহায্যের জন্য, [Azure portal](https://portal.azure.com/) এ উপলব্ধ সমর্থন বিকল্পগুলি ব্যবহার করুন।

## নিরাপত্তা রিপোর্টসমূহ

ব্যক্তিগত দুর্বলতা রিপোর্টিংয়ের জন্য [SECURITY.md](SECURITY.md) অনুসরণ করুন। জনসাধারণের কোর্স সমস্যা আলোচনায় সিক্রেট বা এক্সপ্লয়েট বিস্তারিত পোস্ট করবেন না।

## মাইক্রোসফট সমর্থন নীতি

এই শিক্ষামূলক প্রকল্পের সমর্থন উপরে তালিকাভুক্ত সম্পদ দ্বারা সীমাবদ্ধ। কোর্সের উদাহরণসমূহে উৎপাদন সমর্থন প্রতিশ্রুতি অন্তর্ভুক্ত নয়।
