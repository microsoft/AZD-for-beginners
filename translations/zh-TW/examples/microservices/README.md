# 微服務範例

可執行的實作與其說明位於
**[container-app/microservices](../container-app/microservices/README.md)**。

此目錄僅供導航使用。它沒有 `azure.yaml`、`infra/` 或 `src/`。
請勿在此執行 `azd up`。

從儲存庫根目錄開始：

```bash
cd examples/container-app/microservices
```

接著請參照連結的 README 了解先決條件、部署、驗證、本機開發、實務練習、費用及清理。


訂單、使用者、通知、資料庫及訊息服務是擴充點子， 
並非本儲存庫中包含的實作。
