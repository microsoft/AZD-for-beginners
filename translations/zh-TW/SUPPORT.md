# 支援

## 課程問題與疑問

在回報問題前，請先搜尋 [課程問題](https://github.com/microsoft/AZD-for-beginners/issues)。請包含受影響的英語課程、您執行的指令、您的 AZD/擴充套件版本及錯誤訊息。請從日誌與截圖中移除憑證、令牌、訂閱細節和個人資料。

一般學習問題請使用 [Azure 開發者社群](https://discord.gg/microsoft-azure)。社群回應不保證等同於支援服務。

## 工具與服務問題

可在 [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) 報告可重現的 AZD CLI 錯誤。針對 Azure 服務事件或訂閱相關協助，請使用 [Azure 入口網站](https://portal.azure.com/) 中提供的支援選項。

## 安全性回報

請依照 [SECURITY.md](SECURITY.md) 提供私密的漏洞回報。請勿在公開課程問題中張貼密碼或漏洞細節。

## 微軟支援政策

本教學專案的支援僅限於上述資源。課程範例不包含正式的生產環境支援承諾。
