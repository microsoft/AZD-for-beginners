# 마이크로서비스 예제

실행 가능한 구현과 그 지침은
**[container-app/microservices](../container-app/microservices/README.md)** 에 있습니다.

이 디렉터리는 탐색용입니다. `azure.yaml`, `infra/`, 또는 `src/`가 없습니다.
여기서 `azd up`를 실행하지 마십시오.

저장소 루트에서:

```bash
cd examples/container-app/microservices
```

그런 다음 연결된 README를 따라 필수 조건, 배포, 검증, 로컬
개발, 실습, 비용, 정리에 대해 확인하십시오.

샘플에는 Node.js API 게이트웨이와 읽기 전용 Python 제품 서비스가 포함되어 있습니다.
주문, 사용자, 알림, 데이터베이스, 메시징 서비스는 확장 아이디어일 뿐,
이 저장소에 포함된 구현이 아닙니다.

- [다음: 데이터베이스 앱](../../../../examples/database-app)
- [AI 개발](../../docs/chapter-02-ai-development/README.md)
- [강좌 홈](../../README.md)
