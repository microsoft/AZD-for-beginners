# Exemplo de Microserviços

A implementação executável e as suas instruções estão em
**[container-app/microservices](../container-app/microservices/README.md)**.

Este diretório é apenas para navegação. Não contém `azure.yaml`, `infra/`, ou `src/`.
Não execute `azd up` aqui.

A partir da raiz do repositório:

```bash
cd examples/container-app/microservices
```

Depois siga o README ligado para pré-requisitos, implantação, verificação, desenvolvimento local,
exercícios práticos, custos e limpeza.

O exemplo contém uma API Gateway em Node.js e um Serviço de Produtos apenas leitura em Python.
Serviços de encomenda, utilizador, notificação, base de dados e mensagens são ideias de extensão,
não implementações incluídas neste repositório.
