# الفصل 2: تطوير يعتمد على الذكاء الاصطناعي أولاً

**📚 الدورة**: [AZD للمبتدئين](../../README.md) | **⏱️ المدة**: 4-5 ساعات بما في ذلك ورشة العمل | **⭐ التعقيد**: متوسط

---

## نظرة عامة

يركز هذا الفصل على نشر التطبيقات المدعومة بالذكاء الاصطناعي باستخدام Azure Developer CLI وخدمات Microsoft Foundry. من تطبيقات الدردشة البسيطة إلى الوكلاء الأذكياء المزودين بالأدوات.

> **تحديث Foundry GA (2026-11-09):** حزمة `microsoft.foundry` 1.0 متاحة [عموماً](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). استخدم `azd >= 1.37.0`؛ التقييمات تبقى تثبيتًا منفصلاً. يغطي [الشرح التوضيحي للوكيل المستضاف](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) اختبار Agent Inspector محليًا ونشر الرمز عن بُعد. هذا مراجعة توثيقية، لا تحقق نشر مباشر؛ الميزات الاختيارية في العرض المسبق تحتفظ بحالتها الخاصة.

## أهداف التعلم

عند إتمام هذا الفصل، ستتمكن من:
- نشر تطبيقات الذكاء الاصطناعي باستخدام قوالب AZD الجاهزة
- فهم تكامل Microsoft Foundry مع AZD
- تثبيت حزمة GA واختبار وكيل مستضاف محليًا قبل نشر المصدر إلى Foundry
- مراجعة `azure.yaml`، أصول التقييم، وتنظيف المشاريع الجديدة مقابل المعاد استخدامها
- تكوين وتخصيص وكلاء الذكاء الاصطناعي مع الأدوات
- نشر تطبيقات RAG (التوليد المدعوم بالاسترجاع)

## 🚀 بداية سريعة

اختر خيارًا واحدًا في مجلد جديد فارغ. الأمر `.` في نهايته يقوم بتهيئة الدليل الحالي؛ خلاف ذلك، يمكن لـ AZD إنشاء مجلد فرعي دون تغيير دليل العمل الخاص بالصدفة.

لمسار نشر رمز الوكيل المستضاف لـ **GA**، ابدأ بـ [الشرح الإرشادي](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga). يتطلب AZD إصدار 1.37.0+، وحدة uv الحالية، Python 3.13+، أذونات Foundry، وحصة نموذج. القوالب الكاملة للتطبيق أدناه هي بدائل، وليست متطلبات لذلك الشرح الإرشادي.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 الوعي بالتكلفة

هذه نطاقات توضيحية، وليست عروض أسعار أو حدودًا؛ يمكن لحركة المرور على النماذج، وأصناف البحث/الحوسبة، والمنطقة، والميزات الاختيارية تجاوزها. راجع إرشادات التسعير الحالية للعينة التي اخترتها قبل التوفير.

| البيئة | التكلفة الشهرية المقدرة |
|-------------|----------------------|
| التطوير | 80-150 دولارًا |
| المرحلة التجريبية | 150-300 دولارًا |
| الإنتاج | 300-3,500+ دولارًا |

**التنظيف:** راجع `azd down` قبل التأكيد: للمشروع المنشأ حديثًا في Foundry، يحذف مجموعة الموارد وكل شيء بداخلها. بالنسبة للمشروع المعاد استخدامه في Foundry، يترك موارد المشروع والوكيل في مكانها؛ اتبع [إرشادات تنظيف الشرح الإرشادي](microsoft-foundry-integration.md#7-clean-up-deliberately) لإزالة الموارد غير المرغوب فيها بشكل منفصل.
