# الفصل 6: التخطيط والتحقق قبل النشر

**📚 الدورة**: [AZD للمبتدئين](../../README.md) | **⏱️ المدة**: 2-4 ساعات قراءة؛ وقت إضافي للمختبرات المخصصة | **⭐ التعقيد**: متوسط–متقدم

---

## نظرة عامة

يغطي هذا الفصل خطوات التخطيط والتحقق الأساسية قبل نشر تطبيقك. تعلم كيفية تجنب الأخطاء المكلفة من خلال التخطيط السليم للسعة، اختيار SKU المناسب، والفحوصات المسبقة.

> تم مراجعة إرشادات الأوامر وفقًا للمرجع الصادر `azd 1.37.2`. لم يتم تنفيذ عمليات النشر السحابية. تتضمن الدروس الأطول أجزاء توضيحية، وليست مشاريع نشر محلية كاملة.

## أهداف التعلم

عند إكمال هذا الفصل، ستتمكن من:
- إجراء فحوصات مسبقة قبل النشر
- تخطيط السعة وتقدير متطلبات الموارد
- اختيار SKU المناسبة لتحسين التكلفة
- تكوين Application Insights للمراقبة
- فهم أنماط التنسيق متعددة الوكلاء ومتطلبات نشرها

## 🚀 بداية سريعة

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ قائمة التحقق قبل النشر

### قبل `azd provision`

- [ ] تم التحقق من الحصة للإقليم
- [ ] تم اختيار SKU بشكل مناسب
- [ ] تمت مراجعة تقدير التكلفة
- [ ] تناسق نمط التسمية
- [ ] تم تكوين الأمان/إدارة الوصول المستندة إلى الدور (RBAC)

### قبل `azd deploy`

- [ ] تم تعيين متغيرات البيئة
- [ ] الأسرار في Key Vault
- [ ] تم التحقق من سلاسل الاتصال
- [ ] تم تكوين فحوصات الصحة

## 💰 دليل اختيار SKU

| الحمولة | التطوير | الإنتاج |
|----------|-------------|------------|
| تطبيقات الحاويات | الاستهلاك | استهلاك أو ملف تعريف حمولة مخصص، بناءً على الحمل المقاس |
| خدمة التطبيقات | B1/B2 | P1v3+ |
| نماذج Azure OpenAI | نوع نشر مدفوع حسب الاستخدام مدعوم | مدفوع حسب الاستخدام أو عرض نطاق مخصص؛ يعتمد على النموذج/الإقليم |
| AI Search | مجاني/أساسي ضمن الحدود | المستوى الأساسي أو القياسي مُعد حسب الفهرس، النسخ، وحمل الاستعلام |
