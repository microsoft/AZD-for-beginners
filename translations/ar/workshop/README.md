# ورشة عمل AZD لمطوري الذكاء الاصطناعي

مرحباً بكم في ورشة العمل التفعيلية لتعلم Azure Developer CLI (AZD) مع التركيز على نشر تطبيقات الذكاء الاصطناعي. تساعدك هذه الورشة على اكتساب فهم عملي لقوالب AZD في 3 خطوات:

1. **الاكتشاف** - اكتشف القالب المناسب لك.
1. **النشر** - انشر وتحقق من أنه يعمل
1. **التخصيص** - عدل وكرر لتجعله ملكك!

خلال هذه الورشة، ستتعرف أيضاً على أدوات سير تطوير أساسية لمساعدتك في تبسيط رحلة التطوير الشاملة.

<br/>

## دليل عبر المتصفح

دروس الورشة مكتوبة بلغة Markdown. يمكنك التنقل فيها مباشرة على GitHub - أو إطلاق معاينة عبر المتصفح كما هو موضح في لقطة الشاشة أدناه.

![Workshop](../../../translated_images/ar/workshop.75906f133e6f8ba0.webp)

لاستخدام هذا الخيار - قم بعمل فورك للمستودع إلى ملفك الشخصي، ثم أطلق GitHub Codespaces. بمجرد تفعيل طرفية VS Code، اكتب هذا الأمر:

تعمل هذه المعاينة عبر المتصفح في GitHub Codespaces، حاويات التطوير (dev containers)، أو نسخة محلية مع تثبيت Python وMkDocs.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

نفذ هذه الأوامر من **جذر مستودع الدورة**، وليس من عينة الذكاء الاصطناعي المهيأة بشكل مستقل. اجعل المعاينة أمامك للحفاظ على ظهور الأخطاء؛ أوقفها باستخدام Ctrl+C. للتحقق من الموقع دون خدمته، شغّل `python -m mkdocs build --strict --config-file workshop/mkdocs.yml`.

خلال ثوانٍ، سترى مربع حوار منبثق. اختر الخيار `Open in browser`. سيفتح الدليل المستند إلى الويب الآن في تبويب جديد في المتصفح. بعض مزايا هذه المعاينة:

1. **بحث مدمج** - عثر على الكلمات المفتاحية أو الدروس بسرعة.
1. **أيقونة النسخ** - حرّك المؤشر فوق الكتل البرمجية لمشاهدة هذا الخيار
1. **تبديل السمة** - التبديل بين السمات الداكنة والفاتحة
1. **الحصول على المساعدة** - انقر على أيقونة Discord في التذييل للانضمام!

## ما ستتعلمه

فكر في قالب AZD كصندوق رمل تعليمي لاستكشاف القدرات والأدوات المختلفة لتطوير نهاية إلى نهاية على Microsoft Foundry. بنهاية هذه الورشة، يجب أن تمتلك إحساساً بديهيًا بالأدوات والمفاهيم المختلفة ضمن هذا السياق.

| المفهوم  | الهدف |
|:---|:---|
| **واجهة أوامر مطور أزور (Azure Developer CLI)** | فهم أوامر الأدوات وسير العمل|
| **قوالب AZD**| فهم هيكل المشروع والتكوين|
| **عميل الذكاء الاصطناعي في أزور**| توفير ونشر مشروع Microsoft Foundry  |
| **بحث الذكاء الاصطناعي في أزور**| تمكين هندسة السياق بواسطة العملاء |
| **الرصد والمراقبة**| استكشاف التتبع، الرصد والتقييمات |
| **الفريق الأحمر**| استكشاف الاختبار الهجومي والتدابير |

## تحدي الورشة

تريد تحدي نفسك لفعل المزيد؟ إليك بعض اقتراحات المشاريع - أو شارك أفكارك معنا!!

| المشروع | الوصف |
|:---|:---|
|1. **تفكيك قالب ذكاء اصطناعي معقد** | استخدم سير العمل والأدوات التي أوضحناها وانظر إذا كنت تستطيع نشر والتحقق وتخصيص قالب حل ذكاء اصطناعي مختلف. _ما الذي تعلمته؟_|
|2. **التخصيص وفق سينارك**  | حاول كتابة وثيقة متطلبات منتج (PRD) لسيناريو مختلف. ثم استخدم GitHub Copilot في مستودع القالب في نموذج العميل - واطلب منه توليد سير تخصيص لك. _ما الذي تعلمته؟ كيف يمكنك تحسين هذه الاقتراحات؟_|
