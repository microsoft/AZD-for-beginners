# ورشة عمل AZD لمطوري الذكاء الاصطناعي

> تم مراجعة التوجيه المصدر مقابل AZD 1.37.2 في ٤ نوفمبر ٢٠٢٦. اللقطات التوضيحية؛ توافر الخدمة، تسميات البوابة، وقوالب الافتراضية قد تتغير.

> [!IMPORTANT]  
> **تم تجهيز هذه الورشة بدليل ورشة يمكنك معاينته في متصفحك المحلي. للبدء، افتح المستودع في GitHub Codespaces أو حاوية تطوير، أو نسخة محلية مع تثبيت MkDocs - ثم انتظر حتى ترى محطة VS Code نشطة واكتب:**  
> من جذر مستودع الدورة، قم بتثبيت `requirements-dev.txt`، ثم شغّل `python -m mkdocs serve --config-file workshop/mkdocs.yml` في المقدمة.
> **يجب أن ترى حوارًا منبثقًا لفتح صفحة المعاينة في المتصفح.**

مرحبًا بك في ورشة العمل العملية لتعلم Azure Developer CLI (AZD) مع التركيز على نشر تطبيقات الذكاء الاصطناعي. تساعدك هذه الورشة على اكتساب فهم تطبيقي لقوالب AZD في ٣ خطوات:

1. **الاكتشاف** - اعثر على القالب الذي يناسبك.
1. **النشر** - انشر وتحقق من أنه يعمل 
1. **التخصيص** - عدل وكرر لجعله خاصًا بك!

على مدى هذه الورشة، ستتعرف أيضًا على أدوات تطوير رئيسية وسير عمل، لمساعدتك في تبسيط رحلة التطوير الشاملة الخاصة بك.

## نظرة عامة على الورشة

**المدة:** ٣-٤ ساعات  
**المستوى:** مبتدئ إلى متوسط  
**المتطلبات المسبقة:** إلمام بـ Azure، مفاهيم الذكاء الاصطناعي، VS Code وأدوات سطر الأوامر.

هذه ورشة عمل عملية تتعلم من خلالها من خلال التنفيذ. بعد إكمال التمارين، نوصي بمراجعة منهج AZD للمبتدئين للاستمرار في رحلة التعلم الخاصة بك نحو أفضل ممارسات الأمن والإنتاجية.

| الوقت| الوحدة  | الهدف |
|:---|:---|:---|
| ١٥ دقيقة | المقدمة | تمهيد للمشهد، فهم الأهداف |
| ٣٠ دقيقة | اختيار قالب الذكاء الاصطناعي | استكشاف الخيارات واختيار البداية | 
| ٣٠ دقيقة | التحقق من قالب الذكاء الاصطناعي | نشر الحل الافتراضي على Azure |
| ٣٠ دقيقة | تفكيك قالب الذكاء الاصطناعي | استكشاف الهيكل والتكوين |

| ٣٠ دقيقة | تخصيص قالب الذكاء الاصطناعي | تكييف القالب حسب احتياجاتك |

## ما ستتعلمه

فكر في قالب AZD كصندوق رمل تعليمي لاستكشاف القدرات والأدوات المختلفة لتطوير شامل على Microsoft Foundry. بنهاية هذه الورشة، يجب أن تحصل على إحساس بديهي بمختلف الأدوات والمفاهيم في هذا السياق.

| المفهوم  | الهدف |
|:---|:---|
| **Azure Developer CLI** | فهم أوامر الأدوات وسير العمل |
| **قوالب AZD** | فهم هيكل المشروع والتكوين |
| **وكيل Azure AI** | توفير ونشر مشروع Microsoft Foundry  |
| **بحث Azure AI** | تمكين هندسة السياق بالوكلاء |
| **القابلية للرصد** | استكشاف التتبع، المراقبة والتقييمات |
| **اختبار الفريق الأحمر** | استكشاف الاختبارات المعادية والتخفيفات |
