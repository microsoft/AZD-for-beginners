# AZD للمبتدئين: مخطط الدورة وإطار التعلم

## نظرة عامة على الدورة

اتقن Azure Developer CLI (azd) من خلال فصول منظمة مصممة للتعلم التدريجي. **تركيز خاص على نشر تطبيقات الذكاء الاصطناعي مع تكامل Microsoft Foundry.**

### لماذا هذه الدورة ضرورية للمطورين الحديثين

يحتاج المطورون الذين ينشرون أعباء عمل الذكاء الاصطناعي عادةً إلى إرشاد حول:
- هياكل الذكاء الاصطناعي متعددة الخدمات المعقدة
- أفضل ممارسات نشر الذكاء الاصطناعي في الإنتاج  
- تكامل وتكوين خدمات Azure AI
- تحسين تكلفة أعباء عمل الذكاء الاصطناعي
- استكشاف مشكلات النشر الخاصة بالذكاء الاصطناعي وإصلاحها

### أهداف التعلم الأساسية

عبر إكمال هذه الدورة المنظمة، سوف:
- **اتقان أساسيات AZD**: المفاهيم الأساسية، التثبيت، والتكوين
- **نشر تطبيقات الذكاء الاصطناعي**: استخدام AZD مع خدمات Microsoft Foundry
- **تنفيذ البنية التحتية كرمز**: إدارة موارد Azure باستخدام قوالب Bicep
- **استكشاف أخطاء عمليات النشر وإصلاحها**: حل المشكلات الشائعة وتصحيح الأخطاء
- **التحسين للإنتاج**: الأمان، التوسع، المراقبة، وإدارة التكلفة
- **بناء حلول متعددة الوكلاء**: نشر هياكل الذكاء الاصطناعي المعقدة

## 🎓 تجربة التعلم في الورشة

### خيارات تقديم التعلم المرنة
تم تصميم هذه الدورة لدعم كل من **التعلم الفردي الذاتي** و**جلسات الورش الميسرة**، مما يمكّن المتعلمين من الحصول على تجربة عملية مع AZD أثناء تطوير مهارات عملية من خلال تمارين تفاعلية.

**مثالي للمطورين الفرديين والتعلم المستمر**

**الميزات:**
- **واجهة متصفح الإنترنت**: ورشة عمل كاملة مدعومة بـ MkDocs يمكن الوصول إليها من خلال أي متصفح ويب
- **تكامل GitHub Codespaces**: بيئة تطوير بنقرة واحدة مع أدوات مهيأة مسبقًا
- **بيئة DevContainer تفاعلية**: لا حاجة لإعداد محلي - ابدأ الترميز فورًا
- **تتبع التقدم**: نقاط تفتيش مدمجة وتمارين تحقق
- **دعم المجتمع**: الوصول إلى قنوات Azure Discord للأسئلة والتعاون

**هيكل التعلم:**

- **نظام النقاط التفتيشية**: تحقق من التعلم قبل التقدم إلى المواضيع المعقدة
