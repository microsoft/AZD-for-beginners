# المساهمة في AZD للمبتدئين

شكرًا لاهتمامك بالمساهمة في دورة AZD للمبتدئين! توفر هذه الوثيقة إرشادات ومعلومات للمساهمين.

## كيفية المساهمة

### الإبلاغ عن المشكلات

إذا وجدت أخطاء، أو مشاكل، أو لديك اقتراحات لتحسينات:

1. **التحقق من المشكلات الحالية**: ابحث في [المشكلات الحالية](https://github.com/microsoft/azd-for-beginners/issues) لتجنب التكرار
2. **إنشاء مشكلة جديدة**: استخدم قالب المشكلة المناسب
3. **تقديم التفاصيل**: اذكر خطوات التكرار، السلوك المتوقع، ولقطات الشاشة إذا أمكن

### اقتراح التغييرات

1. **نسخ المستودع**: أنشئ نسخة خاصة بك من المشروع
2. **إنشاء فرع**: أنشئ فرعًا جديدًا للميزة الخاصة بتغييراتك
3. **إجراء التغييرات**: اتبع معايير الترميز والتوثيق الخاصة بنا
4. **اختبار التغييرات**: تحقق من أن جميع الروابط تعمل والمحتوى يُعرض بشكل صحيح
5. **تقديم طلب سحب**: قدم وصفًا واضحًا لتغييراتك

### أنواع المساهمات

نرحب بأنواع المساهمات التالية:

#### تحسينات المحتوى
- تصحيح الأخطاء الإملائية والنحوية ومشاكل التنسيق
- تحسين وضوح الوثائق الحالية
- تحديث المعلومات القديمة
- إضافة شروحات أو سياق مفقود

#### أمثلة جديدة
- إضافة سيناريوهات نشر من الواقع
- إنشاء قوالب AZD جديدة لحالات الاستخدام الشائعة
- توفير عينات كود وتمارين إضافية

#### دعم الترجمة
- المساعدة في صيانة الترجمات الموجودة
- تحسين جودة الترجمة
- إضافة ترجمات للمحتوى الجديد

#### تقارير الأخطاء
- الإبلاغ عن الروابط المعطلة أو أمثلة الكود غير الصحيحة
- التعرف على التناقضات في التوثيق
- الإشارة إلى مشاكل إمكانية الوصول

## إرشادات المساهمة

### معايير التوثيق

- استخدام لغة واضحة وسهلة للمبتدئين
- تضمين أهداف التعلم والنتائج المتوقعة
- تقديم تعليمات خطوة بخطوة مع المخرجات المتوقعة
- إضافة روابط تنقل إلى المحتوى ذي الصلة
- استخدام تنسيق وأسلوب ماركدوان متسق

### أمثلة الكود

- التأكد من اختبار جميع أمثلة الكود وأنها تعمل
- تضمين تعليقات تشرح المفاهيم الرئيسية
- اتباع أفضل الممارسات في Azure و AZD
- تقديم المخرجات المتوقعة حيثما ينطبق ذلك

### التحقق من توثيق اللغة الإنجليزية

من جذر المستودع، ثبّت متطلبات التطوير الحالية وقم بتشغيل:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

يقوم مدقق الروابط غير المتصل بالإنترنت بالتحقق من مسارات Markdown/HTML الإنجليزية، والعناوين، والملفات التعريفية الصريحة، ونماذج الروابط الفارغة. يستثني `translations/` و `translated_images/` المولدة، بما في ذلك الروابط إلى تلك الأدلة. لا يجلب مواقع خارجية أو يتحقق من نشرات Azure. استخدم `--json <report-path>` لتصدير الأخطاء وجرد عناوين URL الخارجية لفحص شبكة منفصلة. تحقق من أوامر upstream الحالية ومتطلبات العينة عند تغيير التعليمات التقنية؛ ميّز التطبيقات المختبرة عن تصاميم المخططات.
