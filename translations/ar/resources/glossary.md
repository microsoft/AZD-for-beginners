## مقدمة

يوفر هذا المسرد الشامل تعريفات للمصطلحات والمفاهيم والاختصارات المستخدمة في Azure Developer CLI وتطوير سحابة Azure. مرجع أساسي لفهم الوثائق التقنية، وحل المشكلات، والتواصل الفعال حول مشاريع azd وخدمات Azure.

## أهداف التعلم

باستخدام هذا المسرد، ستتمكن من:
- فهم مصطلحات ومفاهيم Azure Developer CLI الأساسية
- إتقان مفردات تطوير سحابة Azure والمصطلحات التقنية
- الرجوع بكفاءة إلى مصطلحات البنية التحتية كرمز والنشر
- استيعاب أسماء خدمات Azure، والاختصارات، وأغراضها
- الوصول إلى تعريفات لمصطلحات استكشاف الأخطاء وإصلاحها وتصحيحها
- تعلم مفاهيم متقدمة في هندسة وتطوير Azure

## نتائج التعلم

مع الرجوع المنتظم إلى هذا المسرد، ستتمكن من:
- التواصل بفعالية باستخدام مصطلحات Azure Developer CLI الصحيحة
- فهم الوثائق التقنية ورسائل الخطأ بوضوح أكبر
- التنقل بين خدمات ومفاهيم Azure بثقة
- استكشاف المشكلات باستخدام المفردات التقنية المناسبة
- المساهمة في مناقشات الفريق بلغة تقنية دقيقة
- توسيع معرفتك بتطوير سحابة Azure بشكل منهجي

## أ

**قالب ARM**  
قالب مدير موارد Azure. صيغة بنية تحتية كرمز مبنية على JSON تُستخدم لتعريف ونشر موارد Azure بشكل وصفي.

**خدمة التطبيقات**  
عرض منصة كخدمة (PaaS) من Azure لاستضافة تطبيقات الويب، واجهات برمجة التطبيقات REST، والواجهات الخلفية للتطبيقات المحمولة دون إدارة البنية التحتية.

**Application Insights**  
خدمة مراقبة أداء التطبيقات (APM) من Azure التي توفر رؤى عميقة حول أداء التطبيق وتوفره واستخدامه.

**Azure CLI**  
واجهة سطر الأوامر لإدارة موارد Azure. تكمل AZD لكنها تتطلب تسجيل دخول منفصل؛ يستخدم التوثيق الأساسي لـ AZD `azd auth login`.

**Azure Developer CLI (azd)**  
أداة سطر أوامر تركز على المطور وتسهل عملية بناء ونشر التطبيقات إلى Azure باستخدام القوالب والبنية التحتية كرمز.

**azure.yaml**  
ملف التكوين الرئيسي لمشروع azd الذي يعرّف الخدمات والبنية التحتية وخطافات النشر.

**Azure Resource Manager (ARM)**  
خدمة النشر والإدارة من Azure التي توفر طبقة إدارة لإنشاء وتحديث وحذف الموارد.

## ب

**Bicep**  
لغة مخصصة (DSL) طورتها مايكروسوفت لنشر موارد Azure. توفر بناء جملة أبسط من قوالب ARM بينما تُترجم إلى ARM.

**البناء**  
عملية تجميع شفرة المصدر، وتثبيت التبعيات، وتجهيز التطبيقات للنشر.

**النشر الأزرق-الأخضر**  
استراتيجية نشر تستخدم بيئتين إنتاجيتين متطابقتين (الأزرق والأخضر) لتقليل وقت التوقف والمخاطر.

## ج

**تطبيقات الحاويات**  
خدمة الحاويات الخالية من الخوادم في Azure التي تتيح تشغيل التطبيقات المحوطة بالحاويات دون إدارة بنية تحتية معقدة.

**CI/CD**  
التكامل المستمر/النشر المستمر. ممارسات آلية لدمج تغييرات الشفرة ونشر التطبيقات.

**Cosmos DB**  
خدمة قاعدة بيانات موزعة عالمياً ومتعددة النماذج من Azure توفر اتفاقيات مستوى خدمة شاملة لمعدل النقل، الكمون، التوفر، والاتساق.

**التكوين**  
الإعدادات والمعلمات التي تتحكم في سلوك التطبيق وخيارات النشر.

## د

**النشر**  
عملية تثبيت وتكوين التطبيقات وتبعياتها على البنية التحتية المستهدفة.

**Docker**  
منصة لتطوير وشحن وتشغيل التطبيقات باستخدام تقنية الحاويات.

**ملف Dockerfile**  
ملف نصي يحتوي على تعليمات لبناء صورة حاوية Docker.

## هـ

**البيئة**  
هدف نشر يمثل نسخة محددة من تطبيقك (مثل التطوير، المرحلة التجريبية، الإنتاج).

**متغيرات البيئة**  
قيم تكوين مخزنة كأزواج مفتاح-قيمة يمكن للتطبيقات الوصول إليها أثناء التشغيل.

**النقطة النهائية**  
عنوان URL أو عنوان شبكة حيث يمكن الوصول إلى تطبيق أو خدمة.

## و

**تطبيق الدوال**  
خدمة الحوسبة الخالية من الخوادم في Azure التي تتيح تشغيل رمز مدفوع بالأحداث دون إدارة البنية التحتية.

## ز

**إجراءات GitHub**  
منصة CI/CD مدمجة مع مستودعات GitHub لأتمتة سير العمل.

**Git**  
نظام تحكم بالإصدار موزع يُستخدم لتتبع التغييرات في شفرة المصدر.

## ح

**خطافات**  
نصوص مخصصة أو أوامر تُشغل في نقاط محددة خلال دورة حياة النشر (قبل التوفير، بعد التوفير، قبل النشر، بعد النشر).

**المضيف**  
نوع خدمة Azure حيث يتم نشر التطبيق (مثل appservice، containerapp، function).

## ي

**البنية التحتية كرمز (IaC)**  
ممارسة تعريف وإدارة البنية التحتية من خلال الشفرة بدلاً من العمليات اليدوية.

**التهيئة**  
عملية تهيئة مشروع azd جديد، عادة من قالب.

## ج

**JSON**  
ترميز كائن جافاسكريبت. صيغة تبادل بيانات شائعة الاستخدام لملفات التكوين واستجابات API.

**JWT**  
JSON Web Token. معيار لنقل المعلومات بأمان بين الأطراف ككائن JSON.

## م

**خزانة المفاتيح**  
خدمة Azure لتخزين وإدارة الأسرار والمفاتيح والشهادات بأمان.

**لغة استعلام كوستو (KQL)**  
لغة استعلام تُستخدم لتحليل البيانات في Azure Monitor وApplication Insights والخدمات الأخرى في Azure.

## ل

**موازن التحميل**  
خدمة توزع حركة الشبكة الواردة عبر عدة خوادم أو نسخ.

**تحليلات السجلات**  
خدمة Azure لجمع وتحليل والتصرف على بيانات القياس من البيئات السحابية والمحلية.

## م

**الهوية المُدارة**  
ميزة Azure توفر للخدمات هوية مُدارة تلقائياً للمصادقة على خدمات Azure الأخرى.

**الخدمات المصغرة**  
نهج هندسي حيث تُبنى التطبيقات كمجموعة من الخدمات الصغيرة المستقلة.

**مراقبة**  
حل Azure الموحد للمراقبة الذي يوفر رؤية شاملة عبر التطبيقات والبنية التحتية.

## ن

**Node.js**  
بيئة تشغيل جافاسكريبت مبنية على محرك جافاسكريبت V8 الخاص بكروما لإنشاء تطبيقات الخادم.

**npm**  
مدير الحزم لـ Node.js الذي يدير التبعيات والحزم.

## خ

**الناتج**  
القيم المرجعة من نشر البنية التحتية والتي يمكن للتطبيقات أو الموارد الأخرى استخدامها.

## ب

**الحزمة**  
عملية تجهيز شفرة التطبيق وتبعياته للنشر.

**المعلمات**  
قيم إدخال تُمرر لقوالب البنية التحتية لتخصيص عمليات النشر.

**PostgreSQL**  
نظام قاعدة بيانات علائقية مفتوح المصدر مدعوم كخدمة مُدارة في Azure.

**التوفير**  
عملية إنشاء وتكوين موارد Azure المعرفة في قوالب البنية التحتية.

## ق

**الحصة**  
حدود على كمية الموارد التي يمكن إنشاؤها في اشتراك أو منطقة Azure.

## ر

**مجموعة الموارد**  
حاوية منطقية لموارد Azure التي تشترك في نفس دورة الحياة والأذونات والسياسات.

**رمز المورد**  
سلسلة فريدة تُولد بواسطة azd لضمان تميز أسماء الموارد عبر عمليات النشر.

**REST API**  
نمط معماري لتصميم التطبيقات الشبكية باستخدام طرق HTTP.

**الرجوع للخلف**  
عملية العودة إلى نسخة سابقة من التطبيق أو تكوين البنية التحتية.

## خ

**الخدمة**  
مكون من تطبيقك معرف في azure.yaml (مثل واجهة الويب، الواجهة الخلفية لواجهة برمجة التطبيقات، قاعدة البيانات).

**SKU**  
وحدة حفظ المخزون. تمثل مستويات خدمة أو أداء مختلفة لموارد Azure.

**قاعدة بيانات SQL**  
خدمة قاعدة بيانات علائقية مُدارة من Azure تعتمد على Microsoft SQL Server.

**تطبيقات الويب الثابتة**  
خدمة Azure لبناء ونشر تطبيقات الويب كاملة المكدس من مستودعات شفرة المصدر.

**حساب التخزين**  
خدمة Azure التي توفر تخزين سحابي لكائنات البيانات بما في ذلك كائنات الـ blobs والملفات والطوابير والجداول.

**الاشتراك**  
حاوية حساب Azure التي تحتوي على مجموعات الموارد والموارد، مع إدارة الفوترة والوصول المرتبطة بها.

## ت

**القالب**  
هيكل مشروع مسبق البناء يحتوي على شفرة التطبيق وتعريفات البنية التحتية والتكوين للسيناريوهات الشائعة.

**Terraform**  
أداة مفتوحة المصدر للبنية التحتية كرمز تدعم عدة مزودي سحابة بما في ذلك Azure.

**مدير الحركة**  
موازن تحميل حركة مرور قائم على DNS من Azure لتوزيع الحركة عبر مناطق Azure العالمية.

## ع

**معرف الموارد (URI)**  
معرف الموارد الموحد. سلسلة تحدد موردًا معينًا.

**عنوان URL**  
محدد موقع الموارد الموحد. نوع من URI يحدد مكان المورد وكيفية استرجاعه.

## ف

**الشبكة الافتراضية (VNet)**  
لبنة أساسية للشبكات الخاصة في Azure توفر العزل والتقسيم.

**VS Code**  
Visual Studio Code. محرر شيفرة شهير باندماج ممتاز مع Azure وazd.

## خ

**Webhook**  
رد نداء HTTP يتم تشغيله بواسطة أحداث محددة، مُستخدم بشكل شائع في خطوط أنابيب CI/CD.

**ماذا لو**  
ميزة Azure التي تعرض التغييرات التي سيتم إجراؤها بواسطة نشر دون تنفيذها فعليًا.

## ي

**YAML**  
YAML ليست لغة ترميز. معيار تسلسل بيانات قابل للقراءة البشرية يُستخدم لملفات التكوين مثل azure.yaml.

## ز

**المنطقة**  
أماكن منفصلة فعليًا داخل منطقة Azure توفر التكرار والتوفر العالي.

## تعيينات أسماء خدمات Azure

| الاسم الشائع | الاسم الرسمي لخدمة Azure | نوع المضيف في azd |
|-------------|------------------------------|---------------|
| تطبيق ويب | خدمة تطبيقات Azure | `appservice` |
| تطبيق API | خدمة تطبيقات Azure | `appservice` |
| تطبيق حاوية | تطبيقات حاويات Azure | `containerapp` |
| دالة | وظائف Azure | `function` |
| موقع ثابت | تطبيقات الويب الثابتة في Azure | `staticwebapp` |
| قاعدة بيانات | قاعدة بيانات Azure لـ PostgreSQL | مورد بنية تحتية، ليس تطبيقًا `host` |
| قاعدة بيانات NoSQL | Azure Cosmos DB | مورد بنية تحتية، ليس تطبيقًا `host` |
| التخزين | حساب تخزين Azure | مورد بنية تحتية، ليس تطبيقًا مدمجًا `host` |
| ذاكرة تخزين مؤقت | Redis المدار في Azure | مورد بنية تحتية، ليس تطبيقًا `host` |
| البحث | بحث Azure AI | مورد بنية تحتية، ليس تطبيقًا `host` |
| الرسائل | خدمة حافلة Azure | مورد بنية تحتية، ليس تطبيقًا `host` |

`services.<name>.host` يحدد هدف نشر التطبيق؛ ليس اختصارًا لأي نوع مورد Azure. عادةً ما يتم توفير قواعد البيانات والذاكرات المؤقتة وخدمات البحث والطوابير من خلال مزود البنية التحتية ويتم ربطها بالتطبيق عبر المخرجات/التكوين.

## مصطلحات خاصة بالسياق

### مصطلحات التطوير
- **إعادة تحميل ساخنة**: تحديث التطبيقات تلقائيًا أثناء التطوير دون إعادة التشغيل
- **خط أنابيب البناء**: عملية آلية لبناء واختبار الشفرة
- **فتحة النشر**: بيئة إعداد داخل خدمة التطبيقات
- **تماثل البيئة**: الحفاظ على تشابه بيئات التطوير والإعداد والإنتاج

### مصطلحات الأمان
- **الهوية المُدارة**: ميزة Azure توفر إدارة بيانات اعتماد تلقائية
- **خزانة المفاتيح**: تخزين آمن للأسرار والمفاتيح والشهادات
- **RBAC**: التحكم بالوصول القائم على الدور لموارد Azure
- **مجموعة أمان الشبكة**: جدار ناري افتراضي للتحكم في حركة مرور الشبكة

### مصطلحات المراقبة
- **القياس**: جمع آلي للقياسات والبيانات
- **مراقبة أداء التطبيقات (APM)**: مراقبة أداء البرمجيات
- **تحليلات السجلات**: خدمة لجمع وتحليل بيانات السجلات
- **قواعد التنبيه**: إشعارات آلية بناءً على المقاييس أو الشروط

### مصطلحات النشر
- **النشر الأزرق-الأخضر**: استراتيجية نشر بدون توقف الخدمة
- **النشر الكاناري**: طرح تدريجي لفئة فرعية من المستخدمين
- **التحديث التدريجي**: استبدال تسلسلي لحالات التطبيق
- **الرجوع للخلف**: العودة إلى نسخة سابقة من التطبيق
