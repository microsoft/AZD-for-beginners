# مثال على الخدمات الدقيقة

التنفيذ القابل للتشغيل وتعليماته موجودة في
**[container-app/microservices](../container-app/microservices/README.md)**.

هذا الدليل للتنقل فقط. لا يحتوي على `azure.yaml`، `infra/`، أو `src/`.
لا تقم بتشغيل `azd up` هنا.

من جذر المستودع:

```bash
cd examples/container-app/microservices
```

ثم اتبع ملف README المرتبط للمتطلبات الأساسية، النشر، التحقق، التطوير المحلي،
التمارين العملية، التكاليف، والتنظيف.

يحتوي المثال على بوابة API بـ Node.js وخدمة منتجات بيثون للقراءة فقط.
خدمات الطلبات، المستخدم، الإشعارات، قاعدة البيانات، والرسائل هي أفكار توسعية،
وليست تنفيذات مدرجة في هذا المستودع.

- [السابق: واجهة برمجة تطبيقات فلاس بسيطة](../../../../examples/container-app/simple-flask-api)
- [التالي: تطبيق قاعدة بيانات](../../../../examples/database-app)
- [تطوير الذكاء الاصطناعي](../../docs/chapter-02-ai-development/README.md)
- [الصفحة الرئيسية للدورة](../../README.md)
