# Mikropalveluesimerkki

Suoritettava toteutus ja ohjeet löytyvät
**[container-app/microservices](../container-app/microservices/README.md)**-kansiosta.

Tämä hakemisto on vain navigointia varten. Sillä ei ole `azure.yaml`-, `infra/`- tai `src/`-tiedostoja.
Älä suorita `azd up` täällä.

Arkistopuun juuressa:

```bash
cd examples/container-app/microservices
```

Seuraa sitten linkitettyä README-tiedostoa ennakkoedellytyksistä, käyttöönotosta, varmennuksesta, paikallisesta
kehityksestä, käytännön harjoituksista, kustannuksista ja siivouksesta.

Esimerkki sisältää Node.js API Gatewayn ja kirjoitussuojatun Python-tuotepalvelun.
Tilauksen, käyttäjän, ilmoituksen, tietokannan ja viestintäpalvelujen laajennusehdotuksia,
eivätkä nämä ole tämän repositorion toteutuksia.

- [Edellinen: Yksinkertainen Flask API](../../../../examples/container-app/simple-flask-api)
- [Seuraava: Tietokantasovellus](../../../../examples/database-app)
- [AI-kehitys](../../docs/chapter-02-ai-development/README.md)
- [Kurssin etusivu](../../README.md)
