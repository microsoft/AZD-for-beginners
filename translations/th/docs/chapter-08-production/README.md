# บทที่ 8: รูปแบบสำหรับการผลิต & องค์กร

**📚 คอร์สเรียน**: [AZD สำหรับผู้เริ่มต้น](../../README.md) | **⏱️ เวลาเรียน**: 2-3 ชั่วโมง | **⭐ ความซับซ้อน**: ขั้นสูง

---

## ภาพรวม

บทนี้ครอบคลุมรูปแบบการปรับใช้ที่พร้อมใช้งานในองค์กร การเสริมความปลอดภัย การตรวจสอบ และการเพิ่มประสิทธิภาพด้านต้นทุนสำหรับงาน AI ในการผลิต

นี่คือเอกสารอ้างอิงทางสถาปัตยกรรม ไม่ใช่แม่แบบการปรับใช้แบบสมบูรณ์ที่พร้อมใช้งาน ตัวอย่างละเว้นรายละเอียดการผสานรวมที่ต้องมีการเพิ่มและทดสอบในแอปพลิเคชันของคุณเอง; การอ่านรายการตรวจสอบไม่ได้หมายความว่าผ่านเกณฑ์พร้อมใช้งานสำหรับการผลิต

> **การทบทวนเวอร์ชัน (2026-11-04):** คำแนะนำสำหรับ AI CLI ได้รับการตรวจสอบกับเอกสาร/ซอร์สของ `azd 1.37.2`, ตัวแทน `1.0.0-beta.23` และการประเมินผล `1.0.0-beta.2` ดู [การเปลี่ยนแปลงและการแก้ไขในเวอร์ชัน](production-ai-practices.md#recent-release-changes-and-fixes) สำหรับข้อกำหนดความเข้ากันได้และรายละเอียดการย้ายข้อมูล; นี่ไม่ใช่การตรวจสอบการปรับใช้แบบสด

## วัตถุประสงค์การเรียนรู้

เมื่อเรียนจบบทนี้ คุณจะสามารถ:
- ปรับใช้แอปพลิเคชันหลายภูมิภาคที่มีความทนทาน
- นำรูปแบบความปลอดภัยสำหรับองค์กรมาใช้
- กำหนดค่าการตรวจสอบอย่างครบถ้วน
- ปรับต้นทุนให้เหมาะสมในระดับใหญ่
- ตั้งค่า pipeline CI/CD ด้วย AZD

## 🚀 รายการตรวจสอบสำหรับการผลิต

- [ ] การปรับใช้หลายภูมิภาคเพื่อความทนทาน
- [ ] ใช้ managed identity สำหรับการตรวจสอบสิทธิ์ (ไม่มีคีย์)
- [ ] ใช้ Application Insights ในการตรวจสอบ

- [ ] เปิดใช้งานการสแกนด้านความปลอดภัย
- [ ] การผสาน pipeline CI/CD
- [ ] แผนกู้คืนระบบเมื่อเกิดภัยพิบัติ

```bicep
// Illustrative properties from different resources, NOT a standalone Bicep file.
// Attach identity to the application host:
identity: {
  type: 'SystemAssigned'
}

// AI account properties (also require private endpoints, DNS and app connectivity):
properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }
}
```

## 💰 การเพิ่มประสิทธิภาพต้นทุน

| กลยุทธ์ | ข้อจำกัดหลัก |
|----------|---------|
| ปรับขนาดเป็นศูนย์ (Container Apps) | ต้องมีตัวกระตุ้นที่เหมาะสม; บริการอื่นยังมีต้นทุนเกิดขึ้น |
| ใช้ consumption tiers สำหรับการพัฒนา | เปรียบเทียบราคาบริการและงานที่เลือก |
| การปรับขนาดตามตารางเวลา | ปรับขนาดผ่านโครงสร้างพื้นฐาน/ระบบอัตโนมัติที่รองรับ |
| การสำรอง/ความจุที่จัดสรร | เฉพาะเมื่อรองรับ; ข้อตกลงอาจเพิ่มต้นทุนเวลาว่าง |

ใช้ [รูปแบบทรัพยากรงบประมาณครบถ้วน](production-ai-practices.md#2-cost-monitoring-and-budgets) พร้อมวันที่เริ่มต้นที่ถูกต้อง ขอบเขตการออกบิล ผู้รับ และสิทธิ์ งบประมาณจะส่งแจ้งเตือน; แต่ไม่จำกัดการใช้จ่าย การประหยัดขึ้นอยู่กับการใช้งานที่วัดได้และไม่รับประกันเปอร์เซ็นต์ใด ๆ
