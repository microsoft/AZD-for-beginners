# บทที่ 2: การพัฒนา AI-First

**📚 คอร์สเรียน**: [AZD สำหรับผู้เริ่มต้น](../../README.md) | **⏱️ ระยะเวลา**: 4-5 ชั่วโมงรวมเวิร์กช็อป | **⭐ ระดับความยาก**: ระดับกลาง

---

## ภาพรวม

บทนี้เน้นการปรับใช้แอปพลิเคชันที่ขับเคลื่อนด้วย AI โดยใช้ Azure Developer CLI และบริการ Microsoft Foundry ตั้งแต่อุปกรณ์แชท AI ง่าย ๆ ไปจนถึงเอเจนต์อัจฉริยะที่มีเครื่องมือ

> **อัปเดต Foundry GA (2026-11-09):** ชุด `microsoft.foundry` 1.0 พร้อมให้ [ใช้งานทั่วไป](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/) แล้ว ใช้ `azd >= 1.37.0`; การประเมินยังคงเป็นการติดตั้งแยกต่างหาก [คู่มือโฮสต์เอเจนต์](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) ครอบคลุมการทดสอบ Agent Inspector ในเครื่องและการปรับใช้โค้ดระยะไกล นี่เป็นการทบทวนเอกสาร ไม่ใช่การตรวจสอบการปรับใช้แบบสด; ฟีเจอร์ตัวอย่างที่เป็นทางเลือกยังคงสถานะของตนเองอยู่

## จุดมุ่งหมายการเรียนรู้

เมื่อเรียนจบบทนี้ คุณจะสามารถ:
- ปรับใช้แอปพลิเคชัน AI โดยใช้เทมเพลต AZD ที่สร้างไว้ล่วงหน้า
- เข้าใจการผสานรวม Microsoft Foundry กับ AZD
- ติดตั้งชุด GA และทดสอบโฮสต์เอเจนต์ในเครื่องก่อนที่จะปรับใช้ซอร์สโค้ดไปยัง Foundry
- ทบทวน `azure.yaml`, สินทรัพย์การประเมิน และการทำความสะอาดโปรเจกต์ใหม่กับโปรเจกต์ที่ใช้ซ้ำ
- กำหนดค่าและปรับแต่งเอเจนต์ AI พร้อมเครื่องมือ
- ปรับใช้แอปพลิเคชัน RAG (Retrieval-Augmented Generation)

## 🚀 เริ่มต้นอย่างรวดเร็ว

เลือกหนึ่งตัวเลือกในไดเรกทอรีว่างใหม่ ตัว `.` ท้ายเรื่องจะเริ่มต้นไดเรกทอรีปัจจุบัน; มิฉะนั้น AZD สามารถสร้างไดเรกทอรีย่อยโดยไม่เปลี่ยนไดเรกทอรีทำงานของเชลล์คุณ

สำหรับ **เส้นทางการปรับใช้โค้ดโฮสต์เอเจนต์ GA** ให้เริ่มด้วย [คู่มือการใช้งาน](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) ซึ่งต้องการ AZD 1.37.0+, uv ปัจจุบัน, Python 3.13+, สิทธิ์ Foundry และโควต้าโมเดล เทมเพลตแอปพลิเคชันเต็มด้านล่างเป็นทางเลือก ไม่ใช่ข้อบังคับสำหรับคู่มือนั้น

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 การรับรู้ค่าใช้จ่าย

เหล่านี้เป็นช่วงการประมาณเชิงภาพ ไม่ใช่ราคาหรือขีดจำกัด; ปริมาณการเข้าชมโมเดล, SKUs การค้นหา/คอมพิวต์, ภูมิภาค และฟีเจอร์ทางเลือกอาจเกินช่วงนี้ ตรวจสอบแนวทางราคาปัจจุบันสำหรับตัวอย่างที่คุณเลือกก่อนจัดสรร

| สภาพแวดล้อม | ค่าใช้จ่ายรายเดือนที่ประมาณการณ์ |
|-------------|----------------------|
| การพัฒนา | $80-150 |
| การเตรียมผลิต | $150-300 |
| การผลิต | $300-3,500+ |

**การทำความสะอาด:** ทบทวน `azd down` ก่อนยืนยัน: สำหรับโปรเจกต์ Foundry ที่สร้างใหม่จะลบกลุ่มทรัพยากรและทุกอย่างภายใน สำหรับโปรเจกต์ Foundry ที่ใช้ซ้ำ จะเก็บโปรเจกต์และทรัพยากรเอเจนต์ไว้; ให้ปฏิบัติตาม [คำแนะนำการล้างข้อมูล](microsoft-foundry-integration.md#7-clean-up-deliberately) เพื่อแยกลบทรัพยากรที่ไม่ต้องการ
