# บทที่ 6: การวางแผนและตรวจสอบก่อนการปรับใช้

**📚 หลักสูตร**: [AZD สำหรับผู้เริ่มต้น](../../README.md) | **⏱️ ระยะเวลา**: 2-4 ชั่วโมงการอ่าน; มีเวลาพิเศษสำหรับห้องปฏิบัติการที่ปรับแต่งแล้ว | **⭐ ความซับซ้อน**: ระดับกลาง–ขั้นสูง

---

## ภาพรวม

บทนี้ครอบคลุมขั้นตอนวางแผนและตรวจสอบที่สำคัญก่อนการปรับใช้แอปพลิเคชันของคุณ เรียนรู้วิธีหลีกเลี่ยงข้อผิดพลาดที่มีค่าใช้จ่ายสูงด้วยการวางแผนความจุที่เหมาะสม การเลือก SKU และการตรวจสอบก่อนบิน

> คำแนะนำคำสั่งได้รับการตรวจสอบกับเอกสารอ้างอิง `azd 1.37.2` ที่เผยแพร่แล้ว ยังไม่มีการปรับใช้บนคลาวด์ บทเรียนที่ยาวขึ้นประกอบด้วยตัวอย่างสั้นๆ ไม่ใช่โครงการปรับใช้ท้องถิ่นทั้งหมด

## วัตถุประสงค์การเรียนรู้

เมื่อเรียนจบบทนี้ คุณจะสามารถ:
- ดำเนินการตรวจสอบก่อนบินก่อนการปรับใช้
- วางแผนความจุและประเมินความต้องการทรัพยากร
- เลือก SKU ที่เหมาะสมเพื่อเพิ่มประสิทธิภาพค่าใช้จ่าย
- กำหนดค่า Application Insights เพื่อการตรวจสอบ
- เข้าใจรูปแบบการประสานงานหลายเอเจนท์และความต้องการในการปรับใช้

## 🚀 เริ่มต้นอย่างรวดเร็ว

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ รายการตรวจสอบก่อนปรับใช้

### ก่อน `azd provision`

- [ ] ตรวจสอบโควต้าในภูมิภาค
- [ ] เลือก SKU อย่างเหมาะสม
- [ ] ทบทวนการประเมินค่าใช้จ่าย
- [ ] ใช้รูปแบบการตั้งชื่อที่สอดคล้อง
- [ ] กำหนดค่าความปลอดภัย/RBAC

### ก่อน `azd deploy`

- [ ] ตั้งค่าตัวแปรสภาพแวดล้อม
- [ ] เก็บความลับไว้ใน Key Vault
- [ ] ตรวจสอบสายการเชื่อมต่อ
- [ ] กำหนดค่าการตรวจสอบสุขภาพ
