# AZD สำหรับผู้เริ่มต้น: โครงร่างหลักสูตรและกรอบการเรียนรู้

## ภาพรวมหลักสูตร

ฝึกอบรม Azure Developer CLI (azd) ผ่านบทเรียนที่มีโครงสร้างสำหรับการเรียนรู้อย่างก้าวหน้า **เน้นพิเศษที่การปรับใช้แอปพลิเคชัน AI ด้วยการผสาน Microsoft Foundry**

### เหตุผลที่หลักสูตรนี้สำคัญสำหรับนักพัฒนาสมัยใหม่

นักพัฒนาที่ปรับใช้ AI workloads มักต้องการคำแนะนำเกี่ยวกับ:
- สถาปัตยกรรม AI หลายบริการที่ซับซ้อน
- แนวทางปฏิบัติที่ดีที่สุดสำหรับการปรับใช้ AI ในการผลิต  
- การผสานและการกำหนดค่าบริการ Azure AI
- การเพิ่มประสิทธิภาพค่าใช้จ่ายสำหรับ AI workloads
- การแก้ไขปัญหาการปรับใช้เฉพาะ AI

### วัตถุประสงค์หลักในการเรียนรู้

เมื่อคุณเสร็จสิ้นหลักสูตรที่มีโครงสร้างนี้ คุณจะ:
- **ชำนาญพื้นฐาน AZD**: แนวคิดหลัก, การติดตั้ง และการกำหนดค่า
- **ปรับใช้แอป AI**: ใช้ AZD กับบริการ Microsoft Foundry
- **ใช้ Infrastructure as Code**: จัดการทรัพยากร Azure ด้วยเทมเพลต Bicep
- **แก้ไขปัญหาการปรับใช้**: แก้ไขปัญหาทั่วไปและดีบักปัญหา
- **เพิ่มประสิทธิภาพสำหรับการผลิต**: ความปลอดภัย, การสเกล, การตรวจสอบ และการจัดการค่าใช้จ่าย
- **สร้างโซลูชันหลายตัวแทน**: ปรับใช้สถาปัตยกรรม AI ที่ซับซ้อน

## 🎓 ประสบการณ์การเรียนรู้ในเวิร์กช็อป

### ตัวเลือกการจัดส่งการเรียนรู้ที่ยืดหยุ่น
หลักสูตรนี้ออกแบบมาเพื่อสนับสนุนทั้ง **การเรียนรู้ด้วยตนเองตามจังหวะ** และ **เซสชันเวิร์กช็อปที่มีผู้สอน**, ให้ผู้เรียนได้ฝึกฝนทักษะจริงกับ AZD ผ่านแบบฝึกหัดเชิงโต้ตอบ

#### 🚀 โหมดการเรียนรู้ด้วยตนเอง
**เหมาะสำหรับนักพัฒนารายบุคคลและการเรียนรู้อย่างต่อเนื่อง**

**คุณสมบัติ:**
- **อินเทอร์เฟซผ่านเว็บเบราว์เซอร์**: เวิร์กช็อปที่ใช้ MkDocs สามารถเข้าใช้งานผ่านเบราว์เซอร์ใดก็ได้
- **การผสาน GitHub Codespaces**: สภาพแวดล้อมการพัฒนาด้วยคลิกเดียวที่มีเครื่องมือกำหนดค่าล่วงหน้า
- **สภาพแวดล้อม DevContainer แบบโต้ตอบ**: ไม่ต้องตั้งค่าในเครื่อง - เริ่มเขียนโค้ดได้ทันที
- **การติดตามความคืบหน้า**: มีจุดตรวจสอบและแบบฝึกหัดตรวจสอบความถูกต้องในตัว
- **การสนับสนุนจากชุมชน**: เข้าถึงช่องทาง Azure Discord สำหรับคำถามและการร่วมมือ

**โครงสร้างการเรียนรู้:**
- **เวลาที่ยืดหยุ่น**: เรียนจบบทเรียนตามจังหวะของตัวเองในช่วงหลายวันหรือหลายสัปดาห์
- **ระบบจุดตรวจสอบ**: ตรวจสอบความรู้ก่อนก้าวไปสู่หัวข้อที่ซับซ้อน
- **ห้องสมุดทรัพยากร**: เอกสาร ตัวอย่าง และคู่มือแก้ไขปัญหาอย่างครบถ้วน
- **การพัฒนาผลงาน**: สร้างโปรเจกต์ที่พร้อมปรับใช้สำหรับผลงานมืออาชีพ

#### 🏛️ เซสชันเวิร์กช็อปที่มีผู้สอน
**เหมาะสำหรับการฝึกอบรมในองค์กร, บูตแคมป์ และสถาบันการศึกษา**

**รูปแบบเวิร์กช็อปที่เลือกได้:**

**📚 การผสานหลักสูตรทางวิชาการ (8-12 สัปดาห์)**
- **โปรแกรมมหาวิทยาลัย**: หลักสูตรเทอมเดียวพร้อมเซสชันรายสัปดาห์สองชั่วโมง
- **รูปแบบบูตแคมป์**: โปรแกรมเข้มข้น 3-5 วันพร้อมเซสชันวันละ 6-8 ชั่วโมง
- **การฝึกอบรมองค์กร**: เซสชันทีมรายเดือนพร้อมการนำโปรเจกต์ไปใช้จริง
- **กรอบการประเมินผล**: งานมอบหมายที่มีการให้คะแนน, การทบทวนโดยเพื่อนร่วมงาน และโปรเจกต์สุดท้าย

**🚀 เวิร์กช็อปเข้มข้น (1-3 วัน)**
- **วันแรก**: พื้นฐาน + การพัฒนา AI (บทที่ 1-2) - 6 ชั่วโมง
- **วันที่สอง**: การกำหนดค่า + โครงสร้างพื้นฐาน (บทที่ 3-4) - 6 ชั่วโมง  
- **วันที่สาม**: รูปแบบขั้นสูง + การผลิต (บทที่ 5-8) - 8 ชั่วโมง
- **ติดตามผล**: การให้คำปรึกษาเพิ่มเติม 2 สัปดาห์สำหรับการเสร็จสิ้นโปรเจกต์

**⚡ การบรรยายสำหรับผู้บริหาร (4-6 ชั่วโมง)**
- **ภาพรวมเชิงกลยุทธ์**: ข้อเสนอคุณค่า AZD และผลกระทบทางธุรกิจ (1 ชั่วโมง)
- **สาธิตลงมือทำ**: ปรับใช้แอป AI จากต้นจนจบ (2 ชั่วโมง)
- **ทบทวนสถาปัตยกรรม**: รูปแบบองค์กรและการกำกับดูแล (1 ชั่วโมง)
- **วางแผนการนำไปใช้**: กลยุทธ์การยอมรับขององค์กร (1-2 ชั่วโมง)

#### 🛠️ วิธีการเรียนรู้ในเวิร์กช็อป
**แนวทาง Discovery → Deployment → Customization สำหรับการพัฒนาทักษะเชิงปฏิบัติ**

**เฟส 1: การค้นพบ (45 นาที)**
- **การสำรวจเทมเพลต**: ประเมินเทมเพลตและบริการ Microsoft Foundry
- **วิเคราะห์สถาปัตยกรรม**: เข้าใจรูปแบบหลายตัวแทนและกลยุทธ์การปรับใช้
- **การประเมินความต้องการ**: ระบุความต้องการและข้อจำกัดขององค์กร
- **การตั้งค่าสภาพแวดล้อม**: กำหนดค่าสภาพแวดล้อมการพัฒนาและทรัพยากร Azure

**เฟส 2: การปรับใช้ (2 ชั่วโมง)**
- **การดำเนินการแบบมีคำแนะนำ**: ปรับใช้แอป AI ทีละขั้นตอนด้วย AZD
- **การกำหนดค่าบริการ**: ตั้งค่าบริการ Azure AI, จุดเชื่อมต่อ และการตรวจสอบสิทธิ์
- **การใช้ความปลอดภัย**: นำรูปแบบความปลอดภัยองค์กรและการควบคุมการเข้าถึงมาใช้
- **การทดสอบตรวจสอบ**: ตรวจสอบการปรับใช้และแก้ไขปัญหาทั่วไป

**เฟส 3: การปรับแต่ง (45 นาที)**
- **การแก้ไขแอป**: ปรับเทมเพลตให้เข้ากับกรณีใช้งานและข้อกำหนดเฉพาะ
- **การเพิ่มประสิทธิภาพการผลิต**: นำการตรวจสอบ, การจัดการค่าใช้จ่าย และกลยุทธ์การสเกลมาใช้
- **รูปแบบขั้นสูง**: สำรวจการประสานงานของหลายตัวแทนและสถาปัตยกรรมซับซ้อน
- **การวางแผนขั้นตอนต่อไป**: กำหนดเส้นทางการเรียนรู้สำหรับพัฒนาทักษะต่อเนื่อง

#### 🎯 ผลลัพธ์การเรียนรู้ในเวิร์กช็อป
**ทักษะที่วัดผลได้พัฒนาผ่านการฝึกปฏิบัติจริง**

**ความสามารถทางเทคนิค:**
- **ปรับใช้แอป AI ในการผลิต**: ปรับใช้และกำหนดค่าโซลูชันที่ขับเคลื่อนด้วย AI สำเร็จ
- **ชำนาญ Infrastructure as Code**: สร้างและจัดการเทมเพลต Bicep ที่กำหนดเอง
- **สถาปัตยกรรมหลายตัวแทน**: นำโซลูชันตัวแทน AI ที่ประสานงานกันมาใช้
- **ความพร้อมสำหรับการผลิต**: นำรูปแบบความปลอดภัย, การตรวจสอบ และการกำกับดูแลมาใช้
- **ความเชี่ยวชาญในการแก้ไขปัญหา**: แก้ไขปัญหาการปรับใช้และการกำหนดค่าได้ด้วยตนเอง

**ทักษะเชิงวิชาชีพ:**
- **การเป็นผู้นำโครงการ**: นำทีมเทคนิคในโครงการปรับใช้คลาวด์
- **การออกแบบสถาปัตยกรรม**: ออกแบบโซลูชัน Azure ที่ขยายได้และคุ้มค่าการลงทุน
- **การถ่ายทอดความรู้**: ฝึกอบรมและให้คำปรึกษาเพื่อนร่วมงานเกี่ยวกับแนวปฏิบัติที่ดีที่สุดของ AZD
- **การวางแผนเชิงกลยุทธ์**: มีอิทธิพลต่อกลยุทธ์การนำคลาวด์มาใช้ขององค์กร

#### 🏢 การปรับใช้เวิร์กช็อปในองค์กร
**กลยุทธ์การปรับใช้และการฝึกอบรมในองค์กร**

**โปรแกรมฝึกอบรมในองค์กร:**
- **การปฐมนิเทศนักพัฒนาใหม่**: การแนะนำพื้นฐาน AZD สำหรับพนักงานใหม่ (2-4 สัปดาห์)
- **การเพิ่มทักษะทีม**: เวิร์กช็อปรายไตรมาสสำหรับทีมพัฒนาเดิม (1-2 วัน)
- **ทบทวนสถาปัตยกรรม**: เซสชันรายเดือนสำหรับวิศวกรอาวุโสและสถาปนิก (4 ชั่วโมง)
- **บรรยายสำหรับผู้นำ**: เวิร์กช็อปสำหรับผู้ตัดสินใจทางเทคนิค (ครึ่งวัน)

**การสนับสนุนการนำไปใช้:**
- **ออกแบบเวิร์กช็อปแบบกำหนดเอง**: เนื้อหาที่ปรับแต่งสำหรับความต้องการเฉพาะขององค์กร
- **การบริหารโปรแกรมนำร่อง**: การเปิดตัวที่มีโครงสร้างพร้อมตัวชี้วัดความสำเร็จและข้อเสนอแนะ  
- **การให้คำปรึกษาต่อเนื่อง**: การสนับสนุนหลังเวิร์กช็อปสำหรับการนำโปรเจกต์ไปใช้
- **การสร้างชุมชน**: ชุมชนนักพัฒนา AI Azure ภายในองค์กรและการแบ่งปันความรู้

**ตัวชี้วัดความสำเร็จ:**
- **การได้มาซึ่งทักษะ**: การประเมินก่อน/หลังที่วัดการเติบโตของความสามารถทางเทคนิค
- **ความสำเร็จในการปรับใช้**: เปอร์เซ็นต์ผู้เข้าร่วมที่ปรับใช้แอปในผลิตได้สำเร็จ
- **เวลาสู่ความพร้อมทำงาน**: ลดเวลาปฐมนิเทศสำหรับโปรเจกต์ Azure AI ใหม่
- **การรักษาความรู้**: การประเมินติดตามผล 3-6 เดือนหลังเวิร์กช็อป
