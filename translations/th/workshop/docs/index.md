# เวิร์กช็อป AZD สำหรับนักพัฒนา AI

> คำแนะนำจากแหล่งข้อมูลถูกตรวจสอบกับ AZD 1.37.2 เมื่อวันที่ 4 พฤศจิกายน 2026 ภาพหน้าจอเป็นภาพประกอบ การให้บริการ ป้ายชื่อพอร์ทัล และค่าเริ่มต้นของแม่แบบอาจมีการเปลี่ยนแปลง

> [!IMPORTANT]  
> **เวิร์กช็อปนี้มีคู่มือการใช้งานที่คุณสามารถดูตัวอย่างได้ในเบราว์เซอร์เครื่องของคุณ เพื่อเริ่มต้น ให้เปิดรีโพใน GitHub Codespaces, คอนเทนเนอร์สำหรับนักพัฒนาหรือโคลนเครื่องในเครื่องพร้อมติดตั้ง MkDocs จากนั้นรอจนกว่าจะเห็นเทอร์มินัล VS Code ที่ทำงานและพิมพ์:**  
> จากโฟลเดอร์รากของรีโพสคอร์ส ติดตั้ง `requirements-dev.txt` จากนั้นรัน `python -m mkdocs serve --config-file workshop/mkdocs.yml` แบบพื้นหน้า
> **คุณควรเห็นกล่องโต้ตอบป๊อปอัปเพื่อเปิดหน้าตัวอย่างในเบราว์เซอร์**

ยินดีต้อนรับสู่เวิร์กช็อปแบบลงมือปฏิบัติเพื่อเรียนรู้ Azure Developer CLI (AZD) โดยมุ่งเน้นที่การปรับใช้แอป AI เวิร์กช็อปนี้จะช่วยให้คุณเข้าใจการใช้งานแม่แบบ AZD ใน 3 ขั้นตอน:

1. **ค้นหา** - ค้นหาแม่แบบที่เหมาะสมกับคุณ
1. **ปรับใช้** - ปรับใช้และตรวจสอบว่าใช้งานได้
1. **ปรับแต่ง** - แก้ไขและปรับปรุงให้เป็นของคุณ!

ตลอดหลักสูตรเวิร์กช็อปนี้ คุณจะได้รับการแนะนำเครื่องมือและเวิร์กโฟลว์หลักของนักพัฒนา เพื่อช่วยให้คุณปรับปรุงเส้นทางการพัฒนาครบวงจรของคุณให้มีประสิทธิภาพมากขึ้น

## ภาพรวมเวิร์กช็อป

**ระยะเวลา:** 3-4 ชั่วโมง  
**ระดับ:** ตั้งแต่ผู้เริ่มต้นถึงระดับกลาง  
**ข้อกำหนดเบื้องต้น:** รู้จัก Azure, แนวคิด AI, VS Code และเครื่องมือบรรทัดคำสั่ง

นี่คือเวิร์กช็อปแบบลงมือปฏิบัติที่คุณเรียนรู้โดยการทำ หลังจากทำแบบฝึกหัดเสร็จแล้ว เราแนะนำให้ทบทวนหลักสูตร AZD สำหรับผู้เริ่มต้นเพื่อเรียนรู้ต่อไปเกี่ยวกับแนวปฏิบัติด้านความปลอดภัยและประสิทธิภาพ

| เวลา| โมดูล  | วัตถุประสงค์ |
|:---|:---|:---|
| 15 นาที | บทนำ | เตรียมความพร้อมและทำความเข้าใจเป้าหมาย |
| 30 นาที | เลือกแม่แบบ AI | สำรวจตัวเลือกและเลือกแม่แบบเริ่มต้น | 
| 30 นาที | ตรวจสอบแม่แบบ AI | ปรับใช้โซลูชันเริ่มต้นไปยัง Azure |
| 30 นาที | วิเคราะห์แม่แบบ AI | สำรวจโครงสร้างและการกำหนดค่า |
| 30 นาที | กำหนดค่าแม่แบบ AI | เปิดใช้และทดลองฟีเจอร์ที่พร้อมใช้งาน |
| 30 นาที | ปรับแต่งแม่แบบ AI | ดัดแปลงแม่แบบให้ตรงกับความต้องการของคุณ |
| 30 นาที | รื้อถอนโครงสร้างพื้นฐาน | ทำความสะอาดและคืนทรัพยากร |
| 15 นาที | สรุปและขั้นตอนถัดไป | ทรัพยากรการเรียนรู้, ความท้าทายเวิร์กช็อป |
| | |

## สิ่งที่คุณจะได้เรียนรู้

คิดว่าแม่แบบ AZD เป็นห้องเรียนจำลองเพื่อสำรวจความสามารถและเครื่องมือต่างๆ สำหรับการพัฒนาครบวงจรบน Microsoft Foundry เมื่อจบเวิร์กช็อปนี้ คุณจะมีความเข้าใจในเครื่องมือและแนวคิดต่าง ๆ ในบริบทนี้อย่าง intuitive

| แนวคิด  | วัตถุประสงค์ |
|:---|:---|
| **Azure Developer CLI** | เข้าใจคำสั่งและเวิร์กโฟลว์ของเครื่องมือ|
| **แม่แบบ AZD**| เข้าใจโครงสร้างโปรเจกต์และการกำหนดค่า|
| **Azure AI Agent**| จัดเตรียมและปรับใช้โครงการ Microsoft Foundry  |
| **Azure AI Search**| เปิดใช้งานวิศวกรรมบริบทด้วยเอเจนต์ |
| **การสังเกตการณ์**| สำรวจการติดตาม ตรวจสอบ และการประเมินผล |
| **Red Teaming**| สำรวจการทดสอบต้านการโจมตีและมาตรการป้องกัน |
| | |
