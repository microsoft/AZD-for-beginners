# ตัวอย่างไมโครเซอร์วิส

การใช้งานที่สามารถรันได้และคำแนะนำของมันอยู่ใน
**[container-app/microservices](../container-app/microservices/README.md)**.

โฟลเดอร์นี้ใช้สำหรับการนำทางเท่านั้น ไม่มี `azure.yaml`, `infra/` หรือ `src/`.
ห้ามรัน `azd up` ที่นี่

จากโฟลเดอร์รากของรีโพสิตอรี:

```bash
cd examples/container-app/microservices
```

จากนั้นให้ทำตาม README ที่ลิงก์ไว้สำหรับข้อกำหนดเบื้องต้น การปรับใช้ การตรวจสอบ การพัฒนาในเครื่อง การฝึกปฏิบัติ ค่าใช้จ่าย และการล้างข้อมูล


บริการคำสั่งซื้อ ผู้ใช้ การแจ้งเตือน ฐานข้อมูล และการส่งข้อความเป็นแนวคิดเพิ่มเติม,
ไม่ใช่การใช้งานที่รวมในรีโพสิตอรีนี้

- [ถัดไป: แอปฐานข้อมูล](../../../../examples/database-app)
- [การพัฒนา AI](../../docs/chapter-02-ai-development/README.md)
- [หน้าหลักของหลักสูตร](../../README.md)
