# Ví dụ Microservices

Cài đặt có thể chạy và hướng dẫn của nó nằm trong
**[container-app/microservices](../container-app/microservices/README.md)**.

Thư mục này chỉ để điều hướng. Nó không chứa `azure.yaml`, `infra/`, hoặc `src/`.
Đừng chạy `azd up` ở đây.

Từ thư mục gốc của kho lưu trữ:

```bash
cd examples/container-app/microservices
```

Sau đó làm theo README được liên kết để biết các yêu cầu trước, triển khai, xác minh, phát triển
cục bộ, bài tập thực hành, chi phí và dọn dẹp.

Mẫu chứa một Node.js API Gateway và một dịch vụ sản phẩm Python chỉ đọc.
Các dịch vụ đơn hàng, người dùng, thông báo, cơ sở dữ liệu, và nhắn tin là các ý tưởng mở rộng,
không phải là các cài đặt có trong kho lưu trữ này.

- [Trước: API Flask đơn giản](../../../../examples/container-app/simple-flask-api)
- [Tiếp: Ứng dụng cơ sở dữ liệu](../../../../examples/database-app)
- [Phát triển AI](../../docs/chapter-02-ai-development/README.md)
- [Trang khóa học](../../README.md)
