# Mikroszolgáltatások példa

A futtatható megvalósítás és az utasítások a
**[container-app/microservices](../container-app/microservices/README.md)** könyvtárban találhatók.

Ez a könyvtár csak navigációs célokat szolgál. Nem tartalmaz `azure.yaml`, `infra/` vagy `src/` fájlokat.
Itt ne futtass `azd up`.

A tárház gyökeréből:

```bash
cd examples/container-app/microservices
```

Ezután kövesd a kapcsolt README-t a követelményekhez, telepítéshez, ellenőrzéshez, helyi
fejlesztéshez, gyakorlati feladatokhoz, költségekhez és takarításhoz.

A példa egy Node.js API Gateway-t és egy csak olvasható Python Product Service-t tartalmaz.
A rendelés, felhasználó, értesítés, adatbázis és üzenetküldő szolgáltatások bővítési ötletek,
nem a jelen tárházban található megvalósítások.

- [Előző: Egyszerű Flask API](../../../../examples/container-app/simple-flask-api)
- [Következő: Adatbázis alkalmazás](../../../../examples/database-app)
- [AI fejlesztés](../../docs/chapter-02-ai-development/README.md)
- [Tanfolyam kezdőoldal](../../README.md)
