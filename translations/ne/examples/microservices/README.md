# माइक्रोसर्भिस उदाहरण

चलाउन मिल्ने कार्यान्वयन र यसको निर्देशनहरू
**[container-app/microservices](../container-app/microservices/README.md)** मा छन्।

यो निर्देशिका मात्र नेभिगेसनको लागि हो। यसमा कुनै `azure.yaml`, `infra/`, वा `src/` छैनन्।
यहाँ `azd up` चलाउनुहोस् नहुन्।

रिपोजिटोरीको मूलबाट:

```bash
cd examples/container-app/microservices
```

त्यसपछि लिंक गरिएको README अनुसार पूर्वआवश्यकताहरू, परिनियोजन, प्रमाणीकरण, स्थानीय
विकास, व्यावहारिक अभ्यासहरू, खर्चहरू, र सफाइ प्रक्रिया अनुगमन गर्नुहोस्।

नमूनामा Node.js API Gateway र एउटा पाठमात्र Python Product Service समावेश छ।
अर्डर, प्रयोगकर्ता, सूचना, डाटाबेस, र सन्देश सेवा विस्तार विचारहरू हुन्,
जसलाई यो रिपोजिटोरीमा समावेश गरिएका कार्यान्वयन होइनन्।
