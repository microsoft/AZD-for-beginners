# अध्याय ६: पूर्व-परिनियोजन योजना र प्रमाणिकरण

**📚 पाठ्यक्रम**: [शुरुआतीहरूका लागि AZD](../../README.md) | **⏱️ अवधि**: २-४ घण्टा पढ्ने; अनुकूलित प्रयोगशालाहरूका लागि अतिरिक्त समय | **⭐ जटिलता**: मध्यम–उन्नत

---

## समीक्षा

यस अध्यायले तपाइँको अनुप्रयोग परिनियोजन गर्नु अघि आवश्यक योजना र प्रमाणिकरण कदमहरू समेट्छ। उचित क्षमता योजना, SKU छनौट, र प्रिफ्लाइट जाँचमार्फत महँगो गल्तीहरूबाट बच्न सिक्नुहोस्।

> जारी गरिएको `azd 1.37.2` सन्दर्भसँग कमाण्ड निर्देशन समीक्षा गरिएको। क्लाउड परिनियोजनहरू कार्यान्वयन गरिएका थिएनन्। लामो पाठहरूमा पूर्ण स्थानीय परिनियोजन परियोजनाहरू होइन, उदाहरणात्मक अंशहरू छन्।

## सिक्ने उद्देश्यहरू

यस अध्याय पूरा गरेपछि, तपाईंले:
- परिनियोजन भन्दा पहिले प्रिफ्लाइट जाँचहरू सञ्चालन गर्न
- क्षमता योजना बनाउने र स्रोत आवश्यकताहरू अनुमान गर्न
- लागत अनुकूलनका लागि उपयुक्त SKU छान्ने
- अनुगमनको लागि अनुप्रयोग इनसाइट्स कन्फिगर गर्ने
- बहु-एजेन्ट समन्वय ढाँचाहरू र तिनीहरूको परिनियोजन आवश्यकताहरू बुझ्ने

## 🚀 छिटो सुरु

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ पूर्व-परिनियोजन चेकलिस्ट

### `azd provision` अघि

- [ ] क्षेत्रको कोटा प्रमाणित गरिएको
- [ ] SKU उपयुक्त रूपमा छानिएको
- [ ] लागत अनुमान समीक्षा गरिएको
- [ ] नामकरण सम्मेलन सुसंगत
- [ ] सुरक्षा/RBAC कन्फिगर गरिएको

### `azd deploy` अघि

- [ ] वातावरण चरहरू सेट गरिएको
- [ ] Key Vault मा गोप्यहरू छन्
- [ ] जडान स्ट्रिङ्स प्रमाणित गरिएको
- [ ] स्वास्थ्य जाँचहरू कन्फिगर गरिएको
