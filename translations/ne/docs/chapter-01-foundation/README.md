# अध्याय १: आधार र छिटो सुरु

**📚 कोर्स**: [AZD प्रारम्भकर्ताहरूका लागि](../../README.md) | **⏱️ अवधि**: पहिलो डिप्लोइमेन्ट सहित ७५-१२० मिनेट; अतिरिक्त अभ्यासहरूमा बढी समय लाग्न सक्छ | **⭐ जटिलता**: प्रारम्भिक

---

## अवलोकन

यस अध्यायले Azure Developer CLI (azd) का आधारभूत कुरा परिचय गराउँछ। तपाईंले मुख्य संकल्पनाहरू सिक्नुहुनेछ, उपकरणहरू स्थापना गर्नुहुनेछ, र Azure मा पहिलो एप्लिकेसन डिप्लोय गर्नुहुनेछ।

> कमाण्ड र कन्फिगरेसन समीक्षा लक्ष्य: `azd 1.37.2` (नोभेम्बर २०२६)। समीक्षा समयमा लाइभ Azure प्रावधान सञ्चालन गरिएको थिएन।

## सिकाइ लक्ष्यहरू

यस अध्याय पूरा गरेर, तपाईंले:
- Azure Developer CLI के हो र Azure CLI बाट यसले कसरी फरक छ भनी बुझ्नुहुनेछ
- आफ्नो प्लेटफर्ममा AZD स्थापना र कन्फिगर गर्नुहुनेछ
- आफ्नो पहिलो एप्लिकेसन Azure मा `azd up` प्रयोग गरी डिप्लोय गर्नुहुनेछ
- `azd down` प्रयोग गरी स्रोतहरू सफा गर्नुहुनेछ

## ✅ यहाँबाट सुरु गर्नुहोस्: आफ्नो सेटअप प्रमाणित गर्नुहोस्

सुरु गर्नु अघि, आफ्नो स्थानीय मेसिन अध्याय १ टेम्प्लेटका लागि तयार छ कि छैन पुष्टि गर्नुहोस्:

**विन्डोज:**
```powershell
.\validate-setup.ps1
```

**म्याकओएस / लिनक्स:**
```bash
bash ./validate-setup.sh
```

यदि स्क्रिप्टले उपकरणहरू हराएको रिपोर्ट गर्छ भने, पहिले ती समस्या समाधान गर्नुहोस् र त्यसपछि अध्याय जारी राख्नुहोस्।

---

## 🚀 छिटो सुरु

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ सफलता मापदण्डहरू

यो अध्याय पूरा गरेपछि, तपाईं सक्षम हुनुहुनेछ:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
