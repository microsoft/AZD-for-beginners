# शब्दावली - Azure र AZD शब्दावली

**सबै अध्यायहरूको लागि सन्दर्भ**
- **📚 कोर्स गृह**: [AZD प्रारम्भिकहरूका लागि](../README.md)
- **📖 आधारभूत कुरा सिक्नुहोस्**: [अध्याय 1: AZD का आधारभूत कुरा](../docs/chapter-01-foundation/azd-basics.md)
- **🤖 AI शब्दहरू**: [अध्याय 2: AI-प्रथम विकास](../docs/chapter-02-ai-development/microsoft-foundry-integration.md)

## परिचय

यो व्यापक शब्दावली Azure Developer CLI र Azure क्लाउड विकासमा प्रयोग गरिएका शर्तहरू, अवधारणाहरू, र संक्षेपाक्षरहरूको परिभाषाहरू प्रदान गर्दछ। प्राविधिक दस्तावेज पढ्न, समस्या समाधान गर्न, र azd परियोजनाहरू र Azure सेवाहरूबारे प्रभावकारी रूपमा संवाद गर्न आवश्यक अवलोकन।

## सिकाइ लक्ष्यहरू

यस शब्दावली प्रयोग गरेर, तपाईं:
- आवश्यक Azure Developer CLI शब्दावली र अवधारणाहरू बुझ्नुहुनेछ
- Azure क्लाउड विकासको शब्दावली र प्राविधिक शब्दहरूमा निपूर्ण हुनुहुनेछ
- Infrastructure as Code र deployment शब्दावलिलाई प्रभावकारी रूपमा सन्दर्भ गर्नुहुनेछ
- Azure सेवा नामहरू, संक्षेपाक्षरहरू, र तिनका उद्देश्यहरू बुझ्नुहुनेछ
- समस्या समाधान र डिबगिङ शब्दावलीका परिभाषाहरू पहुँच गर्नुहुनेछ
- उन्नत Azure स्वरचना र विकास अवधारणाहरू सिक्नुहुनेछ

## सिकाइ नतिजाहरू

यस शब्दावलिको नियमित सन्दर्भले तपाईंलाई सक्षम पार्दछ:
- सही Azure Developer CLI शब्दावली प्रयोग गरी प्रभावकारी रूपमा संवाद गर्न
- प्राविधिक दस्तावेज र त्रुटि सन्देशहरू स्पष्ट रूपमा बुझ्न
- Azure सेवाहरू र अवधारणाहरू आत्मविश्वासका साथ नेभिगेट गर्न
- उपयुक्त प्राविधिक शब्दावली प्रयोग गरेर समस्या समाधान गर्न
- टिम छलफलहरूमा सटीक प्राविधिक भाषा प्रयोग गरेर योगदान गर्न
- व्यवस्थित रूपमा Azure क्लाउड विकास ज्ञान विस्तार गर्न

## A

**ARM Template**  
Azure Resource Manager टेम्प्लेट। JSON आधारित Infrastructure as Code ढाँचा जसले Azure स्रोतहरू डिक्लेरेटिभ रूपमा परिभाषित र तैनाथ गर्दछ।

**App Service**  
Azure को platform-as-a-service (PaaS) जसले वेब अनुप्रयोगहरू, REST APIs, र मोबाइल ब्याकएण्डहरू होस्ट गर्छ बिना इन्फ्रास्ट्रक्चर व्यवस्थापनका।

**Application Insights**  
Azure को एप्लिकेशन प्रदर्शन अनुगमन (APM) सेवा जसले एप्लिकेशनको प्रदर्शन, उपलब्धता, र उपयोगमा गहिरो अन्तर्दृष्टि प्रदान गर्दछ।

**Azure CLI**  
Azure स्रोतहरू व्यवस्थापन गर्ने कमाण्ड लाइन इन्टरफेस। यो AZD पूरक हो तर अलग लगइन हुन्छ; मुख्य AZD प्रमाणीकरणले `azd auth login` प्रयोग गर्छ।

**Azure Developer CLI (azd)**  
डेवेलपर-केंद्रित कमाण्ड लाइन उपकरण जुन टेम्प्लेट र Infrastructure as Code प्रयोग गरेर Azure मा अनुप्रयोगहरू छिटो निर्माण र तैनाथ गर्ने प्रक्रिया छिटो बनाउँछ।

**azure.yaml**  
azd परियोजनाको मुख्य कन्फिगरेसन फाइल जुन सेवाहरू, इन्फ्रास्ट्रक्चर, र तैनाथ हुकहरू परिभाषित गर्छ।

**Azure Resource Manager (ARM)**  
Azure को वितरण र व्यवस्थापन सेवा जसले स्रोतहरू सिर्जना, अद्यावधिक, र मेटाउने व्यवस्थापन तह प्रदान गर्दछ।

## B

**Bicep**  
Microsoft द्वारा विकास गरिएको डोमेन-विशेष भाषा (DSL) जुन Azure स्रोतहरू तैनाथ गर्न प्रयोग हुन्छ। ARM टेम्प्लेट भन्दा सरल सिन्ट्याक्स प्रदान गर्दछ र ARM मा कम्पाइल हुन्छ।

**Build**  
स्रोत कोड कम्पाइल गर्ने, निर्भरता स्थापना गर्ने, र अनुप्रयोगहरू तैनाथ गर्न तयार गर्ने प्रक्रिया।

**Blue-Green Deployment**  
तैनाथ रणनीति जसले दुई समान उत्पादन वातावरणहरू (ब्लू र ग्रीन) प्रयोग गरी डाउनटाइम र जोखिमलाई न्यून गर्दछ।

## C

**Container Apps**  
Azure को सर्वरलेस कन्टेनर सेवा जसले जटिल इन्फ्रास्ट्रक्चर व्यवस्थापन बिना कन्टेनराइज्ड अनुप्रयोगहरू चलाउन सक्षम बनाउँछ।

**CI/CD**  
निरन्तर एकीकरण/निरन्तर वितरण। कोड परिवर्तनहरू एकीकरण र अनुप्रयोग तैनाथ गर्ने स्वचालित अभ्यासहरू।

**Cosmos DB**  
Azure को विश्वव्यापी वितरण गरिएको, बहु-मोडल डाटाबेस सेवा जसले throughput, latency, उपलब्धता, र निरन्तरताको समग्र SLA हरू प्रदान गर्दछ।

**Configuration**  
एप्लिकेशन व्यवहार र तैनाथ विकल्पहरू नियन्त्रित गर्ने सेटिङहरू र प्यारामिटरहरू।

## D

**Deployment**  
लक्षित इन्फ्रास्ट्रक्चरमा अनुप्रयोगहरू र तिनका निर्भरता स्थापना र कन्फिगर गर्ने प्रक्रिया।

**Docker**  
कन्टेनराइजेशन प्रविधि प्रयोग गरेर अनुप्रयोगहरू विकास, शिप, र चलाउने प्लेटफर्म।

**Dockerfile**  
Docker कन्टेनर छविको निर्माणका लागि निर्देशनहरू समेटिएको पाठ फाइल।

## E

**Environment**  
विशेष अनुप्रयोगको एक तैनाथ लक्ष्य जस्तै विकास, स्टेजिङ, वा उत्पादन।

**Environment Variables**  
रनटाइममा एप्लिकेशनहरूले पहुँच गर्न सक्ने कन्फिगरेसन मानहरू जसलाई कुञ्जी-मूल्य जोडीको रूपमा संग्रह गरिएको हुन्छ।

**Endpoint**  
URL वा नेटवर्क ठेगाना जहाँबाट अनुप्रयोग वा सेवा पहुँचयोग्य हुन्छ।

## F

**Function App**  
Azure को सर्वरलेस कम्प्युट सेवा जसले घटनामा आधारित कोडलाई इन्फ्रास्ट्रक्चर व्यवस्थापन बिना चलाउन सक्षम बनाउँछ।

## G

**GitHub Actions**  
GitHub भण्डारणगृहहरूसँग एकीकृत CI/CD प्लेटफर्म जसले कार्यप्रवाहहरू स्वचालित गर्दछ।

**Git**  
स्रोत कोडमा भएका परिवर्तनहरू ट्र्याक गर्न प्रयोग हुने वितरण गरिएको संस्करण नियन्त्रण प्रणाली।

## H

**Hooks**  
विशेष तैनाथ जीवनचक्रका बिन्दुहरूमा चल्ने कस्टम स्क्रिप्ट वा कमाण्डहरू (पूर्वप्रावधान, पश्चात्-प्रावधान, पूर्व-तैनाथ, पश्चात-तैनाथ)।

**Host**  
Azure सेवा प्रकार जहाँ अनुप्रयोग तैनाथ गरिनेछ (जस्तै appservice, containerapp, function)।

## I

**Infrastructure as Code (IaC)**  
हार्डवेयर प्रक्रियाहरूको सट्टा कोडमार्फत इन्फ्रास्ट्रक्चर परिभाषित र व्यवस्थापन गर्ने अभ्यास।

**Init**  
नयाँ azd परियोजना आरम्भ गर्ने प्रक्रिया, सामान्यतया टेम्प्लेटबाट।

## J

**JSON**  
JavaScript Object Notation। कन्फिगरेसन फाइल र API प्रतिक्रियाहरूको लागि सामान्य प्रयोग हुने डेटा रूपान्तरण ढाँचा।

**JWT**  
JSON Web Token। JSON वस्तुको रूपमा पक्षहरूबीच सुरक्षित रूपमा जानकारी प्रसारण गर्ने मानक।

## K

**Key Vault**  
Azure को सेवा जसले गोप्य जानकारी, कुञ्जीहरू, र प्रमाणपत्रहरू सुरक्षित रूपमा संग्रह र व्यवस्थापन गर्छ।

**Kusto Query Language (KQL)**  
Azure Monitor, Application Insights, र अन्य Azure सेवाहरूमा डाटालाई विश्लेषण गर्न प्रयोग गरिने क्वेरी भाषा।

## L

**Load Balancer**  
सेवा जुन धेरै सर्भर वा इन्ट्यान्सहरूमा आउने नेटवर्क ट्राफिक वितरण गर्छ।

**Log Analytics**  
Azure सेवा जसले क्लाउड र अन-प्रिमाइस वातावरणबाट टेलीमेट्री डाटा जम्मा, विश्लेषण र कार्यान्वयन गर्छ।

## M

**Managed Identity**  
Azure को सुविधा जसले Azure सेवाहरूलाई अन्य Azure सेवाहरूसँग प्रमाणीकरण गर्न स्वचालित रूपमा व्यवस्थापन गरिने पहिचान प्रदान गर्छ।

**Microservices**  
वास्तुकला दृष्टिकोण जहाँ अनुप्रयोगहरू साना, स्वतन्त्र सेवाहरूको संग्रहको रूपमा बनाइन्छ।

**Monitor**  
Azure को एकीकृत अनुगमन समाधान जसले अनुप्रयोग र इन्फ्रास्ट्रक्चरमा सम्पूर्णस्तरको दृश्यता प्रदान गर्छ।

## N

**Node.js**  
Chrome को V8 JavaScript इन्जिनमा आधारित JavaScript रनटाइम, जसले सर्भर-साइډ अनुप्रयोगहरू निर्माण गर्न प्रयोग हुन्छ।

**npm**  
Node.js का लागि प्याकेज प्रबन्धक जसले निर्भरता र प्याकेजहरू व्यवस्थापन गर्छ।

## O

**Output**  
इन्फ्रास्ट्रक्चर तैनाथबाट फिर्ता गरिएका मानहरू जुन अनुप्रयोग वा अन्य स्रोतहरूले प्रयोग गर्न सक्छन्।

## P

**Package**  
अनुप्रयोग कोड र निर्भरतालाई तैनाथका लागि तयार गर्ने प्रक्रिया।

**Parameters**  
इन्फ्रास्ट्रक्चर टेम्प्लेटहरूलाई परिमार्जन गर्न इनपुट मानहरू पास गर्ने तरिका।

**PostgreSQL**  
खुला स्रोत रिलेशनल डाटाबेस प्रणाली जसलाई Azure मा प्रबन्धित सेवाको रूपमा समर्थन गरिन्छ।

**Provisioning**  
इन्फ्रास्ट्रक्चर टेम्प्लेटहरूमा परिभाषित Azure स्रोतहरू सिर्जना र कन्फिगर गर्ने प्रक्रिया।

## Q

**Quota**  
Azure सदस्यता वा क्षेत्रमा सिर्जना गर्न सकिने स्रोतहरूको सीमितता।

## R

**Resource Group**  
Azure स्रोतहरूका लागि तार्किक कन्टेनर जसले उनीहरूको जीवनचक्र, अनुमति, र नीति साझा गर्छ।

**Resource Token**  
azd द्वारा सिर्जित अनन्य स्ट्रिङ जसले तैनाथहरूमा स्रोत नामहरू अनन्य सुनिश्चित गर्छ।

**REST API**  
HTTP मेथडहरू प्रयोग गरी नेटवर्क अनुप्रयोगहरू डिजाइन गर्ने वास्तुकला शैली।

**Rollback**  
अनुप्रयोग वा इन्फ्रास्ट्रक्चर कन्फिगरेसनको पहिलेको संस्करणमा फर्कने प्रक्रिया।

## S

**Service**  
azure.yaml मा परिभाषित तपाईंको अनुप्रयोगको एक कम्पोनेन्ट (जस्तै वेब फ्रन्टएण्ड, API ब्याकएण्ड, डाटाबेस)।

**SKU**  
Stock Keeping Unit। Azure स्रोतहरूको विभिन्न सेवा तह वा प्रदर्शन स्तरहरू जनाउने।

**SQL Database**  
Microsoft SQL Server आधारित Azure को प्रबन्धित रिलेशनल डाटाबेस सेवा।

**Static Web Apps**  
स्रोत कोड भण्डारहरूबाट पूर्ण-स्ट्याक वेब अनुप्रयोगहरू निर्माण र तैनाथ गर्ने Azure सेवा।

**Storage Account**  
Azure सेवा जसले ब्लब, फाइल, क्यु, र टेबलहरू सहित डेटा वस्तुहरूको क्लाउड स्टोरेज प्रदान गर्छ।

**Subscription**  
Azure खाता कन्टेनर जसले स्रोत समूहहरू र स्रोतहरू राख्छ, बिलिङ र पहुँच व्यवस्थापनसहित।

## T

**Template**  
सामान्य परिदृश्यहरूको लागि एप्लिकेशन कोड, इन्फ्रास्ट्रक्चर परिभाषाहरू, र कन्फिगरेसन समावेश गर्ने पूर्व-निर्मित परियोजना संरचना।

**Terraform**  
खुला स्रोत Infrastructure as Code उपकरण जसले Azure सहित विभिन्न क्लाउड प्रदायकहरूलाई समर्थन गर्छ।

**Traffic Manager**  
Azure को DNS-आधारित ट्राफिक लोड बेलेंसर जसले विश्वव्यापी Azure क्षेत्रहरूमा ट्राफिक वितरण गर्छ।

## U

**URI**  
Uniform Resource Identifier। एउटा विशेष स्रोत चिनाउने स्ट्रिङ।

**URL**  
Uniform Resource Locator। URI को प्रकार जसले स्रोत कहाँ छ र कसरी प्राप्त गर्ने भनेर निर्दिष्ट गर्छ।

## V

**Virtual Network (VNet)**  
Azure मा निजी नेटवर्कहरूको आधारभूत निर्माण खण्ड जसले पृथकता र खण्डीकरण प्रदान गर्छ।

**VS Code**  
Visual Studio Code। Azure र azd एकीकरण सहित लोकप्रिय कोड सम्पादक।

## W

**Webhook**  
विशेष घटनाहरूले ट्रिगर गर्ने HTTP कल ब्याक, सामान्यतया CI/CD पाइपलाइनहरूमा प्रयोग हुने।

**What-if**  
Azure सुविधा जसले तैनाथले कुन परिवर्तनहरू गर्ने हो भनेर देखाउँछ तर वास्तविक रूपमा कार्यान्वयन गर्दैन।

## Y

**YAML**  
YAML Ain't Markup Language। मानव-पठनीय डेटा सिरियलाइजेसन मापदण्ड जुन कन्फिगरेसन फाइलहरू जस्तै azure.yaml का लागि प्रयोग हुन्छ।

## Z

**Zone**

## Azure सेवा नाम म्यासिङहरू

| सामान्य नाम | आधिकारिक Azure सेवा नाम | azd होस्ट प्रकार |
|-------------|------------------------------|---------------|
| वेब अनुप्रयोग | Azure App Service | `appservice` |
| API अनुप्रयोग | Azure App Service | `appservice` |
| कन्टेनर अनुप्रयोग | Azure Container Apps | `containerapp` |
| फंक्शन | Azure Functions | `function` |
| स्थिर साइट | Azure Static Web Apps | `staticwebapp` |
| डाटाबेस | Azure Database for PostgreSQL | Infrastructure स्रोत, अनुप्रयोग होइन `host` |
| NoSQL DB | Azure Cosmos DB | Infrastructure स्रोत, अनुप्रयोग होइन `host` |
| स्टोरेज | Azure Storage Account | Infrastructure स्रोत, बिल्ट-इन अनुप्रयोग होइन `host` |
| क्यास | Azure Managed Redis | Infrastructure स्रोत, अनुप्रयोग होइन `host` |
| खोज | Azure AI Search | Infrastructure स्रोत, अनुप्रयोग होइन `host` |
| सन्देश सेवा | Azure Service Bus | Infrastructure स्रोत, अनुप्रयोग होइन `host` |

`services.<name>.host` ले अनुप्रयोग तैनाथ लक्ष्य चयन गर्छ; यो कुनै Azure स्रोत प्रकारको संक्षेप होइन। डाटाबेसहरू, क्यासहरू, खोज सेवाहरू, र क्युहरू सामान्यतया इन्फ्रास्ट्रक्चर प्रदायकमार्फत प्रावधान गरिन्छ र आउटपुट/कन्फिगरेसन मार्फत अनुप्रयोगसँग जडित हुन्छन्।

## सन्दर्भ-विशेष शब्दहरू

### विकाससम्बन्धी शब्दहरू
- **Hot Reload**: विकासको क्रममा अनुप्रयोगहरूलाई पुन: सुरुविना स्वत: अपडेट गर्ने
- **Build Pipeline**: कोड निर्माण र परीक्षणका लागि स्वचालित प्रक्रिया
- **Deployment Slot**: App Service भित्रको स्टेजिङ वातावरण
- **Environment Parity**: विकास, स्टेजिङ, र उत्पादन वातावरणहरूलाई समान राख्ने

### सुरक्षा शब्दहरू
- **Managed Identity**: स्वचालित प्रमाणीकरण व्यवस्थापन दिने Azure सुविधा
- **Key Vault**: गोप्य सूचना, कुञ्जीहरू, र प्रमाणपत्रहरू सुरक्षित गर्ने स्थान
- **RBAC**: Azure स्रोतहरूको भूमिकामा आधारित पहुँच नियन्त्रण
- **Network Security Group**: नेटवर्क ट्राफिक नियन्त्रणका लागि भर्चुअल फायरवाल

### अनुगमन शब्दहरू
- **Telemetry**: मापन र डाटा स्वचालित रूपमा सङ्कलन गर्ने प्रक्रिया
- **Application Performance Monitoring (APM)**: सफ्टवेयर प्रदर्शन अनुगमन
- **Log Analytics**: लग डाटाको सङ्कलन र विश्लेषण सेवा
- **Alert Rules**: मेट्रिक्स वा अवस्थाहरूमा आधारित स्वचालित सूचना

### तैनाथ शब्दहरू
- **Blue-Green Deployment**: शून्य डाउनटाइम तैनाथ रणनीति
- **Canary Deployment**: प्रयोगकर्ताहरूको उपसमूहमा क्रमशः रोलआउट गर्ने
- **Rolling Update**: अनुप्रयोग इन्स्ट्यान्सहरूको क्रमागत प्रतिस्थापन
- **Rollback**: पहिलेको अनुप्रयोग संस्करणमा फर्किने
