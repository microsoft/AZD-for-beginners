# AI विकासकर्ताहरूका लागि AZD कार्यशाला

> स्रोत निर्देशन AZD 1.37.2 अनुसार ४ नोभेम्बर २०२६ मा समीक्षा गरिएको छ। स्क्रीनशटहरू उदाहरणका लागि हुन्; सेवा उपलब्धता, पोर्टल लेबलहरू, र टेम्प्लेट पूर्वनिर्धारितहरू परिवर्तन हुन सक्छन्।

> [!IMPORTANT]  
> **यो कार्यशाला एक कार्यशाला मार्गदर्शकसहित अनुकूल गरिएको छ जुन तपाईंले आफ्नो स्थानीय ब्राउजरमा पूर्वावलोकन गर्न सक्नुहुन्छ। सुरु गर्न, GitHub Codespaces, एउटा विकास कन्टेनर, वा MkDocs स्थापना गरिएको स्थानीय क्लोनमा रेपो खोल्नुहोस्—पछि सक्रिय VS कोड टर्मिनल देखिँदासम्म पर्खनुहोस् र टाइप गर्नुहोस्:**  
> कोर्स रिपोजिटरी रूटबाट `requirements-dev.txt` इन्स्टल गर्नुहोस्, त्यसपछि `python -m mkdocs serve --config-file workshop/mkdocs.yml` अग्रभूमिमा चलाउनुहोस्।
> **तपाईंले ब्राउजरमा पूर्वावलोकन पृष्ठ खोल्न पप-अप संवाद देख्नुपर्नेछ।**

AI एप्लिकेशन डिप्लोयमेन्टमा केन्द्रित भएर Azure Developer CLI (AZD) सिक्नको लागि स्वागत छ। यो कार्यशालाले तपाईंलाई ३ चरणमा AZD टेम्प्लेटहरूको कार्यान्वयन गर्ने व्यवहारिक बुझाइ दिन्छ:

1. **खोजी** - तपाईंको लागि उपयुक्त टेम्प्लेट फेला पार्नुहोस्।
1. **प्रयोग** - डिप्लोय र काम गर्ने प्रमाणित गर्नुहोस्।
1. **अनुकूलन** - परिमार्जन गरी आफ्नो बनाउनुस्!

यो कार्यशालाको समयमा, तपाईंले कोर विकासकर्ता उपकरणहरू र कार्यप्रवाहहरू पनि सिक्नुहुनेछ, जसले तपाईंको विकास यात्रालाई सहज बनाउनेछ।

## कार्यशाला अवलोकन

**अवधि:** ३-४ घण्टा  
**स्तर:** प्रारम्भ देखि मध्यवर्ती  
**पूर्वसर्तहरू:** Azure, AI अवधारणाहरू, VS Code र कमाण्ड लाइन उपकरणहरूसँग परिचित हुनुपर्छ।

यो हातेमालो कार्यशाला हो जहाँ तपाईं क्रियाकलाप गरेर सिक्नुहुन्छ। अभ्यासहरू पूरा गरेपछि, सिकाइ जारी राख्न सुरक्षा र उत्पादकता उत्कृष्ट अभ्यासहरूको लागि AZD प्रारम्भिक पाठ्यक्रम समीक्षा गर्न सिफारिस गरिन्छ।

| समय| मोड्युल  | उद्देश्य |
|:---|:---|:---|
| १५ मिनेट | परिचय | विषय राख्नुहोस्, लक्ष्य बुझ्नुहोस् |
| ३० मिनेट | AI टेम्प्लेट चयन गर्नुहोस् | विकल्पहरू अन्वेषण गरी सुरुवाती छनौट गर्नुहोस् | 
| ३० मिनेट | AI टेम्प्लेट प्रमाणित गर्नुहोस् | पूर्वनिर्धारित समाधानलाई Azure मा डिप्लोय गर्नुहोस् |
| ३० मिनेट | AI टेम्प्लेट विघटन गर्नुहोस् | संरचना र कन्फिगरेसनको अन्वेषण गर्नुहोस् |
| ३० मिनेट | AI टेम्प्लेट कन्फिगर गर्नुहोस् | उपलब्ध सुविधाहरू सक्रिय गरी प्रयास गर्नुहोस् |
| ३० मिनेट | AI टेम्प्लेट अनुकूलन गर्नुहोस् | टेम्प्लेटलाई तपाईंको आवश्यकताअनुसार अनुकूलित गर्नुहोस् |
| ३० मिनेट | पूर्वाधार फराकिलो गर्नुहोस् | स्रोतहरू सफा गरी मुक्त गर्नुहोस् |
| १५ मिनेट | समापन र अर्को चरणहरू | सिकाइ स्रोतहरू, कार्यशाला चुनौती |
| | |

## तपाईंले के सिक्नुहुनेछ

AZD टेम्प्लेटलाई माइक्रोसफ्ट फाउन्ड्रीमा अन्तदेखि अन्त विकासका विभिन्न क्षमता र उपकरणहरूको अन्वेषण गर्न सिकाइ रेन्डबक्सको रूपमा विचार गर्नुहोस्। यस कार्यशालाको अन्त्यसम्म तपाईं विभिन्न उपकरण र अवधारणाको सहज ज्ञान पाउनुहुनेछ।

| अवधारणा  | उद्देश्य |
|:---|:---|
| **Azure Developer CLI** | उपकरण कमाण्डहरू र कार्यप्रवाहहरूको बुझाइ |
| **AZD टेम्प्लेटहरू**| परियोजना संरचना र कन्फिगरेसन बुझ्नुहोस् |
| **Azure AI Agent**| Microsoft Foundry परियोजना प्रावधान र डिप्लोय गर्नुहोस् |
| **Azure AI Search**| एजेन्टहरूसँग सन्दर्भ इञ्जीनियरिङ सक्षम पार्नुहोस् |
| **पर्यवेक्षण**| ट्रेसिङ, अनुगमन र मूल्याङ्कन अन्वेषण गर्नुहोस् |
| **रेड टीमिङ**| प्रतिस्पर्धात्मक परीक्षण र निवारण अन्वेषण गर्नुहोस् |
| | |
