# Microtjenester Eksempel

Den kjørbare implementeringen og instruksjonene er i
**[container-app/microservices](../container-app/microservices/README.md)**.

Denne katalogen er kun for navigasjon. Den har ingen `azure.yaml`, `infra/`, eller `src/`.
Ikke kjør `azd up` her.

Fra rotmappen av depotet:

```bash
cd examples/container-app/microservices
```

Følg deretter den lenkede README-filen for forutsetninger, distribusjon, verifisering, lokal
utvikling, praktiske øvelser, kostnader og opprydding.

Eksempelet inneholder en Node.js API-gateway og en Python-produktjeneste med kun lesetilgang.
Ordre-, bruker-, varsel-, database- og meldings-tjenester er utvidelsesideer,
ikke implementasjoner inkludert i dette depotet.

- [Forrige: Enkel Flask-API](../../../../examples/container-app/simple-flask-api)
- [Neste: Databaseapp](../../../../examples/database-app)
- [AI-utvikling](../../docs/chapter-02-ai-development/README.md)
- [Kursforside](../../README.md)
