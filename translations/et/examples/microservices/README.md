# Mikroteenuste näide

Käivitatav rakendus ja selle juhised asuvad
**[container-app/microservices](../container-app/microservices/README.md)**.

See kaust on mõeldud ainult navigeerimiseks. Seal pole ühtegi `azure.yaml`, `infra/` ega `src/`.
Ära käivita siin `azd up`.

Repositsiooni juurest:

```bash
cd examples/container-app/microservices
```

Järgmiseks jälgi lingitud README-d, mis käsitleb eeltingimusi, paigaldamist, kontrollimist, kohalikku
arendust, praktilisi harjutusi, kulusid ja koristamist.

Näidis sisaldab Node.js API väravat ja ainult lugemisrežiimis Python toote teenust.
Tellimuse, kasutaja, teavituse, andmebaasi ja sõnumiteenused on laienduse ideed,
mitte selle hoidla osa rakendused.

- [Eelmine: Lihtne Flask API](../../../../examples/container-app/simple-flask-api)
- [Järgmine: Andmebaasi rakendus](../../../../examples/database-app)
- [AI arendus](../../docs/chapter-02-ai-development/README.md)
- [Kursuse avaleht](../../README.md)
