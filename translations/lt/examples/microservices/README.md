# Mikroservisų pavyzdys

Veikianti įgyvendinimo versija ir jos instrukcijos yra
**[container-app/microservices](../container-app/microservices/README.md)**.

Šis katalogas skirtas tik navigacijai. Jame nėra `azure.yaml`, `infra/` ar `src/`.
Čia nevykdykite `azd up`.

Iš repozitorijos šaknies:

```bash
cd examples/container-app/microservices
```

Tada sekite susietą README dėl reikalavimų, diegimo, patikrinimo, vietinio
vystymo, praktinių užduočių, išlaidų ir valymo.

Pavyzdyje yra Node.js API Vartai ir tik skaitymui skirta Python Produkto Paslauga.
Užsakymų, vartotojų, pranešimų, duomenų bazės ir žinučių siuntimo paslaugos yra plėtros idėjos,
o ne įgyvendinimai, įtraukti į šią repozitoriją.

- [Ankstesnis: Paprastas Flask API](../../../../examples/container-app/simple-flask-api)
- [Kitas: Duomenų bazės programa](../../../../examples/database-app)
- [AI vystymas](../../docs/chapter-02-ai-development/README.md)
- [Kursų pradžia](../../README.md)
