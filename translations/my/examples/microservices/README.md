# မိုက်ခရိုဆာဗစ်အထွေထွေဥပမာ

လည်ပတ်နိုင်သော အကောင်အထည်ဖော်မှုနှင့် အညွှန်းများမှာ
**[container-app/microservices](../container-app/microservices/README.md)** တွင် ရှိသည်။

ဤဖိုင်အုပ်စုသည် သွားလမ်းညွှန် ပုံစံဖြစ်သည်။ အတွင်းတွင် `azure.yaml`၊ `infra/` သို့မဟုတ် `src/` မပါဝင်ပါ။
ဒီမှာ `azd up` မဖြင့်ပါနှင့်။

ဂိုဒေါင် ရှေ့တွင် မှာ:

```bash
cd examples/container-app/microservices
```

ထို့နောက်လိုက်လျောညီထွေ README ကို အသုံးပြုလိုက်ပါက မတက်ဖွားမှုများ၊ တပ်ဆင်ခြင်း၊ အတည်ပြုခြင်း၊ ဒေသတွင်းဖွံ့ဖြိုးတိုးတတ်ခြင်း၊ လက်တွေ့လေ့ကျင့်မှုများ၊ ကုန်ကျစရိတ်များနှင့် ရှင်းလင်းရေးဆိုင်ရာ မှုများ ပါဝင်သည်။


အော်ဒါ၊ အသုံးပြုသူ၊ အသိပေးချက်၊ ဒေတာဘေ့စ်နှင့် မက်ဆေ့ခ်ျဆာဗစ်များမှာ ရည်မှန်းချက်ဖြစ်ပြီး၊
ဤဂိုဒေါင်တွင် ပါဝင်သောအကောင်အထည်မဟုတ်ပါ။
