# AI Developer များအတွက် AZD အလုပ်ရုံဆွေးနွေးပွဲ

> အညွှန်းကို AZD 1.37.2 နှင့် ၂၀၂၆ ခုနှစ် နိုဝင်ဘာ ၄ ရက်နေ့တွင် ပြန်လည်သုံးသပ်ထားသည်။ စကရင်ရှော့များသည် ရှင်းပြရန်ဖြစ်ပြီး ဝန်ဆောင်မှုရရှိနိုင်မှု၊ ပေါ်တယ် အမည်များနှင့် မူကြမ်း အဓိကတန်ဖိုးများသည် ပြောင်းလဲနိုင်ပါသည်။

> [!IMPORTANT]  
> **ဤအလုပ်ရုံဆွေးနွေးပွဲကို သင်၏ အပြည့်အဝ ဘရောက်ဇာတွင် ကြည့်ရှုနိုင်သော အလုပ်ရုံလမ်းညွှန်ဖြင့် စီစဉ်ထားသည်။ စတင်ရန် GitHub Codespaces, dev container သို့မဟုတ် MkDocs ထည့်သွင်းထားသော ဒေသဆိုင်ရာ ကလုန်းကို ဖြင့်ပါ—ပြီးနောက် VS Code terminal တစ်ခု လက်ရှိ အသုံးပြုနိုင်သည်ကို မြင်အောင် စောင့်ဆိုင်းပြီး အောက်ပါအတိုင်း ရိုက်ထည့်ပါ။**  
> သင်၏ သင်တန်း repository ရှေ့ပေါ်မှ `requirements-dev.txt` ကို ထည့်သွင်းပြီး အရှေ့တန်းတွင် `python -m mkdocs serve --config-file workshop/mkdocs.yml` ကို ပြေးပါ။
> **ဘရောက်ဇာတွင် ကြိုတင်သုံးသပ်မှု စာမျက်နှာကို ဖွင့်ရန် ပေါ်လာသည့် စာတောင်းပွန်းမှတ်တမ်းကို ကြည့် ရမည် ဖြစ်သည်။**

Azure Developer CLI (AZD) ကို AI လျှောက်လွှာ တပ်ဆင်ရေး အဓိကထားပြီး လက်တွေ့ သင်ယူနိုင်အောင် လက်တွေ့ လမ်းညွှန်အလုပ်ရုံဆွေးနွေးပွဲမှ ကြိုဆိုပါသည်။ ဤအလုပ်ရုံဆွေးနွေးပွဲသည် သင်ကို AZD မူကြမ်းများကို သုံးသပ်ခြင်းနှင့် အောက်ပါ ၃ ခြေလှမ်းဖြင့် အသုံးချခြင်းအား ရယူနိုင်ရန် ကူညီပံ့ပိုးပါသည်။

၁။ **ရှာဖွေခြင်း** - သင်ကိုသင့်တော်သော မူကြမ်းရွေးချယ်ပါ။
၁။ **တပ်ဆင်ခြင်း** - တပ်ဆင်ပြီး အလုပ်လုပ်စွမ်းဆောင်မှုကို စစ်ဆေးပါ
၁။ **စိတ်ကြိုက် ပြင်ဆင်ခြင်း** - ကိုယ်ပိုင်လိုအပ်ချက်အတိုင်း ပြုပြင်ဆင်သွားပါ!

ဤအလုပ်ရုံအတွင်း သင်သည် အဓိက developer ကိရိယာများနှင့် လုပ်ငန်းစဉ်များကိုလည်း မိတ်ဆက်ခြင်းခံကြမည်ဖြစ်၍ သင်၏ စနစ်တကျဖွံ့ဖြိုးတိုးတက်မှု ခရီးစဉ်တစ်လျှောက်တွင် ဆက်လက် မြှင် တင်နိုင်ရန် ကူညီပါလိမ့်မည်။

## အလုပ်ရုံဆွေးနွေးပွဲ အနှစ်ချုပ်

**ကြာချိန်:** ၃-၄ နာရီ  
**အဆင့်:** အစသင်မှ အလယ်အလတ် အဆင့်များအထိ  
**လိုအပ်ချက်များ:** Azure, AI အကြောင်းအရာများနှင့် VS Code၊ command-line ကိရိယာများနှင့် နည်းလမ်းများအား နားလည်မှုရှိမှု။

ဤသည်မှာ လက်တွေ့လုပ်ဆောင်ခြင်းဖြင့် သင်ယူသော အလုပ်ရုံဆွေးနွေးပွဲတစ်ရပ်ဖြစ်သည်။ လေ့ကျင့်ခန်းများပြီးဆုံးပါက AZD အသစ်စတင်လေ့လာသူများ အတန်းအစီအစဉ်ကို ပြန်လည်လေ့လာ၍ လုံခြုံရေးနှင့် ထုတ်လုပ်မှုကောင်းမွန်ရေး ဆိုင်ရာ အကောင်းဆုံးကျင့်ဝတ်များကို ဆက်လက် သင်ယူရန် အကြံပြုပါသည်။

| ကြာချိန်| အပိုင်းအစ  | ရည်ရွယ်ချက် |
|:---|:---|:---|
| ၁၅ မိနစ် | နိဒါန်း | အခြေခံရည်ရွယ်ချက်များကို နားလည်ရန် |
| ၃၀ မိနစ် | AI မူကြမ်း ရွေးချယ်ခြင်း | ရွေးချယ်စရာများ စူးစမ်း၍ စတင်ရန် ရွေးချယ်ပါ | 
| ၃၀ မိနစ် | AI မူကြမ်း စစ်ဆေးခြင်း | ရှေ့ပြေးဖြေရှင်းချက်ကို Azure သို့ တပ်ဆင်ပါ |
| ၃၀ မိနစ် | AI မူကြမ်း ခွဲခြမ်းစိတ်ဖြာခြင်း | ဖွဲ့စည်းပုံနှင့် အဆင့်ဆင့် ကွပ်ကဲမှုများကို စူးစမ်းပါ |
| ၃၀ မိနစ် | AI မူကြမ်း ချိန်ညှိခြင်း | လုပ်ဆောင်ချက်များကို ဖွင့်လှစ်ကြည့်ရှုပါ |
| ၃၀ မိနစ် | AI မူကြမ်း ကိုယ်ပိုင် ပြင်ဆင်ခြင်း | သင့်လိုအပ်ချက်အတွက် မူကြမ်းအား ပြင်ဆင်ပါ |
| ၃၀ မိနစ် | အင်ဖրաစတ်ခ်ချာ ဖျက်သိမ်းခြင်း | သန့်ရှင်းခြင်းနှင့် အရင်းအမြစ်များ လွှတ်ပေးခြင်း |
| ၁၅ မိနစ် | အဆုံးသတ်ခြင်း & နောက်တင်ဆက်ချက်များ | သင်ယူရန် tàiရင်းများ၊ အလုပ်ရုံအပြိုင်အဆိုင် စိန်ခေါ်မှု |

## သင်ကိုဘာတွေ သင်ယူနိုင်မလဲ

AZD မူကြမ်းကို Microsoft Foundry တွင် အစမှ အဆုံး ဖွံ့ဖြိုးတိုးတက်မှု အတွက် အမျိုးမျိုးသော လုပ်ဆောင်ချက်များနှင့် ကိရိယာများကို စူးစမ်းသုံးသပ်ရန် သင်ယူရေး စောင့်ကြည့်ကွင်းငယ်တစ်ခုအဖြစ် စဉ်းစားပါ။ ဤအလုပ်ရုံဆွေးနွေးပွဲပြီးဆုံးသည်နှင့် သင်သည် ဤအကြောင်းအရာ၌ ကိရိယာနှင့် အယူအဆ အမျိုးမျိုးအတွက် ခံစားချက်တစ်ခု ရရှိလာကြမည် ဖြစ်သည်။

| အယူအဆ  | ရည်ရွယ်ချက် |
|:---|:---|
| **Azure Developer CLI** | ကိရိယာ အမိန့်များနှင့် လုပ်ငန်းစဉ်များ နားလည်ရန်|
| **AZD မူကြမ်းများ**| စီမံကိန်း ဖွဲ့စည်းပုံနှင့် ဖွဲ့စည်းမှုကို နားလည်ရန်|
| **Azure AI Agent**| Microsoft Foundry စီမံကိန်း တပ်ဆင်ရေးနှင့် ဖြန့်ချိမည်  |
| **Azure AI Search**| အကြောင်းအရာ အင်ဂျင်နီယာ အတွက် Agent များ ဖွင့်လှစ်ရန် |
| **ရှုမြင်နိုင်ခြင်း**| လမ်းကြောင်းလိုက်ခြင်း၊ စောင့်ကြပ်ခြင်းနှင့် အကဲဖြတ်ခြင်းများ စူးစမ်းရန် |
| **Red Teaming**| တိုက်ခိုက်မှု စမ်းသပ်မှုနှင့် ကာကွယ်နည်းများ စူးစမ်းရန် |
| | |
