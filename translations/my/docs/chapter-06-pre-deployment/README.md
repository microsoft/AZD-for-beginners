## အနှစ်ချုပ်

ဒီအခန်းမှာ သင့်အပလီကေးရှင်းကို တပ်ဆင်ခင်းမလုပ်ခင် လိုအပ်သောစီမံကိန်းရေးဆွဲခြင်းနှင့် အတည်ပြုခြင်းဆိုင်ရာ အရေးပါဆုံး အဆင့်များကို ဖော်ပြထားပါတယ်။ မှန်ကန်စွာ စွမ်းဆောင်ရည် စီမံကိန်းရေးဆွဲခြင်း၊ SKU ရွေးချယ်ခြင်း၊ ကြိုတင်စစ်ဆေးခြင်းဖြင့် လျော့နည်းစရိတ်များကို ရှောင်ရှားနိူင်ပါသည်။

> ထုတ်ပြန်ထားသော `azd 1.37.2` ကိုးကားချက်ဖြင့် ညွှန်ကြားချက်များကို ပြန်လည်ဆန်းစစ်ထားသည်။ Cloud တပ်ဆင်မှုများ မပြုလုပ်ပါ။ မေလည်း သင်ခန်းစာများတွင် ပုံဖော်ထားသော အပိုင်းများပါဝင်သော်လည်း တစ်ပြည့်တည့်သော ဒေသခံတပ်ဆင်မှု မဟုတ်ပါ။

## သင်ယူရမည့် ရည်မှန်းချက်များ

ဒီအခန်းကို ပြီးမြောက်ပါက -
- တပ်ဆင်ခင်းမပြုမီ ကြိုတင်စစ်ဆေးမှုများပြုလုပ်နိုင်မည်
- စွမ်းဆောင်ရည် စီမံကိန်းရေးဆွဲခြင်းနှင့် အရင်းအမြစ် လိုအပ်ချက်များ ခန့်မှန်းနိုင်မည်
- စရိတ်ချွေတာနိုင်မှုအတွက် သင့်လျော်သော SKU များကို ရွေးချယ်နိုင်မည်
- မောနီတာအတွက် Application Insights ကို ဆက်တင် ပြုပြင်နိုင်မည်
- မျိုးစုံ Agent များ ပူးပေါင်းဆောင်ရွက်မှု နမူနာများနှင့် တပ်ဆင်မှု လိုအပ်ချက်များကို နားလည်နိုင်မည်

## 🚀 အလျင်အမြန် စတင်ခြင်း

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ ကြိုတင်တပ်ဆင်ခင်း စစ်ဆေးစာရင်း

### `azd provision` မပြုမီ

- [ ] ဒေသအလိုက် ကွೋಟာ အတည်ပြုပြီး
- [ ] SKU များ သင့်လျော်စွာ ရွေးချယ်ပြီး
- [ ] စရိတ် ခန့်မှန်းချက် ပြန်လည်စစ်ဆေးပြီး
- [ ] အမည်ပုံစံ လိုက်ဖက်ပြီး
- [ ] လုံခြုံရေး/RBAC ဖွဲ့စည်းပြီး

### `azd deploy` မပြုမီ

- [ ] ပတ်ဝန်းကျင် အသတ်မှတ်များ သတ်မှတ်ပြီး
- [ ] Key Vault ထဲ Secrets သိမ်းဆည်းပြီး
- [ ] ချိတ်ဆက်မှု စာကြောင်းများ အတည်ပြုပြီး
- [ ] ကျန်းမာရေးစစ်ဆေးမှုများ ဖွဲ့စည်းပြီး
