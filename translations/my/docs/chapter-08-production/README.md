# အခန်း ၈: ထုတ်လုပ်မှုနှင့် စီးပွားရေး ပုံစံများ

**📚 သင်တန်း**: [AZD အတွက် စတင်သူများ](../../README.md) | **⏱️ ကြာမြင့်ချိန်**: ၂-၃ နာရီ | **⭐ အဆင့်အတန်း**: ကျွမ်းကျင်မြင့်မားသော

## အနှစ်ချုပ်

အခန်းဤတွင် စီးပွားရေးအဆင့်သင့် ဖော်ပြလေ့လာမှု ပုံစံများ၊ လုံခြုံရေးတင်းကြပ်မှု၊ စောင့်ကြည့်မှုနှင့် ထုတ်လုပ်မှုပိုင် AI စနစ်များအတွက် ကုန်ကျစရိတ်အသင့်ဖြည့်ခြင်းတို့ပါဝင်သည်။

၎င်းမှာ ဆောက်လုပ်မှုပုံစံကို ဦးတည်သည်၊ လုံးဝအပြည့်အစုံ Deploy ပြုလုပ်နိုင်သော Template မဟုတ်ပါ။ နမူနာများသည် သင့် application တွင် ဖြည့်စွက်ရန်နှင့် စမ်းသပ်ရန် လိုအပ်သည့် ပေါင်းစပ်မှုအသေးစိတ်များကို မပါဝင်ပါ; စစ်ဆေးစာရင်းကို ဖတ်ရှုခြင်းဖြင့် ထုတ်လုပ်မှုအဆင်သင့် ဖြစ်ကြောင်း အတည်ပြုခြင်း မဖြစ်ပါ။

> **ထုတ်ပြန်သုံးသပ်မှု (2026-11-04):** AI CLI လမ်းညွှန်များကို `azd 1.37.2`၊ agent များ `1.0.0-beta.23` နှင့် သုံးသပ်ချက်များ `1.0.0-beta.2` မူကြမ်းစာရွက်/အရင်းအမြစ်များနှင့် စစ်ဆေးခဲ့သည်။ လက်ရှိအသုံးပြုမှုလိုအပ်ချက်များနှင့် ပြောင်းရွှေ့မှုအသေးစိတ်များအတွက် [ထုတ်ပြန်ချက်များနှင့် ပြင်ဆင်မှုများ](production-ai-practices.md#recent-release-changes-and-fixes) ကို ကြည့်ပါ; ဤသည်မှာ တိုက်ရိုက် deploy စစ်ဆေးခြင်း မဟုတ်ပါ။

## သင်ယူရမည့် ရည်မှန်းချက်များ

ဤအခန်းကို ပြီးမြောက်စွာ လေ့လာခြင်းဖြင့် သင်သည် -
- စျေးကွက်စွမ်းဆောင်မှုမြင့်မားသော မျိုးဆက်ပြသနာချိုး application များ deploy ပြုလုပ်နိုင်မည်
- စီးပွားရေးလုံခြုံရေးပုံစံများ အကောင်အထည်ဖော်နိုင်မည်
- စုံလင်သော စောင့်ကြည့်မှု စနစ်များ ရှိစေမည်
- တိုးပွားမှုနှုန်းအခြေခံပြီး ကုန်ကျစရိတ် လေ့လာ၍ စီမံနိုင်မည်
- AZD ဖြင့် CI/CD pipeline များ ဆက်သွယ်တပ်ဆင်နိုင်မည်

## 💰 ကုန်ကျစရိတ် အာရုံစိုက်မှု

| မူဝါဒ | အဓိက ကန့်သတ်ချက် |
|----------|---------|
| သုညသို့ ဆွဲရာသင့်ခြင်း (Container Apps) | သင့်လျော်သော trigger လိုအပ်သည်; အခြားဝန်ဆောင်မှုများမှာ ကုန်ကျစရိတ်ရှိနေဆဲ |
| ဖွံ့ဖြိုးရေးအတွက် consumption tier များ အသုံးပြုခြင်း | ရွေးချယ်ထားသော ဝန်ဆောင်မှုစျေးနှုန်းနှင့် အလုပ်မတင်မှုနှိုင်းယှဉ်ခြင်း |
| အချိန်ဇယားအလိုက် အရွယ်အစားတိုးခြင်း | ထောက်ခံထားသော အဆောက်အအုံ/အလိုအလျောက်စနစ်ဖြင့် တိုးချဲ့ခြင်း |
| မှတ်ပုံတင်/ ကြိုတင်သတ်မှတ်ထားသော စွမ်းရည် | ထောက်ခံထားသည့်အခါသာဖြစ်ပြီး; ကတိများကြောင့် နားထိုင်သော ကုန်ကျစရိတ် တိုးတက်နိုင်သည် |

မှန်ကန်သောစတင်သည့်ရက်စွဲ၊ ဘီလ်ပေးခွင့်အ ရည်အချင်း၊ လက်ခံသူများနှင့် ခွင့်ပြုချက်များဖြင့် [ပြည့်စုံသော ဘတ်ဂျက်ရင်းမြစ်ပုံစံ](production-ai-practices.md#2-cost-monitoring-and-budgets) ကို အသုံးပြုပါ။ ဘတ်ဂျက်သည် အသိပေးချက်များ ပေးပို့ပေမယ့် သုံးစွဲမှုကို ကန့်သတ်ပေးခြင်း မရှိပါ။ စုဆောင်းနိုင်မှုသည် အသုံးပြုမှုတိုင်းတာချက်ပေါ် မူတည်ပြီး သက်ဆိုင်ရာရာခိုင်နှုန်းများ အတည်ပြုမထားပါ။
