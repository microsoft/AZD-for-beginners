# အခန်း ၈: ထုတ်လုပ်မှုနှင့် စီးပွားရေး လုပ်ထုံးလုပ်နည်းများ

**📚 သင်တန်း**: [AZD စတင်လေ့လာသူများအတွက်](../../README.md) | **⏱️ ကြာမြင့်ချိန်**: ၂-၃ နာရီ | **⭐ အဆင့်အတန်း**: အဆင့်မြင့်

## အနှစ်ချုပ်

ဤအခန်းတွင် စီးပွားရေးအသုံးပြုနိုင်သော တပ်ဆင်မှု ပုံစံများ၊ လုံခြုံရေးတင်းကြပ်မှု၊ မျက်မှောက်ကြည့်ရှုခြင်းနှင့် ထုတ်လုပ်မှု AI အလုပ်ဆောင်မှုများအတွက် ကုန်ကျစရိတ် အကောင်းမြှင့်တင်မှုများကို ဖော်ပြထားသည်။

၎င်းသည် ဆောက်ပုံအမျိုးအစားကို ကိုးကားချက်အဖြစ်သာဖြစ်ပြီး၊ ပြည့်စုံစွာ တပ်ဆင်နိုင်သည့် ထုတ်လုပ်မှုနမူနာ မဟုတ်ပါ။ နမူနာများတွင် သင်၏ကိုယ်ပိုင်လျှောက်လွှာတွင် ထည့်သွင်းစမ်းသပ်ရမည့် ပေါင်းစပ်ချက် အသေးစိတ်များ မပါဝင်ပါ; စစ်တမ်းစာမျက်နှာ ဖတ်ခြင်းအားဖြင့် ထုတ်လုပ်မှု အဆင့်မြှင့်မှု အတည်ပြုခြင်း မရရှိနိုင်ပါ။

> **Foundry GA အပ်ဒိတ် (၂၀၂၆-၁၁-၀၉):** Foundry workflow အတွက် `azd >= 1.37.0` နှင့် ပြည့်စုံလုံခြုံစွာ ရရှိနိုင်သည့် `microsoft.foundry` 1.0 bundle ကို သုံးပါ; အကဲဖြတ်မှုများကို သီးသန့်တပ်ဆင်ထားသည်။ [မိတ်ဆက်ခြင်း နယ်ပယ်နှင့် ရွှေ့ပြောင်းခြင်း](production-ai-practices.md#recent-release-changes-and-fixes) နှင့် [အတည်ပြုချက်ပါ လမ်းကြောင်းနမူနာ](production-ai-practices.md#cicd-pipeline-configuration) ကို ကြည့်ပါ။ ၎င်းသည် စာရွက်အတည်ပြုပြင်ဆင်ခြင်း ဖြစ်ပြီး တိုက်ရိုက်တပ်ဆင်ခြင်း အတည်ပြုခြင်း သို့မဟုတ် ရွေးချယ်အားပေး ပြသချက်များအတွက် GA အခြေအနေ မဟုတ်ပါ။

## လေ့လာမှု ရည်မှန်းချက်များ

ဤအခန်းအား ပြီးမြောက်စွာ သင်ယူပြီးနောက် သင်မှာ:
- တိုင်းဒေသ အမျိုးမျိုးတွင် တပ်ဆင်နိုင်သော သက်တံ့ခံအစားထိုး အပလီကေးရှင်းများ တပ်ဆင်ပါမည်
- စီးပွားရေး လုံခြုံရေး ပုံစံများ ကို အကောင်အထည်ဖော်ပါမည်
- စုံလင်သော မျက်မှောက်ကြည့်ရှုမှု တပ်ဆင်ပါမည်
- သုံးစွဲမှု ကုန်ကျစရိတ်ကို အကောင်းဆုံးဖြစ်စေရန် ပြင်ဆင်နိုင်ပါမည်
- AZD ဖြင့် CI/CD လမ်းကြောင်းများ ကို တပ်ဆင်ပါမည်

## 💰 ကုန်ကျစရိတ် အကောင်းဆုံးပြုခြင်း

| မဟာဗျူဟာ | အဓိက ကန့်သတ်ချက် |
|----------|---------|
| ဝင်ငွေနံပါတ် သတ်မှတ်ထားသည့် အတိုင်း (Container Apps) | သင့်တော်သော လှုံ့ဆော်မှုလိုသည်; အခြားဝန်ဆောင်မှုများ သို့မဟုတ် ကုန်ကျစရိတ်များ ရှိနေဆဲ |
| တီထွင်မှုအတွက် စားသုံးမှုအဆင့်များ အသုံးပြုခြင်း | ရွေးချယ်ထားသော ဝန်ဆောင်မှု စျေးနှုန်းနှင့် အလုပ်လုပြောင့်နှိုင်းယှဉ်ပါ |
| မိုက်မောင်းတင်ပြီး အတိုင်းအတာချိန်ဖြတ် ပမာဏချိန်ညှိခြင်း | ထောက်ပံ့မှုရှိသော အဆောက်အအုံ/အလိုအလျောက်လုပ်ငန်းများ ဖြင့် ချိန်ညှိပါ |
| ကြိုတင်သိုလှောင်မှု/သတ်မှတ်ထားသော စွမ်းအား | ထောက်ပံ့မှုပြီးမှသာ ဖြစ်သည်; ကတိများသည် မဖြည့်ဆည်းသော ကုန်ကျစရိတ်တိုးစေနိုင်သည် |

ကျေးဇူးပြု၍ [ပြည့်စုံသော ဘတ်ဂျက် ရင်းမြစ် ပုံစံ](production-ai-practices.md#2-cost-monitoring-and-budgets) ကို တရားဝင် စတင်မှုရက်စွဲ၊ ဘီလ်အတိုင်းအတာ၊ လက်ခံသူများနှင့် ခွင့်ပြုချက်များဖြင့် အသုံးပြုပါ။ ဘတ်ဂျက်သည် သတိပေးချက်များ ပို့ပေးသော်လည်း အသုံးစရိတ်ကို ကန့်သတ်မထားပါ။ စုစည်းချထားမှုများမှာ တိုင်းတာထားသော အသုံးပြုမှု ပမာဏပေါ်မူတည်ပြီး အာမခံထားသော ရာခိုင်နှုန်း မဖြစ်ပါ။
