## အနှစ်ချုပ်

ဤအခန်းတွင် Azure Developer CLI ထည့်သွင်းမှုများအတွက် ဘောင်အခြေအနေ ဖန်တီးမှု၊ အတည်ပြု စနစ်များနှင့် လုံခြုံရေးအကောင်းဆုံးလေ့ကျင့်မှုများကို မိတ်ဆက်ပေးပါသည်။

> အမိန့်နှင့် ဖန်တီးမှု ပြန်လည်ဆန်းစစ်မှု ရည်မှတ်ချက်: `azd 1.37.2` (နိုဝင်ဘာ ၂၀၂၆)။ သုံးသပ်ချိန်တွင် Live Azure provisioning မပြုလုပ်ခဲ့ပါ။

## သင်ယူရမည့် ရည်ရွယ်ချက်များ

ဤအခန်းကို ပြီးမြောက်စွာ သင်ယူပြီးနောက် သင်သည် -
- AZD ဖန်တီးမှု အဆင့်အတန်းကို ကျွမ်းကျင်စွာ သိရှိမည်
- ပတ်ဝန်းကျင်များစွာ (ဖွံ့ဖြိုးမှု၊ စမ်းသပ်မှု၊ ထုတ်လုပ်မှု) ကို စီမံခန့်ခွဲနိုင်မည်
- စီမံခန့်ခွဲထားသည့် အတည်ပြု စနစ်ဖြင့် လုံခြုံစိတ်ချရစွာ ဆောင်ရွက်နိုင်မည်
- ပတ်ဝန်းကျင် အထူးသဖြင့် သတ်မှတ်ချက်များကို ဖန်တီးနိုင်မည်

## 🚀 မြန်ဆန်စွာ စတင်ခြင်း

သင့်ရှိပြီးသား azd အပလီကေးရှင်း၏ root မှပဲ လုပ်ဆောင်ပါ၊ သင်တန်းရဲ့ အရင်းအမြစ် မဟုတ်ပါ။ ရှိနေပြီးသားဆိုရင် မသုံးရသေးသော ပတ်ဝန်းကျင်အမည်များကို အသုံးပြုပါ။

```bash
# Create multiple environments
azd env new dev
azd env new staging
azd env new prod

# Switch environments
azd env select prod

# Set environment variables
azd env set AZURE_LOCATION eastus
azd env set SKU_NAME P1v3

# View configuration
azd env get-values
```

`SKU_NAME` သည် ဥပမာပြခြင်းဖြစ်ပြီး သင့်အကြမ်းဖျဉ်း မှာ သုံးမယ်ဆိုရင်တင်ပင် အကျိုးသက်ရောက်ပါတယ်။ ပုံမှန် `azd env set` တန်ဖိုးများသည် ဒေတာတွေကို တိတိကျကျ မဖုံးကွယ်ဘဲ ဒေသခံ ထိန်းသိမ်းထားသည်ဖြစ်ပြီး လုံခြုံမှုရှိသော မွေ့လျော်နေရာ မဟုတ်ပါ။

## 🔧 ဖန်တီးမှု အဆင့်အတန်း

သုံးမျိုးသော ဖန်တီးမှု မျက်နှာပြင်များကို ခွဲထုတ်ထားပါ - ကမ္ဘာလုံးဆိုင်ရာ ဦးစားပေးချက်များ (`azd config`), ပရောဂျက်ဖွဲ့စည်းမှု (`azure.yaml`), နှင့် ပတ်ဝန်းကျင်နှင့်သက်ဆိုင်သော တန်ဖိုးများ (`azd env`)။ အချက်အလက်များကို ထောက်ပံ့သော သက်ဆိုင်ရာ Flags များမှသာ override ကျင်းပနိုင်ပြီး အမျိုးမျိုးသော ပတ်ဝန်းကျင်ပြောင်းလဲမှုများကို `azure.yaml` သို့မဟုတ် Bicep ပေါ် အလိုမပေါ်စေပါ။

## 🔐 လုံခြုံရေး အကောင်းဆုံးလေ့ကျင့်မှုများ

```bash
# Runtime managed identity must be enabled in infrastructure and granted RBAC.
# To authenticate azd itself on an Azure host with an assigned identity:
# azd auth login --managed-identity

# Check AZD authentication status
azd auth login --check-status

# Optional: verify Azure CLI context if you plan to run az commands
az account show

# Re-authenticate if needed
azd auth login

# Optional: refresh Azure CLI authentication for az commands
az login
```
