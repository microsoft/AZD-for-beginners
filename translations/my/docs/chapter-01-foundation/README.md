## အနှစ်ချုပ်

ဤအခန်းတွင် Azure Developer CLI (azd) အခြေခံအကြောင်းများကို အသိပညာရရှိမည်။ သင် Core အကြောင်းအရာများကို လေ့လာကာ ကိရိယာများကို ထည့်သွင်းပြီး၊ ပထမဆုံး application ကို Azure တွင် တင်ပေးမည်။

> အမိန့်နှင့် ဖွဲ့စည်းမှုစစ်တမ်း ရည်ရွယ်ချက်: `azd 1.37.2` (နိုဝင်ဘာ ၂၀၂၆)။ စစ်တမ်းအတွင်း Live Azure provisioning မပြုလုပ်ခဲ့ပါ။

## သင်ယူရမည့် ရည်မှန်းချက်များ

ဤအခန်း၌ ပြီးမြောက်သည်နှင့် သင်သည်-
- Azure Developer CLI ဆိုသည်မှာဘာကို နားလည်ပြီး Azure CLI နှင့် ဘယ်လိုကွဲပြားသည်ကို သိရှိတတ်မည်
- ပြင်ပပလက်ဖောင်းပေါ်တွင် AZD ကို ထည့်သွင်းပြီး ဖွဲ့စည်းနိုင်မည်
- ပထမဆုံး application ကို Azure တွင် `azd up` ဖြင့် တင်နိုင်မည်
- `azd down` ဖြင့် အရင်းအမြစ်များကို သန့်ရှင်းဖျက်စီးနိုင်မည်

## ✅ ဒီနေရာကနေ စတင်ပါ: သင့်စနစ်ကို အတည်ပြုပါ

စတင်ရန် မတိုင်မီ၊ သင့်လက်ရှိစက်သည် အခန်း ၁ template အတွက် ပြင်ဆင်ပြီးကြောင်း အတည်ပြုပါ-

**Windows:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

စာမေးလွှာသည် ကိရိယာများ မရှိပါကြောင်း ပြောပါက၊ ပထမဦးစွာ ထိုအရာများကို ပြုပြင်ပြီးနောက် အခန်းကို ဆက်လက် လေ့လာပါ။

## 🚀 လျင်မြန်စတင်ခြင်း

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ အောင်မြင်မှု အခြေအနေများ

ဤအခန်းကို ပြီးမြောက်စဉ်၊ သင်အောက်ဖော်ပြပါကို ပြုလုပ်နိုင်သင့်သည်-

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
