# အခန်း 2: AI-ပထမဦးဆုံး ဖွံ့ဖြိုးတိုးတက်မှု

**📚 သင်တန်း**: [AZD အခြေခံ](../../README.md) | **⏱️ ကြာချိန်**: အလုပ်ရုံပါသော 4-5 နာရီ | **⭐ ခက်ခဲမှု**: အလယ်အလတ်

## အကျဥ်းချုပ်

ဤအခန်းတွင် Azure Developer CLI နှင့် Microsoft Foundry ဝန်ဆောင်မှုများကို အသုံးပြုပြီး AI အားဖြင့်ထောက်ပံ့သည့် အက်ပ်များ စီမံဖြန့်ဖြူးခြင်းကို အာရုံစိုက်ထားသည်။ ရိုးရှင်းသော AI စကားပြောအက်ပ်များမှ စတင်၍ ကိရိယာများပါဝင်သည့် ဉာဏ်ရှိအေးဂျင့်များအထိ။

> **ထုတ်ပြန်ချက်သုံးသပ်ချက် (၂၀၂၆-၁၁-၀၄):** AI CLI လမ်းညွှန်ချက်များကို ထုတ်ပြန်ထားသော `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23`, နှင့် `azure.ai.evaluations` `1.0.0-beta.2` မှတ်တမ်း/ရင်းမြစ်နှင့် နှိုင်းယှဉ်စစ်ဆေးခဲ့သည်။ ပေါင်းစပ်လုပ်ငန်းစဉ်အတွက် `azd >= 1.37.0` ကို အသုံးပြုပါ။ ခွဲခြားသုံးသပ်မှုများတွင် သီးသန့် `azd ai eval` နေရာအမည်ကို အသုံးပြုသည်။ [ထုတ်ပြန်ချက်ပြောင်းလဲမှုများနှင့် ပြောင်းရွှေ့မှု လမ်းညွှန်](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes) ကို ကြည့်ပါ။ ၎င်းသည် တိုက်ရိုက်ထုတ်လုပ်မှုအတည်ပြုခြင်း မဟုတ်ပါ။

## သင်ယူရမည့် ရည်ရွယ်ချက်များ

ဤအခန်းကို ပြီးစီးပြီးနောက်၊ သင်သည် -
- ကြိုတင်ပြုစုပြီးသော AZD ပုံစံများဖြင့် AI အက်ပ်များကို ဖြန့်ချိနိုင်ပါမည်
- AZD နှင့် Microsoft Foundry ပေါင်းစည်းမှုကို နားလည်နိုင်ပါမည်
- ကိရိယာများပါဝင်သည့် AI အေးဂျင့်များကို ဖွဲ့စည်းပြင်ဆင်နိုင်ပါမည်
- RAG (Retrieval-Augmented Generation) အက်ပ်များကို ဖြန့်ချိနိုင်ပါမည်

## 🚀 အလျင်အမြန် စတင်ခြင်း

အသစ်တစ်ခုသော အလွတ် directory တစ်ခုတွင် ရွေးချယ်ပါ။ အဆုံးတွင် `.` သည် လက်ရှိ directory ကို စတင်သတ်မှတ်သည်။ မဟုတ်လျှင် AZD သည် shell ၏ အလုပ်လုပ် directory ကို မပြောင်းဘဲ subdirectory တစ်ခု ဖန်တီးနိုင်ပါသည်။

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 ကုန်ကျစရိတ် အသိပညာ

ဤအကျဉ်းချုပ်သည် ကိုးကားချက်များ သို့မဟုတ် အကန့်အသတ် မဟုတ်ပါ; မော်ဒယ် traffic၊ Search/ကွန်ပျူတာ SKUs၊ ဒေသ၊ နှင့် ရွေးချယ်နိုင်သော လက္ခဏာများသည် ထိုအကွာအဝေးကျော်နိုင်သည်။ သင့်ရွေးချယ်ထားသောနမူနာ၏ လက်ရှိစျေးနှုန်းလမ်းညွှန်ကို ပြန်လည်စစ်ဆေးပြီးမှ ဖွဲ့စည်းပါ။

| ပတ်ဝန်းကျင် | ခန့်မှန်း လစဉ်ကုန်ကျစရိတ် |
|-------------|----------------------|
| ဖွံ့ဖြိုးတိုးတက်မှု | $80-150 |
| စမ်းသပ်မှု | $150-300 |
| ထုတ်လုပ်မှု | $300-3,500+ |

**အကြံပြုချက်:** စမ်းသပ်ပြီးနောက် `azd down` ကို လည်ပတ်ပါက ကုန်ကျစရိတ် ရှောင်ရှားနိုင်သည်။
