# အထောက်အပံ့

## သင်တန်းဆိုင်ရာပြဿနာများနှင့်မေးခွန်းများ

ပြဿနာတင်ပြမည်မဟုတ်မည့်အရင် [course issues](https://github.com/microsoft/AZD-for-beginners/issues) ကိုရှာဖွေပါ။ ထိခိုက်သော အင်္ဂလိပ်ဘာသာမျှ အတန်း၊ သင်အမိန့်ကို မည်သည့်ဟန်ချက်ဖြင့် တည်ဆောက်ခဲ့သည်၊ သင်၏ AZD/extension ဗားရှင်းများနှင့် အမှားမက်ဆေ့ချ်ကို ဖြည့်စွက်ပါ။ မှတ်တမ်းများနှင့် ဓာတ်ပုံများမှ အသုံးပြုသူအမည်၊ token များ၊ subscription အသေးစိတ်များနှင့် ကိုယ်ရေးတတ်တတ်အချက်များကို ဖယ်ရှားပေးပါ။

သင်ယူခြင်းဆိုင်ရာမေးခွန်းများအတွက် [Azure developer community](https://discord.gg/microsoft-azure) ကို အသုံးပြုပါ။ လူထုထံမှ တုံ့ပြန်ချက်များသည် အာမခံထားသော အထောက်အပံ့ဝန်ဆောင်မှုမဟုတ်ပါ။

## ကိရိယာနှင့် ဝန်ဆောင်မှုပြဿနာများ

ထပ်မံထုတ်ပြန်နိုင်သော AZD CLI အမှားများကို [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) တွင် တင်ပြပါ။ Azure ဝန်ဆောင်မှုဖြစ်ရပ်များ သို့မဟုတ် subscription အထူးအကူအညီများအတွက် [Azure portal](https://portal.azure.com/) တွင် ရရှိနိုင်သည့် အထောက်အပံ့ရွေးချယ်စရာများကို အသုံးပြုပါ။

## လုံခြုံရေးအစီရင်ခံစာများ

ကိုယ်ပိုင်ထိခိုက်မှုအစီရင်ခံတင်ပြရန်အတွက် [SECURITY.md](SECURITY.md) ကို လိုက်နာပါ။ လျှို့ဝှက်ချက်များ သို့မဟုတ် ချော်ကားမှု အသေးစိတ်များကို လူထုသင်တန်းပြဿနာတင်ပြရာတွင် မထည့်သွင်းပါနှင့်။

## Microsoft အထောက်အပံ့မူဝါဒ

ဤပညာရေး စီမံကိန်းအတွက် အထောက်အပံ့သည် အထက်ဖော်ပြပါ အရင်းအမြစ်များဖြင့်သာ ကန့်သတ်ထားပါသည်။ သင်တန်းဥပမာများတွင် ထုတ်လုပ်မှုအထောက်အပံ့တာဝန်မပါဝင်ပါ။
