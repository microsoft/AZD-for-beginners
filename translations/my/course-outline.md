# AZD အခြေခံများအတွက် သင်တန်းအစီအစဉ် နှင့် သင်ယူမှု ဖွဲ့စည်းမှု

## သင်တန်းအမြင်

Azure Developer CLI (azd) ကို တိုးတက်စေရန် အသုံးပြုနိုင်ရန် အခန်းစဉ်များဖြင့် စနစ်တကျ သင်ယူပါ။ **Microsoft Foundry အင်တင်ဂရိတ်ဖြင့် AI အက်ပလီကေးရှင်းများ ထည့်တင်ခြင်းအပေါ် အထူးအာရုံစိုက်ထားပါသည်။**

### အခုသင်တန်းသည် ခေတ်မီ Developer များအတွက် အရေးကြီးသော ပြုလုပ်ရမည့်အကြောင်း

AI လုပ်ငန်းခွင်များ ထည့်သွင်း အသုံးပြုရာတွင် Developer များ မကြာခဏ လမ်းညွှန်ချက်လိုအပ်ကြသည်-
- စိနိုင်ခက်ခဲသည့် များစွာသော AI ဝန်ဆောင်မှုများဆက်သွယ်မှု
- ထုတ်လုပ်မှု AI ထည့်သွင်းခြင်းအတွက် အကောင်းဆုံးလေ့လာမှုများ  
- Azure AI ဝန်ဆောင်မှုများ ပေါင်းစပ်ခြင်းနှင့် ပြင်ဆင်ခြင်း
- AI လုပ်ငန်းများအတွက် ကုန်ကျစရိတ် တိုးတက်အောင် ချမှတ်ခြင်း
- AI အထူး ထည့်သွင်းသုံးစွဲမှု ပြဿနာဖြေရှင်းခြင်း

### အဓိကသင်ယူရမည့် ရည်မှန်းချက်များ

ဒီစနစ်တကျ သင်တန်းကို ပြီးစီးမှုဖြင့်-
- **AZD အခြေခံများကို ကျွမ်းကျင်ရန်**: အဓိကအယူအဆများ၊ တပ်ဆင်ခြင်းနှင့် ပြင်ဆင်ခြင်း
- **AI အက်ပလီကေးရှင်းများ ထည့်သွင်းရန်**: AZD နှင့် Microsoft Foundry ဝန်ဆောင်မှုများ အသုံးပြုခြင်း
- **Code အဖြစ် အခြေခံအဆောက်အအုံ ဖန်တီးရန်**: Bicep template များဖြင့် Azure အရင်းအမြစ်များကို စီမံခန့်ခွဲခြင်း
- **ထည့်သွင်းမှု ပြဿနာများ စစ်ဆေးရန်**: ပုံမှန် ဖြစ်ပေါ်နိုင်သော ပြဿနာများ ဖြေရှင်းခြင်းနှင့် ပြသနာရှာဖွေရေး
- **ထုတ်လုပ်မှုအတွက် အဆင်သင့်ပြင်ဆင်ခြင်း**: လုံခြုံရေး၊ ဆွဲဆောင်မှုမီတာ၊ ကြည့်ရှုမှုနှင့် ကုန်ကျစရိတ် စီမံခန့်ခွဲခြင်း
- **စွမ်းဆောင်ရည်မြင့် Multi-Agent ဖြေရှင်းချက်များ တည်ဆောက်ခြင်း**: စိန်ခေါ်မှုများများ ပြည့်စုံသော AI معماريများ ထည့်သွင်းခြင်း

ဒီသင်တန်းကို **ကိုယ်တိုင်သင်ယူခြင်း** နှင့် **လမ်းညွှန်ဆရာနှင့်အတူ စာသင်ကြားမှု** တို့အတွက် ဒီဇိုင်းရေးဆွဲထားပြီး AZD ကို လက်တွေ့ထိတွေ့မြင်ကြသူများအတွက် လေ့ကျင့်ခန်းများဖြင့် ကျွမ်းကျင်နိုင်စေရန် လုပ်ဆောင်ပေးပါသည်။

#### 🚀 ကိုယ်တိုင် သင်ယူသည့်နည်းလမ်း
**အပုဂ္ဂိုလ် Developer များနှင့် ဆက်တိုက်ဉီးဆောင်မှုအတွက် သင်ခန်းစာများ**

- **ဘရောက်ဇာအခြေပြု မျက်နှာပြင်**: MkDocs စနစ်ဖြင့် စီမံထားသော ဝဘ်ဘရောက်ဇာမှ ဝင်ရောက် သင်ကြားနိုင်ခြင်း
- **GitHub Codespaces ပေါင်းစပ်မှု**: တစ်လှည့်နှိပ်မြှောက်၍ ကိရိယာများ ကြိုတင်သတ်မှတ်ထားသော ဖွဲ့စည်းမှု
- **DevContainer မှ လက်တွေ့ကွန်ပျူတာသုံးမှု စနစ်**: ဒေသတွင်း ဆက်ထောက်မှု မလိုအပ်ပဲ ချက်ချင်းရေးသား စတင်နိုင်ခြင်း
- **ဖြတ်ထားချက်များ လမ်းညွှန်မှု**: စကတ်မှတ်တင်ပေးထားသော စစ်ဆေးချက်များနှင့် အတည်ပြုလေ့ကျင့်ခန်းများ
- **အသိုင်းအဝိုင်း ထောက်ပံ့မှု**: Azure Discord စာရင်းများသို့ ဝင်ရောက်မေးမြန်းနှင့် ပူးပေါင်းဆောင်ရွက်နိုင်ခြင်း

**သင်ယူမှုဖွဲ့စည်းမှု:**
- **အချိန်အင်ရွက်မှု**: ကိုယ်တိုင်စဉ်ဆက်မပြတ်မေးမြန်းသင်ယူနိုင်ခြင်း၊ ရက်များ သို့မဟုတ် အပတ်များအတိုင်း
- **ဖြတ်တောက်စနစ်**: စိန်ခေါ်မှု တတ်နိုင်မှု မရှိခင် စစ်ဆေးထားသည်
- **အရင်းအမြစ်စာကြည့်တိုက်**: လက်တွေ့အစီအရင်ခံစာများ၊ ဥပမာများနှင့် ပြဿနာဖြေရှင်းညွှန်ကြားချက်များ

#### 🏛️ လမ်းညွှန်ထားသော စာသင်ကြားမှု
**ကုမ္ပဏီသင်တန်း၊ Bootcamp နှင့် ပညာရေးအဖွဲ့အစည်းများအတွက် သင့်တော်သည်**

**သင်တန်းပုံစံ ရွေးချယ်မှုများ:**

**📚 ပညာရေးနည်းပညာ သင်တန်းပေါင်းစပ်မှု (၈-၁၂ ပတ်)**
- **တက္ကသိုလ် သင်တန်းများ**: တစ်သင်တန်းသတ်မှတ်ထားပြီး တစ်ပတ်လျှင် ၂ နာရီကာလသင်ကြားမှု
- **Bootcamp ပုံစံ**: သုံးရက်မှငါးရက် အားကောင်းသော ဒီဇိုင်းထားသော သင်တန်း၊ ၆-၈ နာရီသင်ကြားမှု တစ်ရက်စီ
- **ကုမ္ပဏီ သင်တန်း**: တစ်လတစ်ကြိမ်အဖွဲ့သင်တန်းနှင့် ကိုက်ညီပြီး ပရောဂျက်ဆောင်ရွက်မှု
- **သုံးသပ်ခြင်း စနစ်**: အဆင့်သတ်မှတ်ချက်များ၊ ရင်းနှီးမြှုပ်နှံသူများ ပြန်လည်သုံးသပ်ခြင်းနှင့် နောက်ဆုံးပရောဂျက်များ

**🚀 အားကောင်းသော သင်တန်း (၁-၃ ရက်)**
- **ရက် ၁**: အခြေခံ + AI ဖွံ့ဖြိုးတိုးတက်မှု (အခန်း ၁-၂) - ၆ နာရီ
- **ရက် ၂**: ပြင်ဆင်မှု + အခြေခံအဆောက်အအုံ (အခန်း ၃-၄) - ၆ နာရီ  
- **ရက် ၃**: မြင့်မားသောပုံစံများ + ထုတ်လုပ်မှု (အခန်း ၅-၈) - ၈ နာရီ
- **နောက်တောင့်**: ပရောဂျက် ပြီးဆုံးရန် ၂ ပတ် အနားယူ မန်တော်းမှု မလMandatory

**⚡ အမှုဆောင် အကျဉ်းချုပ် (၄-၆ နာရီ)**
- **နည်းဗျူဟာ အမြင်**: AZD တန်ဖိုးပေးမှုနှင့် စီးပွားရေး အကျိုးသက်ရောက်မှု (၁ နာရီ)
- **လက်တွေ့ ပြသမှု**: AI အက်ပလီကေးရှင်း တစ်ခုလုံး ထည့်သွင်းပြသခြင်း (၂ နာရီ)
- **ဗျူဟာအကောင်အထည်ဖော်မှု အသုံးပြုခြင်း**: စက်မှုဇုန် ပုံစံများနှင့် အုပ်ချုပ်မှု (၁ နာရီ)
- **အကောင်အထည်ဖော်ခြင်း အစီအစဉ်**: အဖွဲ့အစည်းအတွက် စီမံကိန်းတင်ပြခြင်း (၁-၂ နာရီ)

#### 🛠️ သင်တန်း သင်ယူမှု နည်းပညာကြားမှု
**ရှာဖွေမှု → ထည့်သွင်းမှု → စိတ်ကြိုက်ပြင်ဆင်မှု လမ်းညွှန်မှုဖြင့် လက်တွေ့ကျွမ်းကျင်မှု ဖွံ့ဖြိုးခြင်း**

**အဆင့် ၁: ရှာဖွေမှု (၄၅ မိနစ်)**
- **Template သုံးသပ်ခြင်း**: Microsoft Foundry template များနှင့် ဝန်ဆောင်မှုများ သုံးသပ်ခြင်း
- **ဗျူဟာ စစ်ဆေးခြင်း**: Multi-agent ပုံစံများနှင့် ထည့်သွင်းမှု မျှော်မှန်းချက်များ နားလည်ခြင်း
- **လိုအပ်ချက် ဝေဖန်ခြင်း**: အဖွဲ့အစည်းလိုအပ်ချက်များ နှင့် ကန့်သတ်ချက်များ ဖော်ထုတ်ခြင်း
- **ပတ်ဝန်းကျင် ပြင်ဆင်ခြင်း**: ဖွံ့ဖြိုးရေးပတ်ဝန်းကျင်နှင့် Azure အရင်းအမြစ်များ ပြင်ဆင်ခြင်း

**အဆင့် ၂: ထည့်သွင်းမှု (၂ နာရီ)**
- **လမ်းညွှန်ထားသော အကောင်အထည်ဖော်မှု**: AZD ဖြင့် AI အက်ပလီကေးရှင်းများ တစ်ဆင့်ချင်း ပြုလုပ်ခြင်း
- **ဝန်ဆောင်မှု ပြင်ဆင်ခြင်း**: Azure AI ဝန်ဆောင်မှုများ၊ အပြီးမှတ်များနှင့် ဝင်ခွင့်စနစ် တပ်ဆင်ခြင်း
- **လုံခြုံရေး အကောင်အထည်ဖော်မှု**: စက်မှုဇုန် လုံခြုံရေး ပုံစံများနှင့် ဝင်ခွင့်ထိန်းချုပ်မှုတပ်ဆင်ခြင်း
- **အတည်ပြုစစ်ထုတ်မှု**: ထည့်သွင်းမှုများ စစ်ဆေးပြီး ပုံမှန် ပြဿနာများပြုပြင်ခြင်း

**အဆင့် ၃: စိတ်ကြိုက်ပြင်ဆင်မှု (၄၅ မိနစ်)**
- **အက်ပလီကေးရှင်း ပြုပြင်ခြင်း**: စိတ်ကြိုက် အသုံးပြုမှုများနှင့်လိုအပ်ချက်များအတွက် template များ ပြင်ဆင်ခြင်း
- **ထုတ်လုပ်မှု အကောင်းဆုံးပြုလုပ်မှု**: ကြည့်ကြည့်မှု၊ ကုန်ကျစရိတ် စီမံချက်များနှင့် အဆုတ်ပေါ်တင်မှု များ ဆောင်ရွက်ခြင်း
- **မြင့်မားသော စနစ်များ**: multi-agent ပူးပေါင်းဆောင်ရွက်မှုနှင့် အဆင့်မြင့်ပုံစံများ သွားကြည့်ခြင်း
- **နောက်တင် အစီအစဉ်ရေးဆွဲခြင်း**: စွမ်းရည်ဆက်လက် တိုးတက်ရန် လမ်းကြောင်း သတ်မှတ်ခြင်း

- **ထုတ်လုပ်မှုပတ် AI အက်ပလီကေးရှင်းများ ထည့်သွင်းခြင်း**: AI အားထောက်ပံ့သော ဖြေရှင်းချက်များ ထည့်သွင်းပြီး ပြင်ဆင်နိုင်ခြင်း
- **Infrastructure as Code ကျွမ်းကျင်မှု**: စိတ်ကြိုက် Bicep template များ ဖန်တီးပြီး စီမံနိုင်ခြင်း
- **Multi-Agent Architecture**: ပူးပေါင်းဆောင်ရွက်သော AI agent ဖြေရှင်းချက် အကောင်အထည်ဖော်နိုင်ခြင်း
- **ထုတ်လုပ်မှု အသင့်ပြင်ခြင်း**: လုံခြုံရေး၊ ကြည့်မယ်၊ နှင့် အုပ်ချုပ်မှု ပုံစံအသုံးပြုခြင်း
- **ပြဿနာဖြေရှင်းမှု ကျွမ်းကျင်မှု**: ထည့်သွင်းခြင်းနှင့် ပြင်ဆင်ခြင်း ပြဿနာများကို ကိုယ်တိုင် ဖြေရှင်းနိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ:**
- **ပရောဂျက် ဦးဆောင်မှု**: Cloud ထည့်သွင်းမှုအတွက် နည်းပညာအဖွဲ့များဦးဆောင်ခြင်း
- **ဗျူဟာ ဒီဇိုင်း**: ရှယ်ယာကောင်းပြီး ကုန်ကျစရိတ် သက်သာသော Azure ဖြေရှင်းချက်များ ဒီဇိုင်းရေးဆွဲခြင်း
- **အသိပညာ လွှဲပြောင်းခြင်း**: AZD အကောင်းဆုံး လေ့ကျင့်မှုများကို မိတ်ဖက်များ သင်ကြားပေးခြင်းနှင့် နည်းပြဖြစ်ခြင်း
- **နည်းဗျူဟာ စီမံကိန်းရေးဆွဲခြင်း**: အဖွဲ့အစည်း Cloud စနစ် လက်ခံမှု နည်းဗျူဟာများ ထိန်းသိမ်းလိုက်နာနိုင်ခြင်း

- **ဗျူဟာ စစ်ဆေးခြင်း**: အကြီးအကဲ အင်ဂျင်နီယာများနှင့် ကြီးမားသော အဖွဲ့အတွက် လစဉ်အစည်းအဝေး (၄ နာရီ)

- **ပေးစာဆောင်ရွက်မှု စီမံအုပ်ချုပ်မှု**: အောင်မြင်မှု စနစ်နှင့် ပြန်လည်တုံ့ပြန်မှုစနစ်ဖြင့် စနစ်တကျ ထုတ်လွှင့်ခြင်း  
- **ဆက်လက် မန်တော်းမှု**: Workshop ပြီးဆုံးပြီးနောက် ပရောဂျက် အကောင်အထည်ဖော်မှုအထောက်အပံ့
- **အသိုင်းအဝိုင်း ဖွဲ့စည်းမှု**: အတွင်းပိုင်း Azure AI Developer အသိုင်းအဝိုင်းများနှင့် သတင်းအချက်အလက် မျှဝေခြင်း

**အောင်မြင်မှု တိုင်းတာမှုများ:**
- **ကျွမ်းကျင်မှု ရရှိမှု**: နောက်ပို့ခွဲ နှင့် ယခင်စာမေးပွဲများဖြင့် နည်းပညာတိုးတက်မှု တိုင်းတာခြင်း
- **ထည့်သွင်းမှု အောင်မြင်မှု**: ထုတ်လုပ်လုပ်ငန်း AI အက်ပလီကေးရှင်းများ ထည့်သွင်းနိုင်မှု ရာခိုင်နှုန်း
- **စွမ်းအား တိုးတက်မှု အချိန်**: Azure AI ပရောဂျက် အသစ်များ အတွက် စတင်အသုံးပြုချိန် လျော့နည်းခြင်း

7. **ပြီးမြောက်ခြင်း** (၁၅ မိနစ်): နောက်တစ်ဆင့် ထပ်မံလေ့လာသင်ယူရန် လမ်းကြောင်းသတ်မှတ်ခြင်း

၅. **အခန်း ၇**: ပြဿနာဖြေရှင်းခြင်းနှင့် ဒင်ဘာဂျင်းလုပ်ခြင်း (၁.၅ နာရီ)
၆. **အခန်း ၈**: ထုတ်လုပ်မှုနှင့် စီးပွားရေး ပုံစံများ (၂ နာရီ)

#### 🎓 သင်ယူမှု အပြည့်အဝ လမ်းကြောင်း (၈-၁၂ နာရီ)
အခန်း ၈ အားလုံးကို လိုက်လံပြီး လက်တွေ့လေ့ကျင့်မှုနှင့် အတည်ပြုမှုများဖြင့် ပြီးမြောက်စေသည်

- ✅ အလိုအလျောက် pre-deployment အတည်ပြုခြင်း အကောင်အထည်ဖော်နိုင်ခြင်း

#### အခန်း ၇-၈ ပြီးမြောက်မှု (ပြဿနာဖြေရှင်းခြင်း + ထုတ်လုပ်မှု)

- ✅ စီးပွားရေးအဆင့် လုံခြုံရေး နှင့် စောင့်ကြည့်မှု အကောင်အထည်ဖော်နိုင်ခြင်း
- ✅ အုပ်ချုပ်မှု နဲ့ သင့်တော်သော ထုတ်လုပ်မှုပညာရှိမှုရှိသော application များ တပ်ဆင်နိုင်ခြင်း

### အခြေခံအဆင့် (အခန်း ၁-၂)

- Microsoft Foundry ဝန်ဆောင်မှုများကို AZD deployments နှင့် ပေါင်းစပ်နိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ:**
- အကွာအဝေးသတ်မှတ်ထားသော deployment workflow များအားလိုက်နာခြင်း

### အလယ်အလတ်အဆင့် (အခန်း ၃-၄)
အလယ်အလတ်အပ်ဒိတ်ထားသော အခန်းများ ပြီးမြောက်ပြီးနောက် သင်ယူသူအဖွဲ့ပြသနိုင်မည်မှာ-

**နည်းပညာဆိုင်ရာ အရည်အချင်းများ:**
- ပတ်ဝန်းကျင် မျိုးစုံ (dev၊ staging၊ production) deployment များကို စီမံခန့်ခွဲနိုင်ခြင်း
- infrastructure as code အတွက် စိတ်ကြိုက် Bicep template များ ဖန်တီးနိုင်ခြင်း
- managed identity ဖြင့် လုံခြုံမှု ရှိသော အတည်ပြုမှု များ ညွှန်ပြနိုင်ခြင်း
- စိတ်ကြိုက် ဖွဲ့စည်းထားသော 多服务 အပလီကေးရှင်း များ deployment တိုက်တွန်းနိုင်ခြင်း
- ကုန်ကျစရိတ်နှင့် စွမ်းဆောင်ရည်မြှင့်တင်ရေးအတွက် resource provisioning များကို ပိုမိုကောင်းမွန်စွာ စီမံနိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ:**
- ပမာဏအတိုးအလျားရှိသော infrastructure ပုံစံများကို ဒီဇိုင်းဆွဲနိုင်ခြင်း
- cloud deployment များအတွက် လုံခြုံရေး အကောင်းဆုံးနည်းလမ်းများ ထည့်သွင်းနိုင်ခြင်း
- အဖွဲ့နှင့် ပူးပေါင်း ဆောင်ရွက်ရန် infrastructure ပုံစံများကို စာရွက်စာတမ်းချုပ်ရေးနိုင်ခြင်း
- လိုအပ်ချက်များအတွက် သင့်တော်သော Azure ဝန်ဆောင်မှုများကို ရွေးချယ်နိုင်ခြင်း

**သင်ယူမှု အတည်ပြုခြင်း:**
- ✅ ပတ်ဝန်းကျင်အသီးသီးနှင့် settings များကို သတ်မှတ်ထားသော ပတ်ဝန်းကျင်များ ဖန်တီးနိုင်ခြင်း
- ✅ စိတ်ကြိုက် Bicep template ဖြင့် 多服务 app deployment တတ်နိုင်ခြင်း
- ✅ managed identity authentication ဖြင့် လုံခြုံမှု စီမံနိုင်ခြင်း
- ✅ အမှန်တကယ်ဖြစ်သော မျိုးစုံ သရုပ်ပြမှုများဖြင့် configuration management အပြည့်အဝ ပြုလုပ်နိုင်ခြင်း

### အဆင့်မြင့် အဆင့် (အခန်း ၅-၆)
အဆင့်မြင့်အခန်းများ ပြီးမြောက်ပြီးနောက် သင်ယူသူများပြသနိုင်မည်မှာ-

**နည်းပညာဆိုင်ရာ အရည်အချင်းများ:**
- မျိုးစုံ agent AI ဖြေရှင်းနည်းများကို တပြိုင်နက် workflow ဖြင့် တပ်ဆင်နိုင်ခြင်းနှင့် စီမံခန့်ခွဲခြင်း
- စားသုံးသူနှင့် ကုန်ပစ္စည်းအေဂျင့် အဆောက်အအုံများကို စတိုင်လုပ်နေရာဆိုင်ရာအတွက် တည်ဆောက်နိုင်ခြင်း
- စွမ်းရည် အစီအစဉ်ကောင်း၊ ရင်းမြစ် အတည်ပြုခြင်း ပြုလုပ်နိုင်ခြင်း
- အလိုအလျောက် pre-deployment အတည်ပြုခြင်း၊ အထောက်အကူပြု optimization များ ပြုလုပ်နိုင်ခြင်း
- လုပ်ငန်းလိုအပ်ချက်အရ ကုန်ကျစရိတ်လုပ်ဆောင်နိုင်သော SKU ရွေးချယ်နိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ:**
- ထုတ်လုပ်မှု ပတ်ဝန်းကျင်များအတွက် ရှုပ်ထွေးသော AI ဖြေရှင်းနည်းများ ဒီဇိုင်းဆွဲနိုင်ခြင်း
- AI deployment မဟာဗျူဟာများအပေါ် နည်းပညာဆိုင်ရာ ဆွေးနွေးမှုများ ဦးဆောင်နိုင်ခြင်း
- AZD နှင့် AI deployment အကောင်းဆုံးနည်းလမ်းများအပေါ် သဲျဖူးပါးသူ developer များကို မိတ်ဆက်ပေးနိုင်ခြင်း
- စီးပွားရေး လိုအပ်ချက်များအတွက် AI ပုံစံဆိုင်ရာပုံစံများ အကဲဖြတ် ညွှန်ပြနိုင်ခြင်း

**သင်ယူမှု အတည်ပြုခြင်း:**
- ✅ စားသုံးသူ မျိုးစုံ agent အခြေခံ မြေပုံအား ပြန်လည်သုံးသပ်ကာ မရှိသည့် အပလီကေးရှင်း ကို တိကျစွာ ခွဲခြားနိုင်ခြင်း
- ✅ agent များအကြား စည်းမျဉ်းညှိနှိုင်းခြင်းနှင့် workflow ချရေးလမ်းညွှန်ခြင်း ပြသနိုင်ခြင်း
- ✅ အမှန်တကယ်ရင်းမြစ် ကန့်သတ်ချက်များဖြင့် စွမ်းရည်အစီအစဉ် လေ့ကျင့်ချက်များ ပြီးမြောက်စေခြင်း
- ✅ အလိုအလျောက် pre-flight စစ်ဆေးမှုများဖြင့် deployment အသင့်ရှိမှု အတည်ပြုနိုင်ခြင်း

### ကျွမ်းကျင်သူအဆင့် (အခန်း ၇-၈)
ကျွမ်းကျင်သူအခန်းများ ပြီးမြောက်ပြီးနောက် သင်ယူသူသည် ပြသနိုင်မည်မှာ-

**နည်းပညာဆိုင်ရာ အရည်အချင်းများ:**
- ရှုပ်ထွေးသော Deployment ပြဿနာများကို ကိုယ်တိုင် ရှာဖွေ ဖြေရှင်းနိုင်ခြင်း
- စီးပွားရေးအဆင့် လုံခြုံရေး ပုံစံများနှင့် အုပ်ချုပ်မှု စနစ်များ ထည့်သွင်း အကောင်အထည်ဖော်နိုင်ခြင်း
- စောင့်ကြည့်မှု နှင့် အလားအလာ ပြုလုပ်ခြင်း မဟာဗျူဟာများ ဒီဇိုင်းဆွဲနိုင်ခြင်း
- မျက်နှာချင်းဆိုင်ထုတ်လုပ်မှု deployment များကို ပမာဏ၊ ကုန်ကျစရိတ်နှင့် စွမ်းဆောင်ရည်အရ အကောင်းဆုံး လုပ်ဆောင်နိုင်ခြင်း
- သက်ဆိုင်ရာ စမ်းသပ်မှုနှင့် အတည်ပြုမှုများပါသော CI/CD လမ်းကြောင်းများ တည်ဆောက်နိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ:**
- စီးပွားရေး cloud ပြောင်းလဲမှု လုပ်ငန်းစဉ်များ ဦးဆောင်နိုင်ခြင်း
- အဖွဲ့အစည်း အတိုင်းအတာ deployment စံချိန်စနစ်များ ဒီဇိုင်းနှင့် တပ်ဆင်နိုင်ခြင်း
- အဆင့်မြင့် AZD နည်းလမ်းများအပေါ် အဖွဲ့ဖွံ့ဖြိုးရေး လုပ်ငန်းများ သင်ကြားနိုင်ခြင်း
- စီးပွားရေး AI deployment နယ်ပယ်အတွက် နည်းပညာ ဆုံးဖြတ်ချက်များ အကျိုးသက်ရောက်မှု ရှိစေရန် အာရုံစိုက်နိုင်ခြင်း

**သင်ယူမှု အတည်ပြုခြင်း:**
- ✅ ရှုပ်ထွေးသော မျိုးစုံ ဝန်ဆောင်မှု deployment ပျက်ကွက်မှုများ ဖြေရှင်းနိုင်ခြင်း
- ✅ စည်းကမ်းတက်ရောက်လိုက်နာရမည့် စီးပွားရေး လုံခြုံရေးပုံစံများ ထည့်သွင်း အကောင်အထည်ဖော်နိုင်ခြင်း
- ✅ Application Insights ကို အသုံးပြုကာ ထုတ်လုပ်မှု စောင့်ကြည့်မှုဒီဇိုင်းဆွဲပြီး တပ်ဆင်နိုင်ခြင်း
- ✅ စီးပွားရေး အုပ်ချုပ်မှု စနစ်များ အပြည့်အဝ တည်ဆောက်နိုင်ခြင်း

### သင်တန်းပြီးမြောက်ခြင်းအားဖြင့် ရရှိသော အကျိုးကျေးဇူးများ
အခန်းအားလုံးအောင်မြင်စွာပြီးမြောက်ပြီးနောက် ကျောင်းသားများ ရရှိမည့်အချက်များ

**နည်းပညာပိုင်း ကျွမ်းကျင်မှုများ:**
- **ထုတ်လုပ်မှု အတွေ့အကြုံ**: အမှန်တကယ် AI application များကို Azure ပတ်ဝန်းကျင်များသို့ တပ်ဆင်ထားမှု
- **ပရော်ဖက်ရှင်နယ် ကျွမ်းကျင်မှုများ**: စီးပွားရေးအသင့် deployment နှင့် ပြဿနာဖြေရှင်းနိုင်မှုများ  
- **ပုံစံအသိပညာ**: မျိုးစုံ agent AI ဖြေရှင်းနည်းများနှင့် ရှုပ်ထွေးသော infrastructure ပုံစံများ
- **ပြဿနာဖြေရှင်းမှု ကျွမ်းကျင်မှု**: ကိုယ်တိုင် deployment နှင့် ဖွဲ့စည်းမှု ပြဿနာများ ဖြေရှင်းနိုင်ခြင်း

**ပရော်ဖက်ရှင်နယ် ဖွံ့ဖြိုးတိုးတက်မှု:**
- **လုပ်ငန်းသက်ဆိုင်ရာ အသိအမှတ်ပြုမှု**: AZD နှင့် AI deployment လေ့လာမှုများတွင် တိုက်ရိုက်အကျိုးထားရှိသော ကျွမ်းကျင်မှုများ
- **လုပ်ငန်းအတှဲ အရည်အချင်းမြှင့်တင်မှု**: cloud architect နှင့် AI deployment အထူးပြုရာတွင် သက်ဆိုင်ရာအရည်အချင်းရရှိခြင်း
- **အသိုင်းအဝိုင်း ဦးဆောင်မှု**: Azure developer နှင့် AI အသိုင်းအဝိုင်းများတွင် ဆန်းသစ်တီထွင်မှု ပါဝင်ခြင်း
- **သင်ယူမှု တိုးတက်မှု**: Microsoft Foundry အထူးပြုသင်တန်းများအတွက် အခြေခံအဆောက်အအုံ

**ပေါ့ဖိုလီယို အရင်းအမြစ်များ:**
- **တပ်ဆင်ပြီးသော ဖြေရှင်းချက်များ**: AI application များနှင့် infrastructure ပုံစံများ၏ လက်တွေ့ နမူနာများ
- **စာရွက်စာတမ်းများ**: deployment လမ်းညွှန်များနှင့် ပြဿနာဖြေရှင်းနည်းများ အပြည့်အစုံ
- **အသိုင်းအဝိုင်း ပံ့ပိုးမှု**: Azure အသိုင်းအဝိုင်းနှင့် မျှဝေထားသော ဆွေးနွေးပွဲများ၊ ဥပမာများနှင့် တိုးတက်မှုများ
- **ပရော်ဖက်ရှင်နယ် ကွန်ယက်**: Azure ကျွမ်းကျင်သူများနှင့် AI deployment အကျွမ်းတော်များမှ ချိတ်ဆက်မှုများ

### သင်တန်းပြီးနောက် သင်ယူမှု လမ်းကြောင်း
ဘာသာရပ်ကျွမ်းကျင်မှုအဆင့်မြှင့်တင်ရေးအတွက် အသင့်ပြင်ရှိပြီးဖြစ်သူများအတွက်-
- **Microsoft Foundry အထူးကျွမ်းကျင်သူ**: AI မော်ဒယ် deployment နှင့် ပေါင်းစပ်ထိန်းချုပ်မှု အထူးပြုခြင်း
- **Cloud Architecture ဦးဆောင်မှု**: စီးပွားရေးအဆင့် deployment ဒီဇိုင်းနှင့် အုပ်ချုပ်မှု
- **Developer အသိုင်းအဝိုင်း ဦးဆောင်မှု**: Azure နမူနာများနှင့် အသိုင်းအဝိုင်း အရင်းအမြစ်များ တိုးတက်အောင် ပံ့ပိုးခြင်း
- **Corporate သင်တန်းပေးခြင်း**: အဖွဲ့အစည်းတွင်း AZD နှင့် AI deployment ကျွမ်းကျင်မှု သင်ကြားပေးခြင်း
