# AZD အတွက် စတင်သင်ယူသူများအတွက် လေ့လာမှုအစီအစဉ်နှင့် သင့်တော်သော သင်ယူမှုဖွဲ့စည်းပုံ

## သင်တန်းအကျဉ်းချုပ်

Azure Developer CLI (azd) ကို အဆင့်ဆင့် သင်ယူနိုင်သော ရေးဆွဲထားသည့် အခန်းများမှတဆင့် ကျွမ်းကျင်လာပါ။ **Microsoft Foundry ထည့်သွင်းမှုနှင့်အတူ AI လျှပ်စစ်နှင့်ပတ်သက်သော လျှောက်လွှာများ ထုတ်လုပ်ရာတွင် အထူးအာရုံစိုက်ထားပါသည်။**

### ယခုသင်တန်းသည် ခေတ်ပြိုင် Developer များအတွက် အရေးပါသောအကြောင်းရင်း

AI အလုပ်လုပ်မှုများ တပ်ဆင်နေသော Developer များအား အတန်းလို:
- ဆန်းပြားသော multi-service AI ဖွဲ့စည်းမှုများ
- ထုတ်လုပ်မှု AI တပ်ဆင်မှုအတွက် အကောင်းဆုံးလေ့ကျင့်မှုများ  
- Azure AI ဝန်ဆောင်မှု ထည့်သွင်းမှုနှင့် ဖွဲ့စည်းမှု
- AI အလုပ်လုပ်မှုများအတွက် စရိတ် ထိရောက်စွာ စီမံခန့်ခွဲခြင်း
- AI အထူးသဖြင့် တပ်ဆင်မှုပြဿနာရှာဖွေပြုပြင်ခြင်း

### အဓိက သင်ယူရမည့် ရည်မှန်းချက်များ

ဤ ရေးဆွဲထားသည့် သင်တန်းကို ပြီးမြောက်ခြင်းအားဖြင့်၊ သင်သည်
- **AZD မူလအခြေခံများ ကျွမ်းကျင်မှု**: အခြေခံအတွေးအခေါ်များ၊ တပ်ဆင်ခြင်းနှင့် ဖွဲ့စည်းမှု
- **AI လျှောက်လွှာများ တပ်ဆင်ခြင်း**: AZD နှင့် Microsoft Foundry ဝန်ဆောင်မှုများကို အသုံးပြုခြင်း
- **Infrastructure as Code ကို အကောင်အထည်ဖော်ခြင်း**: Bicep template များဖြင့် Azure ရင်းနှီးမြှုပ်နှံမှု စီမံခန့်ခွဲခြင်း
- **တပ်ဆင်မှုပြဿနာများ ပြင်ဆင်ခြင်း**: ပုံမှန် ပြဿနာများဖြေရှင်းခြင်းနှင့် အမှားရှာဖွေခြင်း
- **ထုတ်လုပ်မှုအတွက် ထိရောက်မှုဖြစ်စေခြင်း**: လုံခြုံရေး၊ အတိုင်းအတာချဲ့ထွင်ခြင်း၊ ကြည့်ရှုစောင့်ကြည့်ခြင်း၊ နှင့် စရိတ်စီမံခန့်ခွဲမှု
- **Multi-Agent ဖြေရှင်းနည်းများ တည်ဆောက်ခြင်း**: ဆန်းသစ်သော AI ဖွဲ့စည်းမှုများ တပ်ဆင်ခြင်း

## 🎓 အလုပ်ရုံလေ့လာမှု အတွေ့အကြုံ

### လွယ်ကူချောမွေ့သော သင်ယူရေးနည်းလမ်းများ
ဤ သင်တန်းသည် **ကိုယ်တိုင်အလိုက် သင်ယူသည့်နည်းလမ်း** နှင့် **အလုပ်ရုံသင်တန်းများ** နှစ်မျိုးရရှိရန် ရည်ရွယ်ထားပြီး AZD နှင့် ပတ်သက်သော လက်တွေ့ကျက်သေဖြစ်စေသည်။

#### 🚀 ကိုယ်တိုင်သင်ယူမှု မော်ဒယ်
**ပုဂ္ဂိုလ်ရေး Developer များနှင့် ကျွန်တော်သင်ကြားမှု ဆက်လက်လုပ်ဆောင်သူများအတွက် အကောင်းဆုံး**

**အင်္ဂါရပ်များ:**
- **Browser အခြေပြု မျက်နှာပြင်**: MkDocs ပလက်ဖောင်းဖြင့် Browser ကို အသုံးပြုပြီး အလုပ်ရုံပညာရပ်ကို လေ့လာနိုင်သည်
- **GitHub Codespaces ဖြင့် ပေါင်းစည်းမှု**: တစ်ချက်နှိပ်လျင် အသင့်ပတ်ဝန်းကျင်တည်ဆောက်ခြင်း
- **DevContainer အပြန်အလှန် လိုက်ဖက်မှု**: ဒေသတြင်း စီစဉ်မှု လိုအပ်မှုမရှိဘဲ စတင်ရေးသားနိုင်ခြင်း
- **တိုးတက်မှုသတင်းအချက်အလက်များ**: အတွင်းက နမူနာနှင့် ပြုပြင်စစ်ဆေးမှုလေ့ကျင့်ခန်းများ ပါဝင်သည်
- **အသိုင်းအဝိုင်း ပံ့ပိုးမှု**: Azure Discord ချန်နယ်များမှ မေးခွန်းများနှင့် ပူးပေါင်းဆောင်ရွက်မှုရယူနိုင်သည်

**သင်ယူမှုဖွဲ့စည်းပုံ:**
- **အချိန်လြှောကျ လေ့လာနိုင်မှု**: ကိုယ့်အချိန်အတိုင်း အခန်းများကို ပြီးမြောက်စေခြင်း
- **စစ်ဆေးမှုစနစ်**: ရှုပ်ထွေးသောအကြောင်းအရာများ မတက်မီ သင်ယူမှုပြုလုပ်ခြင်း
- **အရင်းအမြစ်စာကြည့်တိုက်**: လက်ရေးစာတမ်း၊ နမူနာများနှင့် ပြဿနာဖြေရှင်းလမ်းညွှန်များ
- **ကိုယ်ပိုင် စွမ်းဆောင်ရည်ဖော်ထုတ်မှု**: အလုပ်အတည်ပြုနိုင်သော ပရောဂျက်များ တည်ဆောက်ခြင်း

#### 🏛️ အလွယ်တကူ ဉပမာ အလုပ်ရုံသင်တန်းများ
**ကုမ္ပဏီ လေ့ကျင့်ရေး၊ ဘုတ်ကုမ္ပဏီများနှင့် ပညာရေးအဖွဲ့အစည်းများအတွက် အထူးသင့်တော်သည်**

**အလုပ်ရုံသင်တန်း ပုံစံများ:**

**📚 ပညာရေးသင်တန်းတွဲဖက်မှု (၈-၁၂ ပတ်)**
- **တက္ကသိုလ်အစီအစဉ်များ**: တစ်သက်တမ်း စာချိန်တက်သင်တန်း နှစ်များ ၂ နာရီ အစည်းအဝေးများ
- **ဘုတ်ကစားပြိုင်ပွဲ ပုံစံ**: အထင်ကြီးသော တယူနေ့ ၃-၅ ရက် များနှင့် နေ့စဉ် ၆-၈ နာရီ အစည်းအဝေးများ
- **ကုမ္ပဏီ လေ့ကျင့်ရေး**: လစဉ်အသင်းအစည်းအဝေးများနှင့် လက်တွေ့ပရောဂျက် လုပ်ငန်းစဉ်များ
- **အသက်သေ ချက်**: အဆင့်သတ်မှတ်ချက်များ၊ မိတ်ဆွေသုံးသပ်ချက်များနှင့် နောက်ဆုံးပရောဂျက်များ

**🚀 မျှတသည့် အလုပ်ရုံသင်တန်း (၁-၃ ရက်)**
- **ရက် ၁**: အခြေခံ + AI ဖွံ့ဖြိုးမှု (အခန်း ၁-၂) - ၆ နာရီ
- **ရက် ၂**: ဖွဲ့စည်းမှု + သက်တမ်း (အခန်း ၃-၄) - ၆ နာရီ  
- **ရက် ၃**: အဆင့်မြင့်နမူနာများ + ထုတ်လုပ်မှု (အခန်း ၅-၈) - ၈ နာရီ
- **နောက်ထပ် လေ့ကျင့်မှု**: ၂ ပတ် အကြာတွင် ဆက်လက်ညွှန်ကြားမှု ရွေးချယ်နိုင်သည်

**⚡ အုပ်ချုပ်သူ မိတ်ဆက်စာရွက် (၄-၆ နာရီ)**
- **နည်းဗျူဟာ ရှင်းလင်းချက်**: AZD တန်ဖိုးနှင့် စီးပွားရေး သက်ရောက်မှု (၁ နာရီ)
- **လက်တွေ့ ပြပွဲ**: AI လျှောက်လွှာ အပြီးအပြတ် တပ်ဆင်ခြင်း (၂ နာရီ)
- **ဖွဲ့စည်းမှု ပြန်လည်သုံးသပ်ခြင်း**: စက်မှု နမူနာများနှင့် အုပ်ချုပ်မှု (၁ နာရီ)
- **အကောင်အထည်ဖော်ရေး စီမံချက်**: အဖွဲ့အစည်း လက်ခံအသုံးပြုမှု နည်းဗျူဟာ (၁-၂ နာရီ)

#### 🛠️ အလုပ်ရုံသင်တန်း သင်ကြားရေးနည်းဗျ
**ရှာဖွေခြင်း → တပ်ဆင်ခြင်း → ကိုယ်တည်ဆဲြစေခြင်း နည်းလမ်းဖြင့် လက်တွေ့ကျွမ်းကျင်မှု ထိရောက်စွာတိုးတက်ရေး**

**အဆင့် ၁: ရှာဖွေခြင်း (၄၅ မိနစ်)**
- **Template ရွေးချယ်ပြီး ဆန်းစစ်ခြင်း**: Microsoft Foundry Templates နှင့် ဝန်ဆောင်မှုများ ပြန်လည်သုံးသပ်မှု
- **ဖွဲ့စည်းမှု ခွဲခြမ်းစိတ်ဖြာမှု**: Multi-agent နမူနာများနှင့် တပ်ဆင်မှု များနားလည်ခြင်း
- **လိုအပ်ချက် တွက်ချက်ခြင်း**: အဖွဲ့အစည်းလိုအပ်ချက်များနှင့် ကန့်သတ်ချက်များ ဖော်ထုတ်ခြင်း
- **ပတ်ဝန်းကျင် ပြင်ဆင်ခြင်း**: ဖွံ့ဖြိုးရေး ပတ်ဝန်းကျင် နှင့် Azure ရင်းနှီးမြှုပ်နှံမှု ဖွဲ့စည်းခြင်း

**အဆင့် ၂: တပ်ဆင်ခြင်း (၂ နာရီ)**
- **လမ်းညွှန်သွားသော တပ်ဆင်မှု**: AZD ဖြင့် AI လျှောက်လွှာများ တစ်ဆင့်ချင်း တပ်ဆင်ခြင်း
- **ဝန်ဆောင်မှု ဖွဲ့စည်းမှု**: Azure AI ဝန်ဆောင်မှုများ၊ endpoint များနှင့် အထောက်အထားပြုလုပ်ခြင်း
- **လုံခြုံရေး လုပ်ဆောင်ချက်**: စက်မှု လုံခြုံရေး နမူနာများ နဲ့ အသုံးပြုခွင့်ကန့်သတ်ချက်များ ပြုလုပ်ခြင်း
- **စစ်ဆေးမှု လုပ်ရပ်များ**: တပ်ဆင်ထားမှုများ စစ်ဆေးပြီး ပုံမှန်ပြဿနာများဖြေရှင်းခြင်း

**အဆင့် ၃: ကိုယ်တည်ဆဲြစေခြင်း (၄၅ မိနစ်)**
- **အပလီကေးရှင်းပြင်ဆင်မှု**: အထူးသတ်မှတ်ထားသော အသုံးပြုမှုများနှင့် လိုအပ်ချက်များအတွက် Template များကို ကိုက်ညီ စေရန်ပြင်ဆင်ခြင်း
- **ထုတ်လုပ်မှုအတွက် ထိရောက်မှု တိုးတက်ရေး**: ကြည့်ရှုစောင့်ကြည့်ခြင်း၊ စရိတ် စီမံခန့်ခွဲခြင်းနှင့် အတိုင်းအတာချဲ့ထွင်မှု မိတ်ဆက်ခြင်း
- **အဆင့်မြင့် နမူနာများ**: multi-agent ပူးပေါင်းဆောင်ရွက်မှု နှင့် စုံလင်စွာ ဖွဲ့စည်းမှုများ ကို မျှတစွာ ထောက်လှမ်းခြင်း
- **နောက်တိုးဆက်မှုအစီအစဉ်**: ဆက်လက်ကျွမ်းကျင်မှု တိုးတက်ရန် သင်ကြားမှုလမ်းကြောင်း သတ်မှတ်ခြင်း

- **ထုတ်လုပ်မှု AI လျှောက်လွှာများ တပ်ဆင်ခြင်း**: AI စွမ်းအင်ဖြင့် လုပ်ဆောင်နိုင်သည့် စနစ်များ တပ်ဆင်ပြီး ဖွဲ့စည်းနိုင်ခြင်း
- **Infrastructure as Code ကျွမ်းကျင်မှု**: ကိုယ်ပိုင် Bicep template များ ဖန်တီးပြီး စီမံခန့်ခွဲနိုင်ခြင်း
- **Multi-Agent ဖွဲ့စည်းမှု**: တူညီပြီးနှီးနွှဲသော AI agent စနစ်များ အကောင်အထည်ဖော်နိုင်ခြင်း
- **ထုတ်လုပ်မှုအဆင်သင့်ရှိမှု**: လုံခြုံရေး၊ ကြည့်ရှုစောင့်ကြည့်မှုနှင့် အုပ်ချုပ်မှု နမူနာများကို အသုံးပြုနိုင်ခြင်း
- **ပြဿနာဖြေရှင်းမှု ကျွမ်းကျင်မှု**: တပ်ဆင်မှုနှင့် ဖွဲ့စည်းမှု ပြဿနာများကို ကိုယ်တိုင် ဖြေရှင်းနိုင်ခြင်း

**အလုပ်အမူကျွမ်းကျင်မှုများ:**
- **ပရောဂျက်ခေါင်းဆောင်မှု**: မြေပြင် လုပ်ငန်းအဖွဲ့များအား နည်းပညာ ဘက်မှ ဦးဆောင်နိုင်ခြင်း
- **ဖွဲ့စည်းမှု ဒီဇိုင်နာ**: ကျယ်ပြန့်ပြီး စရိတ်သက်သာသော Azure ဖြေရှင်းနည်းများ ဒီဇိုင်နာလုပ်နိုင်ခြင်း
- **အသိပညာ ပေးပို့မှု**: AZD မှာ အကောင်းဆုံး လေ့လာနည်းများကို မိတ်ဆက်ပြီး မိတ်ဆွေများကို လေ့ကျင့်ပေးနိုင်ခြင်း
- **နည်းဗျူဟာစီမံချက်**: အဖွဲ့အစည်း၏ cloud အသုံးပြုမှု နည်းဗျူဟာများအား ထိရောက်စွာ သက်ရောက်မှု ရရှိစေခြင်း

#### 📋 အလုပ်ရုံ သင်တန်း ရင်းမြစ်များနှင့် ပစ္စည်းများ
**သင်ကြားသူများနှင့် သင်ယူသူများအတွက် စုံလင်ပြည့်စုံသော ကိရိယာများ**

**သင်ကြားသူများအတွက်:**
- **ညွှန်ကြားရေး မကျမ်း**: [အလုပ်ရုံ သင်တန်း အကျဉ်း](workshop/README.md) - အစီအစဉ် စီမံခြင်းနှင့် သင်တန်းနည်းလမ်းညွှန်ချက်များ
- **ပြသခြင်း ပစ္စည်းများ**: စလိုက် ဒက်ခ်များ၊ ဖွဲ့စည်းမှု ပုံဆွဲများနှင့် ပြသမှု စာသားများ
- **အကဲခတ် ကိရိယာများ**: လက်တွေ့ လေ့ကျင့်ခန်းများ၊ သဘောအပေါ် စစ်ဆေးမှုများနှင့် အကဲဖြတ် ညဏ်ပညာများ
- **နည်းပညာ ပြင်ဆင်မှု**: ပတ်ဝန်းကျင် ဖွဲ့စည်းမှု၊ ပြဿနာဖြေရှင်းမှု လမ်းညွှန်ချက်များနှင့် မူလ ပုံစံအခြေခံ များ

**သင်ယူသူများအတွက်:**
- **အပြန်အလှန်ဖြစ်သော အလုပ်ရုံ ပတ်ဝန်းကျင်**: [အလုပ်ရုံ ပစ္စည်းများ](workshop/README.md) - Browser အခြေပြု သင်ယူသည့် ပလက်ဖောင်း
- **လမ်းကြောင်းများ သေချာညွှန်ပြချက်များ**: [လမ်းညွှန် လေ့ကျင့်မှုများ](../../workshop/docs/instructions) - အသေးစိတ် လုပ်ဆောင်လမ်းညွှန်ချက်များ  
- **အညွှန်း စာရွက်များ**: [AI အလုပ်ရုံ ဓါတ်ခွဲခန်း](docs/chapter-02-ai-development/ai-workshop-lab.md) - AI အာရုံစိုက်ထားသော နက်ရှိုင်းသော စမ်းသပ်မှုများ
- **အသိုင်းအဝိုင်း အရင်းအမြစ်များ**: Azure Discord ချန်နယ်များ၊ GitHub ဆွေးနွေးမှုများနှင့် ဗဟုသုတထောက်ခံမှုများ

#### 🏢 စီးပွားရေး အလုပ်ရုံ သင်တန်း ဆောင်ရွက်မှု
**အဖွဲ့အစည်းတစ်ခုလုံး တွင် တပ်ဆင်ခြင်းနှင့် သင်ကြားရေး အတွက် နည်းဗျူဟာများ**

**ကုမ္ပဏီ လေ့ကျင့်ရေး အစီအစဉ်များ:**
- **Developer ဝင်ရောက်ခြင်း**: အသစ် ဝင်ရောက်သည့်သူများအတွက် AZD မူလအချက်အလက်များနှင့်အတူ နိဒါန်းပွဲ (၂-၄ ပတ်)
- **အသင်း အတတ်ပညာ မြှင့်တင်ခြင်း**: လေးလပတ်စဉ် အလုပ်ရုံသင်တန်းများ (၁-၂ ရက်)
- **ဖွဲ့စည်းမှု ပြန်လည် သုံးသပ်ခြင်း**: လစဉ် အကြီးအကဲများ၊ အင်ဂျင်နီယာများနှင့် ဒီဇိုင်နာများအတွက် အစည်းအဝေး (၄ နာရီ)
- **ခေါင်းဆောင်ရေး မိတ်ဆက်ချက်များ**: နည်းပညာ ဆုံးဖြတ်ချက်များအတွက် အုပ်ချုပ်သူ အစည်းအဝေးများ (နေ့ဝက်)

**ဆောင်ရွက်မှု ပံ့ပိုးမှု:**
- **အလုပ်ရုံ ထုတ်လုပ်မှု ဒီဇိုင်း**: အဖွဲ့အစည်းလိုအပ်ချက်များအတွက် စိတ်တိုင်းကျ အကြောင်းအရာများ
- **စမ်းသပ်အစီအစဉ် စီမံခြင်း**: ဖြန့်ဖြူးမှုကို စနစ်တကျ ထိန်းသိမ်းပြီး အောင်မြင်မှုနှင့် အကြံပြုချက်များ ရယူခြင်း  
- **ဆက်လက်ညွှန်ကြားမှု**: အလုပ်ရုံပြီးပြီးနောက် ပရောဂျက် ဆောင်ရွက်မှုအတွက် ပံ့ပိုးမှု
- **အသိုင်းအဝိုင်း ဖွဲ့စည်းခြင်း**: ဖွဲ့စည်းထားသော Azure AI developer အသိုင်းအဝိုင်းများနှင့် အသိပညာ မျှဝေမှု

**အောင်မြင်မှု ဖြစ်စေချက်များ:**
- **ကျွမ်းကျင်မှု ရယူခြင်း**: နောက်ခံ/ နောက်ပိုင်း စစ်တမ်းများဖြင့် နည်းပညာ ကျွမ်းကျင်မှု တိုးတက်မှုတိုင်းတာခြင်း
- **တပ်ဆင်မှု အောင်မြင်မှု**: ထုတ်လုပ်မှု လျော့ပေါ့သော လျှောက်လွှာများ တပ်ဆင်နိုင်သူ ရာခိုင်နှုန်း
- **ထုတ်လုပ်မှုအထိ လုပ်ဆောင်ချိန်**: အသစ် Azure AI ပရောဂျက်များအတွက် စတင်မှုအချိန် လျော့ချပေးခြင်း
- **အသိပညာ သိမ်းဆည်းမှု**: အလုပ်ရုံပြီး ၃-၆ လအကြာ ဆက်လက် စစ်ဆေးမှု

**အသစ် အပြန်အလှန် အတွေ့အကြုံ**: [အလုပ်ရုံ လမ်းညွှန်ပြည့်စုံ](workshop/README.md)
1. **ရှာဖွေခြင်း** (၃၀ မိနစ်): Template ရွေးချယ်ခြင်းနှင့် သုံးသပ်ခြင်း
2. **တပ်ဆင်ခြင်း** (၄၅ မိနစ်): AI template လက္ခဏာများနှင့် တပ်ဆင်မှုနဲ့ ပုံအတည်ပြုခြင်း  
3. **ခွဲခြမ်းစိတ်ဖြာခြင်း** (၃၀ မိနစ်): Template ဖွဲ့စည်းမှု နှင့် အစိတ်အပိုင်းများ နားလည်ခြင်း
4. **ဖွဲ့စည်းမှု စီမံခြင်း** (၃၀ မိနစ်): ဆက်စပ် အချက်များနှင့် Parameters ကို ကိုက်ညီစေရန် ပြင်ဆင်ခြင်း
5. **ကိုယ်တည်ဆဲြစေမှု** (၄၅ မိနစ်): ပြင်ဆင်ပြီး မိမိအတွက် လိုက်ဖက်အောင် လုပ်ဆောင်ခြင်း
6. **သန့်ရှင်းရေး** (၁၅ မိနစ်): ရင်းမြစ်များ သန့်ရှင်းရေးလုပ်ခြင်းနှင့် အသက်တာမှုန့်ကို နားလည်ခြင်း
7. **နောက်ဆုံး အခြေအနေ** (၁၅ မိနစ်): နောက်တိုးတက်ရေး နည်းလမ်းများနှင့် လေ့လာမှု လမ်းကြောင်းများ

## သင်ယူမှုတိုးတက်မှုနှင့် ရှုပ်ထွေးမှု

### တိုးတက်မှုအဆင့်မြှင့်တင်ခြင်း

- **🌱 စတင်သင်ယူသူများ**: အခန်း ၁ (အခြေခံ) မှ စတင် → အခန်း ၂ (AI ဖွံ့ဖြိုးတိုးတက်မှု)
- **🔧 အလယ်အလတ်အဆင့်**: အခန်း ၃ မှ ၄ (ဖွဲ့စည်းမှုနှင့် အဆောက်အဦး) → အခန်း ၆ (အတည်ပြုခြင်း)
- **🚀 အဆင့်မြင့်**: အခန်း ၅ (အေးဂျင့် မဟာဗျူဟာများ) → အခန်း ၇ (ပြဿနာရှာဖွေခြင်း)
- **🏢 စက်မှုလုပ်ငန်းအဆင့်**: အခန်းအားလုံးပြီးမြောက်စွာဖြေဆိုပြီး၊ အခန်း ၈ (ထုတ်လုပ်မှု ဉပမာများ) အပေါ် ဦးတည်ခြင်း

- **Container App လမ်းကြောင်း**: အခန်း ၄ (Containerized ဖြန့်ချိမှု), ၅ (Microservices ပေါင်းစည်းမှု), ၈ (ထုတ်လုပ်မှု အကောင်းဆုံးနည်းလမ်းများ)

### ရှုပ်ထွေးမှု အညွှန်းများ

- **⭐ အခြေခံ**: တစ်ခုတည်းသော ထင်ရှားသော အယူအဆများ၊ လမ်းညွှန်ချက်များဖြင့်၊ ၃၀-၆၀ မိနစ်
- **⭐⭐ အလယ်အလတ်**: အယူအဆအများအပြား၊ လက်တွေ့လုပ်ဆောင်မှု၊ ၁-၂ နာရီ  
- **⭐⭐⭐ အဆင့်မြင့်**: ရှုပ်ထွေးသော ပုံစံများ၊ စိတ်ကြိုက် ဖြေရှင်းနည်းများ၊ ၁-၃ နာရီ
- **⭐⭐⭐⭐ ကျွမ်းကျင်သူ**: ထုတ်လုပ်မှုစနစ်များ၊ စက်မှုလုပ်ငန်း မဟာဗျူဟာများ၊ ၂-၄ နာရီ

### လွယ်ကူသော သင်ယူမှု လမ်းကြောင်းများ

#### 🎯 AI Developer အမြန်လမ်းကြောင်း (၄ - ၆ နာရီ)
၁။ **အခန်း ၁**: အခြေခံနှင့် မြန်ဆန်စတင်ခြင်း (၄၅ မိနစ်)
၂။ **အခန်း ၂**: AI ပထမဦးဆုံး ဖွံ့ဖြိုးတိုးတက်မှု (၂ နာရီ)  
၃။ **အခန်း ၅**: အေးဂျင့်များ ပါဝင်သော AI ဖြေရှင်းနည်း (၃ နာရီ)
၄။ **အခန်း ၈**: ထုတ်လုပ်မှု AI အကောင်းဆုံး လုပ်ထုံးလုပ်နည်းများ (၁ နာရီ)

#### 🛠️ အဆောက်အဦး အထူးပြုလမ်းကြောင်း (၅ - ၇ နာရီ)
၁။ **အခန်း ၁**: အခြေခံနှင့် မြန်ဆန်စတင်ခြင်း (၄၅ မိနစ်)
၂။ **အခန်း ၃**: ဖွဲ့စည်းခြင်းနှင့် အတည်ပြုခြင်း (၁ နာရီ)
၃။ **အခန်း ၄**: အဆောက်အဦးကို ကုဒ်သဘောဆောင်၍ ဖြန့်ချိခြင်း (၁.၅ နာရီ)
၄။ **အခန်း ၆**: ဖြန့်ချိမတိုင်ခင် စစ်ဆေးခြင်းနှင့် စီစဉ်ခြင်း (၁ နာရီ)
၅။ **အခန်း ၇**: ပြဿနာရှာဖွေခြင်းနှင့် သေချာစစ်ဆေးခြင်း (၁.၅ နာရီ)
၆။ **အခန်း ၈**: ထုတ်လုပ်မှုနှင့် စက်မှုလုပ်ငန်း ဥပမာများ (၂ နာရီ)

#### 🎓 ပြီးပြည့်စုံသော သင်ယူမှု ခရီးစဉ် (၈ - ၁၂ နာရီ)
အခန်း ၈ ခုအားလုံးကို အဆင့်လိုက်ပြီး မြင်သာသော လက်တွေ့လုပ်ဆောင်မှုနှင့် အတည်ပြုမှုများဖြင့် ပြီးမြောက်စေရန်

## သင်တန်းပြီးမြောက်မှု ဖွဲ့စည်းပုံ

### ဗဟုသုတ အတည်ပြုမှု
- **အခန်း စစ်ဆေးမှုများ**: ရလဒ်တိုင်းသူတွက်တိုင်းနိုင်သော လက်တွေ့ လေ့ကျင့်ခန်းများ
- **လက်တွေ့အတည်ပြုမှု**: အခန်းတစ်ခုလျှင် အလုပ်လုပ်သော ဖြေရှင်းနည်းများ ဖြန့်ချိသည်
- **တိုးတက်မှု ထိန်းသိမ်းမှု**: မြင်သာသော ပြခန်းများနှင့် ပြီးမြောက်မှု အမှတ်အသားများ
- **အသိုင်းအဝိုင်း အတည်ပြုမှု**: Azure Discord ချန်နယ်များတွင် အတွေ့အကြုံမျှဝေခြင်း

### သင်ယူမှုရလဒ် စစ်တမ်း

#### အခန်း ၁-၂ ပြီးမြောက်မှု (အခြေခံ + AI)
- ✅ AZD အသုံးပြုပြီး မူလ ဝက်ဘ်ဆိုက်ကို ဖြန့်ချိသည်
- ✅ RAG ဖြင့် AI အခြေခံ စကားပြော အက်ပ် ဖြန့်ချိသည်
- ✅ AZD အဓိက တွက်ချက်ချက်များနှင့် AI ပေါင်းစည်းမှုကို နားလည်သည်

#### အခန်း ၃-၄ ပြီးမြောက်မှု (ဖွဲ့စည်းမှု + အဆောက်အဦး)  
- ✅ မျိုးစုံ ပတ်ဝန်းကျင် ဖြန့်ချိမှုများကို စီမံခန့်ခွဲသည်
- ✅ ကိုယ်ပိုင် Bicep အဆောက်အဦး စံနမူနာများ ဖန်တီးသည်
- ✅ လုံခြုံမှု အတည်ပြု စနစ်များ ထည့်သွင်းဆောင်ရွက်သည်

#### အခန်း ၅-၆ ပြီးမြောက်မှု (အေးဂျင့်များ + အတည်ပြုမှု)
- ✅ ရှုပ်ထွေးသော အေးဂျင့် AI ဖြေရှင်းနည်းများ ဖြန့်ချိသည်
- ✅ စွမ်းဆောင်ရည် စီမံခန့်ခွဲမှုနှင့် ကုန်ကျစရိတ် ထိန်းချုပ်မှု ပြုလုပ်သည်
- ✅ အလိုအလျောက် ဖြန့်ချိမတိုင်ခင် စစ်ဆေးမှုများ လုပ်ဆောင်သည်

#### အခန်း ၇-၈ ပြီးမြောက်မှု (ပြဿနာရှာဖွေခြင်း + ထုတ်လုပ်မှု)
- ✅ ကိုယ်ပိုင် စွမ်းတော်ပြည့်စုံစွာ ပြဿနာများကို ကုသနိုင်သည်  
- ✅ စက်မှုအဆင့် လုံခြုံရေးနှင့် ကြည့်ရှုစောင့်ကြည့်မှု စနစ်များ ထည့်သွင်းဆောင်ရွက်သည်
- ✅ အုပ်ချုပ်မှုနှင့် ထုတ်လုပ်မှုအဆင့် ပြည့်စုံသော အက်ပ်များ ဖြန့်ချိသည်

### ဘွဲ့လက်မှတ်နှင့် အသိအမှတ်ပြုခြင်း

- **အသိုင်းအဝိုင်း အသိအမှတ်ပြုခြင်း**: Microsoft Foundry Discord တွင် ပါဝင်ဆောင်ရွက်သည်
- **ပညာရေး အဖွံ့ဖြိုးတိုးတက်မှု**: စက်မှုနှင့် AI ဖြန့်ချိမှု ကျွမ်းကျင်မှုများ
- **အလုပ်အကိုင် ကြီးမားတိုးတက်မှု**: စက်မှုအဆင့် cloud ဖြန့်ချိမှု စွမ်းရည်

## 🎓 ပြည့်စုံသော သင်ယူမှုရလဒ်များ

### အခြေခံ အဆင့် (အခန်း ၁ - ၂)
အခြေခံ အခန်းများပြီးမြောက်ပါက သင်ယူသူများ ပြသနိုင်မည့် အချက်များ

**နည်းပညာဆိုင်ရာ စွမ်းရည်များ:**
- AZD ကမ်းလှမ်းပုံများကို အသုံးပြုပြီး ပေါ့ပေါ့ပါးပါး ဝက်ဘ်ဆာဗာ အက်ပ်များ ဖြန့်ချိနိုင်သည်။
- RAG ပါဝင်သော AI စကားပြော အက်ပ်များ ဖွဲ့စည်း ပြီး ဖြန့်ချိနိုင်သည်။
- AZD ၏ အဓိကထင်ရှားချက်များ (စံနမူနာများ၊ ပတ်ဝန်းကျင်များ၊ provisioning လုပ်ငန်းစဉ်များ) ကို နားလည်သည်။
- Microsoft Foundry ဝန်ဆောင်မှုများအား AZD ဖြည့်စည်းမှုတွင် ပေါင်းစည်းနိုင်သည်။
- Azure AI ဝန်ဆောင်မှုများအတွက် ဖွဲ့စည်းမှုနှင့် API လမ်းကြောင်းများကို ရှာဖွေနိုင်သည်။

**ပညာရှင်အရည်အချင်းများ:**
- ထိရောက်သော ဖြန့်ချိမှု လုပ်ငန်းစဥ်များကို လိုက်နာ ဆောင်ရွက်နိုင်သည်။
- ခွဲခြားပေါင်းစပ်သော ဖြန့်ချိမှု ပြဿနာများကို ရိုးရှင်းသော log များနှင့် စာရွက်စာတမ်းများဖြင့် ဖြေရှင်းနိုင်သည်။
- Cloud ဖြန့်ချိမှုလုပ်ငန်းစဉ်များအကြောင်း ကိုယ်စားပြု၍ ထိရောက်စွာ ဆက်သွယ်ပြောဆိုနိုင်သည်။
- လုံခြုံရေးကောင်းမွန်သော AI ဝန်ဆောင်မှု ပေါင်းစည်းမှုအတွက် အကောင်းဆုံးနည်းလမ်းများကို အသုံးပြု ဆောင်ရွက်နိုင်သည်။

**သင်ယူမှု အတည်ပြုမှု:**
- ✅ `todo-nodejs-mongo` စံနမူနာကို အောင်မြင်စွာ ဖြန့်ချိနိုင်သည်။
- ✅ RAG ပါဝင်သော `azure-search-openai-demo` ကို ဖြန့်ချိ ပြင်ဆင်နိုင်သည်။

### အလယ်အလတ် အဆင့် (အခန်း ၃ - ၄)

- **စက်မှုအသိအမှတ်ပြုမှု**: အမြင့်ဆုံး လိုအပ်ချက်များနှင့် AZD နှင့် AI ဖြန့်ချိမှု ကျွမ်းကျင်မှုများ
- **အလုပ်အကိုင် တိုးတက်မှု**: cloud architect နှင့် AI ဖြန့်ချိမှု အထူးပြု အလုပ်အကိုင်အတွက် လိုအပ်ချက်များ
- **အသိုင်းအဝိုင်း ဦးဆောင်မှု**: Azure ဖွံ့ဖြိုးသူများနှင့် AI အသိုင်းအဝိုင်း အဖွဲ့ဝင်ဖြစ်ခြင်း
- **ဆက်တိုက် သင်ယူမှု**: Microsoft Foundry အဆင့်မြင့် အထူးပြုမှုအတွက် အခြေခံ

**အချက်အလက် စာရွက်စာတမ်းများ:**
- **ဖြန့်ချိထားသော ဖြေရှင်းချက်များ**: AI အက်ပ်များနှင့် အဆောက်အဦး ပုံစံများ၏ အလုပ်လုပ်သော ဥပမာများ
- **စာရွက်စာတမ်းများ**: ဖြန့်ချိမှု လမ်းညွှန်စာအုပ်များနှင့် ပြဿနာရှာဖွေမှု လမ်းညွှန်ချက်များ  
- **အသိုင်းအဝိုင်း ထောက်ပံ့မှုများ**: Azure အသိုင်းအဝိုင်းနှင့် ဝေမျှထားသော ဆွေးနွေးမှုများ၊ ဥပမာများ၊ တိုးတက်မှုများ
- **ပညာရှင်ကွန်ယက်**: Azure ကျွမ်းကျင်သူများနှင့် AI ဖြန့်ချိမှု ဆရာများနှင့် ဆက်သွယ်မှု

### သင်တန်းပြီး မြောက်သည့်နောက် သင်ယူမှု လမ်းကြောင်း
ကျောင်းဆုံးသူများသည် အောက်ပါ အထူးပြုမှုတွင် အသင့်ရှိသည်။

- **ဖွံ့ဖြိုးသူ အသိုင်းအဝိုင်း ဦးဆောင်မှု**: Azure နမူနာများနှင့် အသိုင်းအဝိုင်း အဖွဲ့အစည်းများတွင် ဆောင်ရွက်မှု
- **ကုမ္ပဏီ သင်တန်းများ**: AZD နှင့် AI ဖြန့်ချိမှုစွမ်းရည်များကို အဖွဲ့အစည်းများတွင် သင်ကြားပေးခြင်း
