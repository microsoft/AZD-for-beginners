# Підтримка

## Проблеми та запитання курсу

Перед повідомленням про проблему перегляньте [проблеми курсу](https://github.com/microsoft/AZD-for-beginners/issues). Вкажіть уражений урок англійською, команду, яку ви виконували, версії AZD/розширень та повідомлення про помилку. Видаліть облікові дані, токени, деталі підписки та особисті дані з журналів і скріншотів.

Для загальних питань з навчання використовуйте [спільноту розробників Azure](https://discord.gg/microsoft-azure). Відповіді спільноти не є гарантованою службою підтримки.

## Проблеми з інструментами та сервісами

Повідомляйте про відтворювані помилки AZD CLI у [Azure/azure-dev](https://github.com/Azure/azure-dev/issues). Для інцидентів сервісів Azure або допомоги, пов’язаної з конкретною підпискою, користуйтеся опціями підтримки у [порталі Azure](https://portal.azure.com/).

## Повідомлення про безпеку

Дотримуйтеся [SECURITY.md](SECURITY.md) для приватного повідомлення про вразливості. Не публікуйте секрети або деталі експлуатації у публічних проблемах курсу.

## Політика підтримки Microsoft

Підтримка цього освітнього проєкту обмежується ресурсами, переліченими вище. Приклади курсу не включають зобов’язання щодо підтримки у виробництві.
