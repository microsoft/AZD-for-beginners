# Майстер-клас AZD для розробників штучного інтелекту

Ласкаво просимо на практичний майстер-клас з вивчення Azure Developer CLI (AZD) з акцентом на розгортання AI-застосунків. Цей майстер-клас допоможе вам на практиці зрозуміти шаблони AZD у 3 кроки:

1. **Відкриття** - знайдіть шаблон, який підходить саме вам.
1. **Розгортання** - розгорніть і підтвердьте, що він працює
1. **Налаштування** - змінюйте і адаптуйте під себе!

Протягом цього майстер-класу ви також ознайомитеся з основними інструментами та робочими процесами розробника, щоб оптимізувати вашу повністю інтегровану розробку.

<br/>

## Керівництво у браузері

Уроки майстер-класу представлені у форматі Markdown. Ви можете переглядати їх безпосередньо на GitHub або запустити браузерний перегляд, як показано на скріншоті нижче.

![Workshop](../../../translated_images/uk/workshop.75906f133e6f8ba0.webp)

Щоб скористатися цією можливістю - зробіть форк репозиторію у свій профіль і запустіть GitHub Codespaces. Коли термінал VS Code стане активним, введіть цю команду:

Цей браузерний перегляд працює у GitHub Codespaces, dev-контейнерах або локальному клоні з установленими Python та MkDocs.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

Запускайте ці команди з **кореневої папки репозиторію курсу**, а не з окремо ініціалізованого AI-прикладу. Тримайте перегляд на передньому плані, щоб бачити помилки; зупиніть Ctrl+C. Щоб перевірити сайт без запуску сервера, виконайте `python -m mkdocs build --strict --config-file workshop/mkdocs.yml`.

Через кілька секунд з’явиться спливаюче вікно. Виберіть варіант `Open in browser`. Веб-керівництво відкриється у новій вкладці браузера. Деякі переваги цього перегляду:

1. **Вбудований пошук** - швидко знаходьте ключові слова або уроки.
1. **Іконка копіювання** - наведіть курсор на кодові блоки, щоб побачити цю опцію
1. **Перемикач теми** - змінюйте між темною та світлою темами
1. **Отримайте допомогу** - натисніть іконку Discord у підвалі, щоб приєднатися!

## Чого ви навчитесь

Розглядайте шаблон AZD як навчальну пісочницю для дослідження різних можливостей та інструментів для повноцінної розробки на Microsoft Foundry. До кінця майстер-класу ви повинні отримати інтуїтивне розуміння різних інструментів і концепцій у цьому контексті.

| Концепція  | Мета |
|:---|:---|
| **Azure Developer CLI** | Зрозуміти команди інструменту та робочі процеси|
| **Шаблони AZD**| Зрозуміти структуру проекту та конфігурацію|
| **Azure AI Agent**| Забезпечити та розгорнути проект Microsoft Foundry  |
| **Azure AI Search**| Активувати контекстну інженерію за допомогою агентів |
| **Спостережуваність**| Ознайомитись із трасуванням, моніторингом та оцінками |
| **Red Teaming**| Вивчати тестування на атаки та пом’якшення наслідків |

## Структура майстер-класу

Майстер-клас організовано так, щоб провести вас від відкриття шаблону до розгортання, деконструкції та налаштування - використовуючи офіційний стартер [Getting Started with AI Agents](https://github.com/Azure-Samples/get-started-with-ai-agents) як основу.

### [Модуль 1: Вибір шаблону AI](docs/instructions/1-Select-AI-Template.md) (30 хв)

- Що таке AI-шаблони?
- Де я можу знайти AI-шаблони?
- Як розпочати створення AI-агентів?
- **Лабораторна робота**: Швидкий старт у Codespaces або dev-контейнері

### [Модуль 2: Валідація шаблону AI](docs/instructions/2-Validate-AI-Template.md) (30 хв)

- Яка архітектура AI-шаблону?
- Який робочий процес розробки AZD?
- Як отримати допомогу з розробкою AZD?
- **Лабораторна робота**: Розгортання та перевірка шаблону AI-агентів

### [Модуль 3: Деконструкція шаблону AI](docs/instructions/3-Deconstruct-AI-Template.md) (30 хв)

- Досліджуйте ваше середовище у `.azure/` 
- Досліджуйте налаштування ресурсів у `infra/` 
- Досліджуйте конфігурацію AZD у `azure.yaml`s
- **Лабораторна робота**: Змінити змінні середовища та перебудувати

### [Модуль 4: Налаштування шаблону AI](docs/instructions/4-Configure-AI-Template.md) (30 хв)
- Ознайомтесь: Відновлення із підсиленням (Retrieval Augmented Generation)
- Ознайомтесь: Оцінка агентів та Red Teaming
- Ознайомтесь: Трасування та моніторинг
- **Лабораторна робота**: Ознайомлення з AI агентом + спостережуваністю 

### [Модуль 5: Індивідуалізація шаблону AI](docs/instructions/5-Customize-AI-Template.md) (30 хв)
- Визначте: PRD із вимогами сценарію
- Налаштуйте: змінні середовища для AZD
- Реалізуйте: хуки життєвого циклу для додаткових завдань
- **Лабораторна робота**: Індивідуалізація шаблону під мій сценарій

### [Модуль 6: Демонтаж інфраструктури](docs/instructions/6-Teardown-Infrastructure.md) (30 хв)
- Підсумок: Що таке шаблони AZD?
- Підсумок: Чому використовувати Azure Developer CLI?
- Наступні кроки: Спробуйте інший шаблон!
- **Лабораторна робота**: Зняття інфраструктури та очищення

## Виклик майстер-класу

Хочете собі виклик зробити складніше? Ось кілька проєктних пропозицій - або поділіться своїми ідеями з нами!!

| Проєкт | Опис |
|:---|:---|
|1. **Деконструкція складного AI-шаблону** | Використовуйте описані робочі процеси та інструменти і спробуйте розгорнути, перевірити та індивідуалізувати інший шаблон AI-рішення. _Що ви дізналися?_|
|2. **Індивідуалізація під ваш сценарій**  | Спробуйте написати PRD (Документ вимог до продукту) для іншого сценарію. Потім використовуйте GitHub Copilot у вашому репозиторії шаблону в режимі Agent Model - і попросіть згенерувати робочий процес індивідуалізації. _Що ви дізналися? Як можна покращити ці пропозиції?_|
