# AZD для початківців: Огляд курсу та навчальна структура

## Огляд курсу

Опануйте Azure Developer CLI (azd) через структуровані розділи, розроблені для поступового навчання. **Особлива увага на розгортанні AI-застосунків з інтеграцією Microsoft Foundry.**

### Чому цей курс важливий для сучасних розробників

Розробникам, що впроваджують AI-навантаження, часто потрібна консультація щодо:
- Складних багатосервісних AI-архітектур
- Найкращих практик розгортання AI в продуктивне середовище  
- Інтеграції та налаштування Azure AI сервісів
- Оптимізації витрат на AI-навантаження
- Вирішення проблем розгортання, специфічних для AI

### Основні навчальні цілі

Завершивши цей структурований курс, ви:
- **Опануєте основи AZD**: Основні концепції, встановлення та налаштування
- **Розгортатимете AI-застосунки**: Використання AZD із сервісами Microsoft Foundry
- **Впровадите Infrastructure as Code**: Управління ресурсами Azure за допомогою шаблонів Bicep
- **Вирішуватимете проблеми розгортання**: Виправлення поширених помилок і налагодження
- **Оптимізуватимете під продуктивне середовище**: Безпека, масштабування, моніторинг і управління витратами
- **Створите мультиагентські рішення**: Розгортання складних AI-архітектур

**Ідеально для окремих розробників і безперервного навчання**

- **Система оцінювання**: Оцінювані завдання, взаємні рецензії та фінальні проекти

- **Планування впровадження**: Стратегія організаційного прийняття (1-2 години)
