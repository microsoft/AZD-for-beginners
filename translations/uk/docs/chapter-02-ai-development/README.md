## Огляд

Цей розділ зосереджений на розгортанні додатків із підтримкою ШІ за допомогою Azure Developer CLI та сервісів Microsoft Foundry. Від простих AI-чат-додатків до інтелектуальних агентів з інструментами.

> **Огляд релізу (2026-11-04):** Керівництво AI CLI було перевірено відповідно до опублікованих `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23` та `azure.ai.evaluations` `1.0.0-beta.2` документацій/джерел. Використовуйте `azd >= 1.37.0` для об’єднаного робочого процесу. Оцінки тепер використовують окремий простір імен `azd ai eval`; див. [зміни в релізі та керівництво з міграції](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes). Це не валідація живого розгортання.

## Навчальні цілі

Завдяки проходженню цього розділу ви:
- Розгорнете AI-додатки, використовуючи заздалегідь створені шаблони AZD
- Зрозумієте інтеграцію Microsoft Foundry з AZD
- Налаштуєте і персоналізуєте AI-агентів з інструментами
- Розгорнете додатки RAG (Retrieval-Augmented Generation)

## 🚀 Швидкий початок

Оберіть один варіант у новій порожній директорії. Завершальний `.` ініціалізує поточну директорію; інакше AZD може створити піддиректорію без зміни робочої директорії вашого терміналу.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Інформування про вартість

Це ілюстративні діапазони, а не остаточні ціни або ліміти; трафік моделей, SKU пошуку/обчислень, регіон та додаткові функції можуть їх перевищувати. Перед створенням середовища перегляньте актуальну інформацію щодо цін для вибраного прикладу.

| Середовище | Орієнтовна місячна вартість |
|-------------|------------------------------|
| Розробка | 80–150 $ |
| Тестування (Staging) | 150–300 $ |
| Продуктивне | 300–3500+ $ |

**Порада:** Запустіть `azd down` після тестування, щоб уникнути нарахування платежів.
