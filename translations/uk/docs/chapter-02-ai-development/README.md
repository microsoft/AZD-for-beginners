# Розділ 2: Розробка із пріоритетом для ШІ

**📚 Курс**: [AZD для початківців](../../README.md) | **⏱️ Тривалість**: 4-5 годин включно з практикумом | **⭐ Складність**: Середній рівень

---

## Огляд

Цей розділ зосереджено на розгортанні додатків з підтримкою ШІ за допомогою Azure Developer CLI та сервісів Microsoft Foundry. Від простих чат-додатків зі ШІ до інтелектуальних агентів із інструментами.

> **Оновлення Foundry GA (2026-11-09):** Пакет `microsoft.foundry` 1.0 є [загальнодоступним](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). Використовуйте `azd >= 1.37.0`; оцінювання залишаються окремою інсталяцією. [Покрокова інструкція з хостованим агентом](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) охоплює локальне тестування Agent Inspector та віддалене розгортання коду. Це перегляд документації, а не валідація живого розгортання; необов’язкові функції попереднього перегляду зберігають свій статус.

## Навчальні цілі

Після проходження цього розділу ви зможете:
- Розгортати ШІ-додатки за допомогою попередньо створених шаблонів AZD
- Розуміти інтеграцію Microsoft Foundry з AZD
- Встановити GA пакет і протестувати локально хостованого агента перед розгортанням його коду у Foundry
- Оглянути `azure.yaml`, ресурси для оцінювання та очистку нових і повторно використаних проєктів
- Налаштовувати і персоналізувати агентів ШІ з інструментами
- Розгортати додатки RAG (генерація з підсиленням пошуку)

## 🚀 Швидкий старт

Оберіть один варіант у новій порожній директорії. Кінцевий `.` ініціалізує поточний каталог; інакше AZD може створити підкаталог без зміни робочої директорії оболонки.

Для **шляху розгортання коду хостованого агента GA**, починайте з [покрокового керівництва](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga). Він вимагає AZD 1.37.0+, поточний uv, Python 3.13+, дозволи Foundry та квоту моделі. Повні шаблони додатків нижче є альтернативами, але не передумовами для цього керівництва.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Увага до вартості

Це ілюстративні діапазони, а не пропозиції чи обмеження; трафік моделей, SKU пошуку/обчислення, регіон і додаткові функції можуть їх перевищувати. Перед налаштуванням перегляньте поточні цінові рекомендації вибраного зразка.

| Середовище | Очікувана місячна вартість |
|-------------|----------------------|
| Розробка | $80-150 |
| Попередній перегляд | $150-300 |
| Продуктивне середовище | $300-3,500+ |

**Очищення:** Перед підтвердженням перегляньте `azd down` : для новоствореного проєкту Foundry він видаляє групу ресурсів та все в ній. Для повторно використаного проєкту Foundry залишає проєкт і ресурси агента; дотримуйтеся [інструкцій очищення](microsoft-foundry-integration.md#7-clean-up-deliberately) для окремого видалення небажаних ресурсів.
