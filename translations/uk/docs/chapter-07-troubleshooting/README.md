# Розділ 7: Усунення несправностей і налагодження

**📚 Курс**: [AZD для початківців](../../README.md) | **⏱️ Тривалість**: 1-1.5 години | **⭐ Складність**: Середній рівень

---

## Огляд

Цей розділ допоможе вам діагностувати та вирішувати типові проблеми при роботі з Azure Developer CLI. Від помилок розгортання до специфічних проблем з AI.

> Дії команд перевірені за офіційним посиланням `azd 1.37.2`. Розгортання в хмарі не виконувались. Перед використанням команд замініть прикладові імена ресурсів і ІД.

## Завдання для вивчення

Вивчивши цей розділ, ви зможете:
- Діагностувати типові помилки розгортання AZD
- Відлагоджувати проблеми автентифікації та дозволів
- Вирішувати проблеми з підключенням до AI-сервісів
- Використовувати Azure Portal і CLI для усунення несправностей

## 🚨 Швидкі виправлення

### Проблеми автентифікації
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### Помилки забезпечення ресурсів (provisioning)
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### Конфлікти ресурсів
Спочатку проінспектуйте існуючі ресурси та помилки розгортання. Не видаляйте спільне або продуктивне середовище для вирішення конфлікту імен. Для **нового одноразового середовища** використовуйте унікальне ім’я:

```bash
azd env new different-name
azd up
```

### Перевищення квоти
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

Зміна `AZURE_LOCATION` не переміщує існуючі ресурси і може викликати конфлікти розташування при повторному розгортанні.

## 📋 Довідник кодів помилок

| Помилка | Причина | Рішення |
|-------|-------|----------|
| `AuthenticationError` | Не увійшли в систему | `azd auth login` |
| `ResourceNotFound` | Відсутній ресурс | Перевірте імена ресурсів |
| `QuotaExceeded` | Обмеження підписки | Запросіть збільшення квоти |
| `InvalidTemplate` | Синтаксична помилка Bicep | `az bicep build` |
| `Conflict` | Ресурс існує | Використайте нове ім’я або видаліть |
| `Forbidden` | Недостатньо прав | Перевірте ролі RBAC |

## 🔄 Скидання і відновлення

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

Жорстке скидання видаляє дані і може змінити кінцеві точки. Спочатку зробіть резервну копію і ознайомтесь із інтерактивними підказками видалення. `--force --purge` підходить лише для одноразових середовищ, коли потрібне незворотнє видалення.
