# Розділ 5: Багатоагентні рішення ШІ

**📚 Курс**: [AZD Для початківців](../../README.md) | **⏱️ Тривалість**: 2-3 години | **⭐ Складність**: Просунутий рівень

---

## Огляд

У цьому розділі розглядаються просунуті патерни архітектури багатоагентних систем, оркестрація агентів та готові до виробництва рішення ШІ для складних сценаріїв.

> Керівництво команд перевірено щодо опублікованого довідника `azd 1.37.2`. Хмарні розгортання не виконувалися.

## Цілі навчання

Завершивши цей розділ, ви:
- Зрозумієте патерни архітектури багатоагентних систем
- Розгорнете скоординовані системи агентів ШІ
- Реалізуєте комунікацію між агентами
- Побудуєте готові до виробництва багатоагентні рішення

## 🚀 Швидкий старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **Який підхід обрати?** Використовуйте `azd init --template`, щоб почати з робочого зразка. Використовуйте `azd ai agent init` інтерактивно або `azd ai agent init --template <path-to-azure.yaml>`, щоб прийняти існуючий агентний проєкт. Дивіться [довідник AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) для вимог до версій і міграції оцінок.

Запускайте ці варіанти в окремих порожніх папках. Розширення агентів `1.0.0-beta.23` вимагає `azd >= 1.37.0`; його інтерактивний потік не генерує кастомний конвеєр Service Bus у уроці координації.

## 🎯 Виділене рішення: Роздрібне багатоагентне

У [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонструється:

- **Агент клієнта**: Обробляє взаємодії з користувачем та вподобання
- **Агент інвентаризації**: Керує запасами та обробкою замовлень
- **Оркестратор**: Координує взаємодію між агентами
- **Спільна пам’ять**: Управління контекстом між агентами
