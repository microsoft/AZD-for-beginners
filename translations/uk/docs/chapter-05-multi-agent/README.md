# Розділ 5: Багатокористувацькі AI-рішення

**📚 Курс**: [AZD для початківців](../../README.md) | **⏱️ Тривалість**: 2-3 години | **⭐ Складність**: Просунутий

---

## Огляд

Цей розділ охоплює складні архітектурні шаблони багатокористувацьких агентів, оркестрацію агентів та виробничі розгортання AI для складних сценаріїв.

> Команди перевірено відповідно до опублікованого `azd 1.37.2` референсу. Розгортання в хмарі не виконувались.

## Цілі навчання

Після проходження цього розділу ви зможете:
- Розуміти архітектурні шаблони багатокористувацьких агентів
- Розгортати скоординовані системи AI агентів
- Реалізувати комунікацію між агентами
- Створювати готові до виробництва багатокористувацькі AI-рішення

## 🚀 Швидкий старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **Який підхід вибрати?** Використовуйте `azd init --template`, щоб почати з робочого прикладу. Використовуйте `azd ai agent init` інтерактивно або `azd ai agent init --template <path-to-azure.yaml>` для прийняття існуючого проєкту агента. Див. [AZD AI CLI референс](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) для вимог до версії та міграції оцінювання.

Запускайте ці альтернативи в окремих порожніх папках. Потік роботи GA Foundry вимагає `azd >= 1.37.0`; його інтерактивний процес не створює власний конвеєр Service Bus у координаційному уроці. Для локального тестування, розгортання коду та очищення нових/перевикористаних проєктів дотримуйтеся [інструкцій з hosted-agent](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga).

## 🎯 Представлене рішення: роздрібний багатокористувацький агент

Приклад [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонструє:

- **Агент клієнта**: Обробляє взаємодію з користувачем та його вподобання
- **Агент інвентарю**: Керує запасами та обробкою замовлень
- **Оркестратор**: Координує взаємодію між агентами
- **Спільна пам’ять**: Управління контекстом між агентами

### Використані сервіси

| Сервіс | Призначення |
|---------|---------|
| Microsoft Foundry Models | Розуміння мови |
| Azure AI Search | Каталог товарів |
| Cosmos DB | Стан та пам’ять агента |
| Container Apps | Хостинг агента |
| Application Insights | Моніторинг |
