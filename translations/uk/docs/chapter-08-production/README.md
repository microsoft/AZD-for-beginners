## Огляд

У цьому розділі розглядаються готові до підприємства шаблони розгортання, посилення безпеки, моніторинг і оптимізація витрат для виробничих навантажень штучного інтелекту.

Це архітектурний довідник, а не повний шаблон для розгортання у виробництві. Приклади опускають деталі інтеграції, які повинні бути надані та протестовані у вашому власному додатку; прочитання контрольного списку не гарантує готовність до виробництва.

> **Оновлення Foundry GA (2026-11-09):** Використовуйте `azd >= 1.37.0` і загальнодоступний пакет `microsoft.foundry` 1.0 для робочого процесу Foundry; оцінки встановлюються окремо. Деталі див. у [обсязі релізу та міграції](production-ai-practices.md#recent-release-changes-and-fixes) та [прикладі аутентифікованого конвеєра](production-ai-practices.md#cicd-pipeline-configuration). Це огляд документації, а не валідація живого розгортання чи загальний статус GA для необов’язкових функцій попереднього перегляду.

## Навчальні цілі

Завершуючи цей розділ, ви зможете:
- Розгортати мультирегіональні стійкі додатки
- Впроваджувати корпоративні шаблони безпеки
- Налаштовувати комплексний моніторинг
- Оптимізувати витрати в масштабі
- Налаштувати CI/CD конвеєри з AZD

## 🔐 Найкращі практики безпеки

```bicep
// Illustrative properties from different resources, NOT a standalone Bicep file.
// Attach identity to the application host:
identity: {
  type: 'SystemAssigned'
}

// AI account properties (also require private endpoints, DNS and app connectivity):
properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }
}
```

## 💰 Оптимізація витрат

| Стратегія | Основне обмеження |
|----------|---------|
| Масштабування до нуля (Container Apps) | Потребує відповідного тригера; інші сервіси все ще мають витрати |
| Використання рівнів споживання для розробки | Порівняння цін обраної служби та навантаження |
| Планове масштабування | Масштабування через підтримувану інфраструктуру/автоматизацію |
| Резервування/виділена ємність | Тільки якщо підтримується; зобов’язання можуть збільшити холосту вартість |

Використовуйте [повний шаблон ресурсу бюджету](production-ai-practices.md#2-cost-monitoring-and-budgets) з дійсною датою початку, областю виставлення рахунків, отримувачами та дозволами. Бюджет надсилає сповіщення; він не обмежує витрати. Економія залежить від виміряного використання і не гарантується у відсотках.

