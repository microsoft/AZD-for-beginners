## Огляд

У цьому розділі розглядаються корпоративні патерни розгортання, посилення безпеки, моніторинг та оптимізація витрат для продакшн навантажень штучного інтелекту.

Це архітектурне посилання, а не повний шаблон для розгортання в продакшн. Приклади опускають деталі інтеграції, які потрібно надати та протестувати у власному застосунку; читання чекліста не гарантує готовність до продакшн.

> **Огляд релізу (2026-11-04):** Інструкції AI CLI були перевірені відповідно до документації/джерела `azd 1.37.2`, агентів `1.0.0-beta.23` та eval-ів `1.0.0-beta.2`. Деталі сумісності та міграції дивіться у [змінах та виправленнях релізу](production-ai-practices.md#recent-release-changes-and-fixes); це не валідація живого розгортання.

## Цілі навчання

Після проходження цього розділу ви зможете:
- Розгортати стійкі багаторегіональні застосунки
- Впроваджувати корпоративні патерни безпеки
- Налаштовувати комплексний моніторинг
- Оптимізувати витрати на масштабі
- Налаштовувати CI/CD з AZD

  type: 'SystemAssigned'

  }

## 💰 Оптимізація витрат

| Стратегія | Головне обмеження |
|----------|---------|
| Масштабування до нуля (Container Apps) | Потрібен відповідний тригер; інші сервіси все ще генерують витрати |
| Використання споживчих рівнів для розробки | Порівняння ціноутворення обраного сервісу та робочого навантаження |
| Заплановане масштабування | Масштабування через підтримувану інфраструктуру/автоматизацію |
| Резервування/провізійована потужність | Лише якщо підтримується; зобов’язання можуть збільшувати витрати на незавантажені ресурси |

Використовуйте [повний шаблон ресурсу бюджету](production-ai-practices.md#2-cost-monitoring-and-budgets) з дійсною датою початку, зоною білінгу, отримувачами та дозволами. Бюджет надсилає сповіщення; він не обмежує витрати. Економія залежить від виміряного використання і не гарантується у відсотках.

## 📊 Налаштування моніторингу

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
