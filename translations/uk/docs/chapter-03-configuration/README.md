## Огляд

Цей розділ охоплює налаштування середовища, шаблони автентифікації та передові практики безпеки для розгортання Azure Developer CLI.

> Перевірка команди та конфігурації: `azd 1.37.2` (листопад 2026). Під час перевірки не запускалося пряме розгортання Azure.

## Цілі навчання

Після завершення цього розділу ви:
- Опануєте ієрархію конфігурації AZD
- Керуєте кількома середовищами (розробка, тестування, продакшн)
- Реалізуєте безпечну автентифікацію за допомогою керованих ідентичностей
- Налаштовуватимете параметри, специфічні для кожного середовища

## 🚀 Швидкий старт

Запускайте з кореня **вже ініціалізованого застосунку azd**, а не з репозиторію курсу. Використовуйте незайняті імена середовищ, якщо такі вже існують.

```bash
# Create multiple environments
azd env new dev
azd env new staging
azd env new prod

# Switch environments
azd env select prod

# Set environment variables
azd env set AZURE_LOCATION eastus
azd env set SKU_NAME P1v3

# View configuration
azd env get-values
```

`SKU_NAME` є ілюстративним: він впливає на інфраструктуру лише якщо ваш шаблон явно його використовує. Звичайні значення `azd env set` зберігаються локально у відкритому вигляді; це не є безпечним сховищем секретів.

---

## 🔧 Ієрархія конфігурації

Тримайте окремо три поверхні конфігурації: глобальні налаштування (`azd config`), структуру проекту (`azure.yaml`) та значення для кожного середовища (`azd env`). Прапорці перевизначають лише ті налаштування, які вони справді підтримують; немає універсального накладання довільних змінних середовища на `azure.yaml` або Bicep.

## 🔐 Передові практики безпеки

```bash
# Runtime managed identity must be enabled in infrastructure and granted RBAC.
# To authenticate azd itself on an Azure host with an assigned identity:
# azd auth login --managed-identity

# Check AZD authentication status
azd auth login --check-status

# Optional: verify Azure CLI context if you plan to run az commands
az account show

# Re-authenticate if needed
azd auth login

# Optional: refresh Azure CLI authentication for az commands
az login
```
