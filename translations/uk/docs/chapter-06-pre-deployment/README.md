# Розділ 6: Планування та перевірка перед розгортанням

**📚 Курс**: [AZD Для початківців](../../README.md) | **⏱️ Тривалість**: 2-4 години читання; додатковий час для адаптованих лабораторних робіт | **⭐ Складність**: Середня–Висока

---

## Огляд

У цьому розділі розглядаються основні кроки планування та перевірки перед розгортанням вашого застосунку. Навчіться уникати дорогих помилок за допомогою правильного планування потужності, вибору SKU та перевірок перед польотом.

> Командні рекомендації перевірені за опублікованою довідкою `azd 1.37.2`. Хмарні розгортання не виконувалися. Довші уроки містять ілюстративні фрагменти, а не повні проекти локального розгортання.

## Навчальні цілі

Завершивши цей розділ, ви:
- Проведете перевірки перед розгортанням
- Сплануєте потужність і оціните потреби в ресурсах
- Виберете відповідні SKU для оптимізації витрат
- Налаштуєте Application Insights для моніторингу
- Зрозумієте шаблони координації багатьох агентів та вимоги до їх розгортання

## 🚀 Швидкий старт

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ Контрольний список перед розгортанням

### Перед `azd provision`

- [ ] Перевірка квоти для регіону
- [ ] Відповідний вибір SKU
- [ ] Перегляд оцінки вартості
- [ ] Узгодженість схем найменування
- [ ] Налаштування безпеки/RBAC

### Перед `azd deploy`

- [ ] Встановлені змінні середовища
- [ ] Секрети в Key Vault
- [ ] Перевірені рядки підключення
- [ ] Налаштовані перевірки здоров’я

## 💰 Керівництво з вибору SKU

| Навантаження | Розробка | Продукція |
|----------|-------------|------------|
| Container Apps | Споживання | Споживання або виділений профіль навантаження, залежно від виміряного навантаження |
| App Service | B1/B2 | P1v3+ |
| Моделі Azure OpenAI | Підтримуваний тип розгортання "плати за споживання" | Плата за споживання або виділена пропускна здатність; залежить від моделі/регіону |
| AI Search | Безкоштовно/Базово в межах лімітів | Базовий або Стандартний рівень, розмір залежить від індексу, копій і навантаження запитів |
