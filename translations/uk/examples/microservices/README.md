# Приклад мікросервісів

Виконувана реалізація та інструкції розміщені у
**[container-app/microservices](../container-app/microservices/README.md)**.

Цей каталог призначений лише для навігації. Тут немає `azure.yaml`, `infra/` чи `src/`.
Не запускайте `azd up` тут.

З кореня репозиторію:

```bash
cd examples/container-app/microservices
```

Далі дотримуйтесь посилання у README для вимог, розгортання, перевірки, локальної
розробки, практичних вправ, вартості та очищення.

Приклад містить API-шлюз Node.js та сервіс продуктів лише для читання на Python.
Сервіси замовлень, користувачів, сповіщень, бази даних і повідомлень є ідеями для розширення,
а не реалізаціями, включеними у цей репозиторій.

- [Наступний: Додаток бази даних](../../../../examples/database-app)
- [AI розробка](../../docs/chapter-02-ai-development/README.md)
