# Primer mikro-storitev

Izvedljiva implementacija in njena navodila so v
**[container-app/microservices](../container-app/microservices/README.md)**.

Ta imenik je samo za navigacijo. Ne vsebuje `azure.yaml`, `infra/` ali `src/`.
Ne izvajajte `azd up` tukaj.

Iz korena repozitorija:

```bash
cd examples/container-app/microservices
```

Nato sledite povezani datoteki README za predpogoje, namestitev, preverjanje, lokalni
razvoj, praktične vaje, stroške in čiščenje.

Vzorec vsebuje Node.js API Gateway in Python Product Service samo za branje.
Storitve za naročila, uporabnike, obvestila, baze podatkov in sporočanje so ideje za razširitve,
ne pa implementacije, vključene v ta repozitorij.

- [Prej: Enostaven Flask API](../../../../examples/container-app/simple-flask-api)
- [Naslednje: Aplikacija baze podatkov](../../../../examples/database-app)
- [Razvoj AI](../../docs/chapter-02-ai-development/README.md)
- [Domača stran tečaja](../../README.md)
