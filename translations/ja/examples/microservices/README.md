# マイクロサービスの例

実行可能な実装とその手順は
**[container-app/microservices](../container-app/microservices/README.md)** にあります。

このディレクトリはナビゲーション専用です。`azure.yaml`、`infra/`、または`src/`は含まれていません。
ここで`azd up`を実行しないでください。

リポジトリのルートから：

```bash
cd examples/container-app/microservices
```

その後、リンクされたREADMEに従って前提条件、展開、検証、ローカル開発、実習、費用、およびクリーンアップを行ってください。


注文、ユーザー、通知、データベース、およびメッセージングサービスは拡張のアイデアであり、
このリポジトリに含まれる実装ではありません。
