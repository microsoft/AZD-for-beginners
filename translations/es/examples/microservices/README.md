# Ejemplo de Microservicios

La implementación ejecutable y sus instrucciones están en
**[container-app/microservices](../container-app/microservices/README.md)**.

Este directorio es solo para navegación. No contiene `azure.yaml`, `infra/`, ni `src/`.
No ejecute `azd up` aquí.

Desde la raíz del repositorio:

```bash
cd examples/container-app/microservices
```

Luego, siga el README vinculado para los prerrequisitos, implementación, verificación, desarrollo local,
ejercicios prácticos, costos y limpieza.

La muestra contiene un API Gateway de Node.js y un Servicio de Producto Python de solo lectura.
Los servicios de orden, usuario, notificación, base de datos y mensajería son ideas para extender,
no implementaciones incluidas en este repositorio.
