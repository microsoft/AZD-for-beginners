# Primjer mikroservisa

Izvediva implementacija i upute nalaze se u
**[container-app/microservices](../container-app/microservices/README.md)**.

Ovaj direktorij služi samo za navigaciju. Nema `azure.yaml`, `infra/` ili `src/`.
Nemojte pokretati `azd up` ovdje.

Iz korijena repozitorija:

```bash
cd examples/container-app/microservices
```

Zatim slijedite povezani README za preduvjete, implementaciju, provjeru, lokalni
razvoj, praktične vježbe, troškove i čišćenje.

Primjer sadrži Node.js API Gateway i samo za čitanje Python Product Service.
Usluge za narudžbe, korisnike, obavijesti, baze podataka i slanje poruka su ideje za proširenje,
a ne implementacije uključene u ovaj repozitorij.

- [Prethodno: Jednostavni Flask API](../../../../examples/container-app/simple-flask-api)
- [Sljedeće: Baza podataka aplikacija](../../../../examples/database-app)
- [AI razvoj](../../docs/chapter-02-ai-development/README.md)
- [Početna stranica tečaja](../../README.md)
