# RAD za AI Programere Radionica

> Izvorne upute pregledane prema RAD 1.37.2, 4. studenog 2026. Snimke zaslona su ilustrativne; dostupnost usluge, oznake portala i zadane postavke predložaka mogu se promijeniti.

> **Trebali biste vidjeti iskačući dijalog za otvaranje stranice za pregled u pregledniku.**

Dobrodošli u praktičnu radionicu za učenje Azure Developer CLI (RAD) s fokusom na implementaciju AI aplikacija. Ova radionica pomaže vam steći primijenjeno razumijevanje RAD predložaka u 3 koraka:

1. **Otkriće** - pronađite predložak koji vam odgovara.
1. **Implementacija** - implementirajte i provjerite da radi
1. **Prilagodba** - modificirajte i iterirajte da postane vaš!

Tijekom ove radionice također ćete se upoznati s osnovnim programerskim alatima i radnim tokovima, kako biste pojednostavili vaš cjelokupni razvojni put.

## Pregled radionice

**Trajanje:** 3-4 sata  
**Razina:** Početnik do srednje napredne  
**Preduvjeti:** Poznavanje Azure, AI pojmova, VS Code i alata naredbenog retka.

Ovo je praktična radionica u kojoj učite kroz rad. Nakon što završite vježbe, preporučujemo pregled kurikuluma RAD za početnike kako biste nastavili svoje učenje o sigurnosnim i produktivnim najboljim praksama.

| Vrijeme| Modul  | Cilj |
|:---|:---|:---|
| 15 minuta | Uvod | Postaviti temelje, razumjeti ciljeve |
| 30 minuta | Odabir AI predloška | Istražiti opcije i odabrati početni |
| 30 minuta | Validacija AI predloška | Implementirati zadano rješenje u Azure |
| 30 minuta | Rastavljanje AI predloška | Pregledati strukturu i konfiguraciju |
| 30 minuta | Konfiguracija AI predloška | Aktivirati i isprobati dostupne značajke |
| 30 minuta | Prilagodba AI predloška | Prilagoditi predložak vlastitim potrebama |
| 30 minuta | Rastavljanje infrastrukture | Očistiti i osloboditi resurse |
| 15 minuta | Zaključenje i sljedeći koraci | Resursi za učenje, izazov radionice |
| | |

## Što ćete naučiti

Razmislite o RAD predlošku kao o sandboxu za učenje za istraživanje različitih mogućnosti i alata za cjelokupni razvoj na Microsoft Foundry. Nakon ove radionice trebali biste intuitivno razumjeti različite alate i koncepte u ovom kontekstu.

| Koncept  | Cilj |
|:---|:---|
| **Azure Developer CLI** | Razumjeti naredbe i radne tokove alata |
| **RAD Predlošci**| Razumjeti strukturu projekta i konfiguraciju |
| **Azure AI Agent**| Osigurajte i implementirajte Microsoft Foundry projekt  |
| **Azure AI Search**| Omogućite inženjering konteksta s agentima |
| **Observability**| Istražite praćenje, nadzor i evaluacije |
| **Red Teaming**| Istražite protivničko testiranje i ublažavanja |
| | |
