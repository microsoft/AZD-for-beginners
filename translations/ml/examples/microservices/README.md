# മൈക്രോസെർവിസുകൾ ഉദാഹരണം

പ്രവർത്തിപ്പിക്കാവുന്ന നടപ്പാക്കലും അതിന്റെ നിർദ്ദേശങ്ങളും
**[container-app/microservices](../container-app/microservices/README.md)** ൽ ഉണ്ടായിരിക്കുന്നു.

ഈ ഡയറക്ടറി സഞ്ചാരത്തിനായുള്ളതാണ് മാത്രം. ഇതിൽ `azure.yaml`, `infra/`, അല്ലെങ്കിൽ `src/` ഒന്നും ഇല്ല.
ഇവിടെ `azd up` പ്രവർത്തിപ്പിക്കരുത്.

റിപോസിറ്ററി റൂട്ടിൽ നിന്ന്:

```bash
cd examples/container-app/microservices
```

ശേഷം, മുൻകൂർ ആവശ്യകതകൾ, വിന്യസനം, സ്ഥിരീകരണം, പ്രാദേശിക
വികസനം, പ്രായോഗിക പരിശീലനങ്ങൾ, ചെലവുകൾ, ക്ലീൻഅപ്പ് എന്നിവയ്ക്കായി ലിങ്ക് ചെയ്ത README പിന്തുടരുക.

ഉദാഹരണം ഒരു Node.js API ഗേറ്റ്‌വേയും ഒരു വായനാസാധ്യതയുള്ള Python ഉൽപ്പന്ന സേവനവും ഉൾക്കൊള്ളുന്നു.
ഓർഡർ, ഉപയോക്താവ്, അറിയിപ്പ്, ഡാറ്റാബേസ്, മെസേജിംഗ് സേവനങ്ങൾ വിപുലീകരണ ആശയങ്ങളാണ്,
ഈ സംഭരണിയിലൊരു നടപ്പാക്കലുകളല്ല.
