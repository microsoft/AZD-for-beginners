# പിന്തുണ

## കോഴ്സ് പ്രശ്നങ്ങളും ചോദ്യങ്ങളും

ഒരു പ്രശ്നം റിപ്പോർട്ട് ചെയ്യുന്നതിന് മുമ്പ് [coursue issues](https://github.com/microsoft/AZD-for-beginners/issues) തിരയുക. ബാധിതമായ ഇംഗ്ലീഷ് പാഠം, നിങ്ങൾ റൺ ചെയ്ത കമാൻഡ്, നിങ്ങളുടെ AZD/വിശാരද പതിപ്പുകൾ, എറർ സന്ദേശം എന്നിവ ഉൾപ്പെടുത്തുക. ക്രെഡൻഷ്യലുകൾ, ടോക്കനുകൾ, സബ്‌സ്‌ക്രിപ്ഷൻ വിശദാംശങ്ങൾ, വ്യക്തിഗത ഡാറ്റ എന്നിവ ലോഗുകളും സ്‌ക്രീൻഷോട്ടുകളും നിന്ന് നീക്കം ചെയ്യുക.

സാധാരണ പഠന ചോദ്യങ്ങൾക്ക്, [Azure developer community](https://discord.gg/microsoft-azure) ഉപയോഗിക്കുക. സമൂഹ പ്രതികരണങ്ങൾ ഒരു ഉറപ്പുള്ള പിന്തുണ സേവനം അല്ല.

## ഉപകരണവും സേവനസംബന്ധിയായ പ്രശ്നങ്ങൾ

പുനരാവൃതമാക്കാവുന്ന AZD CLI ബഗുകൾ [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) യിൽ റിപ്പോർട്ട് ചെയ്യുക. Azure സേവന അപകടങ്ങൾക്കോ സബ്സ്ക്രിപ്ഷൻ-സ്പെസിഫിക് സഹായത്തിനോ, [Azure പോർട്ടൽ](https://portal.azure.com/) ൽ ലഭ്യമായ പിന്തുണാ ഓപ്ഷനുകൾ ഉപയോഗിക്കുക.

## സുരക്ഷാ റിപ്പോർട്ടുകൾ

സ്വകാര്യ ദുർബലതകൾ റിപ്പോർട്ട് ചെയ്യാൻ [SECURITY.md](SECURITY.md) പിന്തുടരുക. ഒരു പൊതു കോഴ്സ് പ്രശ്നത്തിൽ രഹസ്യങ്ങളോ ദുരുപയോഗ വിവരങ്ങളോ പോസ്റ്റ് ചെയ്യരുത്.

## മൈക്രോസോഫ്റ്റ് പിന്തുണാ നയം

ഈ വിദ്യാഭ്യാസ പദ്ധതിക്കുള്ള പിന്തുണ മുകളിൽ നൽകിയ വനറുകളിലേക്കാണ് പരിമിതമാക്കിയിരിക്കുന്നത്. കോഴ്സ് ഉദാഹരണങ്ങളിൽ ഉത്പാദന പിന്തുണാ പ്രതിജ്ഞ ഉൾക്കൊള്ളിട്ടില്ല.
