# AI ഡെവലപ്പർമാർക്കുള്ള AZD വർക്ക്ഷോപ്പ്

Azure Developer CLI (AZD) പഠിക്കാനുളള ഹാൻഡ്‌സോൺ വർക്ക്ഷോപ്പിലേക്ക് സ്വാഗതം, പ്രത്യേകിച്ച് AI ആപ്ലിക്കേഷൻ ഡെപ്ലോയ്മെന്റിൽ ધ્યાન കേന്ദ്രീകരിച്ചു. ഈ വർക്ക്ഷോപ്പ് AZD ടെംപ്ലേറ്റുകളുടെ പ്രായോഗികമായ ഒരു മനസ്സിലാക്കൽ 3 ഘട്ടങ്ങളിൽ സഹായിക്കുന്നു:

1. **ശോധനം** - നിങ്ങൾക്കു ശരിയായ ടെംപ്ലേറ്റ് കണ്ടെത്തുക.
1. **ഡെപ്ലോയ്മെന്റ്** - ഡെപ്ലോയ്ചെയ്ത് അത് ശരിയെന്ന് സ്ഥിരീകരിക്കുക
1. **കസ്റ്റമൈസേഷൻ** - മാറ്റം വരുത്തി നിങ്ങളുടെ പ്രോജക്ടായി മാറ്റുക!

ഈ വർക്ക്ഷോപ്പിന്റെ ഇടയിലൂടെ, കോർ ഡെവലപ്പർ ഉപകരണങ്ങളും വർക്ക് ഫ്ലോകളും പരിചയപ്പെടുകയും അന്തിമ വികസന യാത്ര എളുപ്പമാക്കുന്നതിനായുള്ള സഹായങ്ങൾ ലഭ്യമാക്കുകയും ചെയ്യും.

<br/>

## ബ്രൗസർ അടിസ്ഥാന ഗൈഡ്

വർക്ക്ഷോപ്പ് പാഠങ്ങൾ മാർക്ക്ഡൗണിൽ ആണ്. നിങ്ങൾക്ക് അതിനെ നേരിട്ടു GitHub-ൽ നവിเกറ്റ് ചെയ്യാം - അല്ലെങ്കിൽ താഴെയുള്ള സ്‌ക്രീൻഷോട്ടിൽ കാണുന്ന പോലെ ബ്രൗസർ അടിസ്ഥാന പ്രിവ്യൂ ആരംഭിക്കാം.

![വർക്ക്ഷോപ്പ്](../../../translated_images/ml/workshop.75906f133e6f8ba0.webp)

ഈ ഓപ്‌ഷൻ ഉപയോഗിക്കാൻ - റിപ്പോസിറ്ററി നിങ്ങളുടെ പ്രൊഫൈൽ തരംമാറ്റം ചെയ്യുക, GitHub Codespaces ആരംഭിക്കുക. VS Code ടെർമിനൽ സജീവമായാൽ, ഈ കമാൻഡ് ടൈപ്പ് ചെയ്യുക:

ഈ ബ്രൗസർ പ്രിവ്യൂ GitHub Codespaces, ഡെവ് കണ്ടെയ്‌നറുകൾ, അല്ലെങ്കിൽ Python, MkDocs ഇൻസ്റ്റാൾ ചെയ്ത ലോക്കൽ ക്ലോണിൽ പ്രവർത്തിക്കുന്നു.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

ഈ കമാൻഡുകൾ **കോഴ്സ് റിപ്പോസിറ്ററി റൂട്ട്**-ത്തിൽ നിന്നും പ്രവർത്തിക്കണം, പ്രത്യേകമായി തുടക്കത്തിൽ ഒരുക്കിയ AI സാമ്പിൽല്ല. പ്രിവ്യൂ മുൻപിൽ തന്നെ നിലനിര്‍ത്തുക, പിഴവുകൾ കാണാൻ; അവസാനിപ്പിക്കാൻ Ctrl+C അമർത്തുക. സൈറ്റ് സർവ് ചെയ്യാതെ പരിശോധിക്കാൻ `python -m mkdocs build --strict --config-file workshop/mkdocs.yml` പ്രവർത്തിപ്പിക്കുക.

ചില സെക്കൻഡുകൾക്കുള്ളിൽ, ഒരു പോപ്-അപ്പ് ഡയലോഗ് കാണും. `Open in browser` ഓപ്ഷൻ തിരഞ്ഞെടുക്കുക. വെബ് അധിഷ്ഠിത ഗൈഡ് പുതിയ ബ്രൗസർ ടാബിൽ തുറക്കും. ഈ പ്രിവ്യൂ ചില ഗുണങ്ങൾ:

1. **ഇടക്കാല തിരച്ചിൽ** - കീവർഡുകളോ പാഠങ്ങളോ ഉടൻ കണ്ടെത്തും.
1. **പ്രതി കോപ്പി ഐകൺ** - കോഡ് ബ്ലോക്ക് മുകളിൽ ഹോവർ ചെയ്യുമ്പോൾ കാണാം
1. **തീം മാറ്റൽ** - ഡാർക്ക്, ലൈറ്റ് തീംമുകളിൽ മാറ്റം വരുത്തുക
1. **സഹായം നേടുക** - അടിക്കുറിപ്പിലെ ഡിസ്കോർഡ് ഐകൺ ക്ലിക്ക് ചെയ്ത് ചേരുക!

## നിങ്ങൾ പഠിക്കേണ്ടത്

AZD ടെംപ്ലേറ്റിനെ Microsoft Foundry-ൽ എന്റു-ടു-എൻഡ് ഡെവലപ്പ്മെന്റ് വിശാലമായ കഴിവുകളും ഉപകരണങ്ങളും കണ്ടെത്താനുളള പഠന ബോക്സായി കരുതുക. ഈ വർക്ക്ഷോപ്പ് കഴിഞ്ഞാൽ, ഈ പശ്ചാത്തലത്തിൽ വിവിധ ഉപകരണങ്ങളുടെയും ആശയങ്ങളുടെയും സംവേദനാത്മക അറിവ് ലഭിക്കണം.

| ആശയം  | ലക്ഷ്യം |
|:---|:---|
| **Azure Developer CLI** | ഉപകരണ കമാൻഡുകളും വർക്ക് ഫ്ലോകളും മനസ്സിലാക്കുക |
| **AZD ടെംപ്ലേറ്റുകൾ**| പ്രോജക്ട് ഘടനയും കോൺഫിഗറേഷനും മനസ്സിലാക്കുക |
| **Azure AI ഏജന്റ്**| Microsoft Foundry പ്രോജക്ട് പ്രൊവിഷൻ & ഡെപ്ലോയ് ചെയ്യുക |
| **Azure AI സെർച്ച്**| ഏജന്റുകളിലൂടെ സന്ദർഭ എൻജിനീയറിംഗ് സജ്ജമാക്കുക |
| **ഓബ്സർവബിലിറ്റി**| ട്രേസിംഗ്, നിരീക്ഷണം, മൂല്യനിർണ്ണയം അന്വേഷിക്കുക |
| **റെഡ് ടീം**| എതിര്‍പ്പിലെ പരീക്ഷണവും തടസ്സങ്ങൾ ഒന്നിച്ച് പഠിക്കുക |

- പരീക്ഷിക്കുക: ട്രേസിംഗ് & നിരീക്ഷണം
- **ലാബ്**: AI ഏജന്റ് + ഓബ്സർവബിലിറ്റി പരിശോധിക്കുക

### [മോഡ്യൂൾ 5: AI ടെംപ്ലേറ്റ് കസ്റ്റമൈസ് ചെയ്യൽ](docs/instructions/5-Customize-AI-Template.md) (30 മിനിറ്റ്)
- നിർവചിക്കുക: സന്നാഹം ആവശ്യകതകളുള്ള PRD
- കോൺഫിഗർ ചെയ്യുക: AZD-യ്ക്ക് പരിസ്ഥിതി വേരിയബിളുകൾ
- നടപ്പിലാക്കുക: കൂടി ജോലികൾക്കുള്ള ലൈഫ്‌സൈക്കിൾ ഹുക്കുകൾ
- **ലാബ്**: എന്റെ സന്നാഹത്തിന് പരിശോധനിച്ച് ടെംപ്ലേറ്റ് കസ്റ്റമൈസ് ചെയ്യുക

### [മോഡ്യൂൾ 6: ഇൻഫ്രാസ്ട്രക്ചർ അഴിച്ചേൽപ്പ്](docs/instructions/6-Teardown-Infrastructure.md) (30 മിനിറ്റ്)

- അടുത്ത ഘട്ടങ്ങൾ: വേറെ ടെംപ്ലേറ്റ് പരീക്ഷിക്കുക!
- **ലാബ്**: ഇൻഫ്രാസ്ട്രക്ചർ ഡിപ്രൊവിഷൻ & ക്ലീൻ അപ്പ്
