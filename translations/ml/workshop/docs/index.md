# AI വികസിപ്പിക്കുന്നുൾക്ക് AZD വർക്ശോപ്പ്

> ഉറവിട നിർദ്ദേശങ്ങൾ 2026 നവംബർ 4-ന് AZD 1.37.2-നെ അടിസ്ഥാനമാക്കി പരിശോധിച്ചതാണ്. സ്ക്രീൻഷോട്ടുകൾ ഉദാഹരണാർത്ഥമാണ്; സേവന ലഭ്യത, പോർട്ടൽ ലേബലുകൾ, ടെംപ്ലേറ്റ് ഡീഫോൾട്ടുകൾ മാറാം.

> [!IMPORTANT]  
> **ഈ വർക്ശോപ്പ് ഒരു വർക്ശോപ്പ് ഗൈഡോടെ സജ്ജമാക്കിയതാണ്, ഇത് നിങ്ങളുടെ പ്രാദേശിക ബ്രൗസറിൽ പ്രിവ്യൂ ചെയ്യാവുന്നതാണ്. തുടങ്ങാൻ, GitHub Codespaces, dev container, അല്ലെങ്കിൽ MkDocs ഇൻസ്റ്റാൾ ചെയ്ത പ്രാദേശിക ക്ലോൺ ഉപയോഗിച്ച് റെപ്പോ തുറക്കുക—ശേഷം സജീവമായ VS Code ടെർമിനൽ കാണുന്ന വരെ കാത്തിരിക്കുക, പിന്നെ ടൈപ്പ് ചെയ്യുക:**  
> കോഴ്‌സ് റെപ്പോയുടെ മുളശ്ശേരിപാടിൽ നിന്ന്, `requirements-dev.txt` ഇൻസ്റ്റാൾ ചെയ്യുക, പിന്നീട് `python -m mkdocs serve --config-file workshop/mkdocs.yml` ഫോറെഗ്രൗണ്ടിൽ പ്രവർത്തിപ്പിക്കുക.
> **ബ്രൗസറിൽ പ്രിവ്യൂ പേജ് തുറക്കാൻ ഒരു പോപ്പ്-അപ്പ് ഡയലോഗ് കാണണം.**

AI ആപ്ലിക്കേഷൻ വിന്യതിയിൽ കേന്ദ്രീകരിച്ച് Azure Developer CLI (AZD) പഠിക്കാൻ കൈകാര്യം ചെയ്യുന്ന വർക്ശോപ്പിലേക്ക് സ്വാഗതം. ഈ വർക്ശോപ്പ് നിങ്ങൾക്ക് AZD ടെംപ്ലേറ്റുകൾ പ്രായോഗികമായി മനസ്സിലാക്കാൻ 3 ഘട്ടങ്ങളിൽ സഹായിക്കും:

1. **ഡിസ്കവറി** - നിങ്ങളുടെ ആവശ്യത്തിന് അനുയോജ്യമായ ടെംപ്ലേറ്റ് കണ്ടെത്തുക.
1. **വിന്യാസം** - വിന്യസിച്ച് പ്രവർത്തിക്കുന്നതായി സ്ഥിരീകരിക്കുക.
1. **അനുകൂലനം** - മാറ്റങ്ങൾ വരുത്തി അവരുടെ രൂപത്തിൽ മാറ്റങ്ങൾ കൊണ്ടുവരുക!

ഈ വർക്ശോപ്പിനിടെ, കോർ ഡെവലപ്പർ ഉപകരണങ്ങളും പ്രവാഹങ്ങളും പരിചയപ്പെടും, നിങ്ങളുടെ ആകെ വികസന യാത്ര സുഗമമാക്കാൻ സഹായിക്കാൻ.

## നിങ്ങൾ പഠിക്കുന്നത്

AZD ടെംപ്ലേറ്റ് Microsoft Foundry-യിലെ ആകെ വികസനത്തിനായുള്ള വിവിധ കഴിവുകളും ഉപകരണങ്ങളും പഠിക്കാൻ ഒരു sandbox ആയി കരുതുക. ഈ വർക്ശോപ്പ് അവസാനിപ്പിക്കുമ്പോൾ, നിങ്ങൾക്ക് ഈ സാഹചര്യത്തിൽ വിവിധ ഉപകരണങ്ങൾക്കും ആശയങ്ങൾക്കും ആന്തരംഗ ജ്ഞാനം ഉണ്ടായിരിക്കണം.

| ആശയം  | ലക്ഷ്യം |
|:---|:---|
| **Azure Developer CLI** | ഉപകരണ കമാൻഡുകളും പ്രവാഹങ്ങളും മനസിലാക്കുക|
| **AZD ടെംപ്ലേറ്റുകൾ**| പ്രോജക്ട് ഘടനയും ക്രമീകരണവും മനസിലാക്കുക|
| **Azure AI ഏജന്റ്**| Microsoft Foundry പ്രോജക്ട് വിന്യസിക്കുക & വിന്യസിക്കുക  |
| **Azure AI Search**| ഏജന്റുകളുമായി കോൺടെക്സ്റ്റ് എഞ്ചിനീയറിംഗ് സജ്ജമാക്കുക |
| **ഒബ്സർവബിലിറ്റി**| ട്രേസിംഗ്, നിരീക്ഷണം, വിലയിരുത്തലുകൾ പരിശോധിക്കുക |
| **റെഡ് ടീം**| ആഡ്വേഴ്സറിയൽ ടെസ്റ്റിംഗ്, പരിഹാരങ്ങൾ പരീക്ഷിക്കുക |
| | |
