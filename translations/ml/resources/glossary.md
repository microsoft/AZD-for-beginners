- **🤖 AI പദങ്ങൾ**: [Chapter 2: AI-First Development](../docs/chapter-02-ai-development/microsoft-foundry-integration.md)

## പരിചയം

ആസ്യൂർ ഡെവലപ്പർ CLI ഉം ആസ്യൂർ ക്ലൗഡ് ഡെവലപ്മെന്റിലും ഉപയോഗിക്കുന്ന പദങ്ങൾ, ആശയങ്ങൾ, ശരീരം (അക്രോണിമുകൾ) എന്നിവയുടെ നിർവചനങ്ങൾ നൽകുന്ന സമഗ്രമായ വാക്ക് നിർവചനമാണ് ഇത്. സാങ്കേതിക രേഖകൾ ഗ്രഹിക്കാൻ, പ്രശ്‌നപരിഹാരം നടത്താൻ, azd പ്രോജക്ടുകളും ആസ്യൂർ സർവീസുകളും സംബന്ധിച്ച് ഫലപ്രദമായി ആശയവിനിമയം നടത്തുന്നതിനും അത്യവശ്യ പരാമർശമാണ്.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ വാക്ക് നിർവചന ഉപയോഗിച്ച്, നിങ്ങൾ നേടാൻ കഴിയുന്നത്:
- പ്രധാനപ്പെട്ട Azure Developer CLI പദംശാസ്ത്രവും ആശയങ്ങളും മനസ്സിലാക്കുക
- Azure ക്ലൗഡ് ഡെവലപ്മെന്റ് വാക്ക്ഭണ്ഡാരവും സാങ്കേതിക പദശേഖരവും കൈവരിക്കുക
- Infrastructure as Code (IaC) ഉം ഡിപ്ലോയ്മെന്റ് പദങ്ങൾ കാര്യക്ഷമമായി പരാമർശിക്കുക
- Azure സർവീസുകൾ, അവയുടെ പേരുകൾ, ശരീരങ്ങൾ, ആവശ്യങ്ങൾ മനസ്സിലാക്കുക
- പ്രശ്‌നപരിഹാരത്തിനും ഡീബഗിംഗിനും വേണ്ട പദങ്ങൾ നിർവചനം ലഭിക്കുക
- ആസ്യൂർ ആർക്കിടെക്ചറും ഡെവലപ്മെന്റ് ആശയങ്ങളും ആയി അഗാധമായി പഠിക്കുക

## പഠന ഫലം

ഈ വാക്ക് നിർവചന ചുവടെ പതിവായി പരിശോധിച്ച് നിങ്ങൾക്ക്:
- ശരിയായ Azure Developer CLI പദങ്ങൾ ഉപയോഗിച്ച് ഫലപ്രദമായി ആശയവിനിമയം നടത്താൻ കഴിയും
- സാങ്കേതിക രേഖകളും പിഴവു സന്ദേശങ്ങളും കൂടുതൽ വ്യക്തമായും മനസ്സിലാക്കാം
- Azure സർവീസുകളും ആശയങ്ങളും ആത്മവിശ്വാസത്തോടെ പരിചയപ്പെടാം
- അനുയോജ്യമായ സാങ്കേതിക ശബ്ദഷേഷം ഉപയോഗിച്ചു പ്രശ്‌നങ്ങൾ പരിഹരിക്കാം
- കൃത്യമായ സാങ്കേതിക ഭാഷയിൽ ടീം ചര്‍ച്ചകളിൽ പങ്കാളിയാകാം
- ക്രമക്രമമായി Azure ക്ലൗഡ് ഡെവലപ്മെന്റ് അറിവ് വർദ്ധിപ്പിക്കാം

## A

**ARM ടെംപ്ലേറ്റ്**  
Azure Resource Manager ടെംപ്ലേറ്റ്. JSON അടിസ്ഥാനത്തിലുള്ള Infrastructure as Code ഫോർമാറ്റ്, ആസ്യൂർ വിഭവങ്ങൾ നിർവചിച്ച് പ്രഖ്യാപനപരമായി ഡിപ്ലോയ് ചെയ്യാൻ ഉപയോഗിക്കുന്നതാണ്.

**App Service**  
വെബ് ആപ്ളിക്കേഷനുകൾ, REST API-കൾ, മൊബൈൽ ബാക്ക്‌എൻഡുകൾ ഹോസ്റ്റ് ചെയ്യുന്നതിനുള്ള ആസ്യൂറിന്റെ പ്ലാറ്റ്ഫോം-ആസ്-എ-സർവീസ് (PaaS) ഓഫറിംഗ്, ഇത് ഇൻഫ്രാസ്ട്രക്ചർ മാനേജുചെയ്യാതെ ഉപയോഗിക്കാം.

**Application Insights**  
ആസ്യൂറിന്റെ ആപ്ലിക്കേഷൻ പ്രകടനം നിരീക്ഷണ (APM) സേവനം, ആപ്ലിക്കേഷൻ പ്രകടനം, ലഭ്യത, ഉപയോഗം എന്നിവയിൽ ആഴത്തിലുള്ള洞察ങ്ങൾ നൽകുന്നു.

**Azure CLI**  
ആസ്യൂർ വിഭവങ്ങളെ നിയന്ത്രിക്കുന്ന കമാൻഡ്-ലൈൻ ഇന്റർഫേസ്. ഇത് AZD-നു പൂരകമാണ് പക്ഷേ വേർതിരിതമായ ലോഗിൻ ആവശ്യമാണ്; AZD-ന്റെ പ്രധാന സ്ഥിരീകരണം `azd auth login` ആണ്.

**Azure Developer CLI (azd)**  
ടെംപ്ലേറ്റുകളും Infrastructure as Code ആശയങ്ങളും ഉപയോഗിച്ചു ആസ്യൂറിൽ ആപ്ലിക്കേഷൻ നിർമ്മാണവും ഡിപ്ലോയ്മെന്റും വേഗത്തിലും എളുപ്പത്തിലും നടത്താൻ സഹായിക്കുന്ന ഡെവലപ്പർമൈൻഡ് കമാൻഡ്-ലൈൻ ടൂൾ.

**azure.yaml**  
ഒരു azd പ്രോജക്ടിന്റെ പ്രധാന കോൺഫിഗറേഷൻ ഫയൽ, സേവനങ്ങളും ഇൻഫ്രാസ്ട്രക്ചറും ഡിപ്ലോയ്മെന്റ് ഹുക്കുകളും നിർവചിക്കുന്നു.

**Azure Resource Manager (ARM)**  
ആസ്യൂറിന്റെ ഡിപ്ലോയ്മെന്റ്, മാനേജ്മെന്റ് സേവനം, വിഭവങ്ങൾ സൃഷ്ടിക്കാൻ, പുതുക്കാൻ, ഇല്ലാതാക്കാൻ മാനേജ്മെന്റ് ലെയർ നൽകുന്നു.

## B

**Bicep**  
Azure വിഭവങ്ങൾ ഡിപ്ലോയ് ചെയ്യാൻ മൈക്രോസോഫ്റ്റ് വികസിപ്പിച്ച ഡൊമെയ്ൻ-സ്പെസിഫിക് ലാംഗ്വേജ് (DSL). ARM ടെംപ്ലേറ്റുകളേക്കാൾ ലളിതമായ സിന്‌റ്റാക്സ് നൽകുന്നു, ഇന്നും ARM-ലേക്ക് കംപൈൽ ചെയ്യുന്നു.

**Build**  
സോഴ്‌സ് കോഡ് കംപൈൽ ചെയ്യുക, ആശ്രിതകൾ ഇൻസ്റ്റാൾ ചെയ്യുക, ആപ്ലിക്കേഷനുകൾ ഡിപ്ലോയ്മെന്റിനായി തയ്യാറാക്കുക എന്ന പ്രക്രിയ.

**Blue-Green Deployment**  
രണ്ട് ഒരുപോലെ ഉള്ള പ്രൊഡക്ഷൻ എൻവയോൺമെന്റുകൾ (നീലവും പച്ചയും) ഉപയോഗിച്ച് ഡൗൺടൈം കുറയ്ക്കുകയും അപകടം കുറക്കുകയും ചെയ്യുന്ന ഡിപ്ലോയ്മെന്റ് രീതി.

## C

**Container Apps**  
ഇൻഫ്രാസ്ട്രക്ചർ മാനേജ്മെന്റ് ഇല്ലാതെ കണ്ടെയ്‌നറൈസ്ഡ് ആപ്ളിക്കേഷൻ പ്രവർത്തിപ്പിക്കാൻ ആസ്യൂറിന്റെ സെർവർലെസ് കണ്ടെയ്‌നർ സേവനം.

**CI/CD**  
Continuous Integration/Continuous Deployment. കോഡ് മാറ്റങ്ങൾ ഇന്റഗ്രേറ്റ് ചെയ്ത് ആപ്ലിക്കേഷനുകൾ ഡീപ്ലോയ് ചെയ്യുന്ന ഓട്ടോമേറ്റഡ് പ്രാഥമികപരമായ പ്രവൃത്തികൾ.

**Cosmos DB**  
ആസ്യൂറിന്റെ ആഗോളവ്യാപകതയുള്ള, മൾട്ടി-മോഡൽ ഡാറ്റാബേസ് സേവനം, throughput, latency, ലഭ്യത, സാങ്കേതിക നിലനിൽപ്പ് എന്നിവയുടെ സമഗ്ര SLA-കൾ നൽകുന്നു.

**Configuration**  
ആപ്ലിക്കേഷൻ പെരുമാറ്റവും ഡിപ്ലോയ്മെന്റ് ഓപ്ഷനുകളും നിയന്ത്രിക്കുന്ന ക്രമീകരണങ്ങളും പാരാമീറ്ററുകളും.

## D

**Deployment**  
ടാർഗറ്റ് ഇൻഫ്രാസ്ട്രക്ചറിൽ ആപ്ലിക്കേഷനുകളും അവയുടെ ആശ്രിതങ്ങളും ഇൻസ്റ്റാൾ, ക്രമീകരിക്കുന്ന പ്രക്രിയ.

**Docker**  
കണ്ടെയ്‌നറൈസേഷൻ സാങ്കേതികവിദ്യ ഉപയോഗിച്ച് ആപ്ലിക്കേഷനുകൾ വികസിപ്പിച്ച്, ഷിപ്പുചെയ്യുകയും ഓടിക്കുകയുമുള്ള പ്ലാറ്റ്ഫോം.

**Dockerfile**  
Docker കണ്ടെയ്‌നർ ഇമേജ് നിർമ്മിക്കാൻ നിർദ്ദേശങ്ങൾ ഉൾപ്പെടുത്തിയ ടെക്സ്റ്റ് ഫയൽ.

## E

**Environment**  
നിങ്ങളുടെ ആപ്ലിക്കേഷന്റെ ഒരു പ്രത്യേക ഇൻസ്റ്റൻസ് പ്രതിനിധാനം ചെയ്യുന്ന ഡിപ്ലോയ്മെന്റ് ലക്ഷ്യം (ഉദാ. ഡെവലപ്മെന്റ്, സ്റ്റേജിംഗ്, പ്രൊഡക്ഷൻ).

**Environment Variables**  
പ്രവർത്തനസമയത്ത് ആപ്ലിക്കേഷൻ ആക്സസ് ചെയ്യാവുന്ന, കീ-വാല്യു ജോഡികളായി സൂക്ഷിക്കുന്ന ക്രമീകരണ മൂല്യങ്ങൾ.

**Endpoint**  
ഒരു ആപ്ലിക്കേഷനും സർവീസും ആക്സസ് ചെയ്യാൻ കഴിയുന്ന URL അല്ലെങ്കിൽ നെറ്റ്‌വർക്ക് വിലാസം.

## F

**Function App**  
ഇൻഫ്രാസ്ട്രക്ചർ മാനേജുചെയ്യാതെ ഇവന്റ്-ഡ്രിവൻ കോഡ് ഓടിക്കാൻ ആസ്യൂറിന്റെ സെർവർലെസ് കംപ്യൂട്ട് സേവനം.

## G

**GitHub Actions**  
GitHub റിപോസിറ്ററികളുമായി സംയോജിതമായ CI/CD പ്ലാറ്റ്ഫോം, പ്രവൃത്തിവഴികൾ ഓട്ടോമേറ്റുചെയ്യാൻ.

**Git**  
സോഴ്‌സ് കോഡിലെ മാറ്റങ്ങൾ ട്രാക്ക് ചെയ്യാൻ ഉപയോഗിക്കുന്ന വിതിരിഞ്ഞ വേർഷൻ നിയന്ത്രണ സംവിധാനം.

## H

**Hooks**  
ഡിപ്ലോയ്മെന്റ് ലൈഫ്സൈക്കിൾ中特定 ഉണ്ടായിരിക്കുന്ന (preprovision, postprovision, predeploy, postdeploy) സമയങ്ങളിൽ പ്രവർത്തിക്കുന്ന സ്വകാര്യ സ്ക്രിപ്റ്റുകൾ അല്ലെങ്കിൽ കമാൻഡുകൾ.

**Host**  
ആപ്ലിക്കേഷൻ ഡിപ്ലോയ് ചെയ്യാനുള്ള ആസ്യൂർ സർവീസ് തരം (ഉദാ. appservice, containerapp, function).

## I

**Infrastructure as Code (IaC)**  
മാനുവൽ പ്രക്രിയകളിന് പകരം കോഡ് വഴി ഇൻഫ്രാസ്ട്രക്ചർ നിർവചിച്ച്, മാനേജ്ജുചെയ്യുന്ന പ്രയോഗം.

**Init**  
സാധാരണയായി ഒരു ടെംപ്ലേറ്റ് മുതൽ പുതിയത് ആയ azd പ്രോജക്ട് ആരംഭിപ്പിക്കുന്ന പ്രക്രിയ.

## J

**JSON**  
JavaScript Object Notation. കോൺഫിഗറേഷൻ ഫയലുകളും API പ്രതികരണങ്ങളും സാധാരണയായി ഉപയോഗിക്കുന്ന ഡാറ്റാ ഇന്റർചേഞ്ച് ഫോർമാറ്റ്.

**JWT**  
JSON Web Token. JSON ഒബ്‌ജക്റ്റായിട്ട് സുരക്ഷിതമായി വിവരങ്ങൾ കൈമാറാനുള്ള സ്റ്റാൻഡേർഡ്.

## K

**Key Vault**  
രഹസ്യങ്ങളെയും കീകളെയും സർട്ടിഫിക്കറ്റുകളെയും സുരക്ഷിതമായി സൂക്ഷിച്ച് മാനേജുചെയ്യാൻ Azure-യുടെ സേവനം.

**Kusto Query Language (KQL)**  
Azure Monitor, Application Insights തുടങ്ങിയ Azure സേവനങ്ങളിൽ ഡാറ്റ വിശകലനത്തിനായി ഉപയോഗിക്കുന്ന ക്വേരി ലാംഗ്വേജ്.

## L

**Load Balancer**  
പല സര്‍വറുകൾക്കും ഇൻകമ്മിംഗ് നെറ്റ്‌വർക്ക് ട്രാഫിക് വിതരണത്തിനായി ഉപയോഗിക്കുന്ന സേവനം.

**Log Analytics**  
ക്ലൗഡിലും ഓൺ-പ്രെമൈസസ് എൻവയോൺമെന്റുകളിലുണ്ടാകുന്ന ടെലിമെട്രി ഡാറ്റാ ശേഖരിച്ച്, വിശകലനം ചെയ്ത് പ്രവർത്തനങ്ങൾ കൈക്കൊള്ളുന്ന Azure സേവനം.

## M

**Managed Identity**  
മറ്റ് Azure സേവനങ്ങൾക്കു‍ളിൽ സ്വയം മാനേജുചെയ്യപ്പെടുന്ന സാന്നിധ്യം (ഐഡന്റിറ്റി), തിരിച്ചറിയൽ പ്രവർത്തനങ്ങൾക്കായി Azure നൽകുന്ന ഫീച്ചർ.

**Microservices**  
ആപ്ലിക്കേഷനുകൾ ചെറിയ, സ്വതന്ത്ര സേവനങ്ങളുടെ സമാഹാരമായി നിർമ്മിക്കുന്ന ആർക്കിടെക്ചറൽ സമീപനം.

**Monitor**  
ആസ്യൂറിന്റെ ഐക്യപ്പെടുത്തിയ നിരീക്ഷണ പരിഹാരം, ആപ്ലിക്കേഷനുകളുടെയും ഇൻഫ്രാസ്ട്രക്ചറിനും മുഴുവൻ അവബോധം നൽകുന്നു.

## N

**Node.js**  
ക്രോം V8 ജാവാസ്ക്രിപ്റ്റ് എൻജിനിൽ നിർമ്മിച്ച, സെർവർ-സൈഡ് ആപ്ലിക്കേഷനുകൾ പാട്രിച്ച് നിർമ്മിക്കുന്നതിനുള്ള ജാവാസ്ക്രിപ്റ്റ് റൺടൈം.

**npm**  
Node.js-ന്റെ പാക്കേജ് മാനേജർ, ആശ്രിതകളും പാക്കേജുകളും കൈകാര്യം ചെയ്യുന്നു.

## O

**Output**  
ഇൻഫ്രാസ്ട്രക്ചർ ഡിപ്ലോയ്മെന്റിൽ നിന്നും ലഭിക്കുന്ന മൂല്യങ്ങൾ, ആപ്ലിക്കേഷനുകൾക്കും മറ്റ് വിഭവങ്ങൾക്കും ഉപയോഗിക്കാവുന്നതാണ്.

## P

**Package**  
ആപ്ലിക്കേഷൻ കോഡ്, ആശ്രിതങ്ങൾ എന്നിവ ഡിപ്ലോയ്മെന്റിനായി തയ്യാറാക്കുന്ന പ്രക്രിയ.

**Parameters**  
ഇൻഫ്രാസ്ട്രക്ചർ ടെംപ്ലേറ്റുകൾക്ക് കസ്റ്റമൈസ് ചെയ്യാനായി നൽകുന്ന ഇൻപുട്ട് മൂല്യങ്ങൾ.

**PostgreSQL**  
ഓപ്പൺ സോഴ്‌സ് റിലേഷണൽ ഡാറ്റാബേസ് സിസ്റ്റം, ആസ്യൂറിൽ മാനേജുചെയ്യപ്പെടുന്ന സേവനമായി പിന്തുണയ്ക്കപ്പെടുന്നു.

**Provisioning**  
ഇൻഫ്രാസ്ട്രക്ചർ ടെംപ്ലേറ്റുകളിൽ നിർവചിച്ച ആസ്യൂർ വിഭവങ്ങൾ സൃഷ്ടിച്ച് ക്രമീകരിക്കുന്ന പ്രക്രിയ.

## Q

**Quota**  
ആസ്യൂർ സബ്സ്ക്രിപ്ഷനിൽ അല്ലെങ്കിൽ പ്രദേശത്ത് സൃഷ്ടിക്കാവുന്ന വിഭവങ്ങളുടെ പരിമിതികൾ.

## R

**Resource Group**  
ഒരേ ജീവിതചക്രവും, അനുമതികളും, നയങ്ങളും പങ്ക് വയ്ക്കുന്ന Azure വിഭവങ്ങൾക്ക് ഗുണമായ ലാജിക്കൽ കണ്ടെയിനർ.

**Resource Token**  
azd پاران ഉണ്ടാക്കുന്ന അത്യുതകstring, വിഭവങ്ങളുടെ പേരുകൾ വിന്യാസങ്ങളിൽ വ്യത്യസ്തമാക്കാൻ.

**REST API**  
HTTP മെത്തഡുകൾ ഉപയോഗിച്ച് നെറ്റ്‌വർക്ക് ആപ്ലിക്കേഷനുകൾ ഡിസൈൻ ചെയ്യുന്നതിനുള്ള ആർക്കിടെക്ചറൽ ശൈലി.

**Rollback**  
ആപ്ലിക്കേഷൻ അല്ലെങ്കിൽ ഇൻഫ്രാസ്ട്രക്ചർ ക്രമീകരണത്തിന്റെ മുമ്പത്തെ പതിപ്പിലേക്ക് തിരിച്ചെത്തുന്ന പ്രക്രിയ.

## S

**Service**  
azure.yaml-ൽ നിർവചിച്ച നിങ്ങളുടെ ആപ്ലിക്കേഷന്റെ ഘടകങ്ങൾ (ഉദാ. വെബ് ഫ്രണ്ട്‌എൻഡ്, API ബാക്ക്‌എൻഡ്, ഡാറ്റാബേസ്).

**SKU**  
സ്റ്റോക്ക് കീപിങ് യൂണിറ്റ്. Azure വിഭവങ്ങൾക്ക് വ്യത്യസ്ത സേവന തിയറുകളോ പ്രകടന നിലകളോ പ്രതിനിധീകരിക്കുന്നു.

**SQL Database**  
മൈക്രോസോഫ്റ്റ് SQL സെർവറിൽ അടിസ്ഥാനമാക്കിയുള്ള Azure മാനേജുചെയ്യുന്ന റിലേഷണൽ ഡാറ്റാബേസ് സേവനം.

**Static Web Apps**  
സോഴ്‌സ് കോഡ് റിപോസിറ്ററികളിൽ നിന്ന് പൂർണ്ണ-സ്റ്റാക്ക് വെബ് ആപ്ലിക്കേഷനുകൾ ഉണ്ടാക്കാനും ഡിപ്ലോയ് ചെയ്യാനും Azure സേവനം.

**Storage Account**  
ബ്ളോബുകൾ, ഫയലുകൾ, ക്യൂകൾ, ടേബിളുകൾ ഉൾപ്പെടെയുള്ള ഡാറ്റാ ഒബ്‌ജക്ടുകളുടെ ക്ലൗഡ് സംഭരണം നൽകുന്ന Azure സേവനം.

**Subscription**  
Azure അക്കൗണ്ട് കണ്ടെയിനർ, വിഭവകൂട്ടുകളും വിഭവങ്ങളും, ബില്ലിംഗ്, ആക്സസ് മാനേജ്മെന്റ് എന്നിവയുമായി.

## T

**Template**  
சாதാരണ പരിസരങ്ങളിലായുള്ള ആപ്ലിക്കേഷൻ കോഡ്, ഇൻഫ്രാസ്ട്രക്ചർ നിർവചനങ്ങൾ, കോൺഫിഗറേഷൻ ഉൾപ്പെടുത്തിയ മുൻകൂട്ടി നിർമ്മിച്ച പ്രോജക്ട് ഘടന.

**Terraform**  
ബഹുസ്വര ക്ലൗഡ് പ്രൊവൈഡറുകളെ പിന്തുണയ്ക്കുന്ന തുറന്ന സ്രോതസ്സായ Infrastructure as Code ഉപകരണം.

**Traffic Manager**  
ആഗോള Azure പ്രദേശങ്ങളിൽ ട്രാഫിക് വിതർക്കാൻ DNS അടിസ്ഥാനമാക്കിയുള്ള Azure ട്രാഫിക് ലോഡ് ബാലൻസർ.

## U

**URI**  
Uniform Resource Identifier. പ്രത്യേക വിഭവം തിരിച്ചറിയുന്ന ഒരു സ്‌ട്രിംഗ്.

**URL**  
Uniform Resource Locator. ഒരു വിഭവം എവിടെയാണെന്ന് വ്യക്തമാക്കുകയും എങ്ങനെ ലഭ്യമാക്കാമെന്നും നിർദേശിക്കുന്ന URI തരം.

## V

**Virtual Network (VNet)**  
Azure-യിൽ വ്യക്തിഗത നെറ്റ്‌വർക്കുകൾക്ക് അടിസ്ഥാന ഘടകം, ഐസൊലേഷൻ, വിഭാഗീകരണം നൽകുന്നു.

**VS Code**  
Visual Studio Code. Azure ഉം azd ഉം മികച്ച സംയോജനം ഉള്ള ജനപ്രിയ കോഡ് എഡിറ്റർ.

## W

**Webhook**  
പ്രത്യേക ഇവന്റുകളാൽ ട്രിഗർ ചെയ്യുന്ന HTTP കോൾബാക്ക്, സാധാരണയായി CI/CD പൈപ്പ്‌ലൈനുകളിൽ ഉപയോഗിക്കുന്നു.

**What-if**  
ഒരു ഡിപ്ലോയ്മെന്റ് പ്രവർത്തിപ്പിക്കാതെ എത്ര മാറ്റം വരുമെന്ന് ദർശിപ്പിക്കുന്ന Azure ഫീച്ചർ.

## Y

**YAML**  
YAML Ain't Markup Language. human-readable ഡാറ്റാ സീരിയലൈസേഷൻ സ്റ്റാൻഡേർഡ്‌ azure.yaml പോലുള്ള കോൺഫിഗറേഷൻ ഫയലുകൾക്കായി.

## Z

**Zone**  
ഒരു Azure പ്രദേശത്തിനുള്ളിൽ ഫിസിക്കൽ ആയി വേർതിരിച്ചിട്ടുള്ള ലൊക്കേഷനുകൾ, പുനരാവർത്തനവും ഉയർന്ന ലഭ്യതയും നൽകുന്നു.

## സാധാരണ ശരീരം (അക്രോണിമുകൾ)

| API | Application Programming Interface | സോഫ്റ്റ്‌വെയർ നിർമ്മിക്കുന്ന പ്രോട്ടോകോളുകളുടെ സെറ്റ് |
| ARM | Azure Resource Manager | ആസ്യൂറിന്റെ ഡിപ്ലോയ്മെന്റ്, മാനേജ്മെന്റ് സേവനം |
| CDN | Content Delivery Network | വിതരണം ചെയ്ത സർവർ നെറ്റ്‌വർക്ക് |
| CI/CD | Continuous Integration/Continuous Deployment | ഓട്ടോമേറ്റഡ് ഡെവലപ്‌മെന്റ് പ്രവർത്തികൾ |
| CLI | Command Line Interface | ടെക്സ്റ്റ് അടിസ്ഥാനത്തിലുള്ള ഉപയോക്തൃ ഇന്റർഫേസ് |
| DNS | Domain Name System | ഡൊമെയ്ൻ നാമങ്ങൾ IP വിലാസങ്ങളിൽ പരിഭാഷപ്പെടുത്തുന്ന സംവിധാനം |
| HTTPS | Hypertext Transfer Protocol Secure | HTTP-ന്റെ സുരക്ഷിത പതിപ്പ് |
| IaC | Infrastructure as Code | കോഡ് മുഖാന്തിരം ഇൻഫ്രാസ്ട്രക്ചർ നിയന്ത്രണം |
| JSON | JavaScript Object Notation | ഡാറ്റാ ഇന്റർചേഞ്ച് ഫോർമാറ്റ് |
| JWT | JSON Web Token | സുരക്ഷിതമായി വിവരങ്ങൾ കൈമാറാനുള്ള ടോക്കൺ ഫോർമാറ്റ് |
| KQL | Kusto Query Language | Azure ഡാറ്റ സേവനങ്ങൾക്ക് ക്വേരി ഭാഷ |
| RBAC | Role-Based Access Control | ഉപഭോക്തൃ പങ്ക് അടിസ്ഥാനമാക്കിയുള്ള ആക്സസ് നിയന്ത്രണം |
| REST | Representational State Transfer | വെബ് സേവനങ്ങൾക്ക് ആർക്കിടെക്ചറൽ ശൈലി |
| SDK | Software Development Kit | വികസന ഉപകരണങ്ങളുടെ പരമ്പര |
| SLA | Service Level Agreement | സേവന ലഭ്യത/പ്രകടന പ്രതിജ്ഞ |
| SQL | Structured Query Language | റിലേഷണൽ ഡാറ്റാബേസ് മാനേജ്മെന്റ് ഭാഷ |
| SSL/TLS | Secure Sockets Layer/Transport Layer Security | ക്രിപ്‌റ്റോഗ്രാഫിക് പ്രോട്ടോകോളുകൾ |
| URI | Uniform Resource Identifier | വിഭവം തിരിച്ചറിയുന്ന സ്ട്രിംഗ് |
| URL | Uniform Resource Locator | വിഭവം എവിടെ ഉള്ളതും എങ്ങനെ നേടുവുന്നതും വ്യക്തമാക്കുന്ന URI തരം |
| VM | Virtual Machine | കമ്പ്യൂട്ടർ സിസ്റ്റത്തിന്റെ എമുലേഷൻ |
| VNet | Virtual Network | Azureയിലെ സ്വകാര്യ നെറ്റ്‌വർക്ക് |
| YAML | YAML Ain't Markup Language | ഡാറ്റാ സീരിയലൈസേഷൻ സ്റ്റാൻഡേർഡ് |

| Cache | Azure Managed Redis | ഇന്‍ഫ്രാസ്ട്രക്ചർ വിഭവം, ഒരു ആപ്ലിക്കേഷൻ അല്ല `host` |

`services.<name>.host` ഒരു ആപ്ലിക്കേഷൻ ഡിപ്ലോയ്മെന്റ് ലക്ഷ്യം തിരഞ്ഞെടുത്താണ്; ഇത് യാതൊരു Azure വിഭവ തരംക്കും ചുരുക്കപ്പേരല്ല. ഡാറ്റാബേസുകൾ, കാഷ്, തിരയല്‍ സേവനങ്ങൾ, ക്യൂകൾ സാധാരണയായി ഇൻഫ്രാസ്ട്രക്ചർ പ്രൊവൈഡറിലൂടെ പ്രൊവിഷൻ ചെയ്യപ്പെടുകയും അവ അപ്പോഴത്തെ ഔട്ട്‌പുട്ടുകളിലൂടെയും കോൺഫിഗറേഷനിലൂടെയും ആപ്ലിക്കേഷനുമായി ബന്ധിപ്പിക്കപ്പെടുകയും ചെയ്യും.

## പ്രത്യേക സാഹചര്യമുള്ള പദങ്ങൾ

### ഡെവലപ്മെന്റ് പദങ്ങൾ
- **Hot Reload**: ഡെവലപ്പ്മെന്റ് സമയത്ത് ആപ്ലിക്കേഷൻ പുനരാരംഭം ചെയ്യാതെ സ്വയം അപ്‌ഡേറ്റ് ചെയ്യുക
- **Build Pipeline**: കോഡ് നിർമ്മിച്ചും ടെസ്റ്റ് ചെയ്തും ഓട്ടോമേറ്റുചെയ്യുന്ന പ്രക്രിയ
- **Deployment Slot**: App Service-നുള്ളിലെ സ്റ്റേജിംഗ് എൻവയോൺമെന്റ്
- **Environment Parity**: ഡെവലപ്പ്മെന്റ്, സ്റ്റേജിംഗ്, പ്രൊഡക്ഷൻ എൻവയോൺമെന്റുകൾ തമ്മിൽ സമാനമായി നിലനിർത്തുക

### സുരക്ഷാ പദങ്ങൾ
- **Managed Identity**: സ്വയം ക്രെഡ്‌ഷൻഷ്യൽ മാനേജ്മെന്റ് നൽകുന്ന Azure ഫീച്ചർ
- **Key Vault**: രഹസ്യങ്ങൾ, കീകൾ, സർട്ടിഫിക്കറ്റുകൾ സുരക്ഷിതമായി സൂക്ഷിക്കാൻ
- **RBAC**: Azure വിഭവങ്ങൾക്ക് റോളുദ്ദേശ്യമാക്കിയ ആക്സസ് നിയന്ത്രണം
- **Network Security Group**: നെറ്റ്‌വർക്ക് ട്രാഫിക് നിയന്ത്രിക്കുന്ന വിർച്വൽ ഫയറ്വാൾ

### നിരീക്ഷണ പദങ്ങൾ
- **Telemetry**: അളവുകൾക്കും ഡേറ്റക്കും ഓട്ടോമേറ്റഡ് ശേഖരണം
- **Application Performance Monitoring (APM)**: സോഫ്റ്റ്‌വെയറിന്റെ പ്രകടനം നിരീക്ഷിക്കൽ
- **Log Analytics**: ലോഗ് ഡാറ്റ ശേഖരിച്ച് വിശകലനം ചെയ്യുന്ന സേവനം
- **Alert Rules**: മീറ്റ്രിക് അല്ലെങ്കിൽ അവസ്ഥകൾ അടിസ്ഥാനമാക്കി ഓട്ടോമാറ്റിക് അറിയിപ്പുകൾ

### ഡിപ്ലോയ്മെന്റ് പദങ്ങൾ
- **Blue-Green Deployment**: സീറോ-ഡൗൺടൈം ഡിപ്ലോയ്മെന്റ് തന്ത്രം
- **Canary Deployment**: ഉപയോക്താക്കളുടെ ചിലർക്ക് ഘട്ടം ഘട്ടമായി റോള്ഔട്ട്
- **Rolling Update**: ആപ്ലിക്കേഷൻ ഇൻസ്റ്റൻസുകൾ നിരത്തായി മാറ്റൽ
- **Rollback**: മുമ്പത്തെ ആപ്ലിക്കേഷൻ പതിപ്പിലേക്ക് തിരിച്ചെത്തുന്നു
