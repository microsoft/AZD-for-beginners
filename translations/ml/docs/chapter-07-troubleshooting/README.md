## അവലോകനം

Azure Developer CLI ഉപയോഗിക്കുമ്പോൾ സാധാരണ പിഴവുകൾ കണ്ടെത്താനും പരിഹരിക്കാനും ഈ അധ്യായം സഹായിക്കുന്നു. വിന്യസന പരാജയങ്ങളിൽ നിന്നുമുള്ള AI-നിസാരമായ പ്രശ്നങ്ങൾ വരെ.

> പുറത്തിറക്കിയ `azd 1.37.2` സ്രോതസ്സിനെ അടിസ്ഥാനമാക്കിയുള്ള കമാൻഡ് മാർഗനിർദ്ദേശം പരിശോധിച്ചിട്ടുണ്ട്. ക്ലൗഡ് വിന്യാസങ്ങൾ നിർവഹിച്ചിട്ടില്ല. കമാൻഡുകൾ ഉപയോഗിക്കുന്നതിന് മുമ്പ് ഉദാഹരണ വിഭവങ്ങളുടെ നാമങ്ങളും ഐഡിയുകളും മാറ്റുക.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ അധ്യായം പൂർത്തിയാക്കിയാൽ നിങ്ങൾക്ക് കഴിയും:
- സാധാരണ AZD വിന്യാസ പരാജയങ്ങൾ കണ്ടെത്തുക
- പ്രാമാണീകരണവും അനുവാദ പ്രശ്‌നങ്ങളും ഡീബഗ് ചെയ്യുക
- AI സേവന കണക്ടിവിറ്റി പ്രശ്നങ്ങൾ പരിഹരിക്കുക
- പ്രശ്‌നപരിഹാരത്തിനായി Azure പോർട്ടലും CLI-യും ഉപയോഗിക്കുക

## 🚨 വിപരീത പരിഹാരങ്ങൾ

### പ്രാമാണീകരണ പ്രശ്നങ്ങൾ
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### വിന്യാസ പരാജയങ്ങൾ
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### വിഭവങ്ങളിലെ തർക്കങ്ങൾ
നിലവിലുള്ള വിഭവവും വിന്യാസ പിഴവുകളും ആദ്യം പരിശോധിക്കുക. ഒരു പങ്കുവെക്കപ്പെട്ട് അല്ലെങ്കിൽ ഉത്പാദന പരിസ്ഥിതി ഇല്ലാതാക്കാതെ നാമത്തിൽ തർക്കം പരിഹരിക്കരുത്. **പുതിയ ഉപേക്ഷിക്കാൻ കഴിയുന്ന പരിസ്ഥിതിക്ക്**, വ്യത്യസ്തമായ ഒരു പേര് ഉപയോഗിക്കുക:

```bash
azd env new different-name
azd up
```

### ബാധ്യതാരഹിതം
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

`AZURE_LOCATION` മാറ്റുന്നത് നിലവിലുള്ള വിഭവങ്ങളെ മാറ്റുന്നില്ല; മുൻപ് വിന്യസിക്കുമ്പോൾ സ്ഥലം തർക്കങ്ങൾ ഉണ്ടാകാം.

## 📋 പിഴവ് കോഡ് റഫറൻസ്

| പിഴവ് | കാരണം | പരിഹാരം |
|-------|-------|----------|
| `AuthenticationError` | ലോഗിൻ ചെയ്തിട്ടില്ല | `azd auth login` |
| `ResourceNotFound` | വിഭവം കണ്ടെത്താനായില്ല | വിഭവ നാമങ്ങൾ പരിശോധിക്കുക |
| `QuotaExceeded` | സബ്സ്ക്രിപ്ഷൻ പരിധികൾ | ബാധ്യത വർദ്ധിപ്പിക്കാൻ അപേക്ഷിക്കുക |
| `InvalidTemplate` | ബൈസിപ് സങ്കേത പിഴവ് | `az bicep build` |
| `Conflict` | വിഭവം നിലവിലുണ്ട് | പുതിയ പേര് ഉപയോഗിക്കുക അല്ലെങ്കിൽ ഇല്ലാതാക്കുക |
| `Forbidden` | കുറവ് അനുവാദങ്ങൾ | RBAC റോളുകൾ പരിശോധിക്കുക |

## 🔄 പുനക്രമീകരണവും പുനരുദ്ധാരണവും

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

ഹാർഡ് റീസെറ്റു ഡാറ്റ മായ്ക്കുകയും എൻഡ്‌പോയിന്റുകൾ മാറ്റുകയും ചെയ്യും. ആദ്യം ബാക്കപ്പ് എടുക്കുക, സമ്പർക്കമായ മായ്ക്കൽ പ്രോംപ്റ്റുകൾ പരിശോധിക്കുക. `--force --purge` ഉപയോഗിക്കുന്നത് മാറ്റാനാകാത്ത മായ്ക്കൽ ഉദ്ദേശിച്ചാൽ മാത്രമേ അനുയോജ്യമായിരിക്കൂ, ഉപേക്ഷിക്കാൻ കഴിയുന്ന പരിസ്ഥിതികൾക്കായി മാത്രം.
