# അധ്യായം 4: ഇൻഫ്രാസ്ട്രക്ചർ അസ്കോഡ് & ഡിപ്ലോയ്മെന്റ്

**📚 കോഴ്സ്**: [AZD For Beginners](../../README.md) | **⏱️ ദൈർഘ്യം**: 2-3 മണിക്കൂർ വായന; ഡിപ്ലോയ്മെന്റ് അഭ്യാസങ്ങൾക്ക് അധിക സമയം അനുവദിക്കുക | **⭐ സങ്കീർണ്ണത**: മദ്ധ്യമം

## അവലോകനം

ഈ അധ്യായം Bicep ടെംപ്ലേറ്റുകൾ, റിസോഴ്‌സ് പ്രൊവിഷനിംഗ്, Azure Developer CLI ഉപയോഗിച്ച് ഡിപ്ലോയ്മെന്റ് തന്ത്രങ്ങൾ എന്നിവ ഉൾപ്പെടുത്തി ഇൻഫ്രാസ്ട്രക്ചർ അസ്കോഡ് (IaC) ഉം കവരും.

> കമാൻഡ് ആൻഡ് കോൺഫിഗുറേഷൻ റിവ്യൂ ലക്ഷ്യം: `azd 1.37.2` (നവംബർ 2026). റിവ്യൂ സമയത്ത് ലൈവ് Azure പ്രൊവിഷനിംഗ് നടത്തപ്പെട്ടിട്ടില്ല.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ അധ്യായം പൂര്‍ത്തിയാക്കിയാൽ, നിങ്ങൾ:
- Bicep ടെംപ്ലേറ്റ് ഘടനയും സിന്റാക്സും മനസിലാക്കും
- `azd provision` ഉപയോഗിച്ച് Azure റിസോഴ്‌സുകൾ പ്രൊവിഷൻ ചെയ്യും
- `azd deploy` ഉപയോഗിച്ച് ആപ്ലിക്കേഷനുകൾ ഡിപ്ലോയ്മെന്റ് ചെയ്യും
- ബ്ലൂ-ഗ്രീൻ, റോളിങ് ഡിപ്ലോയ്മെന്റ് തന്ത്രങ്ങൾ നടപ്പാക്കും

## 🚀 വേഗത്തിലുള്ള തുടക്കം

```bash
# Initialize from template
mkdir infrastructure-practice
cd infrastructure-practice
azd init --template todo-nodejs-mongo .
azd auth login

# Preview what will be created
azd provision --preview

# Provision infrastructure only
azd provision

# Deploy code only
azd deploy

# Or both together
azd up
```

## 📁 AZD പ്രോജക്റ്റ് ഘടന

```
my-project/
├── azure.yaml            # ← Project definition
├── infra/                # ← Infrastructure as Code
│   ├── main.bicep        # Entry point
│   ├── main.parameters.json
│   └── modules/          # Reusable components
│       ├── web.bicep
│       └── database.bicep
└── src/                  # Application code
    └── api/
```

## 🔧 അനിവാര്യ കമാൻഡുകൾ

| കമാൻഡ് | വിവരണം |
|---------|-------------|
| `azd init` | പ്രോജക്റ്റ് ആരംഭിക്കുക |
| `azd provision` | Azure റിസോഴ്സുകൾ സൃഷ്ടിക്കുക |
| `azd deploy` | ആപ്ലിക്കേഷൻ കോഡ് ഡിപ്ലോയ്മെന്റ് ചെയ്യുക |
| `azd up` | പ്രൊവിഷൻ + ഡിപ്ലോയ്മെന്റ് |
| `azd down` | എല്ലാ റിസോഴ്‌സുകളും നീക്കം ചെയ്യുക |
