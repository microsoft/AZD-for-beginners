## അവലോകനം

ഈ അധ്യായം Azure Developer CLI വിനിയോഗങ്ങൾക്ക് പരിസ്ഥിതി കോൺഫിഗറേഷൻ, ഓത്തന്റിക്കേഷൻ മാതൃകകൾ, സുരക്ഷാ മികച്ച പ്രാക്ടീസുകൾ തുടങ്ങിയവ കൈകാര്യം ചെയ്യുന്നു.

> കമാൻഡ് & കോൺഫിഗറേഷൻ അവലോകന ടാർഗറ്റ്: `azd 1.37.2` (നവംബർ 2026). അവലോകന സമയത്ത് ലൈവ് Azure പ്രൊവിഷനിംഗ് നടത്തപ്പെട്ടിട്ടില്ല.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ അധ്യായം പൂർത്തിയാക്കുമ്പോൾ, നിങ്ങൾക്ക് ഇതു സാധിക്കും:
- AZD കോൺഫിഗറേഷൻ ക്രമരേഖതയിലെ പ്രാവീണ്യം നേടുക
- നിരവധി പരിസരങ്ങൾ (dev, staging, prod) കൈകാര്യം ചെയ്യുക
- മാനേജുചെയ്‌തിരിയപ്പെട്ട ഐഡന്റിറ്റികളുടെ സഹായത്തോടെ സുരക്ഷിത ഓത്തന്റിക്കേഷൻ നടപ്പിലാക്കുക
- പരിസരം-സ്വതന്ത്ര ക്രമീകരണങ്ങൾ കോൺഫിഗർചെയ്യുക

## 🚀 വേഗത്തിലുള്ള ആരംഭം

**മുൻകൂട്ടി ആരംഭിച്ച azd ആപ്ലിക്കേഷൻ** ന്റെ റൂട്ട് ഫോള്ഡറിൽ നിന്ന് ഓടിക്കുക, കോഴ്‌സ് റിപ്പോസിറ്ററി അല്ല. ഇത്തരം പേരിലുള്ള പരിസരങ്ങൾ ഇതിനകം ഉണ്ടെങ്കിൽ ഉപയോഗിക്കാത്ത പേരുകൾ ഉപയോഗിക്കുക.

```bash
# Create multiple environments
azd env new dev
azd env new staging
azd env new prod

# Switch environments
azd env select prod

# Set environment variables
azd env set AZURE_LOCATION eastus
azd env set SKU_NAME P1v3

# View configuration
azd env get-values
```

`SKU_NAME` ഉദാഹരണമാണ്: നിങ്ങളുടെ ടെംപ്ലേറ്റ് അതവ് സ്വീകരിക്കുന്നുവെങ്കിൽ മാത്രമേ ഇത് ഇൻഫ്രാസ്ട്രക്ചർയെ ബാധിക്കൂ. സാധാരണ `azd env set` മൂല്യങ്ങൾ plaintext ആയി പ്രാദേശികമായി സൂക്ഷിക്കപ്പെടുന്നു; അവ സുരക്ഷിതമായ രഹസ്യ സംഭരണശാലയല്ല.

## 🔧 കോൺഫിഗറേഷൻ ക്രമരേഖ

മൂന്ന് വ്യത്യസ്ത കോൺഫിഗറേഷൻ സാന്ദ്രതകൾ വേർതിരിച്ച് വയ്ക്കുക: ആഗോള അഭിരുചികൾ (`azd config`), പ്രോജക്റ്റ് ഘടന (`azure.yaml`), പരിസരം-പ്രത്യേക മൂല്യങ്ങൾ (`azd env`). ഫ്ലാഗുകൾ മാത്രം അവ പിന്തുണച്ച ക്രമീകരണങ്ങൾ മറികടക്കുന്നു; അന്യ അനിയന്ത്രിത പരിസരം വ്യത്യാസങ്ങളുടെ സാർവത്രിക ഓവർലെ `azure.yaml` അല്ലെങ്കിൽ Bicep ലേക്ക് ഇല്ല.

## 🔐 സുരക്ഷാ മികച്ച പ്രാക്ടീസുകൾ

```bash
# Runtime managed identity must be enabled in infrastructure and granted RBAC.
# To authenticate azd itself on an Azure host with an assigned identity:
# azd auth login --managed-identity

# Check AZD authentication status
azd auth login --check-status

# Optional: verify Azure CLI context if you plan to run az commands
az account show

# Re-authenticate if needed
azd auth login

# Optional: refresh Azure CLI authentication for az commands
az login
```
