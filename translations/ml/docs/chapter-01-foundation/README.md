## അവലോകനം

ഈ അദ്ധ്യായം Azure Developer CLI (azd) അടിസ്ഥാനങ്ങൾ പരിചയപ്പെടുത്തുന്നു. നിങ്ങൾ അടിസ്ഥാനം ആശയങ്ങൾ പഠിക്കുകയും, ടൂളുകൾ ഇൻസ്റ്റാൾ ചെയ്ത് നിങ്ങളുടെ ആദ്യ ആപ്ലിക്കേഷൻ Azure ലേക്ക് ഡിപ്പ്ലോയ് ചെയ്യുകയും ചെയ്യും.

> കമാൻഡ് കൂടാതെ കോൺഫിഗറേഷൻ അവലോകന ലക്ഷ്യം: `azd 1.37.2` (നവംബർ 2026). അവലോകനത്തിനിടെ ലൈവ് Azure പ്രൊവിഷനിംഗ് നടത്തപ്പെട്ടിട്ടില്ല.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ അദ്ധ്യായം പൂര്‍ത്തിയാക്കിയാൽ നിങ്ങൾക്ക്:
- Azure Developer CLI എന്താണെന്ന്, Azure CLIയെ അപേക്ഷിച്ച് എങ്ങനെ വ്യത്യസ്തമാണെന്ന് മനസ്സിലാക്കാൻ
- നിങ്ങളുടെ പ്ലാറ്റ്‌ഫോമിൽ AZD ഇൻസ്റ്റാൾ ചെയ്ത് കോൺഫിഗർ ചെയ്യാൻ
- `azd up` ഉപയോഗിച്ച് Azure ലേക്ക് നിങ്ങളുടെ ആദ്യ ആപ്ലിക്കേഷൻ ഡിപ്പ്ലോയ് ചെയ്യാൻ
- `azd down` ഉപയോഗിച്ച് സ്രോതസ്സുകൾ ശുചിത്വം നടത്താൻ

## ✅ ഇവിടെ തുടങ്ങൂ: നിങ്ങളുടെ സെറ്റപ്പ് പൂർണ്ണമായാണെന്ന് ഉറപ്പുവരുത്തുക

നിങ്ങൾ തുടങ്ങുന്നതിന് മുമ്പ്, നിങ്ങളുടെ ലൊക്കൽ മെഷീൻ ചാപ്റ്റർ 1 ടെംപ്ലേറ്റിന് തയ്യാറാണെന്ന് സ്ഥിരീകരിക്കുക:

**Windows:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

സ്ക്രിപ്റ്റ് ഉപകരണങ്ങൾ കാണാനില്ലെന്ന് റിപ്പോർട്ട് ചെയ്താൽ, ആദ്യം അവ പരിഹരിക്കുകയും തുടർന്ന് അദ്ധ്യായം തുടരുകയും ചെയ്യുക.

## 🚀 ക്വിക്ക് സ്റ്റാർട്ട്

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

## ✅ വിജയ കോപ്പൊയ്മകൾ

ഈ അദ്ധ്യായം പൂർത്തിയാക്കിയശേഷം, നിങ്ങൾക്ക് സാധിക്കണം:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
