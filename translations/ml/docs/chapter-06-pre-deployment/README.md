# അദ്ധ്യായം 6: പ്രീ-ഡിപ്ലോയ്‌മെന്റ് പദ്ധതി & വാലിഡേഷൻ

**📚 കോഴ്സ്**: [AZD For Beginners](../../README.md) | **⏱️ ദൈർഘ്യം**: 2-4 മണിക്കൂർ വായന; അനുസൃത ലാബുകളെക്കായി അധിക സമയം | **⭐ ബുദ്ധിമുട്ട്**: മധ്യമത്തിലുള്ളത്–അഡ്വാൻസ്ഡ്

## അവലോകനം

നിങ്ങളുടെ അപ്ലിക്കേഷൻ ഡിപ്ലോയ്‌മെന്റിന് മുൻപ് അനിവാര്യമായ പദ്ധതിയിടലും വാലിഡേഷൻ നിലപാടുകളും ഈ അദ്ധ്യായം ഉൾക്കൊള്ളുന്നു. ശരിയായ ശേഷി പദ്ധതിയിടൽ, SKU തിരഞ്ഞെടുപ്പ്, പ്രീഫ്ലൈറ്റ് പരിശോധനകൾ എന്നിവയിലൂടെ ചെലവുറ്റ പിശകുകൾ ഒഴിവാക്കാൻ പഠിക്കുക.

> പുറത്തിറക്കിയ `azd 1.37.2` റഫറൻസിനെ അടിസ്ഥാനമാക്കി കമാൻഡ് മാർഗ്ഗനിർദേശങ്ങൾ പരിശോധിച്ചു. ക്ലൗഡ് ഡിപ്ലോയ്‌മെന്റുകൾ നടപ്പിലാക്കിയിട്ടില്ല. വലുതായ പാഠങ്ങൾ സമ്പൂർണ ലോകൽ ഡിപ്ലോയ്‌മെന്റ് പ്രോജക്റ്റുകൾ അല്ല, ഉദാഹരണ ചിപ്പുകൾ ഉൾക്കൊള്ളുന്നു.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ അദ്ധ്യായം പൂർത്തിയാക്കിയാൽ, നിങ്ങൾക്ക് സാധിക്കും:
- ഡിപ്ലോയ്‌മെന്റിന് മുമ്പ് പ്രീഫ്ലൈറ്റ് പരിശോധനകൾ നടത്തുക
- ശേഷി പദ്ധതിയിടലും വികസന ആവശ്യകതകളുടെ കണക്കുകൂട്ടലും
- ചെലവ് മെച്ചപ്പെടുത്തലിനായി അനുയോജ്യമായ SKUs തിരഞ്ഞെടുക്കുക
- മേൽനോട്ടത്തിലേക്ക് അപ്ലിക്കേഷൻ ഇൻസൈറ്റ്സ് ക്രമീകരിക്കുക
- മൾട്ടി-എജന്റ് കോർഡിനേഷൻ മാതൃകകളും അവയുടെ ഡിപ്ലോയ്‌മെന്റ് ആവശ്യകതകളും മനസിലാക്കുക

## ☑️ പ്രീ-ഡിപ്ലോയ്‌മെന്റ് വെരിഫിക്കേഷൻ ലിസ്റ്റ്

### `azd provision` മു്

- [ ] പ്രദേശത്തിന് ക്വോട്ട സ്ഥിരീകരിച്ചു
- [ ] SKUs ശരിയായി തിരഞ്ഞെടുക്കപ്പെട്ടു
- [ ] ചെലവ് കണക്കുകൂട്ടൽ അവലോകനം ചെയ്തിരിക്കുന്നു
- [ ] നാമപരമായ വ്യവസ്ഥകൾ ഏകessoമായി പാലിക്കുന്നു
- [ ] സുരക്ഷാ/RBAC ക്രമീകരിച്ചു

### `azd deploy` മു്

- [ ] എൻവയോൺമെന്റ് വേരിയബിൾസ് ക്രമീകരിച്ചു
- [ ] കീ വോൾറ്റിൽ സീക്രെറ്റുകൾ സൂക്ഷിച്ചു
- [ ] ബന്ധ സ്ട്രിങ്കുകൾ പരിശോധിച്ചു
- [ ] ആരോഗ്യ പരിശോധനകൾ ക്രമീകരിച്ചു

| വർക്ക്ലോഡ് | ഡെവലപ്പ്മെന്റ് | പ്രൊഡക്ഷൻ |

| കോൺടെയ്‌നർ ആപ്സ് | കോൺസമ്പ്ഷൻ | മാപിത ലോഡിന്റെ അടിസ്ഥാനത്തിൽ കോൺസമ്പ്ഷൻ അല്ലെങ്കിൽ സമർപ്പിച്ച വർക്ക്ലോഡ് പ്രോഫൈൽ |
| ആപ്പ് സർവിസ് | B1/B2 | P1v3+ |
| അസ്യൂർ ഓപ്പൺഎഐ മോഡലുകൾ | പിന്തുണനൽകുന്ന പേ-ആസ്-യു-ഗോ ഡിപ്ലോയ്‌മെന്റ് തരം | പേ-ആസ്-യു-ഗോ അല്ലെങ്കിൽ പ്രൊവിഷൻ ചെയ്ത ത്രൂപുട്ട്; മോഡൽ/പ്രദേശത്തെ ആശ്രിതം |
| AI സെർച്ചും | പരിധികളിനുള്ളിൽ ഫ്രീ/ബേസിക് | ഇൻഡക്സ്, റെപ്ലിക്കാസുകൾ, ക്വറി ലോഡിനായി സൈസ് ചെയ്ത ബേസിക് അല്ലെങ്കിൽ സ്റ്റാൻഡേർഡ് ടിയർ |
