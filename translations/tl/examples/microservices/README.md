# Halimbawa ng Microservices

Ang patakbong implementasyon at ang mga tagubilin nito ay nasa
**[container-app/microservices](../container-app/microservices/README.md)**.

Ang direktoryong ito ay para sa pag-navigate lamang. Wala itong `azure.yaml`, `infra/`, o `src/`.
Huwag patakbuhin ang `azd up` dito.

Mula sa ugat ng repository:

```bash
cd examples/container-app/microservices
```

Pagkatapos ay sundan ang naka-link na README para sa mga kinakailangan, deployment, beripikasyon, lokal na
pag-unlad, praktikal na pagsasanay, gastusin, at paglilinis.

Ang halimbawa ay naglalaman ng isang Node.js API Gateway at isang read-only na Python Product Service.
Ang mga order, user, notification, database, at messaging services ay mga ideya ng extension,
hindi mga implementasyong kasama sa repository na ito.

- [Nakaraan: Simple Flask API](../../../../examples/container-app/simple-flask-api)
- [Susunod: Database app](../../../../examples/database-app)
- [Pag-unlad ng AI](../../docs/chapter-02-ai-development/README.md)
- [Pahina ng kurso](../../README.md)
