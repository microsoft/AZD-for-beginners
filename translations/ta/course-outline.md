# தொடக்கத்துக்கான AZD: பாடநெறி சுருக்கமும் கற்றல் கட்டமைப்பும்

## பாடநெறி பார்வை

முன்னேற்றமான கற்றலுக்காக வடிவமைக்கப்பட்ட கட்டமைக்கப்பட்ட அத்தியாயங்களின் மூலம் Azure Developer CLI (azd)-ஐ கைதட்டிக்கொள்ளுங்கள். **Microsoft Foundry ஒருங்கிணைப்புடன் AI பயன்பாட்டு வெளியீட்டுக்கு சிறப்பு கவனம்.**

### இக்கல்வியை நவீன டெவேலப்பர்களுக்கு அவசியமாக்கும் காரணம்

AI பணி வெளியீட்டிற்கு டெவேலப்பர்கள் பொதுவாக வழிகாட்டுதலை தேவைப்படுகிறார்கள்:
- சிக்கலான பல சேவைகள் கொண்ட AI கட்டமைப்புகள்
- உற்பத்தி AI வெளியீட்டுக்கான சிறந்த நடைமுறைகள்  
- Azure AI சேவை ஒருங்கிணைப்பு மற்றும் கட்டமைப்பு
- AI பணிகளுக்கான செலவு மேம்பாடு
- AI-சந்தர்ப்பமான வெளியீட்டுப் பிரச்சனைகள் தவிர்க்கும் தீர்வுகள்

### மையக் கற்றல் நோக்கங்கள்

இந்த கட்டமைக்கப்பட்ட பாடநெறியை முடித்ததும் நீங்கள்:
- **AZD அடிப்படைகளை கைதட்டுவது**: மையக் கருத்துக்கள், நிறுவல் மற்றும் கட்டமைப்பு
- **AI பயன்பாடுகளை வெளியீடு செய்தல்**: AZD உடன் Microsoft Foundry சேவைகள் பயன்படுத்தல்
- **அடிப்படை ஆர்கிடெக்சர் குறியீட்டாகும்**: Bicep டெம்ப்ளேட்களுடன் Azure வளங்களை நிர்வகித்தல்
- **வெளியீட்டுப் பிரச்சனைகளை தீர்த்து கொள்ளுதல்**: பொதுவான பிரச்சனைகளுக்கு தீர்வுகள் மற்றும் பிழைதிருத்தம்
- **உற்பத்திக்கான மேம்பாடு**: பாதுகாப்பு, அளவுகோல் நிறுத்துதல், கண்காணிப்பு மற்றும் செலவு மேலாண்மை
- **பல முகவர் தீர்வுகளை உருவாக்குதல்**: சிக்கலான AI கட்டமைப்புகளை வெளியீடு செய்யுதல்

- **பயிற்சி வழிகாட்டி**: [பணிமுறை பார்வை](workshop/README.md) - அமர்வு திட்டமிடல் மற்றும் வழங்கல் வழிகாட்டல்
- **விளக்கக்காட்சி பொருட்கள்**: ஸ்லைடு டெக், அர்க்கிடெக்சர் வரைபடங்கள் மற்றும் டெமோ ஸ்கிரிப்ட்கள்
- **அங்கீகாரம் கருவிகள்**: நடைமுறை பயிற்சிகள், அறிவு சரிபார்ப்புகள் மற்றும் மதிப்பீடு கருவிகள்
- **தொழில்நுட்ப அமைப்பு**: சுற்றுப்புற அமைப்பு, பிரச்சனைகள் தீர்க்கும் வழிகாட்டிகள் மற்றும் பதில்பாதுகாப்பு திட்டங்கள்

**கற்றுநர்களுக்கு:**
- **இணைய பணிமுறை சூழல்**: [பணிமுறை பொருட்கள்](workshop/README.md) - உலாவியிலான கற்றல் தளம்
- **படி படி வழிகாட்டிய பயிற்சிகள்**: [வழிகாட்டிய பயிற்சிகள்](../../workshop/docs/instructions) - விரிவான நடைமுறை விளக்கங்கள்  
- **குறிப்புரை ஆவணங்கள்**: [AI பணிமுறை ஆய்வகம்](docs/chapter-02-ai-development/ai-workshop-lab.md) - AI கவனம் கொண்ட விரிவான ஆய்வுகள்
- **சமூக வளங்கள்**: Azure Discord சேனல்கள், GitHub கலந்துரையாடல்கள் மற்றும் நிபுணர் ஆதரவு

#### 🏢 நிறுவன பணிமுறை அமலாக்கம்
**நிறுவன வெளியீடு மற்றும் பயிற்சி திட்டங்கள்**

**நிறுவன பயிற்சி திட்டங்கள்:**
- **டெவேலப்பர் அறிமுகம்**: AZD அடிப்படைகள் உடன் புதிய பணியாளர்களுக்கு வழிகாட்டல் (2-4 வாரங்கள்)
- **குழு திறன் மேம்பாடு**: உள்ளடக்க குழுக்களுக்கு காலாண்டு பணிமுறை (1-2 நாட்கள்)
- **அர்க்கிடெக்சர் மதிப்பீடு**: மூத்த பொறியாளர்கள் மற்றும் வடிவமைப்பாளர்களுக்கான மாதாந்திர அமர்வுகள் (4 மணி)
- **தலைமை சுருக்கங்கள்**: தொழில்நுட்ப தீர்மானிகளை 위한 நிர்வாக பணிமுறை (அரை நாள்)

**அமலாக்க ஆதரவு:**
- **தனிப்பயன் பணிமுறை வடிவமைப்பு**: குறிப்பிட்ட நிறுவன தேவைகளுக்கு இணக்கமான உள்ளடக்கம்
- **முன்னோடி திட்ட மேலாண்மை**: வெற்றி அளவுகோல்கள் மற்றும் கருத்து திரட்டி கொண்ட நடமாட்டம்  
- **தொடர்ச்சியான வழிகாட்டல்**: பணிமுறை முடிந்த பின் திட்ட செயல்பாட்டிற்கு ஆதரவு
- **சமூக கட்டமைப்பு**: நிறுவன Azure AI டெவேலப்பர் சமூகங்கள் மற்றும் அறிவு பகிர்வு

**வெற்றி அளவுகோல்கள்:**
- **திறன் அடைவு**: தொழிற்தொழில் திறன் வளர்ச்சி அளக்கும் முன்/பின் மதிப்பீடுகள்
- **வெளியீடு வெற்றி**: உற்பத்தி பயன்பாடுகளை வெற்றிகரமாக வெளியீடு செய்த பங்கேற்பாளர்கள் சதவீதம்
- **திறமையான உற்பத்தி காலம்**: புதிய Azure AI திட்டங்களுக்கான முன்னோட்ட நேரம் குறைப்பு
- **அறிவாற்றல் இதரவு**: பணிமுறை முடிந்த 3-6 மாதங்களில் பின்தொடர்புப் பரிசீலனைகள்

5. **சகதரர் மதிப்பீடு**: சிக்கலான நிலைகளில் மற்ற கற்றுக்கொள்ளுபவர்களுடன் ஒத்துழைக்கவும்

### பாடநெறி முடிவு நன்மைகள்
அனைத்து அத்தியாயங்களையும் சரிபார்ப்புடன் முடித்தவுடன், பட்டதாரிகள்:

- **சிக்கல் தீர்வு திறமை**: செயலி இயக்க சிக்கல்கள் மற்றும் கட்டமைப்பு பிரச்சனைகளை சுயமாகத் தீர்க்கும் திறன்

**தொழில்முறை மேம்பாடு:**
- **தொழில் அங்கீகாரம்**: அதிக கோரிக்கையான AZD மற்றும் AI இயக்கத் துறைகளில் படிப்புகளுக்கான திறன்கள்
- **தொழில் முன்னேற்றம்**: மேக கட்டமைப்பாளர் மற்றும் AI இயக்க நிபுணர் பதவிகளுக்கான தகுதிகள்
- **சமுதாய வழிகாட்டுதல்**: Azure டெவலப்பர் மற்றும் AI சமுதாயங்களில் செயலில் இருந்தல்
- **தொடர்ச்சியான கற்றல்**: மேம்பட்ட Microsoft Foundry முறை பரிசோதனை ஆரம்பப்பிணைக்கோல்

**போர்ட்ஃபோலியோ சொத்துகள்:**

- **ஆவணங்கள்**: விரிவான இயக்க கையேடுகள் மற்றும் சிக்கல் தீர்க்கும் செயல்முறைகள்  
- **சமுதாய பங்களிப்புகள்**: Azure சமுதாயத்துடன் பகிரப்பட்ட விவாதங்கள், எடுத்துக்காட்டுகள் மற்றும் மேம்பாடுகள்
- **தொழில்முறை வலைப்பின்னல்**: Azure நிபுணர்களுடன் மற்றும் AI இயக்க உத்திரவாதிகளுடன் தொடர்புகள்

### பாடநெறி முடிந்து பிறகான கற்றல் பாதை
