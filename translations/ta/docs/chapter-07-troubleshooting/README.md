# அத்தியாயம் 7: பிழைங்கள் தீர்க்கும் மற்றும் பிழைகளை கண்டறிதல்

## உள்நோக்கம்

இந்த அத்தியாயம் Azure Developer CLI உடன் வேலை செய்யும் போது சம்பவிக்கும் பொதுவான பிரச்சனைகளை கண்டறிந்து தீர்க்க உதவுகிறது. பயன்பாட்டுத்திறனில் தோல்விகள் முதல் AI-க்கு சார்ந்த பிரச்சனைகள் வரை.

> கட்டளை வழிகாட்டி வெளியிடப்பட்ட `azd 1.37.2` குறிப்பு எதிர்பார்க்கப்பட்டது. மேகம் முறிவுகள் இயங்காமல் இருந்தன. கட்டளைகளை பயன்படுத்துவதற்கு முன் உதாரண வளங்களின் பெயர்களையும் அடையாளங்களையும் மாற்றவும்.

## கற்றல் குறிக்கோள்கள்

இந்த அத்தியாயத்தை முடித்து, நீங்கள்:
- பொதுவான ஆஸிடி வெளியீட்டு தோல்விகளை கண்டறியும்
- அங்கீகார மற்றும் அனுமதி பிரச்சனைகள் பிழைத்திருத்துதல்
- AI சேவை இணைப்பு பிரச்சனைகளை தீர்க்கும்
- பிழையறிதலுக்கு Azure போர்டல் மற்றும் CLI பயன்படுத்துவது

## 🚨 விரைவு சரி செய்யல்கள்

### அங்கீகார பிழைகள்
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### அளவை தோல்விகள்
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### வள பிரச்சனைகள்
முதலில் உள்ள வளமும் வெளியீட்டு பிழைகளையும் பரிசீலிக்கவும். பெயர் மோதலை தீர்க்க ஒன்றுக்கூடப்பட்ட அல்லது உற்பத்தி சூழலை அழிக்காதீர்கள். **புதிய பயன்படுத்திக்கொள்ளும் சூழல்**க்கு தனித்துவமான பெயரை பயன்படுத்தவும்:

```bash
azd env new different-name
azd up
```

### அளவு மீறியது
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

`AZURE_LOCATION` மாற்றுவது உள்ள வளங்களை நகர்த்தமாட்டாது மற்றும் மீண்டும் வெளியீட்டில் இடம் மோதல்களை ஏற்படுத்தும்.

## 📋 பிழை குறியீடு குறிப்பு

| பிழை | காரணம் | தீர்வு |
|-------|-------|----------|
| `AuthenticationError` | உள்நுழையவில்லை | `azd auth login` |
| `ResourceNotFound` | வளம் காணவில்லை | வள பெயர்களைப் பரிசீலிக்கவும் |
| `QuotaExceeded` | சந்தா வரம்புகள் | அளவு அதிகரிப்பு கோரிக்கை விடுத்தல் |
| `InvalidTemplate` | பைசெப் இலக்கணம் பிழை | `az bicep build` |
| `Conflict` | வளம் உள்ளது | புதிய பெயர் பயன்படுத்தவும் அல்லது நீக்கவும் |
| `Forbidden` | போதிய அனுமதிகள் இல்லை | RBAC வேறுபாடுகளை பரிசீலிக்கவும் |

## 🔄 மீட்டமைப்பு மற்றும் மீட்பு

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

கடுமையான மீட்டமைப்பு தரவுகளை நீக்குகிறது மற்றும் இடைப்புள்ளிகளை மாற்றக்கூடும். முதலாவதாக காப்பு எடுத்துக் கொள்ளவும் மற்றும் இடைமுக நீக்க அறிவிப்புகளை பரிசீலிக்கவும். `--force --purge` என்பது மாற்ற முடியாத நீக்கத்திற்கு உகந்தது, சாதாரண சூழல்களுக்கே பொருந்தும்.
