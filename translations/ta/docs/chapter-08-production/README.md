# அத்தியாயம் 8: உற்பத்தி & நிறுவன இட்டல் மாதிரிகள்

**📚 பாடநெறி**: [AZD ஆரம்பநிலை](../../README.md) | **⏱️ காலம்**: 2-3 மணி நேரம் | **⭐ சிக்கல் நிலை**: மேம்பட்டது

## கண்ணோட்டம்

இந்த அத்தியாயம் நிறுவன தயார் தன்மையுள்ள இணைக்கல் மாதிரிகள், பாதுகாப்பு கடினப்படுத்தல், கண்காணிப்பு மற்றும் உற்பத்தி AI பணிகளுக்கான செலவு அதிகரிப்பு குறைப்பு குறித்து கையாள்கிறது.

இது கட்டமைப்பு குறிப்பு, முழுமையான இயக்கக்கூடிய உற்பத்தி மாதிரி அல்ல. உதாரணங்கள் உங்கள் சொந்த விண்ணப்பத்தில் வழங்கி சோதிக்க வேண்டிய ஒருங்கிணைப்பு விவரங்களை தவிர்க்கின்றன; சரிபார்ப்பு பட்டியலை வாசிப்பது உற்பத்தி தயார் நிலையை உறுதி செய்வதாக இல்லை.

> **வெளியீடு மதிப்பாய்வு (2026-11-04):** AI CLI வழிகாட்டி `azd 1.37.2`, முகவர்கள் `1.0.0-beta.23` மற்றும் மதிப்பீடுகள் `1.0.0-beta.2` ஆவணங்கள்/மூலத்துடன் சரிபார்க்கப்பட்டது. இணக்கமான தேவைகள் மற்றும் மைக்ரேஷன் விவரங்களுக்கு [வெளியீட்டு மாற்றங்கள் மற்றும் திருத்தங்கள்](production-ai-practices.md#recent-release-changes-and-fixes) பார்க்கவும்; இது நேரடி இயக்க மதிப்பீடு அல்ல.

## கற்றல் குறிக்கோள்கள்

இந்த அத்தியாயத்தை முடித்தவுடன், நீங்கள்:
- பன்முக மண்டல சக்தி வாய்ந்த பயன்பாடுகளை இயக்கலாம்
- நிறுவன பாதுகாப்பு மாதிரிகளை செயல்படுத்தலாம்
- முழுமையான கண்காணிப்பை அமைக்கலாம்
- அளவுடன் செலவுகளை மேம்படுத்தலாம்
- AZD உடன் CI/CD குழாய்களை அமைக்கலாம்

## 💰 செலவு மேம்படுத்தல்

| रणनीति | முக்கிய கட்டுப்பாடு |
|----------|---------|
| பூஜ்ஜியமாக அளவிடுதல் (கன்டெய்னர் ஆப்ஸ்) | பொருத்தமான தூண்டுகோலை தேவைப்படுத்தும்; பிற சேவைகள் இன்னும் செலவுகள் உருவாக்கும் |
| வளர்ச்சிக்கான கட்டமைப்பு நிலைகள் பயன்படுத்தல் | தேர்ந்தெடுக்கப்பட்ட சேவை விலை மற்றும் பணிமனையை ஒப்பிடுதல் |
| அட்டவணைப்படி அளவிடுதல் | ஆதரவு உடைய கட்டமைப்பு/தானியக்க வழியாக அளவிடுதல் |
| முன்பதிவு/புரொவிஷன் திறன் | மட்டுமே ஆதரிக்கப்படும் போது; உறுதிமொழிகள் மந்தநிலை செலவுகளை உயர்த்தலாம் |

செல்லுபடியாகும் தொடக்க தேதி, பில்லிங் பரப்பு, பெறுநர்கள் மற்றும் அனுமதிகளுடன் கூடிய [முழுமையான பட்ஜெட் வள மாதிரியை](production-ai-practices.md#2-cost-monitoring-and-budgets) பயன்படுத்தவும். பட்ஜெட் எச்சரிக்கைகள் அனுப்புகிறது; இது செலவினத்தைக் கட்டுப்படுத்தாது. சேமிப்பு அளவுக்கேற்ப பயன்படுத்தப்பட்ட பயன்பாட்டின்மேல் சார்புடையது மற்றும் உறுதிப்படுத்தப்பட்ட சதவீதங்கள் இல்லை.
