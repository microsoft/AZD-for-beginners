# அத்தியாயம் 6: முன்னணி பராமரிப்பு திட்டமிடல் மற்றும் சரிபார்ப்பு

## விரிவு

உங்கள் பயன்பாட்டை பரப்புவதற்கு முன் அவசியமான திட்டமிடல் மற்றும் சரிபார்ப்பு படிகளை இந்த அத்தியாயம் கவர்கிறது. சரியான திறன் திட்டமிடல், SKU தேர்வு மற்றும் முன்னணி சோதனைகளுடன் செலவான தவறுகளைத் தவிர்க்க கற்றுக்கொள்ளுங்கள்.

> வெளியிடப்பட்ட `azd 1.37.2` குறிப்பு எதிர் நோக்கிச் சுட்டி வழிகாட்டல். மேகம் பரப்புகள் நடாத்தப்படவில்லை. நீண்ட பாடங்களில் முழுமையான உள்ளூரான பரப்பு திட்டங்கள் அல்லாமல் விளக்கக் கூறுகள் உள்ளன.

## கற்றல் இலக்குகள்

இந்த அத்தியாயத்தை முடிப்பதன் மூலம் நீங்கள்:
- பரப்புவதற்கு முன் முன்னணி சோதனைகளை நடத்த
- திறன் திட்டமிடல் மற்றும் வள தேவைகளை மதிப்பிட
- செலவு tốiமுப்பதற்கான சரியான SKU களை தேர்ந்தெடு
- கண்காணிப்பதற்கான Application Insights ஐ கட்டமைக்க
- பன்முக முகவர் ஒத்துழைப்பு முறைகள் மற்றும் அவற்றின் பரப்பு தேவைகளைப் புரிந்து கொள்

```bash

azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ முன்னணி பரப்பல் சரிபார்ப்பு பட்டியல்

### `azd provision` முன்

- [ ] பிராந்தியத்திற்கு குவோட்டா சரிபார்
- [ ] SKU கள் சரியான முறையில் தேர்வு செய்யப்பட்டுள்ளன
- [ ] செலவு மதிப்பீடு பரிசீலிக்கப்பட்டது
- [ ] பெயரிடல் நடைமுறை ஒரேபோல் உள்ளது
- [ ] பாதுகாப்பு/RBAC அமைக்கப்பட்டது

### `azd deploy` முன்

- [ ] சுற்றுச்சூழல் மாறிலிகள் அமைக்கப்பட்டது
- [ ] கீ வால்ட் இல் இரகசியங்கள் உள்ளன
- [ ] இணைப்பு கயிறுகள் சரிபார்க்கப்பட்டன
- [ ] ஆரோக்கியத்தைக் கண்காணிப்பு அமைக்கப்பட்டது
