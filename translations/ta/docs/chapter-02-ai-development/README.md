## மேல் நோக்கம்

இந்த அத்தியாயம் Azure Developer CLI மற்றும் Microsoft Foundry சேவைகளை பயன்படுத்தி AI சக்தியூட்டப்பட்ட பயன்பாடுகளை மேற்பார்வை செய்யும். எளிய AI சொட்கள் செயலிகள் முதல் கருவிகளுடனான நுண்ணறிவு முகவர்கள் வரை.

> **வெளியீடு மதிப்பாய்வு (2026-11-04):** AI CLI வழிகாட்டி வெளியிடப்பட்ட `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23` மற்றும் `azure.ai.evaluations` `1.0.0-beta.2` ஆவணப்படம்/மூலம் எதிர்வார்ப்பு செய்யப்பட்டது. இணைந்த வேலைப்பாடிற்கு `azd >= 1.37.0` பயன்படுத்தவும். மதிப்பாய்வுகள் தனித்தனியாக `azd ai eval` பெயர்க்கையோடு தற்போது பயன்படுத்தப்படுகிறது; [வெளியீட்டு மாற்றங்கள் மற்றும் மாற்ற வழிகாட்டி](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes) காணவும். இது நேரடி மேற்பார்வை சரிபார்ப்பல்ல.

## கற்றல் குறிக்கோள்கள்

இந்த அத்தியாயத்தை முடித்தவுடன், நீங்கள்:
- முன்பதிவு செய்யப்பட்ட AZD மாதிரிகள் பயன்படுத்தி AI பயன்பாடுகளை மேற்பார்வை செய்வீர்கள்
- AZD உடன் Microsoft Foundry ஒருங்கிணைப்பை புரிந்துகொள்ளவும்
- கருவிகளுடன் AI முகவர்களை அமைக்கவும் மற்றும் தனிப்பயனாக்கவும்
- RAG (Retrieval-Augmented Generation) பயன்பாடுகளை மேற்பார்வை செய்யவும்

## 🚀 விரைவு துவக்கம்

புதிய வெற்று அடைவில் ஒரு விருப்பத்தைத் தெரிவுசெய்க. கடைசியில் உள்ள `.` தற்போதைய அடைவை துவக்குகிறது; இல்லையெனில் AZD உங்கள் shell வேலை அடைவின் செயலாற்றலை மாற்றாமல் துணை அடையை உருவாக்கலாம்.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 செலவு விழிப்புணர்வு

இவை அறிக்கை அளவீடுகள், மேற்கோள்கள் அல்லது வரம்புகள் அல்ல; மாதிரிப் போக்குகள், தேடல்/கணக்கிடல் SKUகள், பிராந்தியம் மற்றும் விருப்ப அம்சங்கள் இதைப் கடந்தும் இருக்கலாம். உங்கள் தேர்ந்த எடுத்துக்காட்டின் தற்போதைய விலைப்பட்டியல் வழிகாட்டியை பரிசீலித்து மேற்பார்வை செய்யவும்.

| சுற்றுச்சூழல் | மாதாந்திர மதிப்பிடப்பட்ட செலவு |
|-------------|----------------------|
| வளர்ச்சி | $80-150 |
| பரிசோதனை | $150-300 |
| உற்பத்தி | $300-3,500+ |

**உதவி:** சோதனை முடிந்த பிறகு கட்டணங்களைத் தவிர்க்க `azd down` இயக்கவும்.
