# அத்தியாயம் 1: அடித்தளம் & விரைவு தொடக்கம்

**📚 பாடநெறி**: [ஆரம்பக்காரர்களுக்கான AZD](../../README.md) | **⏱️ கால அளவு**: முதல்கால விநியோகத்துடன் 75-120 நிமிடங்கள்; கூடுதல் பயிற்சிகள் நீண்ட நேரம் எடுக்கும் | **⭐ கடினத்தன்மை**: ஆரம்பக்காரர்

## பார்வை

இந்த அத்தியாயம் Azure Developer CLI (azd) அடிப்படைகளைக் கொண்டு அறிமுகம் செய்கிறது. நீங்கள் முக்கியக் கருத்துக்களை கற்றுக்கொள்வீர்கள், கருவிகளை நிறுவுவீர்கள் மற்றும் உங்கள் முதல் செயலியை Azure இல் வெளியிடுவீர்கள்.

> கட்டளை மற்றும் கட்டமைப்பு விமர்சனை இலக்கு: `azd 1.37.2` (நவம்பர் 2026). விமர்சனத்தின் போது நேரடி Azure வழங்கல் நடைபெறவில்லை.

## கற்றல் நோக்கங்கள்

இந்த அத்தியாயத்தை முடிப்பதன் மூலம், நீங்கள்:
- Azure Developer CLI என்பது என்ன மற்றும் அது Azure CLI இலிருந்து எப்படி வேறுபடுகிறது என்பதை புரிந்து கொள்வீர்கள்
- உங்கள் தளத்தில் AZD ஐ நிறுவி கட்டமைக்கும்
- உங்கள் முதல் செயலியை Azure இல் `azd up` உதவியுடன் வெளியிடுவீர்கள்
- `azd down` மூலம் வளங்களை சுத்தம் செய்வீர்கள்

## ✅ இங்கே தொடங்குங்கள்: உங்கள் அமைப்பை சரிபார்க்கவும்

நீங்கள் துவங்கும்வரை, உங்கள் உள்ளூர் இயந்திரம் அத்தியாயம் 1 மாதிரிக்கு தயார் என்று உறுதி செய்யுங்கள்:

**விண்டோஸ்:**
```powershell
.\validate-setup.ps1
```

**macOS / லினக்ஸ்:**
```bash
bash ./validate-setup.sh
```

ஸ்கிரிப்ட் கருவிகள் இல்லை என தெரிவித்தால், முதலில் அவற்றை சரிசெய்து அத்தியாயத்துடன் தொடரவும்.

---

## 🚀 விரைவான தொடக்கம்

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ வெற்றி அளவுகோல்கள்

இந்த அத்தியாயத்தை முடித்த பிறகு, நீங்கள் முடியும்:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
