## அறிமுகம்

இந்த விரிவான சொல்விவரக்கோவை Azure Developer CLI மற்றும் Azure மேக வளர்ச்சியில் பயன்படுத்தப்படும் பதங்கள், கருத்துகள் மற்றும் சுருக்கங்களுக்கான வரையறைகளை வழங்குகிறது. தொழில்நுட்ப ஆவணங்களைப் புரிந்துகொள்வதற்கும், பிரச்சினைகளை தீர்க்கவும், azd திட்டங்கள் மற்றும் Azure சேவைகள் பற்றி திறம்பட தொடர்பு கொள்ளவும் அவசியமான குறிப்பு.

## கற்றல் குறிக்கோள்கள்

இந்த சொல்விவரக்கோவை பயன்படுத்தி, நீங்கள்:
- அவசியமான Azure Developer CLI பதியியல் மற்றும் கருத்துக்களை புரிந்துகொள்ள
- Azure மேக வளர்ச்சி சொற்கள் மற்றும் தொழில்நுட்ப பதியியலை நல்ல முறையில் கையாள
- கட்டமைப்பு குறியீடு மற்றும் முகாமிறுத்தும் பதியியலை திறம்பட குறிக்கோள் எடு
- Azure சேவை பெயர்கள், சுருக்கங்கள் மற்றும் அவைகளின் பயன்பாடுகளை புரிந்து கொள்
- பிரச்சனை தீர்க்கும் பதங்கள் மற்றும் பிழைதிருத்த குறியீடுகளுக்கான வரையறைகளை அணுகுக
- மேம்பட்ட Azure வடிவமைப்பு மற்றும் வளர்ச்சி கருத்துக்களை கற்றுகொள்

## கற்றல் முடிவுகள்

இந்த சொல்விவரக்கோவை அடிக்கடி பார்க்கும்மையில், நீங்கள்:
- சரியான Azure Developer CLI பதியியலை பயன்படுத்தி திறம்பட தொடர்பு கொள்ள முடியும்
- தொழில்நுட்ப ஆவணங்கள் மற்றும் பிழை செய்திகளை தெளிவாக புரிந்து கொள்வீர்கள்
- Azure சேவைகள் மற்றும் கருத்துக்களை நம்பிக்கையுடன் இயக்கி முடியும்
- பொருத்தமான தொழில்நுட்ப சொற்களை கொண்டு பிரச்சனைகளை தீர்க்க முடியும்
- குழு விவாதங்களில் துல்லியமான தொழில்நுட்ப மொழியுடன் பங்களிக்க முடியும்
- உங்கள் Azure மேக வளர்ச்சி அறிவை அமைத்துக் கொள்ள முடியும்

## A

**ARM வார்ப்பு**  
Azure வேளாண்மை மேலாளரின் வார்ப்பு. JSON அடிப்படையிலான கட்டமைப்பு குறியீடு வடிவம், Azure வளங்களை விளக்கமாகக் குறிக்க மற்றும் வடிவமைக்க பயன்படுத்தப்படுகிறது.

**ஆப் சேவை**  
Azure இன் பிளாட்ஃபாரம்-என்று-சேவை (PaaS) வழங்குதல், இது அண்டை கலப்பு மேலாண்மை இல்லாமல் வலை பயன்பாடுகள், REST APIகள் மற்றும் மோபைல் பின்னணி சேவைகளை நடத்த உதவுகிறது.

**ஆப்ளிகேஷன் இன்சைட்ஸ்**  
Azure இன் பயன்பாட்டு செயல்திறன் கண்காணிப்பு (APM) சேவை, இது பயன்பாட்டின் செயல்திறன், கிடைக்குத்தன்மை மற்றும் பயன்பாட்டைப் பற்றிய ஆழமான அறிவை தருகிறது.

**Azure CLI**  
Azure வளங்களை நிர்வகிக்கும் கட்டளையாளர் இடைமுகம். இது AZD இன் துணை ஆகும், ஆனால் தனித்தனியான உள்நுழையல் உள்ளது; முக்கிய AZD அங்கீகாரம் `azd auth login` ஐப் பயன்படுத்துகிறது.

**Azure Developer CLI (azd)**  
டெவலப்பர்களுக்கு உட்பட்ட கட்டளையாளர் கருவி, இது வார்ப்புகளையும் கட்டமைப்பு குறியீடு முறையையும் பயன்படுத்தி Azure ல் பயன்பாடுகளை விரைவாக உருவாக்கி வடிவமைக்க உதவுகிறது.

**azure.yaml**  
azd திட்டத்திற்கான முக்கிய கட்டமைப்பு கோப்பு, இது சேவைகள், கட்டமைப்புகள் மற்றும் முகாமிறுத்தும் ஹூக்குகளை வரையறுத்துக்கொள்கிறது.

**Azure Resource Manager (ARM)**  
Azure இன் முகாமிறுத்தும் மற்றும் மேற்பார்வை சேவை, இது வளங்களை உருவாக்க, புதுப்பிக்க அல்லது நீக்க ஒரு முகாமிறுத்தல் அடுக்கு வழங்குகிறது.

## B

**Bicep**  
Microsoft ஆல் உருவாக்கப்பட்ட பகுதி-தொடர்ச்சி மொழி (DSL), இது Azure வளங்களை மேற்பார்வை செய்ய உதவுகிறது. இது ARM வார்ப்புகளை விட எளிய சொற்களை வழங்குகிறது மற்றும் ARM க்காக தொகுக்கப்படுகிறது.

**Build**  
மூலக்கோட் தொகுக்கும், சார்பு திட்டங்களை நிறுவும் மற்றும் பயன்பாடுகளை முகாமிறுத்தத்திற்காக தயார் செய்வது.

**நீலம்-பச்சை முகாமிறுத்தல்**  
இரண்டு ஒரேபோல் உற்பத்தி சூழல்களை (நீலம் மற்றும் பச்சை) பயன்படுத்தி డౌన్ டைம் மற்றும் ஆபத்துக்களை குறைக்கும் முகாமிறுத்தல் திட்டம்.

## C

**Container Apps**  
Azure இன் சேவையில்லா கண்டெய்னர் சேவை, இது சிக்கலான கட்டமைப்பைக் கையாளாமல் கண்டெய்னரை ஆதரிக்கும் பயன்பாடுகளை இயக்க உதவுகிறது.

**CI/CD**  
தொடர்ச்சியான இணைப்பு/தொடர்ச்சியான முகாமிறுத்தல். குறியீடு மாற்றங்களை ஒருங்கிணைத்து பயன்பாடுகளை தானாக முகாமிறுத்தும் நடைமுறைகள்.

**Cosmos DB**  
Azure இன் உலகளாவிய விநியோகிக்கப்பட்ட, பன்மாதிரி தரவுத்தள சேவை, இது ட்ரூபுட், தாமதம், கிடைக்குத்தன்மை மற்றும் ஒருங்கிணைப்பு ஆகியவற்றுக்கு முழுமையான SLAகளை வழங்குகிறது.

**கட்டமைப்பு**  
பயன்பாட்டு நடத்தையும் முகாமிறுத்தல் விருப்பங்களையும் கட்டுப்படுத்தும் அமைப்புகள் மற்றும் அளவுருக்கள்.

## D

**முகாமிறுத்தல்**  
சேவைகளை மற்றும் அவர்களின் சார்புகளை இலக்கக் கட்டமைப்பில் நிறுவி கட்டமைக்கும் செயல்முறை.

**Docker**  
கண்டெய்னரை தொழில்நுட்பத்தை அடிப்படையாகக் கொண்டு பயன்பாடுகளை உருவாக்க, அனுப்ப மற்றும் இயக்கும் தளம்.

**Dockerfile**  
Docker கண்டெய்னர் படம் உருவாக்க கட்டளைகள் உள்ள உரை கோப்பு.

## E

**சூழல்**  
உங்கள் பயன்பாட்டுக்கான ஒரு குறிப்பிட்ட முகாமிறுத்தல் இலக்கு (முன்னோட்டம், மேடையை, உற்பத்தி போன்றவை).

**சூழல் மாறிலிகள்**  
இயக்க நேரத்தில் பயன்பாடுகள் அணுகக்கூடிய முக்கிய-மதிப்பு சேமிப்பு إعدادமைப்புகள்.

**முடிவிடம்**  
ஒரு பயன்பாடு அல்லது சேவை அணுகக்கூடிய URL அல்லது நெட்வொர்க் முகவரி.

## F

**Function App**  
Azure இன் சேவையில்லா கணக்கிடல் சேவை, இது நிகழ்வினால் இயக்கப்படும் குறியீடுகளை கட்டமைப்பு இல்லாமல் இயக்க உதவுகிறது.

## G

**GitHub Actions**  
GitHub களஞ்சியங்களுக்கு ஒருங்கிணைக்கப்பட்ட CI/CD தளம், வேலைப்பாடுகளை தானாக செயற்படுத்த.

**Git**  
மூலக்கோட் மாற்றங்களை கண்காணிக்கப் பயன்படும் பகிர்ந்த பொது பதிப்புக் கட்டுப்பாட்டு அமைப்பு.

## H

**Hooks**  
முகாமிறுத்தல் வாழ்கைசுழற்சியில் குறிப்பிட்ட நேரங்களில் இயங்கும் தனிப்பயன் ஸ்கிரிப்ட்கள் அல்லது கட்டளைகள் (முன்-முயற்சி, பிறகு-முயற்சி, முன்-முகாமிறுத்தல், பிறகு-முகாமிறுத்தல்).

**ஓடுநகர்**  
ஒரு பயன்பாடு இடப்படும் Azure சேவை வகை (எ.கா., appservice, containerapp, function).

## I

**கட்டமைப்பு குறியீடாகும் நெடுவரிசை (IaC)**  
மனிதக் கையாளுதலைவிட குறியீட்டைக் கொண்டு கட்டமைப்பை வரையறுப்பும் முகாமிறுத்தலும் செய்யும் நடைமுறை.

**அரைஞ்சல்**  
புதிய azd திட்டத்தை பொது வார்ப்பிலிருந்து துவங்கும் முகாமிறுத்தல் செயல்முறை.

## J

**JSON**  
JavaScript பொருள் குறிப்பு. கட்டமைப்பு கோப்புகள் மற்றும் API பதிலளிப்புகளுக்குப் பொதுவாகப் பயன்படுத்தப்படும் தரவு பரிமாற்ற வடிவம்.

**JWT**  
JSON வலை டோக்கன். JSON பொருளாக பாதுகாப்பாக தகவலைப் பரிமாறுவதற்கான நிலையான முறைகள்.

## K

**Key Vault**  
ரகசியங்கள், சாவிகள் மற்றும் சான்றிதழ்களை பாதுகாப்பாக சேமிக்க மற்றும் முகாமிறுத்த Azure சேவை.

**கஸ்டோ வினவல் மொழி (KQL)**  
Azure கண்காணிப்பு, ஆப்ளிகேஷன் இன்சைட்ஸ் மற்றும் பிற Azure சேவைகளில் தரவை பகுப்பாய்வு செய்ய பயன்படும் வினவல் மொழி.

## L

**Load Balancer**  
பல சேவையகங்கள் அல்லது நிகழ்வுகளுக்கு மையப்படுத்தப்பட்ட நெட்வொர்க் போக்குவரத்தை பகிர்ந்தளிக்கும் சேவை.

**Log Analytics**  
மேக மற்றும் உள்ளக சூழலிலிருந்து தொலைமுக புள்ளிவிவரங்களை சேகரித்து பகுப்பாய்வு செய்யும் Azure சேவை.

## M

**மேலாண்மை அடையாளம்**  
Azure சேவைகளுக்கு தானாக முகாமிறுத்தப்படும் அடையாளத்தைக் கொடுக்கும் Azure அம்சம்.

**மைக்ரோசர்வீசுகள்**  
சிறிய, சுயாதீன சேவைகளாக உருவாக்கப்படும் பயன்பாடுகளுக்கான கட்டமைப்பு முறை.

**கண்காணி**

## சூழல்-சார்ந்த பதங்கள்

### வளர்ச்சி பதங்கள்
- **ஹாட் ரீலோட்**: மறுஆரம்பமில்லாமல் வளர்ச்சியின் போது பயன்பாடுகளை தானாக புதுப்பித்தல்
- **கட்டுமான குழாய்**: குறியீடு கட்டியமைத்தல் மற்றும் சோதிப்பதற்கான தானியங்கி செயல்முறை
- **முகாமிறுத்தல் இடம்**: ஒரு ஆப் சேவையின் உள்ளே மேடை சூழல்
- **சூழல் சமன்பாடு**: வளர்ச்சி, மேடை மற்றும் உற்பத்தி சூழல்கள் ஒரே மாதிரியாக இருக்க ஆகியவை

### பாதுகாப்பு பதங்கள்
- **மேலாண்மை அடையாளம்**: தானாகக் குறியீட்டினர் முகாமிறுத்தலை வழங்கும் Azure அம்சம்
- **Key Vault**: ரகசியங்கள், சாவிகள் மற்றும் சான்றிதழ்கள் பாதுகாப்பான சேமிப்பு
- **RBAC**: Azure வளங்களுக்கு பங்கு அடிப்படையிலான அணுகல் கட்டுப்பாடு
- **Network Security Group**: நெட்வொர்க் போக்குவரத்தை கட்டுப்படுத்தும் மெய்நிகர் தீவு வரும்

### கண்காணிப்பு பதங்கள்
- **தொலைமுக அளவீடு**: அளவீடுகள் மற்றும் தரவுகளின் தானியங்கி சேகரிப்பு
- **ஆப்ளிகேஷன் செயல்திறன் கண்காணிப்பு (APM)**: மென்பொருள் செயல்திறன் கண்காணிப்பு
- **Log Analytics**: பதிவுகளின் தரவை சேகரித்து பகுப்பாய்வு செய்யும் சேவை
- **எச்சரிக்கை விதிகள்**: அளவுகோள்களின் அடிப்படையில் தானாக அறிவிப்புகள்

### முகாமிறுத்தல் பதங்கள்
- **நீலம்-பச்சை முகாமிறுத்தல்**: நிலைமையாக இல்லாத நேரம் கொண்ட முகாமிறுத்தல் ( zero-downtime ) திட்டம்
- **கனரி முகாமிறுத்தல்**: பயனாளர் ஒரு பகுதிக்குக் குறைந்த அளவு மாதிரிப்பதிவு
- **வலியீட்டை புதுப்பித்தல்**: பயன்பாட்டு நிகழ்வுகளை வரிசைப்படி மாற்றுதல்
- **மீட்டுப்பிரதி**: பழைய பயன்பாட்டு பதிப்பிற்கு திரும்புதல்

---

**பயன்பாட்டு குறிப்பு**: இந்த சொல்விவரக்கோவைஇல் உள்ள குறிப்பிட்ட பதங்களை விரைவாக தேட `Ctrl+F` ஐப் பயன்படுத்தவும். தொடர்புடைய இடங்களில் பதங்கள் குறுக்குவழி குறிப்பிடப்பட்டுள்ளன.
