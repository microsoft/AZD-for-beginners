# AZD தொடங்குபவர்களுக்கு பங்களிப்பது

AZD தொடங்குபவர்களுக்கு курсаக்கு பங்களிப்பதில் உங்கள் ஆர்வத்திற்கு நன்றி! இந்த ஆவணம் பங்களிப்பாளர்களுக்கான வழிகாட்டுதல்கள் மற்றும் தகவல்களை வழங்குகிறது.

## எவ்வாறு பங்களிப்பது

### பிரச்சினைகள் புகாரளித்தல்

தவறுகள், பிழைகள் கண்டுபிடித்தால் அல்லது மேம்படுத்த சிந்தனைகள் இருந்தால்:

1. **தற்போதைய பிரச்சினைகளைப் பாருங்கள்**: நகலெடுக்க தவிர்க்க [தற்போதைய பிரச்சினைகள்](https://github.com/microsoft/azd-for-beginners/issues) தேடவும்
2. **புதிய பிரச்சினை உருவாக்கவும்**: சரியான பிரச்சினை மாதிரியைப் பயன்படுத்தவும்
3. **விவரங்களை வழங்கவும்**: மீண்டும் உருவாக்கும் படிகள், எதிர்பார்க்கப்படும் நடத்தை மற்றும் படங்கள் ഉൾடக்கவும்

### மாற்றங்களை பரிந்துரைத்தல்

1. **பயனரேப்பை ஃபோர் செய்யவும்**: திட்டத்தின் சொந்த ஃபோக்கை உருவாக்கவும்
2. **பிராஞ்ச் உருவாக்கவும்**: உங்கள் மாற்றங்களுக்கான அம்ச பிராஞ்ச் உருவாக்கவும்
3. **மாற்றங்கள் செய்யவும்**: எங்கள் குறியீடு மற்றும் ஆவணக்குறிப்பீட்டுக் கோட்பாடுகளை பின்பற்றவும்
4. **மாற்றங்களை சோதிக்கவும்**: அனைத்து இணைப்புகளும் செயல்படுகின்றதா மற்றும் உள்ளடக்கம் சரியாக காட்சியிடுகின்றதா என்பதை உறுதிப்படுத்தவும்
5. **புல் கோரிக்கையை சமர்ப்பிக்கவும்**: உங்கள் மாற்றங்களுக்கான தெளிவான விளக்கத்தை வழங்கவும்

### பங்களிப்ப விதங்கள்

நாங்கள் கீழ்காணும் பங்களிப்புகளுக்கு வரவேற்கிறோம்:

#### உள்ளடக்க மேம்பாடுகள்
- தவறுகள், இலக்கணமும், வடிவமைப்புச் சிக்கல்களையும் சரி செய்யவும்
- உள்ளடக்கத்தின் தெளிவை மேம்படுத்தவும்
- காலாவதியான தகவல்களை புதுப்பிக்கவும்
- இல்லாத விளக்கங்கள் அல்லது சூழ்நிலைகளை சேர்க்கவும்

#### புதிய எடுத்துக்காட்டுகள்
- உண்மையான வெளியீட்டு சூழ்நிலைகளை சேர்க்கவும்
- பொதுவான பயன்பாடுகளுக்கான புதிய AZD மாதிரிகளை உருவாக்கவும்
- கூடுதல் குறியீட்டு எடுத்துக்காட்டுகள் மற்றும் பயிற்சிகளை வழங்கவும்

#### மொழிபெயர்ப்பு ஆதரவு
- இருந்த மொழிபெயர்ப்புகளை பராமரிக்க உதவவும்
- மொழிபெயர்ப்பு தரத்தை மேம்படுத்தவும்
- புதிய உள்ளடக்கங்களுக்கு மொழிபெயர்ப்புகளைச் சேர்க்கவும்

#### பிழை அறிக்கைகள்
- உடைக்கப்பட்ட இணைப்புகள் அல்லது தவறான குறியீட்டு எடுத்துக்காட்டுகளைப் பதிவு செய்யவும்
- ஆவணச்சான்று முரண்பாடுகளை அடையாளம் காணவும்
- அணுகல் சிக்கல்களை குறியிடவும்

## பங்களிப்பு வழிகாட்டுதல்கள்

### ஆவணப்படுத்தல் கோட்பாடுகள்

- தெளிவாகவும், தொடக்கப் பயனாளிக்களுக்கு உகந்த மொழியில் எழுதவும்
- கற்றல் குறிக்கோள்களும் முடிவுகளும் சேர்க்கவும்
- படிநிலையான வழிமுறைகள் மற்றும் எதிர்பார்க்கப்படும் வெளிப்பாடுகளை வழங்கவும்
- தொடர்புடைய உள்ளடக்கங்களைத் தொடர்புபடுத்தும் வழிச் இணைப்புகளைச் சேர்
- ஒரே மாதிரியான வடிவமைப்பு மற்றும் மார்க்டவுன் பாணியைப் பயன்படுத்தவும்

### குறியீட்டு எடுத்துக்காட்டுகள்

- அனைத்து குறியீட்டு எடுத்துக்காட்டுகளும் சோதிக்கப்பட்டு செயல்படுகின்றன என்பதை உறுதி செய்யவும்
- முக்கியக் கருத்துக்களை விளக்கும் వ్యాఖ్యைகளைக் கொண்டிருக்கவும்
- அசுரே மற்றும் AZD சிறந்த நடைமுறைகளை பின்பற்றவும்
- பொருத்தமான இடங்களில் எதிர்பார்க்கப்படும் வெளிப்பாடுகளை வழங்கவும்

### ஆங்கில ஆவணங்களை உறுதிப்படுத்தல்

பயனரேப்பின் மூலம், உள்ளூர் வளர்ச்சி தேவைகளை நிறுவி இயக்கவும்:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

ஆன்லைன் இணைப்பு சரிபார்ப்பான் ஆங்கில மார்க்டவுன் / HTML பாதைகள், தலைப்புகள், குறிப்பான தங்கல்களையும் காலியான இணைப்பு இடமுயற்சிகளையும் சோதிக்கும். அது உருவாக்கப்பட்ட `translations/` மற்றும் `translated_images/` மற்றும் அந்த அடைவு இணைப்புகளை தவிர்க்கிறது. வெளிநாட்டு இணையதளங்களைப் பெறவில்லை அல்லது அசுரே வெளியீடுகளை சரிபார்க்கவில்லை. தோல்விகளை ஏற்றுமதி செய்ய மற்றும் தனி நெட்வொர்க் சோதனைக்காக வெளியூர் URL பட்டியலைப் பயன்படுத்த `--json <report-path>`ஐ பயன்படுத்தவும். தொழில்நுட்ப வழிமுறைகளில் மாற்றுகை செய்யும் போது தற்போதைய upstream கட்டளைகள் மற்றும் மாதிரி முன்னோக்குகளைக் கண்காணிக்கவும்; பரிசோதிக்கப்பட்ட பயன்பாடுகளை வடிவமைப்புப் ப்ளூபிரின்டுகளிலிருந்து வேறுபடுத்தவும்.
