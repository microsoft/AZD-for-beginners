# மைக்ரோசெர்விஸ்கள் உதாரணம்

இயக்கக்கூடிய நடைமுறை மற்றும் அதற்கான வழிமுறைகள்
**[container-app/microservices](../container-app/microservices/README.md)**இல் உள்ளன.

இந்த அடைவானது வழி கண்டறிதலுக்கே மட்டுப்படுத்தப்பட்டுள்ளது. இதில் எந்த `azure.yaml`, `infra/`, அல்லது `src/`இலும் இல்லை.
இங்கே `azd up`ஐ இயக்க வேண்டாம்.

களஞ்சியத்தின் இரட்டை அடிப்படையிலிருந்து:

```bash
cd examples/container-app/microservices
```

பின்னர் தேவையான முன்நிலைகள், அனுமதி, சரிபார்த்தல், உள்ளூர்
மேம்பாடு, நடைபயிற்சிகள், செலவுகள் மற்றும் சுத்தம் பற்றிய README ஐ பின்பற்றவும்.

இந்த மாதிரியில் Node.js API கேட்ட்வே மற்றும் வாசிப்பதற்கு மட்டும் அனுமதியுள்ள Python தயாரிப்பு சேவை உள்ளது.
ஆர்டர், பயனர், அறிவிப்பு, தரவுத்தளம் மற்றும் செய்தி சேவைகள் விரிவாக்கக் கருத்துக்கள்,
இந்த களஞ்சியத்தில் உள்ள நடைமுறைகள் அல்ல.
