# Contoh Microservices

Implementasi yang dapat dijalankan dan instruksinya ada di
**[container-app/microservices](../container-app/microservices/README.md)**.

Direktori ini hanya untuk navigasi. Tidak memiliki `azure.yaml`, `infra/`, atau `src/`.
Jangan jalankan `azd up` di sini.

Dari akar repositori:

```bash
cd examples/container-app/microservices
```

Kemudian ikuti README yang terhubung untuk persyaratan awal, penyebaran, verifikasi, pengembangan
lokal, latihan praktis, biaya, dan pembersihan.

Contoh ini berisi API Gateway Node.js dan Layanan Produk Python yang hanya-baca.
Layanan pesanan, pengguna, notifikasi, basis data, dan pesan adalah ide ekstensi,
bukan implementasi yang termasuk dalam repositori ini.
