# Допринос AZD За Почетнике

Хвала вам што сте заинтересовани за допринос курсу AZD За Почетнике! Овај документ пружа смернице и информације за сараднике.

## Како допринети

### Пријављивање проблема

Ако нађете грешке, проблеме или имате предлоге за побољшања:

1. **Проверите постојеће проблеме**: Претражите [постојеће проблеме](https://github.com/microsoft/azd-for-beginners/issues) како бисте избегли дупликате
2. **Направите нови проблем**: Користите одговарајући образац за проблем
3. **Пружите детаље**: Укључите кораке за репродукцију, очекивано понашање и снимке екрана ако је применљиво

### Предлагање измена

1. **Направите форк репозиторијума**: Креирајте свој форк пројекта
2. **Креирајте гранање**: Направите грану за нове функције за ваше измене
3. **Направите измене**: Пратите наше стандарде за кодирање и документацију
4. **Тестирајте ваше измене**: Проверите да ли сви линкови функционишу и садржај се исправно приказује
5. **Поднесите захтев за повлачење**: Пружите јасан опис ваших измена

### Врсте доприноса

Добродошли су следећи типови доприноса:

#### Побољшања садржаја
- Исправка правописних грешака, граматике и форматирања
- Побољшање јасноће постојеће документације
- Ажурирање застарелих информација
- Додавање недостајућих објашњења или контекста

#### Нови примери
- Додавање сценарија реалног распореда
- Креирање нових AZD шаблона за уобичајене случајеве
- Пружaње додатних узорака кода и задатака

#### Подршка за превод
- Помоћ у одржавању постојећих превода
- Побољшање квалитета превода
- Додавање превода за нови садржај

- Пријављивање покварених линкова или нетачних примера кода
- Идентификовање недоследности у документацији
- Пријављивање проблема са приступачношћу

## Смернице за допринос

### Стандарди за документацију

- Користите јасан, пријатељски језик за почетнике
- Укључите циљеве учења и очекиване резултате
- Пружите упутства корак по корак са очекиваним излазом
- Додајте навигационе линкове ка сродном садржају
- Користите доследно форматирање и markdown стил

### Примери кода

- Обезбедите да су сви примери кода тестирани и функционишу
- Укључите коментаре који објашњавају кључне концепте
- Пратите најбоље праксе Azure и AZD
- Пружите очекивани излаз где је применљиво

### Валидација енглеске документације

Из корена репозиторијума инсталирајте постојеће захтеве за развој и покрените:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

Оффлине проверавач линкова проверава енглеске Markdown/HTML путеве, наслове, експлицитне сидре и празне плейсхолдере за линкове. Искључује генерисане `translations/` и `translated_images/`, укључујући линкове у те директоријуме. Не приступа спољним вебсајтовима нити верификује Azure распореде. Користите `--json <report-path>` да извезете грешке и спољни URL инвентар за посебну мрежну проверу. Проверите тренутне upstream команде и пример захтева приликом мењања техничких упутстава; разликујте тестиране апликације од дизајнерских планова.
