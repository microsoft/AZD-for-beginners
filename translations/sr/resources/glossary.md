## Увод

Овај обиман речник пружа дефиниције за појмове, концепте и акрониме који се користе у Azure Developer CLI и развоју Azure облака. Неопходна референца за разумевање техничке документације, решавање проблема и ефикасну комуникацију о azd пројектима и Azure услугама.

## Циљеви учења

Коришћењем овог речника, моћи ћете да:
- Разумете основну терминологију и концепте Azure Developer CLI
- Усвојите речник и техничке термине за развој у Azure облаку
- Ефикасно се позивате на терминологију везану за Infrastructure as Code и деплојмент
- Разумете називе Azure сервиса, акрониме и њихове сврхе
- Приступите дефиницијама за терминологију решавања проблема и дебаговања
- Учите напредне концепте Azure архитектуре и развоја

## Резултати учења

Редовним коришћењем овог речника, бићете у стању да:
- Ефикасно комуницирате користећи исправну терминологију Azure Developer CLI
- Јасније разумете техничку документацију и поруке о грешкама
- Са поверењем се крећете кроз Azure сервисе и концепте
- Решавате проблеме користећи одговарајући технички речник
- Дајете допринос тимским дискусијама прецизним техничким језиком
- Систематски ширите своје знање о развоју у Azure облаку

## А

**ARM Template**  
Azure Resource Manager шаблон. JSON-базирани Infrastructure as Code формат који се користи за декларативно дефинисање и распоређивање Azure ресурса.

**App Service**  
Azure платформа као услуга (PaaS) која пружа хостинг веб апликација, REST API-ја и мобилних бектенда без потребе за управљањем инфраструктуром.

**Application Insights**  
Azure сервис за праћење перформанси апликација (APM) који пружа дубоке увиде у перформансе, расположивост и коришћење апликације.

**Azure CLI**  
Командна линија за управљање Azure ресурсима. Допуњује AZD, али има засебну пријаву; основна AZD аутентикација користи `azd auth login`.

**Azure Developer CLI (azd)**  
Алат са командном линијом оријентисан на програмере који убрзава процес прављења и распоређивања апликација на Azure користећи шаблоне и Infrastructure as Code.

**azure.yaml**  
Главни конфигурациони фајл за azd пројекат који дефинише сервисе, инфраструктуру и хукове за деплојмент.

**Azure Resource Manager (ARM)**  
Azure сервис за деплојмент и управљање који пружа слој за креирање, ажурирање и брисање ресурса.

## Б

**Bicep**  
Доменски специфичан језик (DSL) развијен од стране Microsoft-а за распоређивање Azure ресурса. Пружа једноставнију синтаксу од ARM шаблона док компајлира у ARM.

**Build**  
Процес компајлирања изворног кода, инсталирања зависности и припреме апликација за деплојмент.

**Blue-Green Deployment**  
Стратегија деплојмента која користи два идентична продукцијска окружења (плаво и зелено) за минимизирање времена неактивности и ризика.

## Ц

**Container Apps**  
Azure безсервисни контејнер сервис који омогућава покретање апликација у контејнерима без управљања компликованом инфраструктуром.

**CI/CD**  
Континуирана интеграција/континуирани деплојмент. Аутоматизоване праксе за интеграцију промена у коду и распоређивање апликација.

**Cosmos DB**  
Azure глобално дистрибуирана мулти-модел база података која пружа свеобухватне SLA за пропусност, латенцију, расположивост и конзистентност.

**Configuration**  
Подешавања и параметри који контролишу понашање апликације и опције деплојмента.

## Д

**Deployment**  
Процес инсталирања и конфигурисања апликација и њихових зависности на циљној инфраструктури.

**Docker**  
Платформа за развој, доставу и покретање апликација користећи технологију контејнеризације.

**Dockerfile**  
Текстуални фајл који садржи упутства за прављење Docker контејнер слике.

## Е

**Environment**  
Циљ деплојмента који представља одређени инстанцу ваше апликације (нпр. развојно, пред-производно, продукцијско).

**Environment Variables**  
Вредности конфигурације складиштене као парови кључ-вредност којима апликације приступају током извршавања.

**Endpoint**  
URL или мрежна адреса где се апликација или сервис могу приступити.

## Ф

**Function App**  
Azure безсервисна функција компјутерске услуге која омогућава извршавање кода који покрећу догађаји без управљања инфраструктуром.

## Г

**GitHub Actions**  
CI/CD платформа интегрисана са GitHub репозиторијумима за аутоматизацију токова рада.

**Git**  
Дистрибуирани систем за контролу верзија који се користи за праћење измена у изворном коду.

## Х

**Hooks**  
Прилагођени скрипти или команде које се извршавају у одређеним фазама током живота деплојмента (пре-произвођење, после-произвођења, пре-деплојмента, после-деплојмента).

**Host**  
Врста Azure сервиса на којој ће апликација бити деплојирана (нпр. appservice, containerapp, function).

## И

**Infrastructure as Code (IaC)**  
Пракса дефинисања и управљања инфраструктуром преко кода уместо ручних процеса.

**Init**  
Процес инициализације новог azd пројекта, обично користећи шаблон.

## Ј

**JSON**  
JavaScript Object Notation. Формат за размјену података који се често користи у конфигурационим фајловима и API одговорима.

**JWT**  
JSON Web Token. Стандард за безбедан пренос информација између страна као JSON објекат.

## К

**Key Vault**  
Azure сервис за безбедно чување и управљање тајнама, кључевима и сертификатима.

**Kusto Query Language (KQL)**  
Језик за упите који се користи за анализу података у Azure Monitor, Application Insights и другим Azure сервисима.

## Л

**Load Balancer**  
Сервис који распоређује долазни мрежни саобраћај преко више сервера или инстанци.

**Log Analytics**  
Azure сервис за прикупљање, анализу и реаговање на телеметријске податке из облачних и локалних окружења.

## М

**Managed Identity**  
Azure функција која омогућава Azure сервисима аутоматски управљану идентитет за аутентификацију према другим Azure сервисима.

**Microservices**  
Архитектонски приступ у којем се апликације граде као скуп малих, независних сервиса.

**Monitor**  
Јединствено Azure решење за праћење које пружа потпуну видљивост преко апликација и инфраструктуре.

## Н

**Node.js**  
JavaScript runtime изграђен на Chrome-овом V8 JavaScript engine-у за прављење серверских апликација.

**npm**  
Менаџер пакета за Node.js који управља зависностима и пакетима.

## О

**Output**  
Вредности које се враћају након Infrastructure деплојмента које апликације или други ресурси могу користити.

## П

**Package**  
Процес припреме кода апликације и зависности за деплојмент.

**Parameters**  
Улазне вредности прослеђене инфраструктурним шаблонима за прилагођавање деплојмента.

**PostgreSQL**  
Отворени систем релационих база података који се као управљани сервис подржава у Azure.

**Provisioning**  
Процес креирања и конфигурисања Azure ресурса дефинисаних у инфраструктурним шаблонима.

## К

**Quota**  
Ограничења у погледу количине ресурса који се могу креирати у Azure претплати или региону.

## Р

**Resource Group**  
Логички контејнер за Azure ресурсе који деле исти животни циклус, дозволе и политике.

**Resource Token**  
Јединствена низа генерисана од стране azd-а како би се обезбедила јединственост имена ресурса кроз деплојменте.

**REST API**  
Архитектонски стил за дизајнирање мрежних апликација користећи HTTP методе.

**Rollback**  
Процес враћања на претходну верзију апликације или конфигурације инфраструктуре.

## С

**Service**  
Компонента ваше апликације дефинисана у azure.yaml (нпр. веб фронтенд, API бектенд, база података).

**SKU**  
Stock Keeping Unit. Представља различите нивоје сервиса или нивоје перформанси за Azure ресурсе.

**SQL Database**  
Управљани релациони сервис база података Azure-а базиран на Microsoft SQL Server-у.

**Static Web Apps**  
Azure сервис за креирање и распоређивање веб апликација са потпуном стековском подршком из извора кода.

**Storage Account**  
Azure сервис који пружа облачно складиште за објекте података укључујући блобове, фајлове, редове и табеле.

**Subscription**  
Контејнер Azure налога који држи resource group-ове и ресурсе, са повезаним наплатама и управљањем приступом.

## Т

**Template**  
Унапред припремљена структура пројекта која садржи код апликације, дефиниције инфраструктуре и конфигурацију за уобичајене сценарије.

**Terraform**  
Отворени инфраструктурни алат Infrastructure as Code који подржава више провајдера облака укључујући Azure.

**Traffic Manager**  
Azure DNS базиран балансер оптерећења саобраћаја који распоређује саобраћај кроз глобалне Azure регионе.

## У

**URI**  
Uniform Resource Identifier. Низ који идентификује одређени ресурс.

**URL**  
Uniform Resource Locator. Тип URI који указује где се ресурс налази и како му приступити.

## В

**Virtual Network (VNet)**  
Основни грађевински блок за приватне мреже у Azure-у, који обезбеђује изолацију и сегментацију.

**VS Code**  
Visual Studio Code. Популаран уређивач кода са одличном интеграцијом за Azure и azd.

## Ш

**Webhook**  
HTTP повратни позив који се покреће одређеним догађајима, често коришћен у CI/CD пипелинима.

**What-if**  
Azure функција која показује које би измене биле направљене деплојментом без његовог реалног извршења.

## Ј

**YAML**  
YAML Ain't Markup Language. Стандард за серијализацију података који је читљив људима и користи се за конфигурационе фајлове као што је azure.yaml.

## З

**Zone**  
Физички одвојене локације унутар Azure региона које обезбеђују редунданцију и високу расположивост.

## Мапирање назива Azure сервиса

| Општи назив | Службени назив Azure сервиса | azd Host тип |
|-------------|------------------------------|---------------|
| Web App | Azure App Service | `appservice` |
| API App | Azure App Service | `appservice` |
| Container App | Azure Container Apps | `containerapp` |
| Function | Azure Functions | `function` |
| Static Site | Azure Static Web Apps | `staticwebapp` |
| Database | Azure Database for PostgreSQL | Инфраструктурни ресурс, није апликација `host` |
| NoSQL DB | Azure Cosmos DB | Инфраструктурни ресурс, није апликација `host` |
| Storage | Azure Storage Account | Инфраструктурни ресурс, није уграђена апликација `host` |
| Cache | Azure Managed Redis | Инфраструктурни ресурс, није апликација `host` |
| Search | Azure AI Search | Инфраструктурни ресурс, није апликација `host` |
| Messaging | Azure Service Bus | Инфраструктурни ресурс, није апликација `host` |

`services.<name>.host` одабира циљ деплојмента апликације; није кратка ознака за било коју врсту Azure ресурса. Базе података, кешеви, сервис претраге и редови обично се обезбеђују преко провајдера инфраструктуре и повезују са апликацијом кроз output-ове/конфигурацију.

## Контекстно специфични термини

### Термини за развој
- **Hot Reload**: Аутоматско освежавање апликација током развоја без потребе за рестартом
- **Build Pipeline**: Аутоматизовани процес израде и тестирања кода
- **Deployment Slot**: Предпроизводно окружење у оквиру App Service-а
- **Environment Parity**: Одздак начини да развојно, предпроизводно и продукцијско окружење буде слично

### Термини за безбедност
- **Managed Identity**: Azure функција која пружа аутоматско управљање акредитивима
- **Key Vault**: Безбедно складиштење тајни, кључева и сертификата
- **RBAC**: Контрола приступа заснована на улогама за Azure ресурсе
- **Network Security Group**: Виртуални заштитни зид за контролу мрежног саобраћаја

### Термини за мониторинг
- **Telemetry**: Аутоматизовано прикупљање мерења и података
- **Application Performance Monitoring (APM)**: Пратитељ перформанси софтвера
- **Log Analytics**: Сервис за прикупљање и анализу лог података
- **Alert Rules**: Аутоматизоване обавештења базирана на метрикама или условима

### Термини за деплојмент
- **Blue-Green Deployment**: Стратегија деплојмента без застојa
- **Canary Deployment**: Постепени избацивање промена делу корисника
- **Rolling Update**: Низно замењивање инстанци апликације
- **Rollback**: Враћање на претходну верзију апликације
