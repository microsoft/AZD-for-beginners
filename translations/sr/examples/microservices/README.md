# Пример микросервиса

Извршна имплементација и упутства налазе се у
**[container-app/microservices](../container-app/microservices/README.md)**.

Овај директоријум служи само за навигацију. Нема `azure.yaml`, `infra/`, или `src/`.
Не покрећи `azd up` овде.

Из корена репозиторијума:

```bash
cd examples/container-app/microservices
```

Затим пратите повезани README за предуслове, постављање, проверу, локални
развој, практичне вежбе, трошкове и чишћење.

Пример садржи Node.js API Gateway и само за читање Python Product Service.
Услуге за поруџбине, кориснике, обавештења, базу података и размену порука су идеје за проширења,
а не имплементације укључене у овај репозиторијум.

- [Претходно: Једноставан Flask API](../../../../examples/container-app/simple-flask-api)
- [Следеће: Апликација базе података](../../../../examples/database-app)
- [AI развој](../../docs/chapter-02-ai-development/README.md)
- [Почетна страница курса](../../README.md)
