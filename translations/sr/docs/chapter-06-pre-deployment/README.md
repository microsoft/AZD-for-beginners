# Поглавље 6: Планирање и валидација пре примене

**📚 Курс**: [AZD За почетнике](../../README.md) | **⏱️ Трајање**: 2-4 сата читања; додатно време за прилагођене лабараторије | **⭐ Комплексност**: Средњи-Напредни

---

## Преглед

Ово поглавље обухвата основне кораке у планирању и валидацији пре примене апликације. Научите како да избегнете скупе грешке уз правилно планирање капацитета, избор SKU-а и предпрелетне провере.

> Упутства за команду проверена у односу на објављени `azd 1.37.2` референцу. Облачно постављање није извршено. Дуже лекције укључују илустративне фрагменте, а не комплетне локалне пројекте постављања.

## Циљеви учења

Завршавајући ово поглавље, моћи ћете да:
- Покренете предпрелетне провере пре примене
- Планрате капацитет и процените потребе за ресурсима
- Изаберете одговарајуће SKU-ове за оптимизацију трошкова
- Конфигуришете Application Insights за надзор
- Разумете обрасце координације више агената и њихове захтеве за примену

## 🚀 Брзи почетак

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

---

## ☑️ Контролна листа пре примене

### Пре `azd provision`

- [ ] Проверена квота за регион
- [ ] Одговарајуће одабрани SKU-ови
- [ ] Прегледана процена трошкова
- [ ] Конзистентна конвенција именовања
- [ ] Конфигурисана безбедност/RBAC

### Пре `azd deploy`

- [ ] Постављене променљиве окружења
- [ ] Тајне у Key Vault-у
- [ ] Верификовани низови веза
- [ ] Конфигурисане здравствене провере

## 💰 Водич за избор SKU-а

| Оптерећење | Развој | Продукција |
|----------|-------------|------------|
| Container Apps | Конзумација | Конзумација или профил посебног оптерећења, на основу измереног оптерећења |
| App Service | B1/B2 | P1v3+ |
| Azure OpenAI модели | Подржани тип постављања на основу плаћања по коришћењу | Плаћање по коришћењу или приступ са обезбеђеним пропусним опсегом; зависно од модела/региона |
| AI Search | Бесплатни/Основни у оквиру ограничења | Основни или Стандардни ниво прилагођен за индекс, реплике и оптерећење упита |
