## 🚀 Брзи Почетак

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **Који приступ?** Користите `azd init --template` да започнете са радним примером. Користите `azd ai agent init` интерактивно, или `azd ai agent init --template <path-to-azure.yaml>` да усвојите тренутни агент пројекат. Погледајте [AZD AI CLI референцу](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) за захтеве верзије и миграцију евалуације.

Покрените ове алтернативе у посебним празним фасциклама. GA Foundry радни процес захтева `azd >= 1.37.0`; његов интерактивни ток не генерише прилагођени Service Bus пипелине у лекцији окоординације. За локално тестирање, постављање кода и чишћење нових и препакованих пројеката, пратите [упутство за host-agent](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga).

## 🎯 Истакнуто Решење: Рењил Мулти-Агент

Решење [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонстрира:

- **Агент за кориснике**: Руководи интеракцијама и преференцама корисника
- **Агент за залихе**: Управља залихама и обрадом поруџбина
- **Оркестратор**: Координише рад између агената
- **Заједничка меморија**: Управљање контекстом између агената

| Услуга | Сврха |
|---------|---------|

| Azure AI Search | Каталог производа |
| Cosmos DB | Станје и меморија агента |
| Container Apps | Хостовање агената |
| Application Insights | Надзор |
