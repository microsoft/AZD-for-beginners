## 🚀 Брзи почетак

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **Који приступ изабрати?** Користите `azd init --template` да почнете од радног примера. Користите `azd ai agent init` интерактивно, или `azd ai agent init --template <path-to-azure.yaml>` да преузмете постојећи агенатски пројекат. Погледајте [AZD AI CLI референцу](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) за захтеве верзије и миграцију процене.

Покрените ове алтернативе у посебним празним фолдерима. Проширење агената `1.0.0-beta.23` захтева `azd >= 1.37.0`; његов интерактивни ток не генерише прилагођени сервисни бас цевовод у лекцији о координацији.

## 🎯 Истакнуто решење: Вишеагентска малопродаја

Решење [Retail Multi-Agent Solution](../../examples/retail-scenario.md) показује:

- **Кориснички агент**: Управља интеракцијама и преференцама корисника

- **Оркестратор**: Координише агенте
