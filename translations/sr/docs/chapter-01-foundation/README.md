## Преглед

Ово поглавље уводи основе Azure Developer CLI (azd). Учићете основне појмове, инсталирати алате и распоређивати вашу прву апликацију на Azure.

> Циљ командне линије и преглед конфигурације: `azd 1.37.2` (новембар 2026). Ливе Azure постављање није покренуто током прегледа.

## Циљеви Учења

Након завршетка овог поглавља, ви ћете:
- Разумети шта је Azure Developer CLI и како се разликује од Azure CLI
- Инсталирати и конфигурисати AZD на вашој платформи
- Распоређивати вашу прву апликацију на Azure са `azd up`
- Очистити ресурсе помоћу `azd down`

## ✅ Почните Овде: Потврдите Ваше Подешавање

Пре него што почнете, проверите да ли је ваш локални рачунар спреман за шаблон Поглавља 1:

**Windows:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

Ако скрипта прикаже да недостају алати, прво решите то, па наставите са поглављем.

---

## 🚀 Брзи Почетак

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ Критеријуми Успеха

Након завршетка овог поглавља требало би да будете у могућности да:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
