# Поглавље 7: Решавање проблема и отклањање грешака

**📚 Курс**: [AZD за почетнике](../../README.md) | **⏱️ Трајање**: 1-1.5 сат | **⭐ Комплексност**: Средњи ниво

---

## Преглед

Ово поглавље вам помаже да дијагностикујете и решите уобичајене проблеме при раду са Azure Developer CLI. Од неуспеха у имплементацији до проблема специфичних за AI.

> Упутство за команде прегледано у односу на објављени `azd 1.37.2` референцу. Cloud имплементације нису извршаване. Замените пример имена ресурса и ИД-ове пре коришћења команди.

## Циљеви учења

Завршетком овог поглавља, ви ћете:
- Дијагностиковати уобичајене AZD неуспехе у имплементацији
- Отклањати проблеме са аутентификацијом и дозволама
- Решити проблеме повезаности AI сервиса
- Користити Azure портал и CLI за решавање проблема

## 🚨 Брза решења

### Проблеми са аутентификацијом
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### Неуспех имплементације
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### Суконфликти ресурса
Прво прегледајте постојеће ресурсе и грешке у имплементацији. Немојте брисати заједничко или продукцијско окружење да бисте решили конфликт имена. За **ново окружење за једнократну употребу**, користите јединствено име:

```bash
azd env new different-name
azd up
```

### Прекорачење квоте
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

Промена `AZURE_LOCATION` не помера постојеће ресурсе и може изазвати конфликт локација приликом поновне имплементације.

## 📋 Референца кодова грешака

| Грешка | Узрок | Решење |
|-------|-------|----------|
| `AuthenticationError` | Није пријављен | `azd auth login` |
| `ResourceNotFound` | Недостаје ресурс | Проверите имена ресурса |
| `QuotaExceeded` | Ограничења претплате | Затражите повећање квоте |
| `InvalidTemplate` | Синтаксна грешка у Bicep-у | `az bicep build` |
| `Conflict` | Ресурс већ постоји | Користите ново име или избришите |
| `Forbidden` | Недовољне дозволе | Проверите RBAC улоге |

## 🔄 Ресетовање и опоравак

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

Тврд ресет брише податке и може променити крајње тачке. Прво направите резервну копију и пажљиво проверите интерактивне упите за брисање. `--force --purge` је прикладан само за окружења за једнократну употребу када је планирано неповратно брисање.
