## Преглед

Ово поглавље покрива обрасце за производњу спремну за предузећа, осигурање безбедности, надгледање и оптимизацију трошкова за радна оптерећења вештачке интелигенције у производњи.

Ово је архитектонска референца, а не комплетан производни шаблон за имплементацију. Примери изостају детаљи интеграције који морају бити обезбеђени и тестирани у вашој апликацији; читање контролне листе не потврђује спремност за производњу.

> **Преглед издања (2026-11-04):** Упутство за AI CLI проверено је у односу на документацију/изворе `azd 1.37.2`, агенте `1.0.0-beta.23`, и евалуације `1.0.0-beta.2` . Погледајте [промене и исправке издања](production-ai-practices.md#recent-release-changes-and-fixes) за захтеве компатибилности и детаље миграције; ово није валидација директне имплементације.

## Циљеви учења

Завршетком овог поглавља, бићете у стању да:
- Имплементирате мултирегионалне отпорне апликације
- Примeните безбедносне обрасце за предузећа
- Конфигуришете свеобухватно надгледање
- Оптимизујете трошкове у великом обиму
- Поставите CI/CD цевоводе са AZD

## 💰 Оптимизација трошкова

| Стратегија | Главно ограничење |
|----------|---------|
| Скалирање на нулу (Container Apps) | Захтева одговарајући тригер; друге услуге и даље стварају трошкове |
| Користити tier-ове по потрошњи за развој | Упоредити цену изабране услуге и оптерећење |
| Распоредно скалирање | Скале у складу са подржаном инфраструктуром/аутоматизацијом |
| Резервације/постојећи капацитет | Само ако је подржано; обавезе могу повећати трошкове празног хода |

Користите [комплетан образац буџета ресурса](production-ai-practices.md#2-cost-monitoring-and-budgets) са важећим датумом почетка, обимом наплате, примаоцима и дозволама. Буџет шаље упозорења; не поставља лимит на трошкове. Уштеде зависе од мериене искоришћености и нису загарантовани проценти.

## 📊 Постављање надгледања

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
