## Преглед

Ово поглавље покрива обрасце распореда спремних за предузећа, повећање безбедности, мониторинг и оптимизацију трошкова за производне AI радне оптерећења.

Ово је архитектонски референтни материјал, а не комплетан образац за производњу спреман за деплој. Примери изостављају детаље интеграције који морају бити обезбеђени и тестирани у вашој апликацији; читање чек-листе не потврђује спремност за производњу.

> **Ажурирање Foundry GA (2026-11-09):** Користите `azd >= 1.37.0` и општо доступни пакет `microsoft.foundry` 1.0 за Foundry workflow; евалуације се инсталирају посебно. Погледајте [опсег и миграција верзије](production-ai-practices.md#recent-release-changes-and-fixes) и [пример аутентификованог pipeline](production-ai-practices.md#cicd-pipeline-configuration). Ово је преглед документације, а не валидација живог распореда или општи статус GA за опционе preview функције.

## Циљеви учења

Завршавањем овог поглавља, моћи ћете да:
- Распоредите отпорне апликације у више региона
- Имплементирате безбедносне обрасце за предузећа
- Конфигуришете свеобухватни мониторинг
- Оптимизујете трошкове у великом обиму
- Подесите CI/CD pipeline користећи AZD

## 💰 Оптимизација трошкова

| Стратегија | Главно ограничење |
|----------|---------|
| Скалирање на нулу (Container Apps) | Захтева одговарајући тригер; остале услуге и даље праве трошкове |
| Користите tiers за потрошњу у развоју | Упоредите цену изабране услуге и радно оптерећење |
| Распоредно скалирање | Скалирање кроз подржану инфраструктуру/аутоматизацију |
| Резервације/резервисани капацитет | Само када је подржано; обавезе могу повећати трошкове мировања |

Користите [потпуни образац ресурса за буџет](production-ai-practices.md#2-cost-monitoring-and-budgets) са важећим датумом почетка, опсегом наплате, примаоцима и дозволама. Буџет шаље упозорења; не ограничава потрошњу. Уштеда зависи од измерене искоришћености и није загарантован проценат.

## 📊 Подешавање мониторинга

```bash
# Open the Application Insights logs view (requires configured monitoring)

azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
