# Exemplu Microservicii

Implementarea rulabilă și instrucțiunile sale sunt în
**[container-app/microservices](../container-app/microservices/README.md)**.

Acest director este doar pentru navigare. Nu conține `azure.yaml`, `infra/` sau `src/`.
Nu rulați `azd up` aici.

Din rădăcina depozitului:

```bash
cd examples/container-app/microservices
```

Apoi urmați README-ul legat pentru cerințe prealabile, implementare, verificare, dezvoltare locală,
exerciții practice, costuri și curățare.

Exemplul conține un API Gateway Node.js și un serviciu Python Product doar în citire.
Serviciile de comandă, utilizator, notificare, baze de date și mesagerie sunt idei de extensie,
nu implementări incluse în acest depozit.
