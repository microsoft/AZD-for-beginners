# Contoh Microservices

Pelaksanaan yang boleh dijalankan dan arahan-arahannya terdapat di
**[container-app/microservices](../container-app/microservices/README.md)**.

Direktori ini hanya untuk navigasi. Ia tidak mempunyai `azure.yaml`, `infra/`, atau `src/`.
Jangan jalankan `azd up` di sini.

Dari akar repositori:

```bash
cd examples/container-app/microservices
```

Kemudian ikuti README yang dipautkan untuk prasyarat, penghantaran, pengesahan, pembangunan tempatan,
latihan praktikal, kos, dan pembersihan.

Contoh mengandungi API Gateway Node.js dan Perkhidmatan Produk Python yang hanya baca.
Perkhidmatan pesanan, pengguna, pemberitahuan, pangkalan data, dan pemesejan adalah idea lanjutan,
bukan pelaksanaan yang termasuk dalam repositori ini.

- [Sebelumnya: API Flask Mudah](../../../../examples/container-app/simple-flask-api)
- [Seterusnya: Aplikasi Pangkalan Data](../../../../examples/database-app)
- [Pembangunan AI](../../docs/chapter-02-ai-development/README.md)
- [Halaman Kursus](../../README.md)
