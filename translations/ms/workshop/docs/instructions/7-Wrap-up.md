## 2. Konsep Utama yang Dikuasai

### Azure Developer CLI (azd)
- `azd init` - Memulakan projek dari templat
- `azd up` - Menyediakan dan melaksanakan dengan satu arahan
- `azd env` - Menguruskan pemboleh ubah persekitaran
- `azd down` - Membersihkan sumber dengan selamat

### Struktur Templat AZD
- `azure.yaml` - Konfigurasi dan hook pelaksanaan
- `infra/` - Infrastruktur sebagai kod Bicep
- `src/` - Kod sumber aplikasi
- `scripts/` - Skrip automasi dan penyediaan

### Keupayaan Microsoft Foundry
- Perkhidmatan Ejen AI untuk pembantu pintar
- Carian Fail dan Azure AI Search untuk pengambilan pengetahuan
- Penjejakan, pemantauan dan penilaian terbina dalam
- Red teaming untuk pengesahan keselamatan AI
