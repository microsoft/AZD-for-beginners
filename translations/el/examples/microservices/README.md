# Παράδειγμα Μικροϋπηρεσιών

Η εκτελέσιμη υλοποίηση και οι οδηγίες της βρίσκονται στο
**[container-app/microservices](../container-app/microservices/README.md)**.

Αυτός ο κατάλογος είναι μόνο για πλοήγηση. Δεν έχει `azure.yaml`, `infra/` ή `src/`.
Μην εκτελέσετε `azd up` εδώ.

Από τη ρίζα του αποθετηρίου:

```bash
cd examples/container-app/microservices
```

Στη συνέχεια ακολουθήστε το συνδεδεμένο README για τις προϋποθέσεις, την ανάπτυξη, την επαλήθευση, την τοπική
ανάπτυξη, τις πρακτικές ασκήσεις, τα κόστη και τον καθαρισμό.

Το δείγμα περιλαμβάνει ένα Node.js API Gateway και μια μόνο για ανάγνωση Python Product Service.
Οι υπηρεσίες παραγγελίας, χρήστη, ειδοποιήσεων, βάσης δεδομένων και μηνυμάτων είναι ιδέες επέκτασης,
όχι υλοποιήσεις που περιλαμβάνονται σε αυτό το αποθετήριο.

- [Προηγούμενο: Απλό Flask API](../../../../examples/container-app/simple-flask-api)
- [Επόμενο: Εφαρμογή βάσης δεδομένων](../../../../examples/database-app)
- [Ανάπτυξη AI](../../docs/chapter-02-ai-development/README.md)
- [Αρχική σελίδα μαθήματος](../../README.md)
