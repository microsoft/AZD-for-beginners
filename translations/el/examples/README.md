# Παραδείγματα — Αγγλική Πηγή και Δείγματα Azure

Αυτά είναι δείγματα εκμάθησης, όχι εφαρμογές πιστοποιημένες για παραγωγή. Διαβάστε τις
προϋποθέσεις, τους περιορισμούς, τα κόστη και τις οδηγίες καθαρισμού κάθε παραδείγματος πριν
εκτελέσετε τις εντολές. Η διαθεσιμότητα και τα όρια του Azure πρέπει να ελεγχθούν στη συνδρομή σας.

- [Αρχική σελίδα μαθήματος](../README.md)
- [Εγκατάσταση](../docs/chapter-01-foundation/installation.md)
- [Αντιμετώπιση προβλημάτων](../docs/chapter-07-troubleshooting/common-issues.md)

## Τι υπάρχει πραγματικά τοπικά

Υπάρχουν **τέσσερα δείγματα εφαρμογών** και **μία σκαλωσιά υποδομής**:

| Παράδειγμα | Τοπική υλοποίηση | Εστίαση εκμάθησης | Επίπεδο |
|---|---|---|---|
| [Απλό Flask API](../../../examples/container-app/simple-flask-api) | Flask CRUD API, Dockerfile, Bicep, `azure.yaml` | Ανάπτυξη κοντέινερ, probes, αρχεία καταγραφής | Αρχάριος |
| [Μικροϋπηρεσίες δύο υπηρεσιών](../../../examples/container-app/microservices) | Node.js gateway και υπηρεσία μόνο για ανάγνωση προϊόντων Python, Dockerfiles, Bicep, `azure.yaml` | Εσωτερική επικοινωνία HTTPS, ανεξάρτητη κλιμάκωση | Μεσαίο |
| [Εφαρμογή βάσης δεδομένων](../../../examples/database-app) | Flask read API, Azure SQL, App Service, Bicep, `azure.yaml` | Συνδεσιμότητα SQL, αρχικοποίηση, αρχεία καταγραφής | Μεσαίο |
| [Azure OpenAI chat](../../../examples/azure-openai-chat) | Τοπικό Python CLI, Azure OpenAI και Key Vault Bicep, μόνο υποδομή `azure.yaml` | Προμήθεια μοντέλου, ιστορικό συνομιλιών, εκτιμήσεις tokens | Μεσαίο |
| [Υποδομή λιανικής πώλησης](../../../examples/retail-multiagent-arm-template) | ARM template, παραμέτροι, σενάριο ανάπτυξης Bash; **μόνο κοντέινερ hello-world** | Υποδομή για μελλοντική εφαρμογή πολλαπλών πρακτόρων | Προχωρημένο |

Το [σενάριο λιανικής πώλησης](retail-scenario.md) είναι ένα **σχέδιο αρχιτεκτονικής**, όχι
πλήρης υλοποίηση πολλαπλών πρακτόρων. Δεν περιλαμβάνει κώδικα πράκτορα λιανικής, frontend συνομιλίας,
API δρομολογητή, pipeline δεδομένων αναζήτησης, CLI αξιολόγησης, αυτόματη εναλλαγή, ή
ενισχύσεις παραγωγής. Αυτά πρέπει να σχεδιαστούν, να κατασκευαστούν και να δοκιμαστούν ξεχωριστά.

Η [επισκόπηση μικροϋπηρεσιών](microservices/README.md) δείχνει στο εκτελέσιμο
δείγμα δύο υπηρεσιών· δεν είναι ένας άλλος φάκελος ανάπτυξης.

## Προτεινόμενη πορεία εκμάθησης

1. Αναπτύξτε το Flask API και επαληθεύστε το `/health` και τις CRUD λειτουργίες.
2. Αναπτύξτε την εφαρμογή βάσης δεδομένων και επαληθεύστε τα πέντε σπόρια προϊόντων.
3. Αναπτύξτε το παράδειγμα δύο υπηρεσιών και επαληθεύστε τα αιτήματα από gateway σε προϊόν.
4. Προμηθευτείτε τους πόρους συνομιλίας και τρέξτε το διαδραστικό CLI **τοπικά**.
5. Μελετήστε το σχέδιο λιανικής πώλησης μετά την ολοκλήρωση των λειτουργικών δειγμάτων.

Αφιερώστε περίπου 30–60 λεπτά ανά δείγμα εφαρμογής μαζί με τις προϋποθέσεις και την
επαλήθευση. Η υλοποίηση λιανικής είναι ξεχωριστό έργο ανάπτυξης, όχι
εργαστήριο 30 λεπτών. Η ανάγνωση της αρχιτεκτονικής παίρνει περίπου 2–3 ώρες· υλοποίηση
και ετοιμότητα για παραγωγή μπορεί να διαρκέσουν σημαντικά περισσότερο από τις ενδεικτικές
80–120 ώρες ανάπτυξης στον οδηγό.

## Γρήγορη εκκίνηση

Από τη ρίζα του αποθετηρίου, για το πρώτο δείγμα κοντέινερ:

```bash
cd examples/container-app/simple-flask-api
azd auth login
azd env new flask-demo
azd up
API_URL=$(azd env get-value API_ENDPOINT)
curl --fail-with-body "${API_URL}/health"
```

Αναμενόμενο: HTTP 200 και JSON που περιέχει `"status": "healthy"`.
Πρέπει να τρέχει το Docker για το τοπικό χτίσιμο του κοντέινερ.

Για συνομιλία, ακολουθήστε το [chat README](azure-openai-chat/README.md): χρησιμοποιήστε
`azd provision`, φορτώστε το API key από το Key Vault στο τρέχον shell, εγκαταστήστε
`src/requirements.txt`, και τρέξτε `python src/chat.py`. Δεν υπάρχει φιλοξενούμενη υπηρεσία συνομιλίας.

Για τη λιανική, χρησιμοποιήστε τον [οδηγό ARM](retail-multiagent-arm-template/README.md).
Δεν έχει `azure.yaml` και **δεν** αναπτύσσεται ή αφαιρείται από `azd up`/`azd down`.

## Κόστη και περιορισμοί

- Όλες οι αναπτύξεις δημιουργούν χρεώσιμους πόρους Azure. Το scale-to-zero εφαρμόζεται
  μόνο στο app compute· δεν εξαλείφει τα κόστη registry, βάσης δεδομένων, αποθήκευσης, αναζήτησης ή αρχείων καταγραφής.
- Οι ακριβείς τιμές εξαρτώνται από την περιοχή, το νόμισμα, την κίνηση, το μοντέλο/SKU, και τη διατήρηση.
  Χρησιμοποιήστε τον [υπολογιστή τιμολόγησης Azure](https://azure.microsoft.com/pricing/calculator/)
  πριν την ανάπτυξη και διαμορφώστε προϋπολογισμό στο Azure Cost Management.
- Τα δεδομένα Flask CRUD βρίσκονται στη μνήμη, περιορισμένα σε έναν μόνο worker και το πολύ μια replica από
  προεπιλογή. Χάνονται σε επανεκκίνηση ή scale-to-zero. Δεν είναι διαρκής αποθήκευση.
- Η μικροϋπηρεσία προϊόντος εκθέτει μόνο GET endpoints. Δεν περιλαμβάνεται υπηρεσία παραγγελίας,
  υπηρεσία χρήστη, βάση δεδομένων, Service Bus, C# ή Go υλοποίηση.
- Οι πόροι Application Insights δεν ορίζουν αυτόματα μέτρηση για κάθε εφαρμογή.
  Συμβουλευτείτε κάθε παράδειγμα για την πραγματική τηλεμετρία που εκπέμπεται.
- Τα δείγματα δεν εφαρμόζουν αυθεντικοποίηση εφαρμογής. Προσθέστε ταυτότητα, εξουσιοδότηση,
  μόνιμη αποθήκευση, δικτυακούς ελέγχους, δοκιμές, και διαδικασίες λειτουργίας πριν την παραγωγή.

## Δομή αποθετηρίου

```text
examples/
├── azure-openai-chat/               # Local CLI + model infrastructure
├── container-app/
│   ├── simple-flask-api/            # Single Flask API
│   └── microservices/               # Gateway + read-only product service
├── database-app/                    # Flask + Azure SQL on App Service
├── microservices/README.md          # Navigation to the canonical example
├── retail-multiagent-arm-template/  # Infrastructure scaffold only
└── retail-scenario.md               # Architecture blueprint
```

Δεν υπάρχει κοινός `configurations/`, `scripts/` ή φάκελος δοκιμών που να υποσχόμαστε σε
αυτόν τον κατάλογο. Τα πραγματικά αρχεία και οι προαιρετικές ιδέες επεκτάσεων προσδιορίζονται σε κάθε οδηγό.

## Καθαρισμός

Για τα τέσσερα δείγματα AZD, εκτελέστε αυτό **από τον επιλεγμένο κατάλογο δειγμάτων**:

```bash
azd down
```

Εξετάστε την προτροπή διαγραφής. Για τη λιανική, διαγράψτε μόνο την αφιερωμένη ομάδα πόρων
που δημιουργήσατε, χρησιμοποιώντας τις οδηγίες στον οδηγό ARM της. Ελέγξτε το Azure Cost Management
μετά τον καθαρισμό· τα δεδομένα χρέωσης μπορεί να έρθουν αργότερα.
