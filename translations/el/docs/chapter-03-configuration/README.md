## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει τη ρύθμιση περιβάλλοντος, πρότυπα αυθεντικοποίησης και βέλτιστες πρακτικές ασφαλείας για αναπτύξεις Azure Developer CLI.

> Στόχος αναθεώρησης εντολών και ρυθμίσεων: `azd 1.37.2` (Νοέμβριος 2026). Η ζωντανή παροχή Azure δεν εκτελέστηκε κατά την αναθεώρηση.

## Στόχοι Μάθησης

Ολοκληρώνοντας αυτό το κεφάλαιο, θα:
- Εμπεδώσετε την ιεραρχία ρυθμίσεων AZD
- Διαχειρίζεστε πολλαπλά περιβάλλοντα (ανάπτυξη, δοκιμή, παραγωγή)
- Εφαρμόσετε ασφαλή αυθεντικοποίηση με διαχειριζόμενες ταυτότητες
- Ρυθμίσετε ειδικές ρυθμίσεις ανά περιβάλλον

## 🚀 Γρήγορη Έναρξη

Εκτελέστε από τη ρίζα μιας **ήδη αρχικοποιημένης εφαρμογής azd**, όχι από το αποθετήριο του μαθήματος. Χρησιμοποιήστε μη χρησιμοποιημένα ονόματα περιβάλλοντος αν αυτά υπάρχουν ήδη.

```bash
# Create multiple environments
azd env new dev
azd env new staging
azd env new prod

# Switch environments
azd env select prod

# Set environment variables
azd env set AZURE_LOCATION eastus
azd env set SKU_NAME P1v3

# View configuration
azd env get-values
```

`SKU_NAME` είναι ενδεικτικό: επηρεάζει την υποδομή μόνο αν το πρότυπό σας το χρησιμοποιεί ρητά. Κανονικές τιμές `azd env set` αποθηκεύονται τοπικά σε απλό κείμενο∙ δεν είναι ασφαλής αποθήκευση μυστικών.

## 🔧 Ιεραρχία Ρύθμισης

Κρατήστε τρεις διαφορετικές επιφάνειες ρύθμισης ξεχωριστές: παγκόσμιες προτιμήσεις (`azd config`), δομή έργου (`azure.yaml`) και τιμές ανά περιβάλλον (`azd env`). Τα flags παρακάμπτουν μόνο τις ρυθμίσεις που υποστηρίζουν πραγματικά· δεν υπάρχει καθολική επισύμφηση αυθαίρετων μεταβλητών περιβάλλοντος σε `azure.yaml` ή Bicep.

## 🔐 Βέλτιστες Πρακτικές Ασφαλείας

```bash
# Runtime managed identity must be enabled in infrastructure and granted RBAC.
# To authenticate azd itself on an Azure host with an assigned identity:
# azd auth login --managed-identity

# Check AZD authentication status
azd auth login --check-status

# Optional: verify Azure CLI context if you plan to run az commands
az account show

# Re-authenticate if needed
azd auth login

# Optional: refresh Azure CLI authentication for az commands
az login
```
