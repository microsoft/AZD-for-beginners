## Επισκόπηση

Αυτό το κεφάλαιο εισάγει τις βασικές έννοιες του Azure Developer CLI (azd). Θα μάθετε βασικές έννοιες, θα εγκαταστήσετε τα εργαλεία, και θα αναπτύξετε την πρώτη σας εφαρμογή στο Azure.

> Στόχος ανασκόπησης εντολών και ρυθμίσεων: `azd 1.37.2` (Νοέμβριος 2026). Η ζωντανή προμήθεια Azure δεν εκτελέστηκε κατά την ανασκόπηση.

## Στόχοι Μάθησης

Ολοκληρώνοντας αυτό το κεφάλαιο, θα:
- Κατανοήσετε τι είναι το Azure Developer CLI και πώς διαφέρει από το Azure CLI
- Εγκαταστήσετε και ρυθμίσετε το AZD στην πλατφόρμα σας
- Αναπτύξετε την πρώτη σας εφαρμογή στο Azure με το `azd up`
- Καθαρίσετε πόρους με το `azd down`

## 🚀 Γρήγορη Έναρξη

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ Κριτήρια Επιτυχίας

Μετά την ολοκλήρωση αυτού του κεφαλαίου, θα πρέπει να μπορείτε να:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
