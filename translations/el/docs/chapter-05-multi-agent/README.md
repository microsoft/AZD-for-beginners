# Κεφάλαιο 5: Λύσεις Τεχνητής Νοημοσύνης με Πολλαπλούς Πράκτορες

**📚 Μάθημα**: [AZD Για Αρχάριους](../../README.md) | **⏱️ Διάρκεια**: 2-3 ώρες | **⭐ Πολυπλοκότητα**: Προχωρημένο

---

## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει προχωρημένα πρότυπα αρχιτεκτονικής πολλαπλών πρακτόρων, ορχήστρωση πρακτόρων και αναπτύξεις τεχνητής νοημοσύνης έτοιμες για παραγωγή σε σύνθετα σενάρια.

> Η καθοδήγηση εντολών ελέχθηκε με βάση την απελευθερωμένη `azd 1.37.2` αναφορά. Δεν εκτελέστηκαν αναπτύξεις στο cloud.

## Στόχοι Μάθησης

Με την ολοκλήρωση αυτού του κεφαλαίου, θα:
- Κατανοήσετε πρότυπα αρχιτεκτονικής πολλαπλών πρακτόρων
- Αναπτύξετε συντονισμένα συστήματα πρακτόρων τεχνητής νοημοσύνης
- Υλοποιήσετε επικοινωνία πράκτορα προς πράκτορα
- Δημιουργήσετε λύσεις πολλαπλών πρακτόρων έτοιμες για παραγωγή

## 🚀 Γρήγορη Εκκίνηση

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **Ποια προσέγγιση;** Χρησιμοποιήστε `azd init --template` για να ξεκινήσετε από ένα λειτουργικό δείγμα. Χρησιμοποιήστε `azd ai agent init` διαδραστικά, ή `azd ai agent init --template <path-to-azure.yaml>` για να υιοθετήσετε ένα τρέχον έργο πράκτορα. Δείτε την [αναφορά AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) για απαιτήσεις έκδοσης και διαχείριση μετάβασης.

Τρέξτε αυτές τις εναλλακτικές σε ξεχωριστούς άδειους φακέλους. Η επέκταση πρακτόρων `1.0.0-beta.23` απαιτεί `azd >= 1.37.0`· η διαδραστική ροή της δεν δημιουργεί το προσαρμοσμένο κανάλι Service Bus στο μάθημα συντονισμού.

## 🎯 Προτεινόμενη Λύση: Λιανική Πολλαπλών Πρακτόρων

Η [Λύση Πολλαπλών Πρακτόρων Λιανικής](../../examples/retail-scenario.md) demonstrάει:

- **Πράκτορας Πελάτη**: Διαχειρίζεται αλληλεπιδράσεις και προτιμήσεις χρήστη
- **Πράκτορας Αποθεμάτων**: Διαχειρίζεται απόθεμα και επεξεργασία παραγγελιών
- **Ορχήστρα**: Συντονίζει μεταξύ των πρακτόρων
- **Κοινή Μνήμη**: Διαχείριση περιβάλλοντος μεταξύ πρακτόρων

| Υπηρεσία | Σκοπός |
|---------|---------|
| Microsoft Foundry Models | Κατανόηση γλώσσας |
| Azure AI Search | Κατάλογος προϊόντων |
| Cosmos DB | Κατάσταση και μνήμη πρακτόρων |
| Container Apps | Φιλοξενία πρακτόρων |
| Application Insights | Παρακολούθηση |
