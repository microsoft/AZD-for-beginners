**📚 Μάθημα**: [AZD Για Αρχάριους](../../README.md) | **⏱️ Διάρκεια**: 2-3 ώρες | **⭐ Πολυπλοκότητα**: Προχωρημένο

---

## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει προχωρημένα μοτίβα αρχιτεκτονικής πολλαπλών πρακτόρων, ορχήστρωση πρακτόρων και παραγωγικές αναπτύξεις τεχνητής νοημοσύνης για πολύπλοκα σενάρια.

> Οι οδηγίες εντολών αναθεωρήθηκαν σε σχέση με το κυκλοφορημένο `azd 1.37.2` αναφορά. Δεν εκτελέστηκαν αναπτύξεις στο cloud.

## Στόχοι Μάθησης

Με την ολοκλήρωση αυτού του κεφαλαίου, θα:
- Κατανοήσετε τα μοτίβα αρχιτεκτονικής πολλαπλών πρακτόρων
- Αναπτύξετε συντονισμένα συστήματα πράκτορων τεχνητής νοημοσύνης
- Εφαρμόσετε επικοινωνία μεταξύ πρακτόρων
- Δημιουργήσετε παραγωγικές λύσεις με πολλούς πράκτορες

## 🚀 Γρήγορη Έναρξη

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **Ποια προσέγγιση;** Χρησιμοποιήστε `azd init --template` για να ξεκινήσετε από ένα λειτουργικό δείγμα. Χρησιμοποιήστε `azd ai agent init` διαδραστικά, ή `azd ai agent init --template <path-to-azure.yaml>` για να υιοθετήσετε ένα τρέχον έργο πράκτορα. Δείτε την [αναφορά AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) για απαιτήσεις έκδοσης και μετάβαση αξιολόγησης.

Εκτελέστε αυτές τις εναλλακτικές σε ξεχωριστούς άδειους φακέλους. Η ροή εργασίας GA Foundry απαιτεί `azd >= 1.37.0`· η διαδραστική ροή της δεν δημιουργεί τον προσαρμοσμένο αγωγό Service Bus στο μάθημα συντονισμού. Για τοπικές δοκιμές, ανάπτυξη κώδικα και καθαρισμό νέων έναντι επαναχρησιμοποιημένων έργων, ακολουθήστε τον [περπατηματικό οδηγό για hosted-agent](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga).

## 🎯 Επιλεγμένη Λύση: Λιανική με Πολλούς Πράκτορες

Η [Λύση Λιανικής με Πολλούς Πράκτορες](../../examples/retail-scenario.md) παρουσιάζει:

- **Πράκτορας Πελάτη**: Διαχειρίζεται τις αλληλεπιδράσεις και τις προτιμήσεις χρήστη
- **Πράκτορας Αποθεμάτων**: Διαχειρίζεται τα αποθέματα και την επεξεργασία παραγγελιών
- **Ορχηστρωτής**: Συντονίζει μεταξύ των πρακτόρων
- **Κοινή Μνήμη**: Διαχείριση συμφραζομένων μεταξύ πρακτόρων

### Χρησιμοποιημένες Υπηρεσίες

| Υπηρεσία | Σκοπός |
|---------|---------|
| Microsoft Foundry Models | Κατανόηση γλώσσας |
| Azure AI Search | Κατάλογος προϊόντων |
| Cosmos DB | Κατάσταση και μνήμη πρακτόρων |
| Container Apps | Φιλοξενία πρακτόρων |
| Application Insights | Παρακολούθηση |
