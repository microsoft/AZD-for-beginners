**📚 Μάθημα**: [AZD Για Αρχάριους](../../README.md) | **⏱️ Διάρκεια**: 2-3 ώρες | **⭐ Πολυπλοκότητα**: Προχωρημένο

---

## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει πρότυπα ανάπτυξης έτοιμα για επιχειρήσεις, ενίσχυση της ασφάλειας, παρακολούθηση και βελτιστοποίηση κόστους για εργασίες AI παραγωγής.

Αυτό είναι μια αρχιτεκτονική αναφορά, όχι ένα ολοκληρωμένο πρότυπο προς ανάπτυξη παραγωγής. Τα παραδείγματα παραλείπουν λεπτομέρειες ενσωμάτωσης που πρέπει να προστεθούν και να δοκιμαστούν στη δική σας εφαρμογή· η ανάγνωση της λίστας ελέγχου δεν πιστοποιεί ετοιμότητα παραγωγής.

> **Ανασκόπηση έκδοσης (2026-11-04):** Οι οδηγίες AI CLI ελέγχθηκαν σύμφωνα με την τεκμηρίωση/πηγή `azd 1.37.2`, τους πράκτορες `1.0.0-beta.23` και τις αξιολογήσεις `1.0.0-beta.2`. Δείτε [αλλαγές και διορθώσεις έκδοσης](production-ai-practices.md#recent-release-changes-and-fixes) για απαιτήσεις συμβατότητας και λεπτομέρειες μετανάστευσης· αυτή δεν είναι έγκυρη επικύρωση ζωντανής ανάπτυξης.

## Στόχοι Μάθησης

Ολοκληρώνοντας αυτό το κεφάλαιο, θα:
- Αναπτύσσετε πολυπεριφερειακές ανθεκτικές εφαρμογές
- Υλοποιήσετε πρότυπα ασφάλειας επιχειρήσεων
- Διαμορφώσετε ολοκληρωμένη παρακολούθηση
- Βελτιστοποιήσετε κόστη σε κλίμακα
- Στήσετε αγωγούς CI/CD με το AZD

## 💰 Βελτιστοποίηση Κόστους

| Στρατηγική | Κύριος Περιορισμός |
|----------|---------|
| Κλιμάκωση σε μηδέν (Container Apps) | Απαιτεί κατάλληλο ενεργοποιητή· άλλες υπηρεσίες εξακολουθούν να έχουν κόστος |
| Χρήση επιπέδων κατανάλωσης για ανάπτυξη | Σύγκριση τιμολόγησης επιλεγμένης υπηρεσίας και φόρτου εργασίας |
| Προγραμματισμένη κλιμάκωση | Κλιμάκωση μέσω υποστηριζόμενης υποδομής/αυτοματοποίησης |
| Κρατήσεις/διατεθειμένη χωρητικότητα | Μόνο όταν υποστηρίζεται· οι δεσμεύσεις μπορεί να αυξήσουν τα κόστη αδράνειας |

Χρησιμοποιήστε το [πλήρες πρότυπο πόρου προϋπολογισμού](production-ai-practices.md#2-cost-monitoring-and-budgets) με έγκυρη ημερομηνία έναρξης, πεδίο τιμολόγησης, παραλήπτες και δικαιώματα. Ένας προϋπολογισμός στέλνει ειδοποιήσεις· δεν περιορίζει τις δαπάνες. Οι εξοικονομήσεις εξαρτώνται από την μετρημένη χρήση και δεν είναι εγγυημένα ποσοστά.

## 📊 Ρύθμιση Παρακολούθησης

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
