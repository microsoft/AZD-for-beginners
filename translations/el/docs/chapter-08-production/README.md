# Κεφάλαιο 8: Πρότυπα Παραγωγής & Επιχειρήσεων

**📚 Μάθημα**: [AZD Για Αρχάριους](../../README.md) | **⏱️ Διάρκεια**: 2-3 ώρες | **⭐ Πολυπλοκότητα**: Προχωρημένο

---

## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει πρότυπα ανάπτυξης έτοιμα για επιχειρήσεις, ενίσχυση ασφάλειας, παρακολούθηση και βελτιστοποίηση κόστους για τις παραγωγικές εργασίες AI.

Πρόκειται για μία αρχιτεκτονική αναφορά, όχι για ένα πλήρες πρότυπο παραγωγής έτοιμο για ανάπτυξη. Τα παραδείγματα παραλείπουν λεπτομέρειες ενσωμάτωσης που πρέπει να παρέχονται και να δοκιμάζονται στην δική σας εφαρμογή· η ανάγνωση της λίστας ελέγχου δεν πιστοποιεί την ετοιμότητα για παραγωγή.

> **Ενημέρωση Foundry GA (2026-11-09):** Χρησιμοποιήστε `azd >= 1.37.0` και το γενικά διαθέσιμο `microsoft.foundry` 1.0 πακέτο για τη ροή εργασίας Foundry· οι αξιολογήσεις εγκαθίστανται ξεχωριστά. Δείτε [το πεδίο εφαρμογής έκδοσης και τη μετανάστευση](production-ai-practices.md#recent-release-changes-and-fixes) και το [παράδειγμα πιστοποιημένης ροής](production-ai-practices.md#cicd-pipeline-configuration). Πρόκειται για ανασκόπηση τεκμηρίωσης, όχι επιβεβαίωση ενεργής ανάπτυξης ή γενική κατάσταση GA για προαιρετικές λειτουργίες προεπισκόπησης.

## Στόχοι Μάθησης

Με την ολοκλήρωση αυτού του κεφαλαίου, θα:
- Αναπτύξετε εφαρμογές ανθεκτικές σε πολλαπλές περιοχές
- Υλοποιήσετε πρότυπα ασφάλειας επιχειρήσεων
- Ρυθμίσετε ολοκληρωμένη παρακολούθηση
- Βελτιστοποιήσετε το κόστος σε κλίμακα
- Διαμορφώσετε σωληνώσεις CI/CD με AZD

## 💰 Βελτιστοποίηση Κόστους

| Στρατηγική | Κύριος Περιορισμός |
|----------|---------|
| Κλιμάκωση στο μηδέν (Container Apps) | Απαιτεί κατάλληλο trigger· άλλες υπηρεσίες επιβαρύνουν ακόμα το κόστος |
| Χρήση επιπέδων κατανάλωσης για dev | Σύγκριση τιμολόγησης επιλεγμένης υπηρεσίας και φόρτου εργασίας |
| Προγραμματισμένη κλιμάκωση | Κλιμάκωση μέσω υποστηριζόμενης υποδομής/αυτοματοποίησης |
| Κρατήσεις/προετοιμασμένη χωρητικότητα | Μόνο όταν υποστηρίζεται· οι δεσμεύσεις μπορεί να αυξήσουν το κόστος αδράνειας |

Χρησιμοποιήστε το [πλήρες πρότυπο πόρου προϋπολογισμού](production-ai-practices.md#2-cost-monitoring-and-budgets) με έγκυρη ημερομηνία έναρξης, πεδίο χρέωσης, παραλήπτες και δικαιώματα. Ένας προϋπολογισμός στέλνει ειδοποιήσεις· δεν περιορίζει τις δαπάνες. Η εξοικονόμηση εξαρτάται από μετρημένη χρήση και δεν εγγυάται ποσοστά.

## 📊 Ρύθμιση Παρακολούθησης

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
```
