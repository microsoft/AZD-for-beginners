## Επισκόπηση

Αυτό το κεφάλαιο εστιάζει στην ανάπτυξη εφαρμογών με τεχνητή νοημοσύνη χρησιμοποιώντας το Azure Developer CLI και τις υπηρεσίες Microsoft Foundry. Από απλές εφαρμογές συνομιλίας τεχνητής νοημοσύνης έως έξυπνους πράκτορες με εργαλεία.

> **Ανασκόπηση έκδοσης (2026-11-04):** Οι οδηγίες AI CLI ελέγχθηκαν σε σχέση με την δημοσιευμένη τεκμηρίωση/πηγή `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23`, και `azure.ai.evaluations` `1.0.0-beta.2`. Χρησιμοποιήστε `azd >= 1.37.0` για την συνδυασμένη ροή εργασίας. Οι αξιολογήσεις χρησιμοποιούν τώρα τον ξεχωριστό χώρο ονομάτων `azd ai eval`· δείτε [αλλαγές έκδοσης και οδηγίες μετανάστευσης](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes). Αυτή δεν είναι επικύρωση ζωντανής ανάπτυξης.

## Στόχοι Μάθησης

Ολοκληρώνοντας αυτό το κεφάλαιο, θα:
- Αναπτύξετε εφαρμογές τεχνητής νοημοσύνης χρησιμοποιώντας προ-κατασκευασμένα πρότυπα AZD
- Κατανοήσετε την ενσωμάτωση Microsoft Foundry με το AZD
- Διαμορφώσετε και προσαρμόσετε πράκτορες τεχνητής νοημοσύνης με εργαλεία
- Αναπτύξετε εφαρμογές RAG (Ανάκτηση-Ενισχυμένη Γενιά)

## 🚀 Γρήγορη Εκκίνηση

Επιλέξτε μία επιλογή σε έναν νέο άδειο κατάλογο. Η τελευταία `.` αρχικοποιεί τον τρέχοντα κατάλογο· διαφορετικά, το AZD μπορεί να δημιουργήσει έναν υποκατάλογο χωρίς να αλλάξει ο κατάλογος εργασίας του κελύφους σας.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```
