# Κεφάλαιο 2: Ανάπτυξη AI-Πρώτα

**📚 Μάθημα**: [AZD Για Αρχάριους](../../README.md) | **⏱️ Διάρκεια**: 4-5 ώρες συμπεριλαμβανομένου του εργαστηρίου | **⭐ Πολυπλοκότητα**: Ενδιάμεσο

---

## Επισκόπηση

Αυτό το κεφάλαιο εστιάζει στην ανάπτυξη εφαρμογών με τεχνολογία AI χρησιμοποιώντας το Azure Developer CLI και τις υπηρεσίες Microsoft Foundry. Από απλές εφαρμογές chat με AI μέχρι έξυπνους πράκτορες με εργαλεία.

> **Ενημέρωση Foundry GA (2026-11-09):** Το `microsoft.foundry` 1.0 πακέτο είναι [γενικά διαθέσιμο](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). Χρησιμοποιήστε `azd >= 1.37.0`· οι αξιολογήσεις παραμένουν ξεχωριστή εγκατάσταση. Το [βήμα-βήμα με τον hosted-agent](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) καλύπτει τη δοκιμή Agent Inspector τοπικά και την απομακρυσμένη ανάπτυξη κώδικα. Πρόκειται για αναθεώρηση τεκμηρίωσης, όχι επικύρωση ζωντανής ανάπτυξης· οι προαιρετικές λειτουργίες προεπισκόπησης διατηρούν τη δική τους κατάσταση.

## Μαθησιακοί Στόχοι

Με την ολοκλήρωση αυτού του κεφαλαίου, θα:
- Αναπτύσσετε εφαρμογές AI χρησιμοποιώντας προ-κατασκευασμένα πρότυπα AZD
- Κατανοείτε την ενσωμάτωση Microsoft Foundry με το AZD
- Εγκαθιστάτε το πακέτο GA και δοκιμάζετε έναν hosted agent τοπικά πριν την ανάπτυξη του κώδικα στο Foundry
- Αναθεωρείτε `azure.yaml`, πόρους αξιολόγησης, και καθαρισμό νέου έναντι επαναχρησιμοποιημένου έργου
- Διαμορφώνετε και προσαρμόζετε AI agents με εργαλεία
- Αναπτύσσετε εφαρμογές RAG (Retrieval-Augmented Generation)

## 🚀 Γρήγορη Εκκίνηση

Επιλέξτε μία επιλογή σε έναν νέο κενό κατάλογο. Η τελική `.` αρχικοποιεί τον τρέχοντα κατάλογο· διαφορετικά, το AZD μπορεί να δημιουργήσει έναν υποκατάλογο χωρίς να αλλάξει τον κατάλογο εργασίας του shell σας.

Για τη **διαδρομή ανάπτυξης κώδικα hosted-agent GA**, ξεκινήστε με το [καθοδηγούμενο βήμα-βήμα](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga). Απαιτεί AZD 1.37.0+, τρέχον uv, Python 3.13+, δικαιώματα Foundry, και quota μοντέλου. Τα πλήρη πρότυπα εφαρμογών παρακάτω είναι εναλλακτικές, όχι προαπαιτούμενες για αυτό το βήμα-βήμα.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Ενημέρωση Κόστους

Αυτά είναι ενδεικτικά εύρη, όχι προσφορές ή όρια· η κίνηση μοντέλου, τα Search/compute SKUs, η περιοχή, και οι προαιρετικές λειτουργίες μπορούν να τα υπερβούν. Εξετάστε την τρέχουσα καθοδήγηση τιμολόγησης του δείγματος που επιλέξατε πριν την παροχή.

| Περιβάλλον | Εκτιμώμενο Μηνιαίο Κόστος |
|-------------|----------------------|
| Ανάπτυξη | $80-150 |
| Στάδιο Δοκιμών | $150-300 |
| Παραγωγή | $300-3,500+ |

**Καθαρισμός:** Αναθεωρήστε `azd down` πριν την επιβεβαίωση: για ένα νεοδημιουργημένο έργο Foundry διαγράφει την ομάδα πόρων και τα πάντα μέσα σε αυτήν. Για ένα επαναχρησιμοποιημένο έργο Foundry, αφήνει το έργο και τους πόρους agent στη θέση τους· ακολουθήστε τις [οδηγίες καθαρισμού στον οδηγό](microsoft-foundry-integration.md#7-clean-up-deliberately) για να αφαιρέσετε ανεπιθύμητους πόρους ξεχωριστά.
