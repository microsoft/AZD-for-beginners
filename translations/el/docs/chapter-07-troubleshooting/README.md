## Επισκόπηση

Αυτό το κεφάλαιο σας βοηθά να διαγνώσετε και να επιλύσετε κοινά θέματα κατά τη χρήση του Azure Developer CLI. Από αποτυχίες υλοποίησης μέχρι συγκεκριμένα προβλήματα AI.

> Η καθοδήγηση εντολών έχει ελεγχθεί σε σχέση με το δημοσιευμένο `azd 1.37.2` αναφορά. Οι υλοποιήσεις στο cloud δεν εκτελέστηκαν. Αντικαταστήστε τα παραδείγματα ονομάτων πόρων και IDs πριν χρησιμοποιήσετε τις εντολές.

## Μαθησιακοί Στόχοι

Ολοκληρώνοντας αυτό το κεφάλαιο, θα:
- Διαγνώσετε κοινές αποτυχίες υλοποίησης AZD
- Εντοπίσετε και επιλύσετε θέματα αυθεντικοποίησης και δικαιωμάτων
- Επιδιορθώσετε προβλήματα συνδεσιμότητας υπηρεσιών AI
- Χρησιμοποιήσετε το Azure Portal και CLI για την αντιμετώπιση προβλημάτων

## 🚨 Γρήγορες Επιδιορθώσεις

### Προβλήματα Αυθεντικοποίησης
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### Αποτυχίες Παροχής
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### Συγκρούσεις Πόρων
Εξετάστε πρώτα τους υπάρχοντες πόρους και τα σφάλματα υλοποίησης. Μην διαγράψετε ένα κοινόχρηστο ή παραγωγικό περιβάλλον για να επιλύσετε σύγκρουση ονόματος. Για ένα **νέο απορρίψιμο περιβάλλον**, χρησιμοποιήστε ένα μοναδικό όνομα:

```bash
azd env new different-name
azd up
```

### Υπέρβαση Ορίου
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

Η αλλαγή του `AZURE_LOCATION` δεν μετακινεί υπάρχοντες πόρους και μπορεί να προκαλέσει συγκρούσεις τοποθεσίας κατά την επαναυλοποίηση.

## 📋 Αναφορά Κωδικών Σφαλμάτων

| Σφάλμα | Αιτία | Λύση |
|-------|-------|----------|
| `AuthenticationError` | Μη συνδεδεμένος | `azd auth login` |
| `ResourceNotFound` | Λείπει πόρος | Ελέγξτε ονόματα πόρων |
| `QuotaExceeded` | Όρια συνδρομής | Αιτηθείτε αύξηση ορίου |
| `InvalidTemplate` | Σφάλμα σύνταξης Bicep | `az bicep build` |
| `Conflict` | Ο πόρος υπάρχει ήδη | Χρησιμοποιήστε νέο όνομα ή διαγράψτε |
| `Forbidden` | Ελλιπή δικαιώματα | Ελέγξτε ρόλους RBAC |

## 🔄 Επαναφορά και Ανάκτηση

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

Η σκληρή επαναφορά διαγράφει δεδομένα και μπορεί να αλλάξει τα σημεία σύνδεσης. Κάντε backup πρώτα και ελέγξτε τις διαδραστικές προτροπές διαγραφής. Το `--force --purge` είναι κατάλληλο μόνο για απορρίψιμα περιβάλλοντα όταν επιδιώκεται μη αναστρέψιμη διαγραφή.
