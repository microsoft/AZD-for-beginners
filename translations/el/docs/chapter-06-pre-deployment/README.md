## Επισκόπηση

Αυτό το κεφάλαιο καλύπτει βασικά βήματα προγραμματισμού και επαλήθευσης πριν την ανάπτυξη της εφαρμογής σας. Μάθετε να αποφεύγετε δαπανηρά λάθη με σωστό προγραμματισμό χωρητικότητας, επιλογή SKU και ελέγχους πριν την εκτέλεση.

> Οι εντολές ελέγχθηκαν έναντι της δημοσιευμένης αναφοράς `azd 1.37.2`. Δεν πραγματοποιήθηκαν αναπτύξεις στο cloud. Τα μεγαλύτερα μαθήματα περιλαμβάνουν ενδεικτικά αποσπάσματα, όχι πλήρη τοπικά έργα ανάπτυξης.

## Στόχοι Μάθησης

Με την ολοκλήρωση αυτού του κεφαλαίου, θα μπορείτε να:
- Εκτελείτε ελέγχους πριν την ανάπτυξη
- Προγραμματίζετε χωρητικότητα και εκτιμάτε απαιτήσεις πόρων
- Επιλέγετε κατάλληλα SKU για βελτιστοποίηση κόστους
- Ρυθμίζετε το Application Insights για παρακολούθηση
- Κατανοείτε τα μοτίβα συντονισμού πολλαπλών πρακτόρων και τις απαιτήσεις ανάπτυξής τους

## 🚀 Γρήγορη Εκκίνηση

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ Λίστα Ελέγχου πριν την Ανάπτυξη

### Πριν το `azd provision`

- [ ] Επαλήθευση ποσοστώσεων για την περιοχή
- [ ] Επιλογή SKU κατάλληλα
- [ ] Ανασκόπηση εκτίμησης κόστους
- [ ] Συνεπής ονοματοδοσία
- [ ] Διαμόρφωση ασφαλείας/RBAC

### Πριν το `azd deploy`

- [ ] Ορισμός μεταβλητών περιβάλλοντος
- [ ] Μυστικά στο Key Vault
- [ ] Επαλήθευση συμβολοσειρών σύνδεσης
- [ ] Διαμόρφωση ελέγχων υγείας
