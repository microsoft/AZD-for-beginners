## Εισαγωγή

Αυτή η ολοκληρωμένη γλωσσάριο παρέχει ορισμούς για όρους, έννοιες και ακρωνύμια που χρησιμοποιούνται στο Azure Developer CLI και στην ανάπτυξη στο cloud Azure. Απαραίτητη αναφορά για την κατανόηση τεχνικής τεκμηρίωσης, αντιμετώπιση προβλημάτων και αποτελεσματική επικοινωνία για έργα azd και υπηρεσίες Azure.

## Στόχοι Μάθησης

Χρησιμοποιώντας αυτό το γλωσσάριο, θα:
- Κατανοήσετε βασική ορολογία και έννοιες του Azure Developer CLI
- Ειδικευτείτε στο λεξιλόγιο ανάπτυξης cloud Azure και τεχνικούς όρους
- Αναφερθείτε με αποδοτικότητα στην ορολογία Υποδομής ως Κώδικα και ανάπτυξης
- Κατανοήσετε ονόματα υπηρεσιών Azure, ακρωνύμια και τους σκοπούς τους
- Έχετε πρόσβαση σε ορισμούς ορολογίας για αντιμετώπιση και αποσφαλμάτωση
- Μάθετε προχωρημένες έννοιες αρχιτεκτονικής και ανάπτυξης Azure

## Αποτελέσματα Μάθησης

Με τακτική αναφορά σε αυτό το γλωσσάριο, θα μπορείτε να:
- Επικοινωνείτε αποτελεσματικά χρησιμοποιώντας σωστή ορολογία Azure Developer CLI
- Κατανοείτε καλύτερα την τεχνική τεκμηρίωση και τα μηνύματα σφάλματος
- Πλοηγείστε με αυτοπεποίθηση σε υπηρεσίες και έννοιες Azure
- Αντιμετωπίζετε προβλήματα χρησιμοποιώντας κατάλληλο τεχνικό λεξιλόγιο
- Συμβάλλετε σε ομαδικές συζητήσεις με ακριβή τεχνική γλώσσα
- Επεκτείνετε συστηματικά τις γνώσεις σας στην ανάπτυξη cloud Azure

## Α

**ARM Template**  
Πρότυπο Azure Resource Manager. Μορφή Υποδομής ως Κώδικα βασισμένη σε JSON που χρησιμοποιείται για δηλωτικό ορισμό και ανάπτυξη πόρων Azure.

**App Service**  
Η προσφορά πλατφόρμας ως υπηρεσίας (PaaS) της Azure για φιλοξενία ιστότοπων, REST APIs και κινητών backends χωρίς διαχείριση υποδομής.

**Application Insights**  
Υπηρεσία Azure για παρακολούθηση απόδοσης εφαρμογών (APM) που προσφέρει βαθιά insights στην απόδοση, διαθεσιμότητα και χρήση.

**Azure CLI**  
Διεπαφή γραμμής εντολών για διαχείριση πόρων Azure. Συμπληρώνει το AZD αλλά έχει ξεχωριστή είσοδο· ο βασικός έλεγχος ταυτότητας του AZD χρησιμοποιεί `azd auth login`.

**Azure Developer CLI (azd)**  
Εργαλείο γραμμής εντολών φιλικό προς τον προγραμματιστή που επιταχύνει τη διαδικασία δημιουργίας και ανάπτυξης εφαρμογών στο Azure χρησιμοποιώντας πρότυπα και Υποδομή ως Κώδικα.

**azure.yaml**  
Το κύριο αρχείο ρυθμίσεων για ένα έργο azd που ορίζει υπηρεσίες, υποδομή και hooks ανάπτυξης.

**Azure Resource Manager (ARM)**  
Υπηρεσία ανάπτυξης και διαχείρισης της Azure που παρέχει επίπεδο διαχείρισης για δημιουργία, ενημέρωση και διαγραφή πόρων.

## Β

**Bicep**  
Γλώσσα ειδικής χρήσης (DSL) που ανέπτυξε η Microsoft για ανάπτυξη πόρων Azure. Προσφέρει απλούστερη σύνταξη από τα πρότυπα ARM ενώ μεταγλωττίζεται σε ARM.

**Build**  
Η διαδικασία μεταγλώττισης πηγαίου κώδικα, εγκατάστασης εξαρτήσεων και προετοιμασίας εφαρμογών για ανάπτυξη.

**Blue-Green Deployment**  
Στρατηγική ανάπτυξης που χρησιμοποιεί δύο ίδια περιβάλλοντα παραγωγής (μπλε και πράσινο) για ελαχιστοποίηση διακοπών και ρίσκου.

## Γ

**Container Apps**  
Υπηρεσία serverless κοντέινερ της Azure που επιτρέπει τη λειτουργία κοντέινερ εφαρμογών χωρίς διαχείριση πολύπλοκης υποδομής.

**CI/CD**  
Συνεχής Ενσωμάτωση/Συνεχής Ανάπτυξη. Αυτοματοποιημένες πρακτικές για ενσωμάτωση αλλαγών κώδικα και ανάπτυξη εφαρμογών.

**Cosmos DB**  
Παγκοσμίως κατανεμημένη, πολυ-μοντέλο βάση δεδομένων της Azure που παρέχει ολοκληρωμένα SLA για διαθεσιμότητα, καθυστέρηση, διαθεσιμότητα και συνέπεια.

**Configuration**  
Ρυθμίσεις και παράμετροι που ελέγχουν τη συμπεριφορά της εφαρμογής και τις επιλογές ανάπτυξης.

## Δ

**Deployment**  
Η διαδικασία εγκατάστασης και ρύθμισης εφαρμογών και των εξαρτήσεών τους στην υποδομή στόχο.

**Docker**  
Πλατφόρμα για ανάπτυξη, αποστολή και εκτέλεση εφαρμογών χρησιμοποιώντας την τεχνολογία κοντέινερ.

**Dockerfile**  
Αρχείο κειμένου με οδηγίες για κατασκευή εικόνας Docker κοντέινερ.

## Ε

**Environment**  
Στόχος ανάπτυξης που αντιπροσωπεύει συγκεκριμένη περίπτωση της εφαρμογής σας (π.χ., ανάπτυξη, σταδιοποίηση, παραγωγή).

**Environment Variables**  
Τιμές ρυθμίσεων αποθηκευμένες ως ζεύγη κλειδιού-τιμής που οι εφαρμογές μπορούν να προσπελάσουν κατά την εκτέλεση.

**Endpoint**  
URL ή διεύθυνση δικτύου όπου μπορεί να προσπελαστεί μια εφαρμογή ή υπηρεσία.

## Ζ

**Function App**  
Υπηρεσία serverless υπολογισμού της Azure που επιτρέπει εκτέλεση κώδικα κινητοποιημένου από γεγονότα χωρίς διαχείριση υποδομής.

## Η

**GitHub Actions**  
Πλατφόρμα CI/CD ενσωματωμένη σε αποθετήρια GitHub για αυτοματοποίηση ροών εργασίας.

**Git**  
Κατανεμημένο σύστημα ελέγχου εκδόσεων που χρησιμοποιείται για παρακολούθηση αλλαγών σε πηγαίο κώδικα.

## Θ

**Hooks**  
Προσαρμοσμένα scripts ή εντολές που εκτελούνται σε συγκεκριμένα σημεία του κύκλου ζωής ανάπτυξης (προ-προμήθεια, μετά-προμήθεια, προ-ανάπτυξη, μετά-ανάπτυξη).

**Host**  
Τύπος υπηρεσίας Azure όπου θα αναπτυχθεί μια εφαρμογή (π.χ., appservice, containerapp, function).

## Ι

**Infrastructure as Code (IaC)**  
Πρακτική ορισμού και διαχείρισης υποδομής μέσω κώδικα αντί για χειροκίνητες διαδικασίες.

**Init**  
Η διαδικασία αρχικοποίησης ενός νέου έργου azd, συνήθως από πρότυπο.

## Ι

**JSON**  
JavaScript Object Notation. Μορφή ανταλλαγής δεδομένων που χρησιμοποιείται συχνά σε αρχεία ρυθμίσεων και απαντήσεις API.

**JWT**  
JSON Web Token. Πρότυπο για ασφαλή μετάδοση πληροφοριών μεταξύ μερών ως JSON αντικείμενο.

## Κ

**Key Vault**  
Υπηρεσία της Azure για ασφαλή αποθήκευση και διαχείριση μυστικών, κλειδιών και πιστοποιητικών.

**Kusto Query Language (KQL)**  
Γλώσσα ερωτημάτων που χρησιμοποιείται για ανάλυση δεδομένων στο Azure Monitor, Application Insights και άλλες υπηρεσίες Azure.

## Λ

**Load Balancer**  
Υπηρεσία που διανέμει την εισερχόμενη δικτυακή κίνηση σε πολλαπλούς διακομιστές ή περιπτώσεις.

**Log Analytics**  
Υπηρεσία Azure για συλλογή, ανάλυση και δράση σε τηλεμετρικά δεδομένα από περιβάλλοντα cloud και on-premises.

## Μ

**Managed Identity**  
Χαρακτηριστικό Azure που παρέχει στις υπηρεσίες Azure μια αυτόματα διαχειριζόμενη ταυτότητα για πιστοποίηση σε άλλες υπηρεσίες Azure.

**Microservices**  
Αρχιτεκτονική προσέγγιση όπου οι εφαρμογές κατασκευάζονται ως συλλογή μικρών, ανεξάρτητων υπηρεσιών.

**Monitor**  
Ενοποιημένη λύση παρακολούθησης του Azure που προσφέρει πλήρη ορατότητα εφαρμογών και υποδομής.

## Ν

**Node.js**  
Περιβάλλον εκτέλεσης JavaScript βασισμένο στον μηχανισμό V8 της Chrome για κατασκευή server-side εφαρμογών.

**npm**  
Διαχειριστής πακέτων για Node.js που χειρίζεται εξαρτήσεις και πακέτα.

## Ο

**Output**  
Τιμές που επιστρέφονται από ανάπτυξη υποδομής και μπορούν να χρησιμοποιηθούν από εφαρμογές ή άλλους πόρους.

## Π

**Package**  
Η διαδικασία προετοιμασίας κώδικα εφαρμογής και εξαρτήσεων για ανάπτυξη.

**Parameters**  
Εισαγόμενες τιμές που δίνονται στα πρότυπα υποδομής για προσαρμογή των αναπτύξεων.

**PostgreSQL**  
Ανοιχτού κώδικα σχεσιακό σύστημα διαχείρισης βάσεων δεδομένων που υποστηρίζεται ως διαχειριζόμενη υπηρεσία στην Azure.

**Provisioning**  
Η διαδικασία δημιουργίας και ρύθμισης πόρων Azure που ορίζονται σε πρότυπα υποδομής.

## Q

**Quota**  
Όρια στην ποσότητα πόρων που μπορούν να δημιουργηθούν σε συνδρομή ή περιοχή Azure.

## Ρ

**Resource Group**  
Λογικός κοντέινερ για πόρους Azure που μοιράζονται τον ίδιο κύκλο ζωής, δικαιώματα και πολιτικές.

**Resource Token**  
Μοναδικό string που δημιουργείται από azd για να εξασφαλίσει μοναδικότητα ονομάτων πόρων ανά ανάπτυξη.

**REST API**  
Αρχιτεκτονικό στυλ για σχεδιασμό δικτυακών εφαρμογών με χρήση μεθόδων HTTP.

**Rollback**  
Διαδικασία επαναφοράς σε προηγούμενη έκδοση εφαρμογής ή ρύθμισης υποδομής.

## Σ

**Service**  
Συστατικό της εφαρμογής σας ορισμένο στο azure.yaml (π.χ., frontend ιστού, backend API, βάση δεδομένων).

**SKU**  
Μονάδα Διατήρησης Αποθέματος. Αντιπροσωπεύει διαφορετικά επίπεδα υπηρεσίας ή απόδοσης για πόρους Azure.

**SQL Database**  
Διαχειριζόμενη σχεσιακή βάση δεδομένων Azure βασισμένη σε Microsoft SQL Server.

**Static Web Apps**  
Υπηρεσία Azure για κατασκευή και ανάπτυξη full-stack web εφαρμογών από αποθετήρια πηγαίου κώδικα.

**Storage Account**  
Υπηρεσία Azure που προσφέρει αποθήκευση cloud για αντικείμενα δεδομένων όπως blobs, αρχεία, ουρές και πίνακες.

**Subscription**  
Κοντέινερ λογαριασμού Azure που φιλοξενεί ομάδες πόρων και πόρους, με αντίστοιχο τιμολόγηση και διαχείριση πρόσβασης.

## Τ

**Template**  
Προ-κατασκευασμένη δομή έργου που περιλαμβάνει κώδικα εφαρμογής, ορισμούς υποδομής και ρυθμίσεις για κοινά σενάρια.

**Terraform**  
Ανοιχτού κώδικα εργαλείο Υποδομής ως Κώδικα που υποστηρίζει πολλούς παρόχους cloud συμπεριλαμβανομένου του Azure.

**Traffic Manager**  
Φορτωτής ισορροπίας κίνησης DNS που βασίζεται στην Azure για κατανομή κίνησης σε παγκόσμιες περιοχές Azure.

## Υ

**URI**  
Μοναδικός Αναγνωριστής Πόρου (Uniform Resource Identifier). Συμβολοσειρά που προσδιορίζει έναν συγκεκριμένο πόρο.

**URL**  
Uniform Resource Locator. Τύπος URI που καθορίζει πού βρίσκεται ένας πόρος και πώς να τον ανακτήσετε.

## Β

**Virtual Network (VNet)**  
Θεμελιώδες δομικό στοιχείο για ιδιωτικά δίκτυα στο Azure, παρέχοντας απομόνωση και τμηματοποίηση.

**VS Code**  
Visual Studio Code. Δημοφιλής επεξεργαστής κώδικα με εξαιρετική ενσωμάτωση Azure και azd.

## Ω

**Webhook**  
Κλήση HTTP που ενεργοποιείται από συγκεκριμένα γεγονότα, συνηθισμένη σε pipelines CI/CD.

**What-if**  
Χαρακτηριστικό Azure που δείχνει ποιες αλλαγές θα γίνουν από μια ανάπτυξη χωρίς να την εκτελέσει πραγματικά.

## Υ

**YAML**  
YAML Ain't Markup Language. Πρότυπο σειριοποίησης δεδομένων αναγνώσιμο από ανθρώπους που χρησιμοποιείται για αρχεία ρυθμίσεων όπως το azure.yaml.

## Ζ

**Zone**  
Φυσικά ξεχωριστές τοποθεσίες μέσα σε μια περιοχή Azure που παρέχουν πλεονασμό και υψηλή διαθεσιμότητα.

## Αντιστοιχίες Ονομάτων Υπηρεσιών Azure

| Κοινό Όνομα | Επίσημο Όνομα Υπηρεσίας Azure | Τύπος Host azd |
|-------------|------------------------------|---------------|
| Web App | Azure App Service | `appservice` |
| API App | Azure App Service | `appservice` |
| Container App | Azure Container Apps | `containerapp` |
| Function | Azure Functions | `function` |
| Static Site | Azure Static Web Apps | `staticwebapp` |
| Database | Azure Database for PostgreSQL | Πόρος υποδομής, όχι εφαρμογή `host` |
| NoSQL DB | Azure Cosmos DB | Πόρος υποδομής, όχι εφαρμογή `host` |
| Storage | Azure Storage Account | Πόρος υποδομής, όχι ενσωματωμένη εφαρμογή `host` |
| Cache | Azure Managed Redis | Πόρος υποδομής, όχι εφαρμογή `host` |
| Search | Azure AI Search | Πόρος υποδομής, όχι εφαρμογή `host` |
| Messaging | Azure Service Bus | Πόρος υποδομής, όχι εφαρμογή `host` |

`services.<name>.host` επιλέγει στόχο ανάπτυξης εφαρμογής· δεν είναι συντομογραφία για κανέναν τύπο πόρου Azure. Βάσεις δεδομένων, caches, υπηρεσίες αναζήτησης και ουρές παρέχονται συνήθως μέσω του παρόχου υποδομής και συνδέονται με την εφαρμογή μέσω εξόδων/ρυθμίσεων.

## Όροι Κατά Περίσταση

### Όροι Ανάπτυξης
- **Hot Reload**: Αυτόματη ενημέρωση εφαρμογών κατά την ανάπτυξη χωρίς επανεκκίνηση
- **Build Pipeline**: Αυτοματοποιημένη διαδικασία κατασκευής και ελέγχου κώδικα
- **Deployment Slot**: Περιβάλλον σταδιοποίησης εντός ενός App Service
- **Environment Parity**: Διατήρηση ομοιότητας μεταξύ περιβαλλόντων ανάπτυξης, σταδιοποίησης και παραγωγής

### Όροι Ασφαλείας
- **Managed Identity**: Χαρακτηριστικό Azure που παρέχει αυτόματη διαχείριση διαπιστευτηρίων
- **Key Vault**: Ασφαλής αποθήκευση μυστικών, κλειδιών και πιστοποιητικών
- **RBAC**: Έλεγχος πρόσβασης βασισμένος σε ρόλους για πόρους Azure
- **Network Security Group**: Εικονικό τείχος προστασίας για έλεγχο δικτυακής κίνησης

### Όροι Παρακολούθησης
- **Telemetry**: Αυτοματοποιημένη συλλογή μετρήσεων και δεδομένων
- **Application Performance Monitoring (APM)**: Παρακολούθηση απόδοσης λογισμικού
- **Log Analytics**: Υπηρεσία συλλογής και ανάλυσης δεδομένων καταγραφής
- **Alert Rules**: Αυτοματοποιημένες ειδοποιήσεις βασισμένες σε μετρικές ή συνθήκες

### Όροι Ανάπτυξης
- **Blue-Green Deployment**: Στρατηγική ανάπτυξης χωρίς διακοπές λειτουργίας
- **Canary Deployment**: Σταδιακή διάθεση σε υποσύνολο χρηστών
- **Rolling Update**: Διαδοχική αντικατάσταση περιπτώσεων εφαρμογής
- **Rollback**: Επαναφορά σε προηγούμενη έκδοση εφαρμογής
