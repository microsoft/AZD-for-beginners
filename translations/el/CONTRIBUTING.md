# Συμβολή στο AZD Για Αρχάριους

Σας ευχαριστούμε για το ενδιαφέρον σας να συμβάλετε στο μάθημα AZD Για Αρχάριους! Αυτό το έγγραφο παρέχει οδηγίες και πληροφορίες για τους συνεισφέροντες.

## Πώς να Συμβάλετε

### Αναφορά Προβλημάτων

Εάν βρείτε σφάλματα, λάθη ή έχετε προτάσεις για βελτιώσεις:

1. **Ελέγξτε Υπάρχοντα Ζητήματα**: Αναζητήστε [υπάρχοντα ζητήματα](https://github.com/microsoft/azd-for-beginners/issues) για να αποφύγετε διπλοεγγραφές
2. **Δημιουργήστε Νέο Ζήτημα**: Χρησιμοποιήστε το κατάλληλο πρότυπο ζητήματος
3. **Παρέχετε Λεπτομέρειες**: Συμπεριλάβετε βήματα αναπαραγωγής, αναμενόμενη συμπεριφορά και στιγμιότυπα οθόνης αν είναι απαραίτητο

### Πρόταση Αλλαγών

1. **Δημιουργήστε Fork του Αποθετηρίου**: Δημιουργήστε το δικό σας fork του έργου
2. **Δημιουργήστε Κλάδο**: Δημιουργήστε έναν κλάδο λειτουργικότητας για τις αλλαγές σας
3. **Κάντε Αλλαγές**: Ακολουθήστε τα πρότυπα κώδικα και τεκμηρίωσης
4. **Δοκιμάστε τις Αλλαγές σας**: Επιβεβαιώστε ότι όλοι οι σύνδεσμοι λειτουργούν και το περιεχόμενο εμφανίζεται σωστά
5. **Υποβάλετε Pull Request**: Παρέχετε μια σαφή περιγραφή των αλλαγών σας

### Τύποι Συνεισφορών

Καλωσορίζουμε τους ακόλουθους τύπους συνεισφορών:

#### Βελτιώσεις Περιεχομένου
- Διορθώστε ορθογραφικά λάθη, γραμματικά και ζητήματα μορφοποίησης
- Βελτιώστε την ευκρίνεια της υπάρχουσας τεκμηρίωσης
- Ενημερώστε ξεπερασμένες πληροφορίες
- Προσθέστε ελλείπουσες εξηγήσεις ή πλαίσιο

#### Νέα Παραδείγματα
- Προσθέστε σενάρια ανάπτυξης στον πραγματικό κόσμο
- Δημιουργήστε νέα πρότυπα AZD για κοινές χρήσεις
- Παρέχετε επιπλέον δείγματα κώδικα και ασκήσεις

#### Υποστήριξη Μετάφρασης
- Βοηθήστε στη διατήρηση των υπαρχουσών μεταφράσεων
- Βελτιώστε την ποιότητα των μεταφράσεων
- Προσθέστε μεταφράσεις για νέο περιεχόμενο

#### Αναφορές Σφαλμάτων
- Αναφέρετε σπασμένους συνδέσμους ή λανθασμένα παραδείγματα κώδικα
- Εντοπίστε ασυνέπειες στην τεκμηρίωση
- Επισημάνετε ζητήματα προσβασιμότητας

## Οδηγίες Συνεισφοράς

### Πρότυπα Τεκμηρίωσης

- Χρησιμοποιήστε καθαρή, φιλική προς αρχάριους γλώσσα
- Συμπεριλάβετε μαθησιακούς στόχους και αποτελέσματα
- Παρέχετε βήμα-βήμα οδηγίες με αναμενόμενα αποτελέσματα
- Προσθέστε συνδέσμους πλοήγησης σε σχετικό περιεχόμενο
- Χρησιμοποιήστε συνεπή μορφοποίηση και στυλ markdown

### Παραδείγματα Κώδικα

- Εξασφαλίστε ότι όλα τα παραδείγματα κώδικα δοκιμάζονται και λειτουργούν
- Συμπεριλάβετε σχόλια που εξηγούν βασικές έννοιες
- Ακολουθήστε τις βέλτιστες πρακτικές του Azure και AZD
- Παρέχετε αναμενόμενη έξοδο όπου είναι εφαρμόσιμο

### Επικύρωση Τεκμηρίωσης στα Αγγλικά

Από τη ρίζα του αποθετηρίου, εγκαταστήστε τις υπάρχουσες απαιτήσεις ανάπτυξης και εκτελέστε:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

Ο offline έλεγχος συνδέσμων ελέγχει αγγλικές διαδρομές Markdown/HTML, επικεφαλίδες, ρητές εσωτερικές συνδέσεις και άδειες θέσεις συνδέσμων. Εξαιρεί τα παραγόμενα `translations/` και `translated_images/`, συμπεριλαμβανομένων των συνδέσμων προς αυτούς τους καταλόγους. Δεν ανακτά εξωτερικές ιστοσελίδες ή επικυρώνει αναπτύξεις Azure. Χρησιμοποιήστε `--json <report-path>` για να εξάγετε αποτυχίες και εξωτερική λίστα URL για ξεχωριστό έλεγχο δικτύου. Επιβεβαιώστε τις τρέχουσες εντολές upstream και τις προαπαιτήσεις δειγμάτων κατά την αλλαγή τεχνικών οδηγιών. Διαχωρίστε τις δοκιμασμένες εφαρμογές από τα σχέδια σχεδίασης.
