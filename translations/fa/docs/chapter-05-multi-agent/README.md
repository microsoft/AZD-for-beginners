## مرور کلی

این فصل الگوهای معماری پیشرفته چندعاملی، هماهنگی عوامل، و استقرارهای هوش مصنوعی آماده تولید برای سناریوهای پیچیده را پوشش می‌دهد.

> راهنمای فرمان‌ها در مقابل مستندات منتشر شده `azd 1.37.2` بررسی شده است. استقرارهای ابری اجرا نشدند.

## اهداف یادگیری

با تکمیل این فصل، شما قادر خواهید بود:
- الگوهای معماری چندعاملی را درک کنید
- سیستم‌های هماهنگ‌شده عوامل هوش مصنوعی را مستقر کنید
- ارتباط عامل به عامل را پیاده‌سازی کنید
- راه‌حل‌های چندعاملی آماده تولید بسازید

## 🚀 شروع سریع

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **کدام روش؟** برای شروع از یک نمونه عملی، از `azd init --template` استفاده کنید. به صورت تعاملی از `azd ai agent init` استفاده کنید، یا از `azd ai agent init --template <path-to-azure.yaml>` برای پذیرش یک پروژه عامل جاری بهره ببرید. برای نیازهای نسخه و مهاجرت ارزیابی، به [مستندات AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) مراجعه کنید.

این گزینه‌ها را در پوشه‌های جداگانه خالی اجرا کنید. افزونه عوامل `1.0.0-beta.23` نیازمند `azd >= 1.37.0` است؛ جریان تعاملی آن خط لوله سفارشی سرویس باس در درس هماهنگی را ایجاد نمی‌کند.

## 🎯 راه‌حل ویژه: چندعاملی خرده‌فروشی

راه‌حل [چندعامله خرده‌فروشی](../../examples/retail-scenario.md) نشان می‌دهد:

- **عامل مشتری**: مدیریت تعاملات و ترجیحات کاربر
- **عامل موجودی**: مدیریت موجودی و پردازش سفارش‌ها
- **هماهنگ‌کننده**: هماهنگی بین عوامل
- **حافظه مشترک**: مدیریت زمینه بین عوامل

### خدمات استفاده‌شده

| خدمت | هدف |
|---------|---------|
| مدل‌های Microsoft Foundry | درک زبان |
| جستجوی Azure AI | فهرست محصولات |
| Cosmos DB | وضعیت و حافظه عامل |
| برنامه‌های کانتینری | میزبانی عامل |
| Application Insights | نظارت |
