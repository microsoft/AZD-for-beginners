# فصل ۶: برنامه‌ریزی و اعتبارسنجی پیش از استقرار

**📚 دوره**: [AZD برای مبتدیان](../../README.md) | **⏱️ مدت زمان**: ۲-۴ ساعت مطالعه؛ زمان اضافی برای آزمایشگاه‌های سازگار شده | **⭐ پیچیدگی**: متوسط تا پیشرفته

## نمای کلی

این فصل مراحل ضروری برنامه‌ریزی و اعتبارسنجی را قبل از استقرار برنامه شما پوشش می‌دهد. بیاموزید چگونه با برنامه‌ریزی ظرفیت مناسب، انتخاب SKU و بررسی‌های پیش‌پرواز از اشتباهات پرهزینه جلوگیری کنید.

> راهنمای دستور بررسی شده بر اساس مرجع منتشر شده `azd 1.37.2`. استقرارهای ابری انجام نشده است. درس‌های طولانی‌تر شامل قطعات تصویری هستند، نه پروژه‌های کامل استقرار محلی.

## اهداف آموزشی

با تکمیل این فصل، شما خواهید توانست:
- بررسی‌های پیش‌پرواز را قبل از استقرار انجام دهید
- ظرفیت را برنامه‌ریزی کرده و نیازهای منابع را برآورد کنید
- انتخاب SKUهای مناسب برای بهینه‌سازی هزینه‌ها
- پیکربندی Application Insights برای مانیتورینگ
- درک الگوهای هماهنگی چندعامل و نیازهای استقرار آن‌ها

## 🚀 شروع سریع

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ چک‌لیست پیش از استقرار

### قبل از `azd provision`

- [ ] سهمیه منطقه تأیید شده
- [ ] SKUها به درستی انتخاب شده‌اند
- [ ] برآورد هزینه مرور شده
- [ ] قرارداد نام‌گذاری سازگار
- [ ] امنیت/RBAC پیکربندی شده

### قبل از `azd deploy`

- [ ] متغیرهای محیطی تنظیم شده
- [ ] اسرار در Key Vault ذخیره شده‌اند
- [ ] رشته‌های اتصال تأیید شده
- [ ] بررسی‌های سلامت پیکربندی شده

## 💰 راهنمای انتخاب SKU

| بار کاری | توسعه | تولید |
|----------|-------------|------------|
| برنامه‌های کانتینری | مصرف | مصرف یا پروفایل بار کاری اختصاصی، بر اساس بار اندازه‌گیری شده |
| سرویس برنامه | B1/B2 | P1v3+ |
| مدل‌های Azure OpenAI | نوع استقرار پرداخت به ازای مصرف پشتیبانی می‌شود | پرداخت به ازای مصرف یا توان پیش‌تأمین شده؛ بسته به مدل/منطقه |
| جستجوی هوش مصنوعی | رایگان/پایه در محدوده‌ها | پایه یا سطح استاندارد با اندازه متناسب با شاخص، نسخه‌ها و بار پرس‌وجو |
