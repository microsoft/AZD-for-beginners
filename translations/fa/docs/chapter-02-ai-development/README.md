## مرور کلی

این فصل بر استقرار برنامه‌های مبتنی بر هوش مصنوعی با استفاده از Azure Developer CLI و خدمات Microsoft Foundry تمرکز دارد. از برنامه‌های گفتگوی هوش مصنوعی ساده تا عوامل هوشمند با ابزارها.

> **به‌روزرسانی Foundry GA (۹-۱۱-۲۰۲۶):** بسته `microsoft.foundry` 1.0 [به‌طور کلی در دسترس است](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). از `azd >= 1.37.0` استفاده کنید؛ ارزیابی‌ها نصب جداگانه‌ای باقی می‌مانند. [راهنمای عامل میزبان](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) شامل آزمایش محلی Agent Inspector و استقرار کد از راه دور است. این بازبینی مستندات است، نه تأیید استقرار زنده؛ ویژگی‌های پیش‌نمایش اختیاری وضعیت خود را حفظ می‌کنند.

## اهداف یادگیری

با تکمیل این فصل، شما خواهید توانست:
- برنامه‌های هوش مصنوعی را با استفاده از قالب‌های پیش‌ساخته AZD مستقر کنید
- یکپارچه‌سازی Microsoft Foundry با AZD را درک کنید
- بسته GA را نصب کرده و پیش از استقرار منبع در Foundry، عامل میزبان را به‌صورت محلی آزمایش کنید
- `azure.yaml`، دارایی‌های ارزیابی و پاک‌سازی پروژه‌های جدید در مقابل پروژه‌های بازیافتی را مرور کنید
- عامل‌های هوش مصنوعی را با ابزارها پیکربندی و سفارشی کنید
- برنامه‌های RAG (تولید تقویت‌شده با بازیابی) را مستقر کنید

## 🚀 شروع سریع

یک گزینه را در یک پوشه جدید و خالی انتخاب کنید. گزینه انتهایی `.` پوشه جاری را مقداردهی اولیه می‌کند؛ در غیر این صورت AZD می‌تواند پوشه فرعی ایجاد کند بدون اینکه دایرکتوری کاری شل شما را تغییر دهد.

برای **مسیر استقرار کد عامل میزبان GA**، کار را با [راهنمای راهنمای گام به گام](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) شروع کنید. این راهنما به AZD نسخه ۱.۳۷.۰ به بالا، uv کنونی، پایتون ۳.۱۳ به بالا، مجوزهای Foundry و سهمیه مدل نیاز دارد. قالب‌های کامل برنامه زیر به عنوان جایگزین هستند، نه پیش‌نیاز این راهنمای گام به گام.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 آگاهی از هزینه

این‌ها دامنه‌های تقریبی هستند، نه قیمت‌ها یا سقف‌ها؛ ترافیک مدل، SKU‌های جستجو/محاسبه، منطقه و ویژگی‌های اختیاری ممکن است از این حدود فراتر رود. راهنمای قیمت‌گذاری نمونه انتخابی خود را پیش از تهیه مرور کنید.

| محیط | هزینه ماهیانه تخمینی |
|-------------|----------------------|
| توسعه | ۸۰-۱۵۰ دلار |
| مرحله‌بندی | ۱۵۰-۳۰۰ دلار |
| تولید | ۳۰۰-۳۵۰۰+ دلار |

**پاک‌سازی:** پیش از تأیید، `azd down` را مرور کنید: برای پروژه Foundry تازه ایجاد شده، گروه منابع و همه موارد داخل آن را حذف می‌کند. برای پروژه Foundry بازیافتی، منابع پروژه و عامل را باقی می‌گذارد؛ طبق [راهنمای پاک‌سازی راهنما](microsoft-foundry-integration.md#7-clean-up-deliberately) منابع ناخواسته را جداگانه حذف کنید.
