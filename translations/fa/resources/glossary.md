## مقدمه

این فرهنگ جامع تعاریف اصطلاحات، مفاهیم و اختصارات به‌کاررفته در Azure Developer CLI و توسعه ابر Azure را ارائه می‌دهد. مرجعی ضروری برای درک مستندات فنی، رفع اشکال مشکلات و ارتباط مؤثر درباره پروژه‌های azd و سرویس‌های Azure.

## اهداف یادگیری

با استفاده از این فرهنگ اصطلاحات، شما:
- اصطلاحات و مفاهیم اساسی Azure Developer CLI را درک خواهید کرد
- واژگان و اصطلاحات فنی توسعه ابری Azure را فرا خواهید گرفت
- به‌طور مؤثر به اصطلاحات زیرساخت به‌عنوان کد و استقرار مراجعه خواهید کرد
- نام‌ها، اختصارات و کاربردهای سرویس‌های Azure را متوجه خواهید شد
- تعاریف اصطلاحات رفع اشکال و عیب‌یابی را خواهید یافت
- مفاهیم پیشرفته معماری و توسعه Azure را خواهید آموخت

## نتایج یادگیری

با مراجعه منظم به این فرهنگ، قادر خواهید بود:
- با استفاده از اصطلاحات صحیح Azure Developer CLI ارتباط مؤثر برقرار کنید
- مستندات فنی و پیام‌های خطا را بهتر درک کنید
- با اطمینان در سرویس‌ها و مفاهیم Azure حرکت کنید
- مسائل را با واژگان فنی مناسب عیب‌یابی کنید
- در بحث‌های تیمی با زبان فنی صحیح مشارکت کنید
- دانش توسعه ابری Azure خود را به طور سیستماتیک گسترش دهید

## A

**ARM Template**  
قالب مدیر منابع Azure. قالبی مبتنی بر JSON برای زیرساخت به‌عنوان کد که منابع Azure را به صورت بیانی تعریف و مستقر می‌کند.

**App Service**  
سرویس پلتفرم Azure (PaaS) برای میزبانی برنامه‌های وب، APIهای REST و بک‌اند موبایل بدون نیاز به مدیریت زیرساخت.

**Application Insights**  
سرویس نظارت بر عملکرد برنامه Azure که نمای عمیقی از عملکرد، در دسترس بودن و استفاده برنامه‌ها ارائه می‌دهد.

**Azure CLI**  
رابط خط فرمان برای مدیریت منابع Azure. مکمل AZD است اما ورود جداگانه دارد؛ احراز هویت اصلی AZD از `azd auth login` استفاده می‌کند.

**Azure Developer CLI (azd)**  
ابزار خط فرمان متمرکز بر توسعه‌دهنده که فرآیند ساخت و استقرار برنامه‌ها در Azure را با استفاده از قالب‌ها و زیرساخت به‌عنوان کد تسریع می‌کند.

**azure.yaml**  
فایل پیکربندی اصلی پروژه azd که خدمات، زیرساخت و قلاب‌های استقرار را تعریف می‌کند.

**Azure Resource Manager (ARM)**  
سرویس استقرار و مدیریت Azure که لایه مدیریت برای ایجاد، به‌روزرسانی و حذف منابع فراهم می‌کند.

## B

**Bicep**  
زبان دامنه‌خاص (DSL) توسعه‌یافته توسط مایکروسافت برای استقرار منابع Azure. نحو ساده‌تری نسبت به قالب‌های ARM دارد و به ARM کامپایل می‌شود.

**Build**  
فرآیند کامپایل کد منبع، نصب وابستگی‌ها و آماده‌سازی برنامه‌ها برای استقرار.

**Blue-Green Deployment**  
استراتژی استقرار که از دو محیط تولیدی یکسان (آبی و سبز) برای کاهش زمان از کار افتادگی و ریسک استفاده می‌کند.

## C

**Container Apps**  
سرویس کانتینر سرورلس Azure که امکان اجرای برنامه‌های کانتینری بدون مدیریت زیرساخت پیچیده را فراهم می‌کند.

**CI/CD**  
ادغام مداوم/استقرار مداوم. روش‌های خودکار برای ادغام تغییرات کد و استقرار برنامه‌ها.

**Cosmos DB**  
سرویس پایگاه داده چندمدلی توزیع‌شده جهانی Azure که SLAهای جامع برای توان عملیاتی، تأخیر، در دسترس بودن و هم‌خوانی ارائه می‌دهد.

**Configuration**  
تنظیمات و پارامترهایی که رفتار برنامه و گزینه‌های استقرار را کنترل می‌کنند.

## D

**Deployment**  
فرآیند نصب و پیکربندی برنامه‌ها و وابستگی‌هایشان روی زیرساخت هدف.

**Docker**  
پلتفرم توسعه، ارسال و اجرای برنامه‌ها با فناوری کانتینرسازی.

**Dockerfile**  
فایل متنی شامل دستورالعمل‌هایی برای ساخت تصویر کانتینر Docker.

## E

**Environment**  
هدف استقرار که نمونه خاصی از برنامه شما را نشان می‌دهد (مثلاً توسعه، آزمایشی، تولید).

**Environment Variables**  
مقادیر پیکربندی ذخیره‌شده به صورت جفت کلید-مقدار که برنامه‌ها هنگام اجرا به آن‌ها دسترسی دارند.

**Endpoint**  
نشانی URL یا شبکه‌ای که برنامه یا سرویس از طریق آن قابل دسترسی است.

## F

**Function App**  
سرویس محاسبات سرورلس Azure که امکان اجرای کد مبتنی بر رویداد را بدون مدیریت زیرساخت فراهم می‌کند.

## G

**GitHub Actions**  
پلتفرم CI/CD یکپارچه با مخازن GitHub برای خودکارسازی جریان‌های کاری.

**Git**  
سیستم کنترل نسخه توزیع‌شده برای پیگیری تغییرات در کد منبع.

## H

**Hooks**  
اسکریپت‌ها یا دستورات سفارشی که در نقاط خاص چرخه عمر استقرار اجرا می‌شوند (پری‌پروویژن، پست‌پروویژن، پری‌استقرار، پست‌استقرار).

**Host**  
نوع سرویس Azure که برنامه در آن مستقر می‌شود (مثلاً appservice، containerapp، function).

## I

**Infrastructure as Code (IaC)**  
روش تعریف و مدیریت زیرساخت از طریق کد به جای فرآیندهای دستی.

**Init**  
فرآیند مقداردهی اولیه یک پروژه azd جدید، معمولاً از قالب.

## J

**JSON**  
نشانه‌گذاری شیء جاوااسکریپت. قالب تبادل داده که معمولاً برای فایل‌های پیکربندی و پاسخ‌های API استفاده می‌شود.

**JWT**  
توکن وب JSON. استانداردی برای انتقال ایمن اطلاعات بین طرفین به صورت شیء JSON.

## K

**Key Vault**  
سرویس Azure برای ذخیره و مدیریت امن اسرار، کلیدها و گواهی‌ها.

**Kusto Query Language (KQL)**  
زبان پرس‌وجو برای تحلیل داده‌ها در Azure Monitor، Application Insights و سایر سرویس‌های Azure.

## L

**Load Balancer**  
سرویسی که ترافیک ورودی شبکه را بین چند سرور یا نمونه تقسیم می‌کند.

**Log Analytics**  
سرویس Azure برای جمع‌آوری، تحلیل و اقدام بر داده‌های تله‌متری از محیط‌های ابری و محلی.

## M

**Managed Identity**  
ویژگی Azure که به سرویس‌های Azure هویت مدیریت‌شده خودکار برای احراز هویت به سرویس‌های دیگر می‌دهد.

**Microservices**  
رویکرد معماری که در آن برنامه‌ها به صورت مجموعه‌ای از خدمات کوچک و مستقل ساخته می‌شوند.

**Monitor**  
راه‌حل یکپارچه نظارت Azure که رصد کامل برنامه‌ها و زیرساخت را فراهم می‌کند.

## N

**Node.js**  
محیط اجرای جاوااسکریپت ساخته‌شده بر موتور V8 کروم برای ساخت برنامه‌های سمت سرور.

**npm**  
مدیر بسته‌های Node.js که وابستگی‌ها و بسته‌ها را مدیریت می‌کند.

## O

**Output**  
مقادیری که از استقرار زیرساخت بازگردانده می‌شوند و می‌توانند توسط برنامه‌ها یا منابع دیگر استفاده شوند.

## P

**Package**  
فرآیند آماده‌سازی کد برنامه و وابستگی‌ها برای استقرار.

**Parameters**  
مقادیر ورودی که به قالب‌های زیرساخت ارسال می‌شوند تا استقرار را سفارشی کنند.

**PostgreSQL**  
سیستم پایگاه داده رابطه‌ای متن‌باز که به عنوان سرویس مدیریت‌شده در Azure پشتیبانی می‌شود.

**Provisioning**  
فرآیند ایجاد و پیکربندی منابع Azure تعریف‌شده در قالب‌های زیرساخت.

## Q

**Quota**  
محدودیت‌هایی برای میزان منابع قابل ایجاد در یک اشتراک یا منطقه Azure.

## R

**Resource Group**  
ظرف منطقی برای منابع Azure که چرخه عمر، مجوزها و سیاست‌های مشترکی دارند.

**Resource Token**  
رشته منحصر به فردی که توسط azd تولید می‌شود تا نام‌های منابع در استقرارها یکتا باشند.

**REST API**  
سبک معماری برای طراحی برنامه‌های متصل به شبکه با استفاده از روش‌های HTTP.

**Rollback**  
فرآیند بازگشت به نسخه قبلی یک برنامه یا پیکربندی زیرساخت.

## S

**Service**  
جزئی از برنامه شما که در azure.yaml تعریف شده است (مانند frontend وب، backend API، پایگاه داده).

**SKU**  
واحد نگهداری سهام. نماینده سطوح مختلف سرویس یا عملکرد برای منابع Azure.

**SQL Database**  
سرویس پایگاه داده رابطه‌ای مدیریت‌شده Azure مبتنی بر Microsoft SQL Server.

**Static Web Apps**  
سرویس Azure برای ساخت و استقرار برنامه‌های وب فول‌استک از مخازن کد منبع.

**Storage Account**  
سرویس Azure که ذخیره‌سازی ابری برای اشیای داده شامل بلاوب‌ها، فایل‌ها، صف‌ها و جداول فراهم می‌کند.

**Subscription**  
ظرف حساب Azure که گروه‌های منابع و منابع را نگه می‌دارد، همراه با مدیریت صورت‌حساب و دسترسی.

## T

**Template**  
ساختار پروژه از پیش‌ساخته شده شامل کد برنامه، تعاریف زیرساخت و پیکربندی برای سناریوهای رایج.

**Terraform**  
ابزار متن‌باز زیرساخت به‌عنوان کد که از چند ارائه‌دهنده ابر از جمله Azure پشتیبانی می‌کند.

**Traffic Manager**  
متعادل‌کننده بار ترافیک مبتنی بر DNS Azure برای توزیع ترافیک در مناطق جهانی Azure.

## U

**URI**  
شناسه یکنواخت منبع. رشته‌ای که یک منبع خاص را شناسایی می‌کند.

**URL**  
مکان‌یاب یکنواخت منبع. نوعی URI که محل یک منبع را مشخص می‌کند و نحوه بازیابی آن را بیان می‌کند.

## V

**Virtual Network (VNet)**  
بلوک ساختمانی اساسی برای شبکه‌های خصوصی در Azure که تفکیک و جداسازی را فراهم می‌کند.

**VS Code**  
Visual Studio Code. ویرایشگر کد محبوب با یکپارچگی عالی با Azure و azd.

## W

**Webhook**  
فراخوانی HTTP که توسط رویدادهای خاص به طور خودکار فعال می‌شود، معمولاً در خطوط لوله CI/CD.

**What-if**  
ویژگی Azure که نشان می‌دهد استقرار چه تغییراتی ایجاد خواهد کرد بدون اینکه واقعاً آن را اجرا کند.

## Y

**YAML**  
YAML Ain't Markup Language. استاندارد سریال‌سازی داده‌های خواندنی برای انسان که برای فایل‌های پیکربندی مانند azure.yaml استفاده می‌شود.

## Z

**Zone**  
مکان‌های فیزیکی جداگانه در یک منطقه Azure که افزونگی و در دسترس بودن بالا فراهم می‌کنند.

## نگاشت نام‌های سرویس Azure

| نام معمول | نام رسمی سرویس Azure | نوع میزبان azd |
|-------------|------------------------------|---------------|
| Web App | Azure App Service | `appservice` |
| API App | Azure App Service | `appservice` |
| Container App | Azure Container Apps | `containerapp` |
| Function | Azure Functions | `function` |
| Static Site | Azure Static Web Apps | `staticwebapp` |
| Database | Azure Database for PostgreSQL | منبع زیرساخت، نه برنامه `host` |
| NoSQL DB | Azure Cosmos DB | منبع زیرساخت، نه برنامه `host` |
| Storage | Azure Storage Account | منبع زیرساخت، نه برنامه داخلی `host` |
| Cache | Azure Managed Redis | منبع زیرساخت، نه برنامه `host` |
| Search | Azure AI Search | منبع زیرساخت، نه برنامه `host` |
| Messaging | Azure Service Bus | منبع زیرساخت، نه برنامه `host` |

`services.<name>.host` هدف استقرار برنامه را انتخاب می‌کند؛ این اختصاری برای هیچ نوع منبع Azure نیست. پایگاه‌های داده، کش‌ها، سرویس‌های جستجو و صف‌ها معمولاً از طریق ارائه‌دهنده زیرساخت فراهم می‌شوند و از طریق خروجی‌ها/پیکربندی به برنامه متصل می‌شوند.

## اصطلاحات خاص زمینه

### اصطلاحات توسعه
- **بارگذاری داغ (Hot Reload)**: به‌روزرسانی خودکار برنامه‌ها در طول توسعه بدون نیاز به راه‌اندازی مجدد
- **خط‌لوله ساخت**: فرآیند خودکار ساخت و تست کد
- **شکاف استقرار (Deployment Slot)**: محیط آزمایشی در یک App Service
- **تطابق محیط‌ها**: حفظ شباهت بین محیط‌های توسعه، آزمایشی و تولید

### اصطلاحات امنیتی
- **Managed Identity**: ویژگی Azure که مدیریت خودکار اعتبارنامه‌ها را فراهم می‌کند
- **Key Vault**: ذخیره‌سازی امن برای اسرار، کلیدها و گواهی‌ها
- **RBAC**: کنترل دسترسی مبتنی بر نقش برای منابع Azure
- **Network Security Group**: دیوار آتش مجازی برای کنترل ترافیک شبکه

### اصطلاحات نظارتی
- **Telemetry**: جمع‌آوری خودکار اندازه‌گیری‌ها و داده‌ها
- **Application Performance Monitoring (APM)**: نظارت بر عملکرد نرم‌افزار
- **Log Analytics**: سرویس جمع‌آوری و تحلیل داده‌های لاگ
- **Alert Rules**: اطلاع‌رسانی خودکار بر اساس معیارها یا شرایط

### اصطلاحات استقرار
- **Blue-Green Deployment**: استراتژی استقرار بدون زمان از کار افتادگی
- **Canary Deployment**: استقرار تدریجی به زیرمجموعه‌ای از کاربران
- **Rolling Update**: جایگزینی ترتیبی نمونه‌های برنامه
- **Rollback**: بازگشت به نسخه قبلی برنامه
