# نمونه مایکروسرویس‌ها

پیاده‌سازی قابل اجرا و دستورالعمل‌های آن در
**[container-app/microservices](../container-app/microservices/README.md)** قرار دارد.

این پوشه فقط برای ناوبری است. هیچ `azure.yaml`، `infra/` یا `src/` در آن وجود ندارد.
اینجا `azd up` را اجرا نکنید.

از ریشه مخزن:

```bash
cd examples/container-app/microservices
```

سپس README پیوند داده شده را برای پیش‌نیازها، استقرار، بررسی، توسعه محلی،
تمرین‌های عملی، هزینه‌ها و پاک‌سازی دنبال کنید.

نمونه شامل یک دروازه API نود.جی‌اس و یک سرویس محصول پایتون فقط خواندنی است.
سرویس‌های سفارش، کاربر، اعلان، پایگاه داده و پیام‌رسانی ایده‌های افزایشی هستند،
و در این مخزن پیاده‌سازی نشده‌اند.

- [بعدی: برنامه پایگاه داده](../../../../examples/database-app)
