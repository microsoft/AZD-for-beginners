# کارگاه توسعه‌دهندگان هوش مصنوعی با AZD

> راهنمای منبع بر اساس AZD 1.37.2 در 4 نوامبر 2026 بازبینی شده است. عکس‌ها برای نمایش هستند؛ در دسترس بودن سرویس، برچسب‌های پورتال و پیش‌فرض‌های الگو ممکن است تغییر کند.

> [!IMPORTANT]  
> **این کارگاه با راهنمای کارگاه تجهیز شده که می‌توانید آن را در مرورگر محلی خود پیش‌نمایش کنید. برای شروع، مخزن را در GitHub Codespaces، یک کانتینر توسعه، یا یک کلون محلی با MkDocs نصب شده باز کنید—سپس تا زمانی که ترمینال فعال VS Code را دیدید، منتظر بمانید و تایپ کنید:**  
> از ریشه مخزن دوره، `requirements-dev.txt` را نصب کنید، سپس `python -m mkdocs serve --config-file workshop/mkdocs.yml` را در پیش‌زمینه اجرا کنید.
> **باید یک دیالوگ پاپ‌آپ برای باز کردن صفحه پیش‌نمایش در مرورگر مشاهده کنید.**

به کارگاه عملی یادگیری Azure Developer CLI (AZD) با تمرکز بر استقرار برنامه‌های هوش مصنوعی خوش آمدید. این کارگاه به شما کمک می‌کند تا در ۳ مرحله درک کاربردی از قالب‌های AZD به دست آورید:

1. **کشف** – قالب مناسب خود را بیابید.
1. **استقرار** – آن را مستقر کرده و اعتبارسنجی کنید که کار می‌کند
1. **سفارشی‌سازی** – اصلاح و تکرار کنید تا متعلق به شما شود!

در طول این کارگاه، با ابزارها و فرایندهای اصلی توسعه‌دهنده نیز آشنا خواهید شد تا به شما در ساده‌سازی سفر توسعه پایان به پایان کمک کند.

## مرور کارگاه

**مدت زمان:** ۳-۴ ساعت  
**سطح:** مبتدی تا متوسط  
**پیش‌نیازها:** آشنایی با Azure، مفاهیم هوش مصنوعی، VS Code و ابزارهای خط فرمان.

این یک کارگاه عملی است که از طریق انجام یاد می‌گیرید. پس از اتمام تمرین‌ها، توصیه می‌کنیم برنامه درسی AZD برای تازه‌کارها را مرور کنید تا سفر یادگیری خود را به سمت بهترین شیوه‌های امنیت و بهره‌وری ادامه دهید.

| زمان| ماژول  | هدف |
|:---|:---|:---|
| ۱۵ دقیقه | معرفی | تعیین چارچوب، درک اهداف |
| ۳۰ دقیقه | انتخاب قالب هوش مصنوعی | بررسی گزینه‌ها و انتخاب شروع‌کننده | 
| ۳۰ دقیقه | اعتبارسنجی قالب هوش مصنوعی | استقرار راه‌حل پیش‌فرض در Azure |
| ۳۰ دقیقه | رمزگشایی قالب هوش مصنوعی | بررسی ساختار و پیکربندی |
| ۳۰ دقیقه | پیکربندی قالب هوش مصنوعی | فعال کردن و امتحان ویژگی‌های موجود |
| ۳۰ دقیقه | سفارشی‌سازی قالب هوش مصنوعی | تطبیق قالب با نیازهای خود |
| ۳۰ دقیقه | پاک‌سازی زیرساخت | پاک‌سازی و آزادسازی منابع |
| ۱۵ دقیقه | جمع‌بندی و گام‌های بعدی | منابع یادگیری، چالش کارگاه |

## آنچه خواهید آموخت

قالب AZD را به عنوان یک محیط یادگیری برای کاوش قابلیت‌ها و ابزارهای مختلف در توسعه پایان به پایان در Microsoft Foundry در نظر بگیرید. تا پایان این کارگاه، باید حس شهودی نسبت به ابزارها و مفاهیم مختلف در این زمینه پیدا کرده باشید.

| مفهوم  | هدف |
|:---|:---|
| **Azure Developer CLI** | درک دستورات و جریان‌های کاری ابزار|
| **قالب‌های AZD**| درک ساختار پروژه و پیکربندی|
| **عامل هوش مصنوعی Azure**| تأمین و استقرار پروژه Microsoft Foundry  |
| **جستجوی هوش مصنوعی Azure**| فعال‌سازی مهندسی زمینه‌ای با عوامل |
| **مانیتورینگ**| کاوش ردیابی، پایش و ارزیابی‌ها |
| **تست‌های قرمز**| کاوش آزمون‌های خصمانه و راهکارهای کاهش ریسک |
