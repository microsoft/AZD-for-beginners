# AZD برای مبتدیان: طرح درس و چارچوب یادگیری

## نمای کلی دوره

از طریق فصل‌های ساختارمند طراحی شده برای یادگیری تدریجی، فرمان خطی توسعه‌دهنده Azure (azd) را به‌طور کامل یاد بگیرید. **تمرکز ویژه روی استقرار برنامه‌های هوش مصنوعی با ادغام Microsoft Foundry.**

### چرا این دوره برای توسعه‌دهندگان مدرن حیاتی است

توسعه‌دهندگانی که بارهای کاری هوش مصنوعی را مستقر می‌کنند معمولاً نیاز به راهنمایی در موارد زیر دارند:
- معماری‌های پیچیده چندخدمتی هوش مصنوعی
- بهترین شیوه‌های استقرار هوش مصنوعی در محیط تولید  
- ادغام و پیکربندی سرویس‌های هوش مصنوعی Azure
- بهینه‌سازی هزینه برای بارهای کاری هوش مصنوعی
- عیب‌یابی مشکلات خاص استقرار هوش مصنوعی

### اهداف اصلی یادگیری

با تکمیل این دوره ساختارمند، شما قادر خواهید بود:
- **ایجاد تسلط بر مبانی AZD**: مفاهیم اصلی، نصب و پیکربندی
- **استقرار برنامه‌های هوش مصنوعی**: استفاده از AZD با خدمات Microsoft Foundry
- **پیاده‌سازی زیرساخت به‌عنوان کد**: مدیریت منابع Azure با قالب‌های Bicep
- **عیب‌یابی استقرارها**: رفع مشکلات رایج و اشکال‌زدایی مشکلات
- **بهینه‌سازی برای محیط تولید**: امنیت، مقیاس‌بندی، نظارت و مدیریت هزینه
- **ساخت راه‌حل‌های چندعامل‌‍‌ه**: استقرار معماری‌های پیچیده هوش مصنوعی

- **مشارکت‌های جامعه**: بحث‌ها، نمونه‌ها و بهبودهای به اشتراک گذاشته شده با جامعه Azure
- **شبکه حرفه‌ای**: ارتباط با کارشناسان Azure و مجریان استقرار هوش مصنوعی

### مسیر یادگیری پس از دوره
فارغ‌التحصیلان آماده تخصص پیشرفته در:
- **متخصص Microsoft Foundry**: تخصص عمیق در استقرار و ارکستراسیون مدل‌های هوش مصنوعی
- **رهبری معماری کلاد**: طراحی استقرارهای سازمانی و حاکمیت
- **رهبری جامعه توسعه‌دهندگان**: مشارکت در نمونه‌ها و منابع جامعه Azure
- **آموزش شرکتی**: تدریس مهارت‌های AZD و استقرار هوش مصنوعی در سازمان‌ها
