# एझेड फॉर एआय डेव्हलपर्स वर्कशॉप

> स्रोत मार्गदर्शन AZD 1.37.2 विरुद्ध 4 नोव्हेंबर 2026 रोजी पुनरावलोकन केले गेले आहे. स्क्रीनशॉट्स हे उदाहरणार्थ आहेत; सेवा उपलब्धता, पोर्टल लेबल्स, आणि टेम्पलेट डीफॉल्ट्स बदलू शकतात.

> [!IMPORTANT]  
> **हा वर्कशॉप एक वर्कशॉप मार्गदर्शकासह सुसज्ज केला आहे ज्याला तुम्ही तुमच्या स्थानिक ब्राउझरमध्ये प्रीव्ह्यू करू शकता. सुरू करण्यासाठी, GitHub Codespaces, dev container, किंवा MkDocs इंस्टॉल केलेल्या स्थानिक क्लोनमध्ये रेपो उघडा—नंतर सक्रिय VS Code टर्मिनल दिसेपर्यंत वाट पाहा आणि टाइप करा:**  
> कोर्स रिपॉझिटरी रूटवरून, `requirements-dev.txt` इंस्टॉल करा, नंतर `python -m mkdocs serve --config-file workshop/mkdocs.yml` फोरग्राउंडमध्ये चालवा.
> **तुम्हाला ब्राउझरमध्ये प्रीव्ह्यू पृष्ठ उघडण्यासाठी एक पॉप-अप डायलॉग दिसेल.**

Azure Developer CLI (AZD) सह AI अनुप्रयोगांच्या डिप्लॉयमेंटवर लक्ष केंद्रित करताना शिकण्यासाठी सदर वर्कशॉपमध्ये तुमचे स्वागत आहे. ही वर्कशॉप तुम्हाला 3 टप्यांमध्ये AZD टेम्पलेटचा व्यावहारिक समज प्राप्त करण्यास मदत करते:

1. **शोध** - तुमच्यासाठी योग्य टेम्पलेट शोधा.
1. **डिप्लॉयमेंट** - डिप्लॉय करा आणि ते कार्य करते याची पुष्टी करा
1. **सानुकूलन** - सुधारणा करा आणि ते तुमचे बनवा!

या वर्कशॉपदरम्यान, तुम्हाला मुख्य डेव्हलपर साधने व वर्कफ्लोजची ओळखही होईल, जी तुमच्या पूर्ण विकास प्रवासाला सुलभ करण्यात मदत करतील.

## वर्कशॉप आढावा

**कालावधी:** 3-4 तास  
**स्तर:** प्रारंभिक ते मध्यम  
**पूर्व-अट:** Azure, AI संकल्पना, VS Code आणि कमांड-लाइन साधनांची ओळख.

हा एक हातांवर शिकण्याचा वर्कशॉप आहे. तुम्ही जेव्हा सराव पूर्ण कराल, तेव्हा आम्ही AZD फॉर बिगिनर्स अभ्यासक्रमाचा पुनरावलोकन करण्याची शिफारस करतो जेणेकरून तुम्हाला सुरक्षा आणि उत्पादकतेच्या सर्वोत्तम पद्धतींचा अभ्यास सुरू ठेवता येईल.

| वेळ| मॉड्यूल  | उद्दिष्ट |
|:---|:---|:---|
| 15 मिनिटे | परिचय | संकल्पना स्पष्ट करा, उद्दिष्टे समजून घ्या |
| 30 मिनिटे | AI टेम्पलेट निवडा | पर्याए शोधा आणि प्रारंभ करा | 
| 30 मिनिटे | AI टेम्पलेटची पुष्टी करा | डीफॉल्ट सोल्यूशन Azure वर डिप्लॉय करा |
| 30 मिनिटे | AI टेम्पलेट विश्लेषण करा | संरचना व कॉन्फिगरेशन तपासा |
| 30 मिनिटे | AI टेम्पलेट सानुकूलित करा | उपलब्ध वैशिष्ट्ये सक्रिय करा आणि वापरून पहा |
| 30 मिनिटे | AI टेम्पलेट सानुकूल करा | टेम्पलेट तुमच्या गरजेनुसार समायोजित करा |
| 30 मिनिटे | पायाभूत सुविधा तोडा | साफसफाई करा आणि संसाधने मुक्त करा |
| 15 मिनिटे | समारोप व पुढील पायऱ्या | शिक्षण साधने, वर्कशॉप चॅलेंज |
| | |

## तुम्ही काय शिकाल

AZD टेम्पलेटला Microsoft Foundry वरील पूर्ण विकासासाठी विविध क्षमता व साधने शोधण्याचा शिका मानून या वर्कशॉपच्या शेवटी तुम्हाला या संदर्भातील विविध साधने व संकल्पना सहज समजतील.

| संकल्पना  | उद्दिष्ट |
|:---|:---|
| **Azure Developer CLI** | साधनांच्या आदेश व वर्कफ्लोज समजून घ्या|
| **AZD टेम्पलेट्स**| प्रकल्पाची रचना व संरचना समजून घ्या|
| **Azure AI एजंट**| Microsoft Foundry प्रकल्पाची व्यवस्था व डिप्लॉयमेंट  |
| **Azure AI शोध**| एजंटसह संदर्भ अभियांत्रण सक्षम करा |
| **दृश्यता**| ट्रेसिंग, निरीक्षण व मूल्यमापन शोधा |
| **रेड टीमिंग**| विरोधी चाचणी व प्रतिबंध शोधा |
| | |
