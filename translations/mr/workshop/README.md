# AI विकासकांसाठी AZD कार्यशाळा

AI अ‍ॅप्लिकेशन डिप्लॉयमेंटवर लक्ष केंद्रित करून Azure Developer CLI (AZD) शिकण्यासाठी ही हाताळणी कार्यशाळा आपले स्वागत करते. ही कार्यशाळा AZD टेम्पलेट्सची अमलात आणलेली समज 3 टप्प्यात देण्यास मदत करते:

1. **शोध** - आपल्यासाठी योग्य टेम्पलेट शोधा.
1. **डिप्लॉयमेंट** - डिप्लॉय करा आणि ते कार्यरत आहे का ते तपासा
1. **सानुकूलन** - सुधारणा करा आणि ते आपले बनवा!

या कार्यशाळेच्या कालावधीत, आपल्याला मुख्य डेव्हलपर साधने आणि वर्कफ्लोजची ओळख देखील करून देण्यात येईल, ज्यामुळे आपले पूर्ण विकास प्रवास सुलभ होईल.

<br/>

## ब्राउझर-आधारित मार्गदर्शक

कार्यशाळेची धडे Markdown मध्ये आहेत. आपण त्यांना थेट GitHub मध्ये नेव्हिगेट करू शकता - किंवा खालील स्क्रीनशॉटप्रमाणे ब्राउझर-आधारित पूर्वावलोकन सुरू करू शकता.

![Workshop](../../../translated_images/mr/workshop.75906f133e6f8ba0.webp)

हा पर्याय वापरण्यासाठी - रेपॉजिटरी आपल्या प्रोफाइलवर फोर्क करा, आणि GitHub Codespaces सुरू करा. जेव्हा VS Code टर्मिनल सक्रिय होईल, तेव्हा हा आदेश टाइप करा:

हा ब्राउझर पूर्वावलोकन GitHub Codespaces, dev कंटेनर्स किंवा Python आणि MkDocs स्थापित केलेल्या स्थानिक क्लोनमध्ये चालतो.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

या आदेशांना **कोर्स रेपॉजिटरीच्या मूळ** स्थानावर चालवा, स्वतंत्ररित्या इनिशियलाइझ केलेल्या AI नमुन्यावर नाही. पूर्वावलोकन पुढील बाजूस ठेवा जेणेकरून त्रुटी दिसतील; थांबवण्यासाठी Ctrl+C दाबा. साइट सर्व्ह न करता तपासण्यासाठी, `python -m mkdocs build --strict --config-file workshop/mkdocs.yml` चालवा.

काही सेकंदांत, एक पॉप-अप डायलॉग दिसेल. त्यात `Open in browser` हा पर्याय निवडा. वेब-आधारित मार्गदर्शक आता नवीन ब्राउझर टॅबमध्ये उघडेल. या पूर्वावलोकनाचे काही फायदे:

1. **बिल्ट-इन शोध** - कीवर्ड किंवा धडे जलद शोधा.
1. **कॉपी आयकॉन** - कोडब्लॉक्सवर होभर करा ही पर्याय पहाण्यासाठी
1. **थीम टॉगल** - डार्क आणि लाइट थीममध्ये बदला
1. **मदत मिळवा** - फूटरमधील Discord आयकॉन क्लिक करून सामील व्हा!

## आपण काय शिकाल

AZD टेम्पलेट हे Microsoft Foundry वरील एंड-टू-एंड विकासासाठी विविध क्षमतांची आणि साधनांची अन्वेषण करण्यासाठी शिकण्याचे सॅंडबॉक्स समजावे. कार्यशाळेच्या शेवटी, आपल्याला या संदर्भात विविध साधने आणि संकल्पनांचा सहज समज मिळेल.

| संकल्पना  | उद्दिष्ट |
|:---|:---|
| **Azure Developer CLI** | साधन आदेश आणि वर्कफ्लोज समजून घ्या|
| **AZD टेम्पलेट्स**| प्रकल्प संरचना आणि कॉन्फिगरेशन समजावून घ्या|
| **Azure AI एजंट**| Microsoft Foundry प्रकल्पाचा प्राव्हिजन आणि डिप्लॉय करा  |
| **Azure AI शोध**| एजंट्ससह कॉन्टेक्स्ट इंजिनीअरिंग सक्षम करा |
| **ऑब्जर्व्हॅबिलिटी**| ट्रेसिंग, मॉनिटरिंग आणि मूल्यांकन तपासा |
| **रेड टीमिंग**| विरोधी चाचणी आणि प्रतिबंध तपासा |

## कार्यशाळेची रचना

कार्यशाळा आपणास टेम्पलेट शोधणीपासून, डिप्लॉयमेंट, विसर्जन आणि सानुकूलन करण्याच्या प्रवासावर घेऊन जाते - अधिकृत [AI एजंटसह सुरुवात](https://github.com/Azure-Samples/get-started-with-ai-agents) प्रारंभिक टेम्पलेट वापरून.

### [मॉड्यूल 1: AI टेम्पलेट निवडा](docs/instructions/1-Select-AI-Template.md) (30 मिनिटे)

- AI टेम्पलेट्स काय आहेत?
- AI टेम्पलेट्स कुठे सापडतील?
- मी AI एजंट्स तयार करण्यात कसे सुरुवात करू शकतो?
- **प्रयोगशाळा**: Codespaces किंवा dev कंटेनरमध्ये जलद सुरुवात

### [मॉड्यूल 2: AI टेम्पलेट तपासा](docs/instructions/2-Validate-AI-Template.md) (30 मिनिटे)

- AI टेम्पलेट आर्किटेक्चर काय आहे?
- AZD विकास वर्कफ्लो काय आहे?
- AZD विकासासाठी मदत कशी मिळवायची?
- **प्रयोगशाळा**: AI एजंट्स टेम्पलेट डिप्लॉय & तपासा

### [मॉड्यूल 3: AI टेम्पलेट विसर्जन करा](docs/instructions/3-Deconstruct-AI-Template.md) (30 मिनिटे)

- आपले वातावरण `.azure/` मध्ये अन्वेषण करा 
- आपली संसाधन व्यवस्था `infra/` मध्ये अन्वेषण करा 
- आपली AZD कॉन्फिगरेशन `azure.yaml` मध्ये अन्वेषण करा
- **प्रयोगशाळा**: पर्यावरण बदल करा आणि पुन्हा डिप्लॉय करा

### [मॉड्यूल 4: AI टेम्पलेट कॉन्फिगर करा](docs/instructions/4-Configure-AI-Template.md) (30 मिनिटे)
- तपासा: पुनर्प्राप्ती ऑगमेंटेड जनरेशन
- तपासा: एजंट मूल्यांकन आणि रेड टीमिंग
- तपासा: ट्रेसिंग आणि मॉनिटरिंग
- **प्रयोगशाळा**: AI एजंट + ऑब्जर्व्हॅबिलिटी अन्वेषण करा 

### [मॉड्यूल 5: AI टेम्पलेट सानुकूलित करा](docs/instructions/5-Customize-AI-Template.md) (30 मिनिटे)
- परिभाषित करा: PRD सह परिदृश्य आवश्यकताः
- कॉन्फिगर करा: AZD साठी पर्यावरणीय चल
- अंमलात आणा: जोडा लाइफसायकल हुक्स
- **प्रयोगशाळा**: माझ्या परिदृश्यानुसार टेम्पलेट सानुकूलित करा

### [मॉड्यूल 6: इन्फ्रास्ट्रक्चर बंद करा](docs/instructions/6-Teardown-Infrastructure.md) (30 मिनिटे)
- पुनरावलोकन करा: AZD टेम्पलेट्स काय आहेत?
- पुनरावलोकन करा: Azure Developer CLI का वापरावे?
- पुढील पाऊल: वेगळे टेम्पलेट वापरून पाहा!
- **प्रयोगशाळा**: इन्फ्रास्ट्रक्चर डिप्रोव्हिजन आणि क्लीनअप
