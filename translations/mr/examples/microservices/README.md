# मायक्रोसर्व्हिसेस उदाहरण

चालवता येणारी अंमलबजावणी आणि तिचे सूचना येथे आहेत
**[container-app/microservices](../container-app/microservices/README.md)**.

हा निर्देशिका फक्त नेव्हिगेशनसाठी आहे. यात `azure.yaml`, `infra/`, किंवा `src/` यांचा समावेश नाही.
येथे `azd up` चालवू नका.

संग्रहालयाच्या मूळ पासून:

```bash
cd examples/container-app/microservices
```

नंतर लिंक केलेल्या README मध्ये पूर्वअटी, तैनाती, पडताळणी, स्थानिक
विकास, व्यावहारिक सराव, खर्च आणि स्वच्छता यांचा मागोवा घ्या.

नमुन्यात Node.js API Gateway आणि फक्त वाचनासाठी Python उत्पादन सेवा आहे.
ऑर्डर, वापरकर्ता, सूचना, डेटाबेस, आणि संदेश सेवा हे विस्तार कल्पना आहेत,
या संग्रहालयात समाविष्ट करण्यात आलेल्या अंमलबजावणी नाहीत.

- [मागील: साधा Flask API](../../../../examples/container-app/simple-flask-api)
- [पुढील: डेटाबेस अ‍ॅप](../../../../examples/database-app)
- [AI विकास](../../docs/chapter-02-ai-development/README.md)
- [कोर्स मुखपृष्ठ](../../README.md)
