# अध्याय 1: प्राथमिकता आणि जलद प्रारंभ

**📚 कोर्स**: [शुरुआतीसाठी AZD](../../README.md) | **⏱️ कालावधी**: पहिल्या तैनातीसह ७५-१२० मिनिटे; अतिरिक्त सराव जास्त वेळ लागतो | **⭐ क्लिष्टता**: प्रारंभीक

---

## आढावा

हा अध्याय Azure Developer CLI (azd) मूलभूत गोष्टी सादर करतो. तुम्ही मुख्य संकल्पना शिकाल, साधने स्थापित कराल, आणि तुमचे पहिले अॅप्लिकेशन Azure वर तैनात कराल.

> कमांड आणि कॉन्फिगरेशन पुनरावलोकन लक्षित: `azd 1.37.2` (नोव्हेंबर २०२६). पुनरावलोकनादरम्यान थेट Azure प्रोव्हिजनिंग चालवले नाही.

## शिक्षण उद्दिष्टे

हा अध्याय पूर्ण करून, तुम्ही:
- Azure Developer CLI काय आहे आणि ते Azure CLI पासून कसे वेगळे आहे हे समजून घ्या
- तुमच्या प्लॅटफॉर्मवर AZD स्थापित आणि कॉन्फिगर करा
- `azd up` वापरून तुमचे पहिले अॅप्लिकेशन Azure वर तैनात करा
- `azd down` वापरून संसाधने स्वच्छ करा

## ✅ येथे प्रारंभ करा: तुमचे सेटअप तपासा

सुरू करण्यापूर्वी, खात्री करा की तुमचा स्थानिक संगणक अध्याय 1 टेम्पलेटसाठी तयार आहे:

**Windows:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

जर स्क्रिप्टमध्ये साधने हरवलेली असल्याचे अहवाल दिला, तर ती प्रथम दुरुस्त करा आणि नंतर अध्याय सुरू करा.

---

## 🚀 जलद प्रारंभ

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ यशस्वी निकष

हा अध्याय पूर्ण केल्यानंतर, तुम्ही सक्षम असायला हवे:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
