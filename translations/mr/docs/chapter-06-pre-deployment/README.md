# अध्याय 6: पूर्व-रिलीज नियोजन आणि पडताळणी

**📚 कोर्स**: [AZD For Beginners](../../README.md) | **⏱️ कालावधी**: 2-4 तास वाचन; बदललेली प्रयोगशाळा करण्यासाठी अतिरिक्त वेळ | **⭐ गुंतागुंत**: मध्यम–उन्नत

---

## आढावा

हा अध्याय तुमच्या अर्जाला तैनात करण्यापूर्वी आवश्यक नियोजन आणि पडताळणी टप्पे समाविष्ट करतो. योग्य क्षमता नियोजन, SKU निवड आणि प्रीफ्लाइट तपासणींसह महागड्या चुका टाळण्यास शिका.

> कमांड मार्गदर्शन प्रकाशित `azd 1.37.2` संदर्भाच्या विरुद्ध तपासलेले आहे. क्लाउड तैनाती केलेल्या नाहीत. लांबट धडे दाखवणारे तुकडे असतात, पूर्ण स्थानिक तैनात प्रकल्प नाहीत.

## शिकण्याचे उद्दिष्ट

हा अध्याय पूर्ण करून, तुम्ही:
- तैनातीपूर्वी प्रीफ्लाइट तपासणी चालवा
- क्षमता नियोजन करा आणि संसाधन गरजा अंदाज करा
- खर्च ऑप्टिमायझेशनसाठी योग्य SKU निवडा
- मॉनिटरिंगसाठी Application Insights कॉन्फिगर करा
- मल्टी-एजंट समन्वय नमुने आणि त्यांच्या तैनाती गरजा समजून घ्या

## 🚀 जलद प्रारंभ

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ पूर्व-रिलीज तपासणी यादी

### `azd provision` याआधी

- [ ] प्रदेशासाठी कोटा पडताळलेला आहे
- [ ] योग्य पद्धतीने SKU निवडले आहेत
- [ ] खर्चाचा अंदाज पाहिला आहे
- [ ] नाव देण्याचा स्वरूप एकसंध आहे
- [ ] सुरक्षा/RBAC कॉन्फिगर केलेले आहे

### `azd deploy` याआधी

- [ ] पर्यावरण बदलset केले आहेत
- [ ] Key Vault मधील गुपिते
- [ ] कनेक्शन स्ट्रिंग्स पडताळल्या आहेत
- [ ] हेल्थ तपासणी कॉन्फिगर केलेली आहे
