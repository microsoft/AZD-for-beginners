## प्रस्तावना

या सर्वसमावेशक शब्दसंग्रहात Azure Developer CLI आणि Azure क्लाऊड डेव्हलपमेंटमध्ये वापरल्या जाणाऱ्या संज्ञा, संकल्पना आणि संक्षिप्त शब्दांसाठी व्याख्या दिल्या आहेत. तांत्रिक दस्तऐवज समजून घेण्यासाठी, समस्या सोडवण्यासाठी आणि azd प्रकल्प आणि Azure सेवा याबाबत प्रभावी संवाद साधण्यासाठी आवश्यक संदर्भ.

## शिक्षण उद्दिष्टे

या शब्दसंग्रहाचा वापर करून, आपण:
- आवश्यक Azure Developer CLI संज्ञा आणि संकल्पना समजून घेणार
- Azure क्लाऊड डेव्हलपमेंट शब्दसंग्रह आणि तांत्रिक संज्ञांमध्ये प्रावीणता मिळवणार
- Infrastructure as Code आणि डिप्लॉयमेंट संज्ञांचा कार्यक्षम संदर्भ घेणार
- Azure सेवा नावे, संक्षिप्त शब्द, आणि त्यांचे उद्दिष्ट समजून घेणार
- समस्या निवारण आणि डीबगिंग संज्ञांसाठी व्याख्या ऍक्सेस करणार
- प्रगत Azure आर्किटेक्चर आणि विकास संकल्पना शिकणार

## शिक्षण परिणाम

या शब्दसंग्रहाचा नियमित संदर्भ घेऊन, आपण सक्षम असाल:
- योग्य Azure Developer CLI संज्ञा वापरून प्रभावीपणे संवाद साधण्यास
- तांत्रिक दस्तऐवज आणि त्रुटी संदेश अधिक स्पष्टपणे समजून घेण्यास
- आत्मविश्वासाने Azure सेवा आणि संकल्पनांमध्ये नेव्हिगेट करण्यास
- योग्य तांत्रिक शब्दसंग्रह वापरून समस्या सोडवण्यास
- अचूक तांत्रिक भाषेत टीम चर्चेत योगदान देण्यास
- आपल्या Azure क्लाऊड विकास ज्ञानाचे नियोजनबद्धपणे विस्तार करण्यास

## A

**ARM Template**  
Azure Resource Manager साचा. Azure संसाधने घोषित पद्धतीने परिभाषित आणि डिप्लॉय करण्यासाठी JSON-आधारित Infrastructure as Code फॉरमॅट.

**App Service**  
Azure चे platform-as-a-service (PaaS) होस्टिंग वेब अनुप्रयोग, REST API आणि मोबाइल बॅकएंडसाठी जेथे इन्फ्रास्ट्रक्चर व्यवस्थापित करण्याची आवश्यकता नाही.

**Application Insights**  
Azure चे application performance monitoring (APM) सेवा जी अनुप्रयोगाच्या कार्यक्षमता, उपलब्धता आणि वापराबाबत सखोल अंतर्दृष्टी प्रदान करते.

**Azure CLI**  
Azure संसाधने व्यवस्थापित करण्यासाठी कमांड-लाइन इंटरफेस. हे AZD चे पूरक आहे परंतु वेगळा लॉगिन आहे; मुख्य AZD प्रमाणीकरण वापरते `azd auth login`.

**Azure Developer CLI (azd)**  
डेव्हलपर-केंद्रित कमांड-लाइन टूल जे Azure वर अनुप्रयोग तयार करणे आणि डिप्लॉय करण्याची प्रक्रिया वेगवान करतो ज्यात साचा आणि Infrastructure as Code वापरला जातो.

**azure.yaml**  
azd प्रकल्पासाठी मुख्य कॉन्फिगरेशन फाइल जी सेवा, इन्फ्रास्ट्रक्चर आणि डिप्लॉयमेंट हुक्स परिभाषित करते.

**Azure Resource Manager (ARM)**  
Azure ची डिप्लॉयमेंट आणि व्यवस्थापन सेवा जी संसाधने तयार, अद्ययावत आणि हटवण्यासाठी व्यवस्थापन स्तर प्रदान करते.

## B

**Bicep**  
Microsoft कडून तयार केलेली डोमेन-विशिष्ट भाषा (DSL) जी Azure संसाधने डिप्लॉय करण्यासाठी वापरली जाते. ARM templates पेक्षा सोपी सिंटॅक्स देते आणि ARM मध्ये कंपाईल करते.

**Build**  
स्त्रोत कोड संकलित करणे, अवलंबन स्थापित करणे, आणि अनुप्रयोग डिप्लॉय करण्यासाठी तयार करण्याची प्रक्रिया.

**Blue-Green Deployment**  
दोन एकसारख्या उत्पादन पर्यावरणांचा (निळा आणि हिरवा) वापर करणारी डिप्लॉयमेंट रणनीती ज्यामुळे डाउनटाइम आणि जोखमी कमी होतात.

## C

**Container Apps**  
Azure ची सर्व्हरलेस कंटेनर सेवा जी क्लिष्ट इन्फ्रास्ट्रक्चरशिवाय कंटेनरयुक्त अनुप्रयोग चालवण्यास सक्षम करते.

**CI/CD**  
लगातार इंटीग्रेशन/लगातार डिप्लॉयमेंट. कोड बदल समाकलित करण्यासाठी आणि अनुप्रयोग डिप्लॉय करण्यासाठी स्वयंचलित पद्धती.

**Cosmos DB**  
Azure ची जागतिक पातळीवर वितरित, मल्टी-मॉडेल डेटाबेस सेवा जी कामगिरी, विलंबता, उपलब्धता, आणि सातत्यासाठी संपूर्ण SLA प्रदान करते.

**Configuration**  
अनुप्रयोगाचा वर्तन आणि डिप्लॉयमेंट पर्याय नियंत्रित करणाऱ्या सेटिंग्ज आणि पॅरामीटर्स.

## D

**Deployment**  
अनुप्रयोग आणि त्यांच्या अवलंबनांचा लक्ष्य इन्फ्रास्ट्रक्चरवर स्थापित आणि कॉन्फिगर करण्याची प्रक्रिया.

**Docker**  
कंटेनरीकरण तंत्रज्ञानाचा वापर करून अनुप्रयोग विकसित, पाठवणे आणि चालवण्याचे प्लॅटफॉर्म.

**Dockerfile**  
Docker कंटेनर प्रतिमा तयार करण्यासाठी सूचनांचा असलेला मजकूर फाइल.

## E

**Environment**  
डिप्लॉयमेंट लक्ष असलेले विशिष्ट अनुप्रयोगाचे उदाहरण (उदा., विकास, स्टेजिंग, उत्पादन).

**Environment Variables**  
कॉन्फिगरेशन मूल्ये जी की-मूल्य जोड्यांमध्ये संग्रहित असतात आणि अनुप्रयोगांना रनटाइममध्ये प्रवेश मिळू शकतो.

**Endpoint**  
URL किंवा नेटवर्क पत्ता जिथे अनुप्रयोग किंवा सेवा प्रवेशयोग्य आहे.

## F

**Function App**  
Azure ची सर्व्हरलेस संगणकीय सेवा जी इव्हेंट-आधारित कोड व्यवस्थापित न करता चालवण्यास सक्षम करते.

## G

**GitHub Actions**  
GitHub रेपॉझिटरीजसह समाकलित CI/CD प्लॅटफॉर्म जो वर्कफ्लोज स्वयंचलित करतो.

**Git**  
स्त्रोत कोडमधील बदल ट्रॅक करण्यासाठी वापरलेला वितरित आवृत्ती नियंत्रण प्रणाली.

## H

**Hooks**  
कस्टम स्क्रिप्ट किंवा कमांड्स जे डिप्लॉयमेंट जीवनचक्राच्या विशिष्ट टप्प्यावर (पूर्वप्रोव्हिजन, पोस्टप्रोव्हिजन, पूर्वडिप्लॉय, पोस्टडिप्लॉय) चालवले जातात.

**Host**  
Azure सेवा प्रकार जिथे अनुप्रयोग डिप्लॉय होईल (उदा., appservice, containerapp, function).

## I

**Infrastructure as Code (IaC)**  
हस्तचालित प्रक्रियांची जागी कोड वापरून इन्फ्रास्ट्रक्चर परिभाषित व व्यवस्थापित करण्याचा सराव.

**Init**  
नवीन azd प्रकल्प आरंभ करण्याची प्रक्रिया, सहसा साच्यापासून.

## J

**JSON**  
JavaScript Object Notation. कॉन्फिगरेशन फाइल्स आणि API प्रतिसादांसाठी सामान्यपणे वापरला जाणारा डेटा विनिमय फॉरमॅट.

**JWT**  
JSON Web Token. JSON ऑब्जेक्ट म्हणून पक्षांमधील माहिती सुरक्षितपणे पाठविण्याचा मानक.

## K

**Key Vault**  
Azure ची सेवा जी रहस्ये, कळा, आणि प्रमाणपत्र सुरक्षितपणे साठवते आणि व्यवस्थापित करते.

**Kusto Query Language (KQL)**  
Azure Monitor, Application Insights आणि इतर Azure सेवांमधील डेटाचे विश्लेषण करण्यासाठी वापरली जाणारी क्वेरी भाषा.

## L

**Load Balancer**  
सेवा जी येणारा नेटवर्क ट्रॅफिक एकापेक्षा जास्त सर्व्हर किंवा उदाहरणांमध्ये विभागते.

**Log Analytics**  
Azure सेवा जी क्लाऊड आणि ऑन-प्रिमाइसेस वातावरणांमधील टेलीमेट्री डेटा गोळा, विश्लेषण आणि क्रिया करण्यासाठी वापरली जाते.

## M

**Managed Identity**  
Azure वैशिष्ट्य जे Azure सेवांना इतर Azure सेवांवर प्रमाणीकरणासाठी आपोआप व्यवस्थापित ओळख प्रदान करते.

**Microservices**  
असा आर्किटेक्चरल दृष्टिकोन जिथे अनुप्रयोग छोटे, स्वतंत्र सेवांच्या संकलन म्हणून तयार केले जातात.

**Monitor**  
Azure ची एकत्रित देखरेख समाधान जी अनुप्रयोग आणि इन्फ्रास्ट्रक्चरवर संपूर्ण-स्टॅक निरीक्षण प्रदान करते.

## N

**Node.js**  
Chrome च्या V8 JavaScript इंजिनवर आधारित JavaScript रनटाइम जे सर्व्हर-साइड अनुप्रयोग तयार करण्यासाठी वापरले जाते.

**npm**  
Node.js साठी पॅकेज मॅनेजर जो अवलंबने आणि पॅकेजेस व्यवस्थापित करतो.

## O

**Output**  
इन्फ्रास्ट्रक्चर डिप्लॉयमेंटमधून परत आलेली मूल्ये जी अनुप्रयोग किंवा इतर संसाधनांकडून वापरली जाऊ शकतात.

## P

**Package**  
अनुप्रयोगाचा कोड आणि अवलंबने डिप्लॉयमेंटसाठी तयार करण्याची प्रक्रिया.

**Parameters**  
इन्फ्रास्ट्रक्चर साच्यांना सानुकूल डिप्लॉयमेंटसाठी दिलेली इनपुट मूल्ये.

**PostgreSQL**  
Azure मध्ये व्यवस्थापित सेवा म्हणून समर्थित ओपन-सोर्स रिलेशनल डेटाबेस सिस्टम.

**Provisioning**  
इन्फ्रास्ट्रक्चर साच्यांमध्ये परिभाषित Azure संसाधने तयार करण्याची आणि कॉन्फिगर करण्याची प्रक्रिया.

## Q

**Quota**  
Azure सदस्यता किंवा प्रदेशात निर्माण करू शकणाऱ्या संसाधनांची मर्यादा.

## R

**Resource Group**  
Azure संसाधनांसाठी तार्किक कंटेनर जे एकसारखा जीवनचक्र, अधिकार आणि धोरणे सामायिक करतात.

**Resource Token**  
azd ने तयार केलेला अद्वितीय स्ट्रिंग जो डिप्लॉयमेंटनंतर संसाधन नावे अद्वितीय असल्याची खात्री करतो.

**REST API**  
HTTP पद्धती वापरून नेटवर्क अनुप्रयोग डिझाइन करण्याची आर्किटेक्चरल शैली.

**Rollback**  
अनुप्रयोग किंवा इन्फ्रास्ट्रक्चर कॉन्फिगरेशनच्या मागील आवृत्तीमध्ये परत जाण्याची प्रक्रिया.

## S

**Service**  
azure.yaml मध्ये परिभाषित केलेला आपला अनुप्रयोगाचा एक घटक (उदा., वेब फ्रंटएंड, API बॅकएंड, डेटाबेस).

**SKU**  
Stock Keeping Unit. Azure संसाधनांसाठी विविध सेवा स्तर किंवा कामगिरी स्तर दर्शवितो.

**SQL Database**  
Microsoft SQL Server आधारित Azure ची व्यवस्थापित रिलेशनल डेटाबेस सेवा.

**Static Web Apps**  
स्रोत कोड रेपॉझिटरीजमधून फुल-स्टॅक वेब अनुप्रयोग तयार आणि डिप्लॉय करण्यासाठी Azure सेवा.

**Storage Account**  
Azure सेवा जी डेटा ऑब्जेक्ट्ससाठी क्लाऊड संग्रहण प्रदान करते ज्यात ब्लॉब्स, फायली, क्यूज, आणि टेबल्सचा समावेश आहे.

**Subscription**  
Azure खाते कंटेनर जे संसाधन गट आणि संसाधने ठेवते, ज्यात बिलिंग आणि प्रवेश व्यवस्थापन असते.

## T

**Template**  
पूर्व-निर्मित प्रकल्प संरचना ज्यात अनुप्रयोग कोड, इन्फ्रास्ट्रक्चर परिभाषा, आणि सामान्य परिदृश्यांसाठी कॉन्फिगरेशन असते.

**Terraform**  
एक खुला स्रोत Infrastructure as Code साधन जे Azure सहित अनेक क्लाऊड प्रदात्यांना समर्थन देते.

**Traffic Manager**  
Azure चे DNS-आधारित ट्रॅफिक लोड बॅलेंसर जो जागतिक Azure प्रदेशांमध्ये ट्रॅफिक वितरित करतो.

## U

**URI**  
Uniform Resource Identifier. विशिष्ट संसाधन ओळखणार्‍या स्ट्रिंग.

**URL**  
Uniform Resource Locator. URI चा प्रकार जो संसाधन कुठे स्थित आहे आणि ते कसे मिळवायचे ते दर्शवितो.

## V

**Virtual Network (VNet)**  
Azure मधील खाजगी नेटवर्कसाठी मूलभूत बांधकाम ब्लॉक, जो अलगाव आणि विभागणी प्रदान करतो.

**VS Code**  
Visual Studio Code. उत्कृष्ट Azure आणि azd समाकलन असलेला लोकप्रिय कोड संपादक.

## W

**Webhook**  
विशिष्ट घटनांद्वारे ट्रिगर होणारा HTTP कॉलबॅक, सामान्यतः CI/CD पाइपलाइनमध्ये वापरला जातो.

**What-if**  
Azure वैशिष्ट्य जे डिप्लॉयमेंट शर्यत न करता कोणते बदल होतील ते दाखवते.

## Y

**YAML**  
YAML Ain't Markup Language. मानव वाचनीय डेटा सिरियलायझेशन मानक जे azure.yaml सारख्या कॉन्फिगरेशन फाइलसाठी वापरले जाते.

## Z

**Zone**

## Azure सेवा नावांची मॅपिंग

| सामान्य नाव | अधिकृत Azure सेवा नाव | azd होस्ट प्रकार |
|-------------|------------------------------|---------------|
| Web App | Azure App Service | `appservice` |
| API App | Azure App Service | `appservice` |
| Container App | Azure Container Apps | `containerapp` |
| Function | Azure Functions | `function` |
| Static Site | Azure Static Web Apps | `staticwebapp` |
| Database | Azure Database for PostgreSQL | इन्फ्रास्ट्रक्चर संसाधन, अनुप्रयोग नाही `host` |
| NoSQL DB | Azure Cosmos DB | इन्फ्रास्ट्रक्चर संसाधन, अनुप्रयोग नाही `host` |
| Storage | Azure Storage Account | इन्फ्रास्ट्रक्चर संसाधन, अंगभूत अनुप्रयोग नाही `host` |
| Cache | Azure Managed Redis | इन्फ्रास्ट्रक्चर संसाधन, अनुप्रयोग नाही `host` |
| Search | Azure AI Search | इन्फ्रास्ट्रक्चर संसाधन, अनुप्रयोग नाही `host` |
| Messaging | Azure Service Bus | इन्फ्रास्ट्रक्चर संसाधन, अनुप्रयोग नाही `host` |

`services.<name>.host` अनुप्रयोग डिप्लॉयमेंट लक्ष्य निवडतो; ते Azure संसाधन प्रकारासाठी संक्षेप नाही. डेटाबेस, कॅशेस, सर्च सेवा, आणि क्यू सामान्यतः इन्फ्रास्ट्रक्चर पुरवठादाराद्वारे प्राव्हिजन केले जातात आणि आउटपुट/कॉन्फिगरेशनद्वारे अनुप्रयोगाशी कनेक्ट केले जातात.

## संदर्भ-विशिष्ट संज्ञा

### विकास संज्ञा
- **Hot Reload**: विकासादरम्यान अनुप्रयोग स्वयंचलितपणे अपडेट करणे, पुन्हा प्रारंभ न करता
- **Build Pipeline**: कोड तयार करणे आणि चाचणीसाठी स्वयंचलित प्रक्रिया
- **Deployment Slot**: App Service मधील स्टेजिंग पर्यावरण
- **Environment Parity**: विकास, स्टेजिंग आणि उत्पादन पर्यावरण एकसारखे ठेवणे

### सुरक्षा संज्ञा
- **Managed Identity**: Azure वैशिष्ट्य जे आपोआप प्रमाणपत्र व्यवस्थापन प्रदान करते
- **Key Vault**: रहस्ये, कळा, आणि प्रमाणपत्रांसाठी सुरक्षित संग्रह
- **RBAC**: Azure संसाधनांसाठी भूमिका-आधारित प्रवेश नियंत्रण
- **Network Security Group**: नेटवर्क ट्रॅफिक नियंत्रित करण्यासाठी आभासी फायरवॉल

### देखरेख संज्ञा
- **Telemetry**: मोजमाप आणि डेटाचा स्वयंचलित संकलन
- **Application Performance Monitoring (APM)**: सॉफ्टवेअर कार्यक्षमता देखरेख
- **Log Analytics**: लॉग डेटा गोळा करण्यासाठी आणि विश्लेषित करण्यासाठी सेवा
- **Alert Rules**: मेट्रिक्स किंवा अटींवर आधारित स्वयंचलित सूचना

### डिप्लॉयमेंट संज्ञा
- **Blue-Green Deployment**: शून्य-डाउनटाइम डिप्लॉयमेंट रणनीती
- **Canary Deployment**: वापरकर्त्यांच्या उपसमूहावर हळूहळू रोलआउट
- **Rolling Update**: अनुप्रयोग उदाहरणांची अनुक्रमिक बदली
- **Rollback**: मागील अनुप्रयोग आवृत्तीत परत जाणे
