# Mfano wa Microservices

Utekelezaji unaoweza kuendeshwa na maelekezo yake yako ndani ya
**[container-app/microservices](../container-app/microservices/README.md)**.

Saraka hii ni kwa ajili ya urambazaji tu. Haina `azure.yaml`, `infra/`, wala `src/`.
Usiruhusu `azd up` kuendeshwa hapa.

Kutoka kwenye mzizi wa hifadhidata:

```bash
cd examples/container-app/microservices
```

Kisha fuata README iliyoambatishwa kwa ajili ya mahitaji, uanzishaji, uthibitishaji, maendeleo ya ndani,
mazoezi ya vitendo, gharama, na usafi.

Mfano huu unajumuisha API Gateway ya Node.js na Huduma ya Bidhaa ya Python ya kusoma tu.
Huduma za agizo, mtumiaji, arifa, hifadhidata, na ujumbe ni mawazo ya kuongeza,
si utekelezaji uliojumuishwa katika hifadhidata hii.

- [Iliyopita: API rahisi ya Flask](../../../../examples/container-app/simple-flask-api)
- [Inayofuata: Programu ya hifadhidata](../../../../examples/database-app)
- [Maendeleo ya AI](../../docs/chapter-02-ai-development/README.md)
- [Nyumbani kwa kozi](../../README.md)
