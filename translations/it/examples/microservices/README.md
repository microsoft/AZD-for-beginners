# Esempio Microservizi

L'implementazione eseguibile e le sue istruzioni si trovano in
**[container-app/microservices](../container-app/microservices/README.md)**.

Questa directory è solo per la navigazione. Non contiene `azure.yaml`, `infra/` o `src/`.
Non eseguire `azd up` qui.

Dalla radice del repository:

```bash
cd examples/container-app/microservices
```

Seguire quindi il README collegato per i prerequisiti, il deployment, la verifica, lo sviluppo locale,
gli esercizi pratici, i costi e la pulizia.

Il campione contiene un API Gateway Node.js e un Product Service Python in sola lettura.
I servizi di ordine, utente, notifica, database e messaggistica sono idee di estensione,
non implementazioni incluse in questo repository.

- [Precedente: Simple Flask API](../../../../examples/container-app/simple-flask-api)
- [Successivo: Applicazione database](../../../../examples/database-app)
- [Sviluppo AI](../../docs/chapter-02-ai-development/README.md)
- [Home corso](../../README.md)
