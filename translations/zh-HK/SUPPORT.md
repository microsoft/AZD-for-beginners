# 支援

## 課程問題與疑問

在回報問題前，請先搜尋 [課程問題](https://github.com/microsoft/AZD-for-beginners/issues)。請包含受影響的英文課程、您執行的指令、您的 AZD/擴充套件版本，以及錯誤訊息。請從日誌和截圖中移除憑證、令牌、訂閱資料和個人數據。

一般學習問題請使用 [Azure 開發者社群](https://discord.gg/microsoft-azure)。社群回應不保證為官方支援服務。

## 工具和服務問題

可將可重現的 AZD CLI 錯誤回報至 [Azure/azure-dev](https://github.com/Azure/azure-dev/issues)。如為 Azure 服務事件或訂閱專屬協助，請使用 [Azure 入口網站](https://portal.azure.com/) 中提供的支援選項。

## 安全性回報

請參閱 [SECURITY.md](SECURITY.md) 進行私人漏洞回報。請勿在公開課程問題中張貼秘密或漏洞利用細節。

## Microsoft 支援政策

本教育專案的支援僅限於上述資源。課程範例不包含生產環境支援承諾。
