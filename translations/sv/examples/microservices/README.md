# Mikroservicexempel

Den körbara implementeringen och dess instruktioner finns i
**[container-app/microservices](../container-app/microservices/README.md)**.

Denna katalog är endast för navigering. Den innehåller ingen `azure.yaml`, `infra/`, eller `src/`.
Kör inte `azd up` här.

Från repository-roten:

```bash
cd examples/container-app/microservices
```

Följ sedan den länkade README-filen för förutsättningar, distribution, verifiering, lokal
utveckling, praktiska övningar, kostnader och borttagning.

Exemplet innehåller en Node.js API-gateway och en skrivskyddad Python-produktservice.
Order-, användar-, notifierings-, databas- och meddelandeservicar är idéer till tillägg,
inte implementationer som ingår i detta arkiv.

- [Nästa: Databasapp](../../../../examples/database-app)
