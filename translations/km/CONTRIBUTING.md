# ជួយរួមចំណែកទៅកាន់ AZD សម្រាប់អ្នកដំបូងរៀន

សូមអរគុណចំពោះចំណាប់អារម្មណ៍របស់អ្នកក្នុងការជួយរួមចំណែកដល់វគ្គសិក្សា AZD សម្រាប់អ្នកដំបូងរៀន! ឯកសារនេះផ្តល់នូវមគ្គុទេសក៍ និងពព័ត៌មានសម្រាប់អ្នករួមចំណែក។

## របៀបជួយរួមចំណែក

### រាយការណ៍បញ្ហា

ប្រសិនបើអ្នករកឃើញកំហុស ឬមានយោបល់សម្រាប់ការកែលម្អៈ:

1. **ពិនិត្យបញ្ហាដែលមានរួចហើយ**: ស្វែងរក [បញ្ហាដែលមានរួចហើយ](https://github.com/microsoft/azd-for-beginners/issues) ដើម្បីជៀសវាងការដំណើរការម្តងទៀត
2. **បង្កើតបញ្ហាថ្មី**: ប្រើស្លាកបញ្ហាដែលសមរម្យ
3. **ផ្ដល់ព័ត៌មានលម្អិត**: រួមបញ្ចូលជំហានដើម្បីធ្វើឡើងវិញ, សកម្មភាពដែលរំពឹងទុក និងរូបថតបង្ហាញបើអាចប្រើបាន

### ការផ្តល់យោបល់លើការផ្លាស់ប្តូរ

1. **Fork ឃ្លាំងទិន្នន័យ**: បង្កើត fork ផ្ទាល់ខ្លួនរបស់គម្រោង
2. **បង្កើតសាខា**: បង្កើតសាខាសម្រាប់លក្ខណៈពិសេសនៃការផ្លាស់ប្តូររបស់អ្នក
3. **ធ្វើការផ្លាស់ប្តូរ**: អនុវត្តតាមស្តង់ដារកូដ និងឯកសាររបស់យើង
4. **សាកល្បងការផ្លាស់ប្តូរ**: បញ្ជាក់ថាលីងទាំងអស់ដំណើរការបាន និងមាតិកាបង្ហាញត្រឹមត្រូវ
5. **ដាក់ស្នើ Pull Request**: ផ្ដល់ការ​ពិពណ៌នាដែលច្បាស់លាស់អំពីការផ្លាស់ប្តូររបស់អ្នក

### ប្រភេទនៃការរួមចំណែក

យើងសូមស្វាគមន៍ប្រភេទនៃការរួមចំណែកដូចតទៅ:

#### ការកែលម្អមាតិកា
- កែតម្រូវកំហុសវេយ្យាករណ៍ និងបញ្ហាទម្រង់
- លើកកម្ពស់ភាពច្បាស់លាស់នៃឯកសារដែលមានរួច
- បច្ចុប្បន្នភាពព័ត៌មានដែលចាស់
- បន្ថែមពណ៌នាឬបរិបទដែលខ្លាចខ្វះ

#### ឧទាហរណ៍ថ្មីៗ
- បន្ថែមសถานភាពការវេចខ្ចប់ពិតប្រាកដ
- បង្កើតគំរូ AZD ថ្មីសម្រាប់ករណីប្រើប្រាស់ទូទៅ
- ផ្ដល់សំណុំឯកសារកូដ និងវិញ្ញាសាបន្ថែម

#### ជំនួយបកប្រែ
- ជួយថែរក្សាការបកប្រែដែលមានរួច
- កែលម្អគុណភាពបកប្រែ
- បន្ថែមការបកប្រែសម្រាប់មាតិកាថ្មី

#### រាយការណ៍កំហុស
- រាយការណ៍លីងខូចឬឧទាហរណ៍កូដមិនត្រឹមត្រូវ
- កំណត់ចំណុចខុសគ្នានៃឯកសារ
- ធ្វើស្លាកបញ្ហាវិលតាមភាពងាយចូលប្រើ

## មគ្គុទេសក៍សម្រាប់ការចូលរួម

### ស្តង់ដារឯកសារ

- ប្រើភាសាច្បាស់លាស់សមស្របសម្រាប់អ្នកដំបូងរៀន
- រួមបញ្ចូលគោលបំណងសិក្សានិងលទ្ធផល
- ផ្ដល់នូវជំហានទាំងមូលជាមួយលទ្ធផលដែលរំពឹងទុក
- បន្ថែមតំណរណែនាំទៅមាតិកាស្របគ្នា
- ប្រើទម្រង់និងស្ទីល markdown ដូចគ្នា

### ឧទាហរណ៍កូដ

- បញ្ជាក់ថាឧទាហរណ៍កូដទាំងអស់ត្រូវបានសាកល្បងនិងដំណើរការ
- រួមបញ្ចូលមតិយោបល់ពន្យល់ពីមុខងារសំខាន់ៗ
- ត្រូវអនុវត្តតាមបច្ចេកទេសល្អបំផុតរបស់ Azure និង AZD
- ផ្ដល់លទ្ធផលដែលរំពឹងទុកនៅកន្លែងដែលអាចប្រើបាន

### ផ្ទៀងផ្ទាត់ឯកសារ​អង់គ្លេស

ពី root ឃ្លាំងទិន្នន័យ សូមដំឡើងតម្រូវការអភិវឌ្ឍន៍ដែលមានរួចហើយ និងរត់:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

កម្មវិធីពិនិត្យតំណរ offline ពិនិត្យផ្លូវ Markdown/HTML អង់គ្លេស ក្បួនប្រធានបទ អង្គភាពតំណរ និងផ្លាស់ទីតំណរ​ទំនេរ។ វាមិនរាប់បញ្ចូល `translations/` និង `translated_images/` ដែលបានបង្កើតរួចទេ រួមទាំងតំណរ ទៅកាន់ថតទាំងនោះ។ វាមិនទាញយកវេបសាយខាងក្រៅ ឬផ្ទៀងផ្ទាត់ការ​ធ្វើតេស្ត Azure ទេ។ ប្រើ `--json <report-path>` ដើម្បីនាំចេញ​ការបរាជ័យ និងបញ្ជី URL ខាងក្រៅសម្រាប់ការត្រួតពិនិត្យបណ្តាញបន្ថែម។ សូមផ្ទៀងផ្ទាត់ពាក្យបញ្ជាដើម និងលក្ខខ័ណ្ឌលំនាំគំរូពេលផ្លាស់ប្តូរពាក្យបញ្ជាបច្ចេកទេស; បំបែកប្រការ​កម្មវិធីដែលបានសាកល្បង និងរចនាសម្ព័ន្ធគំនូរសូម្បីតែទៅ។

### សារ Commit

ប្រើសារ commit ដែលច្បាស់លាស់ និងបរិយាយ:
- `docs: fix typo in installation guide`
- `feat: add new container app example`
- `fix: correct broken link in chapter 2`
