## មុខសំរាប់សិក្សា

វាក្យសព្ទពុម្ភផ្សព្វផ្សាយពន្យល់ពាក្យ មូលដ្ឋាន និងអក្រូញម្យ៉ាង ដែលប្រើក្នុង Azure Developer CLI និងការអភិវឌ្ឍមេघCloud Azure។ ជាការយោងខុសឆ្គងមិនបានសម្រាប់ការយល់ដឹងឯកសារបច្ចេកទេស ជួយដោះស្រាយបញ្ហា និងទំនាក់ទំនងយ៉ាងមានប្រសិទ្ធភាពអំពីគម្រោង azd និងសេវាកម្ម Azure។

## គោលបំណងរៀន

ដោយប្រើវាក្យសព្ទនេះ អ្នកនឹងអាច៖
- យល់ពីពាក្យ និងមូលដ្ឋានរបស់ Azure Developer CLI
- ជំនាញពាក្យប្រើនិងពាក្យបច្ចេកទេសខាងអភិវឌ្ឍមេಘCloud Azure
- យោងពាក្យដាក់សំណង់ Infrastructure as Code និងជំនួយបញ្ហាប្រយោជន៏
- យល់ពីឈ្មោះសេវាកម្ម Azure អក្រូញ និងគោលបំណងរបស់វា
- ចូលដំណើរការពន្យល់ពាក្យដោះស្រាយបញ្ហានិងធ្វើ Debug
- រៀនពីគំនិតបច្ចេកទេសដំណើរការអភិវឌ្ឍន៍ស្ថាបត្យកម្ម Azure

## លទ្ធផលរៀន

ជាមួយការយោងលើវាក្យសព្ទនេះ ជៀសវាងឱ្យអាចធ្វើបាន៖
- ទំនាក់ទំនងយ៉ាងមានប្រសិទ្ធភាពដោយប្រើពាក្យភាសា Azure Developer CLI ត្រឹមត្រូវ
- យល់ឯកសារបច្ចេកទេស និងសារកំហុសបានច្បាស់លាស់
- ទៅមុខនិងច្បាស់លាស់លើសេវាកម្មនិងគំនិតក្នុង Azure
- ដោះស្រាយបញ្ហា ដោយប្រើពាក្យបច្ចេកទេសដំណើរការពាក់ព័ន្ធ
- រួមចំណែកក្នុងការពិភាក្សាក្រុមជាមួយភាសាបច្ចេកទេសត្រឹមត្រូវ
- ពង្រីកចំណេះដឹងអភិវឌ្ឍមេថហ្លCloud Azure ដោយមានរបៀបវិជ្ជាជីវៈ

## អរូបី A

**គំរូ ARM**  
គំរូ Azure Resource Manager។ របៀបកំណត់ Infrastructure as Code ដែលផ្អែកលើ JSON សម្រាប់កំណត់និងដាក់បញ្ចូលធនធាន Azure ដោយប្រកាសលក្ខណៈពិតប្រាកដ។

**សេវា App Service**  
សេវាទីវទ្យា Platform-as-a-Service (PaaS) របស់ Azure សម្រាប់រៀបចំវេបសាយ បណ្តាញ REST API និងបន្ទាត់ក្រោយទូរស័ព្ទដោយមិនចាំបាច់គ្រប់គ្រងហេដ្ឋារចនាសម្ព័ន្ធ។

**Application Insights**  
សេវាពិនិត្យមើលសមត្ថភាពកម្មវិធី (APM) របស់ Azure ដែលផ្តល់ជូននូវមើលឃើញជ្រាលជ្រៅអំពីប្រសិទ្ធភាព ការរកបាន និងការប្រើប្រាស់កម្មវិធី។

**Azure CLI**  
ចំណុចបញ្ជា command-line សម្រាប់គ្រប់គ្រងធនធាន Azure។ វាបំពេញ AZD ប៉ុន្តែមានការចូលប្រើផ្ទាល់ខ្លួន; ការផ្ទៀងផ្ទាត់ភស្តុតាងគោលរបស់ AZD ប្រើ `azd auth login`។

**Azure Developer CLI (azd)**  
ឧបករណ៍ command-line សំរាប់អ្នកអភិវឌ្ឍន៍ ដែលជំរុញដំណើរការការសង់ និងដាក់បញ្ចូលកម្មវិធីទៅ Azure ដោយប្រើគំរូនិង Infrastructure as Code។

**azure.yaml**  
ឯកសារបង្ហាញចម្បងសម្រាប់គម្រោង azd ដែលកំណត់សេវាកម្ម គ្រប់គ្រងហេដ្ឋារចនាសម្ព័ន្ធ និងការដាក់បញ្ចូល។

**Azure Resource Manager (ARM)**  
សេវាកម្ម Azure សម្រាប់ដាក់បញ្ចូល និងគ្រប់គ្រង ដែលផ្តល់ស្រទាប់គ្រប់គ្រងសម្រាប់បង្កើត,អាប់ដេត និងលុបធនធាន។

## អរូបី B

**Bicep**  
ភាសាផ្នែកការបញ្ជាក់បច្ចេកទេសឯកជន (DSL) ដែល Microsoft បង្កើតសម្រាប់ដាក់បញ្ចូលធនធាន Azure។ ផ្តល់វ៉ាយវាយសាទរាងស្រួលជាងឯកសារ ARM ខណៈដែលបញ្ជំទៅកាន់ ARM។

**Build**  
ដំណើរការបង្រួមកូដចាប់ផ្តើម, ដំឡើងពឹងផ្អែក និងរៀបចំកម្មវិធីសម្រាប់ដាក់បញ្ចូល។

**Blue-Green Deployment**  
យុទ្ធសាស្រ្តដាក់បញ្ចូលដែលប្រើបរិយាកាសផលិតពីរ (ប៊្លូ និងក្រៀន) ដើម្បីកាត់បន្ថយពេលខ្វះ និងហានិភ័យ។

## អរូបី C

**Container Apps**  
សេវាកម្មកុងតឺន័រលើ Azure គ្មានម៉ាស៊ីនបម្រើ ដែលអនុញ្ញាតឱ្យដំណើរការកម្មវិធីកុងតឺន័រដោយគ្មានការគ្រប់គ្រងហេដ្ឋារចនាសម្ព័ន្ធស្មុគស្មាញ។

**CI/CD**  
ការរួមបញ្ចូលបន្ត និងដាក់បញ្ចូលបន្ត។ ចំណេះដឹងស្វ័យប្រវត្តិនៃការបញ្ចូលកូដឱ្យបានរួម និងដាក់កម្មវិធី។

**Cosmos DB**  
សេវាផ្ទុកទិន្នន័យចម្រុះរបស់ Azure ដែលបានចែកចាយជាសកល ដែលផ្តល់កិច្ចព្រមបត្តិ SLA ពេញលេញសម្រាប់ទិន្នន័យចរន្ត, ពេលយឺត, ការរកបាន និងភាពត្រឹមត្រូវ។

**Configuration**  
ការកំណត់ និងប៉ារ៉ាម៉ែត្រ ដែលគ្រប់គ្រងអាកប្បកិរិយាកម្មកម្មវិធី និងជម្រើសដាក់បញ្ចូល។

## អរូបី D

**Deployment**  
ដំណើរការដំឡើង និងកំណត់កម្មវិធី និងពឹងផ្អែករបស់វានៅលើហេដ្ឋារចនាសម្ព័ន្ធគោលដៅ។

**Docker**  
វេទិកាសម្រាប់អភិវឌ្ឍ ចែកចាយ និងដំណើរការកម្មវិធីដោយប្រើបច្ចេកវិទ្យាកុងតឺន័រ។

**Dockerfile**  
ឯកសារអត្ថបទដែលមានការណែនាំសម្រាប់កសាងរូបភាព Docker container។

## អរូបី E

**Environment**  
គោលដៅការដាក់បញ្ចូលដែលតំណាងឱ្យពិតប្រាកដសម្រាប់កម្មវិធីរបស់អ្នក (ឧ. ការអភិវឌ្ឍ, ការតេស្ត, ផលិតកម្ម)។

**Environment Variables**  
តម្លៃកំណត់ដែលរក្សាទុកជាគូគន្លង-តម្លៃ ដែលកម្មវិធីអាចចូលដំណើរការទទួលបាននៅពេលរត់។

**Endpoint**  
URL ឬអាសយដ្ឋានបណ្តាញ ដែលកម្មវិធី ឬសេវាកម្មអាចចូលទៅប្រើបាន។

## អរូបី F

**Function App**  
សេវាកម្មគណនា serverless របស់ Azure ដែលអនុញ្ញាតឱ្យដំណើរករកូដផ្អែកលើព្រឹត្តិការណ៍ដោយគ្មានការគ្រប់គ្រងហេដ្ឋារចនាសម្ព័ន្ធ។

## អរូបី G

**GitHub Actions**  
វេទិកា CI/CD ដែលរួមចំណែកជាមួយផ្ទាំង GitHub សម្រាប់ស្វ័យប្រវត្តិការប្រតិបត្តិ workflow។

**Git**  
ប្រព័ន្ធគ្រប់គ្រងកំណែចែកចាយដែលប្រើសម្រាប់តាមដានការផ្លាស់ប្តូរកូដប្រភព។

## អរូបី H

**Hooks**  
ស្គ្រីប វិញ្ញាបនប័ត្រ ឬការបញ្ជាដែលបើកនៅពេលវេលាពិសេសក្នុងជីវចក្រារដាក់បញ្ចូល (preprovision, postprovision, predeploy, postdeploy)។

**Host**  
ប្រភេទសេវាកម្ម Azure ដែលកម្មវិធីនឹងត្រូវបានដាក់បញ្ចូល (ឧ. appservice, containerapp, function)។

## អរូបី I

**Infrastructure as Code (IaC)**  
ការអនុវត្តកំណត់និងគ្រប់គ្រងហេដ្ឋារចនាសម្ព័ន្ធតាមរយៈកូដ ជំនួសដំណើរការដោយដៃ។

**Init**  
ដំណើរការចាប់ផ្តើមគម្រោង azd ថ្មី ជារឿយៗពីគំរូមួយ។

## អរូបី J

**JSON**  
JavaScript Object Notation។ ទ្រង់ទ្រាយបម្លែងទិន្នន័យដែលកើតពេញនិយមសម្រាប់ឯកសារកំណត់ និងការឆ្លើយតប API។

**JWT**  
JSON Web Token។ ស្តង់ដារសម្រាប់ផ្ញើព័ត៌មានយ៉ាងសុវត្ថិភាពរវាងភាគីជាគម្រប JSON។

## អរូបី K

**Key Vault**  
សេវាកម្ម Azure សម្រាប់រក្សាទុក និងគ្រប់គ្រងអាថ៌កំបាំង កូនសោ និងវិញ្ញាបនប័ត្រ។

**Kusto Query Language (KQL)**  
ភាសាស៊ើបអង្កេតសម្រាប់វិភាគទិន្នន័យនៅក្នុង Azure Monitor, Application Insights និងសេវាកម្ម Azure ផ្សេងទៀត។

## អរូបី L

**Load Balancer**  
សេវាកម្មដែលចែកចាយចរាចរណ៍បណ្តាញវាយតម្រាបព្យាបាលក្នុងម៉ាស៊ីនធ្វើការ ឬវាយតម្រាបព្យាបាលផ្សេងៗ។

**Log Analytics**

## ពាក្យពិសេសជាក់លាក់តាមបរិបទ

### ពាក្យអភិវឌ្ឍ
- **Hot Reload**: ការធ្វើបច្ចុប្បន្នភាពកម្មវិធីដោយស្វ័យប្រវត្តិដំណើរការនៅពេលអភិវឌ្ឍដោយមិនបាច់បើកឡើងវិញ
- **Build Pipeline**: ដំណើរការស្វ័យប្រវត្តិសម្រាប់សំណុំបង្រួម និងតេស្តកូដ
- **Deployment Slot**: បរិយាកាស staging នៅក្នុងសេវា App Service
- **Environment Parity**: រក្សាបរិយាកាសអភិវឌ្ឍ, staging និងផលិតកម្មឲ្យស្រដៀងគ្នា

### ពាក្យសុវត្ថិភាព
- **Managed Identity**: លក្ខណៈពិសេស Azure ផ្តល់ការគ្រប់គ្រងអត្តសញ្ញាណដោយស្វ័យប្រវត្តិ
- **Key Vault**: កន្លែងរឹងមាំសម្រាប់រក្សាទុកអាថ៌កំបាំង កូនសោ និងវិញ្ញាបនប័ត្រ
- **RBAC**: ការគ្រប់គ្រងចូលដោយផ្អែកលើតួនាទីសម្រាប់ធនធាន Azure
- **Network Security Group**: firewall វីរុសសម្រាប់គ្រប់គ្រងចរាចរណ៍បណ្តាញ

### ពាក្យត្រួតពិនិត្យ
- **Telemetry**: ការប្រមូលវិចារណកថា និងទិន្នន័យដោយស្វ័យប្រវត្តិ
- **Application Performance Monitoring (APM)**: ការត្រួតពិនិត្យសមត្ថភាពកម្មវិធី
- **Log Analytics**: សេវាកម្មប្រមូល និងវិភាគទិន្នន័យកំណត់ហេតុ
- **Alert Rules**: ការជូនដំណឹងដោយស្វ័យប្រវត្តិមូលដ្ឋានលើមេត្រិក ឬលក្ខខណ្ឌ

### ពាក្យដាក់បញ្ចូល
- **Blue-Green Deployment**: យុទ្ធសាស្រ្តដាក់បញ្ចូលដោយគ្មានពេលខ្វះ
- **Canary Deployment**: មន្សំដាក់បញ្ចូលទៅអ្នកប្រើ កម្រិតតិច
- **Rolling Update**: ជំនួសយ៉ាងលំលោកលើបន្ទាត់នៃកម្មវិធី
- **Rollback**: ត្រឡប់ទៅកំណែមុននៃកម្មវិធី

---

**Usage Tip**: ប្រើ `Ctrl+F` ដើម្បីស្វែងរកពាក្យជាក់លាក់នៅក្នុងវាក្យសព្ទនេះយ៉ាងលឿន។ ពាក្យត្រូវបានយោងឱ្យគ្នា នៅពេលផ្គាប់សម្រួល។
