# ជាពាណិជ្ជកម្មទី 2៖ ការអភិវឌ្ឍ AI ជាគោលបំណងជាមុន

**📚 វគ្គសិក្សា**៖ [AZD សម្រាប់អ្នកចាប់ផ្តើម](../../README.md) | **⏱️ រយៈពេល**៖ 4-5 ម៉ោង រួមមានសិក្ខាសាលា | **⭐ ភាពស្មុគស្មាញ**៖ មធ្យម

## ទិដ្ឋភាពទូទៅ

ជាពាណិជ្ជកម្មនេះផ្តោតលើការដាក់ប្រើកម្មវិធីដែលបង្កើតដោយ AI ដោយប្រើ Azure Developer CLI និងសេវាកម្ម Microsoft Foundry។ ចាប់ពីកម្មវិធី AI chat សាមញ្ញ រហូតដល់ភ្នាក់ងារឆ្លាតវៃជាមួយឧបករណ៍ផ្សេងៗ។

> **ការត្រួតពិនិត្យចេញផ្សាយ (2026-11-04)៖** គន្លឹះ AI CLI ត្រូវបានពិនិត្យស្របទៅនឹងឯកសារ `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23`, និង `azure.ai.evaluations` `1.0.0-beta.2` ដែលបានផ្សព្វផ្សាយ។ ប្រើ `azd >= 1.37.0` សម្រាប់ដំណើរការរួម។ ការវាស់វែងឥឡូវនេះប្រើ ឈ្មោះដែន `azd ai eval` ដាច់ដោយឡែក; មើល [ការផ្លាស់ប្តូរសមាជិកនិងការណែនាំការផ្លាស់ប្តូរ](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes) ។ នេះមិនមែនជាការផ្ទៀងផ្ទាត់ដាក់ប្រាក់ដោយផ្ទាល់ឡើយ។

## គោលបំណងរៀន

ដោយបញ្ចប់ជាពាណិជ្ជកម្មនេះ អ្នកនឹង៖
- ដាក់ប្រើកម្មវិធី AI ប្រើម៉ូដែល AZD ដែលបានរៀបចំរួចហើយ
- យល់ដឹងពីការសម្ព័ន្ធ Microsoft Foundry ជាមួយ AZD
- កំណត់រចនាសម្ព័ន្ធ និងប្តូរអ្នកប្រតិបត្តិ AI ជាមួយឧបករណ៍ផ្សេងៗ
- ដាក់ប្រើកម្មវិធី RAG (Retrieval-Augmented Generation)

## 🚀 ចាប់ផ្តើមយ៉ាងរហ័ស

ជ្រើសរើសមួយជម្រើសក្នុងថតទទេថ្មីមួយ។ `.` ដែលបន្ថែមនៅចុងបញ្ចូលថតបច្ចុប្បន្ន; ប្រសិនបើមិនដូច្នោះ AZD អាចបង្កើតថតរងដោយមិនបម្លែងថតដែលប្រើក្នុង shell របស់អ្នក។

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```
