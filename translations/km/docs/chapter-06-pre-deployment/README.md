# ជំពូកទី ៦៖ ការយុទ្ធសាស្ត្រនិងការផ្ទៀងផ្ទាត់មុនការចាប់ផ្តើមដាក់ឲ្យប្រើ

**📚 ឯកសារ**៖ [AZD សម្រាប់អ្នកដំណើរកំសាន្ត](../../README.md) | **⏱️ រយៈពេល**៖ ២-៤ ម៉ោងសម្រាប់អាន; ពេលវេលាបន្ថែមសម្រាប់កម្មវិធីហ្គេមដែលបានផ្លាស់ប្តូរ | **⭐ សំខាន់ភាព**៖ កម្រិតមធ្យម–កម្រិតខ្ពស់

## សង្ខេប

ជំពូកនេះគ្របដណ្តប់ពីជំហានសំខាន់ៗនៃការរៀបចំនិងការផ្ទៀងផ្ទាត់មុនការដាក់កម្មវិធីរបស់អ្នកឲ្យប្រើ។ រីករាយរៀនពីរបៀបទល់នឹងកំហុសថ្លៃថ្នូរជាមួយការរៀបចំសមត្ថភាពត្រឹមត្រូវ, ជម្រើស SKU និងការត្រួតពិនិត្យមុនពេលកម្រិត។

> មាតិកាមុខងារបញ្ជាដែលបានពិនិត្យជាមួយសេចក្តីយោង `azd 1.37.2` ដែលបានបញ្ចេញ។ ការដាក់នៅលើពពកមិនត្រូវបានអនុវត្ត។ មេរៀនវែងៗមានផ្នែកបង្ហាញមិនមែនជាកម្មវិធីដាក់ប្រើក្នុងស្រុកពេញលេញ។

## គោលបំណងរៀន

ដោយបញ្ចប់ជំពូកនេះ អ្នកនឹងអាច៖
- ប្រតិបត្តិការត្រួតពិនិត្យមុនការដាក់ជាមួយ
- រៀបចំសមត្ថភាពនិងការវាយតម្លៃតម្រូវការពហុធនធាន
- ជ្រើស SKU ឲ្យសមរម្យសម្រាប់ការសន្សំថ្លៃ
- កំណត់ស្ថាបត្យកម្ម Application Insights សម្រាប់ការត្រួតពិនិត្យ
- យល់ដឹងពីលំនាំសមហេតុផលបុគ្គលរាប់ពហុកាលនិងតម្រូវការតំរូវការដាក់ឲ្យប្រើរបស់ពួកវា

## 🚀 ចាប់ផ្តើមយ៉ាងឆាប់រហ័ស

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ បញ្ជីពិនិត្យមុនការដាក់ប្រើ

### មុន `azd provision`

- [ ] ផ្ទៀងផ្ទាត់គូតា សម្រាប់តំបន់
- [ ] ជ្រើស SKU យ៉ាងសមរម្យ
- [ ] ពិនិត្យការវាយតម្លៃថ្លៃ
- [ ] ការផ្ទៀងផ្ទាត់ឈ្មោះឲ្យឆ្លងកាត់
- [ ] ការកំណត់សុវត្ថិភាព/RBAC

### មុន `azd deploy`

- [ ] កំណត់អថេរបរិយាកាស
- [ ] រក្សា Secret ក្នុង Key Vault
- [ ] ផ្ទៀងផ្ទាត់ខ្សែភ្ជាប់
- [ ] កំណត់ចែងអង្គភាពសុខភាព
