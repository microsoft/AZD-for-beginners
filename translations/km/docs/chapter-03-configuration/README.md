## ទិដ្ឋភាពទូទៅ

ជំពូកនេះគ្របដណ្តប់ពីការកំណត់រចនាសម្ព័ន្ធបរិស្ថាន ម៉ូដែលផ្ទៀងផ្ទាត់អត្តសញ្ញាណ និងអនុវត្តន៍វិធីសាស្ត្រសុវត្ថិភាពល្អបំផុតសម្រាប់ការចេញផ្សាយ Azure Developer CLI។

> គោលដៅការត្រួតពិនិត្យពាក្យបញ្ជារ និងការកំណត់រចនាសម្ព័ន្ធ: `azd 1.37.2` (វិច្ឆិកា 2026)។ មិនបានបើកប្រើប្រាស់ការផ្គត់ផ្គង់ Azure ជាក់ស្តែងនៅពេលត្រួតពិនិត្យឡើយ។

## គោលបំណងសិក្សា

ដោយបញ្ចប់ជំពូកនេះ អ្នកនឹង:
- ឆ្លើយតបបានលំដាប់ភាពកំណត់រចនាសម្ព័ន្ធ AZD
- គ្រប់គ្រងបរិស្ថានច្រើន (អភិវឌ្ឍន៍, ស្តើងនិងផលិតកម្ម)
- អនុវត្តផ្ទៀងផ្ទាត់អត្តសញ្ញាណសុវត្ថិជាមួយអត្តសញ្ញាណគ្រប់គ្រង
- កំណត់រចនាសម្ព័ន្ធពិសេសសម្រាប់បរិស្ថាននីមួយៗ

## 🚀 ចាប់ផ្តើមយ៉ាងរហ័ស

ដំណើរការ​ពី​ឫតនៃកម្មវិធី **azd ដែលបានចាប់ផ្តើមរួចហើយ** មិនមែនពីឃ្លាំងវគ្គសិក្សា។ ប្រើឈ្មោះបរិស្ថានដែលមិនបានប្រើបើមានរួចហើយ។

```bash
# Create multiple environments
azd env new dev
azd env new staging
azd env new prod

# Switch environments
azd env select prod

# Set environment variables
azd env set AZURE_LOCATION eastus
azd env set SKU_NAME P1v3

# View configuration
azd env get-values
```

`SKU_NAME` គឺជាឧទាហរណ៍៖ វាសំខាន់តែម្នាក់នេះសម្រាប់ហេដ្ឋារចនាសម្ព័ន្ធ បើសិនជាគំរូរបស់អ្នកប្រើវាយ៉ាងច្បាស់។ តម្លៃ `azd env set` ធម្មតាត្រូវបានរក្សាទុកក្នុងតំបន់មូលដ្ឋានជាអត្ថបទទេ; វាមិនមែនជាឃុំនាក់សុវត្ថិភាពទេ។

## 🔧 លំដាប់នៃការកំណត់រចនាសម្ព័ន្ធ

រក្សាទុកចំនួនបីផ្ទៃការកំណត់រចនាសម្ព័ន្ធតែមួយ៖ ចំណូលចិត្តជាសកល (`azd config`), រចនាសម្ព័ន្ធគម្រោង (`azure.yaml`), និងតម្លៃជាបរិស្ថាន (`azd env`)។ ពាណិជ្ជកម្មអក្សរតែមួយគត់ដែលគាំទ្រការកំណត់ ដោយគ្មានការ overlay ពេញលេញនៃអថេរបរិស្ថានគ្មានលក្ខណៈលើ `azure.yaml` ឬ Bicep។

## 🔐 វិធីសាស្ត្រសុវត្ថិភាពល្អបំផុត

```bash
# Runtime managed identity must be enabled in infrastructure and granted RBAC.
# To authenticate azd itself on an Azure host with an assigned identity:
# azd auth login --managed-identity

# Check AZD authentication status
azd auth login --check-status

# Optional: verify Azure CLI context if you plan to run az commands
az account show

# Re-authenticate if needed
azd auth login

# Optional: refresh Azure CLI authentication for az commands
az login
```
