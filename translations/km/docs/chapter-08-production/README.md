# ភាគទី ៨៖ លំនាំ​ការផលិត និងសហគ្រាស

**📚 ចំណេះដឹង**: [AZD សម្រាប់អ្នកដែលចាប់ផ្តើម](../../README.md) | **⏱️ រយៈពេល**: 2-3 ម៉ោង | **⭐ កម្រិតស្មុគស្មាញ**: ជំរើស​ខ្ពស់

---

## ទិដ្ឋភាពទូទៅ

ភាគនេះគ្របដណ្តប់លំនាំការដាក់បញ្ចូលដែលអាចប្រើប្រាស់ក្នុងសហគ្រាស, ការបញ្ចុះសុវត្ថិភាព, ការត្រួតពិនិត្យ, និងការបង្កើនប្រសិទ្ធភាពថ្លៃសម្រាប់ការងារ AI ក្នុងផលិតកម្ម។

នេះគឺជា​ឯកសារ​យោង​បច្ចេកទេស មិនមែនជា​វិមជ្ឈកាល​ផលិតកម្ម​ដែល​អាច​ដាក់បញ្ចូលបានទាំងមូលទេ។ គំរូ​មិនរាប់បញ្ចូល​លម្អិត​សម្រាប់​ការ​បញ្ចូល ដែលត្រូវបានផ្តល់ និងត្រូវបានសាកល្បងនៅក្នុងកម្មវិធីរបស់អ្នកផ្ទាល់ទេ។ ការអានបញ្ជីត្រួតពិនិត្យមិនបានធានាការត្រៀមខ្លួនសម្រាប់ផលិតកម្មនោះទេ។

> **ការត្រួតពិនិត្យរចនាសម្ព័ន្ធ (2026-11-04):** យោងដល់ការណែនាំ AI CLI ត្រូវបានពិនិត្យទំព័រជាមួយ `azd 1.37.2`, agents `1.0.0-beta.23`, និងឯកសារ/ប្រភពបន្ទាន់ `1.0.0-beta.2`។ សូមមើល [ការផ្លាស់ប្តូរនិងកំណែសម្រួល](production-ai-practices.md#recent-release-changes-and-fixes) សម្រាប់តម្រូវការសំរាប់ការប្រតិបត្តិ និងព័ត៌មានផ្ទេរកម្មវិធី; នេះមិនមែនជាការត្រួតពិនិត្យការដាក់បញ្ចូលជាលាយឡំទេ។

## គោលបំណងការរៀន

ដោយបញ្ចប់ភាគនេះ អ្នកនឹងអាច៖
- ដាក់បញ្ចូលកម្មវិធីដែលរឹងមាំនៅក្នុងតំបន់ច្រើន
- អនុវត្តលំនាំសុវត្ថិភាពសហគ្រាស
- កំណត់ការត្រួតពិនិត្យទាំងមូល
- បង្កើនប្រសិទ្ធភាពថ្លៃវិនិយោគនៅមាត្រដ្ឋានធំ
- បង្កើតបំពង់ CI/CD ជាមួយ AZD
