# ជំពូក ៨៖ ឧស្សាហកម្ម & លំនាំសហគ្រាស

**📚 វគ្គសិក្សា**: [AZD សម្រាប់អ្នកចាប់ផ្តើម](../../README.md) | **⏱️ រយៈពេល**: ២-៣ ម៉ោង | **⭐ ស្មុគស្មាញ**: កម្រិតខ្ពស់

---

## សង្ខេប

ជំពូកនេះគ្របដណ្តប់លំនាំការដាក់ឧស្សាហកម្មត្រៀមខ្លួនបាន សុវត្ថិភាពកាន់តែរឹងមាំ ការត្រួតពិនិត្យ និងការបង្កើនប្រសិទ្ធភាពថ្លៃដើមសម្រាប់បេសកកម្ម AI ផលិតកម្ម។

នេះគឺជាឯកសារយោងស្ថាបត្យកម្ម មិនមែនគំរូដាក់ឲ្យប្រើបានពេញលេញសម្រាប់ផលិតកម្មទេ។ឧទាហរណ៍មិនរាប់បញ្ចូលព័ត៌មានលម្អិតរួមបញ្ចូលដែលត្រូវផ្គូផ្គង និងសាកល្បងនៅក្នុងកម្មវិធីរបស់អ្នកផ្ទាល់ទេ; ការអានបញ្ជីពិនិត្យមិនមានន័យថាសម្រាប់ស្ថិតិនូវភាពរួចរាល់សម្រាប់ផលិតកម្មទេ។

> **អាប់ដេត Foundry GA (2026-11-09):** ប្រើ `azd >= 1.37.0` និងបណ្ដុំ `microsoft.foundry` 1.0 ដែលមានស្រាប់សម្រាប់ការប្រតិបត្តិ Foundry; ការវាយតម្លៃត្រូវបានដំឡើងបញ្ចូនផ្សេងទៀត។ មើល [វិសាលភាពការចេញផ្សាយ និងការផ្លាស់ប្តូរ](production-ai-practices.md#recent-release-changes-and-fixes) និង [ឧទាហរណ៍បណ្ដាញផាកសង្គ្រោះដែលមានការផ្ទៀងផ្ទាត់](production-ai-practices.md#cicd-pipeline-configuration)។ នេះគឺជាការពិនិត្យឯកសារ មិនមែនការផ្ទៀងផ្ទាត់ដាក់ឧស្សាហកម្មជាសកម្ម ឬស្ថានភាព GA សម្រាប់មុខងារពិសេសពាក់ព័ន្ធទេ។

## គោលបំណងសិក្សា

ដោយបញ្ចប់ជំពូកនេះ អ្នកនឹងអាចៈ
- ដាក់បញ្ចូលកម្មវិធីឌីជីថលច្រើនតំបន់សម្រាប់ភាពរឹងមាំ
- អនុវត្តលំនាំសុវត្ថិភាពសហគ្រាស
- កំណត់ការត្រួតពិនិត្យប៉ារ៉ាម៉ែត្រដោយពេញលេញ
- បង្កើនប្រសិទ្ធភាពថ្លៃកាលពីផែនការ
- រៀបចំបណ្តាញ CI/CD ជាមួយ AZD
