# ដីតាក់ទី 5៖ ដំណោះស្រាយ AI ជាច្រើនភាគី

**📚 មេរៀន**: [AZD សម្រាប់អ្នកចាប់ផ្តើម](../../README.md) | **⏱️ រយៈពេល**: 2-3 ម៉ោង | **⭐ ការលំបាក**: អក្ថរិយៈ

## ទិដ្ឋភាពទូទៅ

ដីតាក់នេះគ្របដណ្តប់លើលំនាំស្ថាបត្យកម្ម AI ជាច្រើនភាគីជាន់ខ្ពស់ ការប្រតិបត្តិការ​ភាគី និងការដាក់ប្រេត AI ស្រេចសម្រាប់សេណារីយ៉ូចម្រុះ។

> មេរៀនបញ្ជាដែលបានពិនិត្យលើការចេញផ្សាយឯកសារ `azd 1.37.2`។ ការដាក់ប្រេតក្នុងពពកមិនត្រូវបានអនុវត្តន៍។

## គោលបំណងសិក្សា

ដោយបញ្ចប់ដីតាក់នេះ អ្នកនឹង:
- យល់ដឹងពីលំនាំស្ថាបត្យកម្មលំនាំ AI ជាច្រើនភាគី
- ដាក់ប្រេតប្រព័ន្ធភាគី AI ដែលសម្របសម្រួលគ្នា
- អនុវត្តការទំនាក់ទំនងពីភាគីទៅភាគី
- បង្កើតដំណោះស្រាយ AI ជាច្រើនភាគីស្រេចសម្រាប់ផលិតកម្ម

## 🚀 ចាប់ផ្តើមយ៉ាងលឿន

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **ផ្លូវមួយណា?** ប្រើ `azd init --template` ដើម្បីចាប់ផ្តើមពីគំរូដែលមានស្រាប់។ ប្រើ `azd ai agent init` ក្នុងរបៀបអន្តរកម្ម ឬ `azd ai agent init --template <path-to-azure.yaml>` ដើម្បីយកគម្រោងភាគីបច្ចុប្បន្ន។ មើលឯកសារ [AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) សម្រាប់តម្រូវការចំរូង និងការផ្លាស់ប្តូរកំណែ។

បើកដំណើរការជម្រើសទាំងនេះក្នុងថតដាច់ផ្សេងៗគ្នាដោយទទេ។ វិធីសាស្រ្ត GA Foundry ត្រូវការប្រើ `azd >= 1.37.0`; ដំណើរការអន្តរកម្មរបស់វាមិនបង្កើតបណ្តាញដំណើរការបុគ្គលិកក្នុងមេរៀនសម្របសម្រួលទេ។ សម្រាប់ការទូទាត់ក្នុងតំបន់ ការដាក់ប្រេតកូដ និងការសម្អាតគម្រោងថ្មីសំរាប់គម្រោងចាស់ សូមអនុវត្តណែនាំ [ដំណើរការអ្នកផ្ដល់សេវាកម្ម](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga)។
