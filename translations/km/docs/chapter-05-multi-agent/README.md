# បទទី 5៖ ដំណោះស្រាយ AI មនុស្សច្រើនភាគី

**📚 មេរៀន**: [AZD សម្រាប់ដំបូង](../../README.md) | **⏱️ រយៈពេល**: 2-3 ម៉ោង | **⭐ កម្រិតស្មុគស្មាញ**: ជំនាញខ្ពស់

## ទិដ្ឋភាពទូទៅ

បទនេះគ្របដណ្ដប់ពីរចនាសម្ព័ន្ធមនុស្សច្រើនភាគីដែលជំនាញខ្ពស់, ការត្រួតពិនិត្យភ្នាក់ងារ, និងការដាក់បញ្ចូល AI ស្រេចលក្ខណៈផលិតកម្មសម្រាប់ស្ថានភាពសំណុំបែបបទស្មុគស្មាញ។

> ការណែនាំបញ្ជាដែលបានពិនិត្យវិញប្រឆាំងនឹងគំរូយោង `azd 1.37.2` ដែលបានបញ្ចេញ។ ការដាក់បញ្ចូលពពកមិនបានអនុវត្តន៍ឡើយ។

## គោលបំណងការសិក្សា

ក្រោយពេលបញ្ចប់បទនេះ អ្នកនឹង:
- យល់ដឹងពីរចនាសម្ព័ន្ធមនុស្សច្រើនភាគី
- ដាក់បញ្ចូលប្រព័ន្ធភ្នាក់ងារ AI ដែលទាក់ទាញគ្នា
- គ្រប់គ្រងការទំនាក់ទំនងរវាងភ្នាក់ងារ
- បង្កើតដំណោះស្រាយមនុស្សច្រើនភាគីស្រេចលក្ខណៈផលិតកម្ម

## 🚀 ការចាប់ផ្តើមយ៉ាងឆាប់រហ័ស

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **វិធីសាស្រ្តណា?** ប្រើ `azd init --template` ដើម្បីចាប់ផ្តើមពីគំរូដំណើរការមួយ។ ប្រើ `azd ai agent init` ដោយអន្តរកម្ម ឬ `azd ai agent init --template <path-to-azure.yaml>` ដើម្បីទទួលយកគម្រោងភ្នាក់ងារបច្ចុប្បន្ន។ មើល [AZD AI CLI reference](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) សម្រាប់ទាមទារកំណែ និងការផ្លាស់ប្តូរវាយតម្លៃ។

សូមបញ្ជាលើជម្រើសទាំងនេះក្នុងថតទទេៗបំបែកគ្នា។ ដំណើរការព្រីសកម្មបន្ថែម `1.0.0-beta.23` ត្រូវការព្រីសកម្ម `azd >= 1.37.0`; ដំណើរអន្តរកម្មរបស់វាមិនបង្កើតបណ្តុំបន្ទាត់បេសកកម្ម Service Bus ផ្ទាល់ខ្លួននៅក្នុងមេរៀនការត្រួតពិនិត្យឡើយ។
