# វគ្គ ៧៖ ការ​ដោះស្រាយ​បញ្ហា និង​ដោះស្រាយ​កូដ

**📚 វគ្គសិក្សា**៖ [AZD សម្រាប់អ្នកចាប់ផ្តើម](../../README.md) | **⏱️ រយៈពេល**៖ ១-១.៥ម៉ោង | **⭐ ភាពស្មុគស្មាញ**៖ ស្ទាត់ជំនាញមធ្យម

## សង្ខេប

វគ្គសិក្សានេះជួយអ្នកវាយតម្លៃ និងដោះស្រាយបញ្ហាទូទៅពេលធ្វើការជាមួយ Azure Developer CLI។ ចាប់ពីការបរាជ័យក្នុងការដាក់ឲ្យដំណើរការ រហូតដល់បញ្ហាពិសេសដែលទាក់ទងនឹង AI។

> ការណែនាំពាក្យបញ្ជាដែលបានពិនិត្យឡើងវិញផ្អែកលើយោង `azd 1.37.2` ដែលបានចេញផ្សាយ។ មិនបានអនុវត្តការដាក់ឲ្យដំណើរការលើពពកនោះទេ។ សូមជំនួសឈ្មោះធនធាន និង ID ឧទាហរណ៍ មុនប្រើពាក្យបញ្ជា។

## គោលបំណងសិក្សា

ដោយបញ្ចប់វគ្គនេះ អ្នកនឹងអាច៖
- វិភាគបញ្ហាបរាជ័យ AZD ដាក់ឲ្យដំណើរការដោយទូទៅ
- ដោះស្រាយបញ្ហា xác thực និងការអនុញ្ញាត
- ដោះស្រាយបញ្ហាការភ្ជាប់សេវាកម្ម AI
- ប្រើ Azure Portal និង CLI សម្រាប់ដោះស្រាយបញ្ហា

## 🚨 ដំណោះស្រាយ​ឆាប់រហ័ស

### បញ្ហា xác thực
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### បរាជ័យក្នុងការផ្ដល់សេវា
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### ដំណើរការរំខានធនធាន
សូមពិនិត្យធនធានដែលមាន និងកំហុសក្នុងការដាក់ឲ្យដំណើរការដំបូង។ មិនត្រូវលុបបរិយាកាសចែករំលែក ឬបរិយាកាសផលិតកម្ម ដើម្បីដោះស្រាយបញ្ហាឈ្មោះ។ សម្រាប់ **បរិយាកាស​ថ្មីដែលអាចលុបបាន** សូមប្រើឈ្មោះដាច់ដោយឡែក៖

```bash
azd env new different-name
azd up
```

### លើសគោលដៅ
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

ការប្ដូរ `AZURE_LOCATION` មិនបញ្ជូនធនធានស្រាប់ទៅកន្លែងថ្មីនោះទេ ហើយអាចបង្កឲ្យមានបញ្ហាតំបន់ពេលដាក់ឲ្យដំណើរការឡើងវិញ។

## 📋 ឯកសារយោងកូដកំហុស

| កំហុស | មូលហេតុ | ដំណោះស្រាយ |
|-------|-------|----------|
| `AuthenticationError` | មិនបានចូលគណនី | `azd auth login` |
| `ResourceNotFound` | បាត់ធនធាន | ពិនិត្យឈ្មោះធនធាន |
| `QuotaExceeded` | កំណត់កម្រិតការជាវ | ស្នើសុំបន្ថែមបរិមាណ |
| `InvalidTemplate` | កំហុសវេយ្យាករណ៍ Bicep | `az bicep build` |
| `Conflict` | មានធនធាន​រួច | ប្រើឈ្មោះថ្មី ឬលុប |
| `Forbidden` | អត្រាជួយមិនគ្រប់គ្រាន់ | ពិនិត្យតួនាទី RBAC |

## 🔄 ការចាប់ផ្តើមឡើងវិញ និង ការស្ដារឡើងវិញ

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

ការចាប់ផ្តើមឡើងវិញរឹងមាំនេះលុបទិន្នន័យ និងអាចផ្លាស់ប្តូរទីតាំងភ្ជាប់។ សូមបម្រុងទុកជាមុន និងពិនិត្យសំណួរលុបបញ្ជាដោយអន្តរាគមន៍។ `--force --purge` សមស្របសម្រាប់បរិយាកាសដែលអាចលុបបាន ប៉ុន្តែមានបំណងលុបមិនអាចត្រឡប់វិញ។
