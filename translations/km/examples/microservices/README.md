# ឧទាហរណ៍មីក្រូសេវា

ការអនុវត្តដែលអាចរត់បាន និងការណែនាំរបស់វា​មាន​នៅក្នុង
**[container-app/microservices](../container-app/microservices/README.md)**។

លិខិតណែនាំនេះគឺជាការនាំផ្លូវតែប៉ុណ្ណោះ។ វាមិនមាន `azure.yaml`, `infra/`, ឬ `src/` ទេ។
សូមកុំរត់ `azd up` នៅទីនេះ។

ចាប់ពីឫសផ្ទុកឃ្លាំង:

```bash
cd examples/container-app/microservices
```

បន្ទាប់មកអនុវត្តតាម README ដែលខ្សែរភ្ជាប់សម្រាប់លក្ខខណ្ឌមុន, ការដាក់ពង្រីក, ការបញ្ជាក់, ការអភិវឌ្ឍន៍ក្នុងស្រុក,
ការអនុវត្តជាក់ស្តែង, ថ្លៃកម្រៃ, និងការសម្អាត។

គំរូនេះមានប្រភេទ Node.js API Gateway និងសេវាកម្មផលិតផល Python សម្រាប់អានតែម្ដង។
សេវាកម្មបញ្ជាទិញ អ្នកប្រើប្រាស់ សេចក្តីជូនដំណឹង មូលដ្ឋានទិន្នន័យ និងសេវាកម្មសារជាជម្រើសបន្ថែម,
មិនមែនជាការអនុវត្តដែលមាននៅក្នុងឃ្លាំងនេះទេ។

- [បន្ទាប់៖ Database app](../../../../examples/database-app)
- [ការអភិវឌ្ឍន៍ AI](../../docs/chapter-02-ai-development/README.md)
