  កម្រិតកំណត់សម្រាប់ការជាវរបស់អ្នក។ ការកំណត់លំនាំដើមគឺជាគំរូ មិនមែនការធានា។
  ពេញចិត្ត [ភាពមានស្រាប់របស់គំរូ](https://learn.microsoft.com/azure/ai-services/openai/concepts/models)។

### របៀបដាក់ឲ្យដំណើរការ

| របៀប | ឯកតាសមត្ថភាព Chat / mini / embedding / grader | រ៉េផ្លីកាតាប Router | រ៉េផ្លីកាតាប Frontend | ជាន់ស្វែងរក | ស្តុក |

| តិចបំផុត | 10 / 10 / 20 / 5 | 0–3 | 1–2 | បណ្ដា, 1 រ៉េផ្លីកា | Standard_LRS |
| កម្រិតស្ដង់ដារ | 20 / 15 / 30 / 15 | 1–3 | 1–2 | ស្ដង់ដារ, 1 រ៉េផ្លីកា | Standard_ZRS |

ប្រ៊ីមៀមមិនបានបើកអនុញ្ញាត Container Apps ដែលមានការការពារដោយតំបន់: វាតិចតួច
តម្រូវការរចនាបណ្តាញបន្ថែម។ ស្វែងរកមូលដ្ឋានគឺគាំទ្រស្វែងរកវ៉ិចទ័រ ដោយមានកំណត់សេវាកម្ម; វាមិនខុសគ្នា

## 🚀 ការចេញផ្សាយប្រញាប់

ពិនិត្យរឿង `azuredeploy.json` និង `azuredeploy.parameters.json` មុន។ ពាក្យបញ្ជា
ខាងក្រោម **បង្កើតធនធាន Azure ដែលអាចគិតថ្លៃ**; វានៅមិនមែនជា​ការ​ពិនិត្យអនឡាញឡើយ។

ពីចម្លងចម្បងនៅក្នុងប្រព័ន្ធឯកសារ:

```bash
cd examples/retail-multiagent-arm-template
bash deploy.sh --help
bash deploy.sh -g retail-learning-rg -m minimal --no-multi-region
```

ស្គ្រីបប្រើផ្លូវទាក់ទងជាមួយថតរបស់ខ្លួន, ពិនិត្យការចូល/ឧបករណ៍/សារណ៍,
បង្កើតក្រុមធនធានប្រសិនបើមិនមាន, ថតយ៉ាងត្រឹមត្រូវនៃការចេញផ្សាយ, ប្រើប្រាស់, និង
បង្ហាញលទ្ធផលគ្មានអត្ថន័យសំងាត់។ មិនចាំបាច់មាន `jq` ការបំពេញទិន្នន័យ ការទាញយកសម្ងាត់ ឬ
ការតំឡើងកម្មវិធីបន្ទាប់ពីការបញ្ចូន។

តម្លៃបើកបរ Command-line ដើមរបស់ស្គ្រីបលើកលែងតម្លៃជាមួយគ្នាក្នុង
គFILES parameters។ កែសម្រួលគFILES parameters សម្រាប់ការកំណត់ដូចជាផ្នែកទីពីរទីបី
អ៊ីនធឺរីយ៉ូម; ប្រើការបញ្ចូន CLI ត្រង់ប្រសិនបើអ្នកត្រូវការការលើកលែងតម្លៃប្រើប្រាស់បែបអេឡិចត្រូនិក:

```bash
az group create --name retail-learning-rg --location eastus2
az deployment group create \
  --resource-group retail-learning-rg \
  --name retail-learning \
  --template-file azuredeploy.json \
  --parameters azuredeploy.parameters.json \
  --parameters projectName=retail environmentName=dev \
    deploymentMode=minimal enableMultiRegion=false
```

ការផ្គត់ផ្គង់អាចប្រើពេល 15–45 នាទី ឬយូរជាង និងអាចបរាជ័យដោយមូលហេតុទំហំតំបន់ ឬ
ការកំណត់រយៈពេលជីវិតរបស់ម៉ូដែល។ កុំព្យាយាមម្ដងទៀតដោយគ្មានការយល់ដឹង: សូមអានប្រតិបត្ដិការដែលបរាជ័យជាមុនសិន។

| `tertiaryLocation` | `francecentral` | តំបន់គណនី embeddings |
| `graderLocation` | តំបន់ដើម | តំបន់គណនីអ្នកវាយតម្លៃដោយឯករាជ្យ |
| `environmentName` | `dev` | `dev`, `staging`, ឬ `prod`; មានតែឈ្មោះ மட்டும் មិនមែនជាការបើកបិទហាតណិន |
| `deploymentMode` | `standard` | ជ្រើសរើស SKU/សមត្ថភាព |
| `enableMultiRegion` | `true` | បន្ថែមគណនីទាបសកល និង embeddings |
| `enableMonitoring` | `true` | បន្ថែមការបញ្ចូល Logs និង Insights/workspace សម្រាប់បរិស្ថាន |
| `enableSecurity` | `true` | បង្កើត vault ទទេដែលមានការអនុញ្ញាត RBAC តែប៉ុណ្ណោះ |

ប៉ារ៉ាម៉ែត្រ `openAiApiVersion` ដែលបង្កច្រឡំ ត្រូវបានយកចេញ: កំណែ API លើផ្ទៃទិន្នន័យ
មិនគ្រប់គ្រងកំណែធនធាន ARM ឬកំណែម៉ូដែលឡើយ។ ឈ្មោះកូដ/កំណែម៉ូដែល
មាននៅក្នុង `variables.modelDeployments`; សូមពិនិត្យពួកវារួមគ្នាជាមួយ SKU ចេញផ្សាយ។

## ពិនិត្យការផ្ដល់សេវា

ប្រើឈ្មោះចេញផ្សាយពីលទ្ធផលស្គ្រីប ឬ `az deployment group list`។
សម្រាប់ការចេញផ្សាយផ្ទាល់ខាងលើ៖

```bash
RG=retail-learning-rg
DEPLOYMENT=retail-learning
az deployment group show -g "$RG" -n "$DEPLOYMENT" \
  --query properties.provisioningState -o tsv
az deployment operation group list -g "$RG" -n "$DEPLOYMENT" -o table
az resource list -g "$RG" -o table
```

មានការរំពឹងទុក៖ ស្ថានភាពចេញផ្សាយ `Succeeded`។ សម្រាប់ករណីបរាជ័យ សូមពិនិត្យព័ត៌មានកំហុសប្រតិបត្តិការ។
លទ្ធផលបញ្ជីធនធាននៅឡែក មិនមែនជាការពិនិត្យស្ថានភាពផ្ដល់សេវាដែលទាន់ទៀងទាត់ទេ។

សាកល្បងទំព័រប្រកាស **root** មិនមែនគន្លងភ្នាក់ងារ​ដែល​មិន​មាន​នោះទេ៖

```bash
ROUTER_URL=$(az deployment group show -g "$RG" -n "$DEPLOYMENT" \
  --query properties.outputs.routerUrl.value -o tsv)
curl --fail-with-body "$ROUTER_URL"
```

មានការរំពឹងទុក៖ ទំព័រ HTTP 200 hello-world, **មិនមែនការឆ្លើយតបជាការជជែក**។ កំហុស HTTP មិនបានរាប់បញ្ចូលថាជាការត្រួតពិនិត្យជោគជ័យទេ។


ដើម្បីសាកល្បងការបកស្រាយម៉ូដែលដើមជាក់ស្តែង (ដែលគិតថ្លៃ)៖

```bash
OPENAI_ENDPOINT=$(az deployment group show -g "$RG" -n "$DEPLOYMENT" \
  --query properties.outputs.openAiEndpointPrimary.value -o tsv)
OPENAI_NAME=$(az cognitiveservices account list -g "$RG" \
  --query "[?kind=='OpenAI' && contains(name, '-openai-primary-')].name | [0]" -o tsv)
OPENAI_KEY=$(az cognitiveservices account keys list -g "$RG" -n "$OPENAI_NAME" \
  --query key1 -o tsv)
curl --fail-with-body \
  "${OPENAI_ENDPOINT%/}/openai/deployments/gpt-4.1-chat/chat/completions?api-version=2024-10-21" \
  -H "Content-Type: application/json" -H "api-key: $OPENAI_KEY" \
  -d '{"messages":[{"role":"user","content":"Say hello"}],"max_tokens":20}'
unset OPENAI_KEY
```

រំពឹងទុក៖ JSON ជាមួយ `choices` និង `usage`។ ឈ្មោះការដាក់បង្ហាញគឺ
`gpt-4.1-chat` មិនមែនឈ្មោះម៉ូដែលមូលដ្ឋាន `gpt-4.1` ទេ។

## 🔧 បន្ទាប់ពីដាក់បង្ហាញ៖ ជំហានបន្ទាប់

នេះគឺជា **បញ្ជីការងារអភិវឌ្ឍន៍** មិនមែនជាការហាត់ប្រាណបានបញ្ចប់ទេ៖

1. អនុវត្តភ្នាក់ងារអតិថិជន/ឃ្លាំងទំនិញដែលមានការផ្ទៀងផ្ទាត់ និងកិច្ចសន្យាសម្រាប់ឧបករណ៍អ្នកបញ្ជូន។
2. អនុវត្តផ្នែកមុខ និងផ្ទៀងផ្ទាត់ការកំណត់រចនាសម្ព័ន្ធរបស់វា។
3. បង្កើត និងបំពេញសន្ទស្សន៍ស្វែងរកដែលមានវិមាត្រ/ប្រវត្តិរូបដែលសម្របសម្រួលជាមួយ
   ម៉ូដែលសម្រង់របស់អ្នក ហើយដោះស្រាយបញ្ហា និងការអាប់ដេតឯកសារ។
4. បង្កើតបញ្ជី និងកំណត់រចនាសម្ព័ន្ធអត្តសញ្ញាណ/សិទិ្ធទាញរូបភាព។
5. សង់ និងបញ្ចូលរូបភាពពិត។ ផ្លាស់ប្តូរប្រភពចរន្តនិងការត្រួតពិនិត្យនៃ Container App ឲ្យ
   នឹងរូបភាពទាំងនោះមុនពេលសាកល្បង; អំពូល 80 នៅទីនេះសម្រាប់ជំនួស។
6. កំណត់សម្ងាត់ ឬអត្តសញ្ញាណដែលគ្រប់គ្រង និងតួនាទីដែនទិន្នន័យដែលមានដែនកំណត់។ កុំ
   យោងទៅឈ្មោះសម្ងាត់បុបទេ៖ គំរូនេះមិនបង្កើតសម្ងាត់កម្មវិធីទេ។
7. បង្ហាញកម្មវិធី កំណត់ការជូនដំណឹង សាកល្បងការបរាជ័យ/ការស្ដារឡើងវិញ និងវាយតម្លៃ
   លទ្ធផលជាមួយចំណាត់ថ្នាក់ដែនពិត និងការត្រួតពិនិត្យមនុស្ស។

មើល [គ្រោងរចនាស្ថាបត្យកម្ម](../retail-scenario.md) សម្រាប់ព្រំដែនរចនា។

## ការដោះស្រាយបញ្ហា និងព្រំដែនសុវត្ថិភាព

- **ម៉ូដែលមិនអាចប្រើបាន៖** ពិនិត្យម៉ូដែល/កំណែ/SKU តំបន់ និងគណនីជាវ;
  ស្គ្រីបមិនបានធ្វើការត្រួតពិនិត្យមុខមាត់នៃបញ្ជីម៉ូដែលទេ។
- **ការត្រួតពិនិត្យបានមិនដំណើរការ:** គោលដៅកំណត់ហេតុបរិស្ថានគឺជា `none` មិនមែនជា
  ការកំណត់ Log Analytics ទទេដែលមិនត្រឹមត្រូវ។
- **មានតែទីតាំងទុកដាក់ប៉ុណ្ណោះ៖** `/chat`, ការវាយតម្លៃភ្នាក់ងារ និងការបញ្ចូលឯកសារមិនមានឡើយ។
- **បណ្ដាញ/អត្តសញ្ញាណ៖** ច្រកសាធារណៈ និងការផ្ទៀងផ្ទាត់មូលដ្ឋានត្រូវបានបើកប្រើ។
  ការបើកអោយ Key Vault RBAC មិនបានបង្កើត ការបែងចែកតួនាទី ឬអត្តសញ្ញាណឡើយ។
- **ផលិតកម្ម៖** បន្ថែមការផ្ទៀងផ្ទាត់, អត្តសញ្ញាណដែលមានវិសាលភាព, ការគ្រប់គ្រងសម្ងាត់,
  បណ្ដាញឯកជននៅកន្លែងសមរម្យ, ការរចនាស្រៈភាព និងការធ្វើតេស្តប្រតិបត្តិការ។
  គណនីម៉ូដែលច្រើនតំបន់មិនផ្ដល់ការចូលដំណើរការបន្ថែមឡើយ។
