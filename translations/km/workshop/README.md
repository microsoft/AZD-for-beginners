# សិក្ខាសាលា AZD សម្រាប់អ្នកអភិវឌ្ឍ AI

សូមស្វាគមន៍មកកាន់សិក្ខាសាលាដែលអនុវត្តដោយដៃសម្រាប់ការរៀន Azure Developer CLI (AZD) ដែលផ្តោតលើការដាក់ពាក្យកម្មវិធី AI។ សិក្ខាសាលានេះជួយអ្នកទទួលបានការយល់ដឹងអំពីគំរូ AZD ក្នុង ៣ ជំហាន៖

1. **ការស្វែងរក** - ស្វែងរកគំរូដែលសមស្របសម្រាប់អ្នក។
1. **ការដាក់ពាក្យ** - ដាក់ពាក្យ និងផ្ទៀងផ្ទាត់ថាវាដំណើរការ។
1. **ការតម្រូវផ្ទាល់ខ្លួន** - ប្តូរ និងធ្វើឡើងវិញឲ្យជារបស់អ្នក!

ក្នុងអំឡុងរយៈពេលសិក្ខាសាលានេះ អ្នកនឹងបានណែនាំឧបករណ៍និងដំណើរការអភិវឌ្ឍន៍សំខាន់ៗ ដើម្បីជួយអ្នកធ្វើដំណើរអភិវឌ្ឍចុងពីលើដល់ចុងក្រោយបានប្រសើរឡើង។

## មគ្គុទេសក៍ផ្អែកលើកម្មវិធីរុករក

មេរៀនកេងោងនៅក្នុង Markdown អ្នកអាចរុករកវាតាមទំព័រ GitHub ដោយផ្ទាល់ ឬបើកមើលជាមុននៅក្នុងកម្មវិធីរុករកដូចដែលបង្ហាញក្នុងរូបភាពខាងក្រោម។

![Workshop](../../../translated_images/km/workshop.75906f133e6f8ba0.webp)

ដើម្បីប្រើជម្រើសនេះ - សូមចំលងរ៉េប៉ូទៅក្នុងប្រវត្តិរូបអ្នក ហើយបើក GitHub Codespaces។ ពេល VS Code terminal ដំណើរការ សូមវាយពាក្យបញ្ជានេះ៖

ការមើលជាមុននេះដំណើរការបាននៅក្នុង GitHub Codespaces, dev containers, ឬចម្លងមកទម្រង់មួយក្នុងម៉ាស៊ីនតាមផ្ទាល់ដែលបានដំឡើង Python និង MkDocs។

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

ប្រតិបត្តិការបញ្ជាទាំងនេះពី **ដើមរ៉េប៉ូរបស់វគ្គសិក្សា** មិនមែនពីគម្រោង AI នីមួយៗដែលបានចាប់ផ្ដើមឡើងនោះទេ។ រក្សាទុកការមើលជាមុននៅមុខ ទើបកំហុសនានា​កើតឡើងអាចមើលឃើញបាន; បញ្ឈប់វាជាមួយ Ctrl+C។ ដើម្បីពិនិត្យគេហទំព័រដោយមិនចំលងវា សូមរត់ `python -m mkdocs build --strict --config-file workshop/mkdocs.yml`។

ខណៈពេលពីរបីវិនាទី អ្នកនឹងឃើញប្រអប់ pop-up មួយ។ ជ្រើសរើសជម្រើស `Open in browser`។ មគ្គុទេសក៍ផ្អែកលើវេបសាយនឹងបើកក្នុងផ្ទាំងថ្មីក្នុងកម្មវិធីរុករក។ អត្ថប្រយោជន៍ខ្លះនៃការមើលជាមុននេះ៖

1. **ស្វែងរកនៅក្នុងកម្មវិធីតែមួយ** - រកពាក្យសំខាន់ ឬមេរៀនឆាប់រហ័ស។
1. **រូបតំណាងចម្លង** - វៀតលើកូដប្លុក ដើម្បីឃើញជម្រើសនេះ
1. **ផ្លាស់ប្តូរមូលដ្ឋានរូបរាង** - ប្តូររវាងរូបរាងខ្មៅ និងស្រាល
1. **ទទួលបានជំនួយ** - ចុចរូបតំណាង Discord នៅផ្នែកជើងដើម្បីចូលរួម!

- **មន្ទីរពិសោធន៍**: ប្តូរតាមតម្រូវការគំរូសម្រាប់សេណារីយ៉ូរបស់ខ្ញុំ

## 챌្លែងសិក្ខាសាលា

ចង់បញ្ចេញ챌្លែងសម្រាប់ខ្លួនឯងទៀតទេ? នៅទីនេះមានគម្រោងមួយចំនួនផ្តល់ជំនួយ - ឬចែករំលែកគំនិតរបស់អ្នកជាមួយយើង!!

| គម្រោង | ការពិពណ៌នា |
|:---|:---|
|1. **បំបែកគំរូ AI ស្មុគស្មាញមួយ** | ប្រើដំណើរការ និងឧបករណ៍ដែលយើងបានរៀបរាប់ ពិនិត្យមើលអាចដាក់ពាក្យ, ផ្ទៀងផ្ទាត់ និងប្តូរតាមតម្រូវការ គំរូដំណោះស្រាយ AI ផ្សេងទៀតបានប៉ុណ្ណា? _តើអ្នកបានរៀនអ្វី?_|
|2. **ប្តូរតាមសេណារីយ៉ូរបស់អ្នក**  | សាកល្បងសរសេរឯកសារតម្រូវការផលិតផល (PRD) សម្រាប់សេណារីយ៉ូផ្សេងទៀត។ បន្ទាប់មកប្រើ GitHub Copilot នៅក្នុង repo គំរូរបស់អ្នកនៅគំរូភ្នាក់ងារ - ហើយសុំឲ្យវាបង្កើតដំណើរការប្តូរតាមតម្រូវការ។ _តើអ្នកបានរៀនអ្វី? តើអ្នកអាចកែលម្អលើយោបល់ទាំងនេះដូចម្តេច?_|
