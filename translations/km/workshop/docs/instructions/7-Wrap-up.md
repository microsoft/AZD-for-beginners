## 1. អ្វី​ដែល​អ្នក​បានសម្រេច

| មូឌុល | អ្វីដែលបានសម្រេច |
|:---|:---|
| **មូឌុល 1** | ស្វែងរក Azure Developer CLI និងជ្រើសរើសពិពណ៌ AI មួយ |
| **មូឌុល 2** | ដំឡើងនិងផ្ទៀងផ្ទាត់ដំណោះស្រាយភ្នាក់ងារពិចារណាសិទិ្ឋ AI ពេញលេញ |
| **មូឌុល 3** | បំបែកពិពណ៌ដើម្បីយល់ដឹងពីស្ថាបត្យកម្មរបស់វា |
| **មូឌុល 4** | ស្វែងយល់ពីការកំណត់រចនាសម្ព័ន្ធ `azure.yaml` និងចំណុចជាប់ខ្សែជីវិត |
| **មូឌុល 5** | ប្តូរផលិតភាពពិពណ៌សម្រាប់ ស្ថានការណ៍ផ្ទាល់ខ្លួនរបស់អ្នក |
| **មូឌុល 6** | ដោះសោស្នាក់នៅគ្រឹះរចនាសម្ព័ន្ធដោយសុវត្ថិភាព និងគ្រប់គ្រងធនធាន |

## 2. គំនិតសំខាន់ៗដែលបានយល់

### Azure Developer CLI (azd)
- `azd init` - ចាប់ផ្តើមគម្រោងពីពិពណ៌
- `azd up` - ផ្គត់ផ្គង់និងដំឡើងក្នុងម៉ោងបញ្ជាเดียว
- `azd env` - គ្រប់គ្រងអថេរស្ថានភាពបរិដ្ឋាន
- `azd down` - សម្អាតធនធានដោយសុវត្ថិភាព

### រចនាសម្ព័ន្ធពិពណ៌ AZD
- `azure.yaml` - ការកំណត់រចនាសម្ព័ន្ធ និងចំណុចជាប់ខ្សែដាក់
- `infra/` - Bicep រចនាសម្ព័ន្ធជាកូដ
- `src/` - កូដប្រភពកម្មវិធី
- `scripts/` - ស្គ្រីបស្វ័យប្រវត្តិ និងការដំឡើង

### សមត្ថភាព Microsoft Foundry
- ឯកសារភ្នាក់ងារពិចារណាសិទិ្ឋសម្រាប់ជំនួយការច្បាស់លាស់
- ស្វែងរកឯកសារនិង Azure AI Search សម្រាប់ការស្រង់ចំណេះដឹង
- ការតាមដាន, ពិនិត្យនិងវាយតម្លៃផ្ទាល់ក្នុង
- ការចូលរួមក្រុមក្រហមសម្រាប់ការបញ្ជាក់សុវត្ថិភាព AI
