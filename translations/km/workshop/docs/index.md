# ឧបករណ៍ហាត់ប្រាណ AZD សម្រាប់អ្នកអភិវឌ្ឍន៍ AI

> ការណែនាំប្រភពត្រូវបានពិនិត្យប្រឆាំងនឹង AZD 1.37.2 នៅថ្ងៃទី ៤ ខែវិច្ឆិកា ឆ្នាំ ២០២៦។ រូបភាពចាប់ផ្តើមគឺសម្រាប់បង្ហាញតែប៉ុណ្ណោះ; ការចូលប្រើសេវាកម្ម ស្លាកផតថល និងលំនាំដើមអាចផ្លាស់ប្ដូរ។

> [!IMPORTANT]  
> **វគ្គហាត់ប្រាណនេះត្រូវបានបង្ហោះជាមួយមគ្គុទេសក៍វគ្គដែលអ្នកអាចមើលមុនក្នុងកម្មវិធី浏览器របស់អ្នក។ ដើម្បីចាប់ផ្តើម បើកrepo ក្នុង GitHub Codespaces ឬ dev container ឬក៏ការចម្លងក្នុងម៉ាស៊ីនមូលដ្ឋានដែលបានដំឡើង MkDocs — បន្ទាប់មករង់ចាំរហូតដល់អ្នកឃើញផ្ទាំង VS Code ដំណើរការនិងវាយបញ្ចូល៖**  
> ពីមូលដ្ឋាន repo វគ្គ សូមដំឡើង `requirements-dev.txt` បន្ទាប់មកបើកដំណើរការ `python -m mkdocs serve --config-file workshop/mkdocs.yml` នៅផ្ទាំងមុខ។
> **អ្នកគួរតែឃើញប្រអប់ជជែកបញ្ចេញដើម្បីបើកទំព័រមើលជាមុនក្នុងកម្មវិធី浏览器។**

សូមស្វាគមន៍មកកាន់វគ្គហាត់ប្រាណរែកតាក់សម្រាប់ការរៀន Azure Developer CLI (AZD) ដែលផ្តោតលើការដាក់ពាក្យ AI ។ វគ្គនេះជួយអ្នកទទួលបានការយល់ដឹងអំពីកិច្ចការជាក់ស្តែងនៃលំនាំ AZD ក្នុង៣ជំហានៈ

1. **ការស្វែងរក** - រកលំនាំដែលសមរម្យសម្រាប់អ្នក។
1. **ការដាក់ពាក្យ** - ដាក់ពាក្យនិងផ្ទៀងផ្ទាត់ថាវាដំណើរការ។
1. **ការប្ដូរតាមតម្រូវការ** - កែប្រែ និងបន្តបង្រួមអោយក្លាយជារបស់អ្នក!

ក្នុងឱកាសវគ្គនេះ អ្នកនឹងទទួលបានការណែនាំអំពីឧបករណ៍អ្នកអភិវឌ្ឍន៍មូលដ្ឋាន និងដំណើរការកម្មវិធី ដើម្បីជួយអ្នកធ្វើដំណើរក្នុងការអភិវឌ្ឍពីដើមដល់ចុង។

## អ្វីដែលអ្នកនឹងរៀន

សូមចងចាំថាលំនាំ AZD គឺជាសម្រង់បរិច្ឆេទសម្រាប់ស្វែងយល់មុខងារ និងឧបករណ៍ផ្សេងៗសម្រាប់ការអភិវឌ្ឍទាំងមូលលើ Microsoft Foundry។ នៅចុងបញ្ចប់នៃវគ្គនេះ អ្នកគួរតែមានការយល់ដឹងថាគ្នាអំពីឧបករណ៍ និងគំនិតផ្សេងៗក្នុងបរិបទនេះ។

| គំនិត  | គោលបំណង |
|:---|:---|
| **Azure Developer CLI** | យល់ពីពាក្យបញ្ជា និងដំណើរការឧបករណ៍|
| **លំនាំ AZD**| យល់ពីរចនាសម្ព័ន្ធគម្រោង និងការកំណត់រចនា|
| **ភ្នាក់ងារបញ្ញាសិប្បនិម្មិត Azure**| ផ្តល់ និងដាក់ពាក្យគម្រោង Microsoft Foundry  |
| **ការស្វែងរក Azure AI**| អនុញ្ញាតការបញ្ចូលបរិបទជាមួយភ្នាក់ងារ |
| **ការអាចមើលឃើញ**| ស្វែងយល់ពីការតាមដាន ការត្រួតពិនិត្យ និងការវាយតម្លៃ |
| **ក្រុមក្រហម**| ស្វែងយល់ពីការប្រយុទ្ធ និងការប្រឆាំងអាកប្បកិរិយា |
