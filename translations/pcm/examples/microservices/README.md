# Microservices Example

Di runnable implementation and im instructions dey for
**[container-app/microservices](../container-app/microservices/README.md)**.

Dis directory na navigation only. E no get `azure.yaml`, `infra/`, or `src/`.
No run `azd up` here.

From di repository root:

```bash
cd examples/container-app/microservices
```

After dat, follow di linked README for prerequisites, deployment, verification, local
development, practical exercises, costs, and cleanup.

Di sample get one Node.js API Gateway and one read-only Python Product Service.
Order, user, notification, database, and messaging services na extension ideas,
dem no be implementations wey dey inside dis repository.
