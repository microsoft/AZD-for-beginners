## Преглед

Тази глава въвежда основите на Azure Developer CLI (azd). Ще научите основни концепции, ще инсталирате инструментите и ще разположите първото си приложение в Azure.

> Цел на прегледа на команди и конфигурация: `azd 1.37.2` (ноември 2026). Живо предоставяне в Azure не е изпълнявано по време на прегледа.

## Учебни цели

Като завършите тази глава, ще можете:
- Да разберете какво е Azure Developer CLI и как се различава от Azure CLI
- Да инсталирате и конфигурирате AZD на вашата платформа
- Да разположите първото си приложение в Azure с `azd up`
- Да почистите ресурсите с `azd down`

## 🚀 Бърз старт

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ Критерии за успех

След завършване на тази глава трябва да можете да:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
