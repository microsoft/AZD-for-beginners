# Глава 2: Разработка с приоритет към ИИ

**📚 Курс**: [AZD за начинаещи](../../README.md) | **⏱️ Продължителност**: 4-5 часа включително работилницата | **⭐ Сложност**: Средно ниво

---

## Преглед

Тази глава е съсредоточена върху внедряването на приложения, захранвани с ИИ, използвайки Azure Developer CLI и Microsoft Foundry услуги. От прости чат приложения с ИИ до интелигентни агенти с инструменти.

> **Преглед на изданието (04-11-2026):** Насоките за AI CLI бяха проверени с публикуваната документация/източник `azd` `1.37.2`, `azure.ai.agents` `1.0.0-beta.23`, и `azure.ai.evaluations` `1.0.0-beta.2`. Използвайте `azd >= 1.37.0` за комбинирания работен поток. Оценките сега използват отделното пространство от имена `azd ai eval`; вижте [промени в изданието и насоки за миграция](../chapter-08-production/production-ai-practices.md#recent-release-changes-and-fixes). Това не е валидиране на живо внедряване.

## Учебни цели

След завършване на тази глава, ще можете:
- Да внедрявате AI приложения с използване на готови AZD шаблони
- Да разбирате интеграцията на Microsoft Foundry с AZD
- Да конфигурирате и персонализирате AI агенти с инструменти
- Да внедрявате RAG (Генериране с подпомагане от извличане) приложения

## 🚀 Бърз старт

Изберете една опция в нова празна директория. Задният `.` инициализира текущата директория; в противен случай AZD може да създаде подпапка без да променя работната директория на вашия шел.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Осъзнаване на разходите

Това са илюстративни диапазони, не оферти или тавани; моделният трафик, Search/compute SKU-та, регион и допълнителни функции могат да ги надминат. Прегледайте актуалните насоки за ценообразуване на избрания пример преди разполагането.

| Среда | Очаквани месечни разходи |
|-------------|----------------------|
| Разработка | $80-150 |
| Тестване | $150-300 |
| Производство | $300-3,500+ |

**Съвет:** Стартирайте `azd down` след тестове, за да избегнете такси.
