# Глава 2: Разработка с акцент върху AI

**📚 Курс**: [AZD за начинаещи](../../README.md) | **⏱️ Продължителност**: 4-5 часа, включително уъркшоп | **⭐ Сложност**: Средно ниво

---

## Преглед

Тази глава се фокусира върху разгръщане на приложения с изкуствен интелект, използвайки Azure Developer CLI и Microsoft Foundry услуги. От прости AI чат приложения до интелигентни агенти с инструменти.

> **Foundry GA актуализация (2026-11-09):** Пакетът `microsoft.foundry` 1.0 е [обществено достъпен](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). Използвайте `azd >= 1.37.0`; оценките остават отделна инсталация. [Ръководството за хоствания агент](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) обхваща локално тестване с Agent Inspector и дистанционно разгръщане на код. Това е преглед на документацията, не валидиция на живо разгръщане; опционалните функции в преглед задържат своя собствен статус.

## Учебни цели

След завършване на тази глава вие ще:
- Разгръщате AI приложения с предварително изградени AZD шаблони
- Разбирате интеграцията на Microsoft Foundry с AZD
- Инсталирате GA пакета и тествате локално хостван агент преди разгръщане на изходния му код в Foundry
- Прегледате `azure.yaml`, оценъчните активи и почистването на нови и повторно използвани проекти
- Конфигурирате и персонализирате AI агенти с инструменти
- Разгърнете RAG (Retrieval-Augmented Generation) приложения

## 🚀 Бърз старт

Изберете една опция в нова празна директория. Крайният `.` инициализира текущата директория; в противен случай AZD може да създаде поддиректория без да променя работната ви директория в терминала.

За **GA пътя на разгръщане на код с хостван агент** започнете с [водено ръководство](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga). Изисква AZD 1.37.0+, текущ uv, Python 3.13+, права за Foundry и квота за модели. По-долу посочените пълни шаблони за приложения са алтернативи, а не предпоставки за това ръководство.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Осъзнаване на разходите

Това са илюстративни диапазони, не оферти или тавани; трафикът на модели, Search/compute SKU-та, регион и опционални функции могат да ги надвишават. Прегледайте текущите насоки за ценообразуване на избрания пример преди да извършите предоставяне.

| Околна среда | Оценена месечна цена |
|-------------|----------------------|
| Разработка | $80-150 |
| Стейджинг | $150-300 |
| Производство | $300-3,500+ |

**Почистване:** Прегледайте `azd down` преди потвърждаване: за новосъздаден проект в Foundry, той изтрива ресурсната група и всичко в нея. За повторно използван проект в Foundry, оставя проекта и ресурсите на агента на място; следвайте [насоките за почистване от ръководството](microsoft-foundry-integration.md#7-clean-up-deliberately), за да премахнете нежеланите ресурси отделно.
