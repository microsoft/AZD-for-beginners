## 🚀 Бърз старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **Кой подход?** Използвайте `azd init --template` за започване от работещ пример. Използвайте `azd ai agent init` интерактивно, или `azd ai agent init --template <path-to-azure.yaml>` за приемане на текущ агентски проект. Вижте [AZD AI CLI справочник](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) за изисквания към версии и миграция при оценка.

Изпълнете тези алтернативи в отделни празни папки. Разширението за агенти `1.0.0-beta.23` изисква `azd >= 1.37.0`; интерактивният му поток не генерира потребителски Service Bus pipeline в координационния урок.

## 🎯 Представено решение: Търговско многоагентно решение

Решението [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонстрира:

- **Агент за клиенти**: Обработва взаимодействията и предпочитанията на потребителя
- **Агент за наличности**: Управлява запасите и обработката на поръчките
- **Оркестратор**: Координира между агентите
- **Споделена памет**: Управление на контекста между агентите

### Използвани услуги

| Услуга | Цел |
|---------|---------|
| Microsoft Foundry Models | Разбиране на езика |
| Azure AI Search | Каталог на продукти |
| Cosmos DB | Състояние и памет на агентите |
| Container Apps | Хостинг на агентите |
| Application Insights | Наблюдение |
