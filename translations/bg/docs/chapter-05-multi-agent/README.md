## Преглед

Тази глава разглежда усъвършенствани модели на многоагентна архитектура, оркестрация на агенти и AI внедрявания, готови за продуктивна среда при сложни сценарии.

> Ръководството за команди е прегледано спрямо издаденото `azd 1.37.2` референтно ръководство. Внедрявания в облака не са изпълнявани.

## Учебни цели

След завършване на тази глава, ще можете:
- Да разбирате модели на многоагентна архитектура
- Да внедрявате координирани системи от AI агенти
- Да реализирате комуникация агент-до-агент
- Да изграждате готови за производство многоагентни решения

## 🚀 Бърз старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **Кой подход?** Използвайте `azd init --template`, за да започнете с работещ пример. Използвайте `azd ai agent init` интерактивно или `azd ai agent init --template <path-to-azure.yaml>`, за да адаптирате текущ проект с агенти. Вижте [AZD AI CLI справочника](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) за изисквания към версията и миграция при оценка.

Изпълнявайте тези алтернативи в отделни празни папки. Работният процес GA Foundry изисква `azd >= 1.37.0`; неговият интерактивен поток не генерира персонализирания Service Bus pipeline в урока за координация. За локално тестване, разгръщане на код и почистване при нови срещу използвани проекти, следвайте [ръководството за хоствани агенти](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga).

## 🎯 Представено решение: Ритейл многоагент

Решението [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонстрира:

- **Агент Клиент**: Управлява взаимодействията и предпочитанията на потребителя
- **Агент Запаси**: Управлява наличностите и обработката на поръчките
- **Оркестратор**: Координира между агентите
- **Споделена памет**: Управление на контекста между агентите

### Използвани услуги

| Услуга | Цел |
|---------|---------|
| Microsoft Foundry Models | Разбиране на езика |
| Azure AI Search | Каталог на продукти |
| Cosmos DB | Състояние и памет на агентите |
| Container Apps | Хостинг на агенти |
| Application Insights | Мониторинг |
