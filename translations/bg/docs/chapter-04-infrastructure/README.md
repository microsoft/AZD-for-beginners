# Глава 4: Инфраструктура като код и внедряване

**📚 Курс**: [AZD за начинаещи](../../README.md) | **⏱️ Продължителност**: 2-3 часа четене; отделете допълнително време за упражнения по внедряване | **⭐ Ниво на сложност**: Средно

## Преглед

Тази глава обхваща модели за Инфраструктура като код (IaC) с Bicep шаблони, предоставяне на ресурси и стратегии за внедряване с помощта на Azure Developer CLI.

> Цел за преглед на команди и конфигурация: `azd 1.37.2` (ноември 2026). Живо предоставяне в Azure не беше изпълнено по време на прегледа.

## Учебни цели

След завършване на тази глава ще можете:
- Да разбирате структурата и синтаксиса на Bicep шаблона
- Да осигурявате Azure ресурси с `azd provision`
- Да внедрявате приложения с `azd deploy`
- Да прилагате стратегии за синьо-зелено и последователно внедряване

## 🚀 Бърз старт

```bash
# Initialize from template
mkdir infrastructure-practice
cd infrastructure-practice
azd init --template todo-nodejs-mongo .
azd auth login

# Preview what will be created
azd provision --preview

# Provision infrastructure only
azd provision

# Deploy code only
azd deploy

# Or both together
azd up
```

## 📁 Структура на проекта AZD

```
my-project/
├── azure.yaml            # ← Project definition
├── infra/                # ← Infrastructure as Code
│   ├── main.bicep        # Entry point
│   ├── main.parameters.json
│   └── modules/          # Reusable components
│       ├── web.bicep
│       └── database.bicep
└── src/                  # Application code
    └── api/
```

## 🔧 Основни команди

| Команда | Описание |
|---------|-------------|
| `azd init` | Инициализиране на проекта |
| `azd provision` | Създаване на Azure ресурси |
| `azd deploy` | Внедряване на код на приложение |
| `azd up` | предоставяне + внедряване |
| `azd down` | Изтриване на всички ресурси |
