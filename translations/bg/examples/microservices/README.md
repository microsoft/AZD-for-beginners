# Пример с микросервизи

Работещата имплементация и инструкциите й са в
**[container-app/microservices](../container-app/microservices/README.md)**.

Тази директория е само за навигация. Тя няма `azure.yaml`, `infra/` или `src/`.
Не изпълнявайте `azd up` тук.

От корена на репозитория:

```bash
cd examples/container-app/microservices
```

След това следвайте свързания README за предварителни изисквания, разгръщане, проверка, локална
разработка, практически упражнения, разходи и почистване.

Примерът съдържа Node.js API Gateway и само за четене Python Product Service.
Услугите за поръчки, потребители, уведомления, база данни и съобщения са идеи за разширение,
а не имплементации включени в този репозиториум.

- [Следваща: Приложение с база данни](../../../../examples/database-app)
