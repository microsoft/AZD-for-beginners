# Exemplo de Microsserviços

A implementação executável e suas instruções estão em
**[container-app/microservices](../container-app/microservices/README.md)**.

Este diretório é apenas para navegação. Não contém `azure.yaml`, `infra/`, ou `src/`.
Não execute `azd up` aqui.

A partir da raiz do repositório:

```bash
cd examples/container-app/microservices
```

Então siga o README vinculado para pré-requisitos, implantação, verificação, desenvolvimento local,
exercícios práticos, custos e limpeza.

O exemplo contém um API Gateway em Node.js e um Serviço de Produto somente leitura em Python.
Serviços de pedido, usuário, notificação, banco de dados e mensagens são ideias para extensão,
não implementações incluídas neste repositório.
