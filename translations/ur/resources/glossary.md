# اصطلاحات نامہ - ایزور اور AZD کی اصطلاحات

**تمام ابواب کے لیے حوالہ**
- **📚 کورس ہوم**: [ابتدائیوں کے لیے AZD](../README.md)
- **📖 بنیادی باتیں سیکھیں**: [باب 1: AZD کی بنیادی باتیں](../docs/chapter-01-foundation/azd-basics.md)
- **🤖 AI اصطلاحات**: [باب 2: AI-فرسٹ ڈویلپمنٹ](../docs/chapter-02-ai-development/microsoft-foundry-integration.md)

## تعارف

یہ جامع اصطلاحات نامہ Azure Developer CLI اور Azure کلاؤڈ ڈویلپمنٹ میں استعمال ہونے والی اصطلاحات، تصورات، اور مخففات کی تعریفیں فراہم کرتا ہے۔ تکنیکی دستاویزات کو سمجھنے، مسائل کے حل کے لیے، اور azd پروجیکٹس اور Azure سروسز کے بارے میں مؤثر طریقے سے بات چیت کرنے کے لیے ایک ضروری حوالہ۔

## سیکھنے کے مقاصد

اس اصطلاحات نامہ کو استعمال کرتے ہوئے، آپ:
- اہم Azure Developer CLI اصطلاحات اور تصورات کو سمجھیں گے
- Azure کلاؤڈ ڈویلپمنٹ کے الفاظ اور تکنیکی اصطلاحات میں مہارت حاصل کریں گے
- انفراسٹرکچر ایز کوڈ اور تعیناتی کی اصطلاحات کا مؤثر حوالہ دیں گے
- Azure سروسز کے نام، مخففات، اور ان کے مقاصد کو سمجھیں گے
- مسائل کے حل اور ڈیبگنگ اصطلاحات کی تعریفیں حاصل کریں گے
- جدید Azure آرکیٹیکچر اور ڈویلپمنٹ تصورات سیکھیں گے

## سیکھنے کے نتائج

اس اصطلاحات نامہ کا باقاعدہ حوالہ دے کر، آپ کر سکیں گے:
- مؤثر بات چیت کریں صحیح Azure Developer CLI اصطلاحات استعمال کرتے ہوئے
- تکنیکی دستاویزات اور ایرر میسجز کو بہتر طریقے سے سمجھیں
- Azure سروسز اور تصورات میں خوداعتمادی کے ساتھ نیویگیٹ کریں
- مناسب تکنیکی الفاظ استعمال کرتے ہوئے مسائل کا حل نکالیں
- ٹیم کی گفتگو میں درست تکنیکی زبان سے حصہ لیں
- اپنے Azure کلاؤڈ ڈویلپمنٹ کے علم کو منظم طریقے سے بڑھائیں

## A

**ARM ٹیمپلٹ**  
Azure Resource Manager ٹیمپلٹ۔ JSON پر مبنی انفراسٹرکچر ایز کوڈ فارمیٹ جو Azure وسائل کو وضاحتی طور پر بیان اور تعینات کرنے کے لیے استعمال ہوتا ہے۔

**ایپ سروس**  
Azure کی پلیٹ فارم-ایز-ا-سروس (PaaS) کی پیشکش، جو ویب ایپلیکیشنز، REST APIs، اور موبائل بیک اینڈز کی ہوسٹنگ کے لیے ہے بغیر انفراسٹرکچر کے انتظام کے۔

**ایپلیکیشن انسائٹس**  
Azure کی ایپلیکیشن پرفارمنس مانیٹرنگ (APM) سروس جو ایپلیکیشن کی کارکردگی، دستیابی، اور استعمال پر گہری بصیرت فراہم کرتی ہے۔

**Azure CLI**  
Azure وسائل کا انتظام کرنے کے لیے کمانڈ لائن انٹرفیس۔ یہ AZD کی تکمیل کرتا ہے لیکن اس کا الگ لاگ ان ہوتا ہے؛ AZD کا مرکزی توثیقی نظام `azd auth login` استعمال کرتا ہے۔

**Azure Developer CLI (azd)**  
ڈویلپرمرکز کمانڈ لائن ٹول جو ایپلیکیشنز کو Azure پر ٹیمپلٹس اور انفراسٹرکچر ایز کوڈ کے ذریعے تیزی سے بنانے اور تعینات کرنے کے عمل کو تیز کرتا ہے۔

**azure.yaml**  
azd پروجیکٹ کی مرکزی کنفیگریشن فائل جو سروسز، انفراسٹرکچر، اور تعیناتی ہکس کی تعریف کرتی ہے۔

**Azure Resource Manager (ARM)**  
Azure کی تعیناتی اور انتظامی سروس جو وسائل کی تخلیق، اپ ڈیٹ، اور حذف کے لیے مینجمنٹ لیئر فراہم کرتی ہے۔

## B

**Bicep**  
مخصوص ڈومین کی زبان (DSL) جو Microsoft نے Azure وسائل کی تعیناتی کے لیے تیار کی ہے۔ ARM ٹیمپلٹس سے آسان نحو فراہم کرتا ہے جبکہ ARM میں کمپائل ہوتا ہے۔

**Build**  
سورس کوڈ کو مرتب کرنے، انحصارات کو انسٹال کرنے، اور ایپلیکیشنز کو تعیناتی کے لیے تیار کرنے کا عمل۔

**Blue-Green Deployment**  
تعیناتی کی حکمت عملی جو ایک جیسے دو پیداواری ماحول (نیلا اور سبز) استعمال کرتی ہے تاکہ بندش اور خطرے کو کم کیا جا سکے۔

## C

**Container Apps**  
Azure کی سرورلیس کنٹینر سروس جو پیچیدہ انفراسٹرکچر کا انتظام کیے بغیر کنٹینر پر مبنی ایپلیکیشنز چلانے کی اجازت دیتی ہے۔

**CI/CD**  
مسلسل انضمام/مسلسل تعیناتی۔ کوڈ تبدیلیوں کو مربوط کرنے اور ایپلیکیشنز کو تعینات کرنے کے لیے خودکار طریقے۔

**Cosmos DB**  
Azure کی عالمی سطح پر تقسیم شدہ، کثیر-ماڈل ڈیٹا بیس سروس جو تھروپٹ، لیٹنسی، دستیابی، اور مستقل مزاجی کے لیے جامع SLA فراہم کرتی ہے۔

**Configuration**  
وہ سیٹنگز اور پیرا میٹرز جو ایپلیکیشن کے رویے اور تعیناتی کے اختیارات کو کنٹرول کرتے ہیں۔

## D

**Deployment**  
ایپلیکیشنز اور ان کے انحصارات کو ہدف انفراسٹرکچر پر انسٹال اور ترتیب دینے کا عمل۔

**Docker**  
ایپلیکیشنز کو تیار، شپ، اور چلانے کے لیے کنٹینرائزیشن ٹیکنالوجی کا پلیٹ فارم۔

**Dockerfile**  
ایک ٹیکسٹ فائل جس میں Docker کنٹینر امیج بنانے کی ہدایات ہوتی ہیں۔

## E

**Environment**  
ایک تعیناتی کا ہدف جو آپ کی ایپلیکیشن کی مخصوص مثال کی نمائندگی کرتا ہے (مثلاً، ڈیولپمنٹ، اسٹجنگ، پروڈکشن)۔

**Environment Variables**  
وہ کنفیگریشن ویلیوز جو کلیدی-قیمت جوڑوں کے طور پر ذخیرہ کی جاتی ہیں اور ایپلیکیشنز رن ٹائم پر انہیں حاصل کر سکتے ہیں۔

**Endpoint**  
وہ URL یا نیٹ ورک ایڈریس جہاں ایک ایپلیکیشن یا سروس تک رسائی حاصل کی جا سکتی ہے۔

## F

**Function App**  
Azure کی سرورلیس کمپیوٹ سروس جو ایونٹ پر مبنی کوڈ چلانے کی اجازت دیتی ہے بغیر انفراسٹرکچر کے انتظام کے۔

## G

**GitHub Actions**  
CI/CD پلیٹ فارم جو GitHub ریپوز کے ساتھ مربوط ہے تاکہ ورک فلو کو خودکار بنایا جا سکے۔

**Git**  
تقسیم شدہ ورژن کنٹرول سسٹم جو سورس کوڈ میں تبدیلیوں کو ٹریک کرنے کے لیے استعمال ہوتا ہے۔

## H

**Hooks**  
مخصوص اسکرپٹس یا کمانڈز جو تعیناتی کی زندگی کے مخصوص نقاط پر چلائے جاتے ہیں (preprovision, postprovision, predeploy, postdeploy)۔

**Host**  
وہ Azure سروس کی قسم جہاں ایک ایپلیکیشن تعینات کی جائے گی (مثلاً، appservice, containerapp, function)۔

## I

**Infrastructure as Code (IaC)**  
انفراسٹرکچر کو دستی طریقوں کی بجائے کوڈ کے ذریعے تعریف اور انتظام کرنے کا عمل۔

**Init**  
نیا azd پروجیکٹ شروع کرنے کا عمل، عام طور پر ٹیمپلٹ سے۔

## J

**JSON**  
جاوا اسکرپٹ آبجیکٹ نوٹیشن۔ ایک ڈیٹا انٹرچینج فارمیٹ جو عام طور پر کنفیگریشن فائلز اور API جوابات میں استعمال ہوتا ہے۔

**JWT**  
JSON ویب ٹوکن۔ JSON آبجیکٹ کی شکل میں فریقین کے درمیان معلومات کو محفوظ طریقے سے منتقل کرنے کا معیار۔

## K

**Key Vault**  
Azure کی سروس جو سیکرٹس، چابیاں، اور سرٹیفکیٹس کو محفوظ طریقے سے ذخیرہ اور مینج کرتی ہے۔

**Kusto Query Language (KQL)**  
Azure Monitor، Application Insights، اور دیگر Azure سروسز میں ڈیٹا تجزیہ کے لیے استعمال ہونے والی کوئری زبان۔

## L

**Load Balancer**  
ایک سروس جو آنے والے نیٹ ورک ٹریفک کو متعدد سرورز یا انسٹینسز میں تقسیم کرتی ہے۔

**Log Analytics**  
Azure کی سروس جو کلاؤڈ اور آن-پرائمائز ماحول سے ٹیلیمیٹری ڈیٹا کو جمع، تجزیہ، اور اس پر عمل کرنے کے لیے ہے۔

## M

**Managed Identity**  
Azure کا فیچر جو دیگر Azure سروسز کے لیے توثیق کے لیے خودکار طور پر مینج کی جانے والی شناخت فراہم کرتا ہے۔

**Microservices**  
فن تعمیراتی انداز جہاں ایپلیکیشنز کو چھوٹے، آزاد خدمات کے مجموعے کے طور پر بنایا جاتا ہے۔

**Monitor**  
Azure کا متحدہ مانیٹرنگ حل جو ایپلیکیشنز اور انفراسٹرکچر میں مکمل اسٹیک مشاہدہ فراہم کرتا ہے۔

## N

**Node.js**  
جاوا اسکرپٹ رن ٹائم جو Chrome کے V8 جاوا اسکرپٹ انجن پر مبنی ہے، سرور-سائیڈ ایپلیکیشنز بنانے کے لیے۔

**npm**  
Node.js کے لیے پیکیج مینیجر جو انحصارات اور پیکیجز کو مینیج کرتا ہے۔

## O

**Output**  
انفراسٹرکچر تعیناتی سے واپسی کی گئی ویلیوز جو ایپلیکیشنز یا دیگر وسائل کے ذریعے استعمال کی جا سکتی ہیں۔

## P

**Package**  
ایپلیکیشن کوڈ اور انحصارات کو تعیناتی کے لیے تیار کرنے کا عمل۔

**Parameters**  
انفراسٹرکچر ٹیمپلٹس کو دیے جانے والے ان پٹ ویلیوز تاکہ تعیناتیاں حسب ضرورت ہوں۔

**PostgreSQL**  
اوپن سورس ریلشنل ڈیٹا بیس سسٹم جو Azure میں منظم سروس کے طور پر سپورٹ کیا جاتا ہے۔

**Provisioning**  
انفراسٹرکچر ٹیمپلٹس میں تعریف کردہ Azure وسائل کو بنانے اور ترتیب دینے کا عمل۔

## Q

**Quota**  
وہ حدود جن کے تحت Azure سبسکرپشن یا خطے میں وسائل بنائے جا سکتے ہیں۔

## R

**Resource Group**  
Azure وسائل کا منطقی کنٹینر جو ایک جیسا لائف سائیکل، اجازتیں، اور پالیسیاں شیئر کرتا ہے۔

**Resource Token**  
azd کے ذریعہ تیار کردہ منفرد سٹرنگ جو تعیناتیوں کے دوران وسائل کے ناموں کی یکتائی کو یقینی بناتی ہے۔

**REST API**  
نیٹ ورکنڈ ایپلیکیشنز کے ڈیزائن کے لیے HTTP میتھڈز کا استعمال کرنے والا فن تعمیراتی انداز۔

**Rollback**  
ایک ایپلیکیشن یا انفراسٹرکچر کنفیگریشن کے پچھلے ورژن پر واپس جانے کا عمل۔

## S

**Service**  
آپ کی ایپلیکیشن کا وہ جزو جو azure.yaml میں تعریف کیا گیا ہو (مثلاً، ویب فرنٹ اینڈ، API بیک اینڈ، ڈیٹا بیس)۔

**SKU**  
اسٹاک کیپنگ یونٹ۔ Azure وسائل کے مختلف سروس درجے یا کارکردگی کی سطحوں کی نمائندگی کرتا ہے۔

**SQL Database**  
Azure کی منظم شدہ ریلشنل ڈیٹا بیس سروس جو Microsoft SQL Server پر مبنی ہے۔

**Static Web Apps**  
Azure کی سروس جو سورس کوڈ ریپوز سے فل اسٹیک ویب ایپلیکیشنز بنانے اور ڈپلائے کرنے کے لیے ہے۔

**Storage Account**  
Azure سروس جو بلیبز، فائلز، کیوز، اور ٹیبلز سمیت ڈیٹا آبجیکٹس کے لیے کلاؤڈ اسٹوریج فراہم کرتی ہے۔

**Subscription**  
Azure اکاؤنٹ کا کنٹینر جو ریسورس گروپس اور وسائل رکھتا ہے، جس کے ساتھ بلنگ اور رسائی مینجمنٹ جڑی ہوئی ہے۔

## T

**Template**  
پری-بلٹ پروجیکٹ ساخت جس میں ایپلیکیشن کوڈ، انفراسٹرکچر کی تعریفیں، اور عام منظرناموں کے لیے کنفیگریشن شامل ہو۔

**Terraform**  
اوپن سورس انفراسٹرکچر ایز کوڈ ٹول جو متعدد کلاؤڈ فراہم کنندگان بشمول Azure کی حمایت کرتا ہے۔

**Traffic Manager**  
Azure کا DNS پر مبنی ٹریفک لوڈ بیلینسر جو عالمی Azure خطوں میں ٹریفک تقسیم کرتا ہے۔

## U

**URI**  
یونیفارم ریسورس آئیڈینٹی فائر۔ ایک سٹرنگ جو کسی خاص وسیلہ کی شناخت کرتی ہے۔

**URL**  
یونیفارم ریسورس لوکیٹر۔ URI کی قسم جو بتاتی ہے کہ وسیلہ کہاں واقع ہے اور اسے کس طرح حاصل کیا جائے۔

## V

**Virtual Network (VNet)**  
Azure میں پرائیویٹ نیٹ ورکس کے لیے بنیادی تعمیراتی بلاک جو الگ تھلگ اور تقسیم فراہم کرتا ہے۔

**VS Code**  
Visual Studio Code۔ مقبول کوڈ ایڈیٹر جو Azure اور azd انٹیگریشن کے ساتھ آتا ہے۔

## W

**Webhook**  
HTTP کال بیک جو مخصوص ایونٹس پر متحرک ہوتا ہے، عام طور پر CI/CD پائپ لائنز میں استعمال ہوتا ہے۔

**What-if**  
Azure کا فیچر جو دیکھاتا ہے کہ تعیناتی سے کیا تبدیلیاں ہوں گی بغیر اسے حقیقت میں نافذ کیے۔

## Y

**YAML**  
YAML اینٹ مارک اپ لینگویج نہیں۔ انسانی پڑھنے کے قابل ڈیٹا سیریلائزیشن معیار جو azure.yaml جیسی کنفیگریشن فائلز کے لیے استعمال ہوتا ہے۔

## Z

**زون**  
Azure کے خطے میں جسمانی لحاظ سے الگ الگ مقامات جو ریڈنڈنسی اور اعلی دستیابی فراہم کرتے ہیں۔

## عام مخففات

| مخفف | مکمل شکل | وضاحت |
|---------|-----------|-------------|
| AAD | Azure Active Directory (اب Microsoft Entra ID) | شناخت اور رسائی مینجمنٹ سروس |
| ACR | Azure Container Registry | کنٹینر امیج رجسٹری سروس |
| AKS | Azure Kubernetes Service | منظم شدہ کوبرنیٹس سروس |
| API | Application Programming Interface | سافٹ ویئر بنانے کے پروٹوکولز کا مجموعہ |
| ARM | Azure Resource Manager | Azure کی تعیناتی اور انتظامی سروس |
| CDN | Content Delivery Network | سرورز کا تقسیم شدہ نیٹ ورک |
| CI/CD | Continuous Integration/Continuous Deployment | خودکار ترقیاتی طریقے |
| CLI | Command Line Interface | متن پر مبنی صارف انٹرفیس |
| DNS | Domain Name System | ڈومین ناموں کو IP پتوں میں ترجمہ کرنے کا نظام |
| HTTPS | Hypertext Transfer Protocol Secure | HTTP کا محفوظ ورژن |
| IaC | Infrastructure as Code | کوڈ کے ذریعے انفراسٹرکچر کا انتظام |
| JSON | JavaScript Object Notation | ڈیٹا انٹرچینج فارمیٹ |
| JWT | JSON Web Token | محفوظ معلومات کی ترسیل کے لیے ٹوکن فارمیٹ |
| KQL | Kusto Query Language | Azure ڈیٹا سروسز کے لیے کوئری زبان |
| RBAC | Role-Based Access Control | صارف کرداروں کی بنیاد پر رسائی کنٹرول کا طریقہ |

## مخصوص سیاق و سباق کی اصطلاحات

### ترقی کی اصطلاحات
- **Hot Reload**: ترقی کے دوران بلا تعطل ایپلیکیشن کی خودکار اپ ڈیٹ
- **Build Pipeline**: کوڈ بنانے اور جانچنے کا خودکار عمل
- **Deployment Slot**: App Service کے اندر اسٹجنگ ماحول
- **Environment Parity**: ترقی، اسٹجنگ، اور پروڈکشن ماحول کو ملتا جلتا رکھنا

### سیکیورٹی اصطلاحات
- **Managed Identity**: خودکار اسناد مینجمنٹ فراہم کرنے والا Azure فیچر
- **Key Vault**: سیکرٹس، چابیاں، اور سرٹیفکیٹس کے لیے محفوظ ذخیرہ
- **RBAC**: Azure وسائل کے لیے رول کی بنیاد پر رسائی کنٹرول
- **Network Security Group**: نیٹ ورک ٹریفک کنٹرول کے لیے ورچوئل فائر وال

### مانیٹرنگ اصطلاحات
- **Telemetry**: خودکار پیمائش اور ڈیٹا کا جمع کرنا
- **Application Performance Monitoring (APM)**: سافٹ ویئر کی کارکردگی کی نگرانی
- **Log Analytics**: لاگ ڈیٹا جمع کرنے اور تجزیہ کرنے کی سروس
- **Alert Rules**: میٹرکس یا شرائط کی بنیاد پر خودکار اطلاعات

### تعیناتی اصطلاحات
- **Blue-Green Deployment**: بغیر بندش کے تعیناتی کی حکمت عملی
- **Canary Deployment**: صارفین کے ایک حصے کو آہستہ آہستہ رول آؤٹ کرنا
- **Rolling Update**: ایپلیکیشن انسٹینسز کی تسلسل وار تبدیلی
- **Rollback**: ایپلیکیشن کے پچھلے ورژن پر واپس جانا

---

**استعمال کی ٹپ**: مخصوص اصطلاحات کو جلدی تلاش کرنے کے لیے `Ctrl+F` استعمال کریں۔ جہاں مناسب ہو اصطلاحات کے متقابل حوالہ جات موجود ہیں۔
