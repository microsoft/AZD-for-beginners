# مائیکروسروسز کی مثال

چلانے کے قابل عمل نفاذ اور اس کی ہدایات
**[container-app/microservices](../container-app/microservices/README.md)** میں موجود ہیں۔

یہ ڈائریکٹری صرف نیویگیشن کے لیے ہے۔ اس میں کوئی `azure.yaml`، `infra/`، یا `src/` نہیں ہے۔
یہاں `azd up` مت چلائیں۔

مخزن کی جڑ سے:

```bash
cd examples/container-app/microservices
```

اس کے بعد prerequisites، تعیناتی، تصدیق، مقامی
ترقی، عملی مشقیں، اخراجات، اور صفائی کے لئے منسلک README کو فالو کریں۔

نمونہ ایک Node.js API گیٹ وے اور ایک صرف پڑھنے کی Python پروڈکٹ سروس پر مشتمل ہے۔
آرڈر، صارف، اطلاع، ڈیٹا بیس، اور میسیجنگ خدمات توسیعی خیالات ہیں،
جو اس ریپوزیٹری میں شامل عملی نفاذ نہیں ہیں۔
