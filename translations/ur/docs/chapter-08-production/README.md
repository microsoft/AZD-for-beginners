# باب 8: پیداواری اور انٹرپرائز پیٹرنز

**📚 کورس**: [AZD برائے مبتدئین](../../README.md) | **⏱️ دورانیہ**: 2-3 گھنٹے | **⭐ پیچیدگی**: اعلیٰ

---

## جائزہ

یہ باب انٹرپرائز کے لیے تیار شدہ تعیناتی کے نمونے، سیکیورٹی کی مضبوطی، نگرانی، اور پیداواری AI کاموں کے لیے لاگت کی بہتری کا احاطہ کرتا ہے۔

یہ ایک تعمیراتی حوالہ ہے، مکمل تعیناتی والے پیداواری ٹیمپلیٹ نہیں۔ مثالیں انضمامی تفصیلات کو چھوڑ دیتی ہیں جو آپ کی اپنی ایپلیکیشن میں فراہم اور جانچی جانی چاہئیں؛ چیک لسٹ پڑھنا پیداواری تیاری کی تصدیق نہیں کرتا۔

> **ریلیز کا جائزہ (2026-11-04):** AI CLI گائیڈنس `azd 1.37.2`، ایجنٹس `1.0.0-beta.23`، اور جائزوں `1.0.0-beta.2` دستاویزات/ماخذ کے خلاف چیک کی گئی۔ مطابقت کی ضروریات اور مائیگریشن کی تفصیلات کے لیے [ریلیز تبدیلیاں اور اصلاحات](production-ai-practices.md#recent-release-changes-and-fixes) دیکھیں؛ یہ لائیو تعیناتی کی تصدیق نہیں ہے۔

## تعلیمی مقاصد

اس باب کو مکمل کرکے، آپ:
- کثیر خطوں میں مضبوط ایپلیکیشنز تعینات کریں گے
- انٹرپرائز سیکیورٹی پیٹرنز نافذ کریں گے
- جامع نگرانی ترتیب دیں گے
- پیمانے پر لاگت کی اصلاح کریں گے
- AZD کے ساتھ CI/CD پائپ لائنز قائم کریں گے

// Illustrative properties from different resources, NOT a standalone Bicep file.

  type: 'SystemAssigned'

properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }

## 💰 لاگت کی بہتری

| حکمت عملی | اہم پابندی |
|----------|---------|
| زیرو تک پیمانہ (کنٹینر ایپس) | ایک مناسب ٹریگر کی ضرورت؛ دیگر خدمات پر لاگت جاری رہتی ہے |
| ترقی کے لیے صارفیت درجات کا استعمال | منتخب شدہ خدمت کی قیمت اور کام کا موازنہ کریں |
| شیڈیول کردہ پیمانہ | معاونت شدہ بنیادی ڈھانچہ / خودکار کاری کے ذریعے پیمانہ بنائیں |
| ریزرویشن/پروویژنڈ صلاحیت | صرف جب معاون ہو؛ وعدے فارغ لاگت بڑھا سکتے ہیں |

درست آغاز تاریخ، بلنگ دائرہ کار، وصول کنندگان، اور اجازت ناموں کے ساتھ [مکمل بجٹ وسیلہ نمونہ](production-ai-practices.md#2-cost-monitoring-and-budgets) استعمال کریں۔ بجٹ الرٹس بھیجتا ہے؛ یہ خرچ کی حد مقرر نہیں کرتا۔ بچت ماپے گئے استعمال پر منحصر ہوتی ہے اور یہ ضمانتی فیصد نہیں ہوتی۔
