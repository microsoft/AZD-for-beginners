# باب 6: پیشگی تعیناتی کی منصوبہ بندی اور تصدیق

**📚 کورس**: [AZD فار بیگنرز](../../README.md) | **⏱️ دورانیہ**: 2-4 گھنٹے مطالعہ؛ ایڈاپٹڈ لیبز کے لیے اضافی وقت | **⭐ پیچیدگی**: درمیانی تا اعلی

---

## جائزہ

یہ باب آپ کی ایپلیکیشن کی تعیناتی سے قبل ضروری منصوبہ بندی اور تصدیقی مراحل کا احاطہ کرتا ہے۔ مناسب صلاحیت کی منصوبہ بندی، SKU کے انتخاب، اور پری فلائٹ چیکس کے ساتھ مہنگی غلطیوں سے بچنا سیکھیں۔

> کمانڈ کی رہنمائی جاری کردہ `azd 1.37.2` حوالہ کے خلاف جانچی گئی۔ کلاؤڈ تعیناتیاں عمل میں نہیں لائی گئیں۔ طویل درسوں میں مکمل مقامی تعیناتی منصوبے نہیں بلکہ تصویر کشی کے ٹکڑے شامل ہیں۔

## تعلیمی مقاصد

اس باب کو مکمل کر کے، آپ:
- تعیناتی سے قبل پری فلائٹ چیکس چلائیں گے
- صلاحیت کی منصوبہ بندی کریں گے اور وسائل کے تقاضے تخمینہ لگائیں گے
- لاگت کی بچت کے لیے مناسب SKUs کا انتخاب کریں گے
- مانیٹرنگ کے لیے ایپلیکیشن انسائٹس کو ترتیب دیں گے
- کثیر ایجنٹ کوآرڈینیشن کے نمونوں اور ان کی تعیناتی کی ضروریات کو سمجھیں گے

## 🚀 فوری آغاز

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ پیشگی تعیناتی چیک لسٹ

### پہلے `azd provision`

- [ ] خطے کے لیے کوٹہ کی تصدیق
- [ ] مناسب طریقے سے SKUs کا انتخاب
- [ ] لاگت کا تخمینہ جائزہ لیا گیا
- [ ] نام رکھنے کا طریقہ کار مستقل
- [ ] سیکورٹی/RBAC ترتیب دی گئی

### پہلے `azd deploy`

- [ ] ماحول کے متغیرات مرتب کیے گئے
- [ ] کی وॉलٹ میں سیکریٹس محفوظ
- [ ] کنکشن اسٹرنگز کی تصدیق
- [ ] صحت کی جانچ ترتیب دی گئی
