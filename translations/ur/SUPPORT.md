# مدد

## کورس کے مسائل اور سوالات

مسئلہ رپورٹ کرنے سے پہلے [کورس کے مسائل](https://github.com/microsoft/AZD-for-beginners/issues) تلاش کریں۔ متاثرہ انگریزی سبق، آپ نے چلائی ہوئی کمانڈ، آپ کے AZD/ایکسٹینشن ورژنز، اور ایرر پیغام شامل کریں۔ لاگز اور اسکرین شاٹس سے اسناد، ٹوکنز، سبسکرپشن کی تفصیلات، اور ذاتی معلومات ہٹا دیں۔

عمومی تعلیمی سوالات کے لیے، [Azure developer community](https://discord.gg/microsoft-azure) استعمال کریں۔ کمیونٹی کے جوابات ایک یقینی مدد کی خدمت نہیں ہیں۔

## ٹول اور سروس کے مسائل

AZD CLI کی قابلِ تکرا ہونے والی بگز کی رپورٹنگ [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) میں کریں۔ Azure سروس واقعات یا سبسکرپشن مخصوص مدد کے لیے، [Azure portal](https://portal.azure.com/) میں دستیاب سپورٹ آپشنز استعمال کریں۔

## سیکیورٹی رپورٹس

نجی کمزوری رپورٹنگ کے لیے [SECURITY.md](SECURITY.md) کی پیروی کریں۔ پبلک کورس مسئلہ میں راز یا استحصال کی تفصیلات پوسٹ نہ کریں۔

## Microsoft سپورٹ پالیسی

اس تعلیمی پروجیکٹ کی سپورٹ صرف اوپر درج وسائل تک محدود ہے۔ کورس کی مثالوں میں پیداواری سپورٹ کی یقین دہانی شامل نہیں ہے۔
