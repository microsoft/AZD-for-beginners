# AZD برائے AI ڈویلپرز ورکشاپ

Azure Developer CLI (AZD) سیکھنے کے لیے ہینڈز آن ورکشاپ میں خوش آمدید جس کا مرکز AI ایپلیکیشنز کی تعیناتی ہے۔ یہ ورکشاپ آپ کو AZD ٹیمپلیٹس کو 3 مراحل میں عملی سمجھ فراہم کرتی ہے:

1. **دریافت** - اپنے لیے درست ٹیمپلیٹ تلاش کریں۔
1. **تنصیب** - تعینات کریں اور اس کی کارکردگی کی تصدیق کریں۔
1. **حسب ضرورت سازی** - اپنی مرضی کے مطابق ترمیم کریں اور بار بار کریں!

اس ورکشاپ کے دوران آپ کو بنیادی ڈویلپر ٹولز اور ورک فلو سے بھی روشناس کرایا جائے گا، تاکہ آپ کے اختتامی نقطہ نظر کے ترقیاتی سفر کو ہموار کیا جا سکے۔

<br/>

## براؤزر پر مبنی رہنمائی

ورکشاپ کے اسباق مارک ڈاؤن میں ہیں۔ آپ انہیں براہ راست گٹ ہب پر نیویگیٹ کر سکتے ہیں - یا نیچے دی گئی اسکرین شاٹ میں دکھائے گئے براؤزر پر مبنی پریویو کو لانچ کریں۔

![ورکشاپ](../../../translated_images/ur/workshop.75906f133e6f8ba0.webp)

اس آپشن کو استعمال کرنے کے لیے - ریپوزیٹری کو اپنے پروفائل پر فورک کریں، اور GitHub Codespaces کو لانچ کریں۔ جب VS Code ٹرمینل فعال ہو، تو یہ کمانڈ لکھیں:

یہ براؤزر پریویو GitHub Codespaces، dev containers، یا Python اور MkDocs انسٹال کردہ مقامی کلون میں کام کرتا ہے۔

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

یہ کمانڈز **کورس ریپوزیٹری کی روٹ** سے چلائیں، نہ کہ الگ سے Initialized AI نمونے سے۔ پریویو کو سامنے رکھیں تاکہ غلطیاں واضح رہیں؛ Ctrl+C سے اسے بند کریں۔ سائٹ کو بغیر سرو کرنے کے چیک کرنے کے لیے `python -m mkdocs build --strict --config-file workshop/mkdocs.yml` چلائیں۔

چند سیکنڈ میں ایک پاپ اپ ڈائیلاگ ظاہر ہوگا۔ `Open in browser` آپشن منتخب کریں۔ ویب پر مبنی رہنمائی اب نئے براؤزر ٹیب میں کھلے گی۔ اس پریویو کے کچھ فائدے:

1. **ان بلٹ سرچ** - کی ورڈز یا اسباق جلدی تلاش کریں۔
1. **کاپی آئیکن** - کوڈ بلاکس پر ہوور کریں یہ آپشن دیکھنے کے لیے
1. **تھیم ٹوگل** - ڈارک اور لائٹ تھیمز کے درمیان سوئچ کریں
1. **مدد حاصل کریں** - فُوٹر میں ڈسکارڈ آئیکن پر کلک کریں!

## آپ کیا سیکھیں گے

AZD ٹیمپلیٹ کو ایک سیکھنے کی ریتھ لپیٹ کے طور پر سوچیں تاکہ Microsoft Foundry پر اختتامی نقطہ نظر کی ترقی کے مختلف صلاحیتوں اور ٹولز کو دریافت کیا جا سکے۔ اس ورکشاپ کے اختتام پر، آپ کو اس سیاق و سباق میں مختلف ٹولز اور تصورات کا ایک فطری احساس حاصل ہو جانا چاہیے۔

| تصور  | مقصد |
|:---|:---|
| **Azure Developer CLI** | ٹول کمانڈز اور ورک فلو کو سمجھیں |
| **AZD ٹیمپلیٹس**| پروجیکٹ کا ڈھانچہ اور کنفیگریشن سمجھیں |
| **Azure AI Agent**| Microsoft Foundry پروجیکٹ فراہم کریں اور تعینات کریں |
| **Azure AI Search**| ایجنٹس کے ساتھ کانٹیکسٹ انجینئرنگ کو فعال کریں |
| **مشاہدہ پذیری**| ٹریسنگ، مانیٹرنگ اور تجزیات دریافت کریں |
| **ریڈ ٹیمنگ**| مخالفانہ ٹیسٹنگ اور تخفیف دریافت کریں |

<br/>

## ورکشاپ کا ڈھانچہ

ورکشاپ کو اس طرح ترتیب دیا گیا ہے کہ آپ کو ٹیمپلیٹ کی دریافت، تعیناتی، تجزیہ اور حسب ضرورت کاری کے سفر پر لے جائے - جو سرکاری [Getting Started with AI Agents](https://github.com/Azure-Samples/get-started-with-ai-agents) سٹارٹر ٹیمپلیٹ پر مبنی ہے۔

### [ماڈیول 1: AI ٹیمپلیٹ منتخب کریں](docs/instructions/1-Select-AI-Template.md) (30 منٹ)

- AI ٹیمپلیٹس کیا ہیں؟
- AI ٹیمپلیٹس کہاں مل سکتے ہیں؟
- AI ایجنٹس کی تعمیر کیسے شروع کروں؟
- **لیب**: Codespaces یا dev container میں کوئیک اسٹارٹ

### [ماڈیول 2: AI ٹیمپلیٹ کی تصدیق کریں](docs/instructions/2-Validate-AI-Template.md) (30 منٹ)

- AI ٹیمپلیٹ کی ساخت کیا ہے؟
- AZD ترقیاتی ورک فلو کیا ہے؟
- AZD ترقی میں مدد کیسے حاصل کریں؟
- **لیب**: AI ایجنٹس ٹیمپلیٹ تعینات اور تصدیق کریں

### [ماڈیول 3: AI ٹیمپلیٹ کا تجزیہ کریں](docs/instructions/3-Deconstruct-AI-Template.md) (30 منٹ)

- اپنے ماحول کو `.azure/` میں تلاش کریں
- اپنے وسائل کی ترتیب کو `infra/` میں دیکھیں
- اپنے AZD کی ترتیب کو `azure.yaml`s میں دریافت کریں
- **لیب**: ماحول کے متغیرات میں تبدیلی کریں اور دوبارہ تعینات کریں

### [ماڈیول 4: AI ٹیمپلیٹ کو ترتیب دیں](docs/instructions/4-Configure-AI-Template.md) (30 منٹ)
- دریافت کریں: Retrieval Augmented Generation
- دریافت کریں: Agent Evaluation اور Red Teaming
- دریافت کریں: ٹریسنگ اور مانیٹرنگ
- **لیب**: AI ایجنٹ + مشاہدہ پذیری دریافت کریں

### [ماڈیول 5: AI ٹیمپلیٹ ذاتی بنائیں](docs/instructions/5-Customize-AI-Template.md) (30 منٹ)
- وضاحت کریں: PRD کے ساتھ منظرنامے کی ضروریات
- ترتیب دیں: AZD کے لیے ماحول کے متغیرات
- نفاذ کریں: اضافی کاموں کے لیے Lifecycle Hooks
- **لیب**: اپنے منظرنامے کے مطابق ٹیمپلیٹ کو ذاتی بنائیں

### [ماڈیول 6: انفراسٹرکچر ختم کریں](docs/instructions/6-Teardown-Infrastructure.md) (30 منٹ)
- جائزہ: AZD ٹیمپلیٹس کیا ہیں؟
- جائزہ: Azure Developer CLI کیوں استعمال کریں؟
- اگلے اقدامات: کوئی مختلف ٹیمپلیٹ آزمائیں!
- **لیب**: انفراسٹرکچر کو ڈی پروویزن کریں اور صفائی کریں
