# Microservices Beispiel

Die ausführbare Implementierung und ihre Anweisungen befinden sich in
**[container-app/microservices](../container-app/microservices/README.md)**.

Dieses Verzeichnis dient nur zur Navigation. Es enthält keine `azure.yaml`, `infra/` oder `src/`.
Führen Sie hier kein `azd up` aus.

Vom Stammverzeichnis des Repositories:

```bash
cd examples/container-app/microservices
```

Folgen Sie dann der verlinkten README für Voraussetzungen, Bereitstellung, Überprüfung, lokale
Entwicklung, praktische Übungen, Kosten und Bereinigung.

Das Beispiel enthält ein Node.js API Gateway und einen schreibgeschützten Python Product Service.
Bestell-, Benutzer-, Benachrichtigungs-, Datenbank- und Messaging-Dienste sind Erweiterungsideen,
keine in diesem Repository enthaltenen Implementierungen.

- [Nächstes: Datenbank-App](../../../../examples/database-app)
