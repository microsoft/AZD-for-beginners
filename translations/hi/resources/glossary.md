# शब्दावली - Azure और AZD शब्दावली

**सभी अध्यायों के लिए संदर्भ**
- **📚 कोर्स होम**: [AZD For Beginners](../README.md)
- **📖 मूल बातें सीखें**: [Chapter 1: AZD Basics](../docs/chapter-01-foundation/azd-basics.md)
- **🤖 AI शब्द**: [Chapter 2: AI-First Development](../docs/chapter-02-ai-development/microsoft-foundry-integration.md)

## परिचय

यह व्यापक शब्दावली Azure Developer CLI और Azure क्लाउड विकास में उपयोग किए जाने वाले शब्दों, अवधारणाओं और संक्षिप्ताक्षरों के लिए परिभाषाएं प्रदान करता है। तकनीकी दस्तावेज़ीकरण को समझने, समस्याओं का निवारण करने, और azd परियोजनाओं और Azure सेवाओं के बारे में प्रभावी ढंग से संवाद करने के लिए आवश्यक संदर्भ।

## सीखने के लक्ष्य

इस शब्दावली का उपयोग करके, आप:
- Azure Developer CLI की आवश्यक शब्दावली और अवधारणाओं को समझेंगे
- Azure क्लाउड विकास की शब्दावली और तकनीकी शब्दों में महारत हासिल करेंगे
- Infrastructure as Code और तैनाती से संबंधित शब्दावली का कुशलतापूर्वक संदर्भ लेंगे
- Azure सेवा नामों, संक्षिप्ताक्षरों, और उनके उद्देश्यों को समझेंगे
- समस्या निवारण और डिबगिंग शब्दावली की परिभाषाओं तक पहुँच प्राप्त करेंगे
- उन्नत Azure वास्तुकला और विकास अवधारणाओं को सीखेंगे

## सीखने के परिणाम

नियमित रूप से इस शब्दावली का संदर्भ लेकर, आप सक्षम होंगे:
- उचित Azure Developer CLI शब्दावली का उपयोग करके प्रभावी संवाद करना
- तकनीकी दस्तावेज़ और त्रुटि संदेशों को अधिक स्पष्टता से समझना
- Azure सेवाओं और अवधारणाओं को आत्मविश्वास से नेविगेट करना
- उचित तकनीकी शब्दावली का उपयोग करके समस्याओं का निवारण करना
- सही तकनीकी भाषा के साथ टीम चर्चाओं में योगदान देना
- अपने Azure क्लाउड विकास ज्ञान का व्यवस्थित विस्तार करना

## A

**ARM टेम्प्लेट**  
Azure Resource Manager टेम्प्लेट। JSON आधारित Infrastructure as Code प्रारूप जो Azure संसाधनों को घोषणात्मक रूप से परिभाषित और तैनात करता है।

**App Service**  
Azure का प्लेटफ़ॉर्म-एज़-ए-सर्विस (PaaS) समाधान जो वेब एप्लिकेशन, REST APIs, और मोबाइल बैकएंड को बुनियादी ढांचे के प्रबंधन के बिना होस्ट करता है।

**Application Insights**  
Azure की एप्लिकेशन प्रदर्शन निगरानी (APM) सेवा जो एप्लिकेशन प्रदर्शन, उपलब्धता, और उपयोग के गहरे अंतर्दृष्टि प्रदान करती है।

**Azure CLI**  
Azure संसाधनों के प्रबंधन के लिए कमांड-लाइन इंटरफ़ेस। यह AZD की पूरक है लेकिन इसका अलग लॉगिन होता है; मुख्य AZD प्रमाणीकरण `azd auth login` का उपयोग करता है।

**Azure Developer CLI (azd)**  
डेवलपर-केंद्रित कमांड-लाइन टूल जो टेम्प्लेट और Infrastructure as Code का उपयोग करके Azure पर एप्लिकेशन बनाने और तैनात करने की प्रक्रिया को तेज करता है।

**azure.yaml**  
azd परियोजना की मुख्य कॉन्फ़िगरेशन फ़ाइल जो सेवाओं, बुनियादी ढांचे, और तैनाती हुक्स को परिभाषित करती है।

**Azure Resource Manager (ARM)**  
Azure की तैनाती और प्रबंधन सेवा जो संसाधनों को बनाने, अपडेट करने, और हटाने के लिए एक प्रबंधन स्तर प्रदान करती है।

## B

**Bicep**  
Microsoft द्वारा विकसित एक डोमेन-विशिष्ट भाषा (DSL) जो Azure संसाधनों को तैनात करने के लिए उपयोग होती है। यह ARM टेम्प्लेट्स की तुलना में सरल सिंटैक्स प्रदान करता है जबकि ARM में संकलित होता है।

**Build**  
स्रोत कोड को संकलित करने, निर्भरता स्थापित करने, और तैनाती के लिए अनुप्रयोगों को तैयार करने की प्रक्रिया।

**Blue-Green Deployment**  
तैनाती रणनीति जो दो समान उत्पादन पर्यावरणों (नीला और हरा) का उपयोग करती है ताकि डाउनटाइम और जोखिम को कम किया जा सके।

## C

**Container Apps**  
Azure की सर्वरलेस कंटेनर सेवा जो जटिल बुनियादी ढांचे को प्रबंधित किए बिना कंटेनरयुक्त अनुप्रयोग चलाने में सक्षम बनाती है।

**CI/CD**  
Continuous Integration/Continuous Deployment। कोड परिवर्तनों को एकीकृत करने और अनुप्रयोग तैनात करने के स्वत: संशोधन अभ्यास।

**Cosmos DB**  
Azure की वैश्विक रूप से वितरित, मल्टी-मॉडल डेटाबेस सेवा जो थ्रूपुट, विलंबता, उपलब्धता, और निरंतरता के लिए व्यापक SLA प्रदान करती है।

**Configuration**  
सेटिंग्स और पैरामीटर जो एप्लिकेशन व्यवहार और तैनाती विकल्पों को नियंत्रित करते हैं।

## D

**Deployment**  
लक्षित बुनियादी ढांचे पर एप्लिकेशन और उनकी निर्भरताओं को स्थापित और कॉन्फ़िगर करने की प्रक्रिया।

**Docker**  
कंटेनरीकरण प्रौद्योगिकी का उपयोग करके अनुप्रयोगों को विकसित, शिप, और चलाने का प्लेटफ़ॉर्म।

**Dockerfile**  
Docker कंटेनर इमेज बिल्ड करने के लिए निर्देशों वाली टेक्स्ट फ़ाइल।

## E

**Environment**  
तैनाती का लक्षित स्थान जो आपके अनुप्रयोग के एक विशिष्ट उदाहरण (जैसे, विकास, स्टेजिंग, उत्पादन) का प्रतिनिधित्व करता है।

**Environment Variables**  
ऐसे विन्यास मान जो कुंजी-मूल्य जोड़े के रूप में संग्रहित होते हैं और जो अनुप्रयोग रनटाइम पर एक्सेस कर सकते हैं।

**Endpoint**  
URL या नेटवर्क पता जहां एक एप्लिकेशन या सेवा का उपयोग किया जा सकता है।

## F

**Function App**  
Azure की सर्वरलेस कंप्यूट सेवा जो बुनियादी ढांचे के प्रबंधन के बिना इवेंट-चालित कोड चलाने में सक्षम बनाती है।

## G

**GitHub Actions**  
GitHub रिपॉजिटरी से जुड़े CI/CD प्लेटफ़ॉर्म जो वर्कफ़्लोज़ को स्वचालित करता है।

**Git**  
एक वितरित संस्करण नियंत्रण प्रणाली जो स्रोत कोड में परिवर्तनों का ट्रैक रखती है।

## H

**Hooks**  
कस्टम स्क्रिप्ट या कमांड जो तैनाती लाइफसाइकल के विशिष्ट बिंदुओं (preprovision, postprovision, predeploy, postdeploy) पर चलते हैं।

**Host**  
वह Azure सेवा प्रकार जहां एक एप्लिकेशन तैनात होगा (जैसे, appservice, containerapp, function)।

## I

**Infrastructure as Code (IaC)**  
कोड के माध्यम से बुनियादी ढांचे को परिभाषित और प्रबंधित करने का अभ्यास, मैनुअल प्रक्रियाओं के बजाय।

**Init**  
एक नए azd प्रोजेक्ट को आरंभ करने की प्रक्रिया, आमतौर पर एक टेम्प्लेट से।

## J

**JSON**  
JavaScript Object Notation। कॉन्फ़िगरेशन फ़ाइलों और API प्रतिक्रियाओं के लिए सामान्य डेटा इंटरचेंज प्रारूप।

**JWT**  
JSON Web Token। पार्टियों के बीच सुरक्षित रूप से जानकारी भेजने का मानक JSON ऑब्जेक्ट के रूप में।

## K

**Key Vault**  
Azure की सेवा जो रहस्यों, कुंजियों और प्रमाणपत्रों को सुरक्षित रूप से संग्रहीत और प्रबंधित करती है।

**Kusto Query Language (KQL)**  
Azure Monitor, Application Insights, और अन्य Azure सेवाओं में डेटा विश्लेषण के लिए क्वेरी भाषा।

## L

**Load Balancer**  
सेवा जो आने वाले नेटवर्क ट्रैफ़िक को कई सर्वर या उदाहरणों में वितरित करती है।

**Log Analytics**  
Azure सेवा जो क्लाउड और ऑन-प्रिमाइसेस वातावरण से टेलीमेट्री डेटा एकत्रित, विश्लेषण, और क्रियान्वित करती है।

## M

**Managed Identity**  
Azure फीचर जो अन्य Azure सेवाओं के प्रमाणीकरण के लिए स्वचालित रूप से प्रबंधित पहचान प्रदान करता है।

**Microservices**  
वास्तुकला दृष्टिकोण जहां अनुप्रयोग छोटे, स्वतंत्र सेवाओं के संग्रह के रूप में बनते हैं।

**Monitor**  
Azure का एकीकृत निगरानी समाधान जो अनुप्रयोगों और बुनियादी ढांचे दोनों में पूर्ण स्टैक अवलोकन प्रदान करता है।

## N

**Node.js**  
Chrome के V8 JavaScript इंजन पर आधारित जावास्क्रिप्ट रनटाइम जो सर्वर-साइड एप्लिकेशन बनाने के लिए उपयोग किया जाता है।

**npm**  
Node.js के लिए पैकेज मैनेजर जो निर्भरताओं और पैकेजों का प्रबंधन करता है।

## O

**Output**  
बुनियादी ढांचे की तैनाती से लौटाए गए मान जो अनुप्रयोगों या अन्य संसाधनों द्वारा उपयोग किए जा सकते हैं।

## P

**Package**  
एप्लिकेशन कोड और निर्भरताओं को तैनाती के लिए तैयार करने की प्रक्रिया।

**Parameters**  
बुनियादी ढांचे के टेम्प्लेट्स में तैनाती को अनुकूलित करने के लिए पास किए गए इनपुट मान।

**PostgreSQL**  
ओपन-सोर्स रिलेशनल डेटाबेस सिस्टम जिसे Azure में प्रबंधित सेवा के रूप में समर्थित किया गया है।

**Provisioning**  
Azure संसाधनों को बनाना और कॉन्फ़िगर करना जो बुनियादी ढांचे के टेम्प्लेट्स में परिभाषित होते हैं।

## Q

**Quota**  
Azure सदस्यता या क्षेत्र में बनाए जा सकने वाले संसाधनों की मात्रा पर सीमाएँ।

## R

**Resource Group**  
Azure संसाधनों के लिए तार्किक कंटेनर जो समान जीवनचक्र, अनुमतियाँ, और नीतियों को साझा करता है।

**Resource Token**  
azd द्वारा उत्पन्न अद्वितीय स्ट्रिंग जो तैनातीओं में संसाधन नामों की विशिष्टता सुनिश्चित करता है।

**REST API**  
नेटवर्क आधारित अनुप्रयोगों को डिजाइन करने के लिए HTTP विधियों का उपयोग करने वाली वास्तुशिल्प शैली।

**Rollback**  
किसी एप्लिकेशन या बुनियादी ढांचे के कॉन्फ़िगरेशन के पिछले संस्करण पर लौटने की प्रक्रिया।

## S

**Service**  
आपका एप्लिकेशन का एक घटक जो azure.yaml में परिभाषित होता है (जैसे, वेब फ्रंटेंड, API बैकएंड, डेटाबेस)।

**SKU**  
स्टॉक कीपिंग यूनिट। Azure संसाधनों के लिए विभिन्न सेवा स्तर या प्रदर्शन स्तर का प्रतिनिधित्व करता है।

**SQL Database**  
Microsoft SQL Server पर आधारित Azure की प्रबंधित रिलेशनल डेटाबेस सेवा।

**Static Web Apps**  
स्रोत कोड रिपॉजिटरी से पूर्ण-स्टैक वेब एप्लिकेशन बनाने और तैनात करने के लिए Azure सेवा।

**Storage Account**  
क्लाउड स्टोरेज प्रदान करने वाली Azure सेवा जो ब्लॉब, फ़ाइलें, कतारें, और तालिकाएँ शामिल करती है।

**Subscription**  
Azure खाता कंटेनर जो संसाधन समूहों और संसाधनों को रखता है, साथ ही बिलिंग और एक्सेस प्रबंधन होता है।

## T

**Template**  
पहले से निर्मित परियोजना संरचना जो सामान्य परिदृश्यों के लिए एप्लिकेशन कोड, बुनियादी ढाँचा परिभाषाएं, और कॉन्फ़िगरेशन शामिल करती है।

**Terraform**  
ओपन-सोर्स Infrastructure as Code टूल जो Azure सहित कई क्लाउड प्रदाताओं का समर्थन करता है।

**Traffic Manager**  
Azure का DNS आधारित ट्रैफ़िक लोड बैलेंसर जो वैश्विक Azure क्षेत्रों में ट्रैफ़िक वितरित करता है।

## U

**URI**  
यूनिफ़ॉर्म रिसोर्स आइडेंटिफ़ायर। एक स्ट्रिंग जो किसी विशेष संसाधन की पहचान करती है।

**URL**  
यूनिफ़ॉर्म रिसोर्स लोकेटर। URI का एक प्रकार जो संसाधन का स्थान और प्राप्ति विधि निर्दिष्ट करता है।

## V

**Virtual Network (VNet)**  
Azure में निजी नेटवर्क के लिए मौलिक निर्माण खंड जो पृथक्करण और विभाजन प्रदान करता है।

**VS Code**  
Visual Studio Code। एक लोकप्रिय कोड संपादक जो उत्कृष्ट Azure और azd एकीकरण प्रदान करता है।

## W

**Webhook**  
HTTP कॉलबैक जो विशिष्ट घटनाओं द्वारा सक्रिय होता है, आमतौर पर CI/CD पाइपलाइनों में उपयोग किया जाता है।

**What-if**  
Azure का फीचर जो दिखाता है कि तैनाती द्वारा कौन-कौन से परिवर्तन किए जाएंगे बिना वास्तव में इसे निष्पादित किए।

## Y

**YAML**  
YAML Ain't Markup Language। मानव-पठनीय डेटा सीरियलाइज़ेशन मानक जो azure.yaml जैसी कॉन्फ़िगरेशन फ़ाइलों के लिए उपयोग होता है।

## Z

**Zone**

## Azure सेवा नाम मैपिंग

| सामान्य नाम | आधिकारिक Azure सेवा नाम | azd Host प्रकार |
|-------------|------------------------------|---------------|
| वेब एप | Azure App Service | `appservice` |
| API एप | Azure App Service | `appservice` |
| कंटेनर एप | Azure Container Apps | `containerapp` |
| फ़ंक्शन | Azure Functions | `function` |
| स्थैतिक साइट | Azure Static Web Apps | `staticwebapp` |
| डेटाबेस | Azure Database for PostgreSQL | आधारभूत संरचना संसाधन, एप्लिकेशन नहीं `host` |
| NoSQL डेटाबेस | Azure Cosmos DB | आधारभूत संरचना संसाधन, एप्लिकेशन नहीं `host` |
| संग्रहण | Azure Storage Account | आधारभूत संरचना संसाधन, अंतर्निर्मित एप्लिकेशन नहीं `host` |
| कैश | Azure Managed Redis | आधारभूत संरचना संसाधन, एप्लिकेशन नहीं `host` |
| खोज | Azure AI Search | आधारभूत संरचना संसाधन, एप्लिकेशन नहीं `host` |
| संदेश सेवा | Azure Service Bus | आधारभूत संरचना संसाधन, एप्लिकेशन नहीं `host` |

`services.<name>.host` एक एप्लिकेशन तैनाती लक्ष्य का चयन करता है; यह किसी Azure संसाधन प्रकार के लिए शॉर्टहैंड नहीं है। डेटाबेस, कैश, खोज सेवाएं, और कतारें सामान्यतः आधारभूत ढांचा प्रदाता के माध्यम से तैयार की जाती हैं और आउटपुट/कॉन्फ़िगरेशन के माध्यम से एप्लिकेशन से जुड़ी होती हैं।

## संदर्भ-विशिष्ट शब्द

### विकास शब्द
- **Hot Reload**: विकास के दौरान एप्लिकेशन को बिना पुनःप्रारंभ के स्वचालित रूप से अपडेट करना
- **Build Pipeline**: कोड निर्माण और परीक्षण के लिए स्वचालित प्रक्रिया
- **Deployment Slot**: App Service के भीतर स्टेजिंग वातावरण
- **Environment Parity**: विकास, स्टेजिंग, और उत्पादन वातावरण को समान बनाए रखना

### सुरक्षा शब्द
- **Managed Identity**: स्वचालित क्रेडेंशियल प्रबंधन प्रदान करने वाला Azure फीचर
- **Key Vault**: रहस्यों, कुंजियों, और प्रमाणपत्रों के लिए सुरक्षित भंडारण
- **RBAC**: Azure संसाधनों के लिए भूमिका-आधारित एक्सेस नियंत्रण
- **Network Security Group**: नेटवर्क ट्रैफ़िक नियंत्रण के लिए वर्चुअल फ़ायरवॉल

### निगरानी शब्द
- **Telemetry**: माप और डेटा का स्वचालित संग्रह
- **Application Performance Monitoring (APM)**: सॉफ़्टवेयर प्रदर्शन की निगरानी
- **Log Analytics**: लॉग डेटा को इकट्ठा करने और विश्लेषण के लिए सेवा
- **Alert Rules**: मेट्रिक्स या शर्तों के आधार पर स्वचालित सूचनाएं

### तैनाती शब्द
- **Blue-Green Deployment**: शून्य डाउनटाइम तैनाती रणनीति
- **Canary Deployment**: उपयोगकर्ताओं के एक उपसमूह को धीरे-धीरे रोलआउट करना
- **Rolling Update**: एप्लिकेशन उदाहरणों का क्रमिक प्रतिस्थापन
- **Rollback**: पिछले एप्लिकेशन संस्करण पर लौटना
