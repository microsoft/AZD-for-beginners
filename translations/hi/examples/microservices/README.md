# माइक्रोसर्विसेज़ उदाहरण

चलाने योग्य कार्यान्वयन और इसके निर्देश
**[container-app/microservices](../container-app/microservices/README.md)** में हैं।

यह निर्देशिका केवल नेविगेशन के लिए है। इसमें कोई `azure.yaml`, `infra/`, या `src/` नहीं है।
यहां `azd up` न चलाएं।

रिपॉजिटरी की मूल से:

```bash
cd examples/container-app/microservices
```

फिर लिंक किए गए README का पालन करें जिसमें आवश्यकताएं, परिनियोजन, सत्यापन, स्थानीय
विकास, व्यावहारिक अभ्यास, लागत, और सफाई शामिल हैं।

नमूने में एक Node.js API गेटवे और एक केवल-पढ़ने योग्य Python प्रोडक्ट सेवा शामिल है।
ऑर्डर, उपयोगकर्ता, अधिसूचना, डेटाबेस, और मैसेजिंग सेवाएँ विस्तार विचार हैं,
जो इस रिपॉजिटरी में शामिल कार्यान्वयन नहीं हैं।

- [अगला: डेटाबेस ऐप](../../../../examples/database-app)
- [AI विकास](../../docs/chapter-02-ai-development/README.md)
- [कोर्स होम](../../README.md)
