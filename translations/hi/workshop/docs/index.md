# AI डेवलपर्स के लिए AZD कार्यशाला

> स्रोत मार्गदर्शन 4 नवंबर, 2026 को AZD 1.37.2 के खिलाफ समीक्षा किया गया। स्क्रीनशॉट उदाहरणात्मक हैं; सेवा उपलब्धता, पोर्टल लेबल, और टेम्पलेट डिफ़ॉल्ट बदल सकते हैं।

> [!IMPORTANT]  
> **यह कार्यशाला एक कार्यशाला गाइड के साथ संलग्न है जिसे आप अपने स्थानीय ब्राउज़र में पूर्वावलोकन कर सकते हैं। शुरू करने के लिए, रिपॉजिटरी को GitHub Codespaces, एक डेव कंटेनर, या MkDocs इंस्टॉल के साथ स्थानीय क्लोन में खोलें—फिर तब तक प्रतीक्षा करें जब तक सक्रिय VS Code टर्मिनल न दिखे और टाइप करें:**  
> कोर्स रिपॉजिटरी रूट से, `requirements-dev.txt` स्थापित करें, फिर फ्रंटग्राउंड में `python -m mkdocs serve --config-file workshop/mkdocs.yml` चलाएं।
> **आपको ब्राउज़र में पूर्वावलोकन पृष्ठ खोलने का एक पॉप-अप संवाद दिखाई देना चाहिए।**

Azure डेवलपर CLI (AZD) सीखने के लिए AI एप्लिकेशन डिप्लॉयमेंट पर केन्द्रित यह व्यावहारिक कार्यशाला में आपका स्वागत है। यह कार्यशाला आपको AZD टेम्पलेट्स की समझ तीन चरणों में प्रदान करती है:

1. **खोज** - आपके लिए सही टेम्पलेट खोजें।
1. **डिप्लॉयमेंट** - इसे डिप्लॉय करें और सत्यापित करें कि यह काम करता है
1. **अनुकूलन** - इसे संशोधित करें और इसे अपना बनाएं!

इस कार्यशाला के दौरान, आप कोर डेवलपर टूल्स और वर्कफ़्लोज़ से भी परिचित होंगे, जो आपकी एंड-टू-एंड डेवलपमेंट यात्रा को सुव्यवस्थित करने में मदद करेंगे।

## कार्यशाला अवलोकन

**समय:** 3-4 घंटे  
**स्तर:** शुरुआती से मध्यवर्ती  
**पूर्वापेक्षाएँ:** Azure, AI अवधारणाओं, VS Code और कमांड-लाइन टूल्स से परिचित होना।

यह एक व्यावहारिक कार्यशाला है जहाँ आप सीखते हुए करते हैं। व्यायामों को पूरा करने के बाद, हम अनुशंसा करते हैं कि आप AZD फॉर बिगिनर्स पाठ्यक्रम की समीक्षा करें ताकि सुरक्षा और उत्पादकता सर्वोत्तम प्रथाओं की आपकी सीख जारी रहे।

| समय| मॉड्यूल  | उद्देश्य |
|:---|:---|:---|
| 15 मिनट | परिचय | मंच तैयार करें, लक्ष्य समझें |
| 30 मिनट | AI टेम्पलेट चुनें | विकल्पों का अन्वेषण करें और प्रारंभ करें | 
| 30 मिनट | AI टेम्पलेट सत्यापित करें | डिफ़ॉल्ट समाधान Azure में डिप्लॉय करें |
| 30 मिनट | AI टेम्पलेट का विघटन करें | संरचना और कॉन्फ़िगरेशन का अन्वेषण करें |
| 30 मिनट | AI टेम्पलेट कॉन्फ़िगर करें | उपलब्ध विशेषताओं को सक्रिय करें और प्रयास करें |
| 30 मिनट | AI टेम्पलेट कस्टमाइज़ करें | टेम्पलेट को अपनी आवश्यकताओं के अनुसार अनुकूलित करें |
| 30 मिनट | अवसंरचना समाप्त करें | संसाधनों की सफाई और विमोचन करें |
| 15 मिनट | समापन और अगले कदम | सीखने के संसाधन, कार्यशाला चुनौती |
| | |

## आप क्या सीखेंगे

AZD टेम्पलेट को एक सीखने वाले सैंडबॉक्स के रूप में सोचें जहाँ आप Microsoft Foundry पर एंड-टू-एंड विकास के लिए विभिन्न क्षमताओं और उपकरणों का अन्वेषण कर सकें। इस कार्यशाला के अंत तक, आपको इस संदर्भ में विभिन्न टूल और अवधारणाओं का सहज ज्ञान हो जाएगा।

| अवधारणा  | उद्देश्य |
|:---|:---|
| **Azure Developer CLI** | उपकरण आदेश और वर्कफ़्लोज़ को समझें|
| **AZD टेम्पलेट्स**| परियोजना संरचना और कॉन्फ़िगरेशन समझें|
| **Azure AI एजेंट**| Microsoft Foundry परियोजना की प्रोविजनिंग और डिप्लॉयमेंट  |
| **Azure AI Search**| एजेंट्स के साथ संदर्भ इंजीनियरिंग सक्षम करें |
| **ऑब्ज़र्वेबिलिटी**| ट्रेसिंग, मॉनिटरिंग और मूल्यांकन का अन्वेषण करें |
| **रेड टीमिंग**| विरोधी परीक्षण और निवारण का अन्वेषण करें |
| | |
