**📚 कोर्स**: [आरंभ करने वालों के लिए AZD](../../README.md) | **⏱️ अवधि**: पहला परिनियोजन सहित 75-120 मिनट; अतिरिक्त अभ्यास में अधिक समय लगता है | **⭐ जटिलता**: शुरुआती

## अवलोकन

इस अध्याय में Azure Developer CLI (azd) के मूल सिद्धांतों का परिचय दिया गया है। आप मुख्य अवधारणाएं सीखेंगे, टूल्स इंस्टॉल करेंगे, और अपना पहला एप्लिकेशन Azure पर परिनियोजित करेंगे।

> कमांड और कॉन्फ़िगरेशन समीक्षा लक्ष्य: `azd 1.37.2` (नवंबर 2026)। समीक्षा के दौरान लाइव Azure प्रावधान नहीं चलाया गया।

## सीखने के उद्देश्य

इस अध्याय को पूरा करके, आप:
- समझेंगे कि Azure Developer CLI क्या है और यह Azure CLI से कैसे भिन्न है
- अपने प्लेटफ़ॉर्म पर AZD इंस्टॉल और कॉन्फ़िगर करना सीखेंगे
- अपने पहले एप्लिकेशन को Azure पर `azd up` के साथ परिनियोजित करेंगे
- `azd down` के साथ संसाधनों की सफाई करेंगे

## ✅ यहाँ से शुरू करें: अपनी सेटअप मान्य करें

शुरू करने से पहले, पुष्टि करें कि आपकी स्थानीय मशीन अध्याय 1 टेम्प्लेट के लिए तैयार है:

**विंडोज़:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

यदि स्क्रिप्ट कोई टूल्स गायब दिखाए, तो पहले उन्हें ठीक करें और फिर अध्याय जारी रखें।

---

## 🚀 त्वरित प्रारंभ

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ सफलता मानदंड

इस अध्याय को पूरा करने के बाद, आप सक्षम होंगे:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
