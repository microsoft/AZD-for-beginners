## 2. Kľúčové pojmy, ktoré ste si osvojili

### Azure Developer CLI (azd)
- `azd init` - Inicializácia projektov zo šablón
- `azd up` - Provisionovanie a nasadzovanie jedným príkazom
- `azd env` - Správa premenných prostredia
- `azd down` - Bezpečné čistenie zdrojov

### Štruktúra šablóny AZD
- `azure.yaml` - Konfigurácia a háčiky nasadzovania
- `infra/` - Bicep infraštruktúra ako kód
- `src/` - Zdrojový kód aplikácie
- `scripts/` - Skripty automatizácie a nastavenia

### Schopnosti Microsoft Foundry
- AI Agent Service pre inteligentných asistentov
- Vyhľadávanie súborov a Azure AI Search pre získavanie znalostí
- Vstavané sledovanie, monitorovanie a hodnotenie
- Red teaming pre overenie bezpečnosti AI
