# Príklad mikroservis

Spustiteľná implementácia a jej inštrukcie sú v
**[container-app/microservices](../container-app/microservices/README.md)**.

Tento priečinok slúži len na navigáciu. Neobsahuje `azure.yaml`, `infra/` ani `src/`.
Neťažte `azd up` tu.

Z koreňa repozitára:

```bash
cd examples/container-app/microservices
```

Potom postupujte podľa odkazovaného README pre požiadavky, nasadenie, overenie, lokálny
vývoj, praktické cvičenia, náklady a vyčistenie.

Vzorka obsahuje API Gateway v Node.js a len na čítanie Python Product Service.
Služby objednávok, používateľov, notifikácií, databázy a správ sú nápady na rozšírenie,
nie implementácie zahrnuté v tomto repozitári.

- [Predošlé: Jednoduché Flask API](../../../../examples/container-app/simple-flask-api)
- [Ďalšie: Databázová aplikácia](../../../../examples/database-app)
- [AI vývoj](../../docs/chapter-02-ai-development/README.md)
- [Domovská stránka kurzu](../../README.md)
