# פרק 6: תכנון ואימות לפני הפריסה

**📚 קורס**: [AZD למתחילים](../../README.md) | **⏱️ זמן**: 2-4 שעות קריאה; זמן נוסף למעבדות מותאמות | **⭐ מורכבות**: בינוני–מתקדם

---

## סקירה כללית

פרק זה מכסה את הצעדים החיוניים לתכנון ואימות לפני פריסת היישום שלך. למד כיצד להימנע מטעויות יקרות עם תכנון קיבולת נכון, בחירת SKU ובדיקות מקדימות.

> הנחיות הפקודה נסקרו לעומת `azd 1.37.2` שפורסמה. פריסות ענן לא בוצעו. השיעורים הארוכים כוללים קטעים מאירים, לא פרויקטים מלאים לפריסה מקומית.

## יעדי הלמידה

בסיום פרק זה, תוכלו:
- לבצע בדיקות מקדימות לפני הפריסה
- לתכנן קיבולת ולהעריך דרישות משאבים
- לבחור SKU מתאימים לאופטימיזציית עלויות
- לקנפג את Application Insights למעקב
- להבין דפוסי תיאום מרובי סוכנים ודרישות הפריסה שלהם

## 🚀 התחלה מהירה

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ רשימת בדיקה לפני פריסה

### לפני `azd provision`

- [ ] אימות מכסת משאבים לאזור
- [ ] בחירת SKU בהתאם
- [ ] סקירת הערכת עלויות
- [ ] עקביות בשמות
- [ ] אבטחה/RBAC מוגדרת

### לפני `azd deploy`

- [ ] משתני סביבה מוגדרים
- [ ] סודות ב-Key Vault
- [ ] אימות מחרוזות חיבור
- [ ] הגדרת בדיקות בריאות

## 💰 מדריך לבחירת SKU

| עומס עבודה | פיתוח | ייצור |
|----------|-------------|------------|
| Container Apps | צריכה | צריכה או פרופיל עומס עבודה ייעודי, בהתאם לעומס הנמדד |
| App Service | B1/B2 | P1v3+ |
| דגמי Azure OpenAI | סוג פריסה בתשלום לפי שימוש נתמך | תשלום לפי שימוש או תעבורה מוקדמת; תלוי בדגם/אזור |
| AI Search | חינם/בסיסי במסגרת המגבלות | בסיסי או סטנדרטי במידות אינדקס, שכפולים ועומס שאילתות |
