# סדנת AZD למפתחים בינה מלאכותית

> ההדרכה מבוססת על גרסת AZD 1.37.2 מ-4 בנובמבר 2026. צילומי המסך להמחשה בלבד; זמינות השירות, תוויות הפורטל, ותבניות ברירת המחדל עלולות להשתנות.

> [!IMPORTANT]  
> **סדנה זו מצוידת במדריך סדנה שניתן לצפות בו בדפדפן המקומי שלך. כדי להתחיל, פתח את המאגר ב-GitHub Codespaces, מיכל פיתוח, או clone מקומי עם MkDocs מותקן — ואז המתן עד שתראה טרמינל VS Code פעיל והקלד:**  
> משורש המאגר, התקן את `requirements-dev.txt`, לאחר מכן הפעל את `python -m mkdocs serve --config-file workshop/mkdocs.yml` בחזית.
> **עליך לראות חלון קופץ לפתיחת דף התצוגה המקדימה בדפדפן.**

ברוכים הבאים לסדנה מעשית ללמידת Azure Developer CLI (AZD) עם דגש על פריסת יישומי AI. סדנה זו תעזור לכם להבין באופן יישומי את תבניות AZD ב-3 שלבים:

1. **גילוי** - מצא את התבנית המתאימה לך.
1. **פריסה** - פרוס ואמת שהיא פועלת
1. **התאמה אישית** - שנה וחזור על מנת להפוך אותה לשלך!

במהלך הסדנה תחשפו גם לכלי מפתח מרכזיים וזרימות עבודה, כדי לסייע לכם לייעל את תהליך הפיתוח מקצה לקצה.

## סקירת הסדנה

**משך:** 3-4 שעות  
**רמה:** מתחיל עד בינוני  
**דרישות מוקדמות:** היכרות עם Azure, מושגי AI, VS Code וכלי שורת פקודה.

זוהי סדנה מעשית שבה לומדים באמצעות עשייה. לאחר שתשלים את התרגילים, אנו ממליצים לעבור על תוכנית הלימודים של AZD למתחילים כדי להמשיך את מסע הלמידה שלך לביטחון ושיטות עבודה מיטביות.

| זמן | מודול  | מטרה |
|:---|:---|:---|
| 15 דקות | מבוא | לקבוע את המסגרת, להבין את היעדים |
| 30 דקות | בחירת תבנית AI | בחינת אפשרויות ובחירת התחלה | 
| 30 דקות | אימות תבנית AI | לפרוס את הפתרון ברירת המחדל ב-Azure |
| 30 דקות | פירוק תבנית AI | לחקור מבנה וקונפיגורציה |
| 30 דקות | קונפיגורציית תבנית AI | להפעיל ולנסות תכונות זמינות |
| 30 דקות | התאמת תבנית AI | להתאים את התבנית לצרכיך |
| 30 דקות | פירוק תשתית | ניקוי ושחרור משאבים |
| 15 דקות | סיכום והצעדים הבאים | משאבי למידה, אתגר הסדנה |
| | |

## מה תלמדו

חשוב לראות את תבנית ה-AZD כחצר משחק ללמידה ולחקור יכולות וכלים שונים לפיתוח מקצה לקצה על Microsoft Foundry. בסיום הסדנה, אמורה להיות לך הבנה אינטואיטיבית של כלים ומושגים בהקשר זה.

| מושג  | מטרה |
|:---|:---|
| **Azure Developer CLI** | להבין פקודות וזרימות עבודה של כלי |
| **תבניות AZD**| להבין מבנה פרויקט וקונפיגורציה|
| **Azure AI Agent**| לפרוס ולהפעיל פרויקט Microsoft Foundry  |
| **Azure AI Search**| לאפשר מהנדס הקשר באמצעות סוכנים |
| **תצפית**| לחקור מעקב, ניטור והערכות |
| **Red Teaming**| לחקור בדיקות אגרסיביות והפחתות סיכון |
| | |
