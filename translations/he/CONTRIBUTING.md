# תרומה ל-AZD למתחילים

תודה על ההתעניינות שלך בתרומה לקורס AZD למתחילים! מסמך זה מספק קווים מנחים ומידע לתורמים.

## איך לתרום

### דיווח על בעיות

אם מצאת באגים, שגיאות, או שיש לך הצעות לשיפור:

1. **בדוק בעיות קיימות**: חפש [בעיות קיימות](https://github.com/microsoft/azd-for-beginners/issues) כדי להימנע מכפילויות
2. **צור בעיה חדשה**: השתמש בתבנית הבעיה המתאימה
3. **ספק פרטים**: כלול צעדים לשחזור הבעיה, התנהגות צפויה, וצילומי מסך אם יש

### הצעת שינויים

1. **צור Fork של המאגר**: צור Fork משלך של הפרויקט
2. **צור סניף**: צור סניף תכונה לשינויים שלך
3. **בצע שינויים**: עקוב אחר תקני הקוד והתיעוד שלנו
4. **בדוק את השינויים שלך**: ודא שכל הקישורים פועלים והתוכן מוצג כראוי
5. **שלח Pull Request**: ספק תיאור ברור של השינויים שלך

### סוגי תרומות

אנו מקבלים בברכה את סוגי התרומות הבאים:

#### שיפורי תוכן
- תיקון שגיאות כתיב, דקדוק ובעיות עיצוב
- שיפור בהירות התיעוד הקיים
- עדכון מידע מיושן
- הוספת הסברים או הקשרים חסרים

#### דוגמאות חדשות
- הוספת תרחישי פריסה מעשיים
- יצירת תבניות AZD חדשות לשימושים נפוצים
- מתן דוגמאות קוד ותרגילים נוספים

#### תמיכה בתרגום
- סיוע בתחזוקת תרגומים קיימים
- שיפור איכות התרגום
- הוספת תרגומים לתוכן חדש

#### דיווח על באגים
- דיווח על קישורים שבורים או דוגמאות קוד שגויות
- זיהוי אי-התאמות בתיעוד
- סימון בעיות נגישות

## קווים מנחים לתרומה

### תקני תיעוד

- השתמש בשפה ברורה וידידותית למתחילים
- כלול מטרות למידה ותוצאות צפויות
- ספק הוראות שלב אחר שלב עם תוצאות צפויות
- הוסף קישורים לניווט לתוכן קשור
- השתמש בעיצוב עקבי וסגנון markdown אחיד

### דוגמאות קוד

- ודא שכל דוגמאות הקוד נבדקו ופועלות
- כלול הערות המסבירות מושגים מרכזיים
- פעל לפי שיטות עבודה מומלצות של Azure ו-AZD
- ספק פלט צפוי במידת הצורך

### אימות תיעוד באנגלית

משורש המאגר, התקן את דרישות הפיתוח הקיימות והרץ:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

בודק הקישורים האופליין בודק נתיבים ב-Markdown/HTML באנגלית, כותרות, עוגנים מפורשים, ומחזיקי קישור ריקים. הוא מפספס `translations/` ו-`translated_images/` שנוצרים, כולל קישורים אל אותם תיקיות. הוא לא מושך אתרי אינטרנט חיצוניים או מאמת פריסות Azure. השתמש ב-`--json <report-path>` לייצא תקלות ומלאי URL חיצוני לבדיקה רשתית נפרדת. אמת פקודות נוכחיות ודרישות מדגמיות כשמשנים הוראות טכניות; הבחין בין יישומים שנבדקו לתכניות עיצוב.
