# דוגמה למיקרוסרוויסים

המימוש הרץ וההוראות שלו נמצאים ב-
**[container-app/microservices](../container-app/microservices/README.md)**.

תיקייה זו היא רק לניווט. אין בה `azure.yaml`, `infra/`, או `src/`.
אל תריץ `azd up` כאן.

משורש המאגר:

```bash
cd examples/container-app/microservices
```

לאחר מכן עקוב אחרי ה-README המקושר עבור דרישות מוקדמות, פריסה, אימות, פיתוח מקומי,
תרגילים מעשיים, עלויות וניקוי.

הדוגמה כוללת שער API ב-Node.js ושירות מוצר לקריאה בלבד ב-Python.
שירותי הזמנה, משתמש, התראה, מסד נתונים והודעות הם רעיונות להרחבה,
אינם מימושים הכלולים במאגר זה.

- [קודם: Simple Flask API](../../../../examples/container-app/simple-flask-api)
- [הבא: אפליקציית מסד נתונים](../../../../examples/database-app)
- [פיתוח בינה מלאכותית](../../docs/chapter-02-ai-development/README.md)
- [דף הבית של הקורס](../../README.md)
