## הקדמה

מילון מונחים מקיף זה מספק הגדרות למונחים, מושגים וקיצורים המשמשים ב-Azure Developer CLI ובפיתוח בענן Azure. מונח חיוני להבנת תיעוד טכני, פתרון בעיות ותקשורת יעילה על פרויקטי azd ושירותי Azure.

## יעדי למידה

באמצעות מילון מונחים זה, תלמדו:
- להבין מונחים ומושגים חשובים של Azure Developer CLI
- לשלוט באוצר מילים טכני של פיתוח בענן Azure
- להפנות מונחים בתשתית כקוד ובהתפרסות בצורה יעילה
- להבין שמות שירותי Azure, קיצורים ומטרותיהם
- לגשת להגדרות למונחים לפתרון בעיות ודיבוג
- ללמוד מושגים מתקדמים של ארכיטקטורת Azure ופיתוח

## תוצאות למידה

עם הפניה סדירה למילון מונחים זה, תוכלו:
- לתקשר ביעילות באמצעות מונחים נכונים של Azure Developer CLI
- להבין טוב יותר תיעוד טכני והודעות שגיאה
- לנהל שירותי Azure ומושגים בביטחון
- לפתור בעיות באמצעות אוצר מילים טכני מתאים
- לתרום לדיונים צוותיים בשפה טכנית מדויקת
- להרחיב את הידע שלכם בפיתוח בענן Azure בצורה שיטתית

## א

**תבנית ARM**  
תבנית Azure Resource Manager. פורמט Infrastructure as Code מבוסס JSON המשמש להגדרה ולהתפרסות דקלרטיבית של משאבי Azure.

**שירות אפליקציות**  
הצעת פלטפורמה כשירות (PaaS) של Azure לאירוח אפליקציות ווב, ממשקי REST ו-backends לנייד ללא ניהול תשתית.

**Application Insights**  
שירות ניטור ביצועי אפליקציה (APM) של Azure המספק תובנות מעמיקות על ביצועי האפליקציה, זמינות ושימוש.

**Azure CLI**  
ממשק שורת פקודה לניהול משאבי Azure. משלים את AZD אך דורש התחברות נפרדת; אימות הליבה של AZD משתמש ב`azd auth login`.

**Azure Developer CLI (azd)**  
כלי שורת פקודה מכוון למפתחים המאיץ את תהליך בנייה והתפרסות האפליקציות ל-Azure באמצעות תבניות ו-Infrastructure as Code.

**azure.yaml**  
קובץ התצורה הראשי לפרויקט azd המגדיר שירותים, תשתית ו-hooks להתפרסות.

**Azure Resource Manager (ARM)**  
שירות פריסה וניהול של Azure המספק שכבת ניהול ליצירה, עדכון ומחיקה של משאבים.

## ב

**Bicep**  
שפת תחום ספציפית (DSL) שפותחה על ידי מיקרוסופט לפריסת משאבי Azure. מספקת תחביר פשוט יותר מתבניות ARM תוך קומפילציה ל-ARM.

**בנייה (Build)**  
תהליך של הידור קוד מקור, התקנת תלותים והכנת אפליקציות לפריסה.

**פריסת Blue-Green**  
אסטרטגיית פריסה המשתמשת בשני סביבות ייצור זהות (כחולה וירוקה) כדי למזער זמן השבתה וסיכון.

## ג

**אפליקציות מכולה (Container Apps)**  
שירות מכולות ללא שרת של Azure המאפשר הרצת אפליקציות מוכלות ללא ניהול תשתית מורכבת.

**CI/CD**  
אינטגרציה מתמשכת / פריסה מתמשכת. פרקטיקות אוטומטיות לשילוב שינויים בקוד ולהתפרסות אפליקציות.

**Cosmos DB**  
שירות מסד נתונים רב-מודלי, גלובלי ומופץ של Azure המציע SLA מקיף ל-Throughput, להשהיה, לזמינות ולעקביות.

**תצורה**  
הגדרות ופרמטרים השולטים בהתנהגות האפליקציה ובאפשרויות הפריסה.

## ד

**פריסה**  
תהליך התקנה והגדרה של אפליקציות ותלותיהן על תשתית היעד.

**Docker**  
פלטפורמה לפיתוח, משלוח והרצת אפליקציות באמצעות טכנולוגיית מכולות.

**Dockerfile**  
קובץ טקסט המכיל הוראות לבניית תמונת מכולת Docker.

## ה

**סביבה**  
יעד פריסה המייצג מופע ספציפי של האפליקציה שלך (למשל, פיתוח, בדיקה, ייצור).

**משתני סביבה**  
ערכי תצורה המאוחסנים כזוגות מפתח-ערך שניתן לגשת אליהם בזמן ריצה.

**נקודת קצה (Endpoint)**  
כתובת URL או כתובת רשת בה ניתן לגשת לאפליקציה או לשירות.

## פ

**אפליקציית פונקציות (Function App)**  
שירות מחשוב ללא שרת של Azure המאפשר הרצת קוד מונחה אירועים ללא ניהול תשתית.

## ך

**GitHub Actions**  
פלטפורמת CI/CD המשולבת עם מאגרי GitHub לאוטומציה של תהליכי עבודה.

**Git**  
מערכת ניהול גרסאות מבוזרת המשמשת למעקב אחר שינויים בקוד מקור.

## ח

**Hooks**  
סקריפטים מותאמים אישית או פקודות שמתבצעות בנקודות ספציפיות במחזור הפריסה (כגון preprovision, postprovision, predeploy, postdeploy).

**מארח (Host)**  
סוג שירות Azure שבו תתפרס האפליקציה (למשל, appservice, containerapp, function).

## י

**תשתית כקוד (Infrastructure as Code - IaC)**  
פרקטיקה של הגדרה וניהול תשתית באמצעות קוד במקום תהליכים ידניים.

**Init**  
תהליך התחלת פרויקט azd חדש, לרוב מתוך תבנית.

## כ

**JSON**  
סמל אובייקטים של JavaScript. פורמט חילופי נתונים נפוץ לקבצי תצורה ותשובות API.

**JWT**  
JSON Web Token. תקן לשידור מאובטח של מידע בין צדדים כאובייקט JSON.

## ל

**Key Vault**  
שירות Azure לאחסון ואבטחה של סודות, מפתחות ותעודות.

**Kusto Query Language (KQL)**  
שפת שאילתות לניתוח נתונים ב-Azure Monitor, Application Insights ושירותי Azure נוספים.

## מ

**מאזן עומסים (Load Balancer)**  
שירות המפזר תעבורת רשת נכנסת על מספר שרתים או מופעים.

**Log Analytics**  
שירות Azure לאיסוף, ניתוח ופיקוד על נתוני טלמטריה מתוך סביבות ענן ועל-גבי שרתים.

## נ

**Managed Identity**  
תכונה של Azure המעניקה לשירותי Azure זהות מנוהלת אוטומטית לאימות מול שירותים אחרים.

**מיקרו-שירותים (Microservices)**  
גישה ארכיטקטונית שבה אפליקציות בנויים כאוסף של שירותים קטנים ועצמאיים.

**Monitor**  
פתרון המעקב המאוחד של Azure המספק תצפית מלאת-שכבות על אפליקציות ותשתית.

## ס

**Node.js**  
סביבה להרצת JavaScript בצד השרת מבוססת על מנוע V8 של Chrome.

**npm**  
מנהל חבילות ל-Node.js לניהול תלות וחבילות.

## ע

**Output**  
ערכים המוחזרים מפריסת תשתית שניתן להשתמש בהם על ידי אפליקציות או משאבים אחרים.

## פ

**חבילה (Package)**  
תהליך הכנת קוד מקור ו/או תלותים של אפליקציה לפריסה.

**פרמטרים**  
ערכי קלט המועברים לתבניות תשתית להתאמת הפריסה.

**PostgreSQL**  
מערכת מסד נתונים יחסית פתוחה הנתמכת כשירות מנוהל ב-Azure.

**פרוביז׳נינג (Provisioning)**  
תהליך יצירה והגדרה של משאבי Azure המוגדרים בתבניות תשתית.

## ק

**מִנּוּם (Quota)**  
מגבלות על כמות המשאבים שניתן ליצור במנוי או באזור ב-Azure.

## ר

**Resource Group**  
מיכל לוגי למשאבי Azure החולקים את אותו מחזור חיים, הרשאות ומדיניות.

**Resource Token**  
מחרוזת ייחודית המנוצלת על ידי azd להבטיח שמות משאבים ייחודיים בין פריסות.

**REST API**  
סגנון ארכיטקטוני לעיצוב אפליקציות רשת באמצעות פרוטוקולי HTTP.

**Rollback**  
תהליך החזרה לגרסה קודמת של אפליקציה או קונפיגורציית תשתית.

## ש

**שירות**  
רכיב באפליקציה שלך המוגדר ב-azure.yaml (למשל, frontend ווב, backend API, מסד נתונים).

**SKU**  
יחידת מלאי. מייצגת שכבות שירות או רמות ביצועים שונות למשאבי Azure.

**מסד נתונים SQL**  
שירות מסד נתונים יחסיים מנוהל של Azure המבוסס על Microsoft SQL Server.

**Static Web Apps**  
שירות Azure לבניית פריסת אפליקציות ורשת מלאות בסיס מקוד מקור במאגרים.

**חשבון אחסון**  
שירות Azure המספק אחסון בענן לאובייקטי נתונים כולל blobs, קבצים, תורים וטבלאות.

**מנוי**  
מיכל חשבון Azure המחזיק קבוצות משאבים ומשאבים עם חיוב וניהול גישה קשורים.

## ת

**תבנית**  
מבנה פרויקט מובנה מראש המכיל קוד אפליקציה, הגדרות תשתית ותצורה לתרחישים נפוצים.

**Terraform**  
כלי Infrastructure as Code קוד פתוח התומך בספקי ענן רבים כולל Azure.

**Traffic Manager**  
מאזין עומס מבוסס DNS של Azure המפזר תנועה על פני אזורי Azure גלובליים.

## ו

**URI**  
מזהה משאב אחיד. מחרוזת שמזהה משאב מסוים.

**URL**  
מיקום משאב אחיד. סוג URI המפרט היכן נמצא משאב וכיצד לגשת אליו.

## פ

**רשת וירטואלית (Virtual Network - VNet)**  
אבני בניין בסיסיות לרשתות פרטיות ב-Azure, המעניקות בידוד וסגמנטציה.

**VS Code**  
Visual Studio Code. עורך קוד פופולרי עם אינטגרציה מעולה ל-Azure ו-azd.

## ש

**Webhook**  
קריאת דעת HTTP שמעוררת בעת אירועים ספציפיים, נפוצים בצנרות CI/CD.

**What-if**  
תכונה של Azure המראה אילו שינויים יבוצעו בפריסה מבלי לבצע אותה בפועל.

## י

**YAML**  
YAML אינה שפת סימון. תקן סיריאליזציה של נתונים קריא לבני אדם המשמש לקבצי תצורה כדוגמת azure.yaml.

## ז

**אזור**  
מיקומים נפרדים פיזית בתוך אזור Azure המספקים יתירות וזמינות גבוהה.

## מיפוי שמות שירותי Azure

| שם נפוץ | שם שירות רשמי של Azure | סוג מארח ב-azd |
|-------------|------------------------------|---------------|
| אפליקציית ווב | Azure App Service | `appservice` |
| אפליקציית API | Azure App Service | `appservice` |
| אפליקציית מכולה | Azure Container Apps | `containerapp` |
| פונקציה | Azure Functions | `function` |
| אתר סטטי | Azure Static Web Apps | `staticwebapp` |
| מסד נתונים | Azure Database for PostgreSQL | משאב תשתית, לא אפליקציה `host` |
| מסד נתונים NoSQL | Azure Cosmos DB | משאב תשתית, לא אפליקציה `host` |
| אחסון | Azure Storage Account | משאב תשתית, לא אפליקציה מובנית `host` |
| Cache | Azure Managed Redis | משאב תשתית, לא אפליקציה `host` |
| חיפוש | Azure AI Search | משאב תשתית, לא אפליקציה `host` |
| הודעות | Azure Service Bus | משאב תשתית, לא אפליקציה `host` |

`services.<name>.host` בוחר יעד פריסת אפליקציה; איננו קיצור לסוג משאב Azure כלשהו. מסדי נתונים, מטמונים, שירותי חיפוש ותורים מוצבים בדרך כלל דרך ספק התשתית ומחוברים לאפליקציה דרך פלטים/תצורה.

## מונחים ספציפיים להקשר

### מונחי פיתוח
- **הטענה חיה (Hot Reload)**: עדכון אוטומטי של אפליקציות במהלך הפיתוח ללא הפעלה מחדש
- **צינור בנייה (Build Pipeline)**: תהליך אוטומטי לבנייה ובדיקת קוד
- **סלוט פריסה (Deployment Slot)**: סביבת בדיקה בתוך שירות אפליקציות
- **התאמת סביבות (Environment Parity)**: שמירת סביבות פיתוח, בדיקה וייצור דומות

### מונחי אבטחה
- **Managed Identity**: תכונת Azure המעניקה ניהול אישורים אוטומטי
- **Key Vault**: אחסון מאובטח לסודות, מפתחות ותעודות
- **RBAC**: בקרת גישה מבוססת תפקידים למשאבי Azure
- **Network Security Group**: חומת אש וירטואלית לבקרת תעבורת רשת

### מונחי ניטור
- **Telemetry**: איסוף אוטומטי של מדידות ונתונים
- **ניטור ביצועי אפליקציה (APM)**: ניטור ביצועי תוכנה
- **Log Analytics**: שירות לאיסוף וניתוח נתוני לוגים
- **חוקי התראה**: התראות אוטומטיות מבוססות מדדים או תנאים

### מונחי פריסה
- **פריסת Blue-Green**: אסטרטגיית פריסה ללא זמן השבתה
- **פריסת Canary**: פריסה בהדרגה לתת-קבוצה של משתמשים
- **עדכון מחליק (Rolling Update)**: החלפה סידרתית של מופעי אפליקציה
- **Rollback**: החזרה לגרסה קודמת של אפליקציה
