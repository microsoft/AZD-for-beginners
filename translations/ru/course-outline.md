# AZD для начинающих: план курса и структура обучения

## Обзор курса

Освойте Azure Developer CLI (azd) через структурированные главы, предназначенные для поэтапного обучения. **Особое внимание уделяется развертыванию AI-приложений с интеграцией Microsoft Foundry.**

### Почему этот курс важен для современных разработчиков

Разработчикам, занимающимся развертыванием AI-решений, обычно нужна помощь по следующим темам:
- Сложные многосервисные AI-архитектуры
- Лучшие практики для продакшн-развертывания AI  
- Интеграция и конфигурация Azure AI сервисов
- Оптимизация затрат для AI-нагрузок
- Устранение неполадок, специфичных для AI-развертываний

### Основные цели обучения

Пройдя этот структурированный курс, вы сможете:
- **Овладеть основами AZD**: основные концепции, установка и настройка
- **Развертывать AI-приложения**: использовать AZD с сервисами Microsoft Foundry
- **Реализовывать инфраструктуру как код**: управлять ресурсами Azure с помощью шаблонов Bicep
- **Устранять неполадки развертываний**: решать типичные проблемы и отлаживать
- **Оптимизировать для продакшна**: безопасность, масштабирование, мониторинг и управление затратами
- **Создавать многозадачные решения**: развертывать сложные AI-архитектуры

## 🎓 Формат обучения на воркшопах

### Гибкие форматы обучения
Этот курс создан для поддержки как **самостоятельного обучения в удобном темпе**, так и **проводимых с фасилитатором воркшопов**, чтобы обучающиеся могли получить практические навыки работы с AZD через интерактивные задания.

#### 🚀 Режим самостоятельного обучения
**Идеально подходит для индивидуальных разработчиков и непрерывного обучения**

**Возможности:**
- **Интерфейс в браузере**: полный воркшоп на базе MkDocs, доступный из любого веб-браузера
- **Интеграция с GitHub Codespaces**: среда разработки в один клик с преднастроенными инструментами
- **Интерактивная среда DevContainer**: не требуется локальная настройка — начинайте кодировать сразу
- **Отслеживание прогресса**: встроенные контрольные точки и проверочные упражнения
- **Поддержка сообщества**: доступ к каналам Azure в Discord для вопросов и сотрудничества

**Структура обучения:**
- **Гибкое расписание**: проходите главы в собственном темпе в течение нескольких дней или недель
- **Система контрольных точек**: проверяйте знания перед переходом к более сложным темам
- **Библиотека ресурсов**: обширная документация, примеры и руководства по устранению неполадок
- **Создание портфолио**: разработка проектов для профессионального портфолио

**Начало работы (самостоятельно):**
```bash
# Option 1: GitHub Codespaces (Recommended)
# Navigate to the repository and click "Code" → "Create codespace on main"

# Option 2: Local Development
git clone https://github.com/microsoft/azd-for-beginners.git
cd azd-for-beginners/workshop
# Follow setup instructions in workshop/README.md
```

#### 🏛️ Воркшопы с фасилитатором
**Идеально подходит для корпоративного обучения, буткемпов и образовательных учреждений**

**Варианты формата воркшопа:**

**📚 Интеграция в учебные курсы (8-12 недель)**

- **Формат буткемпа**: интенсивная программа 3-5 дней с ежедневными 6-8 часовыми занятиями
- **Корпоративное обучение**: ежемесячные командные сессии с практической реализацией проектов
- **Система оценивания**: задания с оценкой, взаимные оценки и финальные проекты

**Подход Обнаружение → Развертывание → Настройка для развития практических навыков**

**Фаза 1: Обнаружение (45 минут)**
- **Изучение шаблонов**: оценка шаблонов и сервисов Microsoft Foundry
- **Анализ архитектуры**: понимание многозадачных шаблонов и стратегий развертывания
- **Оценка требований**: выявление потребностей и ограничений организации
- **Настройка среды**: подготовка среды разработки и ресурсов Azure

**Фаза 2: Развертывание (2 часа)**
- **Пошаговая реализация**: поэтапное развертывание AI-приложений с AZD
- **Настройка сервиса**: конфигурация Azure AI сервисов, конечных точек и аутентификации
- **Реализация безопасности**: применение корпоративных шаблонов безопасности и контроля доступа
- **Проверочное тестирование**: верификация развертываний и устранение распространённых проблем

**Фаза 3: Настройка (45 минут)**
- **Модификация приложения**: адаптация шаблонов под конкретные задачи и требования
- **Оптимизация продакшна**: внедрение мониторинга, управления затратами и масштабирования
- **Продвинутые шаблоны**: исследование координации многозадачных агентов и сложных архитектур
- **Планирование следующих шагов**: определение пути дальнейшего развития навыков
