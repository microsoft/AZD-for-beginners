# AZD для новичков: план курса и учебная структура

## Обзор курса

Освойте Azure Developer CLI (azd) через структурированные главы, предназначенные для поэтапного обучения. **Особое внимание уделяется развертыванию AI-приложений с интеграцией Microsoft Foundry.**

### Почему этот курс важен для современных разработчиков

Разработчикам, занимающимся развертыванием AI-решений, часто нужна помощь в следующих областях:
- Сложные много-сервисные AI-архитектуры
- Лучшие практики развертывания AI в продакшене  
- Интеграция и настройка Azure AI сервисов
- Оптимизация затрат на AI-нагрузки
- Устранение неполадок, специфичных для AI-развертываний

### Основные цели обучения

Пройдя этот структурированный курс, вы сможете:
- **Освоить основы AZD**: ключевые концепции, установка и настройка
- **Разворачивать AI-приложения**: использовать AZD с сервисами Microsoft Foundry
- **Реализовать инфраструктуру как код**: управлять ресурсами Azure с помощью шаблонов Bicep
- **Устранять неполадки при развертывании**: решать распространённые проблемы и дебажить
- **Оптимизировать для продакшена**: безопасность, масштабирование, мониторинг и управление затратами
- **Создавать многоагентные решения**: развертывать сложные AI-архитектуры

## 🎓 Опыт обучения на воркшопах

### Гибкие варианты обучения
Этот курс разработан для поддержки как **самостоятельного обучения в удобном темпе**, так и **проводимых воркшопов** с инструктором, что позволяет участникам получить практический опыт с AZD и развивать навыки через интерактивные упражнения.

#### 🚀 Режим самостоятельного обучения
**Идеально подходит для индивидуальных разработчиков и непрерывного обучения**

**Особенности:**
- **Интерфейс в браузере**: полный воркшоп на базе MkDocs, доступный через любой веб-браузер
- **Интеграция с GitHub Codespaces**: среда разработки одним кликом с преднастроенными инструментами
- **Интерактивная среда DevContainer**: не требуется локальная установка — начинайте кодить сразу
- **Отслеживание прогресса**: встроенные контрольные точки и проверочные упражнения  
- **Поддержка сообщества**: доступ к каналам Azure в Discord для вопросов и совместной работы

**Структура обучения:**
- **Гибкие сроки**: проходите главы в собственном темпе, за дни или недели
- **Система контрольных точек**: проверяйте усвоение перед переходом к сложным темам

#### 🏛️ Проведение структурированных воркшопов
**Идеально для корпоративного обучения, буткемпов и образовательных учреждений**

**Варианты формата воркшопа:**

**📚 Интеграция в академические курсы (8-12 недель)**
- **Университетские программы**: семестровый курс с еженедельными 2-часовыми занятиями
- **Формат буткемпа**: интенсивная программа на 3-5 дней с ежедневными сессиями по 6-8 часов
- **Корпоративное обучение**: ежемесячные командные сессии с практической реализацией проектов
- **Оценочная система**: оценочные задания, взаимные обзоры и итоговые проекты

**🚀 Интенсивный воркшоп (1-3 дня)**
- **День 1**: Основы + разработка AI (главы 1-2) — 6 часов
- **День 2**: Конфигурация + инфраструктура (главы 3-4) — 6 часов  
- **День 3**: Продвинутые паттерны + продакшн (главы 5-8) — 8 часов
- **Поддержка после**: опциональное 2-недельное наставничество для завершения проектов

**⚡ Исполнительный брифинг (4-6 часов)**
- **Стратегический обзор**: ценность AZD и влияние на бизнес (1 час)
