# Пример микросервисов

Запускаемая реализация и её инструкции находятся в
**[container-app/microservices](../container-app/microservices/README.md)**.

Этот каталог предназначен только для навигации. Здесь нет `azure.yaml`, `infra/` или `src/`.
Не запускайте `azd up` здесь.

Из корневой папки репозитория:

```bash
cd examples/container-app/microservices
```

Затем следуйте инструкциям в связанном README для ознакомления с требованиями, развёртывания, проверки, локальной
разработки, практических упражнений, оценки затрат и очистки.

В примере есть Node.js API Gateway и Python Product Service только для чтения.
Службы заказов, пользователей, уведомлений, базы данных и сообщений – это идеи расширения,
а не реализации, включённые в этот репозиторий.
