# Поддержка

## Проблемы и вопросы курса

Ищите по [проблемам курса](https://github.com/microsoft/AZD-for-beginners/issues) перед тем, как сообщать о неисправности. Укажите затронутый урок на английском, выполненную команду, версии AZD/расширений и сообщение об ошибке. Удалите учетные данные, токены, детали подписки и личные данные из журналов и скриншотов.

Для общих вопросов по обучению используйте [сообщество разработчиков Azure](https://discord.gg/microsoft-azure). Ответы сообщества не гарантируют поддержку.

## Проблемы инструментов и сервисов

Сообщайте о воспроизводимых ошибках AZD CLI в [Azure/azure-dev](https://github.com/Azure/azure-dev/issues). По инцидентам сервисов Azure и вопросам, связанным с подпиской, используйте варианты поддержки в [Azure портале](https://portal.azure.com/).

## Сообщения о безопасности

Следуйте инструкции в [SECURITY.md](SECURITY.md) для приватного сообщения о уязвимостях. Не публикуйте секреты или детали эксплуатации в публичных вопросах курса.

## Политика поддержки Microsoft

Поддержка этого образовательного проекта ограничена перечисленными выше ресурсами. Примеры курса не включают обязательств по поддержке производственной среды.
