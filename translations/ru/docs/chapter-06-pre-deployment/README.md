# Глава 6: Планирование и проверка перед развертыванием

**📚 Курс**: [AZD для начинающих](../../README.md) | **⏱️ Продолжительность**: 2-4 часа чтения; дополнительное время для адаптированных лабораторных работ | **⭐ Сложность**: Средний–Продвинутый

---

## Обзор

В этой главе рассматриваются важные шаги планирования и проверки перед развертыванием вашего приложения. Научитесь избегать дорогостоящих ошибок с помощью правильного планирования емкости, выбора SKU и предполетных проверок.

> Руководство по командам проверено в соответствии с выпущенным справочником `azd 1.37.2`. Облачные развертывания не выполнялись. Более длинные уроки включают иллюстративные фрагменты, а не полные проекты локального развертывания.

## Цели обучения

После изучения этой главы вы сможете:
- Выполнять предполетные проверки перед развертыванием
- Планировать емкость и оценивать требования к ресурсам
- Выбирать подходящие SKU для оптимизации затрат
- Настраивать Application Insights для мониторинга
- Понимать паттерны координации многоагентных систем и их требования к развертыванию

## 🚀 Быстрый старт

```bash
# Check subscription quotas
az vm list-usage --location eastus --output table

# Preview infrastructure changes (inspect template hooks before running)
azd provision --preview

# Validate Bicep syntax
az bicep build --file infra/main.bicep

# Check environment configuration
azd env get-values
```

## ☑️ Контрольный список перед развертыванием

### Перед `azd provision`

- [ ] Квота проверена для региона
- [ ] SKU выбраны корректно
- [ ] Проверена оценка стоимости
- [ ] Соблюдается согласованность в наименованиях
- [ ] Настроена безопасность/RBAC

### Перед `azd deploy`

- [ ] Установлены переменные окружения
- [ ] Секреты в Key Vault
- [ ] Проверены строки подключения
- [ ] Настроены проверки работоспособности

## 💰 Руководство по выбору SKU

| Нагрузка | Разработка | Производство |
|----------|-------------|------------|
| Container Apps | Потребление | Потребление или выделенный профиль нагрузки, на основе измеренной нагрузки |
| App Service | B1/B2 | P1v3+ |
| Модели Azure OpenAI | Поддерживаемый тип развертывания по факту использования | По факту использования или с резервированной пропускной способностью; зависит от модели/региона |
| AI Search | Бесплатно/Базовый в пределах лимитов | Базовый или Стандартный уровень, подобранный под индекс, реплики и нагрузку запросов |
