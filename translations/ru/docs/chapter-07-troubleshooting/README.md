# Глава 7: Устранение неполадок и отладка

**📚 Курс**: [AZD для начинающих](../../README.md) | **⏱️ Длительность**: 1-1.5 часа | **⭐ Сложность**: Средний уровень

## Обзор

Эта глава поможет вам диагностировать и решать распространённые проблемы при работе с Azure Developer CLI. От сбоев развертывания до проблем, связанных с ИИ.

> Руководство по командам проверено на основе опубликованной `azd 1.37.2` справки. Облачные развертывания не выполнялись. Перед использованием команд замените примерные имена и идентификаторы ресурсов.

## Цели обучения

Выполнив эту главу, вы сможете:
- Диагностировать распространённые сбои развертывания AZD
- Отлаживать проблемы с аутентификацией и разрешениями
- Решать проблемы с подключением сервисов ИИ
- Использовать Azure Portal и CLI для устранения неполадок

## 🚨 Быстрые исправления

### Проблемы с аутентификацией
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### Сбои при развертывании
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### Конфликты ресурсов
Сначала проверьте существующий ресурс и ошибки развертывания. Не удаляйте общую или рабочую среду для решения конфликта имён. Для **новой одноразовой среды** используйте уникальное имя:

```bash
azd env new different-name
azd up
```

### Превышена квота
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

Изменение `AZURE_LOCATION` не перемещает существующие ресурсы и может вызвать конфликты местоположения при повторном развертывании.

## 📋 Справочник кодов ошибок

| Ошибка | Причина | Решение |
|-------|-------|----------|
| `AuthenticationError` | Не выполнен вход | `azd auth login` |
| `ResourceNotFound` | Отсутствует ресурс | Проверьте имена ресурсов |
| `QuotaExceeded` | Ограничения подписки | Запросите увеличение квоты |
| `InvalidTemplate` | Ошибка синтаксиса Bicep | `az bicep build` |
| `Conflict` | Ресурс существует | Используйте новое имя или удалите |
| `Forbidden` | Недостаточно разрешений | Проверьте роли RBAC |

## 🔄 Сброс и восстановление

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

Жёсткий сброс удаляет данные и может изменить конечные точки. Сначала сделайте резервную копию и внимательно следуйте интерактивным подсказкам удаления. `--force --purge` подходит только для одноразовых сред, когда требуется необратимое удаление.
