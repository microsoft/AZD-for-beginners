# Глава 2: Разработка с акцентом на ИИ

**📚 Курс**: [AZD для начинающих](../../README.md) | **⏱️ Продолжительность**: 4-5 часов включая практику | **⭐ Сложность**: Средний уровень

## Обзор

В этой главе рассматривается развертывание приложений с ИИ с использованием Azure Developer CLI и сервисов Microsoft Foundry. От простых чат-ботов с ИИ до интеллектуальных агентов с инструментами.

> **Обновление Foundry GA (2026-11-09):** Пакет `microsoft.foundry` версии 1.0 [общедоступен](https://devblogs.microsoft.com/azure-sdk/microsoft-foundry-azure-developer-cli-ga/). Используйте `azd >= 1.37.0`; оценки остаются отдельной установкой. Руководство по [хостинг-агенту](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga) охватывает локальное тестирование Agent Inspector и удалённое развертывание кода. Это обзор документации, а не валидация живого развертывания; опциональные функции предварительного просмотра сохраняют свой статус.

## Цели обучения

По завершении этой главы вы сможете:
- Развертывать приложения с ИИ используя готовые шаблоны AZD
- Понимать интеграцию Microsoft Foundry с AZD
- Установить GA пакет и протестировать хостинг-агента локально, прежде чем развертывать его исходный код в Foundry
- Ознакомиться с `azure.yaml`, ресурсами оценки и очисткой новых и повторно используемых проектов
- Настраивать и конфигурировать агентов ИИ с инструментами
- Развертывать приложения RAG (генерация с поддержкой поиска)

## 🚀 Быстрый старт

Выберите один из вариантов в новой пустой директории. Завершающий `.` инициализирует текущую директорию; в противном случае AZD может создать поддиректорию без изменения рабочей директории вашей оболочки.

Для **пути GA с хостинг-агентом и развертыванием кода**, начните с [пошагового руководства](microsoft-foundry-integration.md#hosted-agent-walkthrough-ga). Требуются AZD 1.37.0+, текущий uv, Python 3.13+, права Foundry и квота моделей. Полные шаблоны приложений ниже — альтернативы, а не предпосылки для этого руководства.

```bash
# Option 1: RAG Chat Application
azd init --template azure-search-openai-demo .
azd up

# Option 2: AI Agents
azd init --template get-started-with-ai-agents .
azd up

# Option 3: Quick Chat App
azd init --template openai-chat-app-quickstart .
azd up
```

## 💰 Осведомленность о стоимости

Это иллюстративные диапазоны, а не цены или лимиты; трафик моделей, SKU поиска/вычисления, регион и опциональные функции могут их превышать. Перед развертыванием ознакомьтесь с текущими тарифами выбранного примера.

| Окружение | Оценочная ежемесячная стоимость |
|-------------|------------------------------|
| Разработка | $80-150 |
| Промежуточное | $150-300 |
| Продакшн | $300-3,500+ |

**Очистка:** Ознакомьтесь с `azd down` перед подтверждением: для только что созданного проекта Foundry он удаляет группу ресурсов и всё в ней. Для повторно используемого проекта Foundry он оставляет ресурсы проекта и агента; следуйте [руководству по очистке](microsoft-foundry-integration.md#7-clean-up-deliberately), чтобы удалить нежелательные ресурсы отдельно.
