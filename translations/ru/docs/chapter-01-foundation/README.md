## Обзор

В этой главе представляются основы Azure Developer CLI (azd). Вы узнаете основные концепции, установите инструменты и развернете ваше первое приложение в Azure.

> Цель обзора команд и конфигурации: `azd 1.37.2` (ноябрь 2026). Живое развертывание в Azure во время обзора не выполнялось.

## Цели обучения

Выполнив эту главу, вы:
- Поймете, что такое Azure Developer CLI и чем он отличается от Azure CLI
- Установите и настроите AZD на вашей платформе
- Развернете ваше первое приложение в Azure с помощью `azd up`
- Очистите ресурсы с помощью `azd down`

## ✅ Начните здесь: Проверьте вашу настройку

Прежде чем начать, убедитесь, что ваш локальный компьютер готов для шаблона Главы 1:

**Windows:**
```powershell
.\validate-setup.ps1
```

**macOS / Linux:**
```bash
bash ./validate-setup.sh
```

Если скрипт сообщает об отсутствующих инструментах, сначала устраните это, а затем продолжайте главу.

---

## 🚀 Быстрый старт

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ Критерии успеха

После завершения этой главы вы должны уметь:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
