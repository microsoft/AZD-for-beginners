## Обзор

Эта глава охватывает продвинутые паттерны многоагентной архитектуры, оркестрацию агентов и готовые к производству AI-развертывания для комплексных сценариев.

> Руководство по командам проверено на соответствие опубликованному `azd 1.37.2` справочнику. Облачные развертывания не выполнялись.

Пройдя эту главу, вы:
- Поймёте паттерны многоагентной архитектуры
- Научитесь развёртывать согласованные системы AI-агентов
- Реализуете коммуникацию между агентами
- Создадите готовые к производству многоагентные решения

## 🚀 Быстрый старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively with the GA bundle
azd ext install microsoft.foundry
azd ai agent init
azd up
```

> **Какой подход выбрать?** Используйте `azd init --template`, чтобы начать с рабочего примера. Используйте `azd ai agent init` интерактивно или `azd ai agent init --template <path-to-azure.yaml>` для принятия текущего агентского проекта. См. [справочник AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) для требований к версии и миграции оценки.

Запускайте эти альтернативы в отдельных пустых папках. Рабочий процесс GA Foundry требует `azd >= 1.37.0`; его интерактивный поток не создаёт пользовательский конвейер Service Bus из урока по координации. Для локального тестирования, развертывания кода и очистки между новыми и повторно используемыми проектами следуйте [пошаговому руководству по размещённым агентам](../chapter-02-ai-development/microsoft-foundry-integration.md#hosted-agent-walkthrough-ga).

## 🎯 Выделенное решение: Розничное многоагентное

Решение [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонстрирует:

- **Агент клиента**: Обработка взаимодействий и предпочтений пользователей
- **Агент инвентаризации**: Управление запасами и обработка заказов
- **Оркестратор**: Координация между агентами
- **Общая память**: Управление контекстом между агентами

### Используемые службы

| Служба | Назначение |
|---------|---------|
| Microsoft Foundry Models | Понимание языка |
| Azure AI Search | Каталог продукции |
| Cosmos DB | Состояние и память агента |
| Container Apps | Хостинг агента |
| Application Insights | Мониторинг |
