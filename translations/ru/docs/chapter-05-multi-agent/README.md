## Обзор

Эта глава охватывает продвинутые архитектурные паттерны многоагентных систем, оркестровку агентов и готовые к производству AI-развёртывания для сложных сценариев.

> Руководство по командам проверено относительно опубликованного справочника `azd 1.37.2`. Развёртывания в облаке не выполнялись.

## Цели обучения

Пройдя эту главу, вы:
- Поймёте архитектурные паттерны многоагентных систем
- Научитесь развёртывать координированные системы AI-агентов
- Реализуете взаимодействие агентов между собой
- Создадите готовые к производству многоагентные решения

## 🚀 Быстрый старт

```bash
# Option 1: Deploy the multi-agent template used in Lesson 1
azd init --template Azure-Samples/contoso-creative-writer .
azd up

# Option 2: Initialize a Foundry agent interactively (requires azure.ai.agents)
azd extension install azure.ai.agents
azd ai agent init
azd up
```

> **Какой подход выбрать?** Используйте `azd init --template`, чтобы начать с рабочего примера. Используйте `azd ai agent init` интерактивно, или `azd ai agent init --template <path-to-azure.yaml>`, чтобы принять текущий проект агента. Смотрите [справочник AZD AI CLI](../chapter-08-production/production-ai-practices.md#azd-ai-cli-commands-and-extensions) для требований к версии и миграции оценки.

Запускайте эти варианты в отдельных пустых папках. Расширение агентов `1.0.0-beta.23` требует `azd >= 1.37.0`; его интерактивный режим не генерирует кастомизированный Service Bus конвейер в уроке координации.

## 🎯 Избранное решение: Розничное многоагентное

Решение [Retail Multi-Agent Solution](../../examples/retail-scenario.md) демонстрирует:

- **Агент клиента**: Обрабатывает взаимодействие с пользователем и предпочтения
- **Агент запасов**: Управляет запасами и обработкой заказов
- **Оркестратор**: Координирует работу между агентами
- **Общая память**: Управление контекстом между агентами

### Используемые сервисы

| Сервис | Назначение |
|---------|---------|
| Microsoft Foundry Models | Понимание языка |
| Azure AI Search | Каталог продуктов |
| Cosmos DB | Состояние и память агента |
| Container Apps | Хостинг агентa |
| Application Insights | Мониторинг |
