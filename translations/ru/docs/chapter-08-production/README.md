## Обзор

В этой главе рассматриваются шаблоны развертывания, готовые для корпоративного использования, усиление безопасности, мониторинг и оптимизация затрат для производственных AI-нагрузок.

Это архитектурное руководство, а не полностью готовый к развертыванию производственный шаблон. В примерах опущены детали интеграции, которые должны быть добавлены и протестированы в вашем приложении; чтение чек-листа не гарантирует готовность к продакшену.

> **Обновление Foundry GA (2026-11-09):** Используйте `azd >= 1.37.0` и общедоступный пакет `microsoft.foundry` 1.0 для workflow Foundry; оценки устанавливаются отдельно. Смотрите [область выпуска и миграцию](production-ai-practices.md#recent-release-changes-and-fixes) и [пример аутентифицированного пайплайна](production-ai-practices.md#cicd-pipeline-configuration). Это обзор документации, а не проверка развертывания в реальном времени или универсальный статус GA для опциональных функций предварительного просмотра.

## 🔐 Лучшие практики безопасности

```bicep
// Illustrative properties from different resources, NOT a standalone Bicep file.
// Attach identity to the application host:
identity: {
  type: 'SystemAssigned'
}

// AI account properties (also require private endpoints, DNS and app connectivity):
properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }
}
```

## 💰 Оптимизация затрат

| Стратегия | Основное ограничение |
|----------|---------|
| Масштабирование до нуля (Container Apps) | Требуется подходящий триггер; другие сервисы всё ещё создают затраты |
| Использование модели потребления для разработки | Сравнивайте стоимость выбранного сервиса и нагрузку |
| Плановое масштабирование | Масштабирование через поддерживаемую инфраструктуру/автоматизацию |
| Резервирование/предоставленная ёмкость | Только если поддерживается; обязательства могут увеличить холостой расход |

Используйте [полный шаблон ресурса бюджета](production-ai-practices.md#2-cost-monitoring-and-budgets) с действительной датой начала, областью выставления счетов, получателями и разрешениями. Бюджет посылает оповещения; он не ограничивает расходы. Экономия зависит от измеренного использования и не гарантируется в процентах.

## 📊 Настройка мониторинга

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
