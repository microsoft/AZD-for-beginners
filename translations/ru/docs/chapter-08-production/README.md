## Обзор

В этой главе рассматриваются шаблоны развертывания, готовые для корпоративного использования, усиление безопасности, мониторинг и оптимизация затрат для производственных ИИ нагрузок.

Это архитектурное руководство, а не полный шаблон для развертывания. Примеры опускают детали интеграции, которые должны быть реализованы и протестированы в вашем собственном приложении; просмотр чеклиста не подтверждает готовность к продакшену.

> **Обзор релиза (2026-11-04):** Руководство по AI CLI проверено относительно `azd 1.37.2`, агентов `1.0.0-beta.23` и документации/исходного кода оценок `1.0.0-beta.2`. См. [изменения и исправления релиза](production-ai-practices.md#recent-release-changes-and-fixes) для требований совместимости и деталей миграции; это не валидация живого развертывания.

```bicep
// Illustrative properties from different resources, NOT a standalone Bicep file.

identity: {
  type: 'SystemAssigned'
}

properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }
}
```

## 💰 Оптимизация затрат

| Стратегия | Основное ограничение |
|----------|---------|
| Масштабирование до нуля (Container Apps) | Требуется подходящий триггер; другие сервисы всё ещё генерируют затраты |
| Использование уровней потребления для разработки | Сравнение цен выбранного сервиса и нагрузки |
| Плановое масштабирование | Масштабирование через поддерживаемую инфраструктуру/автоматизацию |
| Резервации/предварительно выделённая емкость | Только при поддержке; обязательства могут увеличить неиспользуемые затраты |

Используйте [полный шаблон бюджета ресурсов](production-ai-practices.md#2-cost-monitoring-and-budgets) с действительной датой начала, областью выставления счетов, получателями и разрешениями. Бюджет отправляет оповещения; он не ограничивает расходы. Экономия зависит от измеренного использования и не является гарантированной.

## 📊 Настройка мониторинга

```bash
# Open the Application Insights logs view (requires configured monitoring)
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
