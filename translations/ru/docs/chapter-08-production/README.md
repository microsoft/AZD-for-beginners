# Глава 8: Шаблоны для производства и предприятий

**📚 Курс**: [AZD для начинающих](../../README.md) | **⏱️ Продолжительность**: 2-3 часа | **⭐ Сложность**: Продвинутый

---

## Обзор

В этой главе рассматриваются шаблоны развертывания, готовые к использованию в предприятиях, усиление безопасности, мониторинг и оптимизация расходов для производственных AI-рабочих нагрузок.

> Проверено с помощью `azd 1.27.1` в июле 2026 года.

## Цели обучения

По завершении этой главы вы сможете:
- Развертывать отказоустойчивые приложения в нескольких регионах
- Внедрять корпоративные шаблоны безопасности
- Настраивать комплексный мониторинг
- Оптимизировать расходы в масштабе
- Настроить CI/CD-пайплайны с AZD

## 🔐 Лучшие практики безопасности

```bicep
// Use managed identity
identity: {
  type: 'SystemAssigned'
}

// Private endpoints for AI services
properties: {
  publicNetworkAccess: 'Disabled'
  networkAcls: {
    defaultAction: 'Deny'
  }
}
```

## 💰 Оптимизация затрат

| Стратегия | Экономия |
|----------|---------|
| Масштабирование до нуля (Container Apps) | 60-80% |
| Использование тарифных планов по потреблению для разработки | 50-70% |
| Плановое масштабирование | 30-50% |
| Зарезервированная емкость | 20-40% |

## 📊 Настройка мониторинга

```bash
# Stream logs
azd monitor --logs

# Check Application Insights
azd monitor --overview

# View metrics
az monitor metrics list --resource <resource-id>
```
