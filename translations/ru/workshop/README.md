# Мастерская AZD для разработчиков ИИ

Добро пожаловать на практическую мастерскую по изучению Azure Developer CLI (AZD) с акцентом на развертывание ИИ-приложений. Эта мастерская поможет вам получить практическое понимание шаблонов AZD в 3 шага:

1. **Обнаружение** - найдите подходящий для вас шаблон.
1. **Развертывание** - разверните и убедитесь, что всё работает
1. **Настройка** - измените и адаптируйте под себя!

В ходе мастерской вы также познакомитесь с основными инструментами и рабочими процессами разработчика, чтобы упростить ваш сквозной процесс разработки.

## Руководство в браузере

Уроки мастерской оформлены в Markdown. Вы можете просматривать их прямо на GitHub или запустить браузерный предпросмотр, как показано на скриншоте ниже.

![Workshop](../../../translated_images/ru/workshop.75906f133e6f8ba0.webp)

Чтобы воспользоваться этим вариантом - форкните репозиторий в свой профиль и запустите GitHub Codespaces. После активации терминала VS Code введите следующую команду:

Этот браузерный предпросмотр работает в GitHub Codespaces, dev-контейнерах или локальном клоне с установленными Python и MkDocs.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

Выполняйте эти команды из **корневой папки репозитория курса**, а не из отдельно инициализированного примера ИИ. Держите предпросмотр на переднем плане, чтобы видеть ошибки; остановите его сочетанием Ctrl+C. Для проверки сайта без его запуска выполните `python -m mkdocs build --strict --config-file workshop/mkdocs.yml`.

Через несколько секунд появится всплывающее окно. Выберите опцию `Open in browser`. Веб-руководство откроется в новой вкладке браузера. Некоторые преимущества этого предпросмотра:

1. **Встроенный поиск** - быстро находите ключевые слова или уроки.
1. **Иконка копирования** - наведите курсор на блоки кода, чтобы увидеть эту опцию
1. **Переключение темы** - меняйте светлую и тёмную темы
1. **Получить помощь** - нажмите на иконку Discord внизу страницы, чтобы присоединиться!

## Чему вы научитесь

Рассматривайте шаблон AZD как учебную песочницу для изучения различных возможностей и инструментов сквозной разработки на Microsoft Foundry. К концу мастерской вы получите интуитивное понимание различных инструментов и концепций в этом контексте.

| Концепция  | Цель |
|:---|:---|
| **Azure Developer CLI** | Понять команды и рабочие процессы инструмента |
| **Шаблоны AZD**| Понять структуру проекта и конфигурацию |
| **Azure AI Agent**| Организация и развертывание проекта Microsoft Foundry  |
| **Azure AI Search**| Включить контекстную инженерию с агентами |
| **Наблюдаемость**| Исследование трассировки, мониторинга и оценок |
| **Red Teaming**| Исследование тестирования и мер противодействия |

## Структура мастерской

Мастерская организована так, чтобы провести вас от поиска шаблона до развертывания, разбора и настройки — используя официальный стартовый шаблон [Getting Started with AI Agents](https://github.com/Azure-Samples/get-started-with-ai-agents).

### [Модуль 1: Выбор AI шаблона](docs/instructions/1-Select-AI-Template.md) (30 мин)

- Что такое AI шаблоны?
- Где я могу найти AI шаблоны?
- Как начать создавать AI агентов?
- **Практика**: Быстрый старт в Codespaces или dev-контейнере

### [Модуль 2: Проверка AI шаблона](docs/instructions/2-Validate-AI-Template.md) (30 мин)

- Какова архитектура AI шаблона?
- Какой рабочий процесс разработки AZD?
- Где я могу получить помощь по разработке с AZD?
- **Практика**: Развертывание и проверка шаблона AI агентов

### [Модуль 3: Разбор AI шаблона](docs/instructions/3-Deconstruct-AI-Template.md) (30 мин)

- Изучите ваше окружение в `.azure/` 
- Изучите настройку ресурсов в `infra/` 
- Изучите конфигурацию AZD в `azure.yaml`
- **Практика**: Изменить переменные окружения и повторно развернуть

### [Модуль 4: Настройка AI шаблона](docs/instructions/4-Configure-AI-Template.md) (30 мин)
- Исследование: Retrieval Augmented Generation
- Исследование: Оценка агентов и Red Teaming
- Исследование: Трассировка и мониторинг
- **Практика**: Изучение AI агента и наблюдаемости

### [Модуль 5: Кастомизация AI шаблона](docs/instructions/5-Customize-AI-Template.md) (30 мин)
- Определить: PRD с требованиями сценария
- Настроить: переменные окружения для AZD
- Реализовать: хуки жизненного цикла для дополнительных задач
- **Практика**: Настройка шаблона под мой сценарий

### [Модуль 6: Очистка инфраструктуры](docs/instructions/6-Teardown-Infrastructure.md) (30 мин)
- Итоги: Что такое шаблоны AZD?

- Следующие шаги: Попробуйте другой шаблон!
- **Практика**: Деактивация инфраструктуры и очистка
