# ਮਾਈਕ੍ਰੋਸਰਵਿਸਿਜ਼ ਉਦਾਹਰਨ

ਚਲਾਉਣਯੋਗ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ ਅਤੇ ਇਸਦੀਆਂ ਹਿਦਾਇਤਾਂ ਹਨ
**[container-app/microservices](../container-app/microservices/README.md)** ਵਿੱਚ।

ਇਹ ਡਾਇਰੈਕਟਰੀ ਸਿਰਫ਼ ਨੈਵੀਗੇਸ਼ਨ ਲਈ ਹੈ। ਇਸ ਵਿੱਚ ਕੋਈ `azure.yaml`, `infra/`, ਜਾਂ `src/` ਨਹੀਂ ਹਨ।
ਇੱਥੇ `azd up` ਨਾ ਚਲਾਓ।

ਰਿਪੋਜ਼ਟਰੀ ਦੀ ਜੜ ਤੋਂ:

```bash
cd examples/container-app/microservices
```

ਫਿਰ ਲਿੰਕ ਕੀਤੇ README ਦਾ ਅਨੁਸਰਣ ਕਰੋ ਪ੍ਰੀਰੇਕੁਜ਼ਿਟ, ਡਿਪਲੌਇਮੈਂਟ, ਤਸਦੀਕ, ਸਥਾਨਕ ਵਿਕਾਸ,
ਪ੍ਰਾਇਕਟਿਕਲ ਅਭਿਆਸ, ਖਰਚੇ, ਅਤੇ ਸਫਾਈ ਲਈ।

ਨਮੂਨਾ ਵਿੱਚ ਇੱਕ Node.js API ਗੇਟਵੇ ਅਤੇ ਇੱਕ ਸਿਰਫ਼ ਪੜ੍ਹਨ ਵਾਲੀ Python ਪ੍ਰੋਡਕਟ ਸਰਵਿਸ ਹੈ।
ਆਰਡਰ, ਯੂਜ਼ਰ, ਨੋਟੀਫਿਕੇਸ਼ਨ, ਡੇਟਾਬੇਸ, ਅਤੇ ਮੈਸੇਜਿੰਗ ਸਰਵਿਸਿਜ਼ ਇੱਕਸਪੈਂਸ਼ਨ ਵਿਚਾਰ ਹਨ,
ਨਾ ਕਿ ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤੇ ਗਏ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ।
