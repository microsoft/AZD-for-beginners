# AZD For Beginners ਵਿੱਚ ਯੋਗਦਾਨ ਦੇਣਾ

AZD For Beginners ਕੋਰਸ ਵਿੱਚ ਯੋਗਦਾਨ ਦੇਣ ਵਿੱਚ ਰੁਚੀ ਦਿਖਾਉਣ ਲਈ ਤੁਹਾਡਾ ਧੰਨਵਾਦ! ਇਹ ਦਸਤਾਵੇਜ਼ ਯੋਗਦਾਨਕਰਤਿਆਂ ਲਈ ਮਾਰਗਦਰਸ਼ਨ ਅਤੇ ਜਾਣਕਾਰੀ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

## ਕਿਵੇਂ ਯੋਗਦਾਨ ਦੇਣਾ ਹੈ

### ਸਮੱਸਿਆਵਾਂ ਦੀ ਰਿਪੋਰਟਿੰਗ

ਜੇ ਤੁਸੀਂ ਬੱਗ, ਗਲਤੀਆਂ, ਜਾਂ ਸੁਧਾਰਾਂ ਲਈ ਸੁਝਾਵ ਲੱਭਦੇ ਹੋ:

1. **ਮੌਜੂਦਾ ਸਮੱਸਿਆਵਾਂ ਜਾਂਚੋ**: ਨਕਲ ਨੂੰ ਟਾਲਣ ਲਈ [ਮੌਜੂਦਾ ਸਮੱਸਿਆਵਾਂ](https://github.com/microsoft/azd-for-beginners/issues) ਵਿੱਚ ਖੋਜ ਕਰੋ
2. **ਨਵੀਂ ਸਮੱਸਿਆ ਬਣਾੳੋ**: ਉਚਿਤ ਸਮੱਸਿਆ ਟੈਮਪਲੇਟ ਦੀ ਵਰਤੋਂ ਕਰੋ
3. **ਵੇਰਵੇ ਦਿਓ**: ਦੁਹਰਾਉਣ ਦੇ ਕਦਮ, ਉਮੀਦ ਕੀਤੀ ਵਿਹਾਰ ਅਤੇ ਸਕਰੀਨਸ਼ਾਟ ਜੇ ਲਾਗੂ ਹੋ ਤਾਂ ਸ਼ਾਮਲ ਕਰੋ

### ਬਦਲਾਵਾਂ ਦਾ ਪ੍ਰਸਤਾਵ

1. **ਰਿਪੋਜ਼ੀਟਰੀ fork ਕਰੋ**: ਪ੍ਰੋਜੈਕਟ ਦੀ ਆਪਣੀ fork ਬਣਾਓ
2. **ਇੱਕ ਸ਼ਾਖਾ ਬਣਾਓ**: ਆਪਣੀਆਂ ਬਦਲਾਵਾਂ ਲਈ ਇੱਕ ਫੀਚਰ ਸ਼ਾਖਾ ਬਣਾਓ
3. **ਬਦਲਾਵ ਕਰੋ**: ਸਾਡੇ ਕੋਡਿੰਗ ਅਤੇ ਦਸਤਾਵੇਜ਼ੀ ਮਿਆਰਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ
4. **ਆਪਣੇ ਬਦਲਾਵਾਂ ਦੀ ਪੜਤਾਲ ਕਰੋ**: ਸਾਰੇ ਲਿੰਕ ਕੰਮ ਕਰਦੇ ਹਨ ਅਤੇ ਸਮੱਗਰੀ ਠੀਕ ਤਰ੍ਹਾਂ ਰੇਂਡਰ ਹੁੰਦੀ ਹੈ, ਇਹ ਸੱਚਤ ਕਰੋ
5. **ਪੁੱਲ ਰਿਕਵੇਸਟ ਸਬਮਿਟ ਕਰੋ**: ਆਪਣੇ ਬਦਲਾਵਾਂ ਦਾ ਸਪష్ట ਵਰਣਨ ਦਿਓ

### ਯੋਗਦਾਨ ਦੇ ਕਿਸਮਾਂ

ਅਸੀਂ ਹੇਠ ਲਿਖੀਆਂ ਕਿਸਮਾਂ ਦੇ ਯੋਗਦਾਨਾਂ ਦਾ ਸਵਾਗਤ ਕਰਦੇ ਹਾਂ:

#### ਸਮੱਗਰੀ ਸੁਧਾਰ
- ਟਾਈਪੋ, ਗ੍ਰਾਮਰ ਅਤੇ ਫਾਰਮੈਟਿੰਗ ਸਮੱਸਿਆਵਾਂ ਦੁਰੁਸਤ ਕਰੋ
- ਮੌਜੂਦਾ ਦਸਤਾਵੇਜ਼ੀ ਦੀ ਸਪਸ਼ਟਤਾ ਵਿੱਚ ਸੁਧਾਰ ਕਰੋ
- ਪੁਰਾਣੀ ਜਾਣਕਾਰੀ ਨੂੰ ਅੱਪਡੇਟ ਕਰੋ
- ਨੁਕਸਾਨ ਵਾਲੀਆਂ ਵਿਆਖਿਆਵਾਂ ਜਾਂ ਸੰਦਰਭ ਸ਼ਾਮਲ ਕਰੋ

#### ਨਵੇਂ ਉਦਾਹਰਨ
- ਅਸਲੀ ਦੁਨੀਆ ਦੇ ਡਿਪਲੋਇਮੈਂਟ ਮਾਮਲੇ ਸ਼ਾਮਲ ਕਰੋ
- ਆਮ ਵਰਤੋਂ ਮਾਮਲਿਆਂ ਲਈ ਨਵੇਂ AZD ਟੈਮਪਲੇਟ ਬਣਾਓ
- ਹੋਰ ਕੋਡ ਨਮੂਨੇ ਅਤੇ ਅਭਿਆਸ ਪ੍ਰਦਾਨ ਕਰੋ

#### ਅਨੁਵਾਦ ਸਹਾਇਤਾ
- ਮੌਜੂਦਾ ਅਨੁਵਾਦਾਂ ਦੀ ਰਖਿਆ ਕਰੋ
- ਅਨੁਵਾਦ ਗੁਣਵੱਤਾ ਵਿੱਚ ਸੁਧਾਰ ਕਰੋ
- ਨਵੀਂ ਸਮੱਗਰੀ ਲਈ ਅਨੁਵਾਦ ਸ਼ਾਮਲ ਕਰੋ

#### ਬੱਗ ਰਿਪੋਰਟ
- ਟੁੱਟੇ ਲਿੰਕਾਂ ਜਾਂ ਗਲਤ ਕੋਡ ਉਦਾਹਰਨਾਂ ਦੀ ਰਿਪੋਰਟ ਕਰੋ
- ਦਸਤਾਵੇਜ਼ੀ ਅਸੰਗਤੀਆਂ ਦੀ ਪਹਿਚਾਣ ਕਰੋ
- ਪਹੁੰਚ ਦਿੱਕਤਾਂ ਨੂੰ ਫਲੈਗ ਕਰੋ

## ਯੋਗਦਾਨ ਮਾਰਗਦਰਸ਼ਕ

### ਦਸਤਾਵੇਜ਼ੀ ਮਿਆਰ

- ਸਾਫ਼, ਸ਼ੁਰੂਆਤੀ-ਮਿੱਤਰ ਭਾਸ਼ਾ ਵਰਤੋ
- ਸਿੱਖਣ ਦੇ ਉਦਦੇਸ਼ ਅਤੇ ਨਤੀਜੇ ਸ਼ਾਮਲ ਕਰੋ
- ਉਮੀਦ ਕੀਤੇ ਨਤੀਜੇ ਨਾਲ ਕਦਮ-ਬਾਈ-ਕਦਮ ਨਿਰਦੇਸ਼ ਦਿਓ
- ਸਬੰਧਿਤ ਸਮੱਗਰੀ ਲਈ ਨੈਵੀਗੇਸ਼ਨ ਲਿੰਕ ਸ਼ਾਮਲ ਕਰੋ
- ਲਗਾਤਾਰ ਫਾਰਮੈਟਿੰਗ ਅਤੇ ਮਾਰਕਡਾਊਨ ਢੰਗ ਵਰਤੋ

### ਕੋਡ ਉਦਾਹਰਨ

- ਸਾਰੇ ਕੋਡ ਉਦਾਹਰਨਾਂ ਦੀ ਟੈਸਟਿੰਗ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ ਯਕੀਨੀ ਬਣਾਓ
- ਮੁੱਖ ਧਾਰਨਾਵਾਂ ਨੂੰ ਸਮਝਾਉਂਦੇ ਹੋਏ ਟਿੱਪਣੀਆਂ ਸ਼ਾਮਲ ਕਰੋ
- ਅਜ਼ੂਰੇ ਅਤੇ AZD ਦੀਆਂ ਵਧੀਆ ਪ੍ਰਥਾਵਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ
- ਜਿੱਥੇ ਲਾਗੂ ਹੋਵੇ ਉਮੀਦ ਕੀਤੀ ਨਤੀਜਾ ਪ੍ਰਦਾਨ ਕਰੋ

### ਅੰਗਰੇਜ਼ੀ ਦਸਤਾਵੇਜ਼ੀ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ

ਰਿਪੋਜ਼ੀਟਰੀ ਦੇ ਰੂਟ ਤੋਂ ਮੌਜੂਦਾ ਵਿਕਾਸ ਦੀਆਂ ਲੋੜਾਂ ਇੰਸਟਾਲ ਕਰੋ ਅਤੇ ਚਲਾਓ:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

ਆਫਲਾਈਨ ਲਿੰਕ ਚੈੱਕਰ ਅੰਗਰੇਜ਼ੀ ਮਾਰਕਡਾਊਨ/HTML ਰਾਹਾਂ, ਸਿਰਲੇਖਾਂ, ਸਪਸ਼ਟ ਲੰਕ ਪੁਆਇੰਟਾਂ ਅਤੇ ਖਾਲੀ ਲਿੰਕ ਥਾਂਵਾਂ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਇਹ ਬਣਾਈਆਂ `translations/` ਅਤੇ `translated_images/` ਨੂੰ ਅਤੇ ਉਹਨਾਂ ਡਾਇਰੈਕਟਰੀਆਂ ਵਿੱਚ ਲਿੰਕਾਂ ਨੂੰ ਬਾਹਰ ਰੱਖਦਾ ਹੈ। ਇਹ ਬਾਹਰੀ ਵੈੱਬਸਾਈਟਾਂ ਨੂੰ ਫੈਚ ਨਹੀਂ ਕਰਦਾ ਅਤੇ ਅਜ਼ੂਰੇ ਡਿਪਲੋਇਮੈਂਟ ਦੀ ਪੁਸ਼ਟੀ ਨਹੀਂ ਕਰਦਾ। ਪਰੇਸ਼ਾਨੀਆਂ ਅਤੇ ਵਿਦੇਸ਼ੀ URL ਦੇ ਇਨਵੈਂਟਰੀ ਨੂੰ ਵੱਖਰੇ ਨੈਟਵਰਕ ਜਾਂਚ ਲਈ ਨਿਰਯਾਤ ਕਰਨ ਲਈ `--json <report-path>` ਦੀ ਵਰਤੋਂ ਕਰੋ। ਤਕਨੀਕੀ ਹੁਕਮਾਂ ਵਿੱਚ ਬਦਲਾਵ ਕਰਦਿਆਂ ਮੌਜੂਦਾ ਅੱਪਸਟਰੀਮ ਕੰਮਾਂਡਾਂ ਅਤੇ ਨਮੂਨਾ ਸਹਾਇਕਤਾਵਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ; ਟੈਸਟ ਕੀਤੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਡਿਜ਼ਾਈਨ ਨਕਸ਼ਿਆਂ ਤੋਂ ਵੱਖਰਾ ਕਰੋ।
