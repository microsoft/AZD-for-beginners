# ਅਧਿਆਇ 6: ਪ੍ਰੀ-ਡਿਪਲੌਇਮੈਂਟ ਯੋਜਨਾ ਅਤੇ ਪ੍ਰਮਾਣਿਕਤਾ

**📚 ਕੋਰਸ**: [ਨਵਾਂਵਾਂ ਲਈ AZD](../../README.md) | **⏱️ ਸਮਾਂ**: 2-4 ਘੰਟੇ ਪੜ੍ਹਾਈ; ਅਨੁਕੂਲਿਤ ਪ੍ਰਯੋਗਸ਼ਾਲਾਂ ਲਈ ਵਾਧੂ ਸਮਾਂ | **⭐ ਜਟਿਲਤਾ**: ਦਰਮਿਆਨਾ–ਉੱਚ

---

## ਜਾਇਜ਼ਾ

ਇਸ ਅਧਿਆਇ ਵਿੱਚ ਤੁਹਾਡੇ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਡਿਪਲੌਇ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਜ਼ਰੂਰੀ ਯੋਜਨਾ ਅਤੇ ਪ੍ਰਮਾਣਿਕਤਾ ਕਦਮ ਸਿੱਖਾਏ ਜਾਣਗੇ। ਸਹੀ ਸਮਰੱਥਾ ਯੋਜਨਾ, SKU ਚੋਣ ਅਤੇ ਪ੍ਰੀਫਲਾਈਟ ਚੈੱਕਾਂ ਨਾਲ ਮਹਿੰਗੀਆਂ ਗਲਤੀਆਂ ਤੋਂ ਬਚੋ।

> ਜਾਰੀ ਕੀਤੇ ਹੋਏ `azd 1.37.2` ਹਵਾਲਾ ਮੁਤਾਬਕ ਕਮਾਂਡ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ ਦੀ ਸਮੀਖਿਆ ਕੀਤੀ ਗਈ। ਕਲਾਉਡ ਡਿਪਲੌਇਮੈਂਟ ਨਹੀਂ ਕੀਤੇ ਗਏ। ਵੱਡੇ ਪਾਠਾਂ ਵਿੱਚ ਉਦਾਹਰਣੀ ਟੁਕੜੇ ਸ਼ਾਮਿਲ ਹਨ, ਪੂਰੇ ਸਥਾਨਕ ਡਿਪਲੌਇ ਪ੍ਰੋਜੈਕਟ ਨਹੀਂ।

## ਸਿੱਖਣ ਦੇ ਲਕਸ਼

ਇਸ ਅਧਿਆਇ ਨੂੰ ਪੂਰਾ ਕਰਕੇ, ਤੁਸੀਂ ਇਹ ਕਰ ਸਕੋਗੇ:
- ਡਿਪਲੌਇਮੈਂਟ ਤੋਂ ਪਹਿਲਾਂ ਪ੍ਰੀਫਲਾਈਟ ਚੈੱਕ ਚਲਾਉਣਾ
- ਸਮਰੱਥਾ ਦੀ ਯੋਜਨਾ ਬਣਾਉਣਾ ਅਤੇ ਸਰੋਤ ਲੋੜਾਂ ਦਾ ਅੰਦਾਜ਼ਾ ਲਗਾਉਣਾ
- ਲਾਗਤ ਅਨੁਕੂਲਤਾ ਲਈ ਯੋਗ SKU ਚੁਣਨਾ
- ਮਾਨੀਟਰਨਿੰਗ ਲਈ ਐਪਲੀਕੇਸ਼ਨ ਇਨਸਾਈਟਸ ਸੰਰਚਿਤ ਕਰਨਾ
- ਬਹੁ-ਏਜੇਂਟ ਸਹਿਯੋਗ ਨਮੂਨਿਆਂ ਅਤੇ ਉਨ੍ਹਾਂ ਦੀਆਂ ਡਿਪਲੌਇਮੈਂਟ ਲੋੜਾਂ ਨੂੰ ਸਮਝਣਾ

## ☑️ ਪ੍ਰੀ-ਡਿਪਲੌਇਮੈਂਟ ਚੈਕਲਿਸਟ

### `azd provision` ਤੋਂ ਪਹਿਲਾਂ

- [ ] ਖੇਤਰ ਲਈ ਕੋਟਾ ਦੀ ਪੁਸ਼ਟੀ ਕੀਤੀ
- [ ] SKU ਯੋਗਤਾ ਨਾਲ ਚੁਣੇ ਗਏ
- [ ] ਲਾਗਤ ਅੰਦਾਜ਼ਾ ਸਮੱਖਿਆ
- [ ] ਨਾਮਕਰਨ ਰਿਵਾਜ਼ ਸਥਿਰ
- [ ] ਸੁਰੱਖਿਆ/RBAC ਸੰਰਚਿਤ

### `azd deploy` ਤੋਂ ਪਹਿਲਾਂ

- [ ] ਵਾਤਾਵਰਨ ਵੈਰੀਏਬਲ ਸੈੱਟ
- [ ] ਸਿਕ੍ਰੇਟ ਕੀ ਵੌਲਟ ਵਿੱਚ
- [ ] ਕਨੇਕਸ਼ਨ ਸਟਰਿੰਗਸ ਦੀ ਪੁਸ਼ਟੀ
- [ ] ਸਿਹਤ ਚੈੱਕ ਸੰਰਚਿਤ
