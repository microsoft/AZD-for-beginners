# ಮೈಕ್ರೋಸರ್ವಿಸ್ ಉದಾಹರಣೆ

ರನ್ನಬಲ್ ಅನುಷ್ಠಾನ ಮತ್ತು ಅದರ ಸೂಚನೆಗಳು ಇಲ್ಲಿ ಇವೆ
**[container-app/microservices](../container-app/microservices/README.md)**.

ಈ ಡೈರೆಕ್ಟರಿ ನ್ಯಾವಿಗೇಶನ್‌ಗೆ ಮಾತ್ರವಾಗಿದೆ. ಇದರಲ್ಲಿ ಯಾವುದೇ `azure.yaml`, `infra/`, ಅಥವಾ `src/` ಇರುವುದಿಲ್ಲ.
ಇಲ್ಲಿ `azd up` ಅನ್ನು ರನ್ ಮಾಡಬಾರದು.

ರೆಪೊಸಿಟರಿ ರೂಟ್‌ನಿಂದ:

```bash
cd examples/container-app/microservices
```

ನಂತರ ಅಗತ್ಯವಿರುವ, ನಿಯೋಜನೆ, ಪರಿಶೀಲನೆ, ಸ್ಥಳೀಯ ಅಭಿವೃದ್ಧಿ, ಪ್ರಾಯೋಗಿಕ ವ್ಯಾಯಾಮಗಳು, ವೆಚ್ಚಗಳು ಮತ್ತು ಕ್ಲೀನಪ್‌ಗಾಗಿ ಲಿಂಕ್ ಮಾಡಲಾದ README ಅನ್ನು ಅನುಸರಿಸಿ.


ಆದೇಶ, ಬಳಕೆದಾರ, ಸೂಚನೆ, ಡೇಟಾಬೇಸ್ ಮತ್ತು ಸಂದೇಶ ಸೇವೆಗಳು ವಿಸ್ತರಣೆ ಆಲೋಚನೆಗಳಾಗಿದ್ದು,
ಈ ರೆಪೊಸಿಟರಿಯಲ್ಲಿ ಒಳಗೊಂಡ ಅನುಷ್ಠಾನಗಳು ಅಲ್ಲ.
