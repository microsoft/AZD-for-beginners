# ಅಧ್ಯಾಯ 1: ಅಡಿಶೋಢನೆ ಮತ್ತು ಶೀಘ್ರ ಪ್ರಾರಂಭ

**📚 ಕೋರ್ಸ್**: [ಬಿಗಿನರ್ಸ್‌ಗಾಗಿ AZD](../../README.md) | **⏱️ ಅವಧಿ**: ಮೊದಲ ನಿಯೋಜನೆ ಸೇರಿ 75-120 ನಿಮಿಷಗಳು; ಹೆಚ್ಚುವರಿ ಅಭ್ಯಾಸಗಳಿಗೆ ಹೆಚ್ಚು ಸಮಯ ಬೇಕಾಗಬಹುದು | **⭐ ಗರಿಷ್ಠತೆ**: ಪ್ರಾರಂಭಿಕ

---

## ಅವಲೋಕನ

ಈ ಅಧ್ಯಾಯದಲ್ಲಿ ಆಜೂರ್ ಡೆವಲಪರ್ CLI (azd) ಮೂಲಭೂತಗಳನ್ನು ಪರಿಚಯಿಸಲಾಗುತ್ತದೆ. ನೀವು ಮುಖ್ಯ ತತ್ವಗಳನ್ನು ಕಲಿಯೋದು, ಸಂಖ್ಯಾಪೂರ್ಣಿಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವುದು ಮತ್ತು ನಿಮ್ಮ ಮೊದಲ ಆಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಆಜೂರ್‌ಗೆ ನಿಯೋಜಿಸುವುದು ಕಲಿಯುತ್ತೀರಿ.

> ಆಜ್ಞೆ ಮತ್ತು ರೂಪರೇಖೆ ವಿಮರ್ಶೆ ಗುರಿ: `azd 1.37.2` (ನವೆಂಬರ್ 2026). ವಿಮರ್ಶೆ ಸಮಯದಲ್ಲಿ ಲೈವ್ ಆಜೂರ್ ಪ್ರೊവിസನಿಂಗ್ ನಡೆಸಲಾಗಿರಲಿಲ್ಲ.

## ಕಲಿಕೆ ಗುರಿಗಳು

ಈ ಅಧ್ಯಾಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸುವ ಮೂಲಕ ನೀವು:
- ಆಜೂರ್ ಡೆವಲಪರ್ CLI ಎಂಬದ್ದು ಏನು ಮತ್ತು ಅದು ಆಜೂರ್ CLI ದಿಂದ ಹೇಗೆ ವಿಭಿನ್ನವಾಗಿದೆ ಎಂಬುದನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಿರಿ
- ನಿಮ್ಮ ವೇದಿಕೆ ಮೇಲೆ AZD ಅನ್ನು ಸ್ಥಾಪಿಸಿ ಹಾಗೂ ಸಂರಚಿಸುವಿರಿ
- ನಿಮ್ಮ ಮೊದಲ ಆಜೂರ್ ಆಪ್ಲಿಕೇಶನ್ ಅನ್ನು `azd up` ಮೂಲಕ ನಿಯೋಜಿಸುವಿರಿ
- `azd down` ಮೂಲಕ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಶುದ್ಧಗೊಳಿಸುವಿರಿ

## ✅ ಇಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ: ನಿಮ್ಮ ಸೆಟ್‌ಅಪ್ ಪರಿಶೀಲಿಸಿ

ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು, ನಿಮ್ಮ ಲೋಕಲ್ ಯಂತ್ರವು ಅಧ್ಯಾಯ 1 ಟೆಂಪ್ಲೇಟ್ಗೆ ಸಿದ್ಧವಾಗಿದೆ ಎಂಬುದನ್ನು ದೃಢೀಕರಿಸಿ:

**ವಿಂಡೋಸ್:**
```powershell
.\validate-setup.ps1
```

**ಮ್ಯಾಕ್‌ಒಎಸ್ / ಲಿನಕ್ಸ್ಗಳು:**
```bash
bash ./validate-setup.sh
```

ಸ್ಕ್ರಿಪ್ಟ್ ಕಾರ್ಯಾಲಯದಲ್ಲಿ ಸಹಾಯಕರಿಲ್ಲದ ಸಾಧನಗಳನ್ನು ತಿಳಿಸಿದಾಗ, ಅವನ್ನು ಮೊದಲಾಗಿ ಸರಿಪಡಿಸಿ ನಂತರ ಅಧ್ಯಾಯ ಮುಂದುವರಿಸಿ.

---

## 🚀 ಶೀಘ್ರ ಪ್ರಾರಂಭ

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ ಯಶಸ್ಸಿನ ಮಾನದಂಡಗಳು

ಈ ಅಧ್ಯಾಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದ ಮೇಲೆ, ನೀವು ಸಾಧ್ಯವಾಗಬೇಕು:

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
