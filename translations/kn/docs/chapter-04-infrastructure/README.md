## ಅವಲೋಕನ

ಈ ಅಧ್ಯಾಯದಲ್ಲಿ Bicep ಟೆಂಪ್ಲೇಟುಗಳು, ಸಂಪನ್ಮೂಲ ಒದಗಿಸುವಿಕೆ ಮತ್ತು Azure ಡೆವಲಪರ್ CLI ಬಳಸಿ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್ ತಂತ್ರಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.

> ಆಜ್ಞೆ ಮತ್ತು ಸಂರಚನೆ ವಿಮರ್ಶೆ ಗುರಿ: `azd 1.37.2` (ನವಂಬರ್ 2026). ವಿಮರ್ಶೆ ಸಮಯದಲ್ಲಿ ಲೈವ್ Azure ಒದಗಿಸುವಿಕೆ ನಡೆಯಲಿಲ್ಲ.

## ಕಲಿಕೆ ಗುರಿಗಳು

ಈ ಅಧ್ಯಾಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸುವ ಮೂಲಕ, ನೀವು:
- Bicep ಟೆಂಪ್ಲೇಟಿನ ರಚನೆ ಮತ್ತು ವ್ಯಾಕರಣವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು
- `azd provision` ಬಳಸಿ Azure ಸಂಪನ್ಮೂಲಗಳನ್ನು ಒದಗಿಸುವುದು
- `azd deploy` ಬಳಸಿ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಡಿಪ್ಲಾಯ್ ಮಾಡುವುದು
- ಬ್ಲೂ-ಗ್ರೀನ್ ಮತ್ತು ರೋಲಿಂಗ್ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್ ತಂತ್ರಗಳನ್ನು ಜಾರಿ ಮಾಡುವುದು

## 🚀 ತ್ವರಿತ ಪ್ರಾರಂಭ

```bash
# Initialize from template
mkdir infrastructure-practice
cd infrastructure-practice
azd init --template todo-nodejs-mongo .
azd auth login

# Preview what will be created
azd provision --preview

# Provision infrastructure only
azd provision

# Deploy code only
azd deploy

# Or both together
azd up
```

```
├── infra/                # ← Infrastructure as Code
│   ├── main.bicep        # Entry point
│   ├── main.parameters.json
│   └── modules/          # Reusable components
│       ├── web.bicep
│       └── database.bicep
└── src/                  # Application code
    └── api/
```

## 🔧 ಅಗತ್ಯ ಆದೇಶಗಳು

| ಆದೇಶ | ವಿವರಣೆ |
|---------|-------------|
| `azd init` | ಪ್ರಾಜೆಕ್ಟ್ ಪ್ರಾರಂಭಿಸುವುದು |
| `azd provision` | Azure ಸಂಪನ್ಮೂಲಗಳನ್ನು ರಚಿಸುವುದು |
| `azd deploy` | ಅಪ್ಲಿಕೇಶನ್ ಕೋಡ್ ಅನ್ನು ಡಿಪ್ಲಾಯ್ ಮಾಡುವುದು |
| `azd up` | ಒದಗಿಸುವಿಕೆ + ಡಿಪ್ಲಾಯ್ ಮಾಡುವುದು |
| `azd down` | ಎಲ್ಲಾ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಅಳಿಸುವುದು |
