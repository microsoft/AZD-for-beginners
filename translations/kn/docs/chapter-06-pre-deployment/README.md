# ಅಧ್ಯಾಯ 6: ಪೂರ್ವ-ವಿತರಣ ಯೋಜನೆ ಮತ್ತು ಪರಿಶೀಲನೆ

**📚 ಪಾಠ್ಯಕ್ರಮ**: [ಆಜಡ್ ಫಾರ್ ಆರಂಭಿಕರು](../../README.md) | **⏱️ ಅವಧಿ**: 2-4 ಗಂಟೆಗಳ ಓದು; ಹೊಂದಿಸಲಾಗಿದ ಲ್ಯಾಬ್ಗಳಿಗೆ ಹೆಚ್ಚುವರಿ ಸಮಯ | **⭐ ಜಟಿಲತೆ**: ಮಧ್ಯಮ–ಅಗತ್ಯ

---

## ಅವಲೋಕನ

ನಿಮ್ಮ ಅಪ್ಲಿಕೇಶನ್ ಮಂಜೂರು ಮಾಡುವ ಮುಂಭಾಗ ಅವಶ್ಯಕ ಯೋಜನೆ ಮತ್ತು ಪರಿಶೀಲನೆ ಹಂತಗಳನ್ನು ಈ ಅಧ್ಯಾಯ ಸೇರಿದೆ. ಸರಿಯಾದ ಸಾಮರ್ಥ್ಯ ಯೋಜನೆ, SKU ಆಯ್ಕೆ ಮತ್ತು ಪೂರ್ವಚೆಕ್ ಗಳೊಂದಿಗೆ ದುಬಾರಿ ತಪ್ಪುಗಳನ್ನು ತಡೆಯಿರಿ.

> ಬಿಡುಗಡೆಗೊಂಡ `azd 1.37.2` ಸಂಧ್ಯಾನಿಕೆಯೊಡನೆ ಪರಿಶೀಲಿತ ಆದೇಶ ಮಾರ್ಗದರ್ಶನ. ಮೆಘ ವಿತರಣೆಗಳನ್ನು ನಿರ್ವಹಿಸಲ್ಪಟ್ಟಿಲ್ಲ. ದೀರ್ಘ ಪಾಠಗಳಲ್ಲಿ ದೃಶ್ಯ חלקಗಳು ಸೇರಿವೆ, ಸಂಪೂರ್ಣ ಸ್ಥಳೀಯ ವಿತರಣೆ ಯೋಜನೆಗಳು ಇಲ್ಲ.

## ಅಧ್ಯಯನ ಉದ್ದೇಶಗಳು

ಈ ಅಧ್ಯಾಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸುವ ಮೂಲಕ ನೀವು:
- ಮಂಜೂರು ಮಾಡುವ ಮೊದಲು ಪೂರ್ವಚೆಕ್ ಗಳನ್ನು ನಡೆಸುತ್ತೀರಿ
- ಸಾಮರ್ಥ್ಯವನ್ನು ಯೋಜಿಸಿ ಸಂಪನ್ಮೂಲ ಅಗತ್ಯಗಳನ್ನು ಅಂದಾಜಿಸುತ್ತೀರಿ
- ವೆಚ್ಚ ಕಡಿಮೆ ಮಾಡಲು ಸರಿಯಾದ SKU ಗಳು ಆಯ್ಕೆಮಾಡುತ್ತೀರಿ
- ವೀಕ್ಷಣೆಗೆ ಅಪ್ಲಿಕೇಶನ್ ಇನ್‌ಸೈಟ್ಸ್ ಅನ್ನು ಸಂರಚಿಸುತ್ತೀರಿ
- ಬಹು-ಏಜೆಂಟ್ ಸಂಯೋಜನೆ ಮಾದರಿಗಳನ್ನು ಮತ್ತು ಅವುಗಳ ವಿತರಣೆ ಅಗತ್ಯಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತೀರಿ

## ☑️ ಪೂರ್ವ-ವಿತರಣ ಪರಿಶೀಲನಾ ಪಟ್ಟಿಕೆ

### `azd provision` ಗಿಂತ ಮುಂದೆ

- [ ] ಪ್ರದೇಶಕ್ಕೆ ಹೊಂದಿಕೆಯಾಗಿರುವ ಕ್ವೋಟಾ ಪರಿಶೀಲಿಸಲಾಗಿದೆ
- [ ] SKU ಗಳು ಸರಿಯಾಗಿ ಆಯ್ದಾಯಿತೇ
- [ ] ವೆಚ್ಚ ಅಂದಾಜು ಪರಿಶೀಲಿಸಲಾಗಿದೆ
- [ ] ಹೆಸರಿಡುವ ನಿಯಮವು ಸಮ್ಮಿಲಿತವಾಗಿದೆ
- [ ] ಭದ್ರತೆ/RBAC ಸಂರಚಿಸಲಾಗಿದೆ

### `azd deploy` ಗಿಂತ ಮುಂದೆ

- [ ] ಪರಿಸರ ಬದಲಾವಣೆಗಳ ನಿಯೋಜನೆ
- [ ] ಕೀ ವಾಲ್ಟ್‌ನಲ್ಲಿನ ರಹಸ್ಯಗಳು
- [ ] ಸಂಪರ್ಕ ಸರಣಿಗಳ ಪರಿಶೀಲನೆ
- [ ] ಆರೋಗ್ಯ ಪರಿಶೀಲನೆಗಳು ಸಂರಚಿಸಲಾಗಿದೆ

| ಕೆಲಸದ ಸೋರಿಕೆ | ಅಭಿವೃದ್ಧಿ | ಉತ್ಪಾದನೆ |

| ಕಂಟೈನರ್ ಅಪ್‌ಗಳ | ಸೇವನೆಗೆ ತಕ್ಕಂತೆ | ಸೇವನೆ ಅಥವಾ ಮೀಮಾಂಸಿತ ಕೆಲಸದ ಪ್ರೊಫೈಲ್, ಮಾಪಿತ ಲೋಡ್ ಆಧರಿಸಿ |
| ಅಪ್ ಸರ್ವಿಸ್ | B1/B2 | P1v3+ |
| ಅಜೂರ್ ಓಪನ್‌ಎಐ ಮಾದರಿಗಳು | ಮಾಪನ-ನಿರ್ವಹಣಾ ಮಾರ್ಗವನ್ನು ಬೆಂಬಲಿಸುವುದು | ಸೇವನೆ ಅಥವಾ ಸಂವಿಧಾನಿತ throughput; ಮಾದರಿ/ಪ್ರದೇಶ ಅವಲಂಬಿತ |
| AI ಶೋಧ | ಗಡಿಗಳೊಳಗಿನ ಉಚಿತ/ಮೂಲಭೂತ | ಮೂಲಭೂತ ಅಥವಾ ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಮಟ್ಟ, ಸೂಚ್ಯಂಕ, ಪ್ರತಿರೂಪಗಳು ಮತ್ತು ಪ್ರಶ್ನೆ ಲೋಡ್ ಗಾಗಿ ಗಾತ್ರ ಹೊಂದಿಸಲಾಗಿದೆ |
