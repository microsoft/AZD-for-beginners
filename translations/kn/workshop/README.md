# AZD for AI Developers ಕಾರ್ಯಾಗಾರ

AI ಅಪ್ಲಿಕೇಶನ್ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸಿ Azure Developer CLI (AZD) ಕಲಿಯಲು ಕೈಂಕರ ಪ್ರಾಯೋಗಿಕ ಕಾರ್ಯಾಗಾರಿಗೆ ಸ್ವಾಗತ. ಈ ಕಾರ್ಯಾಗಾರವು AZD ಟೆಂಪ್ಲೇಟ್‌ಗಳ ಅನ್ವಯಿಸಲಾದ ಅರ್ಥವನ್ನು 3 ಹಂತಗಳಲ್ಲಿ ಅರಿಯಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ:

1. **ಅನ್ವೇಷಣೆ** - ನಿಮ್ಮಿಗೆ ಹೊಂದಿಕೊಂಡ ಟೆಂಪ್ಲೇಟ್ ಕಂಡುಹಿಡಿ.
1. **ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್** - ಡಿಪ್ಲಾಯ್ ಮಾಡಿ ಮತ್ತು ಕೆಲಸ ಮಾಡುತ್ತಿದೆಯೆಂದು ಪರಿಶೀಲಿಸಿ
1. **ಸ೦ಶೋಧನೆ** - ಸಂಪಾದಿಸಿ ಮತ್ತು ನಿಮ್ಮದಾಗಿಸಿಕೊಳ್ಳಿ!

ಈ ಕಾರ್ಯಾಗಾರದ ಅವಧಿಯಲ್ಲಿ ನೀವು ಮೂಲ ಡೆವಲಪರ್ ಉಪಕರಣಗಳು ಮತ್ತು ವರ್ಕ್‌ಫ್ಲೋಗಳಿಗೂ ಪರಿಚಿತರಾಗುತ್ತೀರಿ, ಇದು ನಿಮ್ಮ ಸಂಪೂರ್ಣ ಅಭಿವೃದ್ಧಿ ಪ್ರಯಾಣವನ್ನು ಸರಳಗೊಳಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

<br/>

## ಬ್ರೌಸರ್ ಆಧಾರಿತ ಮಾರ್ಗದರ್ಶಿ

ಕಾರ್ಯಾಗಾರ ಪಾಠಗಳು Markdown ರೂಪದಲ್ಲಿ ಇವೆ. ನೀವು ಅವುಗಳನ್ನು ನೇರವಾಗಿ GitHub ನಲ್ಲಿ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಬಹುದು - ಅಥವಾ ಕೆಳಗಿನ ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ನಲ್ಲಿ ತೋರಿಸುತ್ತಿರುವಂತೆ ಬ್ರೌಸರ್ ಆಧಾರಿತ ಪೂರ್ವವೀಕ್ಷಣೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ.

![Workshop](../../../translated_images/kn/workshop.75906f133e6f8ba0.webp)

ಈ ಆಯ್ಕೆಯನ್ನು ಬಳಸಲು - ಫೋರ್ಕ್ ಅನ್ನು ನಿಮ್ಮ ಪ್ರೊಫೈಲ್‌ಗೆ ಮಾಡಿ, ಮತ್ತು GitHub Codespaces ಪ್ರಾರಂಭಿಸಿ. VS ಕೋಡ್ ಟರ್ಮಿನಲ್ ಸಕ್ರಿಯವಾದ ನಂತರ, ಈ ಆಜ್ಞೆಯನ್ನು ಟೈಪ್ ಮಾಡಿ:

ಈ ಬ್ರೌಸರ್ ಪೂರ್ವವೀಕ್ಷಣೆ GitHub Codespaces, ಡೆವ್ ಕಂಟೇನರ್‌ಗಳು, ಅಥವಾ Python ಮತ್ತು MkDocs ಸ್ಥಾಪಿಸಿದ ಸ್ಥಳೀಯ ಕ್ಲೋನ್‌ನಲ್ಲಿ ಕೆಲಸಮಾಡುತ್ತದೆ.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

ಈ ಕಮಾಂಡ್‌ಗಳನ್ನು **ಕೋರ್ಸ್ ರಿಪೋಜಿಟರಿ ರೂಟ್** ಬಳಿ ಓಡಿಸಿ, ಸ್ವತಂತ್ರವಾಗಿ ಪ್ರಾರಂಭಗೊಂಡ AI ಮಾದರಿ ಅಲ್ಲ. ಮುಂದುನೋಡಿಕೆಯನ್ನು ಮುಂಭಾಗದಲ್ಲಿ ಇಟ್ಟುಕೊಳ್ಳಿ যাতে ದೋಷಗಳು ಕಾಣಿಸಿಬರುತ್ತವೆ; Ctrl+C ನಿಂದ ಅದನ್ನು ನಿಲ್ಲಿಸಿ. ಸರ್ವ್ ಮಾಡದೆ ಈ ಸೈಟ್ ಅನ್ನು ಪರಿಶೀಲಿಸಲು, `python -m mkdocs build --strict --config-file workshop/mkdocs.yml` ನಡಿಸಿ.

ಕೆಲವು ಕ್ಷಣಗಳಲ್ಲಿ, ನೀವು ಒಂದು ಪಾಪ್-ಅಪ್ ಸಂವಾದವನ್ನು ನೋಡುತ್ತೀರಿ. `Open in browser` ಆಯ್ಕೆಮಾಡಿ. ವೆಬ್ ಆಧಾರಿತ ಮಾರ್ಗಸೂಚಿ ಈಗ ಹೊಸ ಬ್ರೌಸರ್ ಟ್ಯಾಬ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ. ಈ ಮುಂದುನೋಟದ ಕೆಲವು ಲಾಭಗಳು:

1. **ಆಂತರಿಕ ಹುಡುಕು** - ಕೀವರ್ಡ್‌ಗಳು ಅಥವಾ ಪಾಠಗಳನ್ನು ತ್ವರಿತವಾಗಿ ಹುಡುಕಿ.
1. **ನಕಲು ಐಕಾನ್** - ಕೋಡ್‌ಬ್ಲಾಕ್‌ಗಳ ಮೇಲೆ ಹೋವರ್ ಮಾಡಿದಾಗ ಇದೇ ಆಯ್ಕೆ ಕಾಣುತ್ತದೆ
1. ** ಥೀಮ್ ٹಾಗಲ್** - ಡಾರ್ಕ್ ಮತ್ತು ಲೈಟ್ ಥೀಮ್‌ಗಳ ನಡುವೆ ಬದಲಾಯಿಸಿ
1. **ಸಹಾಯ ಪಡೆದುಕೊಳ್ಳಿ** - ಅಡಿಲಿನಲ್ಲಿ ಇರುವ Discord ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಿ ಸೇರಲು!

- ** ಪ್ರಯೋಗಾಲಯ**: Codespaces ಅಥವಾ ಡೆವ್ ಕಂಟೇನರ್‌ನಲ್ಲಿ ತ್ವರಿತ ಪ್ರಾರಂಭ

### [ಘಟಕ 3: AI ಟೆಂಪ್ಲೇಟನ್ನು ಪಾರ್ಶ್ವವಾಯು ಮಾಡು](docs/instructions/3-Deconstruct-AI-Template.md) (30 ನಿಮಿಷಗಳು)

- ನಿಮ್ಮ ಪರಿಸರವನ್ನು `.azure/` ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ 
- ನಿಮ್ಮ ಸಂಪನ್ಮೂಲ ಹೊಂದಿಕೆಯನ್ನು `infra/` ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ 
- ನಿಮ್ಮ AZD ಸಂರಚನೆಯನ್ನು `azure.yaml` ಗಳು ವಿವರಣೆ ಮಾಡಿ
- ** ಪ್ರಯೋಗಾಲಯ**: ಪರಿಸರ ವ್ಯತ್ಯಾಸಗಳನ್ನು ಬದಲಾಯಿಸಿ ಮತ್ತು ಮರುನಿಯೋಜಿಸಿ

- ** ಪ್ರಯೋಗಾಲಯ**: AI ಏಜೆಂಟ್ ಮತ್ತು ನಿರೀಕ್ಷಣೆ ಪರಿಶೀಲನೆ

### [ಘಟಕ 5: AI ಟೆಂಪ್ಲೇಟನ್ನು ಕಸ್ಟಮೈಸ್ ಮಾಡು](docs/instructions/5-Customize-AI-Template.md) (30 ನಿಮಿಷಗಳು)
