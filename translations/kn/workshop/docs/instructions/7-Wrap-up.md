| ಮಾಯಾಜಾಲಿಕೆ | ಸಾಧನೆ |
|:---|:---|
| **ಮಾಡ್ಯೂಲ್ 1** | ಅಜ್ಯೂರ್ ಡೆವಲಪರ್ CLI ಮತ್ತು AI ಟೆಂಪ್ಲೇಟ್ ಆಯ್ಕೆಮಾಡುಲಿ |
| **ಮಾಡ್ಯೂಲ್ 2** | ಸಂಪೂರ್ಣ AI ಏಜೆಂಟ್ ಪರಿಹಾರವನ್ನು ನಿಯೋಜಿಸಿ ಪರಿಶೀಲನೆ ಮಾಡುಲಿ |
| **ಮಾಡ್ಯೂಲ್ 3** | ಟೆಂಪ್ಲೇಟ್ ನೆಲತಳವನ್ನು ವಿಶ್ಲೇಷಿಸಿ ಅದರ ವಾಸ್ತುಶಿಲ್ಪವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ |
| **ಮಾಡ್ಯೂಲ್ 4** | `azure.yaml` ಸಂರಚನೆ ಮತ್ತು ಲೈಫ್ಸೈಕಲ್ ಹೂಕ್‌ಗಳನ್ನು ಸಂಶೋಧಿಸಿದಿರಿ |
| **ಮಾಡ್ಯೂಲ್ 5** | ನಿಮ್ಮ ಸ್ವಂತ ಪರಿಸ್ಥಿತಿಗೆ ಟೆಂಪ್ಲೇಟ್ ಅನ್ನು ಕಸ್ಟಮೈಸ್ ಮಾಡಿದಿರಿ |
| **మಾಡ್ಯೂಲ್ 6** | ಭದ್ರವಾಗಿ ಮೈದಾನ ಕಟ್ಟಡವನ್ನು ಕೆಡವಿರಿ ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳನ್ನು ನಿರ್ವಹಿಸಿದಿರಿ |

## 2. ಪ್ರಮುಖ ಕಲಿತ ಸಂಯುಕ್ತ ಕಾನ್ಸೆಪ್ಟ್‌ಗಳು

### ಅಜ್ಯూర్ ಡೆವಲపರ್ CLI (azd)
- `azd init` - ಟೆಂಪ್ಲೇಟ್‌ಗಳಿಂದ ಯೋಜನೆಗಳನ್ನು ಪ್ರಾರಂಭಿಸಿ
- `azd up` - ಒಬ್ಬ ಆದೇಶದಲ್ಲಿ ಒದಗಿಸುವುದು ಮತ್ತು ನಿಯೋಜನೆ
- `azd env` - ಪರಿಸರ ಚರಗಳನ್ನು ನಿರ್ವಹಿಸಿ
- `azd down` - ಸಂಪನ್ಮೂಲಗಳನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ಸ್ವಚ್ಛಗೊಳಿಸಿ

### AZD ಟೆಂಪ್ಲೇಟ್ ರಚನೆ
- `azure.yaml` - ಸಂರಚನೆ ಮತ್ತು ನಿಯೋಜನೆ ಹೂಕ್‌ಗಳು
- `infra/` - ಬೈಸೆಪ್ ಮೂಲಸೌಕರ್ಯ-ಆರ್-ಕೋಡ್
- `src/` - ಅಪ್ಲಿಕೇಶನ್ ಮೂಲ ಕೋಡ್
- `scripts/` - ಸ್ವಯಂಚಾಲನಾ ಮತ್ತು ಸೆಟಪ್ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು

### ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರೀ ಸಾಮರ್ಥ್ಯಗಳು
- ಬುದ್ಧಿವಂತ ಸಹಾಯಕರೆಂದು AI ಏಜೆಂಟ್ ಸೇವೆ
- ಫೈಲ್ ಸರ್ಚ್ ಮತ್ತು ಅಜ್ಯೂರು AI ಸರ್ಚ್ ಜ್ಞಾನ ಹಿಂತಿರುಗಿಸುವಿಕೆಗಾಗಿ
- ನಿರ್ಮಿತ ಟ್ರೇಸಿಂಗ್, ನಿಗಾವಳಿ ಮತ್ತು ಮೌಲ್ಯಮಾಪನ
- AI ಭದ್ರತೆ ಮಾನ್ಯತೆಗೆ ರೆಡ್ ಟೀಮಿಂಗ್

## 3. ನಿಮ್ಮ ಕಲಿಕೆ ಪ್ರಯಾಣವನ್ನು ಮುಂದುವರೆಸಿ

### ಶಿಫಾರಸು ಮಾಡಿದ ಮುಂದಿನ ಹಂತಗಳು

| ಮಾರ್ಗ | ಸಂಪನ್ಮೂಲ | ಸಮಯ |
|:---|:---|:---|
| **ಪೂರ್ಣ ಕೋರ್ಸು** | [ಅಜ್‌ಡೀ ಬಿಗಿನರ್ಸ್ ಓದಲು](https://github.com/microsoft/AZD-for-beginners/blob/main/README.md) | ಸ್ವಯಂ-ಮಾರ್ಗದರ್ಶಿತ |
| **ಮುಂದಿನ ಟೆಂಪ್ಲೇಟ್ ಪ್ರಯತ್ನಿಸಿ** | [ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರೀ ಟೆಂಪ್ಲೇಟ್‌ಗಳು](https://ai.azure.com/templates) | 1-2 ಗಂಟೆಗಳು |
| **ತಿಳಿದುಕೊಳ್ಳಿ ಇನ್ನಷ್ಟು** | [ಅಜ್ಯೂರು ಡೆವಲಪರ್ CLI ದಾಖಲೆ](https://learn.microsoft.com/azure/developer/azure-developer-cli/) | ಮುಂದುವರೆಯುವ |
| **ಸಮುದಾಯ** | [ಅಜ್ಯೂರು ಡಿಸ್ಕಾರ್ಡ್](https://aka.ms/foundry/discord) | ಇಂದು ಸೇರಿ! |

### ಮುಂದಿನ ಸಲಹೆಗಳು: ಪ್ರಯತ್ನಿಸಲು ಟೆಂಪ್ಲೇಟ್‌ಗಳು

1. **[AI ಚಾಟ್ ನೊಂದಿಗೆ ಪ್ರಾರಂಭಿಸಿ](https://github.com/Azure-Samples/get-started-with-ai-chat)** - ನಿಮ್ಮ ಡೇಟಾದೊಂದಿಗೆ ಮೂಲಭೂತ ಚಾಟ್
2. **[ಅಜ್ಯೂರ್ ಶೋಧ OpenAI ಡೆಮೊ](https://github.com/Azure-Samples/azure-search-openai-demo)** - ಉನ್ನತ RAG ಮಾದರಿಗಳು
3. **[ಕಾಂಟೋಸೋ ಚಾಟ್](https://github.com/Azure-Samples/contoso-chat)** - ಉದ್ಯಮ ರೀಟೇಲ್ ಪರಿಸ್ಥಿತಿಗಳು

## 4. ಕಾರ್ಯಾಗಾರ ಚಾಲೆಂಜ್

ನಿಮ್ಮ ಕೌಶಲ್ಯಗಳನ್ನು ಪರೀಕ್ಷಿಸಲು ಸಿದ್ಧರಾ? ಈ ಚಾಲೆಂಜ್‌ಗಳನ್ನು ಪ್ರಯತ್ನಿಸಿ:

| ಚಾಲೆಂಜ್ | ವಿವರಣೆ | ಕಷ್ಟಸ್ತರಿ |
|:---|:---|:---|
| **1. ಬಹು-ಏಜೆಂಟ್ ಪರಿಸ್ಥಿತಿ** | ಬೇರೆ ಕೈಗಾರಿಕೆ (ಉದಾ., ಆರೋಗ್ಯ, ಹಣಕಾಸು)ಗಾಗಿ ನಿಯೋಜಿಸಿ ಮತ್ತು ಕಸ್ಟಮೈಸ್ ಮಾಡಿ | ⭐⭐ |
| **2. ಕಸ್ಟಮ್ ಜ್ಞಾನಾಧಾರ** | ನಿಮ್ಮ ಸ್ವಂತ ಡೇಟಾ ಫೈಲ್‌ಗಳನ್ನು ಸೇರಿಸಿ ಮತ್ತು ಕಸ್ಟಮ್ ಶೋಧ ಸೂಚ್ಯಂಕ ರಚಿಸಿ | ⭐⭐⭐ |
| **3. ಉತ್ಪಾದನಾ ನಿಯೋಜನೆ** | `azd pipeline config` ಉಪಯೋಗಿಸಿ GitHub Actions ಮೂಲಕ CI/CD ಸೆಟಪ್ ಮಾಡಿ | ⭐⭐⭐⭐ |
