# AI ಡೆವಲಪರ್‌ಗಳಿಗಾಗಿ AZD ಕಾರ್ಯಾಗಾರ

> ಮೂಲ ಮಾರ್ಗದರ್ಶನವನ್ನು ನವೆಂಬರ್ 4, 2026 ರಂದು AZD 1.37.2 ನೊಂದಿಗೆ ಪರಿಶೀಲಿಸಲಾಗಿದೆ. ಚಿತ್ರಣಗಳು ಉದಾಹರಣಾರ್ಥ; ಸೇವೆಗಳ ಲಭ್ಯತೆ, ಪೋರ್ಟಲ್ ಲೇಬಲ್ಗಳು ಮತ್ತು ಟೆಂಪ್ಲೇಟ್ ಡೀಫಾಲ್ಟ್‌ಗಳು ಬದಲಾಗಬಹುದು.

> [!IMPORTANT]  
> **ಈ ಕಾರ್ಯಾಗಾರವು ಕಾರ್ಯಾಗಾರ ಗೈಡ್‌ಗಾಗಿ ಯಂತ್ರಸಾಮಗ್ರಿ ಹೊಂದಿದ್ದು, ನೀವು ನಿಮ್ಮ ಸ್ಥಳೀಯ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಪೂರ್ವದೃಶ್ಯ ವೀಕ್ಷಿಸಬಹುದು. ಪ್ರಾರಂಭಿಸಲು, GitHub Codespaces, ಡೆವ್ ಕಂಟೈನರ್ ಅಥವಾ MkDocs ಸ್ಥಾಪಿತ ಲೋಕ್ ಕ್ಲೋನ್‌ನಲ್ಲಿ ರೆಪೊ ತೆರೆಯಿರಿ — ನಂತರ ಸಕ್ರಿಯ VS Code ಟರ್ಮಿನಲ್ ಕಾಣುವವರೆಗೆ ಕಾಯಿರಿ ಮತ್ತು ಟೈಪ್ ಮಾಡಿ:**  
> ಕೋರ್ಸ್ ರೆಪೊ ರೂಟ್‌ನಿಂದ `requirements-dev.txt` ಅನ್ನು ಸ್ಥಾಪಿಸಿ, ಬಳಿಕ `python -m mkdocs serve --config-file workshop/mkdocs.yml` ನ್ನು ಮೊಖಾಂಗವಾಗಿ ಚಾಲನೆ ಮಾಡಿ.
> **ನೀವು ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಪೂರ್ವದೃಶ್ಯ ಪುಟವನ್ನು ತೆರೆಯಲು ಪಾಪ್-ಅಪ್ ಸಂಭಾಷಣೆ ಕಾಣಬೇಕು.**

Azure ಡೆವಲಪರ್ CLI (AZD) ಅನ್ನು ಮಾರ್ಗದರ್ಶಿಸುತ್ತಿರುವ ಕೈಗಾರಿಕಾ ಕಾರ್ಯಾಗಾರಕ್ಕೆ ಸ್ವಾಗತ, ವಿಶೇಷವಾಗಿ AI ಅಪ್ಲಿಕೇಶನ್ ಡಿಪ್ಲಾಯ್ಮೆಂಟ್ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸಿದೆ. ಈ ಕಾರ್ಯಾಗಾರವು ನಿಮಗೆ 3 ಹಂತಗಳಲ್ಲಿ AZD ಟೆಂಪ್ಲೇಟ್‌ಗಳ ಅನ್ವಯಿತ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಿಕೆಗೆ ಸಹಾಯ ಮಾಡುತ್ತದೆ:

1. **ಅನ್ವೇಷಣೆ** - ನಿಮ್ಮಿಗೆ ತಕ್ಕ ಟೆಂಪ್ಲೇಟ್ ಅನ್ನು ಹುಡುಕಿ.
1. **ಡಿಪ್ಲಾಯ್ಮೆಂಟ್** - ಡಿಪ್ಲಾಯ್ ಮಾಡಿ ಮತ್ತು ಅದು ಕೆಲಸ ಮಾಡುತ್ತಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ.
1. **ಅನುಕೂಲನೆ** - ಸ್ಪಷ್ಟಪಡಿಸಿ ಮತ್ತು ಅನೇಕ ಬಾರಿ ಮಾಡಿ, ನಿಮ್ಮದೇ ಆಗಿಸಿ!

ಈ ಕಾರ್ಯಾಗಾರದಾನಂತರ, ನೀವು ಕೋರ್ ಡೆವಲಪರ್ ಸಾಧನಗಳು ಮತ್ತು ಕೆಲಸಗಳ ಪ್ರವಾಹಗಳನ್ನು ಪರಿಚಯಪಡುತೀರಿ, ಇದು ನಿಮ್ಮ ಪ್ರಯಾಣವನ್ನು ಸುಗಮಮಾಡಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

## ಕಾರ್ಯಾಗಾರ ಸಾರಾಂಶ

**ಅವಧಿ:** 3-4 ಗಂಟೆಗಳು  
**ನಿವಂಧನೆ:** ಆರಂಭಿಕರಿಂದ ಮಧ್ಯಮವರೆಗೆ  
**ಪೂರ್ವಪುಟಗಳು:** ಅಜೂರ್, AI ತತ್ವಗಳು, VS Code & ಕಮನ್ಡ್ ಲೈನ್ ಸಾಧನಗಳ ಬಗ್ಗೆ ಪರಿಚಿತತೆ.

ಇದೇ ಒಂದು ಕೈಗಾರಿಕಾ ಕಾರ್ಯಾಗಾರವಾಗಿದೆ, ನೀವು ಮಾಡಿದುದರಿಂದ ಕಲಿಯುವಿರಿ. ವ್ಯಾಯಾಮಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದ ನಂತರ, ನೀವು AZD For Beginners ಪಠ್ಯಕ್ರಮವನ್ನು ಪರಿಶೀಲಿಸಲು ಶಿಫಾರಸು ಮಾಡುತ್ತೇವೆ, ಇದರಿಂದ ನೀವು ಭದ್ರತೆ ಮತ್ತು ಉತ್ಪಾದಕತೆ ಚೆನ್ನಾದ ಅಭ್ಯಾಸಗಳ ಬಗ್ಗೆ ಕಲಿಕೆಯನ್ನ ಮುಂದುವರೆಸಬಹುದು.

| 30 ನಿಮಿಷಗಳು | AI ಟೆಂಪ್ಲೇಟ್ ಪರಿಶೀಲಿಸಿ | ಡೀಫಾಲ್ಟ್ ಪರಿಹಾರವನ್ನು ಅಜೂರ್‌ಗೆ ಡಿಪ್ಲಾಯ್ ಮಾಡಿ |

## ನೀವು ಏನು ಕಲಿಯುತ್ತೀರಿ

AZD ಟೆಂಪ್ಲೇಟ್ ಅನ್ನು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿ ಮೇಲೆ ಅಂತ್ಯದಿಂದ ಅಂತ್ಯದ ಅಭಿವೃದ್ಧಿಗಾಗಿ ವಿವಿಧ ಸಾಮರ್ಥ್ಯಗಳು ಮತ್ತು ಸಾಧನಗಳನ್ನು ಅನ್ವೇಷಿಸಲು ಕಲಿಕೆಯ ಸ್ಯಾಂಡ್‌ಬಾಕ್ಸ್ ಎಂದು ಭಾವಿಸಿ. ಈ ಕಾರ್ಯಾಗಾರದ ಅಂತ್ಯದಲ್ಲಿ, ನೀವು ಈ ಪ್ರಬಂಧದಲ್ಲಿ ವಿವಿಧ ಸಾಧನಗಳು ಮತ್ತು ತತ್ವಗಳನ್ನು ಸ್ವಾಭಾವಿಕವಾಗಿ ತಿಳಿದುಕೊಳ್ಳಬೇಕು.

| ತತ್ವ  | ಗುರಿ |
|:---|:---|
| **ಅಜೂರ್ ಡೆವಲಪರ್ CLI** | ಸಾಧನ ಆಜ್ಞೆಗಳು ಮತ್ತು ಕಾರ್ಯವಿಧಾನಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ|
| **AZD ಟೆಂಪ್ಲೇಟ್‌ಗಳು**| ಹೋಗುವಿಕೆ ರಚನೆ ಮತ್ತು ಸಂರಚನೆಯನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ|
| **ಅಜೂರ್ AI ಏಜೆಂಟ್**| ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ಪ್ರೊವಿಶನ್ ಮತ್ತು ಡಿಪ್ಲಾಯ್ ಮಾಡಿ |
| **ಅಜೂರ್ AI ಹುಡುಕು**| ಏಜೆಂಟ್‌ಗಳೊಂದಿಗೆ ಸಾಂದರ್ಭಿಕ ಎಂಜಿನಿಯರಿಂಗ್ ನಿಷ್ಪಾದನೆ ಮಾಡಿ |
| **ನಿರೀಕ್ಷಣೀಯತೆ**| ಟ್ರೇಸಿಂಗ್, ನಿಯಂತ್ರಣ ಮತ್ತು ಮೌಲ್ಯಮಾಪನಗಳನ್ನು ಅನ್ವೇಷಿಸಿ |
| **ರೆಡ್ ಟೀಮಿಂಗ್**| ಪ್ರತಿಸ್ಪರ್ಧಾತ್ಮಕ ಪರೀಕ್ಷೆಗಳು ಮತ್ತು ಕಡಿತ ಕ್ರಮಗಳನ್ನು ಅನ್ವೇಷಿಸಿ |
| | |
