# Mikroservisler Örneği

Çalıştırılabilir uygulama ve talimatları
**[container-app/microservices](../container-app/microservices/README.md)** dizinindedir.

Bu dizin sadece gezinmek içindir. İçinde `azure.yaml`, `infra/` veya `src/` yoktur.
Burada `azd up` çalıştırmayın.

Depo kökünden:

```bash
cd examples/container-app/microservices
```

Ardından, ön koşullar, dağıtım, doğrulama, yerel geliştirme, pratik egzersizler, maliyetler ve temizlik için bağlantılı README dosyasını takip edin.


Sipariş, kullanıcı, bildirim, veritabanı ve mesajlaşma servisleri, bu depoda bulunmayan genişletme fikirleridir,
uygulamalar değildir.

- [Sonraki: Veritabanı uygulaması](../../../../examples/database-app)
