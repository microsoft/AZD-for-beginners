# AZD ఫర్ బిగినర్స్‌కు సహకరించడం

AZD ఫర్ బిగినర్స్ కోర్సుకు సహకరించడంలో మీ ఆసక్తికి ధన్యవాదాలు! ఈ డాక్యుమెంట్ సహకారుల కోసం మార్గదర్శకాలు మరియు సమాచారాన్ని అందిస్తుంది.

## ఎలా సహకరించాలి

### సమస్యలు నివేదించడం

మీరు బగ్స్, లోపాలు కనుగొంటే లేదా మెచ్చుకోలేకపోయే మార్పుల కోసం సూచనలు ఉంటే:

1. **ఉన్న సమస్యలను పరిశీలించండి**: నకిలీ సమస్యలు కలిగి ఉండకుండా [ఉన్న సమస్యలను](https://github.com/microsoft/azd-for-beginners/issues) శోధించండి  
2. **కొత్త సమస్య సృష్టించండి**: సరైనissue teamplate ని ఉపయోగించండి  
3. **వివరాలు అందించండి**: పునరుత్పత్తి చేయడానికి చర్యలు, ఆశించిన ప్రవర్తన మరియు అవసరమైతే స్క్రీన్‌షాట్లను చేర్పించండి  

### మార్పులను ప్రతిపాదించడం

1. **రిపాజిటరీని Fork చేయండి**: ప్రాజెక్ట్ యొక్క మీ స్వంత fork సృష్టించండి  
2. **బ్రాంచ్ సృష్టించండి**: మీ మార్పుల కోసం ఒక ఫీచర్ బ్రాంచ్ సృష్టించండి  
3. **మార్పులు చేయండి**: మా కోడింగ్ మరియు డాక్యుమెంటేషన్ ప్రమాణాలను అనుసరించండి  
4. **మీ మార్పులను పరిక్షించండి**: అన్ని లింకులు పనిచేస్తున్నాయో మరియు కంటెంటు సరిగా చూపబడుతున్నదో నిర్ధారించండి  
5. **పుల్ రిక్వెస్ట్ సమర్పించండి**: మీ మార్పుల యొక్క స్పష్టమైన వివరణ ఇవ్వండి  

### సహకార రకాలు

మేము ఈ క్రింది రకాల సహకారాలను ఆహ్వానిస్తున్నాము:

#### కంటెంట్ మెరుగుదలలు
- తప్పుల, వ్యాకరణ, మరియు ఫార్మాటింగ్ సమస్యలను సరిచేయండి  
- ఉన్న డాక్యుమెంటేషన్ స్పష్టతను మెరుగుపరచండి  
- పాత సమాచారాన్ని నవీకరించండి  
- మిస్సింగ్ వివరణలు లేదా పరిసరాలను చేర్చండి  

#### కొత్త ఉదాహరణలు
- వాస్తవ ప్రపంచంలో వాడుక సందర్భాలను జోడించండి  
- సాధారణ వాడుక సందర్భాల కోసం కొత్త AZD టెంప్లేట్లను సృష్టించండి  
- అదనపు కోడ్ నమూనాలు మరియు వ్యాయామాలు అందించండి  

#### అనువాద మద్దతు
- ఉన్న అనువాదాలను నిర్వహించడంలో సహాయం చేయండి  
- అనువాద నాణ్యతను మెరుగుపరచండి  
- కొత్త కంటెంట్ కోసం అనువాదాలను జోడించండి  

#### బగ్ నివేదికలు
- బ్రోకెన్ లింకులు లేదా తప్పు కోడ్ ఉదాహరణలను నివేదించండి  
- డాక్యుమెంటేషన్ అసంగతులను గుర్తించండి  
- యాక్సెసిబిలిటీ సమస్యలను పరికించండి  

## సహకార మార్గదర్శకాలు

### డాక్యుమెంటేషన్ ప్రమాణాలు

- స్పష్టమైన, ప్రారంభ దశ విద్యార్థులకు అనువైన భాషను ఉపయోగించండి  
- నేర్చుకునే లక్ష్యాలు మరియు ఫలితాలను చేర్చండి  
- పద్ధతులు మరియు ఆశించిన ఫలితాలతో శ్రేణి సూచనలు ఇవ్వండి  
- సంబంధిత కంటెంట్‌కు నావిగేషన్ లింకులు జోడించండి  
- సరిపోలిన ఫార్మాటింగ్ మరియు మార్క్డౌన్ శైలిని ఉపయోగించండి  

### కోడ్ ఉదాహరణలు

- అన్ని కోడ్ ఉదాహరణలు పరీక్షించి పని చేస్తున్నాయని నిర్ధారించండి  
- కీలక కాన్సెప్టులను వివరిస్తున్న వ్యాఖ్యానాలను చేర్చండి  
- Azure మరియు AZD ఉత్తమ సాధనాలను అనుసరించండి  
- అవసరమైతే ఆశించిన ఫలితాలను అందించండి  

### ఇంగ్లీష్ డాక్యుమెంటేషన్‌ను ధృవీకరించండి

రిపాజిటరీ రూట్ నుండి, ఉన్న అభివృద్ధి అవసరాలను ఇన్‌స్టాల్ చేసి, ఆ పని చేయండి:

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s .github/scripts -p "test_*.py"
python .github/scripts/check_links.py
python -m mkdocs build --strict --config-file workshop/mkdocs.yml
```

ఆఫ్‌లైన్ లింక్ చెకర్ ఇంగ్లీష్ మార్క్డౌన్/HTML మార్గాలు, శీర్షికలు, స్పష్టమైన యాన్కర్లు, మరియు ఖాళీ లింక్ ప్లేస్‌హోల్డర్స్‌ను తనిఖీ చేస్తుంది. ఇది ఉత్పన్నమైన `translations/` మరియు `translated_images/`, ఆ సంభందిత ఫోల్డర్లలో లింకులను మినహాయిస్తుంది. ఇది బాహ్య వెబ్‌సైట్లను పొందదు లేదా Azure నియామకాలని ధృవీకరించదు. విఫలమయ్యే క్లుప్త సమాచారం, మరియు బాహ్య URL జాబితాను వేరే నెట్‌వర్క్ తనిఖీ కోసం `--json <report-path>` ఉపయోగించండి. సాంకేతిక సూచనలను మార్చేటప్పుడు ప్రస్తుత అప్‌స్ట్రీమ్ ఆదేశాలు మరియు నమూనా ముందస్తు అవసరాలను ధృవీకరించండి; పరీక్షించిన అనువర్తనాలను డిజైన్ బూడింపు పత్రాల నుండి వేరు చేయండి.

### కమిట్ సందేశాలు

- `feat: add new container app example`
