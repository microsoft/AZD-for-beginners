# అధ్యాయం 6: ప్రీ-డిప్లాయ్‌మెంట్ ప్లానింగ్ & ధృవీకరణ

## అవలోకనం

మీ అప్లికేషన్‌ను మోపే ముందు అవసరమైన ప్రణాళిక మరియు ధృవీకరణ దశలను ఈ అధ్యాయం కవర్ చేస్తుంది. సక్రమమైన సామర్థ్య ప్రణాళిక, SKU ఎంపిక మరియు ప్రీఫ్లైట్ తనిఖీలతో ఖర్చుతో కూడిన పొరపాట్లను నివారించవచ్చు.

> విడుదల చేసిన `azd 1.37.2` సూచికను పరిశీలించిన కమాండ్ మార్గదర్శకాలు. క్లౌడ్ డిప్లాయిమెంట్లు అమలు చేయలేదు. పొడవైన పాఠాలు పూర్తి స్థానిక డిప్లాయ్‌మెంట్ ప్రాజెక్టులు కాదు, అవి ఉదాహరణ భాగాలను మాత్రమే అందిస్తాయి.

## అభ్యసన లక్ష్యాలు

ఈ అధ్యాయాన్ని పూర్తి చేస్తే, మీరు:
- డిప్లాయ్‌మెంట్ ముందున ప్రీఫ్లైట్ తనిఖీలు నిర్వహిస్తారు
- సామర్థ్య ప్రణాళిక మరియు వనరుల అవసరాలను అంచనా వేస్తారు
- ఖర్చు ఆప్టిమైజేషన్ కోసం సరైన SKUలను ఎంచుకుంటారు
- మానిటరింగ్ కోసం అప్లికేషన్ ఇన్సైట్స్‌ను కాన్ఫిగర్ చేయగలరు
- మల్టీ-ఏజెంట్ సమన్వయ నమూనాలు మరియు వాటి డిప్లాయ్‌మెంట్ అవసరాలను అర్థం చేసుకుంటారు

## ☑️ ప్రీ-డిప్లాయ్‌మెంట్ చెక్‌లిస్ట్

### `azd provision` ముందు

- [ ] ప్రాంతానికి క్వాటా ధృవీకరించబడింది
- [ ] SKUలు సరైన విధంగా ఎంచుకోబడ్డాయి
- [ ] ఖర్చు అంచనా సమీక్షించబడింది
- [ ] నామకరణ సిద్ధాంతం సారూప్యంగా ఉంది
- [ ] భద్రత/RBAC కాన్ఫిగర్ చేయబడింది

### `azd deploy` ముందు

- [ ] పరిసర变量్లు సెటప్ చేయబడ్డాయి
- [ ] కీ వాల్ట్‌లో రహస్యాలు ఉన్నాయి
- [ ] కనెక్షన్ స్ట్రింగ్స్ ధృవీకరించబడ్డాయి
- [ ] ఆరోగ్య తనిఖీలు కాన్ఫిగర్ చేయబడ్డాయి
