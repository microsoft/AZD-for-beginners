# అధ్యాయం 7: సమస్య పరిష్కారం & డీబగ్గింగ్

## అవలోకనం

ఈ అధ్యాయం Azure Developer CLIతో పని చేస్తుండగా చోటు చేసుకొనే సాధారణ సమస్యలను గుర్తించి పరిష్కరించడంలో సహాయపడుతుంది. నియోజకవర్గ విఫలముల నుండి AI-సంబంధిత సమస్యల వరకు.

> విడుదల చేసిన `azd 1.37.2` సూచికతో సమీకరించి ఆదేశ సూచన. క్లౌడ్ నియోజకవర్గాలు అమలు చేయబడలేదు. ఆదేశాలు ఉపయోగించే ముందు ఉదాహరణ వనరుల పేర్లు మరియు IDలను మార్చండి.

## నేర్చుకోవడానికి లక్ష్యాలు

ఈ అధ్యాయం పూర్తి చేసిన తరువాత మీరు:
- సాధారణ AZD నియోజకవర్గ విఫలములను గుర్తించగలుగుతారు
- ప్రామాణీకరణ మరియు అనుమతి సమస్యలను డీబగ్గ్ చేయగలుగుతారు
- AI సేవా కనెక్టివిటీ సమస్యలను పరిష్కరించగలుగుతారు
- సమస్య పరిష్కారానికి Azure పోర్టల్ మరియు CLI ఉపయోగించగలుగుతారు

## 🚨 తక్షణ పరిష్కారాలు

### ప్రామాణీకరణ సమస్యలు
```bash
# Required for AZD workflows
azd auth login

# Optional if you are also using Azure CLI commands directly
az login

azd auth login --check-status
```

### నియోజకవర్గ విఫలములు
```bash
azd show
azd monitor --logs
az deployment sub list --query "[?properties.provisioningState!='Succeeded']"
```

### వనరు విరోధాలు
ఎటువంటి వనరు మరియు నియోజకవర్గ లోపాలను ముందుగా పరిశీలించండి. పేరుని నిర్దేశించే సమస్య పరిష్కారానికి షేర్డ్ లేదా ఉత్పత్తి వాతావరణాన్ని తీసివేయలేరు. **కొత్త తాత్కాలిక వాతావరణం** కొరకు, ప్రత్యేకమైన పేరు ఉపయోగించండి:

```bash
azd env new different-name
azd up
```

### క్వొటా మించిపోవడం
```bash
az vm list-usage --location eastus --output table
# Check the affected service's own quotas, not just VM quotas.
# For a new environment only, choose a supported region with available quota.
```

`AZURE_LOCATION` మార్పు వనరులను కదలవేయదు మరియు పునర్నియోజకవర్గ సమయంలో స్థాన విరోధాలను సృష్టించవచ్చు.

## 📋 లోప కోడ్ సూచిక

| లోపం | కారణం | పరిష్కారం |
|-------|-------|----------|
| `AuthenticationError` | లాగిన్ కాలేదు | `azd auth login` |
| `ResourceNotFound` | వనరు లేదు | వనరు పేర్లను తనిఖీ చేయండి |
| `QuotaExceeded` | సబ్స్క్రిప్షన్ పరిమితులు | క్వొటా పెంపు అభ్యర్థించండి |
| `InvalidTemplate` | బైసిప్ వ్యాకరణ లోపం | `az bicep build` |
| `Conflict` | వనరు ఇప్పటికే ఉంది | కొత్త పేరు ఉపయోగించండి లేదా తీసివేయండి |
| `Forbidden` | సముచిత అనుమతులు లేవు | RBAC పాత్రలను తనిఖీ చేయండి |

## 🔄 రీసెట్ మరియు పునరుద్ధరణ

```bash
# Soft reset (keep resources, redeploy code)
azd deploy

# Hard reset (delete everything, start fresh)
azd down
azd up
```

హార్డ్ రీసెట్ డేటాను తొలగిస్తుంది మరియు ఎండ్పాయింట్లను మార్చవచ్చు. ముందుగా బ్యాకప్ తీసుకోండి మరియు ఇంటరాక్టివ్ తొలగింపు సూచనలను సమీక్షించండి. `--force --purge` తప్పనిసరి తొలగింపు ఉద్దేశించినప్పుడు మాత్రమే తాత్కాలిక వాతావరణాల కొరకు అనుకూలం.
