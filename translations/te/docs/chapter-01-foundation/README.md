## అవలోకనం

ఈ అధ్యాయంలో Azure Developer CLI (azd) మూలాలు పరిచయం చేయబడతాయి. మీరు ప్రాథమిక సిద్ధాంతాలను నేర్చుకుంటారు, పరికరాలను ఇన్‌స్టాల్ చేస్తారు, మరియు మీ ראשון అప్లికేషన్ Azureకి పంపిణీ చేస్తారు.

> కందంకి మరియు కాన్ఫిగరేషన్ సమీక్ష లక్ష్యము: `azd 1.37.2` (నవంబర్ 2026). పరిశీలన సమయంలో ప్రత్యక్ష Azure ప్రదర్శన జరగలేదు.

## నేర్చుకునే లక్ష్యాలు

ఈ అధ్యాయం పూర్తి చేసిన తరువాత, మీరు:
- Azure Developer CLI అంటే ఏమిటి మరియు అది Azure CLI నుండి ఎలా భిన్నమో అర్థం చేసుకోగలరు
- మీ వేదికపై AZD ను ఇన్‌స్టాల్ చేసి కాన్ఫిగర్ చేయగలరు
- `azd up` తో మీ మొదటి అప్లికేషన్ Azureకి పంపిణీ చేయగలరు
- `azd down` తో వనరులను శుభ్రంగా చేస్తారు

## ✅ ఇక్కడనే ప్రారంభించండి: మీ సెటప్‌ను ధృవీకరించండి

మీరు ప్రారంభించే ముందు, మీ ప్రాదేశిక యంత్రం అధ్యాయం 1 టెంప్లేట్‌కు సిద్దమై ఉందని నిర్ధారించండి:

**విండోజ్:**
```powershell
.\validate-setup.ps1
```

**మ్యాక్‌ఓఎస్ / లినక్స్:**
```bash
bash ./validate-setup.sh
```

స్క్రిప్ట్ లో కోల్పోయిన పరికరాలు ఉంటే, వాటిని మొదట సరిచేయండి, ఆపై అధ్యాయం కొనసాగించండి.

## 🚀 త్వరిత ప్రారంభం

```bash
# Check installation
azd version

# Authenticate for AZD
# Optional: az login if you plan to run Azure CLI commands directly
azd auth login

# Deploy your first app
mkdir chapter1-demo
cd chapter1-demo
azd init --template todo-nodejs-mongo .
azd up

# Clean up when done
azd down --force --purge
```

---

## ✅ విజయపు ప్రమాణాలు

ఈ అధ్యాయం పూర్తయిన తర్వాత, మీరు: 

```bash
azd version              # Shows installed version
azd env list             # Lists the initialized environment
azd up                   # Deploys to Azure
azd show                 # Displays running app URL
azd down --force --purge # Cleans up resources
```
