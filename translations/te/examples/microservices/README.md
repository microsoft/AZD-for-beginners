# మైక్రోసర్వీసులు ఉదాహరణ

అమలు చేయగలిగే ఇంప్లిమెంటేషన్ మరియు దాని సూచనలు ఉండేది
**[container-app/microservices](../container-app/microservices/README.md)** లో ఉన్నాయి.

ఈ డైరెక్టరీ కేవలం నావిగేషన్ కోసం ఉంది. దీంట్లో `azure.yaml`, `infra/` లేదా `src/` లేవు.
ఇక్కడ `azd up` నడపకుండండి.

రిపోజిటరీ రూట్ నుండి:

```bash
cd examples/container-app/microservices
```

దానికి తరువాత, అవసరాలు, డిప్లాయ్‌మెంట్, ధృవీకరణ, స్థానిక
అభివృద్ధి, ప్రాయోగిక వ్యాయామాలు, ఖర్చులు మరియు శుభ్రపరిచే విధానం కోసం లింక్ అయిన README ను అనుసరించండి.

ఈ సాంపిల్ లో ఒక Node.js API గేట్వే మరియు ఒక చదవగలిగే Python ఉత్పత్తి సేవ ఉంది.
ఆర్డర్, యూజర్, నోటిఫికేషన్, డేటాబేస్, మరియు మెసేజింగ్ సేవలు విస్తరణ ఆలోచనలు,
రిపోజిటరీలో కలిగిన అమలు లేవు.
