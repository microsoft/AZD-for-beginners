## పరిచయం

ఈ సమగ్ర పదసంచిక Azure Developer CLI మరియు Azure క్లౌడ్ డెవలప్‌మెంట్‌లో ఉపయోగించే పదాలు, భావాలు, సంక్షిప్త రూపాల నిర్వచనాలను అందిస్తుంది. సాంకేతిక డాక్యుమెంటేషన్ అర్థం చేసుకోవడానికి, సమస్యలను పరిష్కరించడానికి మరియు azd ప్రాజెక్టులు మరియు Azure సేవల గురించి సమర్థవంతంగా కమ్యూనికేట్ చేయడానికి అవసరమైన సూచిక.

## నేర్చుకోదలువ్లు

ఈ పదసంచికను ఉపయోగిస్తూ, మీరు:
- అవసరమైన Azure Developer CLI పదజాలం మరియు భావాలను అర్థం చేసుకోగలరు
- Azure క్లౌడ్ డెవలప్‌మెంట్ నిపుణత మరియు సాంకేతిక పదాలు లో ప్రావీణ్యం పొందగలరు
- Infrastructure as Code మరియు డిప్లాయ్‌మెంట్ పదజాలాన్ని సమర్థవంతంగా సూచించగలరు
- Azure సేవల పేర్లు, సంక్షిప్త రూపాలు మరియు వాటి ఉపయోగాలను అర్థం చేసుకోగలరు
- సమస్య పరిష్కార మరియు డీబగ్గింగ్ పదజాల నిర్వచనాలను పొందగలరు
- అధునాతన Azure ఆర్కిటెక్చర్ మరియు డెవలప్‌మెంట్ భావాలు నేర్చుకోగలరు

## నేర్చుకునే ఫలితాలు

ఈ పదసంచికను తరచూ సూచిస్తూ, మీరు చేయగలరు:
- Azure Developer CLI సరైన పదజాలంతో సమర్థవంతంగా సంభాషించగలరు
- సాంకేతిక డాక్యుమెంటేషన్ మరియు పొరపాటు సందేశాలను స్పష్టంగా అర్థం చేసుకోగలరు
- Azure సేవలు మరియు భావాలతో విశ్వాసంగా నావిగేట్ చేయగలరు
- సరైన సాంకేతిక పదజాలంతో సమస్యలను పరిష్కరించగలరు
- సాంకేతిక భాషలో సరిగ్గా బృంద చర్చలకు సహాయం చేయగలరు
- Azure క్లౌడ్ డెవలప్‌మెంట్ పరిజ్ఞానాన్ని పద్ధతిగా విస్తరించగలరు

## A

**ARM టెంప్లేట్**  
Azure Resource Manager టెంప్లేట్. JSON ఆధారిత Infrastructure as Code ఫార్మాట్, Azure వనరులను నిర్వచించి డిక్లరేటివ్‌గా డిప్లాయ్ చేయడానికి ఉపయోగించబడుతుంది.

**అప్ సర్వీస్**  
వెబ్ అప్లికేషన్స్, REST APIs మరియు మొబైల్ బ్యాకెండ్‌లను ఇన్‌ఫ్రాస్ట్రక్చర్ నిర్వహణ లేకుండా హోస్ట్ చేయడానికి Azure యొక్క ప్లాట్‌ఫార్మ్-ఆస్- ఏ-సర్వీస్ (PaaS) ఆఫర్.

**అప్లికేషన్ ఇన్‌సైట్స్**  
అప్లికేషన్ పనితీరు, లభ్యత మరియు వినియోగంపై లోతైన అవగాహనను అందించే Azure యొక్క అప్లికేషన్ పెర్ఫార్మెన్స్ మానిటరింగ్ (APM) సేవ.

**Azure CLI**  
Azure వనరులను నిర్వహించడానికి కమాండ్-లైన్ ఇంటర్‌ఫేస్. ఇది AZDకి అనుబంధంగా ఉంటుంది కానీ వేరే లాగిన్ అవసరం; AZD ప్రాథమిక ధ్రువపత్రీకరణ `azd auth login` ఉపయోగిస్తుంది.

**Azure Developer CLI (azd)**  
డెవలప్‌మెంట్-కേന്ദ്രిత కమాండ్-లైన్ టూల్, టెంప్లేట్లు మరియు Infrastructure as Code ఉపయోగించి Azureకి అప్లికేషన్లను నిర్మించడం మరియు డిప్లాయ్ చేయడం వేగవంతం చేస్తుంది.

**azure.yaml**  
azd ప్రాజెక్ట్ యొక్క ప్రధాన కాన్ఫిగరేషన్ ఫైల్, ఇది సేవలు, ఇన్‌ఫ్రాస్ట్రక్చర్ మరియు డిప్లాయ్‌మెంట్ హుక్స్‌ని నిర్వచిస్తుంది.

**Azure Resource Manager (ARM)**  
వనరులను సృష్టించడం, నవీకరించడం మరియు తొలగించడం కోసం మేనేజ్మెంట్ లేయర్‌ను అందించే Azure డిప్లాయ్‌మెంట్ మరియు నిర్వహణ సేవ.

## B

**Bicep**  
Azure వనరులను డిప్లాయ్ చేయడానికి Microsoft అభివృద్ధి చేసిన డొమైన్-స్పెసిఫిక్ లాంగ్వేజ్ (DSL). ARM టెంప్లేట్ల కంటే సరళమైన సింటాక్స్ను అందిస్తూ ARMకి కాంపైల్ అవుతుంది.

**Build**  
మూల కోడ్‌ను కంపైల్ చేయడం, డిపెండెన్సీలను ఇన్‌స్టాల్ చేయడం మరియు అప్లికేషన్లను డిప్లాయ్‌కు సిద్ధం చేయడం ప్రక్రియ.

**బ్లూ-గ్రీన్ డిప్లాయ్‌మెంట్**  
రెండు అదే విధమైన ఉత్పత్తి వాతావరణాలను (నీలం మరియు ఆకుపచ్చ) ఉపయోగించే డిప్లాయ్‌మెంట్ విధానం, డౌన్‌టైమ్ మరియు ప్రమాదం తగ్గించడం కోసం.

## C

**కంటెయినర్ అప్లికేషన్స్**  
సంక్లిష్టమైన ఇన్‌ఫ్రాస్ట్రక్చర్ నిర్వహణ లేకుండా కంటెయినరైజ్డ్ అప్లికేషన్లను నిర్వహించే Azure యొక్క సర్వర్‌లెస్ కంటెయినర్ సేవ.

**CI/CD**  
నిరంతర ఇంటిగ్రేషన్/నిరంతర డిప్లాయ్‌మెంట్. కోడ్ మార్పులను సమ్మిళితం చేసి అప్లికేషన్లను ఆటోమేట్డ్‌గా డిప్లాయ్ చేసే పద్ధతులు.

**Cosmos DB**  
Azure యొక్క ప్రపంచవ్యాప్తంగా పంపిణీచేసిన, బహుమోడల్ డేటాబేస్ సేవ, ఇన్పుట్, లేటెన్సీ, లభ్యత మరియు సహకారతకు సమగ్ర SLAలు అందిస్తుంది.

**కాన్ఫిగరేషన్**  
అప్లికేషన్ ప్రవర్తన మరియు డిప్లాయ్‌మెంట్ ఎంపికలను నియంత్రించే సెట్టింగ్స్ మరియు పారామీటర్లు.

## D

**డిప్లాయ్‌మెంట్**  
లక్ష్య ఇన్‌ఫ్రాస్ట్రక్చర్‌పై అప్లికేషన్లు మరియు వాటి డిపెండెన్సీల‌ను ఇన్‌స్టాల్ చేసి కాన్ఫిగర్ చేసే ప్రక్రియ.

**డోక్కర్**  
కంటెయినరైజేషన్ టెక్నాలజీ ఉపయోగించి అప్లికేషన్లను అభివృద్ధి, షిప్ చేయడం మరియు నడిపే ప్లాట్‌ఫారం.

**Dockerfile**  
డోక్కర్ కంటెయినర్ ఇమేజ్ బిల్డ్ చేయడానికి సూచనలు కలిగిన టెక్స్ట్ ఫైల్.

## E

**పర్యావరణం**  
మీ అప్లికేషన్ యొక్క నిర్దిష్ట ఉదాహరణను ప్రతిబింబించే డిప్లాయ్‌మెంట్ లక్ష్యము (ఉదా: డెవలప్‌మెంట్, స్టేజింగ్, ప్రొడక్షన్).

**పర్యావరణ వేరియబుల్స్**  
రన్‌టైమ్‌లో అప్లికేషన్లు యాక్సెస్ చేయగల కీ-వాల్యూ జంటలుగా నిల్వ చేయబడిన కాన్ఫిగరేషన్ విలువలు.

**ఎండ్పాయింట్**  
అప్లికేషన్ లేదా సేవ అందుబాటులో ఉహించబడే URL లేదా నెట్‌వర్క్ చిరునామా.

## F

**ఫంక్షన్ అప్లికేషన్**  
సర్వర్‌లెస్ కంప్యూటు సేవ, ఇన్‌ఫ్రాస్ట్రక్చర్ నిర్వహణ లేకుండా ఈవెంట్-ఆధారిత కోడ్ నడపడానికి Azure అందించే సేవ.

## G

**GitHub Actions**  
వర్క్‌ఫ్లోలను ఆటోమేట్ చేసే GitHub రిపాజిటరీలతో సమగ్రీకరించిన CI/CD ప్లాట్‌ఫామ్.

**Git**  
మూల కోడ్ మార్పులను ట్రాక్ చేయడానికి ఉపయోగించే పంపిణీ చేయబడిన వెర్షన్ కంట్రోల్ సిస్టమ్.

## H

**హుక్స్**  
డిప్లాయ్‌మెంట్ లైఫ్‌సైకిల్中特ొప్పiweలు (preprovision, postprovision, predeploy, postdeploy) వద్ద నడిచే కస్టమ్ స్క్రిప్టులు లేదా కమాండ్లు.

**హోస్ట్**  
అప్లికేషన్ డిప్లాయ్ చేయబోయే Azure సేవ రకం (ఉదా: appservice, containerapp, function).

## I

**Infrastructure as Code (IaC)**  
మాన్యువల్ ప్రక్రియలకు బదులుగా కోడ్ ద్వారా ఇన్‌ఫ్రాస్ట్రక్చర్‌ను నిర్వచించడానికి మరియు నిర్వహించడానికి పద్ధతి.

**Init**  
సాధారణంగా ఒక టెంప్లేట్ నుండి కొత్త azd ప్రాజెక్టును ప్రారంభించే ప్రక్రియ.

## J

**JSON**  
JavaScript ఆబ్జెక్ట్ నోటేషన్. కాన్ఫిగరేషన్ ఫైళ్లు మరియు API ప్రతిస్పందనల కోసం సాధారణంగా ఉపయోగించే డేటా మార్పిడి ఫార్మాట్.

**JWT**  
JSON వెబ్ టోకెన్. JSON ఆబ్జెక్టుగా పార్టీల మధ్య సమాచారాన్ని సురక్షితంగా ప్రసారం చేయడానికి ప్రమాణ రూపం.

## K

**కీ వాల్ట్**  
సీక్రెట్లు, కీలు, సర్టిఫికెట్లను సురక్షితంగా నిల్వ చేయడానికి Azure అందించే సేవ.

**Kusto Query Language (KQL)**  
Azure Monitor, Application Insights మరియు ఇతర Azure సేవలలో డేటాను విశ్లేషించడానికి ఉపయోగించే క్వెరీ భాష.

## L

**లోడ్ బాలెన్సర్**  
అనేక సర్వర్‌లు లేదా ఇన్స్టాన్స్‌ల మధ్య వస్తున్న నెట్‌వర్క్ ట్రాఫిక్‌ను పంపిణీ చేసే సేవ.

**లాగ్ అనలిటిక్స్**  
క్లౌడ్ మరియు ఆన్-ప్రెమైసెస్ వాతావరణాల నుండి టెలిమెట్రీ డేటాను సేకరించి విశ్లేషించే Azure సేవ.

## M

**మేనేజ్డ్ ఐడెంటిటీ**  
ఇతర Azure సేవలకు ధ్రువపత్రీకరణ కోసం Azure సేవలకు ఆటోమేటిక్ మేనేజ్డ్ ఐడెంటిటీని అందించే Azure ఫీచర్.

**మైక్రోసర్వీసెస్**  
అప్లికేషన్లను చిన్న, స్వతంత్ర సేవల సమాహారంగా నిర్మించే ఆర్కిటెక్చర్ విధానం.

**మానిటర్**  
Azure యొక్క ఏకీకృత మానిటరింగ్ పరిష్కారం, ఇది అప్లికేషన్లు మరియు ఇన్‌ఫ్రాస్ట్రక్చర్ మీద పూర్తి-స్టాక్ ఆబ్జర్వబిలిటీని అందిస్తుంది.

## N

**Node.js**  
క్రోం V8 JavaScript ఇంజిన్‌పై నిర్మించిన జావాస్క్రిప్ట్ రంటి, సర్వర్ వైపు అప్లికేషన్లు అందించేందుకు.

**npm**  
Node.js కోసం ప్యాకేజీ మేనేజర్, డిపెండెన్సీలను మరియు ప్యాకేజీలను నిర్వహిస్తుంది.

## O

**ఆుట్పుట్**  
ఇన్‌ఫ్రాస్ట్రక్చర్ డిప్లాయ్‌మెంట్ నుండి తిరిగి వచ్చే విలువలు, అప్లికేషన్లు లేదా ఇతర వనరులు వాటిని ఉపయోగించవచ్చు.

## P

**ప్యాకేజీ**  
అప్లికేషన్ కోడ్ మరియు డిపెండెన్సీలను డిప్లాయ్‌కు సిద్ధం చేయడం ప్రక్రియ.

**పారామీటర్లు**  
డిప్లాయ్‌మెంట్‌ను కస్టమైజ్ చేయడానికి ఇన్‌ఫ్రాస్ట్రక్చర్ టెంప్లేట్స్‌కు ఇచ్చే ఇన్‌పుట్ విలువలు.

**PostgreSQL**  
Azureలో మేనేజ్డ్ సేవగా మద్దతు ఉన్న ఓపెన్-సోర్స్ రిలేషనల్ డేటాబేస్ సిస్టమ్.

**Provisioning**  
ఇన్‌ఫ్రాస్ట్రక్చర్ టెంప్లేట్లలో నిర్వచించిన Azure వనరులను సృష్టించి కాన్ఫిగర్ చేసే ప్రక్రియ.

## Q

**క్వోటా**  
Azure సబ్స్క్రిప్షన్ లేదా ప్రాంతంలో సృష్టించవచ్చున    		   

## R

**వనరు గ్రూప్**  
ఒకే జీవనచక్రం, అనుమతులు మరియు విధానాలను పంచుకుంటున్న Azure వనరుల కోసం తార్కిక కంటైనర్.

**వనరు టోకెన్**  
azd ద్వారా రూపొందించబడిన ప్రత్యేక స్ట్రింగ్, డిప్లాయ్‌మెంట్‌లలో వనరు పేర్ల ప్రత్యేకతను నిర్ధారిస్తుంది.

**REST API**  
HTTP పద్ధతులను ఉపయోగించి నెట్‌వర్క్ అప్లికేషన్ల రూపకల్పనకు ఉపయోగించే శైలీ.

**రోల్బ్యాక్**  
అప్లికేషన్ లేదా ఇన్‌ఫ్రాస్ట్రక్చర్ కాన్ఫిగరేషన్ యొక్క మునుపటి సంచికకు తిరిగి వెళ్లే ప్రక్రియ.

## S

**సేవ**  
azure.yamlలో నిర్వచించబడిన మీ అప్లికేషన్ భాగం (ఉదా: వెబ్ ఫ్రంట్‌ఎండ్, API బ్యాకెండ్, డేటాబేస్).

**SKU**  
స్టాక్ కీపింగ్ యూనిట్. Azure వనరుల కోసం వివిధ సేవా తరగతులు లేదా పనితీరు స్థాయిలను సూచిస్తుంది.

**SQL డేటాబేస్**  
Microsoft SQL Server ఆధారంగా Azure యొక్క మేనేజ్డ్ రిలేషనల్ డేటాబేస్ సేవ.

**స్థిర వెబ్ అప్లికేషన్స్**  
మూల కోడ్ రిపాజిటరీల నుండి పూర్తి-స్టాక్ వెబ్ అప్లికేషన్లను నిర్మించి డిప్లాయ్ చేయడానికి Azure సేవ.

**స్టోరేజ్ అకౌంట్**  
బ్లోబ్స్, ఫైళ్లు, క్యూ‌లు మరియు పట్టికల వంటి డేటా వస్తువులకు క్లౌడ్ స్టోరేజ్ అందించే Azure సేవ.

**సబ్స్క్రిప్షన్**  
వనరు గ్రూపులు మరియు వనరులను కలిగి ఉండే Azure అకౌంట్ కంటైనర్, బిల్లింగ్ మరియు యాక్సెస్ మేనేజ్‌మెంట్ తో.

## T

**టెంప్లేట్**  
సాధారణ పరిస్థితుల కోసం అప్లికేషన్ కోడ్, ఇన్‌ఫ్రాస్ట్రక్చర్ నిర్వచనాలు మరియు కాన్ఫిగరేషన్ ఉన్న ముందే తయారుచేసిన ప్రాజెక్ట్ నిర్మాణం.

**టెర్రాఫార్మ్**  
Azure సహా బహుళ క్లౌడ్ ప్రొవైడర్లకు మద్దతు ఇచ్చే ఓపెన్-సోర్స్ Infrastructure as Code టూల్.

**ట్రాఫిక్ మేనేజర్**  
అంతర్జాతీయ Azure ప్రాంతాల చెరట్టుగా ట్రాఫిక్‌ను పంపిణీ చేసే Azure యొక్క DNS ఆధారిత ట్రాఫిక్ లోడ్ బాలెన్సర్.

## U

**URI**  
యూనిఫామ్ రీసోర్సు ఐడెంటిఫైయర్. ఒక ప్రత్యేక వనరును గుర్తించే స్ట్రింగ్.

**URL**  
యూనిఫామ్ రీసోర్సు లోకేటర్. వనరు ఏ చోట ఉందో మరియు దాన్ని ఎలా పొందాలో వివరించే URI రకం.

## V

**వర్చువల్ నెట్‌వర్క్ (VNet)**  
Azureలో ప్రైవేట్ నెట్‌వర్క్‌లకు మౌళిక నిర్మాణం, ఐసోలేషన్ మరియు విభజనను అందిస్తుంది.

**VS కోడ్**  
Visual Studio Code. Azure మరియు azd ఇంటిగ్రేషన్‌తో ప్రాచుర్యం పొందిన కోడ్ ఎడిటర్.

## W

**Webhook**  
నిర్దిష్ట ఈవెంట్ల ద్వారా ట్రిగ్గర్ అయ్యే HTTP కాల్‌బ్యాక్, సాధారణంగా CI/CD పైప్‌లైన్లలో ఉపయోగిస్తారు.

**What-if**  
డిప్లాయ్‌మెంట్ చేయకుండానే ఏ మార్పులు జరుగుతాయో చూపించే Azure ఫీచర్.

## Y

**YAML**  
YAML Ain't Markup Language. azure.yaml వంటి కాన్ఫిగరేషన్ ఫైళ్ళకు ఉపయోగించే మానవ-పఠించదగిన డేటా సీరియలైజేషన్ ప్రమాణం.

## Z

**జోన్**  
Azure ప్రాంతంలో శారీరకంగా వేరుగా ఉన్న స్థలాలు, అవి redundancy మరియు అధిక లభ్యతను అందిస్తాయి.

| సెర్చ్ | Azure AI Search | ఇన్‌ఫ్రాస్ట్రక్చర్ వనరు, అప్లికేషన్ కాదు `host` |

- **బిల్డ్ పైప్‌లైన్**: కోడ్ బ్ల్డ్ మరియు పరీక్షించే ఆటోమేటెడ్ ప్రక్రియ
- **డిప్లాయ్‌మెంట్ స్లాట్**: అప్ సర్వీస్‌లో స్టేజింగ్ పర్యావరణం
- **పర్యావరణ సారూప్యం**: అభివృద్ధి, స్టేజింగ్ మరియు ప్రొడక్షన్ పర్యావరణాలను సమానంగా ఉంచడం

### భద్రతా పదాలు
- **మేనేజ్డ్ ఐడెంటిటీ**: ఆటోమేటిక్ క్రెడెన్షియల్ నిర్వహణని అందించే Azure ఫీచర్
- **కీ వాల్ట్**: సీక్రెట్లు, కీలు మరియు సర్టిఫికెట్ల కోసం సురక్షిత నిల్వ
- **RBAC**: Azure వనరులకు పాత్ర ఆధారిత యాక్సెస్ నియంత్రణ
- **నెట్‌వర్క్ సెక్యూరిటీ గ్రూప్**: నెట్‌వర్క్ ట్రాఫిక్ నియంత్రించే వర్చువల్ ఫైర్వాల్

### మానిటరింగ్ పదాలు
- **టెలిమెట్రీ**: కొలతలు మరియు డేటాను ఆటోమేటెడ్ సేకరణ
- **అప్లికేషన్ పెర్ఫార్మెన్స్ మానిటరింగ్ (APM)**: సాఫ్ట్‌వేర్ పనితీరు మానిటరింగ్
- **లాగ్ అనలిటిక్స్**: లాగ్ డేటాను సేకరించి విశ్లేషించే సేవ
- **అలర్ట్ నియమాలు**: కొలతలు లేదా పరిస్థితుల ఆధారంగా ఆటోమేటెడ్ నోటిఫికేషన్లు

### డిప్లాయ్‌మెంట్ పదాలు
- **బ్లూ-గ్రీన్ డిప్లాయ్‌మెంట్**: జీరో-డౌన్‌టైమ్ డిప్లాయ్‌మెంట్ వ్యూహం
- **క్యానరీ డిప్లాయ్‌మెంట్**: వినియోగదారుల ఉపసమూహానికి క్ర‌మేణ విడదీసుకునే విధానం
- **రోలింగ్ అప్డేట్**: అప్లికేషన్ ఇన్స్టాన్స్‌లను వరుసగా మార్చడం
- **రోల్బ్యాక్**: మునుపటి అప్లికేషన్ సంచికకు తిరిగి వెళ్లడం
