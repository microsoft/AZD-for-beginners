# AI డెవలపర్ల కోసం AZD వర్క్‌షాప్

Azure Developer CLI (AZD) నేర్చుకోవడానికి మరియు AI అనువర్తనం పంపిణీపై దృష్టి పెట్టిన ప్రాయోగిక వర్క్‌షాప్‌కి స్వాగతం. ఈ వర్క్‌షాప్ 3 దశలలో AZD టెంప్లేట్ల అన్వయానుభూతిని పొందేందుకు సహాయం చేస్తుంది:

1. **దొరెనము** - మీకు సరిపోయే టెంప్లేట్ కనుగొనండి.
1. **పంపిణీ** - పంపిణీ చేసి అది పనిచేస్తుందో లేదో ధృవీకరించండి.
1. **అనుకూలీకరణ** - మీ అవసరాలకి తగినట్లు మార్చండి మరియు పునరావృతం చేయండి!

ఈ వర్క్‌షాప్ కోర్స్‌లో, మీరు ప్రాథమిక డెవలపర్ టూల్స్ మరియు వర్క్‌ఫ్లోలతో కూడా పరిచయం అవుతారు, ఇది మీ సంపూర్ణ అభివృద్ధి ప్రయాణాన్ని సులభతరం చేస్తుంది.

<br/>

## బ్రౌజర్-ఆధారిత మార్గదర్శిని

వర్క్‌షాప్ పాఠాలు మార్క్‌డౌన్‌లో ఉన్నాయి. మీరు వాటిని నేరుగా GitHubలో నావిగేట్ చేసుకోవచ్చు - లేదా క్రింద స్క్రీన్షాట్‌లో చూపినట్లుగా బ్రౌజర్-ఆధారిత ప్రివ్యూ ప్రారంభించండి.

![Workshop](../../../translated_images/te/workshop.75906f133e6f8ba0.webp)

ఈ ఎంపిక ఉపయోగించడానికి - రిపాజిటరీని మీ ప్రొఫైల్‌కి ఫోర్క్ చేసుకుని, GitHub Codespaces ప్రారంభించండి. VS Code టెర్మినల్ యాక్టివ్ అయిన తర్వాత ఈ కమాండ్ టైప్ చేయండి:

ఈ బ్రౌజర్ ప్రివ్యూ GitHub Codespaces, డెవ్ కంటెయినర్లు, లేదా Python మరియు MkDocs ఇన్‌స్టాల్ చేయబడిన ఒక లోకల్ క్లోన్‌లో పనిచేస్తుంది.

```bash title="" linenums="0"
python -m pip install -r requirements-dev.txt
python -m mkdocs serve --config-file workshop/mkdocs.yml
```

ఈ కమాండ్లను **కోర్స్ రిపోజిటరీ రూట్** నుండి నడిపించండి, ప్రత్యేకంగా ప్రారంభించిన AI నమూనా నుండి కాదు. తప్పిదాలు కనిపించేలా ముందుముఖంలో ప్రివ్యూ ఉంచండి; Ctrl+Cతో ఆపండి. సర్వ్ చేయకుండా సైట్‌ను తనిఖీ చేయడానికి `python -m mkdocs build --strict --config-file workshop/mkdocs.yml` నడపండి.

కొన్ని సెకన్లలో, మీరు ఒక పాప్-అప్ డైలాగ్ చూడగలరు. `Open in browser` ఆప్షన్‌ని ఎంచుకోండి. వెబ్-ఆధారిత గైడ్ ఇప్పుడు కొత్త బ్రౌజర్ టాబ్‌లో ఓపెన్ అవుతుంది. ఈ ప్రివ్యూ కొన్ని లాభాలు:

1. **బిల్ట్-ఇన్ సెర్చ్** - కీవర్డ్లు లేదా పాఠాలను త్వరగా కనుగొనండి.
1. **కాపీ ఐకాన్** - కోడ్‌బ్లాక్స్‌పై హోవర్ చేయండి ఈ ఆప్షన్ చూడటానికి
1. **థీమ్ టోగుల్** - డార్క్ మరియు లైట్ థీమ్స్ మధ్య మార్చుకోండి
1. **సహాయం పొందండి** - ఫుటర్‌లో డిస్కార్డ్ ఐకాన్‌పై క్లిక్ చేసి చేరండి!

## వర్క్‌షాప్ సమీక్ష

**కాలవ్యవధి:** 3-4 గంటలు  
**స్థాయి:** ప్రారంభం నుంచి మాధ్యమం వరకు  
**ముందస్తు జ్ఞానం:** అజ్యూర్, AI భావనలు, VS కోడ్ & కమాండ్ లైన్ టూల్స్ పరిచయం.

ఇది ఒక ప్రాక్టికల్ వర్క్‌షాప్, మీరు చేయడం ద్వారా నేర్చుకుంటారు. వ్యాయామాలు పూర్తయిన తర్వాత, సెక్యూరిటీ మరియు ప్రొడక్టివిటీ ఉత్తమ అభ్యాసాలకు మీ ప్రయాణాన్ని కొనసాగించడానికి AZD ఫర్ బిగినర్స్ పాఠ్యક્રમ సమీక్ష చేయాలని మనసుపడుతుంది.

## మీరు నేర్చుకునేది

AZD టెంప్లేట్‌ను మైక్రోసాఫ్ట్ ఫౌండ్‌రీలో ఎండ్-టు-ఎండ్ అభివృద్ధికి వివిధ సామర్ధ్యాలు మరియు టూల్స్ అన్వేషించడానికి ఒక అభ్యాస వేదికగా ఆలోచించండి. ఈ వర్క్‌షాప్ ముగిసేవరకు, మీరు ఈ సందర్భంలో వివిధ టూల్స్ మరియు భావనలకు అనుభూతి కలిగిస్తారు.

| భావన  | లక్ష్యం |
|:---|:---|
| **అజ్యూర్ డెవలపర్ CLI** | టూల్ కమాండ్లు మరియు వర్క్‌ఫ్లోలను అర్థం చేసుకోండి |
| **AZD టెంప్లేట్స్**| ప్రాజెక్ట్ నిర్మాణం మరియు కాన్ఫిగరేషన్ అర్థం చేసుకోండి |
| **అజ్యూర్ AI ఏజెంట్**| మైక్రోసాఫ్ట్ ఫౌండ్‌రీ ప్రాజెక్ట్‌ను ప్రావీషనింగ్ & డిప్లాయ్ చేయండి  |
| **అజ్యూర్ AI సెర్చ్**| ఏజెంట్లతో సందర్భం ఇంజనీరింగ్‌ను ప్రారంభించండి |
| **నిరీక్షణ**| ట్రేసింగ్, మానిటరింగ్ మరియు అంచనాలను అన్వేషించండి |
| **రెడ్ టీమింగ్**| ప్రయోజనాత్మక పరీక్షన్లు మరియు పరిహారాలను చూడండి |

## వర్క్‌షాప్ నిర్మాణం

ఈ వర్క్‌షాప్‌ను టెంప్లేట్ అన్వేషణ నుండి ప్రారంభించి, డిప్లాయ్‌మెంట్, విడగొట్టడం, మరియు అనుకూలీకరణ వరకు ప్రయాణం చేసేలా నిర్మించారు - అధికారిక [Getting Started with AI Agents](https://github.com/Azure-Samples/get-started-with-ai-agents) స్టార్టర్ టెంప్లేట్ ఆధారంగా.

- **ల్యాబ్**: కోడ్స్‌పేసెస్ లేదా డెవ్ కంటైనర్‌లో క్విక్‌స్టార్ట్

### [మాడ్యూల్ 2: AI టెంప్లేట్ నిర్ధారించండి](docs/instructions/2-Validate-AI-Template.md) (30 నిమి)

- AZD కాన్ఫిగరేషన్‌ను `azure.yaml` లో అన్వేషించండి
- **ల్యాబ్**: పర్యావరణ 변ుల‌ల‌ను మార్చి తిరిగి నిమగ్నం చేయండి

- **ల్యాబ్**: మౌలిక సదుపాయాల తొలగింపు & శుభ్రపరిచటం

<br/>

## వర్క్‌షాప్ ఛాలెంజ్

మీను మరింత సవాలు చేయాలనుకుంటున్నారా? ఇక్కడ కొన్ని ప్రాజెక్ట్ సూచనలు ఉన్నాయి - లేక మీ ఆలోచనలను మాతో పంచుకోండి!!

| ప్రాజెక్ట్ | వివరణ |
|:---|:---|
|1. **ఒక సంక్లిష్ట AI టెంప్లేట్ విభజించండి** | మనం వివరించిన వర్క్‌ఫ్లో మరియు టూల్స్ ఉపయోగించి వేరే AI సొల్యూషన్ టెంప్లేట్ను డిప్లాయ్, నిర్ధారించండి మరియు అనుకూలీకరించగలారా చూడండి. _మీకు ఏమి నేర్చుకున్నాయి?_|
|2. **మీ సందర్భంతో అనుకూలీకరించండి**  | వేరే దృశ్యం కోసం PRD (ఉత్పత్తి అవసరాల డాక్యుమెంట్) రాయడానికి ప్రయత్నించండి. తర్వాత Agent Modelలో మీ టెంప్లేట్ రిపోలో GitHub Copilot ఉపయోగించి అనుకూలీకరణ వర్క్‌ఫ్లో జనరేట్ చేయమని అడగండి. _మీరు ఏమి నేర్చుకున్నారు? ఈ సూచనలను ఎలా మెరుగుపర్చగలరు?_|
