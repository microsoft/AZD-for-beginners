# 微服務範例

可執行的實作及其指令位於
**[container-app/microservices](../container-app/microservices/README.md)**。

此目錄僅供導覽。它沒有 `azure.yaml`、`infra/` 或 `src/`。
不要在此處執行 `azd up`。

從儲存庫根目錄開始：

```bash
cd examples/container-app/microservices
```

然後跟隨連結的 README 了解先決條件、部署、驗證、本地
開發、實用練習、費用及清理步驟。

範例包含一個 Node.js API Gateway 及一個只讀的 Python 產品服務。
訂單、用戶、通知、資料庫和訊息服務是擴展想法，
並非包含於此存放庫中的實作。
