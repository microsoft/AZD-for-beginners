# 支援

## 課程問題與提問

在回報問題前請先搜尋 [課程問題](https://github.com/microsoft/AZD-for-beginners/issues)。請包含受影響的英文課程、您執行的指令、您的 AZD/擴充版本，以及錯誤訊息。請從日誌和截圖中移除認證資訊、權杖、訂閱細節和個人資料。

若為一般學習問題，請使用 [Azure 開發者社群](https://discord.gg/microsoft-azure)。社群回應不保證為正式支援服務。

## 工具與服務問題

可在 [Azure/azure-dev](https://github.com/Azure/azure-dev/issues) 回報可重現的 AZD CLI 錯誤。若為 Azure 服務事件或訂閱特定協助，請使用 [Azure 入口網站](https://portal.azure.com/) 提供的支援選項。

## 安全性通報

私密漏洞通報請按照 [SECURITY.md](SECURITY.md)。請勿在公開課程問題中張貼機密資料或利用細節。

## Microsoft 支援政策

本教育專案的支援僅限上述資源。課程範例不包含生產環境支援承諾。
