# Microservices Voorbeeld

De uitvoerbare implementatie en de instructies bevinden zich in
**[container-app/microservices](../container-app/microservices/README.md)**.

Deze map is alleen voor navigatie. Het bevat geen `azure.yaml`, `infra/`, of `src/`.
Voer hier geen `azd up` uit.

Vanaf de root van de repository:

```bash
cd examples/container-app/microservices
```

Volg daarna de gelinkte README voor vereisten, deployment, verificatie, lokale
ontwikkeling, praktische oefeningen, kosten, en opruiming.

Het voorbeeld bevat een Node.js API Gateway en een read-only Python Product Service.
Order-, gebruikers-, notificatie-, database- en messagingdiensten zijn uitbreidingsideeën,
geen implementaties opgenomen in deze repository.

- [Volgende: Database-app](../../../../examples/database-app)
- [AI-ontwikkeling](../../docs/chapter-02-ai-development/README.md)
